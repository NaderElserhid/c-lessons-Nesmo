Bit Manipulation Tricks

سنفترض وجود المتغيرين التاليين في جميع الأمثلة:

int x;       // some non-negative integer
int k;       // 0-based bit index (0 = least significant bit)

وسنستخدم أقنعة (masks) مثل 1 << k، والتي يكون فيها البِت رقم $k$ فقط مساويًا لـ 1.

1. فحص ما إذا كان البِت $k$ يساوي 1

bool isSet = (x >> k) & 1;
  • x >> k: إزاحة لليمين بحيث ينتقل البِت رقم $k$ إلى أقصى اليمين.
  • (x >> k) & 1: تُبقي البِت الأيمن فقط وتصفّر باقي البِتّات.

الناتج يكون 0 أو 1، وهو يعادل false أو true منطقيًا.

💡 مثال وتوضيح:

افحص ما إذا كان البِت رقم 1 في $x$ مُعينًا (يساوي 1).

int x = 10;     // 10 = 1010 (in binary)
int k = 1;
bool isSet = (x >> 1) & 1; 
// 1010 >> 1 = 0101
// 0101 & 0001 = 0001 (true)

شرح: بعملية الإزاحة >> 1، تحرك البت الهدف من الموضع 1 ليصبح في الموضع 0 (أقصى اليمين). ثم باستخدام & 1 نحن نتجاهل كل البتات الأخرى ونسأل: "هل البت الأول هو 1؟".

معطى عددان $n$ و $k$، دالة تحدد ما إذا كان البِت رقم $k$ في $n$ مساويًا لـ1:

bool kthBitIsSet(int n, int k) {
    return (n >> k) & 1;
}

2. ضبط البِت رقم $k$ إلى 1

x |= (1 << k);

العامل | يعيّن البِت إلى 1 إذا كان على الأقل أحد الطرفين يحتوي 1. بهذا نجبر البِت رقم $k$ أن يصبح 1، بينما تبقى باقي البِتّات كما هي.

💡 مثال وتوضيح:

int x = 4;      // 0100
x |= (1 << 0);  // 0100 | 0001 = 0101 (5)

شرح: القناع (1 << 0) يولد 0001. عند عمل بوابة OR، فإن أي بت يقابله 0 في القناع لن يتأثر وينزل كما هو، بينما البت الذي يقابله 1 سيتحول إلى 1 إجبارياً.

3. تصفير البِت رقم $k$ (جعله 0)

x &= ~(1 << k);
  • 1 << k: قناع فيه البِت رقم $k$ يساوي 1.
  • ~(1 << k): قناع فيه البِت رقم $k$ يساوي 0، وجميع البِتّات الأخرى تساوي 1.

إجراء & مع هذا القناع يقوم بتصفير البِت رقم $k$ فقط.

💡 مثال وتوضيح:

int x = 13;         // 1101
x &= ~(1 << 2);     // ~(0100) = ...1011
                    // 1101 & 1011 = 1001 (9)

شرح: لكي "نُطفئ" بتاً معيناً دون تدمير الباقي، نحتاج قناعاً كله آحاد 1 ما عدا موقع البت الهدف يجب أن يكون 0. بوابة AND مع 1 تُبقي الرقم كما هو، بينما AND مع 0 تُدمره (تُصفره). الآن البِت رقم 2 أصبح 0.

4. قلب (تبديل) البِت رقم $k$

x ^= (1 << k);

العامل ^ (XOR) يقلب البِت عندما يكون القناع فيه 1:
0 ^ 1 = 1
1 ^ 1 = 0

💡 مثال وتوضيح:

int x = 5;     // 0101
x ^= (1 << 2); // 0101 ^ 0100 = 0001 (1)

شرح: البت رقم 2 كان 1، وأصبح الآن 0. لو أعدنا نفس العملية سينقلب مجدداً ويصبح 1.

5. إزالة أقل بِت معيّن (أقل 1 من اليمين)

هذه حيلة مشهورة جدًّا:

x = x & (x - 1);

هذا السطر يزيل (يُصفّر) أقل بِت معيّن (أول 1 من جهة اليمين) في $x$.

لماذا تعمل هذه الحيلة؟

فكّر ماذا يحدث للبِتّات عندما نطرح 1:

  • عند تنفيذ x - 1، نمشي من اليمين حتى نجد أول بِت قيمته 1.
  • هذا البِت الأقل (أقرب 1 لليمين) يتحوّل إلى 0.
  • كل البِتّات التي على يمينه (والتي كانت 0) تتحوّل إلى 1 (بسبب الاقتراض في الطرح).
x: .... 1 0 0 0 0 x - 1: .... 0 1 1 1 1 ------------------------- x&(x-1): .... 0 0 0 0 0

💡 استنتاج رياضي:

عند إجراء AND، أقل بِت معيّن يصبح 0 لأنه 1 & 0. كل البِتّات التي على يمينه كانت 0 في $x$ وتعطي 0 & 1 = 0. كل البتات التي على يساره متطابقة في الرقمين فتبقى كما هي.

مثال:
x = 12 = 1100
x - 1 = 11 = 1011
x & (x - 1) = 8 = 1000
إذًا قمنا بإزالة أقل بِت معيّن (البِت رقم 2).

6. فحص ما إذا كان $x$ قوة للعدد 2

سنفترض أن $x$ عدد موجب، ونستخدم الحيلة السابقة:

bool isPowerOfTwo = (x & (x - 1)) == 0;

💡 لماذا تعمل هذه الحيلة؟

العدد الذي هو قوة للعدد 2 في الثنائي (1, 10, 100, 1000, …) يحتوي بِتًا واحدًا فقط معيّنًا. عند إزالة هذا البت الوحيد باستخدام x & (x - 1)، تصبح القيمة بأكملها 0.

أمثلة:
$x = 8 \ (1000) \rightarrow 1000 \ \& \ 0111 = 0000$ $\rightarrow$ قوة للعدد 2.
$x = 12 \ (1100) \rightarrow 1100 \ \& \ 1011 = 1000$ $\rightarrow$ ليست 0 $\rightarrow$ ليس قوة للعدد 2.

7. الحصول على أقل بِت معيّن فقط

int lowest = x & -x;

هنا -x هو المتمّم الثنائي (two’s complement) للعدد $x$.

💡 الفكرة والمثال:

التعبير x & -x يعزل أقل بِت معيّن (أول 1 من جهة اليمين) ويصفّر جميع البِتّات الأخرى.

مثال:
x = 12 = ...00001100
-x (two's comp) = -12 = ...11110100
x & -x = 4 = ...00000100
أقل بِت معيّن في $x$ يمثّل القيمة 4 (أي البِت رقم 2).

📌 ملخص سريع للحفظ

  • فحص البِت رقم $k$: isSet = (x >> k) & 1;
  • ضبط البِت رقم $k$ إلى 1: x |= (1 << k);
  • تصفير البِت رقم $k$: x &= ~(1 << k);
  • قلب (تبديل) البِت رقم $k$: x ^= (1 << k);
  • إزالة أقل بِت معيّن: x &= (x - 1);
  • فحص إذا كان $x$ قوة للعدد 2: (x > 0) && (x & (x - 1)) == 0;
  • الحصول على أقل بِت معيّن فقط: lowest = x & -x;
