محاكي عمليات البتات

أداة تفاعلية لفهم كيفية عمل الأقنعة (Masks) وتغيير البتات في الوقت الفعلي.

1. المحاكي التفاعلي

قيمة x الثنائية: 00001010
القناع (Mask): 00000010
النتيجة النهائية:
00000010
بالعشري: 2 (true)

2. مسائل تدريبية

المسألة الأولى: عد البتات المرفوعة (Hamming Weight)

اكتب دالة بلغة C++ تقوم بحساب عدد البتات التي تساوي 1 في رقم معين باستخدام حيلة إزالة أقل بت x & (x - 1).

int countBits(int n) {
    int count = 0;
    while (n > 0) {
        n &= (n - 1); // يحذف أول 1 من اليمين
        count++;
    }
    return count;
}

المسألة الثانية: الرقم الفريد (Single Number)

معطى مصفوفة من الأرقام، كل رقم يتكرر مرتين بالضبط باستثناء رقم واحد. أوجد هذا الرقم باستخدام عملية XOR (بدون استخدام مساحة تخزين إضافية).

int singleNumber(vector<int>& nums) {
    int result = 0;
    for (int num : nums) {
        result ^= num; // المتشابه يلغي بعضه
    }
    return result;
}
