العمليات على مستوى البت 💻

المرحلة الثالثة: التفكير بلغة الآلة (Bitwise Operations). هنا حيث السرعة والأداء العالي!

🎮 محاكي البتات التفاعلي

اضغط على المربعات (0 و 1) لتغيير قيمة البتات، ولاحظ كيف يتغير الرقم العشري (Decimal) ونتيجة العملية!

الرقم A:
0
الرقم B:
0
النتيجة:
0

💡 ما هي العمليات على مستوى البت؟

أجهزة الكمبيوتر لا تفهم الأرقام مثلنا (1, 2, 3...)، بل تفهم فقط الصفر والواحد (0 و 1) وهو ما يسمى بالنظام الثنائي (Binary). كل رقم عشري نكتبه يتم تحويله في الذاكرة إلى سلسلة من البتات.

Bitwise Operations هي عمليات تتيح لنا التعديل على هذه الأصفار والآحاد مباشرة! وبما أنها لغة الكمبيوتر الأم، فإن تنفيذ هذه العمليات يكون أسرع بكثير من العمليات الحسابية العادية (الجمع، الضرب، القسمة).

⚙️ العمليات الأساسية

بوابة AND (و) &

تُعطي 1 فقط إذا كان كلا البتين 1. غير ذلك تعطي 0.

ABA & B
000
010
100
111
int a = 5;  // 0101
int b = 3;  // 0011
cout << (a & b); // 0001 = 1

بوابة OR (أو) |

تُعطي 1 إذا كان أي واحد من البتين 1.

ABA | B
000
011
101
111
int a = 5;  // 0101
int b = 3;  // 0011
cout << (a | b); // 0111 = 7

بوابة XOR (الاستبعاد) ^

تُعطي 1 إذا كان البتان مختلفين. وتُعطي 0 إذا كانا متشابهين.

ABA ^ B
000
011
101
110
int a = 5;  // 0101
int b = 3;  // 0011
cout << (a ^ b); // 0110 = 6

الإزاحة (Bit Shifting) << >>

تُزيح البتات لليسار أو اليمين.
الإزاحة لليسار << تضرب الرقم في 2.
الإزاحة لليمين >> تقسم الرقم على 2.

int x = 5;       // 0000 0101 (5)
cout << (x << 1);// 0000 1010 (10)
cout << (x >> 1);// 0000 0010 (2)

✨ حيل سحرية للأولمبياد باستخدام البتات!

  • هل الرقم زوجي أم فردي؟ بدلاً من x % 2 != 0، استخدم (x & 1). إذا كانت النتيجة 1 فالرقم فردي، وإذا كانت 0 فالرقم زوجي. (أسرع بكثير!).
  • الضرب والقسمة السريعة: لضرب رقم في 2 استخدم x << 1. لضرب رقم في 8 (وهي 2 أس 3) استخدم x << 3. للقسمة على 2 استخدم x >> 1.
  • تبديل متغيرين (Swap) بدون متغير ثالث: يمكنك استخدام XOR لتبديل القيمتين:
    a ^= b; b ^= a; a ^= b;
