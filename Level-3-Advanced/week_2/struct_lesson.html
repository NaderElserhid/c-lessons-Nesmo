الهياكل (struct) 📦

تعلم كيف تصنع أنواع بياناتك المخصصة وتجمع المتغيرات المترابطة في كيان واحد منظم!

🏗️ ما هي البنية (struct)؟

في لغة C++، تسمح لك البنية (struct) بتجميع عدة أجزاء من البيانات تحت اسم واحد. يمكنك التفكير فيها كـ "صندوق" أو "نموذج" يحتوي على عدة متغيرات مختلفة، وهذه المتغيرات قد تكون من أنواع مختلفة (مثل دمج نص string مع رقم int في مكان واحد).

تُسمى المتغيرات الموجودة داخل الـ struct بـ الأعضاء (Members). الـ struct مفيد جداً عندما تريد تمثيل "كيان" واحد له عدة خصائص (مثل طالب له: اسم، وعمر، ومعدل).

الصيغة العامة (Syntax):

struct TypeName {
    type1 member_name1;
    type2 member_name2;
    // ... يمكن إضافة المزيد
};
  • TypeName: هو اسم نوع البيانات الجديد الذي تعرّفه أنت.
  • الفاصلة المنقوطة ; في نهاية القوس المعقوف } ضرورية جداً! وإلا سيظهر لك خطأ برمجي.

🍎 مثال عملي: بنية المنتج (product)

لنفترض أننا نريد تخزين بيانات منتجات في سوبر ماركت. كل منتج له "وزن" و "سعر". بدلاً من تعريف متغيرات منفصلة لكل منتج، سنصنع struct يجمعها:

#include <iostream>
using namespace std;

// 1. تعريف البنية (صنع الصندوق)
struct product {
    int weight;     // الوزن بالجرام
    double price;   // السعر بالريال
};

int main() {
    // 2. إنشاء كائنات (متغيرات) من هذا النوع الجديد
    product apple;
    product banana, melon;

    // 3. الوصول للأعضاء وإعطائها قيماً باستخدام عامل النقطة (.)
    apple.weight = 150;
    apple.price  = 1.99;
    
    banana.weight = 120;
    banana.price  = 0.99;

    // 4. طباعة القيم
    cout << "Apple: "  << apple.weight  << " g, " << apple.price << " SAR" << endl;
    cout << "Banana: " << banana.weight << " g, " << banana.price << " SAR" << endl;
    
    return 0;
}

الوصول إلى الأعضاء (Accessing Members):

للوصول إلى متغير معين داخل الـ struct، نستخدم عامل النقطة . (Dot Operator).

  • apple.weight ← تعني "الوزن الخاص بالتفاحة".
  • apple.price ← تعني "السعر الخاص بالتفاحة".

يمكنك القراءة من هذه الأعضاء أو التعديل عليها أو طباعتها كما تفعل مع أي متغير عادي تماماً.

⚡ اختصار: تعريف الكائنات مع البنية مباشرة

تسمح لك C++ بإنشاء المتغيرات (الكائنات) في نفس اللحظة التي تُعرّف فيها الـ struct، وذلك بكتابة أسماء المتغيرات قبل الفاصلة المنقوطة النهائية:

struct product {
    int weight;
    double price;
} apple, banana, melon; // تعريف الكائنات هنا مباشرة!
هذه الطريقة مختصرة ومفيدة إذا كنت تعرف مسبقاً أنك ستحتاج إلى هذه المتغيرات المحددة فقط. ولكن في الغالب، يُفضل تعريف الـ struct أولاً، ثم إنشاء المتغيرات داخل الـ main لترتيب الكود.
