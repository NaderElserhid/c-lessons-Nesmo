مسألة الحقيبة
Knapsack 1

تعلّم كيف تختار أفضل مجموعة من العناصر بحيث تحصل على أعلى قيمة ممكنة دون تجاوز سعة الحقيبة.

اكتشف المزيد
المسألة

ما هي المسألة؟

لديك حقيبة سعتها W كيلوغرام، وN عنصر، كل عنصر له:


⚖️
الوزن wᵢ

كم يزن هذا العنصر

💎
القيمة vᵢ

كم يساوي هذا العنصر


الهدف: اختر مجموعة جزئية من العناصر بحيث:

مجموع الأوزان ≤ W   &   مجموع القيم → أكبر قيمة ممكنة

⚠️ كل عنصر يمكن أخذه مرة واحدة فقط (0/1 Knapsack)

القيود


  • 1 ≤ N ≤ 100
  • 1 ≤ W ≤ 100,000
  • 1 ≤ wᵢ ≤ W
  • 1 ≤ vᵢ ≤ 10⁹
AtCoder DP Sheet


هذه المسألة من المجموعة الشهيرة Educational DP Contest في AtCoder، وهي من أهم مسائل البرمجة الديناميكية الكلاسيكية.

الشرح

كيف نفكر في الحل؟

🧠 تعريف الحالة dp[i][j]

نعرّف:

dp[i][j] = أكبر قيمة ممكنة بالنظر إلى العناصر من 0 حتى i بسعة j

أي: ماذا لو أن معنا فقط أول i+1 عنصر وحقيبتنا سعتها j؟

🔀 الانتقال بين الحالات

عند النظر في العنصر i، لدينا خياران:


❌ لا نأخذ العنصر i
dp[i][j] = dp[i-1][j]

القيمة تساوي ما حصلنا عليه من العناصر السابقة بنفس السعة

✅ نأخذ العنصر i (إذا j ≥ wᵢ)
dp[i][j] = dp[i-1][j-wᵢ] + vᵢ

نضيف قيمته ونخصم وزنه من السعة المتبقية


نأخذ الأكبر بين الخيارين:

dp[i][j] = max( dp[i-1][j] , dp[i-1][j-wᵢ] + vᵢ )

🏁 الحالة الأساسية

dp[-1][j] = 0    (قبل أي عنصر القيمة صفر)

في الكود نبدأ من العنصر i=0 ونعالج الحالة الأساسية بشكل منفصل.

التعقيد الزمني
O(N × W)
التعقيد المكاني
O(N × W)

تعريف مصفوفة dp

نعرّف dp[i][j] بأنها أكبر قيمة يمكن تحقيقها باستخدام أول i+1 عناصر وسعة j.

نستخدم -1 كقيمة افتراضية للتمييز بين الخلايا المحسوبة وغير المحسوبة (Memoization).

3

إذا كانت السعة تكفي لأخذ العنصر الأول، نعيد قيمته، وإلا نعيد صفرًا.

4

لكل عنصر i وسعة j: نحسب الحالتين (أخذ / عدم أخذ) ونختار الأكبر.

5
استخراج النتيجة

الإجابة هي f(n-1, W) — أي أفضل قيمة باستخدام كل العناصر وكامل السعة.

المتغيرات العامة

knapsack.cpp 
long long dp[200][200000];
int v[200], w[200];
🔍 ماذا يعني هذا؟

dp[i][j] — مصفوفة ثنائية الأبعاد تحفظ أفضل قيمة للعناصر من 0 إلى i بسعة j.
نستخدم long long لأن القيم قد تصل إلى N × 10⁹ = 10¹¹، مما يتجاوز int العادي.
v[] و w[] تخزنان القيم والأوزان لكل عنصر.

الدالة الرئيسية (Recursive + Memoization)

knapsack.cpp 
long long f(int i, int capacity) {

  // الحالة الأساسية: العنصر الأول فقط
  if (i == 0) {
    if (capacity < w[i]) return 0;
    else                 return v[i];
  }

  // إذا سبق حساب هذه الحالة، أعدها مباشرة
  if (dp[i][capacity] != -1) return dp[i][capacity];

  // لا نأخذ العنصر i
  dp[i][capacity] = f(i - 1, capacity);

  // نأخذ العنصر i (إذا وزنه لا يتجاوز السعة)
  if (capacity >= w[i]) {
    dp[i][capacity] = max(dp[i][capacity],
                          f(i - 1, capacity - w[i]) + v[i]);
  }

  return dp[i][capacity];
}
🔍 كيف تعمل الدالة؟

1️⃣ Base case: إذا وصلنا للعنصر الأول، نتحقق هل يمكن أخذه أم لا.

2️⃣ Memoization: إذا حسبنا dp[i][capacity] من قبل، نعيده مباشرة بدلاً من إعادة الحساب — هذا ما يوفر الوقت!

3️⃣ الانتقال: نحسب حالة "عدم الأخذ" أولاً، ثم إذا كان الوزن يسمح، نحسب حالة "الأخذ" ونأخذ الأكبر.

الدالة الرئيسية main

knapsack.cpp 
int main() {
  
  // تهيئة كل الخلايا بـ -1 (لم تُحسب بعد)
  for (int i = 0; i < 200; i++)
    for (int j = 0; j < 200000; j++)
      dp[i][j] = -1;

  int n, weight;
  cin >> n >> weight;
  
  for (int i = 0; i < n; i++)
    cin >> w[i] >> v[i];

  // نطلب الإجابة: كل العناصر، أقصى سعة
  cout << f(n - 1, weight) << endl;
}
🔍 نقاط مهمة في main:

• نبدأ بتهيئة كل dp بـ -1 لنعرف أي خلايا لم تُحسب بعد.
• نقرأ المدخلات: N (عدد العناصر) و W (سعة الحقيبة)، ثم وزن وقيمة كل عنصر.
• نستدعي f(n-1, weight) لأن المصفوفة تبدأ من 0، وnَ1 هو آخر عنصر.

الكود الكامل

knapsack_full.cpp 
#include <iostream>
using namespace std;

long long dp[200][200000];
int v[200], w[200];


long long f(int i, int capacity) {

    if (i == 0) {
        if (capacity < w[i]) return 0;
        else                 return v[i];
    }

    if (dp[i][capacity] != -1) return dp[i][capacity];

    // i في حالة إستبعاد العنصر
    dp[i][capacity] = f(i - 1, capacity);

    // i في حالة أخذ العنصر
    if (capacity >= w[i]) {
        dp[i][capacity] = max(dp[i][capacity],
                              f(i - 1, capacity - w[i]) + v[i]);
    }

    return dp[i][capacity];
}


int main() {
  
    for (int i = 0; i < 200; i++)
        for (int j = 0; j < 200000; j++)
            dp[i][j] = -1;

    int n, weight;
    cin >> n >> weight;
  
    for (int i = 0; i < n; i++)
        cin >> w[i] >> v[i];

    cout << f(n - 1, weight) << endl;
}
