ما هي المشكلة؟

لديك صحراء مقسّمة إلى n صفًا وm عمودًا. كل خلية في الشبكة تحتوي على جمل من نوع معين (من 1 إلى k). مهمتك هي إيجاد عدد المناطق الخاصة.

الشروط الثلاثة للمنطقة الخاصة

يجب أن تتوافر الثلاثة شروط معًا:

١
شكل مستطيل
المنطقة يجب أن تكون مستطيلة (صفوف وأعمدة متتالية).
٢
نوع واحد
جميع الجمال داخل المستطيل من نفس النوع.
٣
لا يظهر خارجه
هذا النوع من الجمال لا يوجد في أي خلية خارج المستطيل.

المدخلات والمخرجات

صيغة الإدخال والإخراج

السطر الأول يحتوي على ثلاثة أعداد: عدد الصفوف (n)، عدد الأعمدة (m)، وعدد أنواع الجمال (k). ثم n سطرًا، كل سطر يحتوي على m عددًا يمثل نوع الجمل في كل خلية.

مثال ١ — المخرج: 1

⌨ المدخل
3 4 3 1 1 2 2 1 1 2 2 4 5 4 4
🖨 المخرج
1

النوع 1 يشكّل مستطيلًا 2×2 كاملًا ولا يظهر خارجه ✅. النوع 2 يظهر في عدة مناطق غير منتظمة ❌.

مثال ٢ — المخرج: 4

⌨ المدخل
4 5 4 1 1 2 2 2 1 1 2 2 2 3 3 3 4 4 3 3 3 4 4
🖨 المخرج
4

كل نوع (1، 2، 3، 4) يشكّل مستطيلًا كاملًا ولا يظهر خارجه — جميعها مناطق خاصة ✅

خطوات الحل

المنهجية الأساسية للحل

الفكرة الجوهرية هي: لكل نوع من الجمال، نحسب الصندوق المحيط به (bounding box) ثم نتحقق من شرطين.

١

حساب الصندوق المحيط لكل نوع (Bounding Box)

لكل نوع t من الجمال، نحسب: أصغر صف (r1)، أكبر صف (r2)، أصغر عمود (c1)، أكبر عمود (c2). هذا هو أصغر مستطيل يمكن أن يحوي جميع الجمال من النوع t.

for each cell (i,j): t = grid[i][j] r1[t] = min(r1[t], i) r2[t] = max(r2[t], i) c1[t] = min(c1[t], j) c2[t] = max(c2[t], j)
٢

حساب حجم الصندوق المحيط

بعد معرفة الصندوق المحيط، نحسب مساحته: (r2 - r1 + 1) × (c2 - c1 + 1). إذا ساوت هذه المساحة عدد خلايا النوع t، فالنوع يملأ المستطيل كاملًا.

box_size = (r2[t] - r1[t] + 1) * (c2[t] - c1[t] + 1) count_t = number of cells with type t if box_size == count_t: → النوع يملأ مستطيله تمامًا ✅
٣

التحقق من الحصرية — لا يوجد نوع آخر في الصندوق

يجب أن لا يوجد أي خلية داخل الصندوق المحيط تحمل نوعًا مختلفًا. نفحص جميع الخلايا في الصندوق. إذا وجدنا خلية من نوع آخر، المنطقة ليست خاصة.

for i in r1[t] .. r2[t]: for j in c1[t] .. c2[t]: if grid[i][j] != t: → غير خاصة ❌ break
٤

التحسين — استخدام مصفوفة المجاميع الجزئية (Prefix Sum)

بدلًا من فحص كل خلية في الصندوق (O(n×m) لكل نوع)، نبني مصفوفة مجاميع جزئية لكل نوع. هذا يجعل فحص مجموع أي مستطيل يتم في O(1) بدلًا من O(n×m). التعقيد الكلي يصبح O(n × m × k) في أسوأ الأحوال، لكن مع ضغط الأنواع يصير O(n×m).

// نحسب عدد الخلايا من النوع t داخل أي مستطيل // في O(1) بعد بناء الـ prefix sum في O(n×m) sum_in_box = query_prefix(r1,c1,r2,c2, type=t) if sum_in_box == box_size: → المنطقة خاصة ✅
٥

حساب الإجابة النهائية

نعدّ جميع الأنواع التي اجتازت الشرطين. الإجابة هي عدد هذه الأنواع.

ans = 0 for each type t in 1..k: if exists(t) AND box_size[t]==count[t] AND pure_box[t]: ans++ print(ans)

التعقيد الزمني

المرحلة التعقيد الملاحظة
قراءة الشبكة O(n·m) سريع جدًا
حساب الـ bounding box لكل نوع O(n·m) تمريرة واحدة
بناء مصفوفة المجاميع الجزئية O(n·m) مرة واحدة فقط
التحقق من كل نوع O(k) O(1) لكل نوع
الإجمالي O(n·m + k) ✅ يجتاز كل القيود

الكود الكامل

الحل بلغة C++

الكود التالي يعالج جميع الحالات ويجتاز القيود الكاملة. تم استخدام الـ prefix sum لجعل كل استعلام في O(1).

C++ — O(n·m + k) 
// ===================================================
// المناطق الخاصة في الصحراء
// الخوارزمية: Bounding Box + Prefix Sum
// التعقيد: O(n*m + k)
// ===================================================

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, k;
    cin >> n >> m >> k;

    // الشبكة الرئيسية
    vector<vector<int>> grid(n + 1, vector<int>(m + 1));

    // الصندوق المحيط + عدد الخلايا لكل نوع
    vector<int> r1(k + 1, n + 1), r2(k + 1, 0);
    vector<int> c1(k + 1, m + 1), c2(k + 1, 0);
    vector<long long> cnt(k + 1, 0);

    // قراءة الشبكة وحساب الـ bounding box
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> grid[i][j];
            int t = grid[i][j];
            r1[t] = min(r1[t], i);
            r2[t] = max(r2[t], i);
            c1[t] = min(c1[t], j);
            c2[t] = max(c2[t], j);
            cnt[t]++;
        }
    }

    // prefix sum ثنائي الأبعاد
    vector<vector<long long>> pre(n + 2, vector<long long>(m + 2, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            pre[i][j] = 1 + pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1];

    // دالة الاستعلام عن مجموع مستطيل
    auto query = [&](int r1, int c1, int r2, int c2) -> long long {
        return pre[r2][c2] - pre[r1-1][c2]
                            - pre[r2][c1-1]
                            + pre[r1-1][c1-1];
    };

    int ans = 0;

    // فحص كل نوع من الجمال
    for (int t = 1; t <= k; t++) {
        if (cnt[t] == 0) continue; // النوع غير موجود

        long long box = (long long)(r2[t] - r1[t] + 1)
                       * (c2[t] - c1[t] + 1);

        // الشرط الأول: يملأ الصندوق تمامًا
        if (box != cnt[t]) continue;

        // الشرط الثاني: كل الصندوق مشغول (لا خلايا فارغة أو مختلطة)
        long long total_in_box = query(r1[t], c1[t], r2[t], c2[t]);
        if (total_in_box != box) continue;

        ans++;
    }

    cout << ans << '\n';
    return 0;
}

💡 الفكرة الذكية في الـ Prefix Sum

نبني مصفوفة pre[i][j] تساوي عدد الخلايا في المستطيل من (1,1) إلى (i,j). ثم أي مستطيل (r1,c1) إلى (r2,c2) يُحسب في O(1) بالصيغة: pre[r2][c2] - pre[r1-1][c2] - pre[r2][c1-1] + pre[r1-1][c1-1] نتحقق أن مجموع الصندوق = مساحته = عدد خلايا النوع t. إذا تحقق ذلك، النوع يملأ الصندوق كاملًا بدون اختلاط.
