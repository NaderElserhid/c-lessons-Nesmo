خطوات الحل والخوارزمية
❌ الحل الساذج (Brute Force) — O(n²): اختبار كل الأزواج مباشرة. يعمل فقط حتى n ≈ 10,000 لكنه سيتجاوز الوقت عند n = 10⁵
✅ الحل الأمثل — O(30 × n) ≈ O(n): نبني الإجابة بتاً بتاً من أعلى بت إلى أدنى بت (Greedy على البتات)
1
الفكرة الأساسية: بناء الإجابة بتاً بتاً من الأعلى
بما أن aᵢ < 2³⁰، فالأعداد لا تتجاوز 30 بتاً. نبدأ من البت الأعلى (رقم 29) ونحاول "تثبيته" في الإجابة. الفكرة: إذا كان بإمكاننا الحصول على إجابة تحتوي هذا البت، فنحن نريده.
2
كيف نتحقق من "إمكانية" تثبيت بت؟
لنفترض أن الإجابة المبنية حتى الآن هي cur، ونريد إضافة البت b. نحاول الإجابة المؤقتة candidate = cur | (1 << b).

ثم نسأل: هل يوجد عددان مختلفان على الأقل في المصفوفة بحيث AND-هما مع candidate يساوي candidate نفسه؟
// إذا كان (aᵢ & candidate) == candidate
// فهذا يعني أن aᵢ يحتوي كل بتات candidate
// أي أن AND(aᵢ, aⱼ) ≥ candidate ممكن
3
الخوارزمية الكاملة
لكل بت من البت 29 حتى البت 0، نجرب إضافته للإجابة. نجمع كل الأعداد التي تحتوي كل بتات candidate. إذا كان عددها ≥ 2، نثبّت هذا البت في الإجابة.
cur = 0
for b = 29 downto 0:
  candidate = cur | (1 << b)
  count = 0
  for each a[i]:
    if (a[i] & candidate) == candidate:
      count++
  if count >= 2:
    cur = candidate // ثبّت هذا البت
print cur
4
لماذا هذا صحيح؟ (إثبات الصحة)
عملية AND لا تُنتج بتاً جديداً — النتيجة دائماً ≤ كل من العددين. إذا أردنا الإجابة النهائية تحتوي مجموعة معينة من البتات، يجب أن يوجد زوج من الأعداد يحتوي كلاهما كل هذه البتات.

المرور من أعلى بت للأدنى (Greedy) يضمن أننا نأخذ أكبر قيمة ممكنة، لأن البتات العليا أكثر قيمة.
5

O(30n)

O(n)

الكود الكامل (C++)
solution.cpp · Greedy Bit by Bit · O(30n) 
// مسألة: AND الأزواج
// الخوارزمية: Greedy من أعلى بت لأدنى بت
// التعقيد: O(30 × n)

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    cin >> n;

    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int cur = 0; // الإجابة المبنية حتى الآن

    // نمر على كل بت من أعلاه (29) إلى أدناه (0)
    for (int b = 29; b >= 0; b--) {

        int candidate = cur | (1 << b);
        // candidate هي الإجابة لو أضفنا البت b

        int count = 0;
        for (int i = 0; i < n; i++) {
            // هل يحتوي a[i] كل بتات candidate؟
            if ((a[i] & candidate) == candidate) {
                count++;
            }
        }

        // إذا وجدنا عددين أو أكثر، ثبّت هذا البت
        if (count >= 2) {
            cur = candidate;
        }
    }

    cout << cur << "\n";

    return 0;
}
