يوجد 3 صناديق تحتوي على كرات من 3 ألوان مختلفة. لكل صندوق، أنت تعرف عدد الكرات من كل لون الموجودة داخله.

هدفك هو نقل أقل عدد ممكن من الكرات من صندوق إلى آخر، بحيث بعد انتهاء جميع النقلات تتحقق الشرطان:
🚫 لا توجد كرتان في نفس الصندوق بلونين مختلفين — كل صندوق يحتوي لوناً واحداً فقط
🚫 لا توجد كرتان في صندوقين مختلفين ولهما نفس اللون — كل لون في صندوق واحد فقط
بمعنى آخر: في النهاية، كل صندوق يحتوي كرات من لون واحد بالضبط، وكل لون موجود في صندوق واحد بالضبط — وهو تعيين تبديلي (Permutation) للألوان على الصناديق.
📥 المدخلات
التوزيع الابتدائي للكرات داخل الصناديق يُعطى على شكل مصفوفة 3×3، تتكون المدخلات من ثلاثة أسطر:
🔴 لون 1 🟢 لون 2 🔵 لون 3
📦 صندوق 1 A₁,₁A₁,₂A₁,₃
📦 صندوق 2 A₂,₁A₂,₂A₂,₃
📦 صندوق 3 A₃,₁A₃,₂A₃,₃
حيث A[i][j] يمثل عدد الكرات من اللون j الموجودة في الصندوق i
القيد: 0 ≤ A[i][j] ≤ 100

خطوات الحل والخوارزمية
💡 الملاحظة الجوهرية: الحالة النهائية هي دائماً تبديل (Permutation) للألوان على الصناديق. بما أن 3 ألوان و3 صناديق، يوجد بالضبط 3! = 6 تباديل ممكنة فقط. نجرب كلها ونأخذ الأفضل.
1
فهم الهدف النهائي
في الحالة المثالية، كل صندوق يحتوي لوناً واحداً فقط، وكل لون في صندوق واحد. هذا يعني أننا نبحث عن تعيين بيجكتيف (Bijection): صندوق 1 → لون ؟، صندوق 2 → لون ؟، صندوق 3 → لون ؟

عدد التعيينات الممكنة = 3! = 6 فقط.
رقم التبديل صندوق 1 → لون صندوق 2 → لون صندوق 3 → لون
1🔴 1🟢 2🔵 3
2🔴 1🔵 3🟢 2
3🟢 2🔴 1🔵 3
4🟢 2🔵 3🔴 1
5🔵 3🔴 1🟢 2
6🔵 3🟢 2🔴 1
2
حساب تكلفة كل تبديل
لتبديل معين، كل صندوق i مُعيَّن للون p[i]. الكرات التي لا تُنقل هي الكرات من اللون p[i] الموجودة أصلاً في الصندوق i، وعددها A[i][p[i]].

إذن: الكرات المُبقاة = Σ A[i][p[i]] لكل i من 1 إلى 3.
والكرات المنقولة = إجمالي كل الكرات − الكرات المُبقاة.
// لكل تبديل p حيث p = [p0, p1, p2] (اللون المعين لكل صندوق)
saved = A[0][p[0]] + A[1][p[1]] + A[2][p[2]]
cost = total - saved
// حيث total = مجموع كل عناصر المصفوفة
3
الخوارزمية الكاملة
نحسب المجموع الكلي ثم نجرب جميع التباديل الـ6 ونأخذ أقل تكلفة.
// 1) احسب المجموع الكلي
total = Σ A[i][j] for all i,j

// 2) جرّب كل التباديل الـ6
perms = [[0,1,2],[0,2,1],[1,0,2],
         [1,2,0],[2,0,1],[2,1,0]]

best = total // في أسوأ حال ننقل الكل
for each perm in perms:
  saved = A[0][perm[0]] + A[1][perm[1]] + A[2][perm[2]]
  best = min(best, total - saved)

print best
4
لماذا هذا صحيح؟ (إثبات)
• أي حالة نهائية صحيحة هي بالضرورة تبديل للألوان على الصناديق (3 صناديق، 3 ألوان، كل لون مرة واحدة) — إذن مجموعة الحلول الممكنة = مجموعة التباديل الـ6 بالضبط.

• تكلفة أي تبديل = إجمالي الكرات − الكرات التي تبقى في مكانها. لتقليل النقلات، نعظّم الكرات المُبقاة.

• بجرب جميع الـ6 تباديل واختيار الأقل تكلفة، نضمن الحل الأمثل.

الكود الكامل (C++)
balls_boxes.cpp · جرب كل التباديل الـ6 · O(1) 
// مسألة: الكرات والصناديق
// الخوارزمية: جرب جميع التباديل الـ6 الممكنة
// التعقيد: O(1) — ثابت تماماً

#include <bits/stdc++.h>
using namespace fn;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int A[3][3];
    int total = 0;

    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++) {
            cin >> A[i][j];
            total += A[i][j];
        }

    // جميع التباديل الـ6 لـ {0,1,2}
    int perms[6][3] = {
        {0,1,2}, {0,2,1},
        {1,0,2}, {1,2,0},
        {2,0,1}, {2,1,0}
    };

    int ans = total; // أسوأ حالة: ننقل الكل

    for (int p = 0; p < 6; p++) {
        // الكرات التي تبقى في مكانها في هذا التبديل
        int saved = A[0][perms[p][0]]
                  + A[1][perms[p][1]]
                  + A[2][perms[p][2]];
        ans = min(ans, total - saved);
    }

    cout << ans << "\n";

    return 0;
}
