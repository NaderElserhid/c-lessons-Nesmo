إزالة الأعداد

في ممر طويل، يقف طلاب في صف — كل واحد يحمل عددًا. يأتي المعلم بقائمة أوامر ويُطلب منه إزالة الطالب الأقرب لليسار حاملًا ذلك العدد.

⏱ 1 ثانية 💾 256 MB 🔢 N, Q ≤ 2·10⁵

وصف المسألة

ما الذي يحدث؟

لديك مصفوفة A من N عنصر تمثّل طلابًا في صف — كل طالب يحمل عددًا. يدخل المعلم بقائمة Q أمر. في كل أمر يُنادي بعدد X، فيغادر الطالب الأقرب إلى اليسار الذي يحمل هذا العدد بهدوء. إذا لم يوجد أحد يحمل X، لا يحدث شيء. في النهاية، اطبع الطلاب الباقين بترتيبهم.

خطوات الحل

المنهجية الأساسية للحل

الفكرة الجوهرية: لكل قيمة نحتفظ بـ قائمة انتظار (queue) من المؤشرات. عند كل أمر، نُزيل الرأس من قائمة تلك القيمة — وهو دائمًا الأقرب لليسار.

١

بناء خريطة القيم ← قوائم المؤشرات

نمر على المصفوفة مرة واحدة ونملأ خريطة (map) تربط كل قيمة بقائمة (queue) من مؤشرات مواضعها بالترتيب من اليسار لليمين.

map<int, queue<int>> pos; for (int i = 0; i < n; i++) pos[A[i]].push(i); // نضيف المؤشر لقائمة قيمته
٢

تنفيذ كل أمر في O(log k)

لكل أمر X: نبحث في الخريطة عن X. إن وُجدت قائمة غير فارغة، نأخذ رأسها (المؤشر الأصغر = الأقرب لليسار) ونضعه في مجموعة المُزالين، ثم نحذفه من القائمة.

set<int> removed; // مجموعة المؤشرات المُزالة for (int x : queries) { if (pos.count(x) && !pos[x].empty()) { int idx = pos[x].front(); // الأقرب لليسار pos[x].pop(); removed.insert(idx); } }
٣

طباعة الباقين بالترتيب

نمر على المصفوفة الأصلية مرة أخيرة ونطبع كل عنصر لم يكن مؤشره في مجموعة المُزالين — الترتيب الأصلي محفوظ تلقائيًا.

for (int i = 0; i < n; i++) if (!removed.count(i)) cout << A[i] << ' ';
٤

لماذا هذا صحيح؟ — الأقرب لليسار دائمًا

لأننا ملأنا قوائم المؤشرات من اليسار لليمين (i=0,1,2,...) فإن front() دائمًا يعطي أصغر مؤشر لم يُزَل بعد = الأقرب لليسار. لا نحتاج لأي بحث خطي!

// مثال: A = [2, 5, 4, 2, 1, 3, 4] // pos[2] = queue{0, 3} ← مؤشرات 2 من اليسار // pos[4] = queue{2, 6} ← مؤشرات 4 من اليسار // أمر X=2 → نأخذ front()=0 → نُزيل A[0]=2 // أمر X=2 → نأخذ front()=3 → نُزيل A[3]=2

الكود الكامل

الحل بلغة C++

الكود التالي يعالج جميع الحالات ضمن القيود. يستخدم unordered_map للوصول الأسرع.

C++ — O((N+Q) log N) 
// =====================================================
// إزالة الأعداد — Queue + HashMap
// التعقيد: O((N+Q) log N)
// =====================================================

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;

    vector<int> A(n);
    for (int i = 0; i < n; i++) cin >> A[i];

    // لكل قيمة: قائمة مؤشراتها من اليسار لليمين
    unordered_map<int, queue<int>> pos;
    for (int i = 0; i < n; i++)
        pos[A[i]].push(i);

    // مجموعة المؤشرات التي سيُزال أصحابها
    unordered_set<int> removed;

    // تنفيذ الأوامر
    for (int i = 0; i < q; i++) {
        int x;
        cin >> x;

        auto it = pos.find(x);
        if (it != pos.end() && !it->second.empty()) {
            int idx = it->second.front(); // الأقرب لليسار
            it->second.pop();
            removed.insert(idx);
        }
        // إن لم يوجد: لا شيء يحدث
    }

    // طباعة الباقين بترتيبهم الأصلي
    bool first = true;
    for (int i = 0; i < n; i++) {
        if (!removed.count(i)) {
            if (!first) cout << ' ';
            cout << A[i];
            first = false;
        }
    }
    cout << '\n';

    return 0;
}

💡 لماذا Queue وليس Vector؟

استخدمنا queue لأننا نحتاج دائمًا إلى أصغر مؤشر (الأقرب لليسار). الـ queue تعطينا front() و pop() في O(1)، بينما حذف من vector يكون O(n). كذلك استخدمنا unordered_set للإزالة بدلًا من التعديل المباشر لتجنب إزاحة العناصر وللحفاظ على الترتيب الأصلي.
