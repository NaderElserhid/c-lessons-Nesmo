مقدمة: ما هو الـ Backtracking؟

Backtracking أو الرجوع للخلف هو أسلوب خوارزمي يُستخدم لاستكشاف جميع الحلول الممكنة لمسألة معينة. تعتمد الفكرة على بناء الحل تدريجيًا خطوةً بخطوة، واستكشاف كل الاحتمالات المتاحة في كل خطوة، ثم التراجع عن آخر قرار اتُّخذ بعد الانتهاء من استكشاف مساره بالكامل.

🔍 التعريف

Backtracking هو أسلوب يبني الحلول خطوةً بخطوة، ويستكشف جميع المسارات الممكنة باستخدام الاستدعاء الذاتي (Recursion). عند انتهاء مسار معين، يتراجع عن آخر خطوة ويجرّب المسار التالي.

🌳
بناء شجرة الحلول
كل خطوة تُولّد فرعين أو أكثر من الاحتمالات، تمامًا كشجرة القرارات
🔙
التراجع (Backtrack)
بعد استكشاف مسار كامل، يُلغي الخوارزمية آخر قرار ويجرّب البديل
🔄
الاستدعاء الذاتي
تعتمد الخوارزمية على Recursion لاستكشاف كل المسارات بشكل منظّم

تضمن الخوارزمية تجربة جميع الحلول الممكنة دون إغفال أي منها

كيف تعمل الخوارزمية؟

يمكن تلخيص عمل خوارزمية الـ Backtracking في أربع خطوات متكررة:

  • ١

    ابدأ بحل فارغ: نبدأ بحل لا يحتوي على أي عنصر بعد، ونمرر موضع البداية (i = 0) للدالة.

  • ٢

    مدّد الحل خطوة بخطوة: في كل استدعاء، نجرّب جميع الاحتمالات المتاحة للعنصر الحالي (إضافته أو استبعاده).

  • ٣

    استكشف بشكل متكرر: بعد كل اختيار، ننادي الدالة نفسها بشكل تكراري للانتقال للعنصر التالي (i+1)، حتى تستكشف جميع المسارات الممكنة.

  • ٤

    تراجع عن آخر خطوة: بعد الانتهاء من استكشاف مسار، نتراجع عن آخر تغيير أجريناه ونجرّب الاحتمال البديل.

💡 متى نتوقف؟

تتوقف الدالة عن الاستدعاء الذاتي عندما نصل إلى الحالة الأساسية (Base Case)، وهي عادةً عندما يتجاوز الموضع i نهاية المصفوفة (أي i == n). عند ذلك نطبع الحل الحالي ونرجع.

٣

توليد المجموعات الجزئية باستخدام Backtracking

لتوليد جميع المجموعات الجزئية لمصفوفة، نمر على عناصرها من اليسار لليمين، ونتّخذ في كل خطوة أحد القرارين:

➕
الاحتمال الأول: الإضافة
نضيف a[i] إلى المتجه v الذي يمثّل المجموعة الجزئية الحالية، ثم نتقدم للعنصر التالي.
➖
الاحتمال الثاني: الاستبعاد
لا نضيف a[i] ونتقدم مباشرةً للعنصر التالي دون أي تغيير.
🎯 فكرة التراجع هنا

بعد استكشاف المسار الذي أضفنا فيه a[i]، نستخدم v.pop_back() لإزالته والرجوع للحالة السابقة، ثم نستكشف المسار الذي لا يحتوي على a[i].

٤

الكود الكامل مع الشرح المفصّل

C++ · Backtracking Subsets 
#include <iostream>
#include <vector>
using namespace std;

int n = 3;
int a[3] = {5, 3, 1};
vector<int> v; // يخزّن عناصر المجموعة الجزئية الحالية

void backtracking(int i) {

    // الحالة الأساسية: تجاوزنا جميع العناصر، اطبع المجموعة الجزئية
    if (i == n) {
        cout << "subset: ";
        for (int j = 0; j < v.size(); j++) {
            cout << v[j] << ' ';
        }
        cout << "\n";
        return;
    }

    // الاحتمال الأول: إضافة a[i] إلى المجموعة الجزئية
    v.push_back(a[i]);    // أضف a[i] إلى v
    backtracking(i + 1); // استكشف جميع الحلول التي تضم a[i]

    // الاحتمال الثاني: استبعاد a[i] من المجموعة الجزئية
    v.pop_back();         // تراجع عن إضافة a[i]
    backtracking(i + 1); // استكشف جميع الحلول التي لا تضم a[i]

    // لا نحتاج لتراجع هنا لأننا لم نُجرِ أي تغيير في الاحتمال الثاني
}

int main() {
    backtracking(0);
    return 0;
}

مسألة تطبيقية: Apple Division (CSES)

📖 نص المسألة

لديك مصفوفة a من n عنصر تمثّل أوزان تفاحات. نريد تقسيم هذه التفاحات إلى مجموعتين بحيث يكون الفرق بين مجموع كل مجموعة أصغر ما يمكن. المطلوب طباعة هذا الفرق الأدنى.

الفكرة: نستخدم Backtracking لاستكشاف جميع طرق التقسيم الممكنة. في كل خطوة، نضع العنصر الحالي في المجموعة الأولى أو الثانية. نحسب الفرق في كل تقسيم ونحتفظ بالأصغر.

C++ · Apple Division Solution 
#include <iostream>
using namespace std;

int n;
long long a[20];
long long best; // أفضل (أصغر) فرق وجدناه حتى الآن

void solve(int i, long long sum1, long long sum2) {

    // الحالة الأساسية: قسّمنا جميع العناصر
    if (i == n) {
        long long diff = abs(sum1 - sum2);
        best = min(best, diff); // نحدّث الحل الأفضل
        return;
    }

    // الاحتمال الأول: نضع a[i] في المجموعة الأولى
    solve(i + 1, sum1 + a[i], sum2);

    // الاحتمال الثاني: نضع a[i] في المجموعة الثانية
    solve(i + 1, sum1, sum2 + a[i]);
}

int main() {
    cin >> n;
    long long total = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        total += a[i];
    }
    best = total; // أسوأ حالة: نضع الكل في مجموعة واحدة
    solve(0, 0, 0);
    cout << best << "\n";
    return 0;
}
▶ مثال على الإدخال والخرج
Input:  n=4, a = {3, 2, 7, 4}
Output: 2
(المجموعة الأولى: {3, 7} = 10 | المجموعة الثانية: {2, 4} = 6 → الفرق = 4)
(أو: {3, 2, 4} = 9 | {7} = 7 → الفرق = 2) ← الأفضل
✨ لماذا لا نحتاج pop_back هنا؟

لأننا نمرر المجاميع (sum1 و sum2) كمعاملات للدالة وليس كمتغيرات عالمية. عند الرجوع من الاستدعاء، القيم تعود تلقائيًا لما كانت عليه قبل الاستدعاء. هذا نمط شائع يُبسّط كتابة الـ Backtracking.

أمثلة إضافية متدرّجة

📘 مثال (أ) — طباعة جميع التباديل Permutations

التبديل هو ترتيب مختلف لعناصر المصفوفة. للمصفوفة {1, 2, 3} يوجد 3! = 6 تباديل. نستخدم مصفوفة used[] لتتبّع ما استُخدم من العناصر.

C++ · Permutations 
int n = 3;
int a[] = {1, 2, 3};
bool used[3] = {false, false, false};
vector<int> perm;

void permutations() {
    if (perm.size() == n) {
        for (int x : perm) cout << x << ' ';
        cout << "\n";
        return;
    }
    for (int i = 0; i < n; i++) {
        if (!used[i]) {
            perm.push_back(a[i]); // اختر a[i]
            used[i] = true;
            permutations();
            perm.pop_back();      // تراجع
            used[i] = false;
        }
    }
}
📗 مثال (ب) — عدّ المجموعات الجزئية ذات المجموع المحدد

عوضًا عن طباعة المجموعات، نحسب كم مجموعة جزئية مجموعها يساوي قيمة هدف معيّنة.

C++ · Count Subsets with Target Sum 
int count_subsets = 0;
int target = 6;

void countSubsets(int i, int currentSum) {
    if (i == n) {
        if (currentSum == target) count_subsets++;
        return;
    }
    countSubsets(i + 1, currentSum + a[i]); // إضافة a[i]
    countSubsets(i + 1, currentSum);         // استبعاد a[i]
}
📙 مثال (ج) — إيجاد أكبر مجموعة جزئية مجموعها أقل من حد معين

تطبيق عملي يجمع Backtracking مع تتبّع الحل الأمثل:

C++ · Largest Subset Sum Below Limit 
int limit = 7;
int bestSum = 0;

void findBest(int i, int currentSum) {
    if (currentSum <= limit)
        bestSum = max(bestSum, currentSum);
    if (i == n || currentSum > limit) return;

    findBest(i + 1, currentSum + a[i]); // جرّب الإضافة
    findBest(i + 1, currentSum);         // جرّب الاستبعاد
}
