القسم الأول

ما هي المجموعة الجزئية؟

قبل أن ندخل في تفاصيل الخوارزمية، يجب أن نُرسّخ المفهوم الأساسي جيدًا. المجموعة الجزئية (Subset) لأي مجموعة هي مجموعة تحتوي على صفر أو أكثر من عناصر المجموعة الأصلية، دون تكرار وبأي ترتيب.

🔍 تعريف رسمي
المجموعة B تُعدّ مجموعة جزئية من المجموعة A إذا كان كل عنصر في B موجودًا أيضًا في A. نُرمز لذلك بالعلامة: B ⊆ A

على سبيل المثال، لو كانت المصفوفة {1, 3, 5, 6, 7}، فإن:

✅
مجموعة جزئية صحيحة
{1, 3} — كلا العنصرين موجودان في المصفوفة الأصلية
✅
مجموعة جزئية صحيحة
{3, 5, 7} — العناصر الثلاثة موجودة في المصفوفة
✅
المجموعة الفارغة
{} — المجموعة الفارغة مجموعة جزئية من أي مجموعة دائمًا
❌
ليست مجموعة جزئية
{1, 4} — العنصر 4 غير موجود في المصفوفة الأصلية
💡 حقيقة مهمة
لمصفوفة طولها n، عدد المجموعات الجزئية المختلفة هو 2ⁿ. فمثلًا لمصفوفة من 3 عناصر يوجد 2³ = 8 مجموعات جزئية.
القسم الثاني

ترميز المجموعات الجزئية كأعداد ثنائية

الفكرة العبقرية هنا هي أننا نُمثّل كل مجموعة جزئية برقم ثنائي. لمصفوفة طولها n، يكون لكل مجموعة جزئية رقم ثنائي مكوّن من n بت، حيث:

1️⃣
البت = 1
العنصر المقابل لهذا البت موجود في المجموعة الجزئية
0️⃣
البت = 0
العنصر المقابل لهذا البت غير موجود في المجموعة الجزئية

باستخدام هذا الترميز، تنتقل المجموعات الجزئية لمصفوفة من 3 عناصر من القيمة الثنائية 000 (المجموعة الفارغة) إلى 111 (المجموعة الكاملة)، أي من 0 إلى 7 بالنظام العشري.

عدد المجموعات الجزئية
2ⁿ مجموعة (من 0 إلى 2ⁿ − 1)
القسم الثالث

جدول الترميز التفصيلي للمصفوفة {5, 3, 1}

لنأخذ المصفوفة a = {5, 3, 1} ذات الحجم n = 3. الجدول التالي يوضح جميع المجموعات الجزئية الثماني مع ترميزها الثنائي والعشري:

المجموعة الجزئية الترميز الثنائي (bit₂ bit₁ bit₀) القيمة العشرية تفسير البتات
{} 000 0 لا يوجد أي عنصر
{5} 001 1 البت 0 = 1 ← a[0]=5
{3} 010 2 البت 1 = 1 ← a[1]=3
{5, 3} 011 3 البتان 0 و 1 = 1 ← 5 و 3
{1} 100 4 البت 2 = 1 ← a[2]=1
{5, 1} 101 5 البتان 0 و 2 = 1 ← 5 و 1
{3, 1} 110 6 البتان 1 و 2 = 1 ← 3 و 1
{5, 3, 1} 111 7 جميع البتات = 1 ← المجموعة الكاملة
🎯 الاستنتاج الأساسي
كل رقم صحيح من 0 إلى 2ⁿ−1 يُمثّل بالضبط مجموعة جزئية واحدة. هذه الخاصية هي جوهر الخوارزمية التي سندرسها.
القسم الرابع

خوارزمية التوليد خطوة بخطوة

لتوليد جميع المجموعات الجزئية، نستخدم حلقتين متداخلتين وعملية التحقق من البت:

🔁
الحلقة الخارجية
تمر بجميع الأعداد من 0 إلى 2ⁿ − 1. كل عدد يُمثّل قناعًا (mask) لمجموعة جزئية معيّنة.
🔍
الحلقة الداخلية
تفحص كل بت في القناع من البت 0 إلى البت n−1 لتحديد العناصر المُضمَّنة في المجموعة الجزئية.
⚡
عملية AND الثنائية
نستخدم i & (1 << j) للتحقق إن كان البت رقم j مضبوطًا في القناع i.
🧮 فهم العملية i & (1 << j)

1 << j تُنشئ عددًا به البت رقم j فقط مضبوطًا على 1. ثم عملية AND تتحقق إن كان هذا البت موجودًا في i: 

i = 6  →  110 (ثنائي)
j = 1  →  1 << 1 = 010
AND    →  110 & 010 = 010 ≠ 0  ✓ البت مضبوط!

j = 0  →  1 << 0 = 001
AND    →  110 & 001 = 000 = 0  ✗ البت غير مضبوط
القسم الخامس

الكود الكامل مع الشرح المفصّل

C++ 
#include <iostream>
using namespace std;

int main() {
  int n = 3;
  int a[3] = {5, 3, 1};

  // نمر بجميع الأعداد من 0 إلى 2^n - 1
  // كل عدد i يُمثّل قناعًا لمجموعة جزئية
  for(int i = 0; i < (1 << n); i++) {
    cout << i << ": ";

    // نتحقق من كل بت في القناع i
    for(int j = 0; j < n; j++) {

      // هل البت رقم j في العدد i يساوي 1؟
      bool set = (i & (1 << j)) != 0;

      if(set) {
        // نطبع العنصر المقابل للبت
        cout << a[j] << ' ';
      }
    }

    cout << endl;
  }
}
▶ ناتج التنفيذ
0: 
1: 5 
2: 3 
3: 5 3 
4: 1 
5: 5 1 
6: 3 1 
7: 5 3 1
✨ لماذا نستخدم (1 << n) بدلًا من pow(2, n) ؟
عملية إزاحة البتات (1 << n) أسرع بكثير من دالة pow() لأنها عملية على مستوى البتات مباشرةً، وتُعطي نتيجة صحيحة دقيقة بدون مشاكل الأرقام العشرية.

📗 مثال 2 – طباعة المجموعات الجزئية بتنسيق مختلف

نطبع كل مجموعة جزئية بين أقواس معقوفة مع فصل العناصر بفاصلة:

C++
for(int i = 0; i < (1 << n); i++) {
  cout << "{ ";
  bool first = true;
  for(int j = 0; j < n; j++) {
    if(i & (1 << j)) {
      if(!first) cout << ", ";
      cout << a[j];
      first = false;
    }
  }
  cout << " }" << endl;
}
📙 مثال 3 – حساب مجموع كل مجموعة جزئية

تطبيق عملي: نحسب مجموع عناصر كل مجموعة جزئية:

C++
for(int i = 0; i < (1 << n); i++) {
  int sum = 0;
  for(int j = 0; j < n; j++) {
    if(i & (1 << j)) {
      sum += a[j];
    }
  }
  cout << "القناع " << i << ": المجموع = " << sum << endl;
}

📕 مثال 4 – مسألة تحدي: هل يوجد مجموعة جزئية مجموعها يساوي X؟

هذا النوع من المسائل يُسمى Subset Sum، وهو من أشهر مسائل البرمجة التنافسية. نبحث إن كان هناك مجموعة جزئية مجموعها يساوي قيمة هدف X:

C++
int target = 8; // هدفنا أن نجد مجموعة مجموعها = 8
bool found = false;

for(int i = 0; i < (1 << n); i++) {
  int sum = 0;
  for(int j = 0; j < n; j++) {
    if(i & (1 << j))
      sum += a[j];
  }
  if(sum == target) {
    cout << "وُجدت! القناع: " << i << endl;
    found = true;
  }
}
if(!found) cout << "لا توجد مجموعة جزئية بهذا المجموع";
