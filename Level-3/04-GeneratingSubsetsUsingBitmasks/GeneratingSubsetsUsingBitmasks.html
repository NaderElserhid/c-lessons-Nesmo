الفصل الرابع: توليد المجموعات الجزئية باستخدام الأقنعة الثنائية

تعلّمنا في الفصلين السابقين كيف نفحص، نُعيّن، ونُصفّر بِتًا واحدًا. الآن سنستخدم هذه المهارة لحل مشكلة أكبر: كيف نُوَلِّد كل المجموعات الجزئية الممكنة من مصفوفة صغيرة، باستخدام عدد ثنائي واحد فقط لكل مجموعة جزئية.

ما هي المجموعة الجزئية؟

المجموعة الجزئية لأي مصفوفة هي مجموعة يتم إنشاؤها من بعض عناصر المصفوفة (ربما بدون أي عنصر على الإطلاق). على سبيل المثال، بالنسبة للمصفوفة {1, 3, 5, 6, 7}:

  • {1, 3}، {3, 5, 7}، و{1, 3, 5, 6, 7} هي مجموعات جزئية صحيحة من المصفوفة.

  • {1, 4} و{2, 7} ليست مجموعات جزئية، لأن العناصر 4 و2 غير موجودة أصلًا في المصفوفة.

ترميز المجموعات الجزئية كأعداد ثنائية

بالنسبة لمصفوفة طولها n، يمكن تمثيل كل مجموعة جزئية باستخدام عدد ثنائي مكوّن من n بِت، حيث كل عنصر في المصفوفة له بِت يقابله في العدد الثنائي:

  • قيمة البِت 1 ⇔ العنصر المقابل موجود ضمن المجموعة الجزئية.

  • قيمة البِت 0 ⇔ العنصر المقابل غير موجود ضمن المجموعة الجزئية.

مثال: المصفوفة {5, 3, 1} (حيث a[0]=5، a[1]=3، a[2]=1). الترميزات الثنائية لكل مجموعاتها الجزئية:

عدد المجموعات الجزئية

عدد المجموعات الجزئية لمصفوفة طولها n = 2ⁿ

هذا منطقي: كل عنصر من عناصر المصفوفة له خياران فقط — إما أن يكون داخل المجموعة الجزئية أو خارجها — وبما أن لدينا n عنصرًا مستقلًا، فعدد التوليفات الممكنة هو 2 × 2 × ... × 2 (بتكرار n مرة) = 2ⁿ. بالنسبة لمصفوفة من 3 عناصر، هذا يعطينا 2³ = 8 مجموعة جزئية بالضبط، كما رأينا في الجدول أعلاه.

توليد كل المجموعات الجزئية

بما أن كل مجموعة جزئية تقابل رقمًا صحيحًا واحدًا بين 0 و 2ⁿ - 1، يمكننا ببساطة المرور عبر جميع هذه الأعداد الصحيحة، وتوليد كل مجموعة جزئية عن طريق التحقق من بِتّاتها واحدًا تلو الآخر.

البرنامج التالي يطبع كل المجموعات الجزئية من المصفوفة a، كل واحدة في سطر منفصل:

subsets.cpp
#include <iostream>
using namespace std;

int main() {
    int n = 3;
    int a[3] = {5, 3, 1};

    for (int i = 0; i < (1 << n); i++) {   // يمر بجميع الأعداد من 0 إلى 2^n - 1
        cout << i << ": ";
        for (int j = 0; j < n; j++) {        // يتكرر عبر جميع بِتّات الرقم i
            bool set = (i & (1 << j)) != 0;  // يتحقق إذا كان البِت j في i يساوي 1
            if (set) {
                cout << a[j] << ' ';
            }
        }
        cout << endl;
    }
}
0: 1: 5 2: 3 3: 5 3 4: 1 5: 5 1 6: 3 1 7: 5 3 1

  • الحلقة الخارجية تختار كل عدد i من 0 إلى 2ⁿ - 1 — كل قيمة لـi تمثّل مجموعة جزئية مختلفة.

  • الحلقة الداخلية تفحص كل بِت j من 0 إلى n-1 في i، وتضيف a[j] إلى الطباعة فقط إذا كان هذا البِت معيّنًا.

نشاط: مراجعة سريعة للترميز والفكّ

حدّد إن كانت كل عبارة صحيحة أم خاطئة (بالنسبة للمصفوفة {5, 3, 1}).

الترميز 110 يمثّل المجموعة الجزئية {3, 1}.

الترميز 000 يمثّل المجموعة {5, 3, 1} كاملة.

البِت رقم 1 (من اليمين) يقابل دائمًا العنصر a[1]، بغض النظر عن قيمته.

لمصفوفة من 3 عناصر، يوجد بالضبط 8 مجموعة جزئية ممكنة (بما فيها المجموعة الفارغة).

أخطاء شائعة

1) استخدام <= بدلًا من <

لو كتبت for (int i = 0; i <= (1 << n); i++)، سيُنفَّذ البرنامج مرة إضافية عند i = 2ⁿ، وهو رقم يحتاج فعليًا n+1 بِت لتمثيله — أي أنه ليس ترميزًا صحيحًا لأي مجموعة جزئية من مصفوفة طولها n. الحد الصحيح دائمًا هو i < (1 << n).

2) الخلط بين رقم البِت وقيمة العنصر

تذكّر أن البِت رقم j يقابل موضع العنصر a[j]، وليس قيمته. طباعة j بدلًا من a[j] خطأ شائع عند الاستعجال في كتابة الحلقة الداخلية.

3) فيضان (overflow) مع n كبيرة

إذا كانت n كبيرة (مثلًا 31 أو أكثر)، فإن 1 << n باستخدام النوع int (32 بِت) يفيض ويصبح رقمًا سالبًا:

overflow.cpp
int n = 31;
cout << (1 << n);  // يطبع -2147483648 بدلًا من 2147483648 !

الأخطر من ذلك: لو استخدمت هذا في شرط الحلقة for (int i = 0; i < (1 << n); i++)، فإن الشرط 0 < -2147483648 يكون خطأً منذ البداية، فتتوقف الحلقة عن التنفيذ فورًا دون أي خطأ ترجمة أو تحذير واضح — ببساطة لن تحصل على أي مخرجات! لتفادي هذا، استخدم long long: 1LL << n.

نشاط: مراجعة سريعة للخوارزمية والأخطاء الشائعة

حدّد إن كانت كل عبارة صحيحة أم خاطئة.

شرط الحلقة الصحيح لتوليد كل المجموعات الجزئية هو i < (1 << n).

استخدام i <= (1 << n) بدلًا من < يعطي نفس النتيجة تمامًا.

مع n = 31 والنوع int، فإن 1 << n يفيض ويصبح رقمًا سالبًا.

في الحلقة الداخلية، يجب أن نطبع a[j] لنحصل على قيمة العنصر، وليس j نفسه.

خلاصة سريعة

كل مجموعة جزئية من مصفوفة طولها n تُرمَّز برقم ثنائي من n بِت، حيث البِت j يعني "هل a[j] موجود؟".
عدد المجموعات الجزئية الكلي هو 2ⁿ.
نولّد كل المجموعات الجزئية بالمرور على كل i من 0 إلى 2ⁿ-1، وفحص بِتّات i واحدًا تلو الآخر.
احذر: استخدم < وليس <=، واحذر فيضان int عندما تكون n كبيرة.

تمارين منزلية

1) فكّ الترميز

المصفوفة a = {2, 4, 6, 8} (أي a[0]=2, a[1]=4, a[2]=6, a[3]=8). ما المجموعة الجزئية التي يمثّلها الترميز mask = 11؟

11 بالثنائي (على 4 بِتّات) = 1011، أي البِتّات 0، 1، و3 معيّنة (البِت 2 غير معيّن).

mask=11 (1011) -> a[0]=2, a[1]=4, a[3]=8 المجموعة الجزئية: {2, 4, 8}

2) الترميز

لنفس المصفوفة a = {2, 4, 6, 8}، ما الترميز العشري (mask) الذي يمثّل المجموعة الجزئية {4, 8}؟

4 هو a[1] و8 هو a[3]، فنُعيّن البِتّين 1 و3: (1<<1) | (1<<3) = 0010 | 1000 = 1010.

encode {4, 8} -> mask = 10 (1010)

3) اكتشف الخطأ الصامت

زميلك كتب الكود التالي لتوليد كل المجموعات الجزئية لمصفوفة كبيرة من 31 عنصرًا، لكنه لم يحصل على أي مخرجات إطلاقًا رغم أن الكود تُرجم بنجاح دون أي تحذير:

find_error3.cpp
int n = 31;
for (int i = 0; i < (1 << n); i++) {
    // ... توليد المجموعة الجزئية رقم i ...
}

ما سبب عدم ظهور أي مخرجات؟ وكيف تُصلح المشكلة؟

1 << 31 بنوع int (32 بِت) يفيض ويصبح -2147483648 (رقمًا سالبًا) بدلًا من 2147483648. وبذلك يصبح شرط الحلقة 0 < -2147483648 خطأً منذ البداية، فلا تُنفَّذ الحلقة ولو مرة واحدة — دون أي رسالة خطأ.

1 << 31 (int) = -2147483648 1LL << 31 (long long) = 2147483648 (الصحيح)

الإصلاح: استخدم long long للحد الأعلى، مثل for (long long i = 0; i < (1LL << n); i++). (ملاحظة جانبية: عمليًا، تكرار 2³¹ مرة بطيء جدًا؛ هذه الحيلة تصلح فقط لقيم n صغيرة، وهو ما سنراه لاحقًا عند دراسة قيود هذا الأسلوب.)
