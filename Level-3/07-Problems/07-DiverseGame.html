Diverse Game (لعبة التنويع)

مسألة إنشائية (Constructive) مباشرة من فصل المسائل الإنشائية: لدينا مصفوفة كاملة (تحتوي كل الأعداد من 1 إلى n·m)، والمطلوب بناء مصفوفة أخرى بنفس الخاصية، لكن مختلفة عن الأولى في كل خلية بلا استثناء. الفكرة نفسها التي رأيناها مع Anti-Identity Permutation، لكن هذه المرة مطبّقة على مصفوفة كاملة بدلًا من مصفوفة أحادية البعد.

Easy Codeforces 1994A

نص المسألة

لديك مصفوفة a بحجم n × m، تحتوي كل الأعداد الصحيحة من 1 إلى n·m كل واحد منها مرة واحدة بالضبط. اِبنِ مصفوفة b بنفس الحجم، تحتوي هي أيضًا كل الأعداد من 1 إلى n·m كل واحد مرة واحدة، بحيث يكون لكل خلية (i, j): a[i][j] ≠ b[i][j]. إن كان هذا مستحيلًا، اطبع -1.

القيود

  • عدد حالات الاختبار 1 ≤ t ≤ 1000

  • 1 ≤ n, m ≤ 10 لكل حالة

  • مجموع n·m على كل حالات الاختبار لا يتجاوز 5×10⁴

مثال

Input: 5 1 1 1 2 1 2 1 1 5 2 4 5 3 1 Output: -1 1 2 4 5 3 1 2

في الحالة الأولى (n=m=1)، لا يوجد سوى قيمة واحدة ممكنة (1)، وهي بالضرورة مطابقة لقيمة a نفسها → مستحيل. في الحالة الثانية، b=[1, 2] يحقّق 1≠2 و2≠1.

ملحوظة مهمة: المسألة تقبل أي مصفوفة b صحيحة، وليس بالضرورة نفس المصفوفة الموجودة في المثال الرسمي. في الحالة الثالثة أعلاه مثلًا، الناتج الرسمي المعطى هو 4 5 3 1 2، لكن حلّنا في هذه الصفحة سيُنتج مصفوفة مختلفة عنها شكليًا (وصحيحة بنفس القدر) — تمامًا كما حدث سابقًا مع مسألة Sum of Three Values.

فكرة الحل: التدوير بمقدار واحد

  • هذه المسألة نسخة مصفوفية من Anti-Identity Permutation: بدل أن نُدوّر مصفوفة أحادية، نُدوّر كل قيمة في المصفوفة الثنائية بمقدار واحد ضمن المجال 1..n·m.

  • لكل خلية: b[i][j] = a[i][j] + 1، إلا إذا كانت a[i][j] = n·m (القيمة الأكبر)، فعندها b[i][j] = 1 (نلفّ من جديد لبداية المجال).

  • لماذا هذا يعمل دائمًا (تقريبًا)؟ لأن التدوير بمقدار واحد يُبقي كل القيم مختلفة عن بعضها (فهو لا يزال تبديلًا كاملًا لـ1..n·m)، وفي نفس الوقت كل قيمة تُصبح مختلفة عن قيمتها الأصلية — إلا في حالة واحدة فريدة.

  • الاستثناء الوحيد: إذا كان n·m = 1 (أي n=m=1)، فإن التدوير يُعيد القيمة الوحيدة إلى نفسها (1 → 1)، تمامًا كما رأينا مع n=1 في Anti-Identity Permutation. هذه هي الحالة الوحيدة المستحيلة.

هذا مثال جميل على قابلية إعادة استخدام فكرة إنشائية واحدة (التدوير بمقدار واحد لتفادي النقاط الثابتة) في أكثر من شكل: مصفوفة أحادية البعد، أو مصفوفة ثنائية الأبعاد، أو أي بنية بيانات أخرى تحتاج "كل عنصر يجب أن يتغيّر".

مختبر تفاعلي: ولّد مصفوفة عشوائية وابنِ نظيرتها

اختر n وm، ثم ولّد مصفوفة a عشوائية حقيقية

اضغط "الخطوة التالية" أو "تشغيل تلقائي" للبدء.

في كل خلية، السطر الرمادي العلوي هو قيمة a الأصلية، والسطر الغامق السفلي هو قيمة b المحسوبة فعليًا بواسطة الخوارزمية الحقيقية أثناء التشغيل (وليست بيانات جاهزة) — جرّب توليد مصفوفة عشوائية جديدة أكثر من مرة لترى أن الفكرة تعمل دائمًا (ما لم تكن n=m=1).

الحل الكامل

diverse_game.cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;

    while (t--) {
        int n, m;
        cin >> n >> m;

        int a[n][m], b[n][m];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                cin >> a[i][j];

                if (a[i][j] == n * m) b[i][j] = 1;
                else b[i][j] = a[i][j] + 1;
            }
        }

        if (n == 1 && m == 1) {
            cout << -1 << "\n";
            continue;
        }

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                cout << b[i][j] << ' ';
            }
            cout << "\n";
        }
    }
}

ملحوظة قابلية النقل: التصريح int a[n][m] بأبعاد غير ثابتة (VLA — Variable Length Array) مقبول في مصرّفات مثل GCC (المستخدم في أغلب حكّام المسائل)، لكنه ليس جزءًا من معيار ++C القياسي رسميًا. البديل المحمول والآمن دائمًا هو استخدام vector<vector<int>> a(n, vector<int>(m));.

نقاط يجب الانتباه لها

ترتيب الفحصاحسب b بالكامل أثناء القراءة، ثم افحص حالة n=m=1 قبل الطباعة — إن طبعت b قبل التأكد من الاستحالة ستطبع إجابة خاطئة لتلك الحالة تحديدًا.
لا تنسَ سطر جديد بعد كل حالةكل حالة اختبار يجب أن تُطبَع في سطر/أسطر منفصلة؛ عدم إضافة "\n" بعد كل صف قد يخلط مخرجات حالات الاختبار المتتالية.
القيمة المطبوعة ليست فريدةلا يوجد "الحل الصحيح الوحيد" — أي مصفوفة b تحقّق الشرطين (تبديل كامل + اختلاف عن a في كل خلية) مقبولة لدى الحكم.

نفس درس Anti-Identity Permutation بالضبط، لكن على بنية بيانات مختلفة: "أزح كل قيمة بمقدار واحد دائريًا" يبني تبديلًا بلا نقاط ثابتة تلقائيًا، وحالة الاستحالة الوحيدة تظهر فقط عندما لا يوجد سوى عنصر واحد في كامل البنية.
