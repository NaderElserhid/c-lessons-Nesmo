Backtracking

في الفصل الرابع ولّدنا كل المجموعات الجزئية بالمرور على أرقام من 0 إلى 2ⁿ-1. الآن سنرى طريقة أخرى، أكثر عمومية وقوة: Backtracking — نبني الحل قرارًا بعد قرار، ونتراجع (نلغي القرار) كلما استكشفنا كل الاحتمالات في اتجاه معيّن. هذا الأسلوب سيصبح أداتك الأساسية لحل مسائل أكبر بكثير من مجرد توليد المجموعات الجزئية.

ما هو Backtracking؟

Backtracking هو أسلوب يستكشف جميع الحلول الممكنة لمشكلة معينة. يقوم الـ Backtracking ببناء الحلول خطوة بخطوة، ويتراجع عن الخطوات كلما انتهى من استكشاف اتجاه معيّن.

كيف تعمل؟

تبدأ خوارزمية Backtracking بحل فارغ. في كل خطوة، تحاول الخوارزمية كل الطرق الممكنة. بعد استكشاف جميع الطرق، تتراجع الخوارزمية إلى الخطوة السابقة عن طريق إلغاء آخر خطوة. يمكن تلخيص الخوارزمية كما يلي:

  • ابدأ بحل فارغ.

  • قم بتمديد الحل خطوة بخطوة.

  • استكشف بشكل متكرر جميع الطرق المختلفة التي يمكن أن يُبنى بها الحل.

  • تراجع عن آخر خطوة تم تنفيذها.

لاحظ أن هذا الوصف عامّ جدًا — Backtracking ليس خوارزمية واحدة محددة، بل هو إطار عام نطبّقه بطرق مختلفة حسب المشكلة. سنرى مثالين مختلفين في هذا الفصل.

توليد المجموعات الجزئية عبر Backtracking

لتوليد جميع المجموعات الجزئية لمصفوفة باستخدام Backtracking، ابدأ بحل فارغ. في كل خطوة، لديك الموقع i؛ حاول كلا الاحتمالين: إضافة a[i] إلى المجموعة الجزئية أو استبعاده. بعد استكشاف كل طريقة، تراجع عن آخر تغيير. عندما يصبح i خارج المصفوفة (i == n)، اطبع المجموعة الجزئية الحالية.

subsets_backtracking.cpp
#include <iostream>
#include <vector>
using namespace std;

int n = 3;
int a[3] = {5, 3, 1};
vector<int> v;

void backtracking(int i) {

    // إذا i == n، تم المرور على جميع العناصر، اطبع المجموعة الجزئية الحالية
    if (i == n) {
        cout << "subset: ";
        for (int j = 0; j < v.size(); j++) {
            cout << v[j] << ' ';
        }
        cout << "\n";
        return;
    }

    // حاول إضافة a[i] إلى المجموعة الجزئية
    v.push_back(a[i]);   // أضفها إلى v
    backtracking(i + 1); // حاول جميع الحلول حيث a[i] موجودة في v

    // حاول إستبعاد a[i] من المجموعة الجزئية
    v.pop_back();        // تراجع عن إضافة a[i]
    backtracking(i + 1); // حاول جميع الحلول حيث a[i] غير موجودة في v

    // لا نحتاج لأي تراجع هنا لأننا لم نغيّر شيئًا في آخر خطوة
}

int main() {
    backtracking(0);
}

نشاط: مراجعة سريعة لفكرة Backtracking

حدّد إن كانت كل عبارة صحيحة أم خاطئة.

Backtracking يبني الحل خطوة بخطوة ويتراجع بعد استكشاف كل اتجاه.

في مثال المجموعات الجزئية، عند كل موقع i نجرّب احتمالًا واحدًا فقط.

v.pop_back() في الكود يمثّل خطوة "التراجع" (إلغاء آخر قرار).

الترتيب الذي تُطبع به المجموعات الجزئية عبر Backtracking مطابق تمامًا لترتيبها عبر الأقنعة الثنائية.

مثال على مسألة: Apple Division

CSES 1623 — لديك مصفوفة p من n تفاحة بأوزان معلومة. تريد تقسيم التفاحات إلى مجموعتين بحيث يكون الفرق بين مجموع وزن كل مجموعة أصغر ما يمكن. المطلوب طباعة أصغر فرق ممكن.

القيدالنطاق
عدد التفاحات n1 ≤ n ≤ 20
وزن كل تفاحة p_i1 ≤ p_i ≤ 10⁹

مثال (من الموقع الرسمي)

input
5
3 2 7 4 1
1

التفسير: المجموعة الأولى بأوزان 2، 3، 4 (المجموع 9)، والمجموعة الثانية بأوزان 1، 7 (المجموع 8). الفرق = |9 - 8| = 1، وهو أصغر فرق ممكن.

الحل

سنستخدم Backtracking لتجربة كل التقسيمات الممكنة: عند كل تفاحة i، نجرّب وضعها في المجموعة الأولى، ثم نجرّب وضعها في المجموعة الثانية. عندما نُنهي كل التفاحات (i == n)، نقارن الفرق الحالي بأفضل فرق وجدناه حتى الآن.

apple_division.cpp
#include <iostream>
using namespace std;

int n;
int a[20];
long long sum1 = 0;         // مجموع المجموعة الأولى
long long sum2 = 0;         // مجموع المجموعة الثانية
long long ans = 2000000000; // الحل، رقم كبير جدًا مبدئيًا

void backtracking(int i) {
    // إذا i == n، حدّث الحل الحالي
    if (i == n) {
        ans = min(ans, abs(sum1 - sum2));
        return;
    }
    // حاول جميع الاختيارات الممكنة

    // حاول إضافة a[i] للمجموعة الأولى
    sum1 += a[i];
    backtracking(i + 1);
    sum1 -= a[i];

    // حاول إضافة a[i] للمجموعة الثانية
    sum2 += a[i];
    backtracking(i + 1);
    sum2 -= a[i];
}

int main() {
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    backtracking(0);

    cout << ans << "\n";
}
1

لاحظ استخدام long long للمجاميع، وليس int. بما أن كل وزن قد يصل إلى 10⁹ وقد يوجد حتى 20 تفاحة، فإن أكبر مجموع ممكن يصل إلى نحو 2×10¹⁰ — وهذا يتجاوز حدّ int (نحو 2.1×10⁹) بكثير.

أخطاء شائعة

1) نسيان خطوة التراجع (undo)

انظر إلى هذا الكود المعدَّل لتوليد المجموعات الجزئية — نسي كاتبه سطر v.pop_back();:

missing_undo.cpp
void backtracking(int i) {
    if (i == n) {
        cout << "subset: ";
        for (int j = 0; j < (int)v.size(); j++) cout << v[j] << ' ';
        cout << "\n";
        return;
    }
    v.push_back(a[i]);
    backtracking(i + 1);

    // !! نسينا v.pop_back(); هنا !!
    backtracking(i + 1);
}

بدون التراجع، تبقى العناصر متراكمة في v إلى الأبد، فتحصل على مجموعات جزئية خاطئة ومتضخّمة بدلًا من 8 مجموعات صحيحة ومميّزة. كل خطوة تُغيّر حالة مشتركة (مثل v أو sum) يجب أن تُلغى بعد استكشاف ذلك الاتجاه — هذا هو جوهر "التراجع" في Backtracking.

2) استخدام int بدلًا من long long للمجاميع الكبيرة

في مسألة Apple Division، إذا استخدمت int بدلًا من long long لتخزين sum1 وsum2، فقد يحدث فيضان (overflow) بصمت عندما تكون الأوزان كبيرة:

1500000000 + 1500000000 كـ int = -1294967296 (خطأ!) 1500000000 + 1500000000 كـ long long = 3000000000 (صحيح)

3) استكشاف اتجاه واحد فقط

إذا نسيت أحد الفرعين (مثلًا استكشفت "إضافة العنصر" فقط دون "استبعاده")، فلن تستكشف الخوارزمية كل الحلول الممكنة، وقد تفوّتك الإجابة الصحيحة تمامًا.

نشاط: مراجعة سريعة لمسألة Apple Division والأخطاء الشائعة

حدّد إن كانت كل عبارة صحيحة أم خاطئة.

في Apple Division، يجب استخدام long long للمجاميع لأن الأوزان قد تصل إلى 10⁹ ولدينا حتى 20 وزنًا.

نسيان v.pop_back() (أو ما يعادلها) لا يؤثر على صحة النتائج.

بما أن n ≤ 20 في هذه المسألة، فإن تجربة كل 2ⁿ تقسيم ممكن (حتى 2²⁰ ≈ مليون) تبقى سريعة بما يكفي.

يكفي دائمًا استكشاف فرع واحد فقط (إضافة العنصر) للحصول على كل الحلول الممكنة.

خلاصة سريعة

Backtracking يبني الحل خطوة بخطوة، ويستكشف كل الاحتمالات بشكل متكرر، ثم يتراجع بعد كل استكشاف.
لتوليد المجموعات الجزئية: عند كل عنصر، جرّب إضافته ثم استبعاده، وتراجع بين المحاولتين.
في Apple Division: عند كل تفاحة، جرّب وضعها في المجموعة الأولى ثم الثانية، وحدّث أفضل فرق عند اكتمال التقسيم.
لا تنسَ خطوة التراجع أبدًا، واستخدم النوع المناسب (long long) لتفادي الفيضان.

تمارين منزلية

1) تتبّع يدوي لمصفوفة أصغر

بنفس كود توليد المجموعات الجزئية بالـ Backtracking، لكن مع المصفوفة a = {2, 4} (أي n=2)، اكتب بالترتيب كل الأسطر التي سيطبعها البرنامج.

subset: 2 4 subset: 2 subset: 4 subset:

الترتيب: نضيف 2، ثم نضيف 4 فوقه (يطبع "2 4")، نتراجع عن 4 (يطبع "2")، نتراجع عن 2، نضيف 4 فقط (يطبع "4")، نتراجع عن 4 (يطبع المجموعة الفارغة).

2) طبّق Apple Division يدويًا

لديك 4 تفاحات بأوزان {10, 10, 10, 7}. ما أصغر فرق ممكن بين مجموعتين؟

المجموع الكلي = 37. أفضل تقسيم: المجموعة الأولى {10, 7} = 17، والمجموعة الثانية {10, 10} = 20.

|17 - 20| = 3

وهذا بالفعل أصغر فرق ممكن (يمكنك التحقق بتجربة بقية التقسيمات الثمانية).

3) اكتشف الخطأ

زميلك عدّل كود Apple Division بحيث يستكشف فرعًا واحدًا فقط لكل تفاحة (وضعها في المجموعة الأولى فقط):

find_error4.cpp
void backtracking(int i) {
    if (i == n) {
        ans = min(ans, abs(sum1 - sum2));
        return;
    }
    sum1 += a[i];
    backtracking(i + 1);
    sum1 -= a[i];
    // !! نسي فرع "إضافة a[i] للمجموعة الثانية" بالكامل !!
}

ما الخطأ في هذا الكود؟ وماذا سيطبع دائمًا؟

الكود يستكشف فرعًا واحدًا فقط (كل تفاحة تُوضع في المجموعة الأولى دائمًا)، ولا يجرّب أبدًا وضع أي تفاحة في المجموعة الثانية. بما أن sum2 تبقى 0 دائمًا، فإن الناتج سيكون دائمًا |مجموع كل الأوزان - 0|، أي مجموع كل الأوزان — وهو أسوأ حل ممكن تقريبًا، وليس الحل الأمثل.

الإصلاح: أضف الفرع الثاني (sum2 += a[i]; backtracking(i+1); sum2 -= a[i];) لاستكشاف كلا الاحتمالين.

قاموس المصطلحات

Backtrackingالتراجع الخوارزمي

أسلوب لاستكشاف كل الحلول الممكنة عبر بناء الحل تدريجيًا والتراجع بعد كل استكشاف.

Recursionالاستدعاء المتكرر

استدعاء الدالة لنفسها لحل نسخة أصغر من نفس المشكلة.

Base Caseالحالة الأساسية

الشرط الذي يوقف الاستدعاء المتكرر (مثل i == n)، ويمنع الدالة من استدعاء نفسها إلى ما لا نهاية.

Undo Stepخطوة التراجع

إلغاء آخر تغيير في الحالة المشتركة (مثل pop_back أو طرح قيمة) بعد استكشاف اتجاه معيّن.

Call Stackمكدس الاستدعاءات
