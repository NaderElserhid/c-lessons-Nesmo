# Nasmo Informatics Olympiad Curriculum

Welcome to the official repository for the **Nasmo Competition** training program. This repository contains interactive tools, teaching notes, and practice problems designed to take students from foundational programming to advanced algorithmic mastery.

---

## 🚀 Curriculum Overview

The training is divided into three progressive levels, each focusing on critical competitive programming skills.

### 📁 [Level 1: Foundations](./Level-1-Foundations)
*Focus: Mastering data structures and basic logic.*
* **Topics:** Sets, Maps (STL), and Sorting Algorithms.
* **Tools:** Interactive HTML simulators for set operations and sorting visualizations.

### 📁 [Level 2: Intermediate](./Level-2-Intermediate)
*Focus: Efficiency and Mathematical foundations.*
* **Topics:** Binary Search and Modular Arithmetic.
* **Tools:** Binary Search visualizer and modular math guides.

### 📁 [Level 3: Advanced](./Level-3-Advanced)
*Focus: Bit manipulation and optimization.*
* **Topics:** Bitwise Operations and Subset Generation using Bitmasks.
* **Tools:** Bitmask generator and interactive bitwise logic tables.

---

## 🛠 How to Use These Materials
1. **Interactive Tools:** Open the `.html` files in any modern web browser to use the simulators.
2. **Practice:** Check the `Practice_Problems.md` in each folder for curated problem sets (Codeforces/Vjudge).
3. **Teaching Notes:** Use the provided PDF and Markdown summaries for quick revision.
