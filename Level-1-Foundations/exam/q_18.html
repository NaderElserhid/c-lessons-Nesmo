تحليل الدالة التكرارية (Recursion)

السؤال: ما نتيجة استدعاء rec(261074)؟

int rec(int x) {
  if (x == 0) {
    return 0;
  }
  if (x % 10 == 0) {
    return rec(x / 10);
  }
  return 1 + rec(x - 1);
}

🔍 مفتاح الحل: ماذا تفعل الدالة؟

هذه الدالة تقوم فعلياً بحساب مجموع الخانات (Sum of Digits)، ولكن بطريقة غير مباشرة:

  • إذا كان الرقم ينتهي بـ 0 (x % 10 == 0): نقسم على 10 (ننتقل للخانة التالية).
  • إذا كان الرقم لا ينتهي بـ 0: ننقص 1 ونضيف 1 للمجموع (نعد قيمة الخانة الحالية).
