تحليل مسألة المتجهات (Vector)

1. الكود البرمجي (The Code)

vector<int> v;
for (int i = 1; i < 1000; i++) {
  for (int j = 0; j < i; j++) {
    v.push_back(j); // إضافة القيم 0, 1, 2...
  }
}

2. فكرة الحل (The Logic)

كيف ينمو المتجه؟

المتجه لا ينمو بشكل خطي، بل يضيف "كتلاً" من الأرقام في كل دورة:

  • عند i=1: يضيف رقمًا واحدًا (0).
  • عند i=2: يضيف رقمين (0, 1).
  • عند i=3: يضيف ثلاثة أرقام (0, 1, 2).

إذن، عدد العناصر الكلي في المتجه هو عبارة عن متسلسلة حسابية:

1 + 2 + 3 + ... + n

3. الحساب الرياضي (Calculation)

البحث عن الموقع 100,000

نستخدم قانون مجموع المتسلسلة الحسابية لمعرفة متى نصل للرقم 100,000:

Sum = n(n + 1) / 2 ≈ 100,000

بالتجربة والتقريب، نجد أن n = 446 هو أقرب رقم:

  • المجموع عند 446 = (446 × 447) / 2 = 99,681

هذا يعني أن العناصر من الموقع 0 وحتى الموقع 99,680 قد تم ملؤها بالكامل بواسطة الدورات السابقة.

4. الوصول للإجابة (Final Step)

تحديد القيمة

بما أن المجموع وصل إلى 99,681، فإن الدورة التالية (الكتلة الجديدة حيث i=447) ستبدأ من الموقع رقم 99,681.

في بداية أي كتلة جديدة، يبدأ العداد j من الصفر (0، 1، 2...).
نحن نريد القيمة في الموقع 100,000.

الفرق بين الموقع المطلوب وموقع بداية الكتلة هو:

100,000 - 99,681 = 319

بما أن القيم تبدأ من 0، فإن القيمة في هذا الموقع هي 319.

الإجابة الصحيحة: B) 319
