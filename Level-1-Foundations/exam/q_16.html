تحليل عدد المخرجات المختلفة (Distinct Outputs)

int f(int i) {
  int j = (i > 0 ? i : -i); // j is always positive
  return (j % 2) * (j % 3) * (j % 4);
}

1. مفتاح الحل: الدورية (Periodicity)

بما أن المعادلة تعتمد على باقي القسمة (Modulo) للأرقام 2، 3، و 4، فإن النتائج ستتكرر بنمط ثابت.
طول النمط هو المضاعف المشترك الأصغر (LCM) لهذه الأرقام:
LCM(2, 3, 4) = 12
لذا، يكفي تجربة الأرقام من 0 إلى 11 فقط.
