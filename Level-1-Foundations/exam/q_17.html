تحليل الكود وتتبع المتغيرات

السؤال: ما هي قيمة n النهائية بعد تنفيذ الكود التالي؟

int n = 478;
while (n > 100) {
    n -= n % 11;
    n -= 4;
}

💡 فكرة الحل (المنطق الرياضي)

داخل الحلقة (Loop)، يتم تنفيذ عمليتين في كل دورة:

  1. n -= n % 11: طرح باقي القسمة يعني تحويل الرقم إلى أقرب مضاعف للعدد 11 (تصغير الرقم).
  2. n -= 4: طرح 4 من الناتج.

الملاحظة الذكية: في كل دورة، ينقص العدد بمقدار ثابت تقريباً (وهو 11) لأننا نعود لمضاعف الـ 11 ثم ننقص 4.

📊 جدول تتبع القيم (Tracing Table)

رقم الدورة قيمة n (البداية) هل n > 100؟ n % 11 (الباقي) n - الباقي (مضاعف 11) n - 4 (النهاية)

2 469 ✅ نعم 7 462 458
... (يستمر النمط بطرح 11 في كل مرة) ...
