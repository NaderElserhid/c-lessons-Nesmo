شرح منطق "روبوت المتاهة"

كيف يفكر الكود ويتخذ القرارات؟ شرح خطوة بخطوة

1

ذاكرة الروبوت (Variables)

قبل أن يتحرك الروبوت، يحتاج أن يعرف ثلاثة أشياء أساسية:

  • أين أنا؟ (pi, pj): إحداثيات الموقع الحالي في المصفوفة.
  • إلى أين أنظر؟ (di, dj): اتجاه الحركة الحالي.
  • كم مشيت؟ (steps): عداد الخطوات (وهو المطلوب في السؤال).
int pi = 3, pj = 3; // موقع البداية
int di = -1, dj = 0; // الاتجاه للأعلى (Up)
int steps = 0; // العداد يبدأ من صفر
2

المحرك (The Loop)

الكود يستخدم حلقة تكرار while. تخيلها كأنها تقول للروبوت:

"استمر في تكرار المحاولة طالما أنك لم تقف على نقطة النهاية (o)"

while (b[pi][pj] != 'o') {
  // اتخذ قراراً: تحرك أو استدر
}
3

الدماغ: اتخاذ القرار (If / Else)

في كل دورة، يقوم الروبوت "بالنظر" إلى المربع الذي أمامه مباشرة b[pi + di][pj + dj].

السيناريو أ: الطريق سالك

إذا كان المربع القادم ليس جداراً (!= '#'):

  1. تقدم خطوة للأمام (حدث pi, pj).
  2. سجّل خطوة (steps++).
pi += di; pj += dj;
steps++;

السيناريو ب: اصطدام!

إذا كان المربع القادم جداراً (else):

  1. لا تتحرك من مكانك.
  2. لا تزد العداد.
  3. غيّر اتجاهك لليسار.
// معادلة الدوران
di = -dj; dj = di_;
انتبه: عداد الخطوات (steps) يزيد فقط عندما يتحرك الروبوت. عملية الدوران لا تحتسب كخطوة!
4

كيف يعمل الدوران؟ (The Math)

الكود يستخدم معادلة رياضية ذكية لتدوير المتجه (Vector) بزاوية 90 درجة عكس عقارب الساعة (لليسار):

int di_ = di;
di = -dj;
dj = di_;
⬆
كان للأعلى
(-1, 0)
←
⬅
أصبح لليسار
(0, -1)
←
⬇
أصبح للأسفل
(1, 0)

ببساطة: كلما اصطدم بحائط، يستدير لليسار ويحاول مرة أخرى في الدورة القادمة.
