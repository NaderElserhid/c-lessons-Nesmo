Bit++ Problem

هذا الشرح مقدم من منصة تويت كود

نص المسألة

في لغة Bit++، يوجد متغير واحد فقط هو x وقيمته الابتدائية 0. تحتوي اللغة على عمليتين:

  • ++: تزيد قيمة x بمقدار 1.
  • --: تنقص قيمة x بمقدار 1.

المطلوب هو تنفيذ سلسلة من الجمل (مثل ++X أو X--) وحساب القيمة النهائية للمتغير x.

خطوات الحل

1
قراءة المدخلات: نستقبل عدد الجمل البرمجية n.
2
الفحص المنطقي: في كل جملة، نتحقق من وجود إشارة + أو -.
3
تحديث المتغير: إذا كانت العملية جمعاً، نزيد x بـ 1؛ وإذا كانت طرحاً، ننقصه بـ 1.

المحاكي التفاعلي للغة Bit++

أدخل العمليات مفصولة بمسافات (مثال: ++X X-- ++X):

bit_plus_plus.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int x = 0; // القيمة الابتدائية
    while (n--) {
        string s;
        cin >> s;
        
        // نتحقق من الحرف الثاني في الجملة (دائماً يمثل العملية)
        if (s[1] == '+') {
            x++;
        } else {
            x--;
        }
    }
    
    cout << x << endl;
    return 0;
}
