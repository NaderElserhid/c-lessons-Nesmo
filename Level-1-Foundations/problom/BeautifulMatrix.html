Beautiful Matrix

هذا الشرح مقدم من منصة تويت كود

وصف المسألة

يتم إعطاؤك مصفوفة بحجم 5 × 5 تتكون من أصفار ورقم "1" واحد فقط. المصفوفة تكون "جميلة" إذا كان الرقم "1" يقع في المركز تماماً (الصف الثالث والعمود الثالث). المطلوب هو حساب أقل عدد من الخطوات لنقل الرقم "1" إلى المركز.

مشاهدة المسألة على Codeforces

خطوات التفكير والحل

1
إيجاد الموقع: نقوم بالمرور على جميع عناصر المصفوفة لتحديد رقم الصف (i) ورقم العمود (j) الخاص بالرقم "1".
2
حساب المسافة: المركز هو الموقع (3, 3). المسافة هي حاصل جمع فرق الصفوف وفرق الأعمدة (القيمة المطلقة).
3
القيمة المطلقة: نستخدم دالة للتأكد من أن النواتج دائماً موجبة، لأن الخطوات لا يمكن أن تكون سالبة.

المختبر التفاعلي: حرّك الرقم 1

اضغط على أي مربع لوضع الرقم 1 وشاهد عدد الخطوات المطلوبة للوصول للمركز:

اختر موقعاً للبدء...
beautiful_matrix.cpp
#include <iostream>
using namespace std;

// دالة لحساب القيمة المطلقة لضمان ناتج موجب
int abs_val(int v) {
    return (v > 0 ? v : -v); 
}

int main() {
    int r, c;

    // 1. البحث عن موقع الرقم 1 في المصفوفة 5x5
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= 5; j++) {
            int x;
            cin >> x;

            if (x == 1) {
                r = i; // تخزين رقم الصف
                c = j; // تخزين رقم العمود
            }
        }
    }

    // 2. حساب المسافة إلى المركز (3, 3)
    // النتيجة هي مجموع فرق الصفوف + مجموع فرق الأعمدة
    int result = abs_val(r - 3) + abs_val(c - 3);

    // 3. طباعة إجمالي الخطوات
    cout << result;

    return 0;
}
