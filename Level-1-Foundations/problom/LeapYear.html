Leap Year

هذا الشرح مقدم من منصة تويت كود

وصف المسألة

تُعرف السنة الكبيسة بأنها السنة التي تحتوي على 366 يوماً بدلاً من 365. المهمة هي كتابة برنامج يقرأ السنة ويحدد ما إذا كانت كبيسة أم لا بناءً على المعايير الفلكية.

قواعد الفحص البرمجي

1
القاعدة الأساسية: يجب أن تقبل السنة القسمة على 4 بدون باقٍ.
2
الاستثناء المئوي: إذا كانت تقبل القسمة على 100، فهي ليست كبيسة...
3
الاستثناء النهائي: ...إلا إذا كانت تقبل القسمة أيضاً على 400، فحينها تعود لتصبح كبيسة!

مختبر فحص السنوات

أدخل السنة لاختبارها:

هل تقبل القسمة على 4؟
هل تقبل القسمة على 100؟
هل تقبل القسمة على 400؟
leap_year.cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    // 1. استقبال السنة من المستخدم
    cin >> year;

    // 2. التحقق من الشروط المنطقية المركبة
    // السنة كبيسة إذا كانت (تقبل على 4 و لا تقبل على 100) أو (تقبل على 400)
    if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
        cout << "YES" << endl; // سنة كبيسة
    } else {
        cout << "NO" << endl;  // سنة بسيطة
    }

    return 0;
}
