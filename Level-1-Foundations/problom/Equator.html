وصف المسألة

يحل مبرمج عدداً من المسائل يومياً. المطلوب هو تحديد رقم اليوم الذي يكون فيه المبرمج قد أنجز نصف إجمالي المسائل (أو أكثر قليلاً) التي حلها خلال كامل الفترة.

مشاهدة المسألة على Codeforces

خطوات الحل

1
المجموع الكلي: نجمع كافة المسائل التي تم حلها في جميع الأيام.
2
نقطة التوازن: نحسب نصف المجموع الكلي (نقطة الاستواء).
3
البحث: نمر على الأيام ونجمع المسائل يوماً بعد يوم حتى نصل للنصف المطلوب.
being transformed into a prefix sum array [1, 4, 6, 7] with a marker at index 2 where sum 4 is >= 7/2]

مختبر البحث عن يوم التوازن

أدخل عدد المسائل المحلولة يومياً (مفصولة بمسافة):

equator.cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    // 1. استقبال عدد الأيام
    int n;
    cin >> n;

    vector<int> a(n);
    long long total_sum = 0;

    // 2. قراءة المسائل وحساب المجموع الكلي
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        total_sum += a[i];
    }

    // 3. تحديد الهدف (نصف المجموع على الأقل)
    long long current_sum = 0;
    long long target = (total_sum + 1) / 2; 

    // 4. البحث عن أول يوم يحقق الشرط
    for (int i = 0; i < n; i++) {
        current_sum += a[i];
        if (current_sum >= target) {
            // طباعة رقم اليوم (نظام 1-indexed)
            cout << i + 1 << endl;
            break;
        }
    }

    return 0;
}
