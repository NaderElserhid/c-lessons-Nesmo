وصف المسألة

لديك مجموعة من المتسابقين في مسابقة، ومطلوب منك حساب كم عدد الذين سيتأهلون للجولة القادمة. القاعدة هي: يتأهل المتسابق إذا حقق درجة تساوي أو تزيد عن درجة الشخص الذي يحتل المركز المحدد للتأهل، بشرط أن تكون درجته أكبر من الصفر تماماً.

مشاهدة المسألة على Codeforces

تنبيهات برمجية هامة

  • استبعاد الحاصلين على صفر: المتسابق لا يتأهل أبداً إذا كانت درجته صفراً، حتى لو حقق شرط المركز المطلوبة.
  • الدرجات مرتبة: المتسابقون مدخلون من أعلى درجة إلى أقل درجة دائماً.

مختبر التأهيل التفاعلي

أدخل درجات المتسابقين (مفصولة بمسافة):

حدد ترتيب المتسابق الذي يحدد درجة التأهل:

next_round.cpp
#include <iostream>
using namespace std;

int main() {
    // 1. استقبال عدد المتسابقين والترتيب المطلوب
    int n, k;
    cin >> n >> k;

    // 2. قراءة درجات المتسابقين في مصفوفة
    int a[n], ans = 0;
    for (int i = 0; i < n; i++) cin >> a[i];

    // 3. التحقق من كل متسابق بناءً على شرطين:
    // - درجته أكبر من أو تساوي درجة المتسابق في المركز المحدد
    // - درجته أكبر من الصفر تماماً
    for (int i = 0; i < n; i++) {
        if (a[i] >= a[k - 1] && a[i] > 0) ans++;
    }

    // 4. طباعة عدد المتأهلين النهائي
    cout << ans;

    return 0;
}
