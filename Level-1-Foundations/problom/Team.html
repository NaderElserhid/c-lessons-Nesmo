وصف المسألة

هناك ثلاثة أصدقاء يحبون حل المسائل البرمجية. قرروا أنهم لن يقوموا بحل أي مسألة إلا إذا وافق اثنان منهم على الأقل بأنهم يعرفون طريقة الحل. لديك قائمة بعدد من المسائل، والمطلوب هو حساب كم مسألة سيقوم الفريق بحلها في النهاية.

مشاهدة المسألة على Codeforces

خطوات التفكير والحل

1
استقبال البيانات: نعرف عدد المسائل الكلي الذي سنقوم بفحصه.
2
التكرار: نمر على كل مسألة ونقرأ رأي الأصدقاء الثلاثة (1 يعني يعرف الحل، 0 يعني لا يعرف).
3
الشرط المنطقي: نجمع آراءهم؛ إذا كان المجموع 2 أو أكثر، نقوم بزيادة عداد المسائل المحلولة بمقدار 1.

team_solution.cpp
#include <iostream>
using namespace std;

int main() {
    // 1. استقبال عدد المسائل n
    int n;
    cin >> n;

    // عداد المسائل التي سيتم حلها
    int ans = 0;

    // 2. حلقة تكرار لكل مسألة
    for (int i = 0; i < n; i++) {
        int f1, f2, f3;
        // قراءة رأي الأصدقاء الثلاثة
        cin >> f1 >> f2 >> f3;

        // 3. إذا كان مجموع الواثقين 2 أو أكثر
        if (f1 + f2 + f3 >= 2) {
            ans++;
        }
    }

    // 4. طباعة الناتج النهائي
    cout << ans;

    return 0;
}
