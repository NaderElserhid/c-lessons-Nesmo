للتعلم البرمجي التفاعلي

Beautiful Year

هذا الشرح مقدم من منصة تويت كود

وصف المسألة

المطلوب هو إيجاد أصغر سنة تكون أكبر تماماً من السنة المعطاة، بشرط أن تكون جميع أرقام هذه السنة مختلفة وغير مكررة.

خطوات الحل البرمجي

1
زيادة أولية: نبدأ بالبحث من السنة التي تلي السنة المعطاة مباشرة (year + 1).
2
حلقة التحقق: نستخدم حلقة while لفحص كل سنة، ونقوم بتفكيك أرقامها الأربعة.
3
شرط النجاح: إذا لم نجد أي رقمين متطابقين، نخرج من الحلقة ونطبع السنة الجميلة.

مختبر البحث التفاعلي

أدخل السنة الحالية للبحث عما بعدها:

beautiful_year.cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;

    // 1. البدء من السنة التالية مباشرة
    year += 1;

    // 2. حلقة تستمر طالما أن أرقام السنة غير مختلفة
    while (true) {
        int a = year / 1000;       // آلاف
        int b = (year / 100) % 10; // مئات
        int c = (year / 10) % 10;  // عشرات
        int d = year % 10;         // آحاد

        // 3. التحقق من عدم وجود أي تكرار
        if (a != b && a != c && a != d && b != c && b != d && c != d) {
            break; // وجدنا السنة المطلوبة
        }
        
        // 4. الانتقال للسنة التالية إذا فشل الاختبار
        year += 1;
    }

    cout << year << '\n';
    return 0;
}
