Dislike of Threes

هذا الشرح مقدم من منصة تويت كود

وصف المسألة

لنتخيل تسلسلاً من الأرقام التي "تحبها" الخوارزمية. الأرقام التي **لا تحبها** هي التي تحقق أحد الشرطين: إما أنها تقبل القسمة على 3، أو أن رقم آحادها هو 3. المطلوب منك هو إيجاد الرقم الذي يحتل الترتيب الذي تختاره في هذا التسلسل.

مشاهدة المسألة على Codeforces

خطوات التفكير والحل

1
البحث المستمر: نبدأ بالعد من الرقم 1 فصاعداً ونستمر حتى نجد العدد المطلوب من الأرقام "المحبوبة".
2
اختبار الكره: الرقم يكون "مكروهاً" إذا كان (يقبل القسمة على 3) أو (باقي قسمته على 10 يساوي 3). في هذه الحالة، نتخطاه.
3
الترتيب النهائي: بمجرد وصولنا للعدد المطلوب من الأرقام الناجحة، نتوقف ونطبع آخر رقم وصلنا إليه.

مختبر الفلترة التفاعلي

ادخل ترتيب الرقم الذي تريد الوصول اليه

dislike_of_threes.cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t; // عدد حالات الاختبار
    
    while (t--) {
        int k;
        cin >> k; // الترتيب المطلوب
        
        int current_num = 0;
        int count_liked = 0;
        
        // البحث عن الرقم رقم k في التسلسل المحبوب
        while (count_liked < k) {
            current_num++;
            // التحقق من شروط "الكره"
            if (current_num % 3 == 0 || current_num % 10 == 3) {
                continue; // تخطي الرقم
            }
            count_liked++; // زيادة عداد الأرقام المحبوبة
        }
        
        cout << current_num << endl;
    }
    return 0;
}
