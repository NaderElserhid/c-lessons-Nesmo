Holiday of Equality

هذا الشرح مقدم من منصة تويت كود

وصف المسألة

يوجد في المملكة عدد n من المواطنين، ولكل فرد ثروة محددة. قرر الملك جعل الجميع متساوين في الثروة مع الشخص الأكثر ثراءً بينهم.

مشاهدة المسألة على Codeforces

خطوات التفكير والحل

1
استخدام دالة المقارنة لإيجاد القيمة العظمى.
2
تخزين ثروات المواطنين في مصفوفة.
3
حساب مجموع الفروقات بين القيمة العظمى وكل ثروة.

المختبر البياني التفاعلي

أدخل الثروات مفصولة بمسافة:

holiday_of_equality.cpp
#include <iostream>
using namespace std;

// دالة المقارنة لإيجاد الأكبر
int max_function(int x, int y) {
    if (x > y) return x;
    else return y;
}

int main() {
    int n;
    cin >> n;

    int a[n];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int max_value = a[0];
    for (int i = 0; i < n; i++) {
        max_value = max_function(max_value, a[i]);
    }

    int coins = 0;
    for (int i = 0; i < n; i++) {
        coins += max_value - a[i];
    }

    cout << coins;
    return 0;
}
