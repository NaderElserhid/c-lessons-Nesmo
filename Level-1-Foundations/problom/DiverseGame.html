Diverse Game

هذا الشرح مقدم من منصة تويت كود

وصف المسألة

يتم إعطاؤك مصفوفة تحتوي على جميع الأرقام من 1 إلى (N × M) مرة واحدة فقط. المهمة هي إنشاء مصفوفة جديدة بنفس الحجم، بحيث لا يتساوى أي رقم في المصفوفة الجديدة مع الرقم الموجود في نفس الموقع في المصفوفة القديمة. إذا تعذر ذلك، تظهر النتيجة -1.

مشاهدة المسألة على Codeforces

خطوات التفكير والحل

1
حالة الاستحالة: إذا كانت المصفوفة تحتوي على عنصر واحد فقط (1×1)، فمن المستحيل تغييره، لذا نطبع -1.
2
خوارزمية التغيير: نقوم بزيادة كل رقم بمقدار 1 لضمان اختلافه عن القيمة الأصلية.
3
التدوير الذكي: إذا وصل الرقم لأقصى قيمة ممكنة (N × M)، نقوم بإعادته للقيمة 1.

مختبر التحويل الرقمي

أدخل أبعاد المصفوفة (الصفوف × الأعمدة):

×

diverse_game.cpp
#include <iostream>
using namespace std;

int main() {
// Ask the user for matrix dimensions
    int n, m;
    cout << "Enter number of rows (n) and columns (m): ";
    cin >> n >> m;

    // Special case: 1x1 matrix
    if (n == 1 && m == 1) {
        cout << -1;
        return 0;
    }

    int a[n][m], b[n][m];

    // Generate numbers from 1 to n*m automatically
    int num = 1;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            a[i][j] = num;
            num++;
        }
    }

    // Apply transformation (+1, last becomes 1)
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (a[i][j] == n * m)
                b[i][j] = 1;
            else
                b[i][j] = a[i][j] + 1;
        }
    }

    // Print result matrix
    cout << "Generated Result Matrix:\n";
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cout << b[i][j] << " ";
        }
        cout << endl;
    }


    return 0;
}
