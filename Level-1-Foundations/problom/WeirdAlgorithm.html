Weird Algorithm

هذا الشرح مقدم من منصة تويت كود

وصف المسألة

تبدأ هذه الخوارزمية برقم صحيح تختاره أنت، ثم تطلب منك تطبيق مجموعة من الخطوات المتكررة حتى تصل في النهاية إلى الرقم 1:

  • إذا كان الرقم زوجياً: نقوم بقسمة الرقم على 2.
  • إذا كان الرقم فردياً: نقوم بضرب الرقم في 3 ثم نضيف إليه 1.

خطوات التفكير والحل

1
إنشاء الحلقة: نستخدم حلقة تكرارية تستمر في العمل طالما أن الرقم لم يصبح 1.
2
فحص نوع الرقم: نختبر إذا كان الرقم الحالي يقبل القسمة على 2 بدون باقٍ.
3
تطبيق القواعد: ننفذ عملية القسمة للزوجي، وعملية الضرب والجمع للفردي، ونطبع النتيجة.

مختبر التفكير المتسلسل

أدخل الرقم الذي تريد أن تبدأ به الخوارزمية:

weird_algorithm.cpp 
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;

    while (true) {
        cout << n << " ";
        if (n == 1) break;

        if (n % 2 == 0) {
            n /= 2;
        } else {
            n = n * 3 + 1;
        }
    }
    return 0;
}
