Sum Product

هذا الشرح مقدم من منصة تويت كود

وصف المسألة

عند إعطاء ثلاثة أعداد صحيحة a و b و c، المطلوب هو إيجاد أصغر عدد بينهم، ثم ضربه في مجموع العددين الآخرين المتبقيين.

خطوات التفكير والحل

1
تحديد الأصغر: المقارنة بين الأرقام الثلاثة لاستخراج أصغر قيمة.
2
جمع البقية: استبعاد الأصغر وجمع القيمتين المتبقيتين.
3
الضرب النهائي: ضرب نتيجة الجمع في القيمة الصغرى.

المختبر التفاعلي (خطوة بخطوة)

أدخل الأرقام الثلاثة:

sum_product.cpp
#include <iostream>
#include <algorithm> // min لاستخدام دالة

using namespace std;

int main() {
    // 1. Read three integers from the user
    int a, b, c;
    cin >> a >> b >> c;

    // 2. Find the smallest number manually
    int smallest = a;

    if (b < smallest) {
        smallest = b;
    }

    if (c < smallest) {
        smallest = c;
    }

    // 3. Calculate the sum of all numbers minus the smallest
    int others_sum = (a + b + c) - smallest;

    // 4. Multiply the smallest number by the sum of the other two
    cout << smallest * others_sum << endl;
}
