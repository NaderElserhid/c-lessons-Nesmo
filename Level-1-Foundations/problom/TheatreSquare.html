Theatre Square

هذا الشرح مقدم من منصة تويت كود

وصف المسألة

المطلوب هو تغطية ساحة مستطيلة أبعادها N × M باستخدام أقل عدد ممكن من بلاطات الرخام المربعة التي طول ضلعها A. يُسمح للبلاط بأن يغطي مساحة أكبر من الساحة، لكن لا يمكن كسر البلاط.

مشاهدة المسألة على Codeforces

خطوات التفكير والحل

1
تغطية الطول (N): نحسب كم بلاطة نحتاج لرصف الطول، ونقرب للزيادة دائماً.
2
تغطية العرض (M): نحسب كم بلاطة نحتاج لرصف العرض بالكامل، ونقرب للزيادة أيضاً.
3
حساب الإجمالي: نضرب عدد بلاطات الطول في عدد بلاطات العرض.

مختبر الرصف المطور (بأبعاد واضحة)

theatre_square.cpp
#include <iostream>
using namespace std;

int main() {
    // 1. استقبال أبعاد الساحة N, M وطول ضلع البلاطة A
    int n, m, a;
    cin >> n >> m >> a;

    // 2. حساب عدد البلاطات في كل اتجاه (v طولي، h عرضي)
    // نستخدم صيغة التقريب للأعلى الذكية: (A + B - 1) / B
    long long v = (n + a - 1) / a;
    long long h = (m + a - 1) / a;

    // 3. طباعة إجمالي البلاطات (حاصل الضرب)
    cout << v * h;

    return 0;
}
