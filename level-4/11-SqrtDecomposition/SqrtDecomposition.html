الفكرة الأساسية

🧩 لماذا نحتاج هذه التقنية؟

عندما نمتلك مصفوفةً ونريد الإجابة عن استعلامات تطلب قيمةً محددة (مجموع، أو أصغر قيمة، أو أكبر قيمة) لنطاق من العناصر، فإن الطريقة الساذجة تستغرق زمن O(n) لكل استعلام. إذا كان عدد الاستعلامات Q كبيراً، يصبح الأداء الكلي O(n × Q) وهو ضعيف جداً.

تحليل الجذر التربيعي يُقدّم حلاً وسطاً ذكياً: يُقسّم المصفوفة إلى كتل بحجم √n تقريباً، ويُخزّن نتيجةً محسوبةً مسبقاً لكل كتلة. هذا يُتيح الإجابة عن أي استعلام في زمن O(√n).

استعلام النطاق — تعريف

استعلام على مستوى نطاق هو استعلام يطلب حساب قيمة محددة (مجموع / أصغر / أكبر) لجميع عناصر المصفوفة في النطاق [l, r].

🏗️ بناء الهيكل خطوةً بخطوة

لنفترض أن لدينا مصفوفة a بطول n. خطوات بناء هيكل الجذر التربيعي:

  1. نحسب حجم الكتلة: sz = ⌈√n⌉. بما أن √n × √n = n، يكون عدد الكتل تقريباً √n أيضاً.

  2. ننشئ مصفوفة مساعدة b بطول √n، حيث يخزّن b[i] القيمة المحسوبة مسبقاً للكتلة رقم i.

  3. ينتمي العنصر a[j] إلى الكتلة رقم j / sz (القسمة الصحيحة).

  4. نملأ مصفوفة b بمرور واحد على المصفوفة a، وهو ما يستغرق زمن O(n).

مثال عددي: إذا كانت n = 9، فإن sz = 3. الكتلة الأولى (b[0]) تضم العناصر a[0], a[1], a[2]. الكتلة الثانية (b[1]) تضم a[3], a[4], a[5]. الثالثة (b[2]) تضم a[6], a[7], a[8].

⚗️ مختبر بناء الهيكل

أدخل مصفوفةً من الأعداد مفصولةً بمسافات، ثم اضغط «بناء» لمشاهدة تقسيمها إلى كتل وحساب مصفوفة b.

معالجة الاستعلامات

🔍 كيف نُجيب عن استعلام [l, r]؟

النطاق [l, r] ينقسم إلى ثلاثة أجزاء:

  1. الكتلة الأولى (جزئية): من l حتى نهاية كتلتها. نمشي على هذه العناصر واحداً واحداً.

  2. الكتل الوسطى (كاملة): كتل مغطاة بالكامل. نستخدم القيم في b مباشرةً دون المرور على عناصرها الفردية.

  3. الكتلة الأخيرة (جزئية): من بداية كتلتها حتى r. نمشي على هذه العناصر واحداً واحداً.

الحالة الخاصة: إذا كان l و r ينتميان إلى الكتلة ذاتها (blockL == blockR)، نمشي على جميع العناصر من l إلى r مباشرةً. لا توجد كتل كاملة في هذه الحالة.

التعقيد الزمني للاستعلام: O(√n) ≈ √n عنصراً جزئياً + √n كتلةً كاملة

تحديث نقطة

✏️ كيف نُحدّث عنصراً؟

تحديث العنصر في الموضع j إلى القيمة v يمر بخطوتين:

  1. تحديث المصفوفة الأصلية: a[j] = v بزمن O(1).

  2. إعادة حساب الكتلة كاملةً: نمر على جميع عناصر الكتلة التي ينتمي إليها j ونحسب قيمتها من الصفر. بما أن حجم الكتلة √n، يستغرق هذا زمن O(√n).

لماذا نُعيد حساب الكتلة كاملةً؟ بعد تغيير a[j]، قد تكون القيمة القديمة هي التي كانت تحدد نتيجة الكتلة (مثلاً القيمة الكبرى). لذا لا يمكننا تحديث b[blockJ] بشكل مباشر دون إعادة المرور على كامل الكتلة.

التعقيد الكلي للتحديث: O(√n)

كتابة الكود

⚙️ الحسابات المسبقة — بناء الهيكل

نمر مرةً واحدة على المصفوفة ونملأ b. العنصر a[i] ينتمي إلى الكتلة رقم i / sz.

build.cpp
// نملأ مصفوفة الكتل b بمرور واحد على a
for (int i = 0; i < n; i++) {
    b[i / sz] = max(a[i], b[i / sz]);  // i/sz هو رقم الكتلة التي ينتمي إليها i
}

🔍 دالة الاستعلام — القيمة العظمى

نُعالج الكتلة الأولى الجزئية، ثم الكتل الوسطى الكاملة، ثم الكتلة الأخيرة الجزئية. الحالة الخاصة عندما يقع l و r في الكتلة ذاتها.

queryMax.cpp
int queryMax(int l, int r) {
    int blockL = l / sz;
    int blockR = r / sz;
    int ans = INT_MIN;

    // الحالة الخاصة: l و r في الكتلة ذاتها
    if (blockL == blockR) {
        for (int i = l; i <= r; i++)
            ans = max(ans, a[i]);
        return ans;
    }

    // الجزء الأيسر — الكتلة الأولى الجزئية
    for (int i = l; i < (blockL + 1) * sz; i++)
        ans = max(ans, a[i]);

    // الكتل الوسطى الكاملة (نستخدم b مباشرةً — لا نمر على عناصرها)
    for (int i = blockL + 1; i < blockR; i++)
        ans = max(ans, b[i]);

    // الجزء الأيمن — الكتلة الأخيرة الجزئية
    for (int i = blockR * sz; i <= r; i++)
        ans = max(ans, a[i]);

    return ans;
}

🔍 شرح كود الاستعلام سطراً بسطر

  1. blockL و blockR: نحسب رقم الكتلة التي تنتمي إليها l و r بقسمتهما على sz. هذا يُخبرنا إذا كانا في نفس الكتلة أم لا.

  2. الحالة الخاصة (blockL == blockR): إذا كان النطاق بأكمله داخل كتلة واحدة، نمشي عليه مباشرةً. لا توجد كتل كاملة هنا ولا جزء آخر.

  3. الكتلة الأولى الجزئية: من l حتى (blockL + 1) * sz - 1. نمشي فردياً لأنها غير مغطاة بالكامل.

  4. الكتل الكاملة: من الكتلة blockL+1 حتى blockR-1. نقرأ b[i] مباشرةً. هذا هو جوهر التحسين — نتجنب المرور على كل عنصر داخل هذه الكتل.

  5. الكتلة الأخيرة الجزئية: من blockR * sz حتى r. نمشي فردياً لأنها غير مغطاة بالكامل.

✏️ دالة التحديث النقطي — شرح مفصّل

نُحدّث a[j] أولاً، ثم نُعيد حساب الكتلة blockJ كاملةً من الصفر.

pointUpdate.cpp
void pointUpdate(int j, int v) {
    int blockJ = j / sz;  // رقم الكتلة التي ينتمي إليها j

    a[j] = v;              // تحديث المصفوفة الأصلية — O(1)

    // إعادة حساب b[blockJ] من الصفر
    b[blockJ] = INT_MIN;
    for (int i = blockJ * sz; i < (blockJ + 1) * sz; i++) {
        b[blockJ] = max(b[blockJ], a[i]);
    }
}

🔍 شرح كود التحديث

  1. blockJ = j / sz: نجد رقم الكتلة التي ينتمي إليها j.

  2. a[j] = v: نُحدّث قيمة العنصر في المصفوفة الأصلية مباشرةً. هذا O(1).

  3. b[blockJ] = INT_MIN: نُعيد ضبط قيمة الكتلة إلى القيمة الأدنى ممكنة تمهيداً لإعادة حساب الحد الأقصى.

  4. حلقة إعادة الحساب: نمر على جميع عناصر الكتلة من blockJ * sz حتى (blockJ + 1) * sz - 1 ونحسب الحد الأقصى الجديد. التعقيد: O(sz) = O(√n).

المسألة التطبيقية — Dynamic Range Minimum Queries

📋 نص المسألة (CSES)

لديك مصفوفة a من n عنصر، وتريد معالجة q استعلام من نوعين:

النوع الأول: 1 k u — حدّث القيمة في الموضع k إلى u.
النوع الثاني: 2 l r — ما أصغر قيمة في النطاق [l, r]؟

💡 الملاحظات المهمة في الكود

  1. MAXN و sz في النطاق العام: المصفوفات الكبيرة يجب أن تكون في الذاكرة الثابتة (Static Memory) لا في المكدّس (Stack)، لذا نُعرّفها خارج main.

  2. k-- و l-- و r--: المسألة ترقّم العناصر ابتداءً من 1، لكن مصفوفات C++ تبدأ من 0. نطرح 1 من كل مؤشر قبل التعامل معه.

  3. تهيئة b بـ INT_MAX: لأننا نحسب الحد الأدنى، نهيّئ الكتل بأكبر قيمة ممكنة حتى لا تُؤثر على النتيجة قبل ملئها.

  4. ceil(sqrt(MAXN)): نستخدم القيمة القصوى MAXN لضمان صحة حجم مصفوفة b في جميع الأحوال بدلاً من sqrt(n).

drmq.cpp
#include <iostream>
#include <cmath>
#include <climits>
using namespace std;

const int MAXN = 200000;
const int sz   = (int)ceil(sqrt(MAXN));  // ≈ 448
int a[MAXN];   // المصفوفة الأصلية
int b[sz];     // الحد الأدنى لكل كتلة

int queryMin(int l, int r) {
    int blockL = l / sz, blockR = r / sz;
    int ans = INT_MAX;

    if (blockL == blockR) {
        for (int i = l; i <= r; i++) ans = min(ans, a[i]);
        return ans;
    }
    for (int i = l;         i < (blockL+1)*sz; i++) ans = min(ans, a[i]);
    for (int i = blockL+1;  i < blockR;        i++) ans = min(ans, b[i]);
    for (int i = blockR*sz; i <= r;          i++) ans = min(ans, a[i]);
    return ans;
}

void pointUpdate(int j, int v) {
    int blockJ = j / sz;
    a[j] = v;
    b[blockJ] = INT_MAX;
    for (int i = blockJ*sz; i < (blockJ+1)*sz; i++)
        b[blockJ] = min(b[blockJ], a[i]);
}

int main() {
    int n, q;
    cin >> n >> q;

    for (int i = 0; i < n; i++) cin >> a[i];

    // تهيئة الكتل
    for (int i = 0; i < sz; i++) b[i] = INT_MAX;
    for (int i = 0; i < n; i++)
        b[i / sz] = min(a[i], b[i / sz]);

    while (q--) {
        int type; cin >> type;
        if (type == 1) {
            int k, u; cin >> k >> u;
            pointUpdate(--k, u);  // k-- لأن الترقيم يبدأ من 1
        } else {
            int l, r; cin >> l >> r;
            cout << queryMin(--l, --r) << "\n";
        }
    }
    return 0;
}
