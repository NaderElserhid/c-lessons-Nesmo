📦 ما هو الـ std::pair؟

تخيل أن لديك صندوقاً مقسماً إلى خانتين. الـ std::pair في لغة C++ هو أداة (حاوية) تربط قيمتين معاً وتعاملهما كوحدة واحدة. هاتان القيمتان يمكن أن تكونا من نفس النوع البرمجي أو من نوعين مختلفين.

لاستخدام الـ Pair، يُفضل دائماً استدعاء مكتبة <utility>. 
#include <iostream>
#include <utility>

using namespace std;

int main() {
    // تعريف زوج يحتوي على رقم صحيح ونص
    pair<int, string> student;
    return 0;
}

🛠️ كيفية التعريف وإعطاء القيم

يوجد عدة طرق لإعطاء القيم للـ Pair، لكن استخدام الأقواس المعقوفة {} هو الأسرع والأكثر شيوعاً في المسابقات.

int main() {
    // 1. الطريقة الكلاسيكية باستخدام first و second
    pair<int, int> p1;
    p1.first = 10;
    p1.second = 20;

    // 2. باستخدام دالة make_pair
    pair<string, int> p2 = make_pair("Ali", 95);

    // 3. استخدام الأقواس المعقوفة (الطريقة الأفضل والأسرع)
    pair<int, int> p3 = {5, 15};
    
    return 0;
}

⚖️ المقارنة والترتيب (ميزة قوية)

الـ Pair يمتلك ميزة الترتيب التلقائي (Lexicographical). عند مقارنة زوجين، فإنه ينظر دائماً للـ first أولاً، وإذا تعادلا، ينتقل للـ second. 

int main() {
    pair<int, int> A = {1, 100};
    pair<int, int> B = {2, 5};
    pair<int, int> C = {1, 200};

    // A < B : صحيح! لأن 1 (first) أصغر من 2
    // A < C : صحيح! تساويا في الأول، لكن 100 (second) أصغر من 200
    
    if (A < C) {
        cout << "A is smaller!" << endl;
    }
    
    return 0;
}

🚀 3 أمثلة وتطبيقات عملية

1. تخزين إحداثيات شبكة (2D Grid Coordinates)

عند التعامل مع المصفوفات ثنائية الأبعاد (مثل المتاهات)، نستخدم الـ Pair لتخزين رقم الصف ورقم العمود كـ X و Y.

pair<int, int> point = {3, 5};
cout << "X = " << point.first << ", Y = " << point.second << endl;
// المخرجات: X = 3, Y = 5

2. تخزين حواف الرسم البياني (Graph Edges)

بدلاً من استخدام مصفوفتين، يمكننا تخزين العقدتين المتصلتين معاً كزوج داخل Vector.

vector<pair<int, int>> edges;
edges.push_back({1, 2}); // Edge من العقدة 1 إلى 2
edges.push_back({2, 3}); // Edge من العقدة 2 إلى 3

for(auto e : edges) {
    cout << "Edge between " << e.first << " and " << e.second << endl;
}

3. ترتيب مصفوفة مع الاحتفاظ بمكان العنصر الأصلي (Value & Index)

نخزن القيمة في first والمؤشر (Index) في second. عند الترتيب سيتم الترتيب حسب القيمة، وسنظل نحتفظ بالمكان الأصلي.

#include <algorithm> // من أجل دالة sort
// ...
vector<pair<int, int>> arr = { {50, 0}, {10, 1}, {30, 2} };

sort(arr.begin(), arr.end()); // سيرتب حسب الرقم الأول تلقائياً

for(auto p : arr) {
    cout << "Value: " << p.first << " was at Index: " << p.second << endl;
}
// المخرجات: 
// Value: 10 was at Index: 1
// Value: 30 was at Index: 2
// Value: 50 was at Index: 0
