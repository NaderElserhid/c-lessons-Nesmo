القواسم والأعداد الأولية

Divisors & Prime Numbers · نظرية الأعداد الأساسية

🎯 ما الهدف من هذا الدرس؟

عندما يكون العدد N صغيراً (مثل 50)، يمكننا فعل أي شيء. لكن عندما يصل N إلى مليار — 1,000,000,000 — الطريقة الخاطئة ستجمّد كودك تماماً!

في هذا الدرس نتعلم سؤالين أساسيين:

🔹 ما هي الأعداد التي تقسم N؟ (إيجاد القواسم Divisors)

🔹 هل N عدد أولي؟ (اختبار الأولية Primality Test)

📌 تعريفات أساسية

القاسم (Divisor)

العدد d يُسمّى قاسمًا لـn إذا كان n % d == 0، أي أن n يقبل القسمة على d بدون باقٍ.

مثال: قواسم 12 هي: 1, 2, 3, 4, 6, 12

لأن: 12÷1=12 ، 12÷2=6 ، 12÷3=4 ، 12÷4=3 ، 12÷6=2 ، 12÷12=1

العدد الأولي (Prime Number)

العدد الأولي هو عدد أكبر من 1، له بالضبط قاسمان فقط: 1 ونفسه.

أعداد أولية: 2, 3, 5, 7, 11, 13, 17, 19, 23 ...

ليست أولية: 1 (قاسم واحد)، 4 (له قاسم 2)، 9 (له قاسم 3)

⚠️ الاستثناء المهم: العدد 2 هو العدد الأولي الزوجي الوحيد!

لماذا التحسين مهم جداً؟

الطريقة البطيئة: حلقة من 1 إلى N

إذا كان N = 1,000,000,000 → يحتاج ~10 ثوانٍ ❌

الطريقة المحسّنة: حلقة من 1 إلى √N

إذا كان N = 1,000,000,000 → √N ≈ 31,623 → يحتاج جزء من الثانية ✅

💻 الكود: إيجاد القواسم

❌ الطريقة البطيئة — O(N)

C++// إذا كان N = 10^9، هذا يستغرق ~10 ثوانٍ — بطيء جداً!
for (int i = 1; i <= n; i++) {
    if (n % i == 0) cout << i << " ";
}
⚠ O(N) — بطيء

✅ الطريقة المحسّنة — O(√N)

C++#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    long long n = 36;
    vector<long long> divisors;

    // i * i <= n أفضل من i <= sqrt(n)
    // لأنها تتجنب الأعداد العشرية البطيئة
    for (long long i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            divisors.push_back(i);       // القاسم الصغير
            
            if (i != n / i) {           // تجنّب التكرار (مثل 6 في n=36)
                divisors.push_back(n / i); // الشريك الكبير
            }
        }
    }

    for (long long d : divisors) cout << d << " ";
}
✓ O(√N) — سريع جداً

✅ الكود: اختبار الأولية

C++bool isPrime(long long n) {
    if (n <= 1) return false; // 0 و 1 ليسا أوليين
    
    for (long long i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return false; // وجدنا قاسماً! إذن ليس أولياً
        }
    }
    return true; // نجا من الحلقة؟ إذن هو أولي!
}
✓ O(√N)

⚡ الفكرة الكبرى: حيلة الجذر التربيعي

هذه الحيلة هي الأهم في نظرية الأعداد الأساسية. دعنا نفهمها بالتفصيل.

المبدأ: القواسم دائماً تأتي في أزواج! إذا كان a × b = n وكان a صغيراً، فإن b يجب أن يكون كبيراً. الزوجان "يلتقيان" بالضبط عند √n.

🔑 القاعدة الذهبية: لا تحتاج للتحقق من الأعداد الأكبر من √n. إذا لم تجد عاملاً بحلول ذلك الوقت، إما أنه غير موجود، أو أنك وجدت شريكه بالفعل!

لماذا i * i <= n وليس i <= sqrt(n)؟

⚠️ sqrt(n) تُرجع عدداً عشرياً (double)، وهذا بطيء ويمكن أن يسبب أخطاء تقريبية.

✅ i * i <= n تستخدم ضرب الأعداد الصحيحة فقط — أسرع وأدق.

⚠️ تحذير: إذا كان N كبيراً جداً، i * i قد يتجاوز حد int، لذا استخدم دائماً long long.

🥁 مسألة 1: The Marching Band

📋 نص المسألة

فرقة موسيقية لديها 240 عضواً. يريد المدير ترتيبهم في تشكيل مستطيل مع الشروط:

  • يجب تضمين جميع الأعضاء (بدون فراغات)
  • يجب أن يكون هناك 10 صفوف على الأقل
  • لا يمكن أن يكون هناك أكثر من 20 صفاً

كم عدد التشكيلات المختلفة الممكنة؟

🧠 التحليل

نحتاج إيجاد قواسم 240 التي تقع بين 10 و 20. كل قاسم يمثل عدد الصفوف، والشريك يمثل عدد الأعمدة.

C++int findFormations(int n) {
    vectorint, int>> divisors;
    
    for (int i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            if (i * i == n) {
                divisors.push_back({i, i});
            } else {
                divisors.push_back({i, n/i});
                divisors.push_back({n/i, i}); // كلا الاتجاهين
            }
        }
    }

    int count = 0;
    for (auto p : divisors) {
        if (p.first >= 10 && p.first <= 20) {
            count++;
            cout << p.first << " صفوف × " << p.second << " أعمدة\n";
        }
    }
    return count;
}

⭐ مسألة 2: T-Prime

📋 نص المسألة

العدد الأولي له قاسمان. نسمي عدداً T-Prime إذا كان له بالضبط ثلاثة قواسم مختلفة. لكل عدد في المصفوفة، حدد هل هو T-Prime أم لا.

🧠 الحل التحليلي

الإثبات: الأعداد T-Prime هي فقط مربعات الأعداد الأولية!

إذا كان X = p² (حيث p أولي) → القواسم هي: 1, p, p² (ثلاثة بالضبط) ✅

إذا كان X له عاملان أوليان مختلفان p وq → له على الأقل أربعة قواسم: 1, p, q, pq ❌

C++int n;
cin >> n;

for (int i = 0; i < n; ++i) {
    long long x;
    cin >> x;

    long long y = sqrt(x);
    if (y * y != x) {
        cout << "NO\n"; // ليس مربعاً كاملاً
        continue;
    }

    if (isPrime(y))
        cout << "YES\n";
    else
        cout << "NO\n";
}

سهل  سؤال 2
أيّ من التالي هو عدد أولي؟
13 عدد أولي لأن قواسمه فقط 1 و13. أما 9=3×3, 15=3×5, 21=3×7.
سهل  سؤال 3
ما هي نقطة التوقف في حيلة الجذر التربيعي لإيجاد قواسم العدد 100؟
√100 = 10، لذا نتوقف عند 10. أي قاسم أكبر من 10 هو شريك لقاسم أصغر وجدناه بالفعل.
سهل  سؤال 4
لماذا نفضّل كتابة i * i <= n بدلاً من i <= sqrt(n)؟
sqrt() تُرجع عدداً عشرياً (double) وقد تسبب أخطاء تقريبية، بينما i*i تعمل على الأعداد الصحيحة فقط وهي أسرع وأدق.
سهل  سؤال 5
هل العدد 1 يعتبر عدداً أولياً؟
بالتعريف، العدد الأولي يجب أن يكون أكبر من 1 وله بالضبط قاسمان. العدد 1 له قاسم واحد فقط (نفسه)، لذا ليس أولياً.
🟡 متوسط (5 أسئلة)
متوسط  سؤال 6
كم عدد خطوات الحلقة لإيجاد قواسم العدد 10,000 باستخدام حيلة الجذر؟ (تقريباً)
√10,000 = 100، لذا الحلقة تُنفَّذ ~100 مرة فقط بدلاً من 10,000 مرة. هذا توفير ضخم في الوقت!
متوسط  سؤال 7
عند إيجاد قواسم 25، لماذا لا نضيف القاسم 5 مرتين؟
عندما i == n/i (أي عندما i = √n مربع كامل)، القاسم وشريكه هما نفس العدد. الكود يتحقق: if (i != n/i) قبل إضافة الشريك لتجنب التكرار.
متوسط  سؤال 8
ما هو تعريف العدد T-Prime؟
T-Prime هو عدد له بالضبط 3 قواسم مختلفة. وقد أثبتنا أن هذه الأعداد هي فقط مربعات الأعداد الأولية: p².
متوسط  سؤال 9
هل العدد 49 هو T-Prime؟ ولماذا؟
49 = 7², و7 عدد أولي. قواسم 49 هي: 1, 7, 49 — ثلاثة بالضبط. إذن هو T-Prime! ✅
متوسط  سؤال 10
ما هو التعقيد الزمني لدالة isPrime() باستخدام حيلة الجذر؟
الدالة تتكرر من 2 إلى √N فقط، لذا تعقيدها O(√N). هذا أسرع بكثير من O(N).
🔴 صعب (5 أسئلة)
صعب  سؤال 11
إذا كان N = 10⁶، كم مرة تكرر الحلقة في الطريقة المحسّنة مقارنة بالطريقة البطيئة؟
√(10⁶) = 10³ = 1000. الطريقة البطيئة: 10⁶ خطوة. الطريقة المحسّنة: 10³ خطوة. النسبة = 10⁶/10³ = 1000 مرة أسرع! ✅
صعب  سؤال 12
عند استخدام long long i والتحقق بـ i * i <= n، ما المشكلة المحتملة إذا استخدمنا int i و N = 10⁹؟
حد int هو ~2.1 × 10⁹. عندما i ≈ 46,341، فإن i*i ≈ 2.1 × 10⁹ تتجاوز حد int وتسبب overflow (أعداد سالبة خاطئة). الحل: استخدم long long دائماً مع الأعداد الكبيرة.
صعب  سؤال 13
لماذا لا يمكن لأي عدد T-Prime أن يكون زوجياً (ما عدا 4)؟
T-Prime يجب أن يكون p² حيث p أولي. العدد الأولي الزوجي الوحيد هو 2، إذن 2²=4 هو T-Prime الزوجي الوحيد. أي p أولي آخر فردي → p² فردي.
صعب  سؤال 14
في مسألة الفرقة الموسيقية (240 عضو)، إذا كان الشرط 15 صفاً على الأقل و30 صفاً كحد أقصى، كم تشكيلاً يكون ممكناً؟
قواسم 240 بين 15 و30: 16 (240÷16=15)، 20 (240÷20=12)، 24 (240÷24=10). هذه ثلاثة تشكيلات. يمكنك التحقق تفاعلياً في قسم المسائل!
صعب  سؤال 15
كم عدداً T-Prime موجود أصغر من 100؟ وما هي؟
الأعداد الأولية ≤ √100 = 10 هي: 2,3,5,7. مربعاتها: 4, 9, 25, 49 — كلها أقل من 100. 11² = 121 > 100. إذن الإجابة 4 أعداد: 4, 9, 25, 49. ✅
