01
ما هي ordered_set ؟

ordered_set هي بنية بيانات متقدمة تعمل تمامًا مثل set العادي في C++ (لا تسمح بالتكرار، ومرتبة تلقائيًا)، لكنها تُضيف عليه قدرتين استثنائيتين لا تجدهما في الـ set العادي.

هي جزء من PBDS وليست جزءًا من المعيار الرسمي لـ C++، لكنها متاحة في جميع المسابقات تقريبًا (Codeforces، CSES، إلخ).

🔍 find_by_order(k)
إيجاد العنصر بترتيبه

تُرجع مؤشرًا للعنصر في الترتيب k (يبدأ من 0) من الأصغر إلى الأكبر.

O(log n)
📊 order_of_key(x)
إيجاد رتبة العنصر

تُرجع عدد العناصر الأصغر من x في المجموعة.

O(log n)

03
الكود الأساسي (Template)
⚠️ هذا الكود يعمل مع GCC فقط. لن يعمل مع MSVC (Visual Studio) أو Clang بدون تعديلات.
C++ — الملفات المطلوبة والـ Template 
// الملفات المطلوبة
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>
using namespace __gnu_pbds;

// التعريف الكامل لـ ordered_set
template<typename T>
using ordered_set = tree<
    T,                                    // نوع العناصر
    null_type,                            // لا يوجد value (مثل set)
    less<T>,                              // ترتيب تصاعدي
    rb_tree_tag,                          // Red-Black Tree
    tree_order_statistics_node_update     // يتيح find_by_order/order_of_key
>;

// طريقة الاستخدام:
ordered_set<int> os;
os.insert(10);
os.insert(20);
os.insert(30);

// العنصر في الرتبة 0 (الأصغر): 10
auto it = os.find_by_order(0); // يشير إلى 10

// كم عنصر أصغر من 25؟ الجواب: 2 (وهما 10 و 20)
int cnt = os.order_of_key(25); // = 2

💡 حل مشكلة التكرار — استخدام الأزواج
💡 الـ ordered_set لا تقبل تكرار القيم تمامًا كـ set. الحل الذكي في مسائل كـ Sliding Window Median: نخزن كل عنصر كزوج (قيمة، فهرس) بدلًا من مجرد القيمة!
1

المشكلة: إذا كان لدينا مصفوفة [3, 1, 3, 2] والنافذة تحتوي على [3, 1, 3]، فلن نستطيع إدراج الـ 3 مرتين!

2

الحل: نحوّل كل عنصر a[i] إلى زوج (a[i], i). الآن (3,0) و (3,2) عنصران مختلفان!

3

الترتيب محفوظ: الأزواج تُرتب أولًا بالقيمة ثم بالفهرس، لذا ترتيبنا من الأصغر إلى الأكبر لا يتأثر.

📘 مسألة: Sliding Window Median

المسألة: لديك مصفوفة من n عنصر وقيمة k. اطبع الوسيط لكل مصفوفة جزئية بطول k.

الوسيط: العنصر الأوسط بعد الترتيب. إذا كان k زوجيًا فالوسيط هو القيمة الصغرى من الوسطين. مثال: [1, 2, 3, 4] ← الوسيط = 2

الكود الكامل للحل
C++ — Sliding Window Median 
#include <iostream>
using namespace std;

#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>
using namespace __gnu_pbds;

template<typename T>
using ordered_set = tree<T, null_type, less<T>, rb_tree_tag, tree_order_statistics_node_update>;

int main() {
    int n, k;
    cin >> n >> k;

    pair<int, int> a[n];
    for (int i = 0; i < n; i++) {
        cin >> a[i].first;
        a[i].second = i;  // الفهرس يضمن عدم التكرار
    }

    ordered_set<pair<int, int>> os;

    // أدخل النافذة الأولى
    for (int i = 0; i < k; i++) {
        os.insert(a[i]);
    }

    // حساب موضع الوسيط
    int median = (k % 2 == 0) ? k/2 - 1 : k/2;

    // طباعة وسيط النافذة الأولى
    pair<int, int> ans = *os.find_by_order(median);
    cout << ans.first << ' ';

    // التحرك عبر جميع النوافذ
    for (int i = 0; i < n - k; i++) {
        os.erase(a[i]);      // احذف أول عنصر في النافذة
        os.insert(a[i + k]); // أضف العنصر الجديد

        pair<int, int> ans = *os.find_by_order(median);
        cout << ans.first << ' ';
    }
    return 0;
}
// التعقيد الزمني: O(n log n)
// التعقيد المكاني: O(k)
