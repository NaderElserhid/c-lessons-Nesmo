🌳 ما هي الشجرة؟

الشجرة هي رسم بياني غير موجّه ومتصل ولا يحتوي على دورات. تُستخدم في حل طيف واسع من مسائل الأولمبياد لأنها تضمن وجود مسار وحيد بين أي عقدتين.

📌 التعريف الرسمي:
الرسم البياني G = (V, E) يكون شجرةً إذا وفقط إذا كان:
  ① متصلاً (Connected)
  ② خالياً من الدورات (Acyclic)
✅ الخاصية الذهبية:
بين أي عقدتين u وv، يوجد بالضبط مسار بسيط واحد.
هذه الخاصية هي سر كثرة ظهور الأشجار في مسائل الأولمبياد.

📐 خصائص رياضية مهمة

① إضافة حرف → دورة

في الشجرة يوجد مسار وحيد بين أي u وv. لو أضفت حرفاً جديداً (u,v) تحصل على دورة: المسار القديم + الحرف الجديد.

⚠️ الشجرة هي الرسم البياني المتصل الأدنى: لا يمكن حذف أي حرف مع الحفاظ على الاتصال، ولا يمكن إضافة أي حرف دون إنشاء دورة.

② حذف حرف → انفصال

كل حرف في الشجرة هو جسر (Bridge). حذف أي حرف يُنتج مكوّنين منفصلين تماماً.

③ التجذير يُعطي هيكلاً عائلياً

المصطلحالتعريفمثال (جذر = 0)
الجذر (Root)العقدة المختارة كبدايةالعقدة 0

💻 التمثيل البرمجي

قائمة الجوار (Adjacency List)

int n;                           // عدد العقد (0..n-1)
vector<int> g[n];              // g[v] = قائمة جيران v

// قراءة الأحرف من المدخلات
for (int i = 0; i < n-1; i++) {
    int u, v;
    cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);   // غير موجّه
}

DFS لحساب الأب والعمق

vector<int> parent(n, -1), depth(n, 0);

void dfs(int v, int p) {
    parent[v] = p;
    for (int to : g[v]) {
        if (to == p) continue;  // تجنب الرجوع للأب
        depth[to] = depth[v] + 1;
        dfs(to, v);
    }
}
// استدعاء: dfs(root, -1);

DFS لحساب حجم الشجرة الفرعية (sub)

vector<int> sub(n, 1);

void dfs_sub(int v, int p) {
    for (int to : g[v]) {
        if (to == p) continue;
        dfs_sub(to, v);
        sub[v] += sub[to];   // اجمع أحجام الأبناء
    }
}
/* sub[v] = عدد عقد الشجرة الفرعية لـ v */
💡 نصيحة الأولمبياد: دائماً مرّر الأب p في DFS على الأشجار غير الموجّهة لتتجنب العودة للأب الذي يُفسد المنطق.
