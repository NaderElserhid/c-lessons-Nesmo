الأشجار في علوم الحاسوب (Trees)

منهج تفاعلي للمتسابقين · المستوى المتقدم

الشجرة هي الهيكل الذي يظهر في أكثر مسائل الأولمبياد تنوّعًا: من عدّ العقد وحساب الأعماق، وصولًا إلى قطر الشجرة، السلف المشترك الأدنى (LCA)، وتقنية إعادة التجذير (Rerooting). كل ما ستراه هنا هو الأساس الذي تُبنى عليه هذه التقنيات المتقدمة.

🌳 ما هي الشجرة؟

الشجرة هي رسم بياني غير موجّه ومتصل ولا يحتوي على دورات. تُستخدم في حل طيف واسع من مسائل الأولمبياد لأنها تضمن وجود مسار وحيد بين أي عقدتين.

📌 التعريف الرسمي: الرسم البياني G = (V, E) يكون شجرةً إذا وفقط إذا كان:
① متصلاً (Connected)
② خالياً من الدورات (Acyclic)

✅ الخاصية الذهبية: بين أي عقدتين u وv، يوجد بالضبط مسار بسيط واحد. هذه الخاصية هي سر كثرة ظهور الأشجار في مسائل الأولمبياد.

nعدد العقد (Nodes)
n−1عدد الأحرف (Edges)
1مسار بين كل عقدتين
∞تطبيقات في الأولمبياد

تمييز مهم: كل شجرة هي رسم بياني، لكن ليس كل رسم بياني متصل هو شجرة — يجب أن يكون خاليًا من الدورات أيضًا. رسم بياني متصل بـ n عقدة وأكثر من n−1 حافة يحتوي بالضرورة على دورة واحدة على الأقل، وبالتالي ليس شجرة.

🔵 تصور الشجرة

شجرة مجذّرة بـ 7 عقد — اضغط على أي عقدة لرؤية معلوماتها الكاملة (الأب، العمق، الأبناء، الشجرة الفرعية).

📐 خصائص رياضية مهمة

① إضافة حرف → دورة

في الشجرة يوجد مسار وحيد بين أي u وv. لو أضفت حرفاً جديداً (u,v) تحصل على دورة: المسار القديم + الحرف الجديد.

الشجرة هي الرسم البياني المتصل الأدنى: لا يمكن حذف أي حرف مع الحفاظ على الاتصال، ولا يمكن إضافة أي حرف دون إنشاء دورة.

② حذف حرف → انفصال

كل حرف في الشجرة هو جسر (Bridge). حذف أي حرف يُنتج مكوّنين منفصلين تماماً.

③ التجذير يُعطي هيكلاً عائلياً

المصطلحالتعريفمثال (جذر = 0)

أين تُستخدم هذه المفاهيم فعليًا في الأولمبياد؟

بمجرد إتقان الجذر/الأب/العمق/حجم الشجرة الفرعية، تصبح هذه المسائل الكلاسيكية (من CSES Tree Algorithms) في متناولك مباشرة:

Subordinates — حساب حجم الشجرة الفرعية (sub[v]) بالضبط كما رأينا في تبويب "الكود". CSES 1674 ↗
Tree Diameter — أطول مسار في الشجرة؛ يُحل بتشغيل DFS/BFS مرتين: من أي عقدة نصل لأبعد عقدة a، ثم من a نصل لأبعد عقدة b، فيكون a→b هو القطر. CSES 1131 ↗
Tree Distances I / II — حساب أبعد مسافة من كل عقدة إلى بقية الشجرة، باستخدام تقنية إعادة التجذير (Rerooting) بدلاً من تشغيل DFS منفصل لكل عقدة. CSES 1132/1133 ↗
Company Queries II — إيجاد السلف المشترك الأدنى (LCA) لعقدتين بكفاءة O(log n) باستخدام تقنية Binary Lifting (تحضير أسلاف كل عقدة على مسافات 2^0, 2^1, 2^2...). CSES 1688 ↗

هذه التقنيات الأربع (DP على الأشجار، القطر، Rerooting، Binary Lifting/LCA) ستُشكّل صلب الفصول القادمة في المستوى المتقدم.

💻 التمثيل البرمجي

قائمة الجوار (Adjacency List)

tree_input.cpp
int n;                           // عدد العقد (0..n-1)
vector<int> g[n];              // g[v] = قائمة جيران v

// قراءة الأحرف من المدخلات
for (int i = 0; i < n-1; i++) {
    int u, v;
    cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);   // غير موجّه
}

DFS لحساب الأب والعمق

tree_parent_depth.cpp
vector<int> parent(n, -1), depth(n, 0);

void dfs(int v, int p) {
    parent[v] = p;
    for (int to : g[v]) {
        if (to == p) continue;  // تجنب الرجوع للأب
        depth[to] = depth[v] + 1;
        dfs(to, v);
    }
}
// استدعاء: dfs(root, -1);

DFS لحساب حجم الشجرة الفرعية (sub)

tree_subtree_size.cpp
vector<int> sub(n, 1);

void dfs_sub(int v, int p) {
    for (int to : g[v]) {
        if (to == p) continue;
        dfs_sub(to, v);
        sub[v] += sub[to];   // اجمع أحجام الأبناء
    }
}
/* sub[v] = عدد عقد الشجرة الفرعية لـ v */

💡 نصيحة الأولمبياد: دائماً مرّر الأب p في DFS على الأشجار غير الموجّهة لتتجنب العودة للأب الذي يُفسد المنطق.

🔍 محاكاة DFS التفاعلية

جرّب DFS خطوة بخطوة على شجرة مخصصة. اختر الجذر وابدأ المحاكاة لترى ترتيب زيارة العقد وقيم depth وparent وsub.

لم تُزَر قيد المعالجة الآن اكتملت (sub محسوبة) الجذر المختار
اضغط على عقدة لاختيارها جذراً، ثم اضغط "تشغيل DFS"
nodeparentdepthsub

جرّب هذا: شغّل DFS بجذر 0، ثم أعد التعيين واختر جذرًا مختلفًا (مثل 2). ستلاحظ أن قيم parent وdepth تتغيّر بالكامل رغم أن حواف الشجرة نفسها لم تتغيّر — هذه هي الملاحظة الجوهرية التي تُبنى عليها تقنية Rerooting المتقدمة.
