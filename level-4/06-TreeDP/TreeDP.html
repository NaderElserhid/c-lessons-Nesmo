البرمجة الديناميكية على الأشجار (Tree DP)

من الأساس حتى المسألة الكلاسيكية: أكبر مجموعة مستقلة · للمتسابقين 15-20 سنة

بعد أن أتقنّا الجذر والأب والعمق وحجم الشجرة الفرعية، نستخدمها الآن لبناء أول خوارزمية DP حقيقية على الأشجار. الفكرة بسيطة وقوية: احسب إجابة كل عقدة من إجابات أبنائها، ثم اصعد نحو الجذر.

💡 ما هي Tree DP؟

البرمجة الديناميكية على الأشجار (Tree DP) هي تقنية تحسب جواب كل عقدة بالاعتماد على أجوبة أبنائها، بعد تجذير الشجرة واختيار جذر.

🎯 الفكرة الجوهرية: بعد تجذير الشجرة، الأشجار الفرعية (Subtrees) لا تتداخل أبداً. لذلك يمكننا حل كل شجرة فرعية مرة واحدة، ثم دمج النتائج صعوداً نحو الجذر.

🪜 خطوات الحل العامة

  1. جذّر الشجرة: اختر أي عقدة (عادةً 0 أو 1) لتكون الجذر. هذا يعطي الشجرة اتجاهاً من الأعلى للأسفل.

  2. عرّف حالات DP لكل عقدة: فكّر: ما المعلومة التي تحتاجها كل عقدة لاتخاذ قرارها؟ هذه هي حالات DP.

  3. نفّذ DFS واحسب الأبناء أولاً: في DFS، عند الرجوع (post-order) تكون قيم DP للأبناء جاهزة قبل الأب.

  4. ادمج نتائج الأبناء: استخدم صيغة رياضية بسيطة تجمع قيم الأبناء لتحسب قيمة الأب.

📌 بعد التجذير، كل ابن يُعطى جزءاً مستقلاً تماماً من الشجرة (subtree). هذه الأجزاء لا تتقاسم أي عقد أو أحرف. لذلك يمكن حساب كل واحدة بشكل مستقل ودمجها بأمان.

🟠 المسألة الكلاسيكية: أكبر مجموعة مستقلة

تعريف المسألة

اختر أكبر عدد ممكن من عقد الشجرة، بشرط أن لا تختار عقدتين متجاورتين (مرتبطتان بحرف مباشر).

🌿 مثال: في شجرة 0→1→2→3 (خطية)، يمكن اختيار {0,2} أو {1,3} أو {0,3} — كل هذه مستقلة. أفضلها هو {0,2,4...} بالتبادل.

📊 حالات DP والانتقالات

تعريف الحالتين

لكل عقدة v، نحسب رقمين:

dp1[v]

أفضل نتيجة إذا اخترنا v داخل subtree(v) كاملة

dp0[v]

أفضل نتيجة إذا تركنا v داخل subtree(v) كاملة

معادلات الانتقال

🟠 اخترنا v → dp1[v] dp1[v] = 1 + Σ dp0[c] (لكل ابن c)
🔵 تركنا v → dp0[v] dp0[v] = Σ max(dp0[c], dp1[c]) (لكل ابن c)

🟠 dp1[v]: نعدّ v نفسها (الـ 1)، ثم كل ابن مجبر على أن يكون غير مختار → نأخذ dp0[c].

🔵 dp0[v]: لا نعدّ v، وكل ابن حر في اختياره أو تركه → نأخذ max(dp0[c], dp1[c]) لكل ابن بشكل مستقل.

✅ الجواب النهائي: max(dp0[root], dp1[root])

💻 الكود الكامل (C++)

الهيكل العام

tree_dp_setup.cpp
int n;
vector<vector<int>> g(n);   // قائمة الجوار
vector<int> dp0(n, 0), dp1(n, 0);

دالة DFS الرئيسية

tree_dp_mis.cpp
void dfs(int v, int p) {
    dp1[v] = 1;   // نختار v → نبدأ بعدّها
    dp0[v] = 0;   // لا نختار v → لا نعدّها

    for (int to : g[v]) {
        if (to == p) continue;   // تجاهل الأب
        dfs(to, v);              // احسب الابن أولاً

        // اخترنا v → مجبورون على ترك الابن
        dp1[v] += dp0[to];

        // تركنا v → الابن حر، خذ الأفضل
        dp0[v] += max(dp0[to], dp1[to]);
    }
}

// الاستخدام:
dfs(0, -1);
int ans = max(dp0[0], dp1[0]);

🔑 نصيحة الأولمبياد: دائماً ابدأ بـ dp1[v] = 1 (لتعدّ العقدة v نفسها)، وdp0[v] = 0. ثم الحلقة على الأبناء تبني الباقي. البنية دائماً نفسها في أغلب مسائل Tree DP.

🎮 محاكاة Tree DP التفاعلية

شجرة من 6 عقد — اضغط "تشغيل" لرؤية DP خطوة بخطوة. الشجرة: 0 هو الجذر، أبناؤه {1,2}، أبناء 1 هم {3,4}، ابن 2 هو {5}.

لم تُحسب بعد قيد المعالجة dp0/dp1 محسوبتان الجذر (0)
اضغط "تشغيل كامل" أو "خطوة واحدة"
nodedp0[v]dp1[v]

🔬 مثال مفصّل: ابنان a وb

البيانات المعطاة

قيم الابن a

dp0[a] = 3
dp1[a] = 4

قيم الابن b

dp0[b] = 2
dp1[b] = 2

حساب dp1[v] — نختار v

إذا اخترنا v، يجب ترك كلا الابنين:

dp1[v] = 1 + dp0[a] + dp0[b] = 1 + 3 + 2 = 6

حساب dp0[v] — نترك v

إذا تركنا v، كل ابن حر، نأخذ الأفضل منهما:

dp0[v] = max(dp0[a], dp1[a]) + max(dp0[b], dp1[b]) = max(3, 4) + max(2, 2) = 4 + 2 = 6

✅ في هذا المثال، الحالتان تعطيان 6. الجواب النهائي: max(6, 6) = 6
