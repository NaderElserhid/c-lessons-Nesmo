غربال إراتوستينس

Sieve of Eratosthenes · البرمجة التنافسية · نظرية الأعداد

أسرع خوارزمية لإيجاد جميع الأعداد الأولية حتى حدٍّ معين — من اختراع عالم الرياضيات اليوناني إراتوستينس قبل أكثر من ألفي عام، وما زالت حاضرة في كل مسابقة برمجة حتى اليوم.

التعريفات المفهوم الخطوات الكود لماذا i² التعقيد Noldbach الملخص الأسئلة

📚 التعريفات الأساسية

تعريف — العدد الأولي (Prime Number)

عدد صحيح أكبر من 1 لا يقبل القسمة إلا على 1 وعلى نفسه. أمثلة: 2، 3، 5، 7، 11، 13، 17... العدد 2 هو الوحيد بين الأعداد الأولية الزوجية.

تعريف — الغربال (Sieve)

خوارزمية تصفية جماعية تبدأ بافتراض أن كل الأعداد أولية، ثم تشطب المضاعفات تدريجياً حتى تبقى الأعداد الأولية فقط. أشبه بغربال حقيقي يُرسَب منه ما ليس بأولي.

تعريف — المضاعفات (Multiples)

مضاعفات العدد i هي الأعداد 2i, 3i, 4i, ... — وهي بطبيعة الحال مقسومة على i فلا يمكن أن تكون أولية (طالما i > 1).

تعريف — مصفوفة is_prime[]

مصفوفة منطقية (Boolean) نستخدمها في الغربال. is_prime[i] = true تعني "نفترض أن i أولي حتى الآن"، وتُصبح false عند شطبه كمضاعف.

💡 المفهوم — كيف يعمل الغربال؟

"بدلاً من فحص كل عدد على حدة، نشطب المضاعفات بالجملة!" تخيّل الأعداد من 1 إلى 20 مكتوبة أمامك. الفكرة أن كل مضاعف لعدد أولي ليس أولياً — فنشطبه فوراً. ما يبقى بعد انتهاء العملية هو الأعداد الأولية فقط.

محاكاة تفاعلية — الأعداد من 1 إلى 50

جاهز — اضغط "خطوة للأمام" للبدء
عدد أولي ✓ مشطوب (مضاعف) لم يُحدد بعد

⚙️ خطوات الخوارزمية

  1. إنشاء المصفوفة وتهيئتها: أنشئ مصفوفة منطقية is_prime[] بحجم MAX_N + 1 وأدخل القيمة true في جميع خاناتها — أي "نفترض أن الجميع أولي في البداية".

  2. الحالات الحافة: 0 و1: اضبط is_prime[0] = is_prime[1] = false لأن 0 و1 ليسا أوليين بالتعريف.

  3. الحلقة الرئيسية: من 2 إلى √N: ابدأ من i = 2 وارفع حتى i * i <= MAX_N. إذا كان is_prime[i] = true فاشطب جميع مضاعفاته.

  4. شطب المضاعفات من i² فصاعداً: الحلقة الداخلية تبدأ من j = i * i (تحسين مهم!) وتزيد بمقدار i في كل خطوة: j += i

  5. ما يبقى هو الأعداد الأولية: بعد انتهاء الحلقة، كل i حيث is_prime[i] = true هو عدد أولي. أجمعها في متجه إن أردت.

💻 الكود الأساسي — Sieve of Eratosthenes

sieve.cpp
#include <iostream>
#include <vector>
using namespace std;

// الحد الأقصى للأعداد التي نريد فحصها
const int MAX_N = 1000000;
vector<bool> is_prime(MAX_N + 1, true); // افترض الجميع أولي

void sieve() {
    is_prime[0] = is_prime[1] = false; // الحالات الحافة

    for (int i = 2; i * i <= MAX_N; i++) {
        // إذا لم يُشطب i بعد، فهو أولي
        if (is_prime[i]) {
            // اشطب مضاعفاته — ابدأ من i² (تحسين!)
            for (int j = i * i; j <= MAX_N; j += i) {
                is_prime[j] = false;
            }
        }
    }
}

شرح تفاعلي سطر بسطر

  1. تهيئة المصفوفة: vector<bool> is_prime(MAX_N+1, true) — ننشئ مصفوفة منطقية بطول MAX_N+1 ونملؤها بـ true. نستخدم vector<bool> لأنها تُحسّن استهلاك الذاكرة (بت واحد لكل عنصر بدلاً من بايت).

  2. الحالات الحافة: is_prime[0] = is_prime[1] = false — 0 و1 بالتعريف ليسا أوليين، لذا نشطبهما قبل بدء الحلقة.

  3. شرط التوقف: i * i <= MAX_N — لماذا √N وليس N؟ لأنه إذا كان للعدد n قاسم أكبر من √n، فلا بد أن يكون له قاسم أصغر من √n أيضاً، وهذا الأصغر قد شطب n بالفعل. لذا لا حاجة للاستمرار بعد √N.

  4. فحص إذا كان أولياً: if (is_prime[i]) — إذا لم يُشطب i من قِبَل عدد أولي سابق، فهو بالتأكيد أولي. ليس علينا إثبات ذلك — الغربال يضمنه.

  5. البدء من i²: j = i * i — هذا التحسين الجوهري! المضاعفات 2i, 3i, 4i, ..., (i-1)·i قد شُطبت بالفعل حين معالجة الأعداد الأولية الأصغر من i. أول مضاعف لم يُلمس هو i².

  6. الشطب: j += i — ننتقل من مضاعف لآخر بإضافة i في كل مرة (أي نشطب i², i²+i, i²+2i, ...)، ونضع is_prime[j] = false لكل منها.

🔍 لماذا نبدأ الشطب من i² وليس من 2i؟

هذا التحسين الحاسم يُقلل عدد العمليات بشكل ملحوظ. دعنا نفهم السبب بمثال:

مثال — عندما i = 5

لماذا لا نشطب 10 = 5×2 أو 15 = 5×3 أو 20 = 5×4؟

المضاعفما شطبه مسبقاًالنتيجة
5 × 2 = 10العدد الأولي 2مشطوب بالفعل ✓
5 × 3 = 15العدد الأولي 3مشطوب بالفعل ✓
5 × 4 = 20العدد الأولي 2مشطوب بالفعل ✓
5 × 5 = 25لا أحد← أول مضاعف غير مشطوب!

القاعدة: كل مضاعف i × k حيث k < i يحتوي على عامل أولي أصغر من i، وقد شطبته حلقة سابقة. إذن أول مضاعف يحتاج معالجة هو i × i = i².

📊 التعقيد الزمني والمكاني

O(N log log N) التعقيد الزمني — شبه خطي، ممتاز
O(N) التعقيد المكاني — مصفوفة بحجم N
O(N√N) مقارنة بديهية — فحص كل عدد منفرداً

لماذا O(N log log N) وليس O(N²)؟

رغم وجود حلقتين متداخلتين، العمليات الفعلية هي مجموع N/2 + N/3 + N/5 + N/7 + ... (على الأعداد الأولية فقط). هذا المجموع رياضياً يساوي N · log(log N)، وهو قريب جداً من الخطي في الممارسة. لـ N = 10,000,000 تعمل في أجزاء من الثانية.

🏆 مسألة تطبيقية — Noldbach

📖 نص المسألة

يدّعي Noldbach أن على الأقل k عدد أولي في النطاق من 2 إلى n يمكن التعبير عنها كـ (عدد أولي + عدد أولي متجاور + 1).

مثلاً: 5 = 2 + 2 + 1 أو 7 = 3 + 3 + 1 أو 11 = 5 + 5 + 1.

يُطلق على عددين أوليين اسم متجاورين إذا لم يكن بينهما عدد أولي آخر (مثل 3 و5، أو 11 و13).

المطلوب: هل Noldbach على حق أم على خطأ؟ اطبع YES أو NO.

📐 تحليل الحل

  1. شغّل الغربال حتى n: نولّد جميع الأعداد الأولية من 2 إلى n باستخدام غربال إراتوستينس ونخزنها في متجه primes[].

  2. فحص كل زوج من الأعداد الأولية المتجاورة: لكل زوج متجاور primes[i-1] و primes[i]، احسب المجموع primes[i-1] + primes[i] + 1.

  3. تحقق هل المجموع أولي: استخدم is_prime[] مباشرةً (فحص O(1)) لمعرفة هل هذا المجموع أولي.

  4. قارن العداد بـ k: إذا كان عدد الأعداد الأولية المقبولة ≥ k اطبع YES، وإلا NO.

noldbach.cpp
#include <iostream>
#include <vector>
using namespace std;

const int MAX_N = 1000000;
vector<bool> is_prime(MAX_N + 1, true);
vector<int> primes;

int findPrime(int n) {
    is_prime[0] = is_prime[1] = false;

    // الغربال
    for (int i = 2; i * i <= MAX_N; i++)
        if (is_prime[i])
            for (int j = i * i; j <= MAX_N; j += i)
                is_prime[j] = false;

    // جمع الأعداد الأولية حتى n
    for (int i = 2; i <= n; ++i)
        if (is_prime[i])
            primes.push_back(i);

    int count = 0;
    // فحص كل زوج متجاور
    for (int i = 1; i < (int)primes.size(); ++i) {
        int sum = primes[i] + primes[i - 1] + 1;
        if (sum <= MAX_N && is_prime[sum])
            count++;
    }

    return count;
}

int main() {
    int n, k;
    cin >> n >> k;

    if (findPrime(n) >= k)
        cout << "YES\n";
    else
        cout << "NO\n";

    return 0;
}

شرح تفاعلي للكود

  1. الغربال أولاً: نشغّل الغربال على كامل MAX_N (وليس فقط n) لأن مجموع الأعداد الأولية قد يتجاوز n. مثلاً إذا n=100 فمجموع أوليين قريبين منه قد يصل لـ 200.

  2. جمع الأعداد الأولية: primes.push_back(i) — نبني قائمة مرتبة بالأعداد الأولية حتى n. بما أن الغربال يمر بالترتيب التصاعدي، القائمة مرتبة تلقائياً — كل عنصران متجاوران في القائمة هما أعداد أولية متجاورة.

  3. فحص الشرط: primes[i] + primes[i-1] + 1 — نجمع كل زوج متتالي ونضيف 1. ثم is_prime[sum] يجيبنا فوراً (O(1)) هل المجموع أولي — هذا هو جمال الغربال: الفحص فوري بعد بنائه!

  4. الشرط الإضافي: sum <= MAX_N — نتحقق أن المجموع لا يتجاوز حجم المصفوفة قبل الوصول إليها، حمايةً من خطأ تجاوز الحدود.
