🏆 تدريبات أولمبياد البرمجة التنافسية (نظرية الأعداد) 🏆

السؤال الأول: صناديق تمور القصيم (مستوى مبتدئ)

نص المسألة:
يمتلك مزارع في منطقة القصيم A كيلوجرام من تمر السكري، و B كيلوجرام من تمر العجوة. يريد المزارع تعبئة هذه التمور في صناديق متطابقة، بحيث يحتوي كل صندوق على نفس الكمية من السكري ونفس الكمية من العجوة، دون أن يتبقى لديه أي تمور خارج الصناديق.
المطلوب: ما هو أكبر عدد ممكن من الصناديق التي يمكن للمزارع تجهيزها؟

شرح خطوات الحل:
1. بما أننا نريد تقسيم الكميتين إلى أجزاء متساوية، فنحن نبحث عن "قاسم".
2. وبما أننا نريد "أكبر عدد ممكن من الصناديق"، فنحن نبحث عن "القاسم المشترك الأكبر" (GCD).
3. لحل المسألة بسرعة دون تجاوز الوقت (TLE)، سنستخدم خوارزمية إقليدس التي تعتمد على باقي القسمة.

⚙️ عرض تفاعلي لخوارزمية إقليدس

أدخل كميات التمور لترى كيف تحسب الخوارزمية الحل خطوة بخطوة:

الكود البرمجي (C++):

// تضمين المكتبات الأساسية
#include <iostream>
using namespace std;

// دالة خوارزمية إقليدس الذكية
int gcd(int a, int b) {
    if (b == 0) 
        return a; // إذا وصلنا للصفر، فالعدد الآخر هو الحل
    
    return gcd(b, a % b); // نمرر الرقم الثاني، وباقي القسمة
}

int main() {
    int a, b;
    cin >> a >> b; // قراءة كمية السكري والعجوة
    
    int max_boxes = gcd(a, b);
    
    cout << max_boxes << endl;
    return 0;
}

السؤال الثاني: رحلات مترو الرياض (مستوى متوسط)

نص المسألة:
انطلق قطاران من المحطة الرئيسية لمترو الرياض (محطة مركز الملك عبدالله المالي) في نفس اللحظة. القطار على المسار الأزرق يقوم برحلة دائرية ويعود للمحطة كل X دقيقة، والقطار على المسار الأحمر يعود للمحطة كل Y دقيقة.
المطلوب: بعد كم دقيقة سيلتقي القطاران معاً في المحطة الرئيسية للمرة القادمة؟

شرح خطوات الحل:
1. القطار الأول يعود في الدقائق: X, 2X, 3X... والقطار الثاني في: Y, 2Y, 3Y...
2. نحن نبحث عن "مضاعف" مشترك للوقتين، ونريد أول لقاء، أي "المضاعف المشترك الأصغر" (LCM).
3. لحساب LCM بكفاءة ودون التعرض لمشكلة تجاوز سعة الأرقام (Overflow)، نستخدم القاعدة الذهبية: LCM = (X / GCD(X,Y)) * Y.
ملاحظة: تذكر استخدام نوع البيانات long long لأن الوقت قد يكون كبيراً جداً!

🔄 عرض تفاعلي لحساب نقطة الالتقاء

أدخل زمن دورة كل قطار بالدقائق:

الكود البرمجي (C++):

// تضمين المكتبات
#include <iostream>
using namespace std;

// دالة GCD مطلوبة لحساب LCM
long long gcd(long long a, long long b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

// دالة LCM الآمنة من الفيض (Overflow)
long long lcm(long long a, long long b) {
    if (a == 0 || b == 0) return 0;
    return (a / gcd(a, b)) * b; // نقسم أولاً ثم نضرب!
}

int main() {
    long long x, y; // استخدمنا long long لتجنب الأخطاء مع الأرقام الكبيرة
    cin >> x >> y;
    
    long long meeting_time = lcm(x, y);
    
    cout << meeting_time << endl;
    return 0;
}
