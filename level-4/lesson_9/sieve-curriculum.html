غربال إراتوستينس

Sieve of Eratosthenes

أسرع خوارزمية لإيجاد جميع الأعداد الأولية حتى حدٍّ معين — من اختراع عالم الرياضيات اليوناني إراتوستينس قبل أكثر من ألفي عام، وما زالت حاضرة في كل مسابقة برمجة حتى اليوم.

📚

التعريفات الأساسية

تعريف — العدد الأولي (Prime Number)

عدد صحيح أكبر من 1 لا يقبل القسمة إلا على 1 وعلى نفسه. أمثلة: 2، 3، 5، 7، 11، 13، 17... العدد 2 هو الوحيد بين الأعداد الأولية الزوجية.

تعريف — الغربال (Sieve)

خوارزمية تصفية جماعية تبدأ بافتراض أن كل الأعداد أولية، ثم تشطب المضاعفات تدريجياً حتى تبقى الأعداد الأولية فقط. أشبه بغربال حقيقي يُرسَب منه ما ليس بأولي.

تعريف — المضاعفات (Multiples)

مضاعفات العدد i هي الأعداد 2i, 3i, 4i, ... — وهي بطبيعة الحال مقسومة على i فلا يمكن أن تكون أولية (طالما i > 1).

تعريف — مصفوفة is_prime[]

مصفوفة منطقية (Boolean) نستخدمها في الغربال. is_prime[i] = true تعني "نفترض أن i أولي حتى الآن"، وتُصبح false عند شطبه كمضاعف.

خطوات الخوارزمية

1

إنشاء المصفوفة وتهيئتها

أنشئ مصفوفة منطقية is_prime[] بحجم MAX_N + 1 وأدخل القيمة true في جميع خاناتها — أي "نفترض أن الجميع أولي في البداية".

2

الحالات الحافة: 0 و1

اضبط is_prime[0] = is_prime[1] = false لأن 0 و1 ليسا أوليين بالتعريف.

3

الحلقة الرئيسية: من 2 إلى √N

ابدأ من i = 2 وارفع حتى i * i <= MAX_N. إذا كان is_prime[i] = true فاشطب جميع مضاعفاته.

4

شطب المضاعفات من i² فصاعداً

الحلقة الداخلية تبدأ من j = i * i (تحسين مهم!) وتزيد بمقدار i في كل خطوة: j += i

5

ما يبقى هو الأعداد الأولية

بعد انتهاء الحلقة، كل i حيث is_prime[i] = true هو عدد أولي. أجمعها في متجه إن أردت.

💻

الكود الأساسي — Sieve of Eratosthenes

C++ — Sieve of Eratosthenes
#include <iostream>
#include <vector>
using namespace std;

// الحد الأقصى للأعداد التي نريد فحصها
const int MAX_N = 1000000;
vector<bool> is_prime(MAX_N + 1, true); // افترض الجميع أولي

void sieve() {
    is_prime[0] = is_prime[1] = false; // الحالات الحافة

    for (int i = 2; i * i <= MAX_N; i++) {
        // إذا لم يُشطب i بعد، فهو أولي
        if (is_prime[i]) {
            // اشطب مضاعفاته — ابدأ من i² (تحسين!)
            for (int j = i * i; j <= MAX_N; j += i) {
                is_prime[j] = false;
            }
        }
    }
}
شرح تفاعلي سطر بسطر
1
تهيئة المصفوفة: vector<bool> is_prime(MAX_N+1, true) — ننشئ مصفوفة منطقية بطول MAX_N+1 ونملؤها بـ true. نستخدم vector<bool> لأنها تُحسّن استهلاك الذاكرة (بت واحد لكل عنصر بدلاً من بايت).
2
الحالات الحافة: is_prime[0] = is_prime[1] = false — 0 و1 بالتعريف ليسا أوليين، لذا نشطبهما قبل بدء الحلقة.
3
شرط التوقف: i * i <= MAX_N — لماذا √N وليس N؟ لأنه إذا كان للعدد n قاسم أكبر من √n، فلا بد أن يكون له قاسم أصغر من √n أيضاً، وهذا الأصغر قد شطب n بالفعل. لذا لا حاجة للاستمرار بعد √N.
4
فحص إذا كان أولياً: if (is_prime[i]) — إذا لم يُشطب i من قِبَل عدد أولي سابق، فهو بالتأكيد أولي. ليس علينا إثبات ذلك — الغربال يضمنه.
5
البدء من i²: j = i * i — هذا التحسين الجوهري! المضاعفات 2i, 3i, 4i, ..., (i-1)·i قد شُطبت بالفعل حين معالجة الأعداد الأولية الأصغر من i. أول مضاعف لم يُلمس هو i².
6
الشطب: j += i — ننتقل من مضاعف لآخر بإضافة i في كل مرة (أي نشطب i², i²+i, i²+2i, ...)، ونضع is_prime[j] = false لكل منها.
🔍

لماذا نبدأ الشطب من i² وليس من 2i؟

هذا التحسين الحاسم يُقلل عدد العمليات بشكل ملحوظ. دعنا نفهم السبب بمثال:

مثال — عندما i = 5

لماذا لا نشطب 10 = 5×2 أو 15 = 5×3 أو 20 = 5×4؟

المضاعفما شطبه مسبقاًالنتيجة
5 × 2 = 10العدد الأولي 2مشطوب بالفعل ✓
5 × 3 = 15العدد الأولي 3مشطوب بالفعل ✓
5 × 4 = 20العدد الأولي 2مشطوب بالفعل ✓
5 × 5 = 25لا أحد← أول مضاعف غير مشطوب!

القاعدة: كل مضاعف i × k حيث k < i يحتوي على عامل أولي أصغر من i، وقد شطبته حلقة سابقة. إذن أول مضاعف يحتاج معالجة هو i × i = i².

مصفوفة بحجم N
مقارنة بديهية

لماذا O(N log log N) وليس O(N²)؟

رغم وجود حلقتين متداخلتين، العمليات الفعلية هي مجموع N/2 + N/3 + N/5 + N/7 + ... (على الأعداد الأولية فقط). هذا المجموع رياضياً يساوي N · log(log N)، وهو قريب جداً من الخطي في الممارسة. لـ N = 10,000,000 تعمل في أجزاء من الثانية.

مسألة تطبيقية — Noldbach

📖 نص المسألة

مسألة Noldbach

يدّعي Noldbach أن على الأقل k عدد أولي في النطاق من 2 إلى n يمكن التعبير عنها كـ (عدد أولي + عدد أولي متجاور + 1).

مثلاً: 5 = 2 + 2 + 1 أو 7 = 3 + 3 + 1 أو 11 = 5 + 5 + 1.

يُطلق على عددين أوليين اسم متجاورين إذا لم يكن بينهما عدد أولي آخر (مثل 3 و5، أو 11 و13).

المطلوب: هل Noldbach على حق أم على خطأ؟ اطبع YES أو NO.

📐 تحليل الحل
1

شغّل الغربال حتى n

نولّد جميع الأعداد الأولية من 2 إلى n باستخدام غربال إراتوستينس ونخزنها في متجه primes[].

2

فحص كل زوج من الأعداد الأولية المتجاورة

لكل زوج متجاور primes[i-1] و primes[i]، احسب المجموع primes[i-1] + primes[i] + 1.

3

تحقق هل المجموع أولي

استخدم is_prime[] مباشرةً (فحص O(1)) لمعرفة هل هذا المجموع أولي.

4

قارن العداد بـ k

إذا كان عدد الأعداد الأولية المقبولة ≥ k اطبع YES، وإلا NO.

C++ — Noldbach Solution
#include <iostream>
#include <vector>
using namespace std;

const int MAX_N = 1000000;
vector<bool> is_prime(MAX_N + 1, true);
vector<int> primes;

int findPrime(int n) {
    is_prime[0] = is_prime[1] = false;

    // الغربال
    for (int i = 2; i * i <= MAX_N; i++)
        if (is_prime[i])
            for (int j = i * i; j <= MAX_N; j += i)
                is_prime[j] = false;

    // جمع الأعداد الأولية حتى n
    for (int i = 2; i <= n; ++i)
        if (is_prime[i])
            primes.push_back(i);

    int count = 0;
    // فحص كل زوج متجاور
    for (int i = 1; i < (int)primes.size(); ++i) {
        int sum = primes[i] + primes[i - 1] + 1;
        if (sum <= MAX_N && is_prime[sum])
            count++;
    }

    return count;
}

int main() {
    int n, k;
    cin >> n >> k;

    if (findPrime(n) >= k)
        cout << "YES\n";
    else
        cout << "NO\n";

    return 0;
}
شرح تفاعلي للكود
1
الغربال أولاً: نشغّل الغربال على كامل MAX_N (وليس فقط n) لأن مجموع الأعداد الأولية قد يتجاوز n. مثلاً إذا n=100 فمجموع أوليين قريبين منه قد يصل لـ 200.
2
جمع الأعداد الأولية: primes.push_back(i) — نبني قائمة مرتبة بالأعداد الأولية حتى n. بما أن الغربال يمر بالترتيب التصاعدي، القائمة مرتبة تلقائياً — كل عنصران متجاوران في القائمة هما أعداد أولية متجاورة.
3
فحص الشرط: primes[i] + primes[i-1] + 1 — نجمع كل زوج متتالي ونضيف 1. ثم is_prime[sum] يجيبنا فوراً (O(1)) هل المجموع أولي — هذا هو جمال الغربال: الفحص فوري بعد بنائه!
4
الشرط الإضافي: sum <= MAX_N — نتحقق أن المجموع لا يتجاوز حجم المصفوفة قبل الوصول إليها، حمايةً من خطأ تجاوز الحدود.

سهل

المستوى الأول

س١

ما الفرق بين فحص عدد واحد للتأكد من كونه أولياً وبين غربال إراتوستينس؟ متى تستخدم كلاً منهما؟

تعريفمقارنة
+

فحص عدد واحد: نقسم n على كل الأعداد من 2 إلى √n. تعقيده O(√n). يُستخدم عند الحاجة لفحص عدد واحد أو بضعة أعداد.

الغربال: يولّد جميع الأعداد الأولية حتى N في O(N log log N). أبطأ في البناء، لكن بعده كل فحص يصبح O(1) فوري.

القاعدة: إذا احتجت فحص عدد واحد → فحص مباشر. إذا احتجت فحص آلاف الأعداد في نطاق → الغربال.

س٢

لماذا نضبط is_prime[0] = is_prime[1] = false في بداية الغربال؟

حالات حافةتعريف
+

لأن 0 و1 بالتعريف ليسا أوليين. العدد الأولي يجب أن يكون أكبر من 1 ولا يقبل القسمة إلا على 1 وعلى نفسه.

إذا لم نفعل ذلك، سيبقى is_prime[0] وis_prime[1] بالقيمة true ونحصل على نتائج خاطئة عند الاستعلام عنهما.

س٣

ما مخرجات الكود التالي؟ sieve(); cout << is_prime[17];

تتبع كودأعداد أولية
+

المخرج: 1 (وهو يعني true).

17 عدد أولي لأنه لا يقبل القسمة على أي عدد من 2 إلى √17 ≈ 4.1. نفحص: 17÷2=8.5، 17÷3=5.6، 17÷4=4.25 — لا قسمة صحيحة. إذن is_prime[17] = true.

س٤

ما الفرق بين vector<bool> وvector<int> في سياق الغربال؟ أيهما أفضل ولماذا؟

ذاكرةتحسين
+

vector<bool> تُخزّن كل قيمة في بت واحد فقط، بينما vector<int> تستخدم 4 بايت (32 بت) لكل قيمة.

للغربال حتى N=10,000,000: vector<bool> تستهلك ~1.2 MB، بينما vector<int> تستهلك ~40 MB. في المسابقات حيث حد الذاكرة عادةً 256 MB، هذا فرق مهم.

عيب vector<bool>: قد تكون أبطأ نسبياً بسبب عمليات الضغط/الفك. في الغالب نستخدمها في الغربال.

س٥

كم عدد الأعداد الأولية بين 1 و20؟ عدّدها وبيّن كيف يجدها الغربال.

تطبيق يدويتتبع
+

الأعداد الأولية بين 1 و20 هي 8 أعداد: 2، 3، 5، 7، 11، 13، 17، 19.

مسار الغربال: يبدأ من i=2 → يشطب {4,6,8,10,12,14,16,18,20} | i=3 → يشطب {9,15} (6,12,18 مشطوبة) | i=4 → is_prime[4]=false نتجاهل | i=5 → يبدأ من 25>20 فيتوقف. ما بقي صحيحاً هو الأعداد الأولية.

متوسط

المستوى الثاني

س٦

اكتب كوداً يستخدم الغربال لطباعة جميع الأعداد الأولية التوأم (Twin Primes) حتى N. الأعداد الأولية التوأم هي الأزواج التي تفصلها مسافة 2 مثل (3,5) و(11,13).

Twin Primesتطبيق
+

بعد بناء الغربال، نبحث عن كل عدد أولي p حيث p+2 أيضاً أولي:

C++
sieve();
for (int p = 2; p + 2 <= N; p++) {
    if (is_prime[p] && is_prime[p + 2])
        cout << "(" << p << ", " << p+2 << ")\n";
}

الفكرة مباشرة: بعد بناء الغربال، الفحص is_prime[p] هو O(1)، فنكتفي بحلقة واحدة.

س٧

كيف تُنشئ غربالاً يغطي نطاقاً معيناً [L, R] حيث L وR يمكن أن يكونا كبيرين جداً (مثل 10¹²) لكن R-L لا يتجاوز 10⁶؟

Segmented Sieveمتقدم
+

هذا هو الغربال المجزأ (Segmented Sieve). الفكرة:

١. شغّل غربالاً عادياً حتى √R لجمع الأعداد الأولية الصغيرة.

٢. أنشئ مصفوفة seg[] بحجم R-L+1 تُمثّل الأعداد في [L, R].

٣. لكل عدد أولي صغير p، اشطب مضاعفاته في النطاق [L,R] بالبدء من أول مضاعف لـ p ≥ L.

C++ — Segmented Sieve (مبسّط)
vector<bool> seg(R - L + 1, true);
if (L == 1) seg[0] = false;
for (int p : small_primes) {
    long long start = ((long long)L + p - 1) / p * p;
    if (start == p) start += p;
    for (long long j = start; j <= R; j += p)
        seg[j - L] = false;
}
س٨

استخدم الغربال لحساب مجموع جميع الأعداد الأولية حتى N. ما أقصى قيمة N يمكن التعامل معها دون تجاوز نوع البيانات long long؟

مجموعoverflow
+

الكود بسيط: بعد الغربال نجمع كل i حيث is_prime[i]:

C++
sieve();
long long sum = 0;
for (int i = 2; i <= N; i++)
    if (is_prime[i]) sum += i;

أقصى قيمة long long ≈ 9.2 × 10¹⁸. مجموع الأعداد الأولية حتى 10⁸ ≈ 2.79 × 10¹⁴، وحتى 10⁹ ≈ 2.4 × 10¹⁶. إذن لـ N حتى ≈ 10⁹ نحن بأمان مع long long.

س٩

اشرح كيف يمكن تعديل الغربال لحساب أصغر عامل أولي (Smallest Prime Factor) لكل عدد. ما الفائدة من ذلك؟

SPFتحليل إلى عوامل
+

نُضيف مصفوفة spf[] (Smallest Prime Factor) تُعبأ أثناء الغربال:

C++ — SPF Sieve
vector<int> spf(MAX_N + 1);
iota(spf.begin(), spf.end(), 0); // spf[i] = i مبدئياً

for (int i = 2; i * i <= MAX_N; i++) {
    if (spf[i] == i) { // i أولي
        for (int j = i * i; j <= MAX_N; j += i)
            if (spf[j] == j)
                spf[j] = i; // أصغر عامل أولي لـ j
    }
}

// تحليل n إلى عوامل في O(log n)
while (n > 1) {
    cout << spf[n] << " ";
    n /= spf[n];
}

الفائدة: تحليل أي عدد إلى عوامله الأولية في O(log n) بدلاً من O(√n) — مفيد جداً في المسائل التي تتطلب تحليل آلاف الأعداد.

س١٠

في مسألة Noldbach، ماذا لو طُلب منك حساب المجموع بدلاً من العدد؟ عدّل الكود وفسّر التغييرات.

Noldbachتعديل كود
+

بدلاً من عد الأعداد المقبولة، نجمعها:

C++
long long total = 0;
for (int i = 1; i < (int)primes.size(); ++i) {
    int sum = primes[i] + primes[i-1] + 1;
    if (sum <= MAX_N && is_prime[sum])
        total += sum; // اجمع العدد الأولي نفسه
}
cout << total << "\n";

التغيير الوحيد: استبدال count++ بـ total += sum. نستخدم long long للمجموع لتجنب الفيض في الأعداد الكبيرة.

صعب

المستوى الثالث

س١١

اشرح غربال euler (Linear Sieve) وكيف يحقق تعقيداً حقيقياً O(N) مقارنةً بـ O(N log log N) للغربال التقليدي.

Linear Sieveنظري متقدم
+

في الغربال التقليدي، العدد المركب يُشطب أكثر من مرة (مثل 12 يُشطب عند i=2 وعند i=3). غربال أويلر يضمن شطب كل عدد مرة واحدة فقط:

C++ — Linear Sieve
vector<int> primes, spf(N+1, 0);
for (int i = 2; i <= N; i++) {
    if (!spf[i]) {       // i أولي
        spf[i] = i;
        primes.push_back(i);
    }
    for (int p : primes) {
        if (p > spf[i] || (long long)i * p > N) break;
        spf[i * p] = p;  // اشطب i*p مرة واحدة فقط
    }
}

المبدأ: نشطب كل مركّب باستخدام أصغر عامله الأولي فقط. الشرط p > spf[i] يمنع الشطب المكرر. النتيجة: تعقيد زمني O(N) صارم — كل عدد يُعالج مرة واحدة بالضبط.

س١٢

احسب عدد الأعداد الأولية في النطاق [L, R] حيث L وR قد يصلان لـ 10¹² و R-L ≤ 10⁶. اكتب الكود الكامل.

Segmented Sieveكود كامل
+
C++ — Segmented Sieve Complete
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long L, R;
    cin >> L >> R;

    int sqrtR = (int)sqrt((double)R) + 1;

    // غربال صغير حتى √R
    vector<bool> small(sqrtR + 1, true);
    small[0] = small[1] = false;
    for (int i = 2; i * i <= sqrtR; i++)
        if (small[i])
            for (int j = i*i; j <= sqrtR; j += i)
                small[j] = false;

    // غربال النطاق [L, R]
    int sz = (int)(R - L + 1);
    vector<bool> seg(sz, true);
    if (L == 1) seg[0] = false;

    for (int p = 2; p <= sqrtR; p++) {
        if (!small[p]) continue;
        long long start = max((long long)p*p,
                  (L + p - 1) / p * p);
        for (long long j = start; j <= R; j += p)
            seg[j - L] = false;
    }

    int count = 0;
    for (bool b : seg) if (b) count++;
    cout << count << "\n";
    return 0;
}

الكود يعمل في O(√R + (R-L) log log √R) — أقل من ثانية لـ R=10¹² وR-L=10⁶.

كيف تُعدّل الغربال لحساب دالة أويلر φ(n) (Euler's Totient) لجميع الأعداد حتى N في O(N log log N)؟

Euler Totientنظرية الأعداد
+

دالة أويلر φ(n) = عدد الأعداد من 1 إلى n التي تكون أولية نسبياً مع n. يمكن حسابها لجميع الأعداد بتعديل الغربال:

C++ — Totient Sieve
vector<int> phi(N + 1);
iota(phi.begin(), phi.end(), 0); // phi[i] = i

for (int i = 2; i <= N; i++) {
    if (phi[i] == i) { // i أولي
        for (int j = i; j <= N; j += i) {
            // تطبيق الصيغة: φ(n) = n × Π(1 - 1/p)
            phi[j] -= phi[j] / i;
        }
    }
}

نتيجة: phi[n] يحتوي φ(n) لكل n من 1 إلى N. مثلاً: φ(6)=2، φ(7)=6، φ(12)=4. مفيد في مسائل النظرية العددية كنظرية أويلر وRSA.

sieve();

// a=2, b أولي, 2+b أولي

كيف تُطبّق الغربال لحساب عدد مقسمات (Number of Divisors) لكل عدد من 1 إلى N بكفاءة؟ استخدمه للعثور على العدد الذي له أكبر عدد مقسمات.

عدد المقسماتDivisor Sieveمتقدم
+

نُنشئ مصفوفة d[] (عدد المقسمات) ونعبّئها بطريقة مشابهة للغربال — لكل i، أضف 1 لجميع مضاعفاته:

C++ — Divisor Count Sieve
vector<int> d(N + 1, 0);

// لكل عدد i، اشطب مضاعفاته وأضف 1
for (int i = 1; i <= N; i++)
    for (int j = i; j <= N; j += i)
        d[j]++;

// أوجد العدد الذي له أكبر عدد مقسمات
int maxDiv = 0, bestN = 1;
for (int i = 1; i <= N; i++)
    if (d[i] > maxDiv) {
        maxDiv = d[i];
        bestN = i;
    }

cout << "العدد " << bestN << " له أكبر عدد مقسمات: " << maxDiv << "\n";

التعقيد: O(N log N) — نفس تعقيد السلسلة التوافقية. لكل i، نُعالج N/i مضاعف، والمجموع = N(1/1+1/2+...+1/N) = N·H(N) ≈ N·ln(N).

مثال: حتى N=1000، العدد 840 له 32 مقسماً — أكبر عدد في هذا النطاق.
