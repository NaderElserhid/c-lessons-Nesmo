المفاهيم الأساسية
تعريف المكون المتصل:
في الرسم البياني غير الموجه، يُقال إن الرأسين u و v ينتميان إلى نفس المكون المتصل إذا كان هناك مسار يربط بينهما. إذا كان الرسم البياني يتكون من مكون واحد فقط فإنه يُعتبر متصلاً بالكامل.
💡 فكرة جوهرية:
عند تشغيل DFS من رأس غير مزار، فإنها ستزور جميع الرؤوس القابلة للوصول منه — أي كل رؤوس مكونه المتصل. لذا نعد عدد مرات بدء DFS لتعرف عدد المكونات.
⚠️ تنبيه:
هذه التقنية تعمل فقط على الرسوم البيانية غير الموجهة. للرسوم الموجهة هناك مفهوم مختلف يُسمى "المكونات القوية الترابطية" (SCCs).

خطوات الخوارزمية

  • ١
    قراءة الرسم البياني (الرؤوس والأحرف) وبناء قائمة الجوار adj[].
  • ٢
    إنشاء مصفوفة زيارة vis[] بقيم false.
  • ٣
    للمرور على جميع الرؤوس، إذا لم يُزر الرأس i بعد، نشغّل DFS منه ونزيد عداد المكونات.
  • ٤
    في DFS: نضع vis[u] = true ثم ندعو DFS لكل جار غير مزار.
  • ٥
    نستخدم نتيجة عداد المكونات للإجابة على متطلبات المسألة.

CSES ↗

يوجد n مدينة و m طريقاً بينها. مهمتك هي إيجاد الحد الأدنى من عدد الطرق التي يجب إضافتها بحيث يكون هناك مسار بين أي مدينتين، وتحديد أي الطرق يجب بناؤها.

الفكرة الرئيسية:
إذا كان هناك k مكوناً متصلاً، فنحتاج بالضبط إلى k - 1 طريقاً لتوحيدها. الاستراتيجية: نختار رأساً "مرجعياً" من المكون الأول ونوصله بمرجع كل مكون آخر.

تتبع المثال
  • ١
    نشغّل DFS من كل رأس غير مزار ونحفظ أول رأس في كل مكون (sources[]).
  • ٢
    الإجابة = sources.size() - 1 (عدد المكونات ناقص واحد).
  • ٣
    نطبع الأزواج: sources[0] ↔ sources[i] لكل i > 0.
C++
const int maxN = 200'001;

bool vis[maxN];
vector<int> adj[maxN];

// DFS تزور جميع رؤوس المكون وتعلّم vis[u]
void dfs(int u) {
    vis[u] = true;
    for (int v : adj[u])
        if (!vis[v]) dfs(v);
}

int main() {
    int n, m;
    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u); // رسم غير موجه
    }

    vector<int> sources; // أول رأس في كل مكون

    for (int i = 1; i <= n; i++)
        if (!vis[i]) {
            sources.push_back(i);
            dfs(i);
        }

    cout << sources.size() - 1 << "\n";
    for (int i = 1; i < sources.size(); i++)
        cout << sources[0] << ' ' << sources[i] << "\n";
}

مثال: n=5, m=2, أحرف: 1-2 و 3-4

عدد الطرق المطلوبة: 3 - 1 = 2
الطرق: 1 3   و   1 5

Cyclic Components

Codeforces ↗

معطى رسم بياني غير موجه، احسب عدد المكونات التي هي دورات. المكون الذي يتكون من n رأساً يُعتبر دورة إذا كان له بالضبط n حرفاً (أي كل رأس فيه درجة = 2).

البرهان:
إذا كان كل رأس في المكون مجاور لرأسين بالضبط (degree = 2)، فإن المكون يشكل دورة بسيطة. هذا شرط ضروري وكافٍ في الرسوم البيانية البسيطة غير الموجهة.
💡 تحسين في الكود:
دالة dfs تُرجع bool — صحيح إذا كان المكون دورة. نستخدم &= لضمان أن الشرط يسري على جميع الرؤوس في المكون.
الحل المشروح
الكود الكامل
  • ١
    نشغّل DFS من كل رأس غير مزار.
  • ٢
    أثناء DFS، نبدأ بافتراض أن المكون دورة (ret = degree[u] == 2).
  • ٣
    نُضاعف النتيجة مع كل رأس في المكون باستخدام ret &= dfs(v).
  • ٤
    إذا أرجعت dfs قيمة true نزيد العداد ans.
C++
const int maxN = 200'001;

vector<int> adj[maxN];
bool vis[maxN];

// تُرجع true إذا كان المكون دورة كاملة
bool dfs(int u) {
    vis[u] = 1;
    bool ret = (adj[u].size() == 2); // شرط الدورة

    for (int v : adj[u])
        if (!vis[v]) ret &= dfs(v); // AND على كل الرؤوس

    return ret;
}

int main() {
    int n, m;
    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    int ans = 0;
    for (int i = 1; i <= n; i++)
        if (!vis[i]) ans += dfs(i);

    cout << ans << "\n";
}
