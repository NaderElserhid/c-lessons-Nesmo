Segment Tree
شجرة القطاعات

هيكل بيانات قوي لمعالجة استعلامات النطاق والتحديثات على المصفوفات بكفاءة O(log n).

المستوى: متوسط–متقدم
الوقت التقديري: 90 دقيقة
الأسئلة: 15 سؤالاً
التعقيد O(log n)
1
ما هي Segment Tree؟
🌳 التعريف

Segment Tree (شجرة القطاعات) هي شجرة ثنائية يمثّل كل عقدة (node) فيها قيمةً مجمَّعةً لمقطع (نطاق) معين من المصفوفة الأصلية. تتميز بأنها تُتيح معالجة استعلامات النطاق والتحديثات في زمن O(log n) بدلاً من O(n).

قاعدة البناء

كل leaf node يمثّل عنصراً واحداً فقط من المصفوفة. كل internal node يمثّل دمجاً لطفليه (مجموع، أو أصغر قيمة، أو أكبر قيمة، أو غير ذلك).

📐 مثال بصري على المصفوفة [2, 4, 6, 8]

شجرة القطاعات لحساب المجموع على المصفوفة [2, 4, 6, 8] تبدو هكذا. الأرقام بين الأقواس تمثّل النطاق الذي يغطيه كل node.

2
عدد العقد والحشو والتمثيل
🔢 عدد العقد

في كل مستوى من الشجرة يتضاعف عدد العقد: 1، 2، 4، 8، … أي قوى العدد 2. وبما أن كل قوة تساوي مجموع القوى السابقة زائد 1، فإن العدد الكلي لعقد شجرة ذات N ورقة هو:

Total Nodes = 2N − 1

لذا نُخصّص مصفوفة بحجم 2 * N لتخزين الشجرة (نُهمل الموضع 0 للتبسيط).

🧩 الحشو (Padding)

إذا كان طول المصفوفة n ليس قوةً للعدد 2، نحتاج إلى حشو العناصر حتى يكون عدد الأوراق N هو أقرب قوة للعدد 2 لا تقل عن n.

مثال

المصفوفة [2, 4, 6] بطول 3. أقرب قوة لـ 2 تعلو 3 هي N = 4. نُضيف 0 كعنصر رابع، فتصبح الشجرة بـ 7 عقد (2×4 − 1). القيمة المُضافة 0 لا تُؤثر على حسابات المجموع ولا الحد الأقصى، لكن للحد الأدنى نُضيف INT_MAX.

حساب N برمجياً

يمكن حساب N بطريقتين متكافئتين في C++:

C++ — حساب N
// الطريقة الأولى: بالبت
int N = 1 << (32 - __builtin_clz(n - 1));

// الطريقة الثانية: بالحلقة (ملاحظة: الفاصلة المنقوطة في نهاية for مهمة!)
int N;
for (N = 1; N < n; N *= 2);  // الفاصلة المنقوطة هنا تعني أن جسم الحلقة فارغ
📍 التمثيل كمصفوفة — خاصية الأرقام

نُمثّل الشجرة كمصفوفة seg بدلاً من بنية شجرية صريحة. هذا يُوفّر الذاكرة ويُسرّع العمليات. العقدة رقم i لها العلاقات التالية:

العلاقةالصيغةالمعنى
الطفل الأيسر2 * iالفرع الأيسر للعقدة i
الطفل الأيمن2 * i + 1الفرع الأيمن للعقدة i
الوالدi / 2الأب في الشجرة
الورقة للعنصر jj + N - 1موضع العنصر j في مصفوفة seg
مثال على التمثيل

للشجرة السابقة مع N = 4: الجذر في الموضع 1 (يغطي [1,4]). أبناؤه في الموضعين 2 و 3. الأوراق في المواضع 4, 5, 6, 7 وتقابل العناصر a[1], a[2], a[3], a[4] على التوالي.

أدخل مصفوفةً وعملية الدمج، ثم اضغط «بناء» لمشاهدة الشجرة بالكامل بشكل مرئي.

الاستعلام عن نطاق
🔍 كيف تعمل دالة query؟

الدالة query(id, l, r, ql, qr) تعمل بشكل تعاودي (Recursive) بثلاث حالات:

  1. لا تقاطع (No Overlap): إذا كان نطاق الاستعلام [ql, qr] لا يتقاطع مع نطاق العقدة [l, r] تماماً (ql > r || l > qr)، نُرجع القيمة المحايدة (0 للمجموع، INT_MAX للحد الأدنى، INT_MIN للحد الأقصى) ونتوقف.
  2. تغطية كاملة (Full Cover): إذا كان نطاق الاستعلام يغطي نطاق العقدة بالكامل (ql <= l && r <= qr)، نُرجع قيمة العقدة مباشرةً دون نزول إضافي.
  3. تقاطع جزئي (Partial): نقسم على المنتصف m = (l + r) / 2 ونستدعي الدالة على الطفلين ثم ندمج النتيجتين.
التعقيد الزمني: O(log n) على الأكثر 4 × log(N) عقدة تُزار
C++ — دالة query
int query(int id, int l, int r, int ql, int qr) {
    // حالة 1: لا تقاطع — يُرجع القيمة المحايدة
    if (ql > r || l > qr) {
        return 0;  // 0 للمجموع | INT_MAX للحد الأدنى | INT_MIN للحد الأقصى
    }
    // حالة 2: تغطية كاملة — يُرجع قيمة العقدة مباشرةً
    if (ql <= l && r <= qr) {
        return seg[id];
    }
    // حالة 3: تقاطع جزئي — تقسيم واستدعاء ذاتي
    int m = (l + r) / 2;
    return query(id * 2, l, m, ql, qr) + query(id * 2 + 1, m + 1, r, ql, qr);
}
// استدعاء الاستعلام عن النطاق [ql, qr]:
// query(1, 1, N, ql, qr)
🔍 شرح الكود سطراً بسطر
  1. المعاملات id, l, r: id هو رقم العقدة الحالية في مصفوفة seg. l و r هما حدا النطاق الذي تغطيه هذه العقدة.
  2. المعاملات ql, qr: هما حدا نطاق الاستعلام الذي يُريده المستخدم. تبقى ثابتةً في كل الاستدعاءات التعاودية.
  3. شرط اللاتقاطع: إذا كان nod range لا يتداخل مع query range، لا فائدة من النزول أعمق. نُرجع القيمة المحايدة (0 لا تُؤثر على المجموع).
  4. شرط التغطية الكاملة: إذا كان نطاق الاستعلام يحتوي نطاق العقدة بالكامل، نُرجع seg[id] مباشرةً. هذا هو سرّ كفاءة الشجرة — نتجنب إعادة حساب ما حُسب مسبقاً.
  5. الاستدعاء التعاودي: نقسم على المنتصف ونستدعي الطفلين، ثم ندمج النتيجتين بعملية الدمج المناسبة (+ أو min أو max).
⚗️ مختبر الاستعلام

بعد بناء الشجرة، أدخل نطاقاً [ql, qr] وشاهد أي العقد تُزار وكيف تُدمج النتائج.

تحديث نقطة
✏️ كيف نُحدّث عنصراً؟

لتحديث العنصر في الموضع j إلى القيمة v، نتبع خطوتين:

  1. تحديث الورقة: الورقة التي تمثّل j تقع في الموضع j + N - 1 في مصفوفة seg. نضبط قيمتها على v.
  2. إعادة حساب الآباء: نصعد من الورقة إلى الجذر بقسمة الرقم على 2، ونُعيد حساب كل أب بدمج طفليه. عدد الآباء هو log(N) وهو أيضاً عمق الشجرة.
لماذا نصعد إلى الجذر؟

لأن كل أب يحمل قيمةً محسوبةً من أبنائه. بتغيير ورقة، تتغير قيمة كل أب على المسار من الورقة إلى الجذر، لذا يجب إعادة حسابها جميعاً.

التعقيد الزمني: O(log n)
C++ — pointUpdate
void pointUpdate(int j, int v) {
    a[j] = v;          // تحديث المصفوفة الأصلية

    int idx = j + N - 1;  // موضع الورقة في مصفوفة seg
    seg[idx] = v;

    // الصعود من الورقة إلى الجذر وإعادة حساب كل أب
    for (int i = idx / 2; i > 0; i /= 2) {
        seg[i] = seg[i * 2] + seg[i * 2 + 1];  // دمج الطفلين
    }
}
🔍 شرح كود التحديث
  1. a[j] = v: نُحدّث المصفوفة الأصلية للإبقاء عليها متزامنةً مع الشجرة.
  2. idx = j + N - 1: نحوّل فهرس المصفوفة الأصلية (مرقّم من 1) إلى موضع الورقة في مصفوفة seg. مثلاً إذا j=2 و N=4، فالورقة في الموضع 5.
  3. seg[idx] = v: نُحدّث الورقة مباشرةً.
  4. حلقة الصعود (i /= 2): نبدأ من والد الورقة (idx/2) ونصعد إلى الجذر. في كل خطوة نُعيد حساب قيمة العقدة i بدمج طفليها (i*2) و(i*2+1). نتوقف عند i=0 (تجاوزنا الجذر).
⚗️ مختبر التحديث

أدخل موضع العنصر j (يبدأ من 1) والقيمة الجديدة v لمشاهدة مسار التحديث في الشجرة.

كود البناء الكامل
⚙️ بناء شجرة القطاعات — الخطوات
  1. حساب N: أقرب قوة للعدد 2 لا تقل عن n.
  2. ملء الأوراق من المصفوفة الأصلية: seg[i + N] = a[i] لكل عنصر.
  3. ملء الأوراق الإضافية بالقيمة المحايدة: 0 للمجموع، INT_MAX للحد الأدنى.
  4. بناء العقد الداخلية بترتيب عكسي: من N−1 حتى 1، كل عقدة = دمج طفليها.
C++ — بناء الشجرة
// ملء الأوراق من المصفوفة الأصلية (مرقّمة من 0)
for (int i = 0; i < n; i++) {
    seg[i + N] = a[i];
}

// ملء الأوراق المُضافة (الحشو) بالقيمة المحايدة
for (int i = n + N; i < 2 * N; i++) {
    seg[i] = 0;  // 0 للمجموع | INT_MAX للحد الأدنى | INT_MIN للحد الأقصى
}

// بناء العقد الداخلية من الأسفل إلى الأعلى
for (int i = N - 1; i > 0; i--) {
    seg[i] = seg[i * 2] + seg[i * 2 + 1];  // دمج الطفلين
}
🔍 شرح كود البناء
  1. الحلقة الأولى (ملء الأوراق): العنصر a[0] يذهب إلى seg[N]، وa[1] إلى seg[N+1]، وهكذا. لاحظ أننا نُرقّم المصفوفة من 0 ولكن الشجرة تبدأ من 1.
  2. الحلقة الثانية (الحشو): نملأ الأوراق الإضافية بالقيمة المحايدة حتى لا تُؤثر على النتائج.
  3. الحلقة الثالثة (البناء التصاعدي): نبدأ من N−1 (الأب المباشر للأوراق) وننتهي عند 1 (الجذر). كل عقدة داخلية i تأخذ قيمتها من دمج طفليها 2i و 2i+1. السبب في الترتيب العكسي هو ضمان أن الأبناء مبنيون قبل الأباء.

تحديث نقطةO(log n)log(N) أب على مسار الورقة للجذر

المسألة التطبيقية — Dynamic Range Minimum Queries
📋 نص المسألة (CSES)

لديك مصفوفة a من n عنصر وتريد معالجة q استعلام من نوعين:

النوع الأول

1 k u — حدّث القيمة في الموضع k إلى u.

النوع الثاني

2 l r — ما أصغر قيمة في النطاق [l, r]؟

💡 ملاحظات مهمة على الكود
  1. التعريف في النطاق العام مع MAXN ثابت: نستخدم MAXN كحد أقصى ثابت لحساب N في وقت الترجمة. هذا يُتيح تعريف seg كمصفوفة ذات حجم ثابت.
  2. قيمة الحشو INT_MAX: لأننا نحسب الحد الأدنى، الأوراق الإضافية تُملأ بـ INT_MAX حتى لا تُؤثر على النتيجة.
  3. في الاستعلام نُرجع INT_MAX لا 0 عند اللاتقاطع: لأن دمج min(a, INT_MAX) = a وهو ما نريده.
  4. pointUpdate تستخدم j (من 1) لا j-1: الدالة تستقبل الفهرس المرقّم من 1 وتُحوّله داخلياً إلى موضع الورقة بـ j + N - 1.
C++ — الكود الكامل للمسألة
#include <iostream>
#include <climits>
using namespace std;

const int MAXN = 200000;
const int N = (1 << (32 - __builtin_clz(MAXN - 1)));  // = 262144

int seg[N * 2];
int a[MAXN];

int query(int id, int l, int r, int ql, int qr) {
    if (ql > r || l > qr) return INT_MAX;  // لا تقاطع
    if (ql <= l && r <= qr) return seg[id];   // تغطية كاملة
    int m = (l + r) / 2;
    return min(query(id*2, l, m, ql, qr), query(id*2+1, m+1, r, ql, qr));
}

void pointUpdate(int j, int v) {
    a[j - 1] = v;
    int idx = j + N - 1;
    seg[idx] = v;
    for (int i = idx / 2; i > 0; i /= 2)
        seg[i] = min(seg[i * 2], seg[i * 2 + 1]);
}

int main() {
    int n, q;
    cin >> n >> q;

    for (int i = 0; i < n; i++) cin >> a[i];

    for (int i = 0; i < n; i++)   seg[i + N] = a[i];
    for (int i = n + N; i < 2*N; i++) seg[i] = INT_MAX;
    for (int i = N-1; i > 0; i--)   seg[i] = min(seg[i*2], seg[i*2+1]);

    while (q--) {
        int type; cin >> type;
        if (type == 1) {
            int k, u; cin >> k >> u;
            pointUpdate(k, u);
        } else {
            int ql, qr; cin >> ql >> qr;
            cout << query(1, 1, N, ql, qr) << "\n";
        }
    }
    return 0;
}
