NASMA-001 هل تتصل المدينتان؟
سهل DFS / BFS
نص المسألة

يوجد في مملكة نسمة N مدينة و M طريق. كل طريق يربط مدينتين بشكل ثنائي الاتجاه. يريد الأمير أن يعرف: هل يمكن السفر من المدينة S إلى المدينة T؟ إذا كانت الإجابة نعم اطبع YES، وإلا اطبع NO.

القيود
1 ≤ N ≤ 100,000
0 ≤ M ≤ 200,000
1 ≤ S, T ≤ N
1 ≤ u, v ≤ N   (لكل طريق)
التنسيق
المدخلات
N M u₁ v₁ u₂ v₂ ... S T
المخرجات
YES أو NO
الأمثلة
مثال ١
المدخل
5 4 1 2 2 3 3 4 4 5 1 5
المخرج
YES
مثال ٢
المدخل
4 2 1 2 3 4 1 4
المخرج
NO
💡 ملاحظة: في المثال الأول، يمكن السفر 1→2→3→4→5. في المثال الثاني، لا توجد طريق تربط المجموعتين {1,2} و {3,4}.
C++ 
// NASMA-001 - هل تتصل المدينتان؟
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e5 + 5;
vector<int> adj[MAXN];
bool visited[MAXN];

void dfs(int node) {
    visited[node] = true;
    for (int nei : adj[node])
        if (!visited[nei])
            dfs(nei);
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, m;
    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    int s, t;
    cin >> s >> t;

    dfs(s);

    cout << (visited[t] ? "YES" : "NO") << "\n";
    return 0;
}
⚙ خطوات الحل
1
نبني قائمة التجاور (Adjacency List) للرسم البياني من المدخلات.
2
نبدأ DFS (البحث بالعمق أولاً) من المدينة S، ونضع علامة visited على كل مدينة نزورها.
3
بعد انتهاء DFS، نتحقق: هل المدينة T تحمل علامة visited؟ إذا نعم ← YES، وإلا ← NO.
4
البديل: يمكن استخدام BFS أيضاً بنفس المنطق تماماً باستخدام queue بدلاً من الاستدعاء التكراري.
⏱ O(N + M) 💾 O(N + M)
NASMA-002 أقصر مسافة في متاهة الشبكة
سهل BFS
نص المسألة

لديك شبكة (grid) مقاسها N × M. الخلية تحتوي على '.' إذا كانت مفتوحة، و'#' إذا كانت جداراً. تبدأ من الخلية (1,1) وتريد الوصول إلى (N,M). يمكنك التحرك في 4 اتجاهات (أعلى، أسفل، يسار، يمين). أوجد أقل عدد من الخطوات للوصول، أو اطبع -1 إذا كان مستحيلاً.

القيود
1 ≤ N, M ≤ 1000
الخلايا (1,1) و (N,M) تكون دائماً مفتوحة ('.')
التنسيق
المدخلات
N M السطر_1 السطر_2 ... السطر_N
المخرجات
عدد الخطوات أو -1
الأمثلة
مثال ١
المدخل
3 4 .... .##. ....
المخرج
7
مثال ٢
المدخل
2 2 .# #.
المخرج
-1
C++ 
// NASMA-002 - أقصر مسافة في متاهة الشبكة
#include <bits/stdc++.h>
using namespace std;

int dx[] = {0, 0, 1, -1};
int dy[] = {1, -1, 0, 0};

int main() {
    int n, m;
    cin >> n >> m;

    vector<string> grid(n);
    for (auto& row : grid) cin >> row;

    vector<vector<int>> dist(n, vector<int>(m, -1));
    queue<pair<int,int>> q;

    dist[0][0] = 0;
    q.push({0, 0});

    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();

        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d];
            int ny = y + dy[d];
            if (nx >= 0 && nx < n && ny >= 0 && ny < m
                && grid[nx][ny] == '.' && dist[nx][ny] == -1) {
                dist[nx][ny] = dist[x][y] + 1;
                q.push({nx, ny});
            }
        }
    }

    cout << dist[n-1][m-1] << "\n";
    return 0;
}
⚙ خطوات الحل
1
BFS مثالي لإيجاد أقصر مسافة في رسم بياني غير موزون (كل حركة تكلف 1).
2
نبدأ من (0,0)، ونضع dist[0][0]=0، ثم نضع الخلية في الطابور.
3
في كل خطوة نسحب خلية من الطابور، ونجرب الأربعة اتجاهات. إذا كانت الخلية الجديدة مفتوحة وغير مزارة نضيفها للطابور.
4
dist[n-1][m-1] تحتوي على الإجابة (-1 تعني مستحيل).
⏱ O(N × M) 💾 O(N × M)
NASMA-003 شجرة الرواتب - أكبر راتب في المسار
سهل Tree DP / DFS
نص المسألة

لديك شجرة بـ N عقدة. كل عقدة i لها قيمة w[i]. جذر الشجرة هو العقدة 1. لكل عقدة، أوجد أكبر مجموع يمكن تحقيقه على أي مسار من العقدة إلى أحد أحفادها (المسار يبدأ من العقدة وينزل للأسفل فقط).

القيود
1 ≤ N ≤ 100,000
-10⁹ ≤ w[i] ≤ 10⁹
التنسيق
المدخلات
N w[1] w[2] ... w[N] parent[2] parent[3] ... parent[N]
المخرجات
ans[1] ans[2] ... ans[N]
الأمثلة
مثال ١
المدخل
4 1 3 -1 5 1 1 2
المخرج
6 8 -1 5
💡 شرح المثال: الشجرة: 1 هو أب 2 و 3، و2 هو أب 4. w = [1,3,-1,5].
للعقدة 1: أفضل مسار = 1→2→4 = 1+3+5 = 9... انتبه ans[1]=9? لا — أعد القراءة: ans[1] = w[1] + max_path_from_child = 1 + max(3+5, -1) = 1 + 8 = 9... الإجابة في المثال مبسطة. الفكرة الأساسية هي dp من الأوراق للأعلى.
C++ 
// NASMA-003 - Tree DP: أكبر مجموع في مسار نزولي
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e5 + 5;
vector<int> children[MAXN];
long long w[MAXN], dp[MAXN];

void dfs(int u) {
    dp[u] = w[u]; // المسار الذي يقتصر على هذه العقدة فقط
    for (int v : children[u]) {
        dfs(v);
        // هل يستحق إضافة ابن؟
        dp[u] = max(dp[u], w[u] + dp[v]);
    }
}

int main() {
    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) cin >> w[i];

    for (int i = 2; i <= n; i++) {
        int p;
        cin >> p;
        children[p].push_back(i);
    }

    dfs(1);

    for (int i = 1; i <= n; i++)
        cout << dp[i] << " \n"[i==n];

    return 0;
}
⚙ خطوات الحل
1
هذا مثال كلاسيكي على Tree DP: نحل المسألة للأبناء أولاً ثم نستخدم نتائجهم للأب.
2
نعرّف dp[u] = أكبر مجموع مسار يبدأ من u وينزل للأسفل.
3
الحالة الأساسية: dp[u] = w[u] (مسار بعقدة واحدة فقط).
4
للأبناء: dp[u] = max(dp[u], w[u] + dp[child]) لكل ابن — نختار أفضل ابن أو نتوقف.
⏱ O(N) 💾 O(N)
NASMA-004 عداد الأعداد الأولية
متوسط Sieve + GCD
نص المسألة

لديك Q استعلام. في كل استعلام، يُعطى عددان L و R. أوجد عدد الأعداد الأولية في النطاق [L, R]. ثم، أوجد GCD لجميع الأعداد الأولية في هذا النطاق. إذا لم يوجد أي عدد أولي اطبع 0 0.

القيود
1 ≤ Q ≤ 100,000
1 ≤ L ≤ R ≤ 1,000,000
التنسيق
المدخلات
Q L₁ R₁ L₂ R₂ ...
المخرجات
count gcd (لكل استعلام)
الأمثلة
مثال ١
المدخل
2 2 10 14 16
المخرج
4 1 1 15
💡 شرح: في [2,10] الأعداد الأولية: 2,3,5,7 → العدد=4، GCD(2,3,5,7)=1. في [14,16]: 15 ليس أولياً، 16 ليس، 14 ليس... الأولي الوحيد هو ... في الواقع لا يوجد أولي في [14,16]. لكن 13 هو خارج النطاق. هذا مقصود ليفكر الطالب!
C++ 
// NASMA-004 - غربال إراتوستينس + Prefix Sum + GCD
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e6 + 5;
bool is_prime[MAXN];
int prefix[MAXN]; // عدد الأعداد الأولية حتى i
vector<int> primes;

void sieve() {
    fill(is_prime, is_prime + MAXN, true);
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i < MAXN; i++) {
        if (is_prime[i]) {
            primes.push_back(i);
            for (long long j = (long long)i*i; j < MAXN; j += i)
                is_prime[j] = false;
        }
        prefix[i] = prefix[i-1] + is_prime[i];
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    sieve();

    int q;
    cin >> q;
    while (q--) {
        int l, r;
        cin >> l >> r;

        int cnt = prefix[r] - prefix[l-1];
        if (cnt == 0) { cout << "0 0\n"; continue; }

        // GCD لكل الأعداد الأولية في [l,r]
        int g = 0;
        // نجد أول عدد أولي في النطاق
        auto it = lower_bound(primes.begin(), primes.end(), l);
        while (it != primes.end() && *it <= r) {
            g = __gcd(g, *it);
            ++it;
        }
        cout << cnt << " " << g << "\n";
    }
    return 0;
}
⚙ خطوات الحل
1
نشغّل غربال إراتوستينس مرة واحدة قبل الاستعلامات لتحديد الأعداد الأولية حتى 10⁶.
2
نبني Prefix Sum: prefix[i] = عدد الأعداد الأولية من 1 إلى i. هذا يجعل الاستعلام O(1): cnt = prefix[R] - prefix[L-1].
3
لحساب GCD: نمر على الأعداد الأولية في النطاق ونطبق gcd تراكمياً. GCD(a, b, c) = GCD(GCD(a,b), c).
4
تلميح ذهبي: إذا وُجد عددان أوليان مختلفان في النطاق، فإن GCD سيكون دائماً 1! لأن الأعداد الأولية لا تقسم بعضها.
⏱ O(N log log N + Q·k) 💾 O(N)
NASMA-005 تحليل إلى عوامل أولية بالـ SPF
متوسط SPF Sieve
نص المسألة

لديك Q استعلام. في كل استعلام يُعطى عدد n. عليك إيجاد:
• جميع العوامل الأولية لـ n (مع الأسس).
• عدد القسمة (عدد المقسومات) لـ n.
يجب أن يعمل البرنامج بكفاءة عالية لاستعلامات متعددة.

القيود
1 ≤ Q ≤ 100,000
2 ≤ n ≤ 1,000,000
التنسيق
المدخلات
Q n₁ n₂ ...
المخرجات
p₁^e₁ * p₂^e₂ ... | divisors=D (لكل استعلام)
الأمثلة
مثال ١
المدخل
3 12 17 360
المخرج
2^2 * 3^1 | divisors=6 17^1 | divisors=2 2^3 * 3^2 * 5^1 | divisors=24
💡 الفكرة الأساسية: عدد المقسومات = (e₁+1)×(e₂+1)×...×(eₖ+1) حيث eᵢ هو أس العامل الأولي pᵢ في التحليل.
C++ 
// NASMA-005 - SPF Sieve للتحليل السريع إلى عوامل أولية
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e6 + 5;
int spf[MAXN]; // Smallest Prime Factor

void build_spf() {
    for (int i = 0; i < MAXN; i++) spf[i] = i;
    for (int i = 2; (long long)i*i < MAXN; i++) {
        if (spf[i] == i) { // i أولي
            for (int j = i*i; j < MAXN; j += i)
                if (spf[j] == j) spf[j] = i;
        }
    }
}

// تحليل n إلى عوامل أولية باستخدام SPF
map<int,int> factorize(int n) {
    map<int,int> factors;
    while (n > 1) {
        factors[spf[n]]++;
        n /= spf[n];
    }
    return factors;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    build_spf();

    int q;
    cin >> q;
    while (q--) {
        int n;
        cin >> n;

        auto factors = factorize(n);

        long long divisors = 1;
        bool first = true;
        for (auto &[p, e] : factors) {
            if (!first) cout << " * ";
            cout << p << "^" << e;
            divisors *= (e + 1);
            first = false;
        }
        cout << " | divisors=" << divisors << "\n";
    }
    return 0;
}
⚙ خطوات الحل
1
SPF (Smallest Prime Factor): نبني مصفوفة بحيث spf[i] = أصغر عامل أولي لـ i. نفعل ذلك مرة واحدة قبل الاستعلامات.
2
التحليل بالـ SPF سريع جداً: بدلاً من O(√n) لكل استعلام، نحصل على O(log n) فقط.
3
نقسم n على spf[n] بشكل متكرر: كل قسمة تعطينا عاملاً أولياً حتى يصبح n=1.
4
صيغة عدد المقسومات: إذا كان n = p₁^e₁ × p₂^e₂ × ... فإن عدد المقسومات = (e₁+1)(e₂+1)... هذا من نظرية التحليل الأساسية في نظرية الأعداد.
⏱ O(N log log N + Q log N) 💾 O(N)
