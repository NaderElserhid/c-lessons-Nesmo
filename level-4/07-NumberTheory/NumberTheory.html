🔢 ما هي نظرية الأعداد؟

نظرية الأعداد هي فرع من الرياضيات يُعنى بدراسة الأعداد الصحيحة (… , -2, -1, 0, 1, 2, …). لا كسور، لا أعداد عشرية، فقط أعداد نقية كاملة. في البرمجة التنافسية، تُعدّ من أكثر المواضيع شيوعاً في أسئلة الأولمبياد.

لماذا نهتم بها؟ تظهر نظرية الأعداد في مئات المسائل التنافسية: تبسيط الكسور، جدولة المواعيد المتكررة، التشفير، وتحليل الأعداد الأولية.

⚙️ القاسم المشترك الأكبر (GCD)

GCD(12, 18) = 6

تعريف: أكبر عدد يقسم كلا العددين بدون باقٍ. قواسم 12: {1,2,3,4,6,12} وقواسم 18: {1,2,3,6,9,18} والمشترك الأكبر هو 6.

GCD(7, 13) = 1

حالة خاصة: حين يكون الناتج 1، نسمي العددين أوليّين نسبياً (Coprime). لا يشتركان في أي عامل سوى الواحد.

🐢 الطريقة الساذجة (البطيئة)

كرّر من 1 إلى min(a,b) وتحقق من كل عدد:

gcd_naive.cpp
int gcd_naive(int a, int b) {
    int result = 1;
    for (int i = 1; i <= min(a, b); i++) {
        if (a % i == 0 && b % i == 0)
            result = i;
    }
    return result;
}
// التعقيد: O(min(a,b)) — بطيء جداً للأعداد الكبيرة!

تحذير: لا تستخدم هذه الطريقة في الأولمبياد! إذا كانت a و b بالمليارات، ستنتهي مهلة البرنامج. نحتاج لشيء أذكى.

🏛️ خوارزمية إقليدس (الطريقة الذكية)

الفكرة الأساسية

اكتشف إقليدس قبل نحو 2300 سنة العلاقة التالية:

GCD(a, b) = GCD(b, a % b)

استمر في أخذ الباقي حتى يصبح صفراً، فالعدد الآخر هو الإجابة.

مثال خطوة بخطوة: GCD(48, 18)

GCD(48, 18) → 48 % 18 = 12 → GCD(18, 12) GCD(18, 12) → 18 % 12 = 6 → GCD(12, 6) GCD(12, 6) → 12 % 6 = 0 → GCD(6, 0) = 6 ✓
euclid.cpp
// الطريقة التعاودية (Recursive) — الأكثر شيوعاً
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

// الطريقة التكرارية (Iterative) — بدون تعاود
int gcd_iter(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

// مدمجة في C++17 (الأسهل!)
// #include <numeric>
// std::gcd(a, b)  أو  __gcd(a, b) للإصدارات الأقدم

التعقيد الزمني: O(log(min(a,b))) — سريع جداً! يمكنه معالجة أعداد بالمليارات في ميكروثوانٍ.

لماذا يعمل GCD(a,b) = GCD(b, a%b)؟

ليكن d = GCD(a,b)، ولتكن r = a % b، أي a = b×q + r لعدد صحيح q.

بما أن d يقسم a و b، فهو يقسم أيضاً a - b×q = r. إذن d قاسم مشترك لِـ b و r.

بالعكس، أي قاسم مشترك لِـ b و r يقسم أيضاً b×q + r = a، فهو قاسم مشترك لِـ a و b.

النتيجة: مجموعة القواسم المشتركة لِـ (a,b) هي نفسها لِـ (b,r)، وبالتالي GCD(a,b) = GCD(b,r) تماماً. هذا ما يضمن صحة الخوارزمية.

🔄 المضاعف المشترك الأصغر (LCM)

الفكرة البصرية

LCM هو أول نقطة التقاء لمضاعفات عددين. فكّر في قطارين يغادران المحطة معاً — متى يلتقيان مجدداً؟

مضاعفات 4: 4، 8، 12، 16، 20، 24… مضاعفات 6: 6، 12، 18، 24… LCM(4, 6) = 12 ← أول لقاء!
lcm.cpp
// الصيغة: LCM(a,b) = (a × b) / GCD(a,b)
int lcm(int a, int b) {
    if (a == 0 || b == 0) return 0;
    return (a / gcd(a, b)) * b; // قسّم أولاً لتجنب الفيض!
}

// مدمجة في C++17
// std::lcm(a, b)

تنبيه الفيض (Overflow)! لا تكتب a * b / gcd(a,b) — إذا كانت a وb كبيرة، يمكن أن يفيض a*b قبل القسمة. اكتب دائماً (a / gcd(a,b)) * b.

simplify_fraction.cpp
#include <iostream>
#include <numeric>
using namespace std;

int main() {
    int num = 18, den = 24;
    int common = std::gcd(num, den); // = 6
    num /= common; // 18/6 = 3
    den /= common; // 24/6 = 4
    cout << num << "/" << den; // Output: 3/4
}

📌 مثال 2: نقطة الالتقاء (مصباحان يوميضان)

مصباح A يومض كل 12 ثانية، ومصباح B كل 15 ثانية. لقد ومضا معاً الآن. متى يومضان معاً مرة أخرى؟

الحل: نبحث عن أصغر وقت هو مضاعف لكلا الرقمين. هذا بالضبط هو LCM(12, 15) = 60 ثانية.

blinking_lights.cpp
#include <iostream>
#include <numeric>
using namespace std;

int main() {
    int a = 12, b = 15;
    cout << "يومضان معاً بعد: " << std::lcm(a, b) << " ثانية";
    // Output: يومضان معاً بعد: 60 ثانية
}

🎯 تلميح متقدم: GCD لأكثر من عددين. يمكن تطبيق GCD على مصفوفة كاملة! الخاصية: GCD(a, b, c) = GCD(GCD(a, b), c)

gcd_array.cpp
// GCD لمصفوفة كاملة
int arr[] = {12, 18, 24, 36};
int result = arr[0];
for (int x : arr)
    result = gcd(result, x);
// result = 6
إضافة احترافية: خوارزمية إقليدس الممتدة (Extended Euclidean Algorithm)

الخوارزمية العادية تعطينا فقط قيمة GCD. لكن أحياناً نحتاج أيضاً معرفة عددين صحيحين x و y يحققان:

a × x + b × y = GCD(a, b)

هذه تُعرف بـ مطابقة بيزو (Bézout's Identity)، وتضمن دائماً وجود حل صحيح x, y مهما كانت قيم a و b.

extended_gcd.cpp
int extended_gcd(int a, int b, int &x, int &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    int x1, y1;
    int g = extended_gcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

لماذا هذا مهم للمتسابقين؟ هذه الخوارزمية هي الأساس لحساب المعكوس الضربي (Modular Inverse) — أداة أساسية للقسمة تحت باقي القسمة (modulo)، وهي مفهوم ستقابله كثيراً في مسائل أصعب لاحقاً. كما تُستخدم لحل المعادلات الديوفانتية الخطية a×x + b×y = c، والتي لها حل صحيح فقط إذا كان c قابلاً للقسمة على GCD(a,b).
