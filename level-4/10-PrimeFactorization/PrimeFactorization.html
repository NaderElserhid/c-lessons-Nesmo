🔑 ما هو التحليل إلى عوامل أولية؟

التحليل إلى عوامل أولية هو عملية تفكيك عدد صحيح إلى ضرب مجموعة من الأعداد الأولية. الأعداد الأولية هي البنى التحتية لجميع الأعداد الصحيحة، تماماً كما أن الذرات هي البنى التحتية للمادة.

المبرهنة الأساسية في الحساب

كل عدد صحيح أكبر من 1 يمتلك تحليلاً وحيداً وفريداً إلى عوامل أولية (باستثناء ترتيب العوامل).

360 = 2³ × 3² × 5¹

العدد 1 لا يُعدّ أولياً. أما العدد الأولي فهو عدد لا يقسمه سوى 1 ونفسه. إذا كان العدد n نفسه أولياً، فتحليله هو هو مباشرةً.

1

القسمة التجريبية

🧩 الفكرة العامة

هذه الطريقة مثالية حين نريد تحليل عدد واحد كبير (حتى 10¹²). تعتمد على قسمة العدد n على كل عدد صحيح i بدءاً من 2، مع تكرار القسمة طالما أن i يقسم n بلا باقٍ.

لماذا نتوقف عند √n؟ إذا كان لـ n عامل أولي أكبر من √n، فبإمكانه أن يكون عاملاً واحداً فقط (لأن ضرب عاملين أكبر من √n يتجاوز n). لذا نكتفي بالتكرار حتى i² ≤ n، وإن بقي n > 1 في النهاية فهو نفسه عامل أولي.

⚙️ خطوات الخوارزمية

  1. ابدأ بـ i = 2 (أصغر عدد أولي).

  2. طالما i × i ≤ n: قسّم n على i مراراً وسجّل i كعامل في كل مرة.

  3. زِد i بمقدار 1 وكرّر.

  4. الحالة الحرجة: إذا بقي n > 1 بعد انتهاء الحلقة، فهذا يعني أن n نفسه عامل أولي. أضفه إلى قائمة العوامل.

trial_division.cpp
#include <iostream>
#include <vector>
using namespace std;

void factorize(long long n) {
    cout << "Factors of " << n << ": ";

    for (long long i = 2; i * i <= n; i++) {
        // طالما i يقسم n، فهو عامل أولي
        while (n % i == 0) {
            cout << i << " ";
            n /= i;
        }
    }

    // الحالة الحرجة: إذا بقي n > 1 فهو عامل أولي
    if (n > 1) {
        cout << n;
    }
    cout << endl;
}

int main() {
    long long n;
    cin >> n;
    factorize(n);
    return 0;
}

🔍 شرح الكود سطراً بسطر

  1. الحلقة الخارجية: for (long long i = 2; i * i <= n; i++) — نبحث عن كل عامل ابتداءً من 2 حتى √n. نستخدم i * i <= n بدلاً من i <= sqrt(n) لتجنب مشاكل الأعداد العشرية.

  2. الحلقة الداخلية: while (n % i == 0) — نستخرج كل نسخ من العامل i. مثلاً إذا كان n = 12 و i = 2، ستُسجَّل 2 مرتين وتصبح n = 3.

  3. الحالة الحرجة: if (n > 1) — بعد استنفاد جميع العوامل الصغيرة، إذا بقي n > 1، فهذا يعني أن n نفسه عامل أولي لم يُقسم على أي شيء.

التعقيد الزمني: O(√n)

تحسين SPF — أصغر عامل أولي

⚡ متى نستخدم هذه الطريقة؟

عندما نحتاج إلى تحليل مئة ألف عدد أو أكثر في وقت واحد (حيث كل عدد ≤ 10⁶)، تصبح الطريقة الأولى بطيئة جداً. الحل هو الحساب المسبق باستخدام غربال SPF.

فكرة SPF (Smallest Prime Factor): بدلاً من تخزين "هل العدد أولي؟"، نخزن أصغر عامل أولي لكل عدد. مثال: spf[10] = 2، spf[15] = 3، spf[7] = 7. ثم لتحليل أي عدد، نقفز تنازلياً بقسمته على spf[x] مراراً حتى يصبح 1.

spf_sieve.cpp
const int MAXN = 1000000;
int spf[MAXN + 1];

void sieve() {
    // خطوة التهيئة: كل عدد هو أصغر عامل أولي لنفسه في البداية
    for (int i = 1; i <= MAXN; i++) spf[i] = i;

    for (int i = 2; i * i <= MAXN; i++) {
        if (spf[i] == i) { // i أولي (لم يُعدَّل)
            for (int j = i * i; j <= MAXN; j += i) {
                // سجّل i كأصغر عامل أولي لـ j إن لم يُسجَّل بعد
                if (spf[j] == j) {
                    spf[j] = i;
                }
            }
        }
    }
}
spf_query.cpp
vector<int> getFactors(int x) {
    vector<int> ret;
    while (x != 1) {
        ret.push_back(spf[x]);  // أضف أصغر عامل أولي
        x = x / spf[x];          // اقسم وتابع
    }
    return ret;
}

🔍 شرح كود الغربال

  1. التهيئة: نملأ مصفوفة spf بحيث spf[i] = i لكل i. هذا يعني "لم أجد عاملاً أصغر بعد".

  2. الغربال: لكل عدد أولي i (حيث spf[i] == i)، نبدأ من i² ونضع spf[j] = i لكل مضاعفاته، لكن فقط إن لم يُحدَّث spf[j] من قبل. نبدأ من i² لأن الأعداد i×2، i×3، … تغطيها أعداد أولية أصغر.

  3. الاستعلام: لتحليل العدد x، نأخذ spf[x] ونضيفه، ثم نقسم x عليه، ونكرر حتى x = 1. التعقيد: O(log x) فقط!

تعقيد الحساب المسبق: O(N log log N) لكل الأعداد حتى N  |  تعقيد كل استعلام: O(log x)

📦 المسألة التطبيقية — مستودع المربع المثالي

📋 نص المسألة

مدير مستودع تلقّى شحنةً من n صندوقاً متطابقاً. يريد تكديسها على الأرض لتشكيل ترتيب مربعي (مثلاً: 2×2، 5×5). أدرك أن n قد لا يكون عدداً مربعاً كاملاً، فقرّر طلب شحنات إضافية بنفس الحجم حتى يصبح الإجمالي مربعاً كاملاً.

المطلوب: ما هو أقل عدد من الشحنات (بما فيها الأولى) يحتاجها حتى يتمكن من بناء المربع المثالي؟

💡 طريقة الحل

لكي يكون العدد n × k مربعاً كاملاً، يجب أن يكون كل أس في تحليله الأولي زوجياً. إذن:

  1. حلّل n إلى عوامل أولية.

  2. لكل عامل أولي ذي أسٍ فردي، يجب ضرب n بذلك العامل مرةً واحدة لجعل الأس زوجياً.

  3. ناتج ضرب هذه العوامل الفردية هو أصغر مضاعف k.

مثال تفصيلي: n = 45 = 3² × 5¹ → الأس الوحيد الفردي هو أس العامل 5. إذن k = 5، والمجموع = 45 × 5 = 225 = 15².

perfect_square.cpp
#include <iostream>
using namespace std;

// تجد أصغر مضاعف يجعل n مربعاً كاملاً
int findSmallestMultiplier(int n) {
    int multiplier = 1;

    // الخطوة 1: فحص قابلية القسمة على 2
    int count = 0;
    while (n % 2 == 0) { count++; n /= 2; }
    if (count % 2 != 0) multiplier *= 2; // أسٌ فردي → نحتاج 2 إضافية

    // الخطوة 2: العوامل الفردية (3، 5، 7، …)
    for (int i = 3; i * i <= n; i += 2) {
        count = 0;
        while (n % i == 0) { count++; n /= i; }
        if (count % 2 != 0) multiplier *= i;
    }

    // الخطوة 3: إذا بقي n > 2 فهو عامل أولي بأسٍ = 1 (فردي)
    if (n > 2) multiplier *= n;

    return multiplier;
}

int main() {
    int n;
    cin >> n;
    cout << findSmallestMultiplier(n) << "\n";
    return 0;
}

🔍 شرح كود المسألة

  1. نبدأ بـ multiplier = 1: هذا هو العامل التصحيحي الذي سنبنيه تدريجياً.

  2. فحص العامل 2 بشكل منفصل: لأننا نزيد i بمقدار 2 في الحلقة الرئيسية (لتخطي الأعداد الزوجية)، يجب معالجة 2 أولاً. إذا كان عدد مرات القسمة على 2 فردياً، نضرب multiplier في 2.

  3. حلقة الأعداد الفردية (i += 2): نفحص 3، 5، 7، … فقط، مما يوفر نصف الوقت تقريباً. كلما كان عدد تكرارات العامل i فردياً، أضفناه إلى multiplier.

  4. الحالة الحرجة (n > 2): إذا بقي n > 2 بعد الحلقة، فهو عامل أولي بأسٍ = 1، وهو فردي، فنضيفه إلى multiplier.

أدخل n وشاهد كيف نجد أصغر عدد شحنات يجعل المجموع مربعاً كاملاً.
