البحث في العمق — DFS

Depth-First Search | الدرس الثاني

الدرس 02
🔍
ما هو البحث في العمق؟

البحث في العمق (DFS) هو خوارزمية اجتياز على الرسوم البيانية (Graphs). تعمل بأسلوب المتاهة: تسير للأمام بأقصى عمق ممكن، فإذا وصلت إلى طريق مسدود عادت خطوة للخلف وجربت مساراً آخر.

يُستخدم DFS في العديد من المسائل مثل: إيجاد المسارات، اكتشاف الدورات، التلوين الثنائي للرسوم البيانية، وغيرها.

⏱ التعقيد الزمني: O(V + E) — حيث V = عدد الرؤوس، E = عدد الأحرف
💡
نصيحة المدرب

فكّر في DFS كشخص يستكشف متاهة: يضع يده دائماً على الجدار الأيمن ويمشي حتى يزور كل ركن.

⚙️
كيف يعمل DFS خطوة بخطوة؟
1

ابدأ عند الرأس المصدر وضع عليه علامة مُزار (visited).

2

انظر إلى جميع جيران الرأس الحالي. إذا وجدت جاراً لم يُزَر بعد، انتقل إليه وكرر العملية.

3

إذا تمت زيارة جميع الجيران، ارجع (backtrack) إلى الرأس الأب واستمر.

4

تنتهي الخوارزمية عندما تُزار جميع الرؤوس المتصلة بالمصدر.

💻
الكود الأساسي لـ DFS

الكود التالي يُنفّذ DFS باستخدام التعاود (Recursion)، وهو الأسلوب الأكثر وضوحاً:

C++ — DFS الأساسي 
const int maxN = 200001;

bool vis[maxN];                    // مصفوفة الزيارة
vector<int> adj[maxN];            // قائمة التجاور

void dfs(int u) {
    vis[u] = true;               // ضع علامة على الرأس الحالي

    for (int v : adj[u]) {
        if (!vis[v])             // إذا لم يُزَر الجار
            dfs(v);             // زُره بشكل تكراري
    }
}
⚠️
نقطة مهمة

مصفوفة vis[] ضرورية جداً — بدونها ستدخل الخوارزمية في حلقة لا نهائية إذا كان الرسم البياني يحتوي على دورات!

المسائل التطبيقية

Path Finding — إيجاد المسار

سهل

معطى رسم بياني غير موجه يتكون من N رأساً مرقمة من 1 إلى N و M حرفاً. تحقق مما إذا كان الرأس 1 يمكنه الوصول إلى الرأس N، واطبع المسار الممكن.

💡
فكرة الحل

نخزن مصفوفة p[] حيث p[v] = الرأس الذي اكتشف v. بعد انتهاء DFS نتتبع المسار عكسياً من N إلى 1.

C++ — Path Finding 
const int maxN = 200001;
int vis[maxN], p[maxN];        // vis = زيارة, p = الأب
vector<int> adj[maxN];

void dfs(int u) {
    vis[u] = true;
    for (int v : adj[u]) {
        if (!vis[v]) {
            p[v] = u;          // u أب v
            dfs(v);
        }
    }
}

int main() {
    int n, m;
    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    dfs(1);

    if (!vis[n]) cout << "No";
    else {
        cout << "Yes\n";
        vector<int> pth;
        // تتبع المسار عكسياً
        for (int i = n; i != 1; i = p[i])
            pth.push_back(i);
        reverse(pth.begin(), pth.end());
        cout << 1 << ' ';
        for (int i : pth) cout << i << ' ';
    }
}

Building Teams — تشكيل الفرق (CSES)

متوسط

يوجد N تلميذاً في الصف وM صداقة بينهم. قسّم التلاميذ إلى فريقين بحيث لا يكون أي تلميذين في نفس الفريق أصدقاء. هذا يُعرف بـ التلوين الثنائي (Bipartite Coloring).

💡
فكرة الحل

لوّن كل رأس بلون (0 أو 1). جميع جيرانه يجب أن يكون لونهم مختلفاً. إذا وجدت تناقضاً (جاران بنفس اللون)، فالتقسيم مستحيل.

🚨
تنبيه

قد يتكون الرسم البياني من مكونات منفصلة، لذا يجب تشغيل DFS على كل رأس غير مُزار في الحلقة الرئيسية.

C++ — Building Teams 
const int maxN = 200001;

bool vis[maxN], clr[maxN];
bool contradiction = false;
vector<int> adj[maxN];

void dfs(int u) {
    vis[u] = true;
    for (int v : adj[u]) {
        if (vis[v]) {
            // الجار مُزار: تحقق من عدم التناقض
            if (clr[v] == clr[u]) contradiction = true;
        } else {
            // الجار غير مُزار: لوّنه باللون العكسي
            clr[v] = !clr[u];
            dfs(v);
        }
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    // نشغل DFS على كل مكون
    for (int i = 1; i <= n; i++)
        if (!vis[i]) dfs(i);

    if (contradiction) cout << "IMPOSSIBLE";
    else
        for (int i = 1; i <= n; i++)
            cout << 1 + clr[i] << ' ';
}
