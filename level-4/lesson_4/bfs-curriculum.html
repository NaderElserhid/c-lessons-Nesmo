البحث بالعرض

Breadth-First Search — BFS

استكشف الرسوم البيانية طبقةً طبقةً، واكتشف أقصر المسارات في الرسوم غير الموزونة بكفاءة وأناقة.

📚

التعريفات الأساسية

تعريف — الرسم البياني (Graph)

هيكل بيانات يتكون من مجموعة من العقد (Vertices/Nodes) المتصلة ببعضها عبر الحواف (Edges). يُستخدم لتمثيل العلاقات بين الكيانات كالشبكات والخرائط وغيرها.

تعريف — BFS (البحث بالعرض)

خوارزمية اجتياز للرسم البياني تبدأ من عقدة مصدر وتستكشف جميع العقد المجاورة أولاً قبل الانتقال إلى العقد الأبعد. تعمل بمبدأ "الطبقة تلو الطبقة" وتضمن العثور على أقصر مسار في الرسوم غير الموزونة.

تعريف — الطابور (Queue)

هيكل بيانات يعمل بمبدأ FIFO (أول داخل أول خارج). تُدخل العناصر من الخلف وتُسحب من الأمام. هو العنصر الجوهري الذي تعتمد عليه BFS لضمان ترتيب المعالجة الصحيح.

تعريف — قائمة المجاورة (Adjacency List)

طريقة لتخزين الرسم البياني حيث لكل عقدة قائمة بجيرانها المباشرين. تُستخدم في أغلب تطبيقات BFS لكفاءتها في الذاكرة والوقت.

💡

الفكرة الجوهرية

"زر كل شيء يبعد خطوةً واحدة، ثم خطوتين، ثم ثلاث خطوات…"

BFS تعمل على مبدأ استكشاف الرسم البياني على شكل دوائر متسعة حول نقطة البداية. تماماً كما ينتشر الموج في الماء عند إلقاء حجر — يصل للقريب أولاً، ثم يتسع تدريجياً للأبعد.

متى تستخدم BFS؟

المسألة لماذا BFS؟ الضمان
أقصر مسار في رسم غير موزون تستكشف الطبقات بالترتيب O(V + E)

⚙️

خطوات الخوارزمية

1

تهيئة المسافات

اضبط dist[v] = -1 لجميع العقد (يعني "لم تُزر بعد")، ثم اضبط dist[start] = 0 لعقدة البداية.

2

أدخل عقدة البداية في الطابور

أضف عقدة البداية إلى الطابور q.push(start) — هذا هو بذرة الاستكشاف.

3

اسحب عقدة من الطابور

خذ العقدة الأمامية من الطابور v = q.front(); q.pop(); وابدأ معالجة جيرانها.

4

استكشف كل الجيران

لكل جار to غير مُزار، اضبط dist[to] = dist[v] + 1 ثم أدخله للطابور.

5

كرر حتى يفرغ الطابور

استمر في الخطوات 3 و4 حتى q.empty(). عند الانتهاء، dist[v] يحتوي أقصر مسافة من البداية لكل عقدة.

💻

التنفيذ الأساسي — BFS من مصدر واحد

نفترض أن الرسم البياني مخزن في قائمة مجاورة g[] وعدد العقد n:

C++ — BFS Basic
// إعلان قائمة المجاورة
int n;
vector<int> g[n];

// BFS من مصدر واحد
vector<int> dist(n, -1);   // -1 تعني "لم تُزر"
queue<int> q;

int s = 0;               // عقدة البداية
dist[s] = 0;
q.push(s);

while (!q.empty()) {
    int v = q.front();
    q.pop();

    for (int to : g[v]) {
        if (dist[to] != -1) continue;  // تجاوز المُزارة
        dist[to] = dist[v] + 1;
        q.push(to);
    }
}
شرح تفاعلي سطر بسطر
1
تهيئة المسافات: vector<int> dist(n, -1) — ننشئ مصفوفة بحجم n ونملؤها بـ -1، وهو "رمز" لعدم الزيارة. أي عقدة قيمتها -1 تعني أن BFS لم تصل إليها بعد.
2
بداية BFS: dist[s] = 0 و q.push(s) — نضبط مسافة عقدة البداية على صفر (لأنها المصدر نفسه) ونضعها في الطابور لتكون أول ما يُعالج.
3
حلقة البحث الرئيسية: while (!q.empty()) — نستمر في المعالجة طالما الطابور فيه عقد. عند فراغه، وصلنا لجميع العقد القابلة للوصول.
4
سحب العقدة الحالية: q.front() ثم q.pop() — نأخذ العقدة الأمامية في الطابور (الأقدم دخولاً) ونحذفها. هذا هو قلب مبدأ FIFO الذي يضمن استكشاف الطبقات بالترتيب.
5
تجاوز المُزارة: if (dist[to] != -1) continue — إذا كان الجار قد زُر مسبقاً (مسافته ليست -1)، نتجاوزه. هذا يمنع الدورات اللانهائية ويضمن أننا نسجل أقصر مسافة فقط.
6
تحديث المسافة وإدخال الجار: dist[to] = dist[v] + 1 — مسافة الجار = مسافة العقدة الحالية زائد 1 (خطوة واحدة إضافية). ثم q.push(to) لمعالجة جيرانه لاحقاً.
نتيجة التشغيل

بعد انتهاء الكود: dist[v] = 0 لعقدة البداية | dist[v] = k للعقد التي تبعد k حرفاً | dist[v] = -1 للعقد غير القابلة للوصول من s

🔍

استخراج المسار الفعلي (Parent Array)

المسافة وحدها لا تكفي أحياناً — نحتاج مسار العقد بالترتيب من s إلى t. الحل: نخزن المصدر (parent) لكل عقدة عند اكتشافها.

C++ — BFS + Path Reconstruction
vector<int> dist(n, -1), parent(n, -1);
queue<int> q;

int s = 0;
dist[s] = 0;
q.push(s);

while (!q.empty()) {
    int v = q.front();
    q.pop();
    for (int to : g[v]) {
        if (dist[to] != -1) continue;
        dist[to] = dist[v] + 1;
        parent[to] = v;   // خزن من أين وصلنا
        q.push(to);
    }
}

// إعادة بناء المسار من s إلى t
vector<int> path;
int t = 7;
if (dist[t] != -1) {
    for (int v = t; v != -1; v = parent[v])
        path.push_back(v);
    reverse(path.begin(), path.end());
}
شرح تفاعلي
1
مصفوفة parent: parent[to] = v — في كل مرة نكتشف عقدة جديدة، نخزن من أي عقدة وصلنا إليها. في البداية كل القيم -1 (لا مصدر).
2
التتبع العكسي: for (int v = t; v != -1; v = parent[v]) — نبدأ من الهدف t ونتبع سلسلة الآباء للوراء حتى نصل للمصدر (حيث parent[s] = -1).
3
عكس المسار: reverse(...) — بما أن التتبع يسير من الهدف للمصدر، نعكس المتجه في النهاية ليكون بالترتيب الصحيح من s إلى t.
4
التحقق من إمكانية الوصول: if (dist[t] != -1) — قبل بناء المسار، نتحقق أن t قابل للوصول من s. إذا كانت dist[t] == -1 فلا يوجد مسار.

لماذا تضمن BFS أقصر المسارات؟

البرهان الحدسي يعتمد على خاصية الطابور:

البرهان

الطابور في BFS يحتوي في أي لحظة على عقد من طبقتين متتاليتين على الأكثر. عقد المسافة k تُعالج كلها قبل أي عقدة بمسافة k+1. لذا، أول مرة تصل BFS لعقدة ما، تكون قادمة عبر أقصر طريق ممكن — لأنه لو وُجد طريق أقصر لكانت BFS قد سلكته بالفعل قبل هذه اللحظة.

سهل

المستوى الأول

س١

ما هيكل البيانات الذي تستخدمه خوارزمية BFS؟ ولماذا هو ضروري لصحة الخوارزمية؟

تعريفqueue
+

تستخدم BFS الطابور (Queue) الذي يعمل بمبدأ FIFO (أول داخل أول خارج).

الطابور ضروري لأنه يضمن معالجة العقد بنفس ترتيب اكتشافها. هذا يعني أن جميع عقد المسافة k تُعالج قبل أي عقدة بمسافة k+1، وهو ما يضمن الحصول على أقصر المسارات. لو استخدمنا مكدساً (Stack) بدلاً منه لأصبحنا نجري DFS وليس BFS.

س٢

ماذا يعني dist[v] = -1 في تنفيذ BFS؟

تعريفdist[]
+

القيمة -1 في مصفوفة dist تعني أن العقدة v لم تُزر بعد من قبل BFS.

نستخدم -1 كعلامة لأن المسافات الحقيقية دائماً أعداد صحيحة موجبة أو صفر. في نهاية تشغيل BFS، أي عقدة لا تزال قيمتها -1 تعني أنه لا يوجد مسار من عقدة البداية إليها (غير قابلة للوصول).

س٣

في رسم بياني غير موزون، هل تضمن BFS إيجاد أقصر مسار؟ وضح الإجابة.

مفهومأقصر مسار
+

نعم، BFS تضمن إيجاد أقصر مسار في الرسوم البيانية غير الموزونة (حيث تكلفة كل حرف = 1).

السبب: BFS تستكشف العقد بترتيب مسافة متزايد من المصدر. فأول مرة تصل لعقدة ما، تكون عبر أقصر طريق ممكن. لو وُجد طريق أقصر، لكانت BFS قد سلكته مسبقاً لأن الطابور يضمن معالجة الأقرب دائماً أولاً.

ملاحظة: في الرسوم الموزونة (أوزان مختلفة) نستخدم Dijkstra بدلاً من BFS.

س٤

ما الفرق الجوهري بين BFS وDFS من حيث ترتيب الاستكشاف؟

مقارنةBFS vs DFS
+

BFS تستكشف عرضياً: تزور جميع جيران العقدة الحالية قبل الانتقال لأبعد منها. تعمل طبقةً طبقة وتستخدم طابوراً.

DFS تستكشف عمقياً: تتبع فرعاً واحداً حتى نهايته قبل العودة لاستكشاف فروع أخرى. تستخدم مكدساً أو الاستدعاء التكراري.

النتيجة: BFS تجد أقصر مسار، بينما DFS لا تضمن ذلك لكنها أفضل في كشف الدورات والفرز الطوبولوجي.

س٥

ما التعقيد الزمني لخوارزمية BFS؟ وما المقصود بـ V وE في هذا السياق؟

تعقيد زمنيO(V+E)
+

التعقيد الزمني لـ BFS هو O(V + E).

V (Vertices) = عدد العقد في الرسم البياني. كل عقدة تُدخل الطابور وتُسحب منه مرة واحدة بالضبط.

E (Edges) = عدد الحواف. كل حرف يُفحص مرة أو مرتين (في الرسوم غير الموجهة).

هذا التعقيد ممتاز — خطي في حجم المدخلات — مما يجعل BFS من أكفأ خوارزميات الرسوم البيانية.

متوسط

المستوى الثاني

س٦

اكتب كود C++ يستخدم BFS لإيجاد عدد العقد التي تبعد بالضبط مسافة k من عقدة المصدر.

تطبيقكود
+

بعد تشغيل BFS وحساب المسافات، نمر على جميع العقد ونحسب تلك التي dist[v] == k:

C++
// بعد تشغيل BFS وحساب dist[]
int countAtDistance(vector<int>& dist, int k) {
    int count = 0;
    for (int v = 0; v < (int)dist.size(); v++) {
        if (dist[v] == k)
            count++;
    }
    return count;
}

الفكرة بسيطة: مصفوفة dist[] تخزن المسافة الدقيقة لكل عقدة من المصدر، فنكتفي بعد العقد ذات المسافة k.

س٧

كيف تستخدم BFS للتحقق مما إذا كان الرسم البياني غير الموجه متصلاً (Connected Graph)؟

اتصالتطبيق
+

الفكرة: نشغّل BFS مرة واحدة من أي عقدة. إذا كانت جميع العقد قد زُيرت (لا توجد قيمة -1 في dist[])، فالرسم البياني متصل.

C++
bool isConnected(int n, vector<int> g[]) {
    vector<int> dist(n, -1);
    queue<int> q;
    dist[0] = 0;
    q.push(0);
    while (!q.empty()) {
        int v = q.front(); q.pop();
        for (int to : g[v]) {
            if (dist[to] == -1) {
                dist[to] = dist[v] + 1;
                q.push(to);
            }
        }
    }
    for (int i = 0; i < n; i++)
        if (dist[i] == -1) return false;
    return true;
}
س٨

لديك شبكة مدن وطرق. كيف تُمثّل المسألة كرسم بياني وتستخدم BFS لإيجاد أقل عدد طرق بين مدينتين؟

نمذجةتطبيق واقعي
+

خطوات النمذجة:

١. كل مدينة = عقدة في الرسم البياني (ارقمها من 0 إلى n-1).

٢. كل طريق بين مدينتين = حرف في الرسم البياني (غير موزون لأن جميع الطرق بتكلفة 1).

٣. شغّل BFS من مدينة المصدر. قيمة dist[target] بعد الانتهاء = أقل عدد طرق للوصول للهدف.

٤. إذا dist[target] == -1 فلا يوجد طريق بينهما.

هذا النموذج يُستخدم في GPS والشبكات الاجتماعية (درجات الفصل) وتوجيه الحزم في الشبكات.

س٩

ما الذي يحدث لو نسينا شرط التحقق if (dist[to] != -1) continue في كود BFS؟

أخطاء شائعةتحليل
+

بدون هذا الشرط ستحدث مشكلتان خطيرتان:

١. دورات لانهائية: في الرسوم التي تحتوي دورات، ستعود BFS لزيارة العقد مراراً وتكراراً — الطابور لن يفرغ أبداً وسينفذ البرنامج بلا توقف.

٢. مسافات خاطئة: حتى لو توقف البرنامج، ستُستبدل المسافات الصحيحة بقيم أكبر منها لأن العقد تُعاد زيارتها عبر مسارات أطول.

هذا الشرط هو ضمان الزيارة الواحدة — قلب صحة خوارزمية BFS.

س١٠

في مسألة المتاهة (Maze)، كيف تُطبّق BFS للعثور على أقصر مسار من نقطة البداية لنقطة الخروج؟

متاهةشبكة 2D
+

المتاهة تُمثَّل كشبكة ثنائية الأبعاد. كل خلية (r, c) هي عقدة، وجيرانها الأربعة (أعلى/أسفل/يسار/يمين) هي الحواف.

C++ — BFS on 2D Grid
int dx[] = {0, 0, 1, -1};
int dy[] = {1, -1, 0, 0};

queue<pair<int,int>> q;
dist[sr][sc] = 0;
q.push({sr, sc});

while (!q.empty()) {
    auto [r, c] = q.front(); q.pop();
    for (int d = 0; d < 4; d++) {
        int nr = r + dx[d];
        int nc = c + dy[d];
        if (valid(nr,nc) && dist[nr][nc] == -1
            && !wall[nr][nc]) {
            dist[nr][nc] = dist[r][c] + 1;
            q.push({nr, nc});
        }
    }
}

الإجابة = dist[er][ec] حيث (er, ec) هي نقطة الخروج.

صعب

المستوى الثالث

س١١

اشرح كيف تُطبّق BFS ثنائية المصدر (0-1 BFS) وما الفرق بينها وبين BFS التقليدية؟

0-1 BFSdequeمتقدم
+

0-1 BFS تُستخدم عندما تكون أوزان الحواف إما 0 أو 1 فقط (وليس أرقاماً عشوائية).

الفرق: بدلاً من queue عادية، نستخدم deque (طابور من طرفين):

C++ — 0-1 BFS
deque<int> dq;
dist[s] = 0;
dq.push_back(s);

while (!dq.empty()) {
    int v = dq.front(); dq.pop_front();
    for (auto [to, w] : g[v]) {  // w = 0 أو 1
        if (dist[v] + w < dist[to]) {
            dist[to] = dist[v] + w;
            if (w == 0)
                dq.push_front(to);  // حواف بوزن 0 تُضاف للأمام
            else
                dq.push_back(to);   // حواف بوزن 1 تُضاف للخلف
        }
    }
}

الحواف بوزن 0 تُضاف لمقدمة الطابور (لأنها لا تزيد المسافة)، بينما الحواف بوزن 1 تُضاف للخلف. هذا يحقق كفاءة O(V + E) بدلاً من O((V+E) log V) في Dijkstra.

س١٢

كيف تستخدم Multi-Source BFS (BFS متعددة المصادر) لحساب أقرب خلية ملوّنة لكل خلية في شبكة؟

multi-sourceشبكة 2Dمتقدم
+

Multi-Source BFS تبدأ من عدة مصادر في آنٍ واحد بدلاً من مصدر واحد فقط.

الحيلة: نُدخل جميع المصادر في الطابور معاً في البداية بمسافة 0:

C++ — Multi-Source BFS
queue<pair<int,int>> q;

// أدخل جميع الخلايا الملوّنة معاً
for (int r = 0; r < R; r++)
    for (int c = 0; c < C; c++)
        if (isColored(r, c)) {
            dist[r][c] = 0;
            q.push({r, c});
        }

// BFS اعتيادية من هنا
while (!q.empty()) {
    auto [r, c] = q.front(); q.pop();
    for (int d = 0; d < 4; d++) {
        int nr = r+dx[d], nc = c+dy[d];
        if (valid(nr,nc) && dist[nr][nc] == -1) {
            dist[nr][nc] = dist[r][c] + 1;
            q.push({nr, nc});
        }
    }
}

النتيجة: dist[r][c] = المسافة لأقرب خلية ملوّنة لكل خلية في الشبكة — بتعقيد O(R × C).

س١٣

في مسألة تبديل الكلمات (Word Ladder)، كيف تُنمذج المسألة كرسم بياني وتحلها باستخدام BFS؟

Word Ladderنمذجة متقدمة
+

المسألة: حوّل الكلمة A إلى الكلمة B بتغيير حرف واحد في كل خطوة، وكل كلمة وسيطة يجب أن تكون في قاموس معطى. أوجد أقل عدد خطوات.

النمذجة:

١. كل كلمة = عقدة.

٢. حرف بين كلمتين إذا اختلفتا بحرف واحد فقط.

٣. شغّل BFS من الكلمة المصدر — أول وصول للكلمة الهدف = أقل عدد تحويلات.

C++ — Word Ladder
bool diffByOne(string& a, string& b) {
    int diff = 0;
    for (int i = 0; i < a.size(); i++)
        if (a[i] != b[i]) diff++;
    return diff == 1;
}

// BFS على قاموس الكلمات
map<string, int> dist;
queue<string> q;
dist[start] = 0;
q.push(start);

while (!q.empty()) {
    string cur = q.front(); q.pop();
    for (string& word : dict) {
        if (!dist.count(word) && diffByOne(cur, word)) {
            dist[word] = dist[cur] + 1;
            q.push(word);
        }
    }
}
س١٤

كيف تُحسب عدد أقصر المسارات (وليس فقط طولها) بين عقدتين باستخدام BFS؟

عد المساراتcount[]متقدم
+

نضيف مصفوفة cnt[] لحساب عدد المسارات الأقصر لكل عقدة:

C++ — Count Shortest Paths
vector<int> dist(n, -1);
vector<long long> cnt(n, 0);
queue<int> q;

dist[s] = 0;
cnt[s] = 1;  // مسار واحد للمصدر (المسار الفارغ)
q.push(s);

while (!q.empty()) {
    int v = q.front(); q.pop();
    for (int to : g[v]) {
        if (dist[to] == -1) {
            dist[to] = dist[v] + 1;
            cnt[to] = cnt[v];  // ورث عدد المسارات
            q.push(to);
        } else if (dist[to] == dist[v] + 1) {
            cnt[to] += cnt[v];  // مسار آخر بنفس الطول
        }
    }
}

القيمة cnt[t] = عدد أقصر المسارات من s إلى t. المفتاح هو الحالة الثانية else if: عندما نجد عقدة تبعد نفس المسافة من مسار مختلف، نجمع الأعداد.

س١٥

في رسم بياني ثنائي التقسيم (Bipartite Graph)، كيف تستخدم BFS للتحقق من الخاصية وتلوين العقد؟

Bipartiteتلوينمتقدم
+

الرسم البياني ثنائي التقسيم هو رسم يمكن تقسيم عقده لمجموعتين بحيث لا توجد حواف بين عقد نفس المجموعة. يمكن التحقق من ذلك بتلوين العقد بلونين متناوبين باستخدام BFS:

C++ — Bipartite Check via BFS
vector<int> color(n, -1);

bool isBipartite() {
    for (int start = 0; start < n; start++) {
        if (color[start] != -1) continue;
        queue<int> q;
        color[start] = 0;
        q.push(start);

        while (!q.empty()) {
            int v = q.front(); q.pop();
            for (int to : g[v]) {
                if (color[to] == -1) {
                    color[to] = 1 - color[v]; // تبادل اللون
                    q.push(to);
                } else if (color[to] == color[v]) {
                    return false; // تعارض → ليس bipartite
                }
            }
        }
    }
    return true;
}

الحيلة: 1 - color[v] تعطي اللون المعاكس (0→1، 1→0). إذا وجدنا حرفاً بين عقدتين بنفس اللون، فالرسم ليس ثنائي التقسيم.
