Beautiful Year

This explanation is provided by the TweetKod platform

Problem Description

You need to find the smallest year that is strictly greater than the given year, on the condition that all the digits of that year are different, with no repeats.

Steps to the Solution

1
Initial increment: we start searching from the year right after the given year (year + 1).
2
Checking loop: we use a while loop to check each year, breaking it down into its four digits.
3
Success condition: if we don't find any two matching digits, we exit the loop and print the beautiful year.

Interactive Search Lab

Enter the current year to search after it:

beautiful_year.cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;

    // 1. Start right from the following year
    year += 1;

    // 2. Loop that continues while the year's digits aren't all different
    while (true) {
        int a = year / 1000;       // thousands
        int b = (year / 100) % 10; // hundreds
        int c = (year / 10) % 10;  // tens
        int d = year % 10;         // units

        // 3. Check that there is no repeated digit
        if (a != b && a != c && a != d && b != c && b != d && c != d) {
            break; // found the year we need
        }

        // 4. Move to the next year if the check fails
        year += 1;
    }

    cout << year << '\n';
    return 0;
}
