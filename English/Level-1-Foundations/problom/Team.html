Problem Description

There are three friends who love solving programming problems. They decided they won't solve a problem unless at least two of them agree that they know how to solve it. You're given a list of problems, and you need to compute how many the team will end up solving.

View the problem on Codeforces

Steps to the Solution

1
Read the input: we find out the total number of problems we'll check.
2
The loop: we go through each problem and read the opinion of the three friends (1 means they know the solution, 0 means they don't).
3
The logical condition: we sum their opinions; if the total is 2 or more, we increase the solved-problems counter by 1.

#include <iostream>
using namespace std;

int main() {
    // 1. read the number of problems n
    int n;
    cin >> n;

    // counter for the problems that will be solved
    int ans = 0;

    // 2. loop over each problem
    for (int i = 0; i < n; i++) {
        int f1, f2, f3;
        // read the opinion of the three friends
        cin >> f1 >> f2 >> f3;

        // 3. if the sum of confident friends is 2 or more
        if (f1 + f2 + f3 >= 2) {
            ans++;
        }
    }

    // 4. print the final result
    cout << ans;

    return 0;
}
