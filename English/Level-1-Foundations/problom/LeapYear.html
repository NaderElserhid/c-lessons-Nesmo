Leap Year

This explanation is provided by the TweetKod platform

Problem Description

A leap year is defined as a year with 366 days instead of 365. The task is to write a program that reads a year and determines whether it is a leap year based on the astronomical criteria.

Programmatic Check Rules

1
The basic rule: the year must be divisible by 4 with no remainder.
2
The century exception: if it's also divisible by 100, it's not a leap year...
3
The final exception: ...unless it's also divisible by 400, in which case it becomes a leap year again!

Year Checking Lab

leap_year.cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    // 1. read the year from the user
    cin >> year;

    // 2. check the compound logical conditions
    // a year is a leap year if (divisible by 4 and not by 100) or (divisible by 400)
    if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
        cout << "YES" << endl; // leap year
    } else {
        cout << "NO" << endl;  // common year
    }

    return 0;
}
