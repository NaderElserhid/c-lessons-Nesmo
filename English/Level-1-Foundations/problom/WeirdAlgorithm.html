Weird Algorithm

This explanation is provided by the TweetKod platform

Problem Description

This algorithm starts with an integer you choose, then asks you to apply a set of repeated steps until you eventually reach the number 1:

  • If the number is even: we divide the number by 2.
  • If the number is odd: we multiply the number by 3 and then add 1.

Steps to the Solution

1
Build the loop: we use a loop that keeps running as long as the number hasn't become 1.
2
Check the number's type: we test whether the current number is divisible by 2 with no remainder.
3
Apply the rules: we perform the division for an even number, and the multiplication-and-addition for an odd number, then print the result.

Sequential Thinking Lab

Enter the number you want the algorithm to start with:

weird_algorithm.cpp 
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;

    while (true) {
        cout << n << " ";
        if (n == 1) break;

        if (n % 2 == 0) {
            n /= 2;
        } else {
            n = n * 3 + 1;
        }
    }
    return 0;
}
