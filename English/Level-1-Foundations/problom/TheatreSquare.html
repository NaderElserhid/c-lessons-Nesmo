Theatre Square

This explanation is provided by the TweetKod platform

Problem Description

The task is to cover a rectangular square with dimensions N × M using the smallest possible number of square marble tiles with side length A. Tiles are allowed to cover more area than the square, but a tile cannot be broken.

View the problem on Codeforces

Steps to the Solution

1
Covering the length (N): we compute how many tiles we need to pave the length, always rounding up.
2
Covering the width (M): we compute how many tiles we need to fully pave the width, also rounding up.
3
Computing the total: we multiply the number of length tiles by the number of width tiles.

Advanced Paving Lab (with clear dimensions)

theatre_square.cpp
#include <iostream>
using namespace std;

int main() {
    // 1. read the square's dimensions N, M and the tile side length A
    int n, m, a;
    cin >> n >> m >> a;

    // 2. compute the number of tiles in each direction (v lengthwise, h widthwise)
    // we use the smart round-up formula: (A + B - 1) / B
    long long v = (n + a - 1) / a;
    long long h = (m + a - 1) / a;

    // 3. print the total number of tiles (the product)
    cout << v * h;

    return 0;
}
