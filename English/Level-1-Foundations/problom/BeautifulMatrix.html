Beautiful Matrix

This explanation is provided by the TweetKod platform

Problem Description

You are given a 5 × 5 matrix made up of zeros and a single "1". The matrix is "beautiful" if the "1" is located exactly in the center (row 3, column 3). You need to compute the minimum number of moves to bring the "1" to the center.

View the problem on Codeforces

Thinking Through the Solution

1
Find the position: we go through every element of the matrix to find the row number (i) and column number (j) of the "1".
2
Compute the distance: the center is position (3, 3). The distance is the sum of the row difference and the column difference (absolute value).
3
Absolute value: we use a function to make sure the results are always positive, since the number of moves can't be negative.

beautiful_matrix.cpp
#include <iostream>
using namespace std;

// Function to compute the absolute value, guaranteeing a positive result
int abs_val(int v) {
    return (v > 0 ? v : -v);
}

int main() {
    int r, c;

    // 1. Find the position of the 1 in the 5x5 matrix
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= 5; j++) {
            int x;
            cin >> x;

            if (x == 1) {
                r = i; // store the row number
                c = j; // store the column number
            }
        }
    }

    // 2. Compute the distance to the center (3, 3)
    // The result is the row difference plus the column difference
    int result = abs_val(r - 3) + abs_val(c - 3);

    // 3. Print the total number of moves
    cout << result;

    return 0;
}
