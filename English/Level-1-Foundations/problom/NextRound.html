Next Round

This explanation is provided by the TweetKod platform

Problem Description

You have a group of contestants in a competition, and you need to calculate how many will qualify for the next round. The rule is: a contestant qualifies if they score equal to or higher than the score of the person in the specified qualifying position, provided their score is strictly greater than zero.

View the problem on Codeforces

Important Programming Notes

  • Excluding zero scores: a contestant never qualifies if their score is zero, even if they meet the required position condition.
  • Scores are sorted: contestants are always entered from highest score to lowest.

#include <iostream>
using namespace std;

int main() {
    // 1. read the number of contestants and the required position
    int n, k;
    cin >> n >> k;

    // 2. read the contestants' scores into an array
    int a[n], ans = 0;
    for (int i = 0; i < n; i++) cin >> a[i];

    // 3. check each contestant against two conditions:
    // - their score is greater than or equal to the score at the specified position
    // - their score is strictly greater than zero
    for (int i = 0; i < n; i++) {
        if (a[i] >= a[k - 1] && a[i] > 0) ans++;
    }

    // 4. print the final number of qualifiers
    cout << ans;

    return 0;
}
