Worked Examples — Applying the Sum and Product Rules

How Do We Use This Lesson?

In the previous lesson we learned the Sum Rule and the Product Rule. In this lesson we'll apply both rules together to seven worked problems, ranging in difficulty from Easy to Medium to Hard. Each problem has an interactive lab that animates how the possibilities are built step by step, then two separate buttons to reveal the solution steps and the final answer whenever you're ready.

verify_ex1.cpp
long long count = 0;
for(int d1 = 1; d1 <= 9; d1++)
for(int d2 = 0; d2 <= 9; d2++)
for(int d3 = 0; d3 <= 9; d3++)
    count++;
cout << count;

for(int d2 = 0; d2 <= 9; d2++) if(d2 != d1)

Medium

Exactly One Digit

A password consists of three symbols. Each symbol is either an uppercase English letter or a digit. How many passwords contain exactly one digit?

Interactive Lab: Watch the Three Separate Cases

1

We notice the single digit can fall in one of three positions: first, second, or third.

2

We count the number of passwords for each case: the position with the digit has 10 choices, and the other two positions (letters) have 26 choices each.

3

The three cases are completely separate; each password belongs to exactly one case, based on its single digit's position.

4

Since the cases don't overlap, we add them per the Sum Rule. And since each case gives the same value (10×26×26), the total is 3 × (10×26×26).

3 · 10 · 26² = 20280

verify_ex3.cpp
bool isDigit(int s) { return s < 10; } // 0-9 are digits, 10-35 are letters

long long count = 0;
for(int s1 = 0; s1 < 36; s1++)
for(int s2 = 0; s2 < 36; s2++)
for(int s3 = 0; s3 < 36; s3++) {
    int digits = isDigit(s1) + isDigit(s2) + isDigit(s3);
    if(digits == 1) count++;
}
cout << count;
20280
Medium

Different Colors for Adjacent Stripes

A flag consists of four horizontal stripes. Each stripe is red, green, or blue, and each stripe's color must differ from the color of the stripe next to it. How many different flags can be formed?

Interactive Lab: Watch the Flag Get Colored Stripe by Stripe

1

First stripe: 3 choices (any of the three colors).

2

Second stripe: only 2 choices (any color different from the first stripe's).

3

Third stripe: only 2 choices (different from the second stripe).

4

Fourth stripe: only 2 choices (different from the third stripe).

5

The choices are successive (each stripe is chosen after the one before it), so we multiply the four numbers per the Product Rule.

3 · 2 · 2 · 2 = 24

verify_ex4.cpp
long long count = 0;
for(int a = 0; a < 3; a++)
for(int b = 0; b < 3; b++) if(b != a)
for(int c = 0; c < 3; c++) if(c != b)
for(int d = 0; d < 3; d++) if(d != c)
    count++;
cout << count;

verify_ex5.cpp
long long count = 0;
for(int a = 0; a < 4; a++)
for(int b = 0; b < 4; b++)
for(int c = 0; c < 4; c++) {
    int pairs = (a==b) + (b==c) + (a==c);
    if(pairs == 1) count++;  // exactly one matching pair
}
cout << count;
36

A PIN With Conditions

A PIN consists of four digits, and contains exactly one zero and exactly one other even digit, with no digit repeated. How many PINs satisfy these conditions?

Interactive Lab: Follow the PIN Being Built Step by Step

Position 4
1

We choose the zero's position among the four positions: 4 choices.

2

We choose the value of the other even digit from the set {2,4,6,8}: 4 choices.

3

We choose its position among the three remaining positions: 3 choices.

4

We fill the first remaining odd position with an odd digit from {1,3,5,7,9}: 5 choices.

5

We fill the last odd position with an odd digit different from the previous one: 4 choices.

6

All the choices are successive (each step depends on what came before it), so we multiply them all together.

4 · 4 · 3 · 5 · 4 = 960

verify_ex6.cpp
long long count = 0;
for(int d1 = 0; d1 <= 9; d1++)
for(int d2 = 0; d2 <= 9; d2++) if(d2 != d1)
for(int d3 = 0; d3 <= 9; d3++) if(d3 != d1 && d3 != d2)
for(int d4 = 0; d4 <= 9; d4++) if(d4 != d1 && d4 != d2 && d4 != d3) {
    int digs[4] = {d1, d2, d3, d4};
    int zeroCount = 0, evenNonZeroCount = 0;
    for(int x : digs) {
        if(x == 0) zeroCount++;
        else if(x % 2 == 0) evenNonZeroCount++;
    }
    if(zeroCount == 1 && evenNonZeroCount == 1) count++;
}
cout << count;
960
Hard

Circular Coloring

There are four numbered seats around a circular table. Each seat is colored red, green, or blue, and each seat's color must differ from the colors of the two seats next to it. How many valid colorings exist?

Interactive Lab: Try Coloring the Seats Yourself

2
1
3
4

Click on any seat to change its color, and try to find a valid coloring yourself!

Color all four seats to start checking...
1

We choose the color of the first seat: 3 choices.

2

We choose the color of the second seat so it differs from the first: 2 choices.

3

We look at the third seat by splitting into cases: if its color matches the first, it has 1 choice, and the fourth then has 2 choices. If it differs from both the first and second, it has 1 choice, and the fourth's color becomes fixed (1 choice).

4

We add the results of the two cases: 1×2 + 1×1 = 3 ways to color the third and fourth seats.

5

We multiply that by the number of ways to choose the first and second seats: 3 × 2 × 3 = 18.

1·2 + 1·1 = 3

3 · 2 · 3 = 18

verify_ex7.cpp
long long count = 0;
for(int s1 = 0; s1 < 3; s1++)
for(int s2 = 0; s2 < 3; s2++) if(s2 != s1)
for(int s3 = 0; s3 < 3; s3++) if(s3 != s2)
for(int s4 = 0; s4 < 3; s4++) if(s4 != s3 && s4 != s1)  // s4 is adjacent to s3 and also to s1 (circular)
    count++;
cout << count;
18

Notice the shared technique across the harder problems: when we can't write a direct product formula, we split the problem into separate cases (casework), compute the number of ways within each case by multiplying, then add the cases' results. This is exactly the Sum and Product Rules combined.

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

CaseworkSplit into cases

A method for solving counting problems by splitting them into separate cases, then adding each case's result.

Brute forceTry everything

Actually trying every possibility through code to verify a mathematical formula.

ConstraintA restriction

A condition that limits the allowed choices, like forbidding repeated digits.

AdjacentRight next to

Two elements immediately next to each other, like two neighboring stripes on a flag or two neighboring seats around a table.
