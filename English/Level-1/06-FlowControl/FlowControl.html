The Simple Statement

A simple statement in C++ is one of the individual instructions in a program — like defining a variable or an arithmetic expression. Every simple statement ends with a semicolon ;, and statements execute in the order they appear in the code, from top to bottom.

simple_statements.cpp 
int x = 5;
x = x + 2;
cout << x;

Output:

7

Extra example — the same idea in a different context (tracking a player's score):

score_example.cpp
int score = 0;
score = score + 10;
cout << "Score: " << score;

Output:

Score: 10

In both examples, each line is a simple statement ending with ;, executed in sequence from top to bottom with no branching or repetition.

Beyond Linear Execution

Programs aren't limited to a plain linear sequence of instructions. In fact, a program might:

1

Repeat a certain part of the code

Using loops to execute the same instructions multiple times without rewriting them.

2

Make decisions to follow a different path

Using conditionals to execute a specific part of the code only when a certain condition is met.

To make this possible, C++ provides flow control statements — tools that tell the program: what to do, when to do it, and under what conditions. We'll get to know each of these tools in detail in upcoming lessons:

Conditional branching — executing a part of the code only if a certain condition holds.

Compound Statements

A compound statement is a group of instructions enclosed in curly braces { }, and this group is treated as a single block. A compound statement looks like this:

compound_syntax.cpp
{
    statement1;
    statement2;
    statement3;
}

Each instruction inside the block ends with its own semicolon, while the whole block is considered a single statement in the context of flow control — and this is exactly what later allows several instructions to be placed inside a single if or while body.

Another real-world example:

compound_example.cpp
{
    int temp = 5;
    temp = temp * 2;
    cout << temp;
}

This entire block (with its three instructions) will later become — for example — the body of a single if statement, executed entirely together or not at all depending on whether the condition holds.

Try the idea visually yourself — watch how 3 separate statements turn into a single block:

{ One Block }
int temp = 5;
temp = temp * 2;
cout << temp;
Currently: 3 separate statements, each evaluated on its own.

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

StatementA single instruction

A single instruction in a program, like defining a variable or printing a value.

ExpressionProduces a value

A combination of values and operators that produces a single value, like x + 2.

Sequential executionTop-to-bottom order

Executing instructions in the order they were written, from top to bottom.

Flow controlChanges the execution path

Tools that change a program's execution path through repetition or conditions instead of just linear sequence.

ConditionalRuns only if true

An instruction that runs only if a certain condition holds, like if.

LoopRepeats instructions

A tool that repeats a set of instructions multiple times, like while and for.

Compound statementGrouped into one block

A group of instructions enclosed in { } treated as a single block.

BlockAnother word for compound statement

Another name for a compound statement; a unit that groups instructions between curly braces.
