Why Do We Need vector?

In C++, arrays have a fixed size, meaning the number of elements they hold cannot be changed after they're created. This can be a problem if we don't know in advance how many elements we'll need. To solve this problem, C++ provides the std::vector object.

A vector works exactly like an array, but it can grow or shrink as elements are added or removed while the program runs.

Think of an array as a fixed-size box that never changes, while a vector is more like a stretchy bag that can expand to hold new items or shrink when items are taken out of it.

Why Is vector So Important in Competitive Programming?

vector is probably the most-used data container in competitive programming. The reason is simple: in most problems you don't know the size of the data in advance — it's given to you at runtime (usually as the first value read in). A regular array forces you to guess a fixed maximum size in advance (and sometimes reserve a very large size "just in case"), while vector solves this problem completely.

Key uses of vector in competitions:

Use caseWhy vector is ideal here
Reading an unknown number of inputsWe read elements one by one with push_back without needing to know the total count in advance.
Representing a grid or 2D arrayvector<vector<int>> is widely used to represent grids and adjacency lists in graphs.
Passing collections of data between functionsAn entire vector can easily be passed to another function, unlike arrays, which lose their size information when passed.
Building results dynamically while solvingLike collecting numbers that satisfy a certain condition, without knowing their final count in advance.

In almost every competitive programming contest (Codeforces, AtCoder, informatics olympiads) you'll see vector used in nearly the very first solution. Mastering it is an essential fundamental.

Declaring a vector

vector is part of a library called <vector> and is declared as follows:

declare.cpp
#include <vector>
using namespace std;
vector<type> name;
ElementExplanation
nameThe vector's name.
typeThe type of data stored in the vector. It can be any valid C++ type (int, double, string, etc.).

After declaring a vector this way, it's completely empty (like an array of size 0). To give a vector an initial size, we use the following syntax:

declare_with_size.cpp
#include <vector>
using namespace std;
vector<type> name(size, value);
ElementExplanation
sizeThe number of elements in the vector.
valueThe initial value given to every element of the vector.

Operations on a vector

A vector behaves similarly to arrays, but has important additional functions. Suppose we've declared a vector named v:

vector_v.cpp
#include <vector>
using namespace std;
vector<int> v;

Since v's size can change, we use v.size() to get the number of elements in v. The two main functions that make vector special are v.push_back(x), which adds the value x to the end of the vector, and v.pop_back(), which removes its last element.

FunctionDescription
v.size()Returns the current number of elements in the vector.
v.push_back(x)Adds the element x to the end of the vector.
v.pop_back()Removes the last element from the vector.
v.resize(n)Changes the vector's number of elements to n. If n is larger than the current size, new elements (with value 0) are added; if smaller, the extra elements are removed from the end.
v.clear()Removes all elements from the vector.
v.empty()Returns true (printed as 1) if the vector is empty, and false (printed as 0) otherwise.
v.front()Returns the value of the first element in the vector.
v.back()Returns the value of the last element in the vector.
v.at(i)Returns the element at index i, exactly like v[i], but first checks that i is within valid bounds.
v.capacity()Returns the capacity actually reserved in memory (details in the next section).

An example showing front(), back(), at(), and empty() together:

vector_extra_functions.cpp
vector<int> v = {10, 20, 30};
cout << v.front() << endl;   // first element
cout << v.back() << endl;    // last element
cout << v.at(1) << endl;     // the element at index 1
cout << v.empty() << endl;   // 0 because v is not empty

vector<int> empty_v;
cout << empty_v.empty() << endl; // 1 because it's empty

30
20
0
1

The important difference between v[i] and v.at(i): if i is out of valid bounds, v[i] leads to undefined behavior that may not show up as an error immediately, while v.at(i) stops the program right away with a clear error. In competitive programming we usually use v[i] because it's faster, but v.at(i) is very useful while debugging.

How Does vector Work Internally? (Size vs Capacity)

Behind the scenes, a vector is really just a regular array stored in memory, but it keeps track of two different numbers: size(), the actual number of elements we've placed in it, and capacity(), the amount of memory actually reserved (which is usually larger than size()).

When you use push_back and there's remaining space within the current capacity, the new value is added directly and very quickly. But when the vector becomes completely full (size() == capacity()), it automatically does the following:

  1. Reserves a new, larger block of memory (usually double the old capacity).
  2. Copies all the old elements into the new memory.
  3. Frees the old memory.

This is what makes repeated push_back operations very fast on average (called Amortized O(1)), even though the reallocation itself happens relatively rarely as the vector grows. Notice in the following example how the capacity roughly doubles each time it fills up:

size_vs_capacity.cpp
vector<int> v;
for(int i = 0; i < 10; i++) {
    v.push_back(i);
    cout << "size=" << v.size() << " capacity=" << v.capacity() << endl;
}

size=4 capacity=4

size=8 capacity=8
size=9 capacity=16

The exact growth pattern (doubling capacity here) may vary slightly depending on the compiler and library used, but the "doubling" strategy is the most common one, and it's the reason for vector's high efficiency.

More Examples

Example 1 — Building a vector Dynamically From User Input

The best thing about vector is that we don't have to know the number of elements in advance like with arrays. Here we read the count n, then add each value in sequence using push_back:

ex1_dynamic_build.cpp
int n;
cin >> n;
vector<int> v;
for(int i = 0; i < n; i++) {
    int x;
    cin >> x;
    v.push_back(x);
}
cout << "Number of elements: " << v.size() << endl;
for(int i = 0; i < v.size(); i++) {
    cout << v[i] << ' ';
}

Here we start with a completely empty vector (size = 0), then use push_back inside a for loop to add a new element on every iteration. This would be impossible to do just as easily using a regular array, since its size must be fixed before execution.

Example 2 — Finding the Largest Value Inside a vector

The same "largest value" idea we learned with arrays, but this time using vector and the function v.size() instead of a fixed number:

ex2_max.cpp
vector<int> v = {12, 45, 7, 89, 34};
int maxVal = v[0];
for(int i = 1; i < v.size(); i++) {
    if(v[i] > maxVal) {
        maxVal = v[i];
    }
}
cout << "Largest value: " << maxVal << endl;

Notice that the condition in the loop's header is i < v.size() and not a fixed number; this makes the code work correctly no matter how the vector's size changes later.

Example 3 — A Dynamic Shopping Cart

A real-world example combining push_back, pop_back, and size() together: a customer adds products to their cart, then cancels the last product they added, and we compute the total:

ex3_shopping_cart.cpp
vector<int> cart;
cart.push_back(50);
cart.push_back(120);
cart.push_back(75);
cout << "Number of products: " << cart.size() << endl;
cart.pop_back();
cout << "Number of products after cancellation: " << cart.size() << endl;
int total = 0;
for(int i = 0; i < cart.size(); i++) {
    total += cart[i];
}
cout << "Total: " << total << endl;
Number of products: 3
Number of products after cancellation: 2
Total: 170

cart.pop_back() removed the last product added (75), leaving only the two products priced 50 and 120 in the cart, totaling 170.

First Exercise

Write a program that reads integers from the user one at a time, storing them in a vector using push_back, and stops reading when the user enters the number -1 (as a stop signal). Then print the number of values entered and their sum. Notice that here we don't know the number of values in advance, and that's exactly what makes vector suitable here rather than an array.

hw1_solution.cpp
vector<int> v;
int x;
while(cin >> x && x != -1) {
    v.push_back(x);
}
int sum = 0;
for(int i = 0; i < v.size(); i++) {
    sum += v[i];
}
cout << "Number of values: " << v.size() << endl;
cout << "Sum: " << sum << endl;

Example: if the user enters 5 10 15 -1:

Number of values: 3
Sum: 30

Second Exercise

You have a fixed array of 8 integers. Use a vector to store only the even numbers from it (using push_back inside an if statement), then print how many there are and print them all.

int arr[8] = {3, 8, 12, 5, 6, 11, 20, 7};

Fourth Exercise

This exercise uses a vector inside another vector (vector<vector<int>>) — a very common structure in competitive programming for representing grids and 2D arrays. Create a 3×3 table, fill it with the values from 1 to 9 using push_back for each row, then print it completely using two nested for loops.

hw4_solution.cpp
vector<vector<int>> table;
for(int i = 0; i < 3; i++) {
    vector<int> row;
    for(int j = 0; j < 3; j++) {
        row.push_back(i * 3 + j + 1);
    }
    table.push_back(row);
}
for(int i = 0; i < table.size(); i++) {
    for(int j = 0; j < table[i].size(); j++) {
        cout << table[i][j] << ' ';
    }
    cout << endl;
}
1 2 3
4 5 6
7 8 9

Notice that table[i] is itself an entire vector<int> (one row), so we use table[i].size() to find the length of each row individually.

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

vectorResizable array

A data container like an array, but able to change its size while the program runs.

push_back()Add to the end

A function that adds a new element to the end of the vector.

pop_back()Remove from the end

A function that removes the last element of the vector.

size()Current element count

A function that returns the current number of elements in the vector.

resize()Change the size

A function that changes the vector's number of elements to a new specified size.

clear()Empty it out

A function that removes all of the vector's elements, making its size zero.

empty()Is it empty?

A function that returns true if the vector has no elements at all.

front()The first element

A function that returns the value of the first element in the vector.

back()The last element

A function that returns the value of the last element in the vector.

at(i)Safe access

Like v[i] but checks that the index is valid and stops the program with a clear error if not.

capacity()Reserved memory

The amount of memory actually reserved for the vector, usually larger than size().

Amortized O(1)Averages out to constant

A description of push_back's efficiency: most operations are instant, and the rare reallocations don't affect the overall average.

Dynamic arrayAnother name for vector

Another name for vector, since its size isn't fixed.
