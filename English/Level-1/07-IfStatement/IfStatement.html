The if Statement — Making Decisions

The if statement is used to make decisions inside a program — it makes the program execute a specific part only if a certain condition is true. This takes you from a program that always runs the same instructions, to a program that "thinks" and chooses what to do based on the situation.

Basic structure:

if_syntax.cpp
if (condition)
    statement;
Click on any line to see its explanation here...
  • condition is an expression that evaluates to either true or false.
  • If the condition is true, the statement is executed.
  • If the condition is false, the statement is skipped, and the program continues executing after the if statement.

Example:

if_example.cpp
if (x == 100)
    cout << "x is 100";
Click on any line to see its explanation here...

If the value of x is exactly 100, the message "x is 100" will be printed. Otherwise, nothing happens and the program continues normally.

Multiple Statements Inside if — the Compound Block

If you want to execute more than one statement when the condition is true, group them between curly braces { } to form a block:

if_block.cpp
if (x == 100)
{
    cout << "x is ";
    cout << x;
}
Click on any line to see its explanation here...

This block is treated as a single statement in the context of flow control.

Indentation and line formatting don't affect how the program runs. So the following code is exactly equivalent to the code above, despite the different look:

if_block_oneline.cpp
if (x == 100) { cout << "x is "; cout << x; }

Using else

You can add an else part to specify what happens when the condition is false:

if_else.cpp
if (x == 100)
    cout << "x is 100";
else
    cout << "x is not 100";

  • If the condition is true, the first statement runs.
  • If it's false, the statement after else runs instead.

else if Chains

You can chain several conditions using else if to handle multiple cases. The program checks the conditions in order from top to bottom, and executes only the first branch whose condition is true, then skips the rest of the chain entirely:

else_if_chain.cpp
if (x > 0)
    cout << "x is positive";
else if (x < 0)
    cout << "x is negative";
else
    cout << "x is 0";
Click on any line to see its explanation here...

This structure lets the program choose among several alternatives: if x is greater than zero → it prints "x is positive". If x is less than zero → it prints "x is negative". Otherwise (meaning x is exactly zero) → it prints "x is 0".

Notice that else if isn't a new keyword in C++ — it's simply else followed by a new if. You can chain any number of consecutive else ifs before the final (optional) else.

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

ifA conditional statement

Executes a part of the code only if a certain condition is true.

elseThe otherwise branch

Specifies what happens when the if condition is false.

else ifChains another condition

Chains several conditions together to choose among more than two alternatives.

ConditionEvaluates to true/false

An expression that evaluates to true or false, determining which branch runs.

Boolean expressionOnly true or false

An expression whose only possible value is true or false.

Selection statementChooses among paths

A general name for statements like if and switch that choose one path among several.

BlockGrouped instructions

A group of instructions between { } treated as a single statement inside an if.

BranchOne possible path

One of the possible paths a program's execution might take.
