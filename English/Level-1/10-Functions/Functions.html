What Is a Function?

A function is a group of instructions grouped together under a specific name. That name can be called to run the instructions whenever needed, instead of rewriting them every time.

A function in C++ consists of four main parts:

1

Function name

The name that will be used to call the function.

2

Function body

The place where the function's instructions are written.

3

Parameters

The values that are passed to the function when it's called. A function can have any number of parameters (including zero).

4

Return type

Functions can return a value to the place where they were called. The return type determines the type of this value. If a function doesn't return anything, its type must be void.

Function Syntax

How to write a function:

Functions are usually written outside the main() function, like this:

function_syntax.cpp
return_type function_name(parameter1, parameter2, ... , parameterN) {
    // function body
}
ElementExplanation
return_typeThe type of value the function will return (like int, long long, string...). If it's void, the function won't return any value.
function_nameThe name you use to call the function.
parameter1, ..., parameterNThe function's parameters.

How to call a function:

To call a function we use the following syntax:

function_call.cpp
function_name(value1, value2, ... , valueN);

First Example: A Function With No Parameters and No Return Value

An example of a program containing a function that doesn't return any value (return_type = void) and has no parameters:

hello_function.cpp 
#include<iostream>
using namespace std;

void f() {
    cout << "Hello Function" << endl;
}

int main() {
    f();
    cout << "Hello Main" << endl;
    f();
}

Parameters

Defining a function with parameters:

Parameters are variables that receive a value when the function is called. They're defined like this: parameter_type parameter_name. Example:

multiply.cpp
void multiply(int x, int y) {
    cout << x * y << endl;
}
Click on any line to see its explanation here...

Here we've defined a function multiply() that takes two parameters (x and y) and prints their product.

Passing parameters:

To call multiply() we put the values we want to pass inside the parentheses at the call site. The order of the passed values must match the order of the parameters in the definition:

multiply_call.cpp
multiply(5, 3);

This is how the passed values get linked to the parameters inside the function:

int multiply(int x, int y)
x = 5
y = 3
Call
multiply(5, 3)

Passing Parameters by Value and by Reference

When you pass a variable to a function, its value is copied and assigned to the function's parameter. Any change made to the parameter inside the function does not affect the original variable. This is called pass by value.

But a variable can also be passed by reference, so that the parameter becomes the exact same variable that was passed, and any change made to the parameter changes the original variable's value. To pass a parameter by reference, we add & before the parameter's name:

value_vs_reference.cpp
void addOneByValue(int x) {
    x = x + 1;
}
void addOneByReference(int &x) {
    x = x + 1;
}

An example using both approaches together:

ref_example.cpp 
#include<iostream>
using namespace std;
void addOneByReference(int &x) {
    x = x + 1;
}
void addOneByValue(int x) {
    x = x + 1;
}
int main() {
    int n = 5;
    addOneByValue(n);
    cout << n << endl;
    addOneByReference(n);
    cout << n << endl;
}
Click on any line to see its explanation here...

Output:

5
6

When calling addOneByValue(n);, n's value was copied into x, so the change to x didn't change n's value. But when calling addOneByReference(n);, x became n itself, so the change to x changed n's value.

Quick rule: without & = a separate copy (pass by value). With & = the exact same variable (pass by reference).

Return Values

After a function finishes, it can return a value to the place where it was called by writing return. To write a function that returns a certain value, you must specify the return type before the function's name:

add.cpp
int add(int a, int b) {
    return a + b;
}
int main() {
    int result = add(5, 3);
}

Calling Functions Within Functions

A function can be called from inside another function. When the called function finishes, execution returns to the function that called it:

call_chain.cpp 
#include<bits/stdc++.h>
using namespace std;

void m() {
    cout << "third" << endl;
}

void f() {
    cout << "second" << endl;
    m();
    cout << "fourth" << endl;
}

int main() {
    cout << "first" << endl;
    f();
    cout << "fifth" << endl;
}

Output:

first
second
third
fourth
fifth

The program starts by running main(), and execution moves through three nested functions before returning:

main() ← f() ← m()
main(): "first"
main() → calls f()
f(): "second"
f() → calls m()
m(): "third"
m() finishes → returns to f()
f(): "fourth"
f() finishes → returns to main()
main(): "fifth"

Recursive Functions

Recursive functions (or self-calling functions) are functions that call themselves while they run. Example: computing the factorial n!, which is calculated as:

factorial_formula.txt
n! = 1 * 2 * 3 .... * (n - 1) * n

So the factorial of 4 (4!) is:

factorial_4.txt
4! = 4 * 3 * 2 * 1 = 24

Note: the factorial of n is the product of the factorial of n - 1 and n (i.e. n! = (n - 1)! * n).

factorial.cpp 
#include<bits/stdc++.h>
using namespace std;

int factorial(int x) {
    if (x <= 1) {
        return 1;
    } else {
        return factorial(x - 1) * x;
    }
}

int main() {
    int n;
    cin >> n;
    cout << factorial(n) << endl;
}
Click on any line to see its explanation here...

In this program we wrote a function factorial() that calls itself to compute the factorial of a given number. If we enter the number 3, factorial(3) is called, which calls factorial(2), which calls factorial(1). factorial(1) returns 1, so factorial(2) returns 1 * 2 = 2, and finally factorial(3) returns 2 * 3 = 6 to main() to be printed.

Important note: the condition if (x <= 1) is called the base case, and it's essential to avoid the function calling itself forever.

The call diagram for factorial(3) — notice how the calls stop at the base case, then the values return upward, multiplied at each level:

Call Stack — factorial(3)
factorial(3) → call
factorial(2) → call
factorial(1) → call (base case)
factorial(1) → return 1
factorial(2) → return 1 * 2 = 2
factorial(3) → return 2 * 3 = 6

Extra example: the same recursion idea, but computing the sum of numbers from 1 to n instead of a product:

recursive_sum.cpp
int sumTo(int n) {
    if (n <= 1) {
        return n; // base case
    } else {
        return sumTo(n - 1) + n; // recursive call
    }
}
// sumTo(4) = sumTo(3) + 4 = sumTo(2) + 3 + 4 = ... = 1+2+3+4 = 10

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

FunctionA named block of code

A group of instructions grouped together under a specific name that can be called whenever needed.

ParameterNamed input slot

A variable defined in a function's header to receive a value when it's called.

ArgumentValue passed in

The actual value passed to a function when it's called.

Return typeType of the result

The type of the value a function returns to where it was called.

voidNo return value

A special type meaning the function doesn't return any value.

Pass by valueCopies the value

Copying the variable's value into the parameter; changes don't affect the original.

Pass by referenceShares the variable

The parameter is the exact same variable as the original; changes affect it directly.

Call stackTracks active calls

The sequence in which functions are called and return during a program's execution.

RecursionSelf-calling function

When a function calls itself to solve a smaller version of the same problem.

Base caseStops the recursion

The condition that stops a recursive function from calling itself again.
