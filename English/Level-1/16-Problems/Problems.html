    for(int d3 = 0; d3 <= 9; d3++)
    for(int d4 = 0; d4 <= 9; d4++)
    for(int d5 = 0; d5 <= 9; d5++)

Exactly One Vowel

Solved

A string of three letters is formed using the 26 English letters, and contains exactly one vowel. Consider A, E, I, O, and U vowels. Repetition is allowed.

Interactive Lab: Watch Where the Vowel Settles

?
Position 1
?
Position 2
?
Position 3
1

We choose the vowel's position among the three positions: 3 choices.

2

We choose the vowel itself from among the five: 5 choices.

3

We fill each of the other two positions with a consonant from the remaining 21 consonants (repetition is allowed): 21 choices per position.

4

We multiply the four numbers together per the Product Rule.

3 · 5 · 21² = 6615

verify_p6.cpp
#include <iostream>
#include <string>
using namespace std;

bool isVowel(char c) { return c=='A'||c=='E'||c=='I'||c=='O'||c=='U'; }

int main() {
    string letters = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    long long count = 0;
    for(char a : letters)
    for(char b : letters)
    for(char c : letters) {
        int vowels = isVowel(a) + isVowel(b) + isVowel(c);
        if(vowels == 1) count++;
    }

    cout << count;
    return 0;
}

Colored Pieces

Solved

Five pieces are placed in a row. Each piece's color is red, green, or blue, and each piece must differ in color from the piece next to it. How many different rows can be formed?

Interactive Lab: Watch the Row Get Colored Piece by Piece

1

2

3

verify_p7.cpp
#include <iostream>

int main() {
    long long count = 0;
    for(int a = 0; a < 3; a++)
    for(int b = 0; b < 3; b++) if(b != a)
    for(int c = 0; c < 3; c++) if(c != b)
    for(int d = 0; d < 3; d++) if(d != c)
    for(int e = 0; e < 3; e++) if(e != d)
        count++;

    cout << count;
    return 0;
}

Exactly Two Digits

Solved

A password consists of five symbols using uppercase English letters and digits. It must contain exactly two digits. Repetition is allowed.

Interactive Lab: Watch Which Positions Become Digits

1

We choose which two of the five positions will be digits: C(5,2) = 10 ways.

2

We fill each digit position with a digit from 0 to 9 (repetition is allowed): 10 choices per digit position, i.e. 10×10.

3

We fill each letter position with an uppercase letter from the 26 letters: 26 choices per letter position, i.e. 26×26×26.

4

We multiply the number of ways to choose the positions by the number of ways to fill them.

C(5,2) · 10² · 26³ = 17,576,000

verify_p8.cpp
#include <iostream>
using namespace std;

int main() {
    long long total = 0;
    for(int mask = 0; mask < 32; mask++) {
        if(__builtin_popcount(mask) != 2) continue;
        long long ways = 1;
        for(int i = 0; i < 5; i++)
            ways *= (mask & (1 << i)) ? 10 : 26;
        total += ways;
    }

    cout << total;
    return 0;
}

verify_p9.cpp
#include <iostream>
#include <string>
#include <map>
using namespace std;

int main() {
    string syms = "ABCDE";
    long long count = 0;
    for(char a : syms) for(char b : syms) for(char c : syms) for(char d : syms) {
        map<char,int> freq;
        freq[a]++; freq[b]++; freq[c]++; freq[d]++;
        bool hasThree = false;
        for(auto &p : freq) if(p.second == 3) hasThree = true;
        if(hasThree && freq.size() == 2) count++;
    }

    cout << count;
    return 0;
}

Hard

A Number With Conditions

Solved

How many four-digit positive integers have all different digits and contain exactly one even digit?

Interactive Lab: Compare the Two Cases for the Even Digit

1

Zero is also an even digit, so we split the problem into two cases based on the value of the single even digit.

2

Case 1 — the even digit is zero: it can't be in the first position, so it has 3 possible positions. The remaining three digits are odd and different, from {1,3,5,7,9}: 5×4×3=60 arrangements. Case total: 3×60=180.

3

Case 2 — the even digit is one of {2,4,6,8}: 4 choices for its value, and it can be placed in any of the four positions (since it's not zero): 4 choices for its position. The remaining three digits are odd and different: 5×4×3=60 arrangements. Case total: 4×4×60=960.

4

The two cases are completely separate (determined by the even digit's value), so we add them per the Sum Rule.

180 + 960 = 1140

verify_p10.cpp
#include <iostream>
using namespace std;

int main() {
    long long count = 0;
    for(int d1 = 1; d1 <= 9; d1++)
    for(int d2 = 0; d2 <= 9; d2++) if(d2 != d1)
    for(int d3 = 0; d3 <= 9; d3++) if(d3 != d1 && d3 != d2)
    for(int d4 = 0; d4 <= 9; d4++) if(d4 != d1 && d4 != d2 && d4 != d3) {
        int digs[4] = {d1, d2, d3, d4};
        int evenCount = 0;
        for(int x : digs) if(x % 2 == 0) evenCount++;
        if(evenCount == 1) count++;
    }

    cout << count;
    return 0;
}
1140

Solved

A string of four symbols is formed using A, B, C, and D. It must contain exactly two different symbols, each appearing twice. How many strings can be formed?

1

We choose the two different symbols that will appear in the string from among the four symbols: C(4,2) = 6 ways.

2

After choosing the two symbols, we arrange them across the four positions so that each appears exactly twice: the number of distinct arrangements = 4!/(2!×2!) = 6.

3

We multiply the number of ways to choose the two symbols by the number of ways to arrange them.

C(4,2) · 6 = 36

verify_p11.cpp
#include <iostream>
#include <string>
#include <map>
using namespace std;

int main() {
    string syms = "ABCD";
    long long count = 0;
    for(char a : syms) for(char b : syms) for(char c : syms) for(char d : syms) {
        map<char,int> freq;
        freq[a]++; freq[b]++; freq[c]++; freq[d]++;
        if(freq.size() == 2) {
            bool bothTwice = true;
            for(auto &p : freq) if(p.second != 2) bothTwice = false;
            if(bothTwice) count++;
        }
    }

    cout << count;
    return 0;
}
36

Round-Trip Routes

Solved

There are 3 routes from city A to city B, and 4 routes from city B to city C. In how many ways can a person travel from A to C via B, then return without using either of the two routes they used on the way there?

Interactive Lab: Track the Route Choices Going and Returning

Return
A
1

The trip there: we choose a route from A to B (3 choices) then a route from B to C (4 choices): 3×4=12 possible trips there.

2

The return trip must not use either of the two routes used on the way there: from C to B there remain 4−1=3 available routes, and from B to A there remain 3−1=2 available routes.

3

The number of possible return trips for each trip there: 3×2=6.

4

Going and returning are successive steps, so we multiply the number of trips there by the number of possible return trips for each.

(3 · 4) · (3 · 2) = 12 · 6 = 72

verify_p12.cpp
#include <iostream>
using namespace std;

int main() {
    int goWays = 3 * 4;      // A to B then B to C
    int returnWays = 3 * 2;  // C to B and B to A, avoiding the ones used
    cout << goWays * returnWays;
    return 0;
}
72

When it's not possible to write a direct product formula (as in problems 10 and 12), split the problem into separate cases or "there then back" steps, compute each part on its own, then add or multiply the results depending on the relationship between them.
