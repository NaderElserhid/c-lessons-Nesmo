Why do we need constants?

Sometimes we need a value that never changes while the program runs, and that's exactly the role of constants. Constants help prevent mistakes (like accidentally changing a number) and make code easier to understand.

constants.cpp 
#include <iostream>
using namespace std;

int main() {
    int age = 15;
    age = 16; // we can change it

    const double PI = 3.14159;
    // PI = 3.14;  Error! cannot change a constant

    cout << "PI is " << PI << endl;
    return 0;
}

Why Use Constants?

1

Protecting important values

Constants prevent an important value from being accidentally changed somewhere else in the code.

2

Clarity

The variable PI is clearer than writing the number 3.14159 directly everywhere it's used.

3

Easy to update

If you ever need to change the value later (rare with PI, but still), you can edit it in a single place instead of searching for it throughout the file.

Defining Constants

You create a constant in C++ by adding the const keyword before the data type:

define_const.cpp
const int DAYS_IN_WEEK = 7;
const double GRAVITY = 9.81;
const char GRADE = 'A';

Constants must be given a value the moment they're defined, and can't be left uninitialized to be filled in later the way we sometimes do with regular variables.

Literal Constants

Literal constants are values that appear directly in the code, also called raw values — written directly without first being stored in a separate variable:

literals.cpp
int x = 5;          // 5 is an integer literal
double pi = 3.14;   // 3.14 is a double literal
char letter = 'A';  // 'A' is a character literal
string word = "Hi"; // "Hi" is a string literal

Common Literal Suffixes

You can tell C++ the type of a numeric value using the following suffixes:

suffixes.cpp
float a = 3.14f;
long long b = 10000000000LL;
long double c = 3.1415926535L;

If you don't add a suffix, C++ automatically assumes int for whole numbers and double for decimal numbers.

Constants Using #define (the Old Way)

Before the const keyword existed, programmers used #define to define constants:

define_old.cpp
#define PI 3.14159
#define GREETING "Hello"

This approach still works, but const is considered safer and is preferred in modern C++ — because it respects the data type and is checked by the compiler, unlike #define, which just performs a simple text substitution before compilation.

Quick Summary

1

Use const for values that should never change.

2

Use suffixes like LL or f to pick the right numeric type.

3

Avoid #define for constants except when reading old code.

Using constants makes your code safer, clearer, and easier to maintain!

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

ConstantNever changes

A value that's set once and can never be changed while the program runs.

LiteralA raw value in code

A raw value written directly in the code, like the number 5 or the text "Hi".

SuffixA type-marking symbol

A symbol added after a numeric value to pin down its type precisely, like LL or f.

UnsignedNon-negative only

A data type that stores only positive numbers, no negative values.

InitializeGive a first value

Giving a variable or constant its first value the moment it's defined.

Read-onlyViewable, not editable

A value that can be read and used, but cannot be modified.

MacroA text substitution

A text substitution performed by #define before actual compilation.

Preprocessor directiveRuns before compiling

A command starting with # that runs before the code itself is compiled, like #define or #include.

Single / double precisionTwo levels of accuracy

Levels of accuracy for representing decimal numbers — float is single precision, double is double precision.
