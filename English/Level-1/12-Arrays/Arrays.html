Why Do We Need Arrays?

When a program needs a large number of similar variables, defining each one separately (like int grade1, grade2, grade3, ...;) makes the code long and disorganized. To solve this problem we use arrays, which let us group related data together in an organized way under a single name.

What is an array?

An array is a fixed number of variables of the same type, stored in memory consecutively, sharing a single name. The variables inside an array are called elements.

To tell the elements inside an array apart, each element is given a unique number known as its index. When an array has n elements, they're numbered consecutively from 0 to n - 1.

Numbering in arrays always starts at 0, not 1. This is one of the most important rules to remember well when working with arrays in C++.

Declaring Arrays

To declare an array in C++ we use the following syntax:

syntax
type name[size];
ElementExplanation
typeThe type of every element inside the array (like int or double).
nameThe name we'll use to access the array.
sizeThe number of elements the array holds.

For example:

declare.cpp
int a[4];

This declaration creates an array named a made up of 4 elements, each of type int.

An array's size is fixed and cannot be changed after it's created.

An array's size doesn't have to be an explicit number — it can be an expression computed while the program runs, letting us set the array's size based on the program's state at runtime:

dynamic_size.cpp
int n;
cin >> n;
int a[n + 1]; // creates an array of size n + 1

Setting an Array's Values

When you define an array locally, none of its elements have determined values — that is, their values are unknown. To set an array's values, we give it initial values, for example:

init.cpp
int a[4] = {2, 4, 5, 0};

This creates an array containing the values 2, 4, 5, and 0. We can represent it as follows, where the cells represent the array's elements, and the numbers below them are the indices:

If we want to define an array locally and have all its elements start at 0, we can write:

int a[2000] = {};

This line creates an array with 2000 elements, each one equal to 0.

Accessing Elements

Any element inside an array can be accessed using its index, with the following syntax:

syntax
name[index];
ElementExplanation
nameThe array's name.
indexThe index of the element you want to access.

Iterating Over an Array

We can use loops to iterate over every element of an array, by iterating over its indices (from 0 to the array's size - 1). For example, to compute the sum of all of an array's elements, we write:

sum.cpp 
#include <iostream>
using namespace std;
int main () {
    int n;
    cin >> n; // reads the array's size

    int a[n]; // declares an array of size n
    for(int i = 0; i < n; i++) {
        cin >> a[i]; // reads a value into each index of a[i]
    }
    int sum = 0;
    for (int i = 0 ; i < n ; i++) {
        sum += a[i]; // adds each value of a[i] to sum
    }
    cout << sum << endl;
}
Click on any line to see its explanation here...

In this example: we read the number of elements n from the user, then create an array a of size n, use a loop to read the array's values, then use another loop to compute the total sum of the elements and print the result.

More Examples Using Arrays

Here are five progressive examples showing different uses of arrays, ending with examples that combine a for loop and an if statement together:

Example 1 — Printing Students' Grades

We store 5 students' grades in an array, then print them one by one using a for loop:

ex1_grades.cpp
int grades[5] = {85, 92, 78, 90, 88};
for(int i = 0; i < 5; i++) {
    cout << "Student " << i+1 << ": " << grades[i] << endl;
}

Here i goes through every index from 0 to 4, and on each iteration we print the student's number (i+1 since students are numbered starting from 1) next to their grade grades[i].

The result will appear here...

Example 2 — Computing the Average

We use a loop to add up all the elements first, then divide the sum by the number of elements to find the average:

ex2_average.cpp
int scores[4] = {70, 80, 90, 100};
int sum = 0;
for(int i = 0; i < 4; i++) {
    sum += scores[i];
}
double average = sum / 4.0;
cout << "Sum: " << sum << endl;
cout << "Average: " << average << endl;

Notice that we divide by 4.0 and not just 4, to make sure the division is floating-point rather than integer division that would drop the fraction.

The following examples combine a for loop with an if statement, one of the most commonly used patterns when working with arrays.

Example 3 — Finding the Largest Value (for + if)

We start by assuming the first element is the largest, then go through the rest of the elements, using if each time to compare and update the largest value if we find something bigger:

ex3_max.cpp
int nums[6] = {4, 17, 9, 25, 3, 12};
int maxVal = nums[0];
for(int i = 1; i < 6; i++) {
    if(nums[i] > maxVal) {
        maxVal = nums[i];
    }
}
cout << "Largest value: " << maxVal << endl;

We start the loop at i = 1 and not 0 because we already used nums[0] as the starting value for maxVal.

The result will appear here...

Example 4 — Counting Even Numbers (for + if)

We go through every element, and use an if statement with the remainder % to check if the number is even, and if so we increase a counter:

ex4_count_even.cpp
int nums[7] = {3, 8, 12, 5, 6, 11, 20};
int count = 0;
for(int i = 0; i < 7; i++) {
    if(nums[i] % 2 == 0) {
        count++;
    }
}
cout << "Number of even numbers: " << count << endl;

The condition nums[i] % 2 == 0 is only true when the element is divisible by 2 with no remainder, i.e. when it's even.

Example 5 — Searching for a Specific Value (for + if)

We go through every element and compare it to the target value using if; if they match, we print the element's index. This is called linear search:

ex5_search.cpp
int nums[5] = {10, 25, 30, 45, 60};
int target = 30;
bool found = false;
for(int i = 0; i < 5; i++) {
    if(nums[i] == target) {
        cout << "Element " << target << " found at index " << i << endl;
        found = true;
    }
}
if(!found) {
    cout << "Element not found" << endl;
}

The variable found, of type bool, helps us know whether we found the element or not, so we can print the right message in either case.

Multi-Dimensional Arrays

Multi-dimensional arrays are arrays that contain other arrays inside them, meaning each element can itself be an array. Each of these levels is called a dimension. Look at the following example:

multi_dim.cpp
int a[5];
int b[5][4];
ElementExplanation
aA one-dimensional array containing 5 integers.
bA two-dimensional array, made up of 5 arrays, each containing 4 integers.

a[0] represents a single integer, while b[0] represents an entire array of four integers.

To access an element inside a multi-dimensional array, you must specify the index in each dimension: to access an element in a we write a[i], while to access an element in b we write b[i][j].

Try it yourself: click on any cell of the array b[5][4] to see its exact value and position (like b[2][1], which holds the value 14):

Click on a cell of the grid above...

The total number of cells in a multi-dimensional array equals the product of the lengths of all its dimensions. In our example, b contains 5 × 4 = 20 elements.

An array can have more than two dimensions — it can even have seven or more dimensions (like int c[2][3][4][5][2][3][2];), though common usage in competitive programming is usually limited to one or two dimensions.

First Exercise

Create an array of 6 integers representing the temperatures for six days, then print each temperature along with its category (Hot / Mild / Cold) using a for loop and an if / else if / else chain. Consider: 30 or above = hot, between 15 and 29 = mild, below 15 = cold.

hw1_solution.cpp
int temps[6] = {32, 18, 5, 27, 14, 38};
for(int i = 0; i < 6; i++) {
    cout << "Day " << i+1 << ": " << temps[i] << " degrees - ";
    if(temps[i] >= 30) {
        cout << "Hot" << endl;
    } else if(temps[i] >= 15) {
        cout << "Mild" << endl;
    } else {
        cout << "Cold" << endl;
    }
}
Day 1: 32 degrees - Hot
Day 2: 18 degrees - Mild
Day 3: 5 degrees - Cold
Day 4: 27 degrees - Mild
Day 5: 14 degrees - Cold
Day 6: 38 degrees - Hot

Second Exercise

Write a program that reads an array size n from the user, then reads n integers, then prints the number of even numbers and the number of odd numbers among them, using a for loop and an if statement.

hw2_solution.cpp
int n;
cin >> n;
int a[n];
for(int i = 0; i < n; i++) {
    cin >> a[i];
}
int evenCount = 0, oddCount = 0;
for(int i = 0; i < n; i++) {
    if(a[i] % 2 == 0) {
        evenCount++;
    } else {
        oddCount++;
    }
}
cout << "Even numbers: " << evenCount << endl;
cout << "Odd numbers: " << oddCount << endl;

Example: if the user enters n = 5 then the values 1 2 3 4 5:

Even numbers: 2
Odd numbers: 3

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

ArrayFixed-size list

A fixed number of variables of the same type, stored consecutively and sharing a single name.

ElementOne item in it

Each individual variable inside the array.

IndexPosition number

The unique number identifying each element inside the array, starting from 0.

SizeElement count

The number of elements the array holds, fixed after it's created.

InitializationSetting starting values

Giving an array's elements initial values when it's defined.

IterateGo through each item

Going through every element of an array, usually using a loop.

Multi-dimensional arrayArrays inside arrays

An array containing other arrays inside it.

DimensionOne nesting level

Each level within a multi-dimensional array.

Linear searchCheck items one by one

Going through an array's elements one after another, looking for a specific value.
