Variables and Types

This lesson is brought to you by the TweetKod platform

Why do we need variables?

To solve programming problems, we need to store data and work with it, such as numbers, characters, or words. We store this data inside variables — spaces in memory that we give a name to so we can use them later in our program.

variables.cpp 
#include <iostream>
using namespace std;

int main() {
    int age = 15;
    double height = 1.70;
    char grade = 'A';
    string name = "Ali";
    cout << name << " is " << age << " years old.";
    return 0;
}

Extra numeric types: long long

When numbers get too large to fit in an int variable (for instance, working with billions or trillions), we use the long long type:

population.cpp
long long population = 8000000000; // 8 billion

The reason is that int can typically store values up to about 2 billion (2,147,483,647). If we need larger numbers, we use long long.

float and double

Both types store decimal numbers, but they differ in precision (how many decimal digits can be represented accurately):

TypeApproximate precisionExample
floatAbout 6–7 decimal digits3.141593
doubleAbout 15–16 decimal digits3.141592653589793
precision.cpp
float f = 1.61;
double d = 1.61;
cout << setprecision(20); // show 20 decimal digits
cout << f << endl; // prints 1.6100000143051147461
cout << d << endl; // prints 1.6100000000000000977

Warning: as you notice in the example, most real numbers cannot be represented with perfect accuracy using float or double. Always keep that in mind when working with these types. Programmers usually prefer double because it's more precise, but it uses 8 bytes of memory versus only 4 bytes for float. So only use float if you actually need to reduce memory usage.

bool

A variable of type bool can only take two values: true or false. We often use it in conditions and logic inside if expressions:

bool.cpp
bool isEven = true;
bool isPrime = false;

int x = 7;
bool big = x > 10;
cout << big; // prints 0 (false)

The value true is represented internally by the number 1, while false is represented by 0.

Type Conversion

Sometimes we mix different types in the same operation:

conversion.cpp
int a = 3;
double b = 2.5;
cout << a + b; // 5.5

C++ temporarily converts the variable a to double, so the result comes out as the same type.

Optional: auto

The auto keyword lets the compiler automatically determine a variable's type from the value assigned to it:

auto.cpp
auto x = 5;        // int
auto y = 3.14;     // double
auto word = "Hi";  // const char*

You'll often use it in more advanced problems later on.

Naming Variables

When creating variables in C++, you must choose a name for each one that makes its purpose clear to the program (and to a human reader). Good names make code clearer and easier to understand.

You can
  • Use letters, digits, and the underscore (_)
  • Start with a letter or an underscore
  • Use uppercase and lowercase letters (C++ treats them differently)
You cannot
  • Start with a digit
  • Use spaces
  • Use special symbols like @, $, %, !, #, ?
  • Use reserved words (like int, for, return, while)
Valid names
int age;
double total_price;
bool isValid;
string firstName;
Invalid names
int 2cats;       // starts with a digit
int my variable; // contains a space
int total$;      // special symbol
int int;         // reserved word

Case Sensitivity

C++ distinguishes between uppercase and lowercase letters:

case.cpp
int score = 10;
int Score = 20;
cout << score; // prints 10

In this example, score and Score are two completely different variables.

Naming Styles

There are several styles for naming variables, and most C++ programmers use one of the following:

StyleExampleCommon use
snake_caseplayer_healthFor variables and functions in simple programs
camelCaseplayerHealthUsually used in larger projects or libraries
PascalCasePlayerHealthUsually used when defining classes or structs

Pick one style and stick to it throughout your code — consistency matters more than which particular style you choose.

naming.cpp 
#include <iostream>
using namespace std;

int main() {
    int playerHealth = 100;
    int playerScore = 2500;
    bool isAlive = true;
    cout << "Health: " << playerHealth << endl;
    cout << "Score: " << playerScore << endl;
    cout << "Alive: " << isAlive << endl;
    return 0;
}

Output:

Health: 100
Score: 2500
Alive: 1

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

VariableA named memory slot

A space in memory with a name, used to store a value that can change later.

IntegerA whole number

A number without decimal fractions, positive or negative.

Floating-pointA decimal number

A number that has a fractional part after the decimal point.

PrecisionDigits of accuracy

The number of decimal digits a number can be represented accurately with.

BooleanA two-value type

A value that can only be true or false.

StringA text value

A sequence of characters used to store words and sentences.

CharacterA single symbol

A single symbol only, like a letter, digit, or punctuation mark.

MemoryWhere data lives

The space inside a computer where variables are stored while a program runs.

ByteA unit of storage

A unit for measuring the size of data stored in memory.

Type conversionChanging a value's type

Converting a value from one data type to another, automatically or manually.

KeywordA reserved language word

A word with a special meaning in the language, like int or return.

Reserved wordCannot be used as a name

A word that cannot be used as a variable name because it's part of the language itself.

Case sensitiveUpper/lowercase matters

Distinguishes between uppercase and lowercase letters, so score and Score are different.

Naming conventionA consistent naming style

A unified style for writing variable names, like snake_case or camelCase.

Input / OutputReading and printing data

Receiving data from the user (input) or displaying it on the screen (output).

autoAutomatic type inference

A keyword that lets the compiler determine a variable's type automatically from its value.
