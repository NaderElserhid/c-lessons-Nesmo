What Is Scope?

In C++, where a variable is defined affects where it can be used. Scope is the part of a program where a variable can be defined and accessed directly using its name. If a variable is defined in a certain scope, we say the name is visible in that scope.

Most scopes are regions surrounded by curly braces { }. The area outside any scope is called global scope, and any other area is called a local scope.

A Complete Example of Scopes

Click on any variable definition line to see which scope it belongs to:

scope_example.cpp 
#include<iostream>
using namespace std;

int x = 5; // global scope
int main() {
    int y = 4; // local scope 1

    for (int i = 0; i < 5; i++) {
        int z = 20; // local scope 2
        if (i % 2 == 0) {
            // local scope 3
            cout << z + x << ' ' << z + y << endl;
        }
        else {
            // local scope 4
            cout << z - y << ' ' << z - x << endl;
        }
    }
}

In this example we have one global scope and four local scopes. Notice that scope 1 spans the entire main() function, scope 2 is the region inside the for loop, and scopes 3 and 4 are the regions inside if and else respectively.

Where is a variable visible?

Variables defined globally (global variables) are visible in every scope after their definition. Variables defined locally (local variables) are visible only within the scope they were defined in, including any inner scopes within it.

Notice that variables defined inside a for loop's header (like i) belong to the loop's own scope, even though the definition comes right before the curly brace.

Warning: Using a Variable Outside Its Scope

Using a variable outside the scope it was defined in leads to a compilation error. As soon as you leave the scope (i.e. after the closing curly brace), the variable stops existing.

Example: trying to use z after the end of the for loop it was defined inside:

scope_error.cpp
for (int i = 0; i < 5; i++) {
    int z = 20;
    // ...
}
cout << z; // z doesn't exist here, outside its scope

Naming Within a Scope

Within a single scope, a name can represent only one variable:

duplicate_name.cpp
int main() {
    int x = 5;
    string x = "Hello world"; // compile error! x was already defined in the same scope
}

But we can define a variable in one scope, then define another variable with the exact same name in a different, inner scope. In this case, when that name is used inside the inner scope, the inner variable is the one used (this is called name shadowing):

name_shadowing.cpp
int x = 5;
int main() {
    int x;
    cin >> x;

    if (x == 5) {
        string x = "Hello world";
        cout << x << endl;
    }
    else {
        cout << x << endl;
    }
}
Click on any line to see its explanation here...

This is allowed because each definition sits in a different scope: int x; inside main()'s scope, and string x inside the inner if scope.

More Examples

Example 1 — the same name in two different functions causes no conflict at all:

Each function has its own local scope, even if the variable names are identical:

two_functions.cpp
void printSquare() {
    int result = 4 * 4; // result here is local to this function only
    cout << result << endl;
}

void printCube() {
    int result = 3 * 3 * 3; // a completely different result, a different scope
    cout << result << endl;
}
16
27

Both variables share the name result, but each one exists only within its own function's scope, so there's no conflict and no compile error.

Example 2 — reusing a loop counter's name in another loop:

Since every for loop opens its own scope, i can safely be used in more than one loop as long as they don't overlap:

two_loops.cpp
for (int i = 0; i < 3; i++) {
    cout << "A" << i << ' ';
}
// the first i's scope ends here
for (int i = 0; i < 3; i++) {
    cout << "B" << i << ' ';
}
A0 A1 A2 B0 B1 B2

Example 3 — a global variable used inside several functions:

global_counter.cpp
int counter = 0; // global scope

void increment() {
    counter = counter + 1; // counter is visible here because it's global
}

int main() {
    increment();
    increment();
    cout << counter << endl;
}
2

Since counter is global, it's visible inside both the increment() function and the main() function without needing to pass it as a parameter.

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

ScopeWhere a name works

The part of the program where a variable can be accessed directly by its name.

VisibilityCan be reached by name

The ability to access a variable by its name from a given point in the code.

Global scopeVisible everywhere

The area outside any function or block; variables here are visible everywhere after them.

Local scopeVisible in one block

Any region surrounded by curly braces inside a function or block; its variables are only visible within it.

BlockCode between { }

A group of statements surrounded by { }, which often forms a new local scope.

Name shadowingInner name wins

Using the same name for a variable in an inner scope, so the closer one is used when there's a conflict.

Compilation errorFails to compile

An error that prevents the compiler from producing a runnable program, such as using a variable outside its scope.
