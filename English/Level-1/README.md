# Level 1 — Foundations

Core C++ syntax and programming logic, for students starting from zero. Each chapter is a standalone interactive HTML lesson — open it directly in a browser.

| # | Chapter | Topic |
|---|---------|-------|
| 01 | [ProgramStructure](./01-ProgramStructure/ProgramStructure.html) | Anatomy of a C++ program: `#include`, `main()`, statements, compiling and running |
| 02 | [VariablesAndTypes](./02-VariablesAndTypes/VariablesAndTypes.html) | Variables, primitive data types, declaration and assignment |
| 03 | [Constants](./03-Constants/Constants.html) | `const` values and why they matter |
| 04 | [Operators](./04-Operators/Operators.html) | Arithmetic, comparison, logical, and assignment operators |
| 05 | [InputOutput](./05-InputOutput/InputOutput.html) | `cin`/`cout`, basic I/O patterns |
| 06 | [FlowControl](./06-FlowControl/FlowControl.html) | Introduction to conditional and iterative control flow |
| 07 | [IfStatement](./07-IfStatement/IfStatement.html) | `if` / `else if` / `else` branching |
| 08 | [WhileLoop](./08-WhileLoop/WhileLoop.html) | `while` and `do-while` loops |
| 09 | [ForLoop](./09-ForLoop/ForLoop.html) | `for` loops and iteration patterns |
| 10 | [Functions](./10-Functions/Functions.html) | Defining and calling functions, parameters and return values |
| 11 | [Scope](./11-Scope/Scope.html) | Variable scope and lifetime |
| 12 | [Arrays](./12-Arrays/Arrays.html) | Fixed-size arrays and indexing |
| 13 | [Vector](./13-Vector/Vector.html) | `std::vector` — dynamic arrays |
| 14 | [SumAndProductRule](./14-SumAndProductRule/SumAndProductRule.html) | Basic combinatorics: sum rule and product rule |
| 15 | [WorkedExamples](./15-WorkedExamples/WorkedExamples.html) | Fully worked example problems combining the concepts above |
| 16 | [Problems](./16-Problems/Problems.html) | Practice problem set |
| 17 | [ContestsAndPlatforms](./17-ContestsAndPlatforms/ContestsAndPlatforms.html) | Introduction to competitive programming judges and platforms |
| 18 | [ProblemsWithSubproblems](./18-ProblemsWithSubproblems/ProblemsWithSubproblems.html) | Multi-part problems combining several concepts |
| 19 | [Debugging](./19-Debugging/Debugging.html) | Code style, print-debugging, `assert`, and a practical debugging checklist |

## Note

This is the English translation of the Arabic `Level-1/` curriculum. Every chapter's content, design, and interactivity mirror the original exactly — only the language has changed (page direction switched from RTL to LTR, and any layout CSS that depended on the text direction was mirrored to match).

The [`Level-1/Extras/`](../../Level-1/Extras) folder (quiz text files, a lesson-authoring template, and CodeRunner test-case files) is internal authoring material rather than a user-facing lesson page, and has not been translated as part of this pass.
