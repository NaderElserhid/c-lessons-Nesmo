Input and Output

The Terminal

When a user runs a program, a screen called the terminal appears. Through this screen, the program can display information or receive it from the user. We call the process of displaying information output, and the process of receiving information from the user input.

Streams

Input and output in C++ are handled through what are called streams. A stream is a datatype that can receive data, send data, or both. The two main streams used in C++ are cin for input and cout for output.

To work with streams, we use the operators << and >>:

streams_syntax.cpp
stream << variable; // feeds the variable's value into the stream
stream >> variable; // takes data from the stream and stores it in the variable

In the first case, the variable doesn't change; in the second case, the variable receives a new value.

Note: the term "Stream" here refers to a type, while cin and cout are variables of that type. To use them, we need to add the line #include <iostream> at the beginning of the program.

cout

Suppose you wrote the following program:

hidden_value.cpp
int x = 5;
// add 1 if x is divisible by 3 and add 2 otherwise
int y = x + (x % 3 == 0 ? 1 : 2);

The variable y is stored in memory, and there's no way for the user to know its value. If you want to show them this value, you need to output it to the terminal:

show_y.cpp
cout << y;

This line prints the value of the variable y directly to the terminal. To print plain text, we use quotation marks "...":

spacing_bug.cpp
cout << "The value of y is";
cout << y;

The result will be:

The value of y is7

This doesn't quite look right, and the reason is that C++ doesn't understand what looks visually correct — it just executes the instructions exactly as written. Since we didn't specify a space after "is", the program didn't add one automatically.

So we need to write the space explicitly inside the text:

spacing_fixed.cpp
cout << "The value of y is ";
cout << y;

And we can print multiple expressions on the same line:

chained_cout.cpp
cout << "The value of y is " << y;

We can also print the newline character '\n' to move to a new line:

newline.cpp
cout << "Hello" << '\n' << "World";

Output:

Hello
World

cin

We now know how to write a program that defines data, works with it, and prints it, but the problem is that the program performs the exact same operations every time it runs. Sometimes we want to write a program that lets the user enter values each time — that's what cin is for:

cin_example.cpp
int x;
cin >> x;
cout << "You entered: " << x;

Program execution pauses at the instruction cin >> x until the user enters a value in the terminal and presses Enter. The value is then stored in the variable x.

Example input:

5

Expected output:

You entered: 5

Note: notice that the operators used are different: >> with cin, and << with cout.

The getline Function

When using cin, the stream reads until it finds whitespace (a space) or the end of input. Sometimes we want to read an entire line even if it contains spaces — that's what the getline function is for:

getline_example.cpp
string s;
getline(cin, s);

cout << "The line is: " << s;

To use getline, you must pass two arguments: the stream we want to read from (cin), and the variable where we'll store the result (s).

Warning: it's not recommended to use cin and getline together in the same program; cin can leave a leftover newline character in the stream, which the next getline call would then mistakenly read as an empty line.

Solved Practice Problem

The problem: write a program that reads two whole numbers and prints the smaller one first, then the larger one, each on its own line.

Solution steps:

1

Define two integer variables to store the inputs.

2

Use cin to read the values.

3

Define two more variables to store the answers.

4

Use the ternary operator to determine the smaller and larger values.

5

Use cout to print the result.

min_max.cpp 
int a, b;
cin >> a >> b; // several variables can be read on the same line

int small = (a < b ? a : b);
int large = (a > b ? a : b);

cout << small << '\n' << large;

Fast I/O

When using cout, data might not appear on screen immediately, since it's sometimes stored temporarily in a buffer to speed up execution. By default, every time cin is used, this buffer gets flushed, which can sometimes slow things down.

We can untie cin from cout and make cout flush its data only once at the end of execution, by adding the following two lines at the start of main():

fast_io.cpp
cin.tie(0); // tie the cin stream to stream (0) i.e no stream
cin.sync_with_stdio(0);

Important: in competitive programming, programs are tested automatically, and the user doesn't type values by hand — they're read from a file that may contain very large amounts of input (hundreds of thousands of numbers, for instance). So when a problem involves a huge amount of input, it's important to put these two lines at the start of your code to avoid slow execution.

Quick Exercise — Write It by Hand Now

This exercise is different from the previous ones: don't type it on the computer — write the code by hand on paper or in your notebook during class, then compare your answer to the model solution afterward.

What's required:

  1. Write a complete C++ program (starting with #include and ending with return 0;).
  2. The program reads a student's name (as text with no spaces) then their age (as an integer), using cin only.
  3. The program prints exactly one welcome sentence, exactly as in the example below — pay close attention to the spaces!

Example input:

Ali 15

Exact expected output:

Hello Ali, you are 15 years old.

Hint: you'll need a string variable for the name and an int variable for the age, and you can read them together on a single line just like we did in the previous problem: cin >> name >> age;

welcome_student.cpp
#include <iostream>
using namespace std;

int main() {
    string name;
    int age;
    cin >> name >> age;

    cout << "Hello " << name << ", you are " << age << " years old.";

    return 0;
}

Notice the deliberate spaces inside the text: after "Hello ", after "you are ", and before " years old." — this is exactly what we learned in the spacing issue above.

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

TerminalThe text window

The text window through which the user interacts with the program while it runs.

StreamCarries data in or out

A data type responsible for moving information into or out of a program, like cin and cout.

OutputDisplaying data

Displaying information from the program to the user through the terminal.

InputReceiving data

Receiving data from the user through the terminal into the program.

BufferTemporary storage

A space where data is temporarily stored before actually being displayed, to improve performance.

WhitespaceSpaces and line breaks

Any space, newline, or tab that separates values when reading with cin.

Standard input/outputThe default I/O channels

The default channels through which a program communicates with the user via the terminal.

SynchronizationKeeping streams in step

Linking the operation of more than one stream so one waits on the other, like cin being tied to cout by default.

getlineReads a full line

A function that reads an entire line of input even if it contains spaces, unlike regular cin.
