The Sum and Product Rules

Sum and Product Rule — the first lesson of the Basic Counting unit

What Are Counting Problems?

Counting problems ask for the number of choices or elements that satisfy certain conditions. We usually want to compute this number without listing every possibility one by one — imagine trying to count every possible code made of two letters and a digit; listing them by hand would be practically impossible, but two simple rules are enough to compute the number instantly: the Sum Rule and the Product Rule.

The Sum Rule

If a choice is made from only one out of several separate cases, we add the number of possibilities.

For example, suppose we can choose one pen out of 4 red pens or one pen out of 3 blue pens. The number of possible choices is:

4 + 3 = 7

The cases must not overlap; otherwise an element belonging to more than one case would be counted multiple times, giving a result larger than the true one.

We can verify this by writing a simple program that counts each pen individually as an independent choice:

sum_rule_check.cpp
int count = 0;
for(int red = 1; red <= 4; red++) count++;   // each red pen is an independent choice
for(int blue = 1; blue <= 3; blue++) count++; // each blue pen is an independent choice
cout << count;
7

The Product Rule

If forming a single outcome requires several successive choices, we multiply the numbers of choices.

For example, suppose we choose one shirt out of 3 shirts, then one pair of pants out of two pairs. The number of possible outfits is:

3 · 2 = 6

product_rule_check.cpp
int count = 0;
for(int shirt = 1; shirt <= 3; shirt++) {
    for(int pants = 1; pants <= 2; pants++) {
        count++;   // each (shirt, pants) combination is a different outfit
    }
}
cout << count;
6

The Product Rule also works with more than two choices. If a code consists of two English letters followed by one digit, and repetition is allowed, the number of possibilities is:

26 · 26 · 10 = 6760

code_symbol_check.cpp
long long count = 0;
for(char c1 = 'A'; c1 <= 'Z'; c1++) {
    for(char c2 = 'A'; c2 <= 'Z'; c2++) {
        for(char d = '0'; d <= '9'; d++) {
            count++;
        }
    }
}
cout << count;
6760

Sum or Product?

Choice structureRule
Choosing from case A or case BAdd
Choosing from A then choosing from BMultiply

For example:

  • Choosing one pen out of 4 pens or one notebook out of 3 notebooks gives us 4+3=7 choices.
  • Choosing one pen out of 4 pens together with one notebook out of 3 notebooks gives us 4·3=12 choices.

The words or and with are useful hints, but what matters most is determining whether the possibilities are separate alternatives (one case chosen out of several) or successive choices (each choice built on top of the last).

Combining Both Rules

Suppose we want to travel from city A to city E through the following one-way road network. The numbers on the arrows represent the number of different roads between each pair of cities:

There are 3·2=6 ways to reach C through B, and 2·4=8 ways to reach it through D. These are two separate cases, so the number of ways to reach C is:

3·2 + 2·4 = 14

And from C there are 5 choices for the last road to E. So the number of ways from A to E is:

(3·2 + 2·4)·5 = 70

combined_rule_check.cpp
int waysToB = 3;
int waysToD = 2;
int waysToC = waysToB * 2 + waysToD * 4;  // through B or through D (we add)
int waysToE = waysToC * 5;                // then to E (we multiply)
cout << waysToE;
70

In general: we multiply the numbers of choices within each case (successive choices), then add the results of the separate cases (independent alternatives). This principle comes up often in counting problems in competitive programming.

Glossary of Terms

The most important terms from this lesson, along with a short gloss:

Counting problemHow many ways?

A problem asking for the number of choices or elements that satisfy certain conditions.

Sum RuleAdd the cases

We add the numbers of possibilities when a choice is made from one out of several separate cases.

Product RuleMultiply the choices

We multiply the numbers of possibilities when an outcome requires several successive choices.

Disjoint casesNo overlap

Cases that don't overlap with each other, meaning no element belongs to more than one case.

Sequential choicesOne after another

A series of choices, each built on top of the previous one, to form a single outcome.

CombinatoricsThe math of counting

A branch of mathematics concerned with counting and arranging elements and possibilities.
