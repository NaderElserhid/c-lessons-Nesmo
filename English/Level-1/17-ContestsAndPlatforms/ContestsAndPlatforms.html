Contests and Platforms — Your First Steps in Competitive Programming

What Is Competitive Programming?

Competitive Programming (CP) is a mental sport based on solving precisely defined algorithmic problems within two strict limits: a Time Limit your program must not exceed, and a Memory Limit it must not exceed during execution.

No human grades your solution by hand; instead, an Online Judge — an automated program — runs your solution against dozens or hundreds of hidden test cases, comparing its output to the correct output for each test. If your solution passes every test within the allowed limits, it's considered Accepted.

This style of problem solving trains you in algorithmic thinking, writing correct and fast code, and handling edge cases you might not think of at first glance.

In this course we'll focus mainly on the Codeforces platform, since it's the platform the official exam will be held on. All upcoming exercises are designed to prepare you to solve competitive programming problems there specifically, so be sure to create your account and practice on it regularly.

Online Platforms

There are many websites known as an Online Judge, through which you can take part in real contests or solve problems purely for practice. The most notable ones are:

Codeforces

By far the most popular. It hosts weekly contests suitable for all levels, and has a huge library of problems for practice. This is our primary platform in this course.

USACO

Hosts contests roughly every two months, and contains problems aimed at more experienced competitors.

CSES

Doesn't host contests, but has an excellent, well-organized library of problems suited for learning different algorithmic topics.

Getting Started With Codeforces

In this section we'll discuss the detailed steps for creating an account on the Codeforces platform and solving your first problem on it.

1) Registration

After opening codeforces.com, click the Register button in the top corner of the page.

codeforces.com
Home Problemset Contests Gym

Fill in the required information and choose a strong password. Choose a username (handle) that represents your identity, keeping in mind you'll only be able to change it once a year.

You must register with your real email address, and using a temporary email is not recommended, since you'll need to verify the account through it later.

2) Verification

After completing registration, open your email to verify the account. Once you finish this step, you'll be able to log in successfully and start solving problems.

Problem Statement

This section describes the problem and its requirements. At the top, the problem's title appears along with the allowed time and memory limits.

The problem asks us to write a program that reads an integer w from input, and checks whether this number can be represented as the sum of two positive even integers a and b, then prints "Yes" or "No".

This section explains how to print the result: should the letters be uppercase or lowercase? Are outputs separated by spaces or newlines? And how many decimal places are required when dealing with decimal numbers?

The Wrong Idea

If we try a few numbers by hand, we might notice a pattern: if w is odd, it's impossible for the sum of a and b to be an odd number, because even + even = even. So our first idea might be: if w is odd print "No", otherwise print "Yes".

This idea is incorrect! The counterexample is w = 2; it's an even number, but it cannot be represented as the sum of two positive even numbers (the smallest possible representation is 2 + 2 = 4).

The Correct Approach

For any even number greater than 2, we can simply choose a = 2 and b = w - 2, and this approach will always work. As for odd numbers and the number 2, we've already shown it's impossible to satisfy the condition for them.

Translating the Idea into Code

Once we've reached the correct solution, we express it as code: first we read the input, then apply the logic, then print the output.

watermelon.cpp
#include <iostream>
using namespace std;

int main() {
    int w;
    cin >> w;

    if (w == 2 || w % 2 == 1) cout << "No";
    else cout << "Yes";
}
Input: 8 → Output: Yes Input: 3 → Output: No Input: 2 → Output: No

Submitting the Solution

At the top of the page, below the main bar, you'll find options like Statement, Submit, and My Submissions. Clicking Submit takes you to the submission page.

Interactive Lab: Try Submitting a Solution Yourself

#include <iostream>
using namespace std;

int main() {
    int w;
    cin >> w;

    if (w == 2 || w % 2 == 1) cout << "No";
    else cout << "Yes";
}

The default language setting is usually C, not C++, which causes beginners to get a Compilation Error on their first attempt. Always make sure to select a correct version of C++, such as GNU C++17, before clicking Submit.

After that, copy your code and paste it into the Source code field, then click Submit. You'll be redirected to the Submissions page, which shows the verdict for your submission.

Possible Verdicts

Accepted The solution passed all the tests successfully.
Wrong Answer The solution printed an incorrect result on one of the tests.
Time Limit Exceeded The solution took longer than the allowed time.
Memory Limit Exceeded The solution used more memory than the allowed limit.
Runtime Error An error occurred while the program was running (such as division by zero or going out of an array's bounds).

Usually you can't see the exact test your program failed on, since it might be too large or hidden by the contest organizers. So the real challenge is discovering the bug yourself by thinking through edge cases your solution might fail on.

Glossary of Terms

The most important terms you'll encounter on Codeforces, along with a short gloss:

Online JudgeAutomated grader

An automated system that runs your solution against hidden tests and determines its correctness automatically.

HandleUsername

The name your account appears under on the platform, which can only be changed once a year.

RatingDifficulty score

A number that measures the difficulty of a problem, or a competitor's skill level, in multiples of 100.

VerdictJudging result

The final judgment the judge gives your solution, such as Accepted or Wrong Answer.

AcceptedPassed

The solution passed all the tests within the allowed time and memory limits.

Time Limit ExceededToo slow

The solution is logically correct but too slow compared to the allowed time limit.

Compilation ErrorBuild failure

The code doesn't follow the rules of the selected language correctly, so it fails before it even runs — often due to selecting the wrong language.
