What does every C++ program consist of?

Before we write complex programs, we first need to understand the general structure that repeats in every C++ program. Let's look at the simplest possible program, then break down its components line by line.

main.cpp 
#include <iostream>

using namespace std;

// Your first program!

int main() {
    cout << "Hello, World!";
    return 0;
}

When you run this program, the following result will appear on the screen:

Core Components

1

Preprocessor commands

These start with the # symbol, like #include <iostream>, and tell the compiler to add extra files or tools before the program is compiled.

2

Namespaces

We often write using namespace std;. You don't need to understand namespaces deeply right now — just add this line to your early programs so you can use cout and cin easily.

3

The main() function

This is the point where program execution begins. The computer executes the instructions inside the braces { ... } from top to bottom.

4

Curly braces { }

Used to group a set of instructions into a single block. You'll see them later in functions, loops, and conditional statements.

5

The semicolon ;

Every instruction ends with a semicolon. Forgetting it causes an error at compile time, and it's one of the most common mistakes beginners make.

6

The return statement

The line return 0; ends the program's execution, indicating that it finished successfully with no errors.

Comments

Comments are notes written by the programmer that the computer completely ignores during execution. Their purpose is to clarify what parts of the program do, and you'll use them a lot to explain what the code does and remind yourself — or someone else — of its purpose later.

comments.cpp
// This is a single-line comment

/*
This is a comment
spanning several consecutive lines
*/

Extra example: printing more than one line

Let's apply what we've learned in a new example that uses cout several times, along with the word endl, which means moving to a new line after printing:

welcome.cpp 
#include <iostream>
using namespace std;

int main() {
    // Print a welcome message on two lines
    cout << "Welcome to C++!" << endl;
    cout << "This is my second line." << endl;
    return 0;
}

The output on the screen will be:

Welcome to C++!
This is my second line.

Notice the difference: without endl, each cout statement would print directly next to the previous one on the same line.

Indentation and Readability

It's always best to indent inside braces { } using a Tab or 4 spaces, because this makes the code clearer and easier to read. Formatting a program doesn't change how it runs, but it matters a great deal for reading and maintaining it later.

Good style
int main() {
    cout << "Good style matters!";
}
Bad style
int main(){
cout<<"Hard to read";
}

Creating a Project and Running Your First Program

1

New project

From the main menu: File → New → Project → Console application, then choose C++ and click Next.

2

Naming the project

Enter a name such as HelloWorld, choose a folder to save it in, then click Finish. Code::Blocks will create a file named main.cpp.

3

Writing the program

Open main.cpp and replace its entire contents with the Hello World program shown above.

4

Build and run

Click the Build and run button (the green triangle) or press F9. You should see the result Hello, World!.

What actually happens? When you click Build, Code::Blocks calls the compiler (MinGW on Windows or Clang on macOS), which turns the source code into an executable (binary) file that the operating system can run directly — usually with a .exe extension on Windows. Later you'll learn in more detail about the compiler, the linker, and build settings; for now, it's enough to understand the general idea.

Glossary of Terms

Here are the most important terms that appeared in this lesson, along with a short gloss, so you get comfortable using them with confidence:

PreprocessorPre-compilation stage

A stage that runs before compilation, executing commands that start with #.

NamespaceA named scope

A set of names (functions, variables) grouped under one scope to avoid naming conflicts.

FunctionA named block of code

A set of instructions grouped under one name to perform a specific task.

main()The program's entry point

The starting point where the computer executes the first instruction in the program.

CompilerSource-to-binary translator

A program that turns source code into an executable file the computer understands.

CommentA note ignored by the compiler

A text note written by the programmer that the computer ignores during execution.

IndentationConsistent code spacing

Formatting code with consistent spacing to improve clarity and readability.

IDEIntegrated Development Environment

A program that combines a code editor, compiler, and run tools in one place.

CompileTranslating source to machine code

The process of turning source code into an executable file.

LinkerCombines compiled pieces

A tool that links the compiled parts of a program together to produce the final executable.

BuildCompile + link, end to end

The full process from compiling to linking that produces a runnable program.

Executable / BinaryA ready-to-run program file

The finished file that the operating system can run directly.

endlEnd line (new-line insertion)

Short for "end line," used with cout to move to a new line.

Console applicationA text-only terminal program

A program that runs through a simple text window (terminal) with no graphical interface.
