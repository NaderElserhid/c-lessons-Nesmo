Generating Subsets Using Bitmasks

In the previous two chapters we learned how to check, set, and clear a single bit. Now we'll use this skill to solve a bigger problem: how to generate every possible subset of a small array, using just a single binary number for each subset.

What Is a Subset?

A subset of any array is a collection formed from some of the array's elements (possibly none at all). For example, for the array {1, 3, 5, 6, 7}:

  • {1, 3}, {3, 5, 7}, and {1, 3, 5, 6, 7} are all valid subsets of the array.

  • {1, 4} and {2, 7} are not subsets, because the elements 4 and 2 don't actually exist in the array.

Encoding Subsets as Binary Numbers

For an array of length n, every subset can be represented using a binary number made of n bits, where each array element has a corresponding bit in the binary number:

  • Bit value 1 ⇔ the corresponding element is included in the subset.

  • Bit value 0 ⇔ the corresponding element is not included in the subset.

Example: the array {5, 3, 1} (where a[0]=5, a[1]=3, a[2]=1). The binary encodings for all its subsets:

{3}0102

{5, 3, 1}1117

Notice that bit number j (from the right, starting at 0) always corresponds to element a[j], not its value. Bit number 0 always corresponds to a[0], regardless of what a[0]'s value actually is.

The Number of Subsets

Number of subsets for an array of length n = 2ⁿ

This makes sense: each element of the array has only two choices — either being inside the subset or outside it — and since we have n independent elements, the number of possible combinations is 2 × 2 × ... × 2 (repeated n times) = 2ⁿ. For an array of 3 elements, this gives us exactly 2³ = 8 subsets, as we saw in the table above.

Generating All Subsets

Since every subset corresponds to exactly one integer between 0 and 2ⁿ - 1, we can simply loop through all these integers, and generate each subset by checking its bits one by one.

The following program prints every subset of the array a, each on a separate line:

subsets.cpp
#include <iostream>
using namespace std;

int main() {
    int n = 3;
    int a[3] = {5, 3, 1};

    for (int i = 0; i < (1 << n); i++) {   // loops through every number from 0 to 2^n - 1
        cout << i << ": ";
        for (int j = 0; j < n; j++) {        // iterates over every bit of the number i
            bool set = (i & (1 << j)) != 0;  // checks whether bit j in i equals 1
            if (set) {
                cout << a[j] << ' ';
            }
        }
        cout << endl;
    }
}
0: 1: 5 2: 3 3: 5 3 4: 1 5: 5 1 6: 3 1 7: 5 3 1

  • The outer loop picks every number i from 0 to 2ⁿ - 1 — each value of i represents a different subset.

  • The inner loop checks every bit j from 0 to n-1 in i, and adds a[j] to the printed output only if that bit is set.

Common Mistakes

1) Using <= Instead of <

If you wrote for (int i = 0; i <= (1 << n); i++), the program would run one extra time at i = 2ⁿ, a number that actually needs n+1 bits to represent — meaning it isn't a valid encoding for any subset of an array of length n. The correct bound is always i < (1 << n).

2) Confusing the Bit Number with the Element's Value

Remember that bit number j corresponds to the position of element a[j], not its value. Printing j instead of a[j] is a common mistake when rushing to write the inner loop.

3) Overflow with Large n

If n is large (say 31 or more), then 1 << n using the type int (32 bits) overflows and becomes a negative number:

overflow.cpp
int n = 31;
cout << (1 << n);  // prints -2147483648 instead of 2147483648 !

Even more dangerously: if you used this in the loop condition for (int i = 0; i < (1 << n); i++), the condition 0 < -2147483648 is false from the very start, so the loop stops executing immediately without any compilation error or clear warning — you simply get no output at all! To avoid this, use long long: 1LL << n.

Quick Summary

Every subset of an array of length n is encoded by an n-bit binary number, where bit j means "is a[j] included?"
The total number of subsets is 2ⁿ.
We generate all subsets by looping over every i from 0 to 2ⁿ-1, and checking the bits of i one by one.
Careful: use < and not <=, and watch out for int overflow when n is large.

Homework

1) Decode It

The array a = {2, 4, 6, 8} (i.e. a[0]=2, a[1]=4, a[2]=6, a[3]=8). What subset does the encoding mask = 11 represent?

11 in binary (on 4 bits) = 1011, meaning bits 0, 1, and 3 are set (bit 2 is not set).

mask=11 (1011) -> a[0]=2, a[1]=4, a[3]=8 Subset: {2, 4, 8}

2) Encode It

For the same array a = {2, 4, 6, 8}, what decimal encoding (mask) represents the subset {4, 8}?

4 is a[1] and 8 is a[3], so we set bits 1 and 3: (1<<1) | (1<<3) = 0010 | 1000 = 1010.

encode {4, 8} -> mask = 10 (1010)

3) Find the Silent Bug

A classmate wrote the following code to generate all subsets of a large array of 31 elements, but got no output at all even though the code compiled successfully without any warning:

find_error3.cpp
int n = 31;
for (int i = 0; i < (1 << n); i++) {
    // ... generate subset number i ...
}

Why does no output appear? And how do you fix the problem?

1 << 31 with type int (32 bits) overflows and becomes -2147483648 (a negative number) instead of 2147483648. This makes the loop condition 0 < -2147483648 false from the very start, so the loop never runs even once — with no error message at all.

1 << 31 (int) = -2147483648 1LL << 31 (long long) = 2147483648 (correct)

The fix: use long long for the upper bound, such as for (long long i = 0; i < (1LL << n); i++). (Side note: in practice, looping 2³¹ times is extremely slow; this trick only works for small values of n, as we'll see later when studying the limits of this approach.)

SubsetSubset

A collection made up of some (or all, or none) of a given array's elements.

BitmaskBitmask
