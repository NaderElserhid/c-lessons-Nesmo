Structs (struct)

So far you've stored every piece of information in a separate variable. But what if you want to group several related pieces of information together — like a product's weight and price — under one name? In this chapter you will learn how to design your own custom data type using struct, a fundamental building block you'll need often in the bigger problems ahead.

What Is a struct?

In C++, a struct (struct) lets you group several pieces of data together under a single name. You can think of it as a custom data type that you design yourself.

A struct groups a set of related variables (called members), which may be of different types, inside the same entity.

General Syntax

struct_syntax.cpp
struct TypeName {
    member_type1 member_name1;
    member_type2 member_name2;
    // ...
};

  • TypeName → the name of the new data type you're defining.

  • Inside the curly braces { } → the members, which are the variables that belong to this type.

Notice the semicolon ; after the final closing brace } — forgetting it is one of the most common mistakes when writing a struct for the first time, and we'll see the actual error message later in this chapter.

Example: the product Struct

product.cpp
#include <iostream>
using namespace std;

struct product {
    int weight;     // in grams
    double price;   // in riyals
};

int main() {
    product apple;
    product banana, melon;

    apple.weight = 150;
    apple.price  = 1.99;

    banana.weight = 120;
    banana.price  = 0.99;

    cout << "Apple: "  << apple.weight  << " g, " << apple.price << " SAR" << endl;
    cout << "Banana: " << banana.weight << " g, " << banana.price << " SAR" << endl;
}

In this example:

  • We defined a new type called product.

  • This type has two members: weight of type int representing the weight in grams, and price of type double representing the price in riyals.

  • We then created variables (objects) of this type: apple, banana, and melon, and gave each one its own values.

Apple: 150 g, 1.99 SAR Banana: 120 g, 0.99 SAR

Member Access

We use the dot operator . to access the members of an object:

  • apple.weight → a member of type int

  • apple.price → a member of type double

You can read from these members or modify them just like any ordinary variable.

Declaring Objects Right After the Struct Definition

You can also declare variables right at the end of the struct definition:

product_inline.cpp
struct product {
    int weight;
    double price;
} apple, banana, melon;

Here: product is the type's (struct's) name, and apple, banana, melon are variables (objects) of this type — exactly as if you had written them on a separate line after the struct definition.

To access the weight member in the apple object, we write apple-weight.

A semicolon ; must be placed after the final closing brace in a struct definition.

Every object of type product (like apple and banana) has its own copy of the members weight and price.

Why Use Structs?

Without struct, we'd have to store every piece of information about every product in completely separate variables, which quickly becomes messy as the number of products or properties grows:

Without structWith struct
int appleWeight; double applePrice;
int bananaWeight; double bananaPrice;		product apple; product banana;
Two separate variables per product, with no clear link between them in the codeA single object that groups all the product's properties, with the relationship immediately clear

The core idea: struct makes the code closer to the way we think — instead of "the apple's weight" and "the apple's price" as two separate variables, we think of "the apple" as a single object that has properties.

Common Mistakes

Forgetting the semicolon after the struct definition: this code fails to compile:

missing_semicolon.cpp
struct product {
    int weight;
    double price;
}  // we forgot the ; here!

int main() {
    return 0;
}
error: expected ';' after struct definition

Relying on uninitialized members: in the product example above, the object melon was created but we never assigned any value to its members. If we tried to print melon.weight now, we'd get an unexpected garbage value already sitting in memory — not necessarily zero.

Always make sure to assign a value to every member before using it, exactly as you would with any ordinary variable.

Confusing the type name with the variable name: product is the name of the type (the template), while apple is an actual variable (object) of that type. You cannot write product.weight directly — product itself is not an object, it's the type from which objects are built.

Activity: Quick Review of Common Mistakes and Benefits

Determine whether each statement is true or false.

Forgetting the semicolon after a struct definition causes no compilation problems.

An object whose members were never assigned a value holds unexpected garbage values.

You can write product.weight to access a member without creating an object first, since product is a data type.

Using struct makes grouping related data clearer compared to separate variables.

Quick Summary

struct groups several variables (members) of possibly different types under a single type name you design yourself.
We access an object's members with the dot operator ., like apple.weight.
Objects can be declared on a separate line, or right after the struct definition.
Don't forget the semicolon after }, and always make sure to initialize every member before using it.

Homework

1) A Student Struct

Define a struct Student containing name (a string), age (an integer), and gpa (a decimal number). Create an object named student1 with the values: name "Sara", age 17, GPA 3.8, then print it in the form: name, age years old, GPA: gpa.

student.cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int age;
    double gpa;
};

int main() {
    Student student1;
    student1.name = "Sara";
    student1.age = 17;
    student1.gpa = 3.8;

    cout << student1.name << ", " << student1.age
         << " years old, GPA: " << student1.gpa << endl;
}
Sara, 17 years old, GPA: 3.8

3) Trace the Program

Without running the code, determine what the final lines will print:

trace_item.cpp
struct Item {
    int id;
    double cost;
};

int main() {
    Item a, b;
    a.id = 1;
    a.cost = 10.5;
    b.id = 2;
    b.cost = 20.0;

    a.cost = b.cost + 5;

    cout << a.id << " " << a.cost << "\n";
    cout << b.id << " " << b.cost << "\n";
}

The line a.cost = b.cost + 5; only changes the cost member in object a (it becomes 20.0 + 5 = 25), and has no effect at all on object b — since each object has its own independent copy of the members.

Glossary

structstruct

A keyword in C++ used to define a new data type that groups several members under one name.

MemberMember

A variable that sits inside a struct definition, belonging to every object created from that type.

Object / InstanceObject / Instance

An actual variable created from a struct type, holding its own copy of every member.

Dot Operator (.)Dot Operator (.)

The symbol used to access a member inside an object, such as apple.weight.

Type DefinitionType Definition

The description of the data structure (member names and types) that every later object is built from.

UninitializedUninitialized

Describes a member or variable that has not yet been assigned any value, so it holds a random value from memory.
