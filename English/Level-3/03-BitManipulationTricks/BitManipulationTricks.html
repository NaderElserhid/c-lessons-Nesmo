Bit Manipulation Tricks

In the previous chapter you learned the fundamental bitwise operations: & | ^ ~ << >>. Now we'll combine these operations to build ready-made, very fast tricks: how to check a single bit, how to change it, and how to take advantage of a curious property of subtraction to remove or isolate a specific bit in one shot.

Setup: Variables and Masks

Throughout this chapter we'll assume we have two variables:

setup.cpp
int x;       // a non-negative integer
int k;       // the bit number (0-based), where k=0 is the least significant bit (LSB)

We'll rely heavily on the mask 1 << k, a number in which only bit number k equals 1 and everything else is zero. All the tricks in this chapter are simply different combinations of this mask with the operators &, |, ^, ~.

Checking Whether Bit k Equals 1

bool isSet = (x >> k) & 1;

  • x >> k → a right shift so that bit number k moves all the way to the rightmost position.

  • (x >> k) & 1 → keeps only the rightmost bit and clears all the rest.

  • The result is 0 or 1, equivalent logically to false or true.

Example

check_bit.cpp
int x = 10;     // 10 = 1010 (in binary)
int k = 1;

bool isSet = (x >> 1) & 1; // 1010 >> 1 = 101;  101 & 1 = 1 (true)
isSet = 1 (true)

Setting Bit k to 1

x |= (1 << k);

  • The | operator sets a bit to 1 if at least one of the two sides has a 1.

  • This forces bit number k to become 1, while all other bits stay unchanged.

Example

set_bit.cpp
int x = 4;      // 0100
x |= (1 << 0);  // 0100 | 0001 = 0101 (5)
x = 5

Clearing Bit k (Setting It to 0)

x &= ~(1 << k);

  • 1 << k → a mask where bit number k equals 1.

  • ~(1 << k) → a mask where bit number k equals 0, and every other bit equals 1.

  • Performing & with this mask clears only bit number k, leaving everything else unchanged.

Example

clear_bit.cpp
int x = 13;         // 1101
x &= ~(1 << 2);     // ~(0100) = ...11111011
                    // 1101 & 1011 = 1001 (9)
x = 9

Toggling (Flipping) Bit k

x ^= (1 << k);

The ^ (XOR) operator flips a bit wherever the mask has a 1:

Original bitXOR 1Result
011
110

Example

toggle_bit.cpp
int x = 5;     // 0101
x ^= (1 << 2); // 0101 ^ 0100 = 0001 (1)
x = 1

Removing the Lowest Set Bit

This is a very famous trick:

x = x & (x - 1);

This line removes (clears) the lowest set bit — that is, the first 1 from the right — in x.

Why Does This Trick Work?

Think about what happens to the bits when we subtract 1:

  • When we perform x - 1, we walk from the right until we find the first bit whose value is 1.

  • This lowest set bit (the closest 1 to the right) flips to 0.

  • Every bit to its right (which was 0) flips to 1 (because of the borrowing in subtraction).

So around the lowest set bit, the pattern looks like this:

pattern
x:       .... 1 0 0 0 0
x - 1:   .... 0 1 1 1 1

When we perform AND:

and_pattern
x        = .... 1 0 0 0 0
x - 1    = .... 0 1 1 1 1
-------------------------
x&(x-1)  = .... 0 0 0 0 0

  • The lowest set bit becomes 0 because 1 & 0.

  • Every bit to its right was 0 in x, so it gives 0 & anything = 0 regardless of x-1.

  • Every bit to its left is unaffected, since the subtraction never changed it; it stays the same after AND.

Example

remove_lowest.cpp
x           = 12 = 1100
x - 1       = 11 = 1011
x & (x - 1) =  8 = 1000
The lowest set bit (bit number 2) was removed, and the result = 8

Checking Whether x Is a Power of Two

Assuming x is a positive number, we use the previous trick directly:

bool isPowerOfTwo = (x & (x - 1)) == 0;

Why Does This Trick Work?

  • A number that is a power of two in binary (1, 10, 100, 1000, …) has exactly one bit set.

  • Performing x & (x - 1) removes the lowest set bit.

  • If there was only one bit set, removing it makes the value 0.

So: x & (x - 1) == 0 ⇔ x has exactly one bit set (i.e. is a power of two).

Examples

xbinaryx & (x-1)Result
810000000Power of two ✓
1211001000Not 0 → not a power of two

Getting Only the Lowest Set Bit

int lowest = x & -x;

Here -x is the two's complement of x — exactly what we learned in the previous chapter (flip all the bits, then add 1).

The idea: the expression x & -x isolates the lowest set bit (the first 1 from the right) and clears every other bit.

Example

isolate_lowest.cpp
x                      = 12 = ...00001100
-x (two's complement)      = ...11110100
x & -x                     = ...00000100 = 4
The lowest set bit in x represents the value 4 (i.e. bit number 2)

Find the Bug: && Is Not & !

Look at this function, which is supposed to check whether bit number k in n equals 1:

buggy_kth_bit.cpp
bool kthBitIsSet(int n, int k) {
    return (n >> k) && 1;   // !! this is a bug !!
}

This code does not work correctly. Try it with n = 10 (i.e. 1010):

kActual bit number k in 1010(n >> k) && 1
00true (wrong!)
11true
20true (wrong!)
31true

Why? Because && is a logical operator (logical AND), not a bitwise operator (bitwise AND). The expression (n >> k) && 1 means: "is n >> k nonzero?" — and this is true as long as any bit anywhere in n >> k is set, not necessarily just the last bit.

The fix: use & (a single bitwise operator) instead of &&: return (n >> k) & 1;

Confusing & with && (and likewise | with ||) is one of the most common mistakes when starting out with bit tricks — always make sure to use the bitwise operator when working with individual bits.

Homework

1) Trace a Sequence

We have x = 6 (i.e. 0110). Apply the following sequence in order and determine the value of x after each step: (a) set bit number 0, (b) clear bit number 1, (c) toggle bit number 2.

trace.cpp
int x = 6;          // 0110
x |= (1 << 0);      // 0110 | 0001 = 0111 = 7
x &= ~(1 << 1);     // 0111 & 1101 = 0101 = 5
x ^= (1 << 2);      // 0101 ^ 0100 = 0001 = 1
After (a): x = 7 (0111) After (b): x = 5 (0101) After (c): x = 1 (0001)

2) Find the Bug in the Removal Trick

A classmate wrote the following code to remove the lowest set bit from y = 12, but picked the wrong operator:

find_error2.cpp
int y = 12;
y = y | (y - 1);   // supposed to remove the lowest set bit

What's wrong? And what is the actual result compared to the correct result?

The mistake is using | (OR) instead of & (AND). The OR operation removes no bits at all — on the contrary, it may add new bits.

y | (y - 1) = 1100 | 1011 = 1111 = 15 (incorrect) y & (y - 1) = 1100 & 1011 = 1000 = 8 (correct)

The fix: use y = y & (y - 1);

Glossary

MaskMask

A binary number specially designed to isolate or modify specific bits when combined with a bitwise operator.

LSB (Least Significant Bit)LSB (Least Significant Bit)

The rightmost bit in a binary representation, representing the value 2^0.

Set a bitSet a bit

Making a specific bit's value equal 1 using | with an appropriate mask.

Clear a bitClear a bit

Making a specific bit's value equal 0 using & with an inverted mask (~).

Toggle a bitToggle a bit

Flipping a specific bit's value (from 0 to 1 or vice versa) using ^.

Lowest set bitLowest set bit

The first bit from the right whose value is 1 in a number's binary representation.

Power of twoPower of two

A number that has exactly one bit set in its binary representation, such as 1, 2, 4, 8, 16.

Logical AND (&&) vs Bitwise AND (&)Logical AND (&&) vs Bitwise AND (&)

&& checks "zero or not" for the entire value, while & operates bit by bit — confusing the two is a common and dangerous mistake.
