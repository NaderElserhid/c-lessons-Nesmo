Maps

Now that you've learned how to store unique values using a set, it's time to learn how to link each value to extra information using a map. In this chapter you'll discover how data is stored as key-value pairs, how to avoid the most common trap beginners fall into when accessing elements, and you'll use what you learn to build practical tools like a word-frequency counter.

What is a map?

A map is a container in C++ that stores pairs of elements in this form: key -> value, and sorts them by key automatically.

map_intro.cpp
#include <iostream>
#include <map>
using namespace std;

int main() {
    map<string, int> ages;
    ages["Alice"] = 25;
    ages["Bob"] = 30;
    ages["Charlie"] = 22;

    for (auto p : ages)
        cout << p.first << ": " << p.second << endl;
}
Alice: 25 Bob: 30 Charlie: 22

Notice that the names were printed in alphabetical order, even though we inserted them in a different order — because map sorts keys automatically.

Creating a map

To use a map, add the following header:

#include <map>

Then you can declare it in several ways depending on the key and value types:

map_declare.cpp
map<int, string> students;     // key: int, value: string
map<string, double> prices;    // key: string, value: double
map<char, int> frequency;      // key: char, value: int

Adding and Accessing Elements

map_access.cpp
map<string, int> scores;
scores["Mark"] = 90;          // add using []
cout << scores["Mark"];       // prints 90
90

If you try to access a key that doesn't exist using [], it will be created automatically with a default value (like 0 for integers), even if you only intended to read it and not modify it!

cout << scores["Unknown"]; — creates the key "Unknown" with value 0, and it becomes an actual part of the map from now on.

If you don't want this behavior, use count() to check first whether the key exists without creating it:

safe_check.cpp
if (scores.count("Tom"))
    cout << "Tom found!";

Example: Counting Word Frequency

One of the most common uses of a map is counting how many times each element (word, character, number...) appears within certain data:

word_frequency.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    string text = "apple banana apple orange banana apple";
    map<string, int> freq;
    string word;

    for (auto c : text) {
        if (c == ' ') {
            if (!word.empty()) freq[word]++;
            word.clear();
        } else {
            word += c;
        }
    }
    if (!word.empty()) freq[word]++; // last word

    for (auto p : freq)
        cout << p.first << ": " << p.second << endl;
}
apple: 3 banana: 2 orange: 1

Notice the elegant trick here: freq[word]++ takes advantage of the automatic-creation-with-0 behavior — the first time a word appears, map creates an entry for it with value 0 and then immediately increments it to 1, with no extra code needed to check whether it already existed!

Iterating Over a Map

You can iterate using a range-based for loop:

range_based.cpp
for (auto p : myMap)
    cout << p.first << " -> " << p.second << endl;

Or using iterators:

iterator.cpp
for (auto it = myMap.begin(); it != myMap.end(); it++)
    cout << it->first << ": " << it->second << endl;

first = the key, and second = the value, whether you use p.first or it->first.

Example: unordered_map

unordered_map_demo.cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    unordered_map<string, int> age;
    age["Bob"] = 30;
    age["Alice"] = 25;
    age["Tom"] = 28;

    for (auto p : age)
        cout << p.first << ": " << p.second << endl;
}
(the order may be random, for example) Tom: 28 Alice: 25 Bob: 30

So unordered_map is usually faster, but it doesn't sort keys — use it only when you don't care about output order.

Additional Examples

Additional Example 1: Finding the Key with the Largest Value

We can go through the map's elements and keep track of the largest value we've seen so far along with its key:

find_max.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> ages;
    ages["Alice"] = 25;
    ages["Bob"] = 30;
    ages["Charlie"] = 22;

    string bestName = "";
    int bestAge = -1;
    for (auto p : ages) {
        if (p.second > bestAge) {
            bestAge = p.second;
            bestName = p.first;
        }
    }

    cout << bestName << " is the oldest at " << bestAge;
}
Bob is the oldest at 30

Additional Example 2: Modern Iteration Using Structured Bindings

In C++17 and later, you can unpack the pair p.first and p.second directly into two clear names, making the code easier to read:

structured_bindings.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> ages = {{"Alice", 25}, {"Bob", 30}, {"Charlie", 22}};

    for (auto& [name, age] : ages)
        cout << name << " -> " << age << endl;
}
Alice -> 25 Bob -> 30 Charlie -> 22

Homework Exercises

1) Count the Frequency of Each Character in a Text

Read a line of text, and print how many times each character appears in it (excluding spaces), using map<char, int>.

hw1.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    string text;
    getline(cin, text);

    map<char, int> freq;
    for (char c : text) {
        if (c != ' ') freq[c]++;
    }

    for (auto p : freq)
        cout << p.first << ": " << p.second << endl;
}
Input: aabbbc Output: a: 2 b: 3 c: 1

2) Checking for a Key Without Accidentally Creating It

We have map<string, int> stock containing some products. Read a number of queries, and for each one print "Yes" if the product exists in stock or "No" if it doesn't — without the query itself accidentally adding the product.

hw2.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> stock;
    stock["apple"] = 10;
    stock["banana"] = 5;

    int q;
    cin >> q;
    while (q--) {
        string item;
        cin >> item;
        if (stock.count(item))  // count() doesn't create the key, unlike []
            cout << "Yes" << endl;
        else
            cout << "No" << endl;
    }

    cout << "Final size: " << stock.size();
}
Input: 3 / apple mango banana Output: Yes No Yes Final size: 2

3) Merging Two Maps

We have two maps a and b representing element frequencies from two different sources. Combine them into a single map merged, such that if the same key repeats in both maps, its two values are added together.

hw3.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> a = {{"apple", 3}, {"banana", 2}};
    map<string, int> b = {{"banana", 4}, {"cherry", 1}};

    map<string, int> merged = a;
    for (auto p : b) {
        merged[p.first] += p.second; // creates the key with value 0 first if it doesn't exist, then adds
    }

    for (auto p : merged)
        cout << p.first << ": " << p.second << endl;
}
apple: 3 banana: 6 cherry: 1

Glossary

MapMap

A container that stores key-value pairs, automatically sorted by key.

KeyKey

The unique identifier used to access the value associated with it.

ValueValue

The data stored and associated with a given key.

Unordered_mapUnordered Map

Like map but with no guaranteed order, and faster on average via hashing.

pairPair

The basic unit inside a map, containing first (the key) and second (the value).

Structured BindingsStructured Bindings

A C++17 feature that lets you unpack a pair or struct into separate, clearly named variables.
