Sorting

In the last chapter you learned how to measure the speed of algorithms using Big O notation, and saw that algorithms like binary search only work on sorted data. In this chapter we'll learn how to actually sort data: first by hand with the Selection Sort algorithm, then the professional way that competitive programmers actually use — the built-in sort() function — and we'll compare the speed of both approaches numerically to see the real difference choosing the right algorithm makes.

What is sorting?

Sorting means rearranging the elements of a data set into a specific sequence, usually from smallest to largest (ascending), or alphabetically if the elements are text.

Sorting makes data easier to search, compare, and process efficiently. Many important algorithms — such as Binary Search, which you studied in the last chapter — only work correctly if the data is already sorted.

Remember that binary search runs in O(log n) time, but it assumes the array is already sorted. That's why sorting is often the "preparation step" before using much faster algorithms.

Selection Sort

The idea: Selection sort repeatedly finds the smallest element in the unsorted part of the array, and moves it to the beginning of that part.

Step by step

  • Find the smallest element in the entire array.

  • Swap it with the first element.

  • Find the smallest element in the remaining part, and swap it with the second element.

  • Continue the same way until the entire array is sorted.

Example

Suppose we have the array:

[5, 8, 3, 4, 2]

We find the smallest element, 2, and swap it with the first element 5. The array becomes:

[2, 8, 3, 4, 5]

Now we want to place the second-smallest element in the second position. We find the smallest among 8, 3, 4, 5, which is 3, and swap it with the second element 8. The array becomes:

[2, 3, 8, 4, 5]

We find the third-smallest element among 8, 4, 5, which is 4, and swap it with the third element 8:

[2, 3, 4, 8, 5]

In the final step, we find the fourth-smallest element among 8, 5, which is 5, and swap it with the fourth element 8:

[2, 3, 4, 5, 8]

The array is now fully sorted!

The Code

selection_sort.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {5, 8, 3, 4, 2};
    int n = arr.size();

    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex])
                minIndex = j;
        }
        swap(arr[i], arr[minIndex]);
    }

    for (int x : arr)
        cout << x << ' ';
    cout << '\n';
}
2 3 4 5 8

Selection sort is easy to understand, but it is not very efficient for large arrays.

Time Complexity

There are two nested loops: the outer one runs n times, and the inner one runs up to n times as well. So it takes roughly n² steps → time O(n²).

Using the Built-in sort Function

In real programs and in competitive programming, we rarely write sorting by hand. C++ provides a very fast sorting function in its standard library, inside <algorithm>.

Sorting a vector

sort_vector.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {5, 8, 3, 4, 2};
    sort(arr.begin(), arr.end());

    for (int x : arr)
        cout << x << ' ';
    cout << '\n';
}
2 3 4 5 8

The line sort(arr.begin(), arr.end()); sorts the entire vector in ascending order.

Sorting a regular array

The same sort can be used with regular arrays too:

sort_array.cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n = 5;
    int arr[] = {5, 8, 3, 4, 2};

    sort(arr, arr + n);

    for (int i = 0; i < n; i++)
        cout << arr[i] << ' ';
    cout << '\n';
}
2 3 4 5 8

sort(arr, arr + n); means: sort the array starting from arr up to arr + n (that is, right after the last element).

Sorting in Descending Order

If you want to sort from largest to smallest, use a custom comparison:

For a vector

sort_desc.cpp
sort(arr.begin(), arr.end(), greater<int>());
// or using reversed iterators:
sort(arr.rbegin(), arr.rend());

For a regular array

sort_desc_array.cpp
sort(arr, arr + n, greater<int>());

All three approaches produce, on the array {5, 8, 3, 4, 2}, the same result:

8 5 4 3 2

Sorting Other Types

The same function works with string, double, or any comparable type:

sort_strings.cpp
vector<string> names = {"Bob", "Alice", "Charlie"};
sort(names.begin(), names.end());

for (auto &s : names) cout << s << ' ';
Alice Bob Charlie

Notice that the default order for strings is alphabetical (lexicographic), not by length.

Sorting with a Custom Comparator

You can sort an array based on your own criteria by writing a comparator function that takes two elements a and b and returns true if a should come before b.

Example: Sorting Strings by Length

sort_comparator.cpp
bool comparator_by_length(string a, string b) {
    int len_a = a.length();
    int len_b = b.length();

    if (len_a < len_b)
        return 1;
    else
        return 0;
}

Then we use it with sort as a third argument:

use_comparator.cpp
vector<string> names = {"Bob", "Alice", "Charlie"};
sort(names.begin(), names.end(), comparator_by_length);

for (auto &s : names) cout << s << ' ';
Bob Alice Charlie

Notice the difference: while the default sort gave us Alice Bob Charlie (alphabetically), the length comparator gave us Bob Alice Charlie (from shortest, 3 letters, to 5 letters, to 7 letters).

Important note: a comparator function must behave like a real "less than" operation: it must not contradict itself, and must not contain cycles such as a < b then b < c then c < a all at once. If the comparator is inconsistent, the behavior of sort becomes undefined, and your program may crash.

C++'s built-in sort function only works with integers (int), and cannot be used with strings.

The Time Complexity of Sorting

The built-in sort function in the standard library uses an optimized algorithm (a mix of quicksort, heapsort, and insertion sort), with time complexity O(n log n) — much faster than the O(n²) of selection sort when n is large.

nSelection Sort O(n²)Built-in sort O(n log n)
10100≈ 33
10010,000≈ 664
1,0001,000,000≈ 9,966

At n = 1000: selection sort performs about 1,000,000 operations, while the sort function performs only about 10,000 operations — roughly 100 times faster! And the larger n gets, the wider the gap grows (recall the growth-rate comparison table from the last chapter).

That's why, in competitive programming, we almost always use the built-in sort function instead of writing selection sort by hand — it's faster and far less error-prone.

Homework Exercises

1) Sort in Descending Order Using a Comparator

You have the array {9, 1, 7, 3, 5}. Write code that sorts it in descending order using greater<int>().

hw1.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {9, 1, 7, 3, 5};
    sort(arr.begin(), arr.end(), greater<int>());
    for (int x : arr) cout << x << ' ';
}
9 7 5 3 1

2) Sort by First Letter Only

You have the array {"Cherry", "Apple", "Banana", "Date"}. Write a comparator function that sorts the strings by first letter only (not the whole string).

hw2.cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

bool cmpFirstLetter(string a, string b) {
    return a[0] < b[0];
}

int main() {
    vector<string> words = {"Cherry", "Apple", "Banana", "Date"};
    sort(words.begin(), words.end(), cmpFirstLetter);
    for (auto &w : words) cout << w << ' ';
}
Apple Banana Cherry Date

We only compare a[0] with b[0] instead of comparing the whole string.

3) Sort Students by Score in Descending Order

You have an array of pairs pair<string, int>, each representing (student name, score): {{"Ali",88}, {"Sara",95}, {"Omar",72}}. Sort it in descending order by score.

hw3.cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

bool cmpByScoreDesc(pair<string,int> a, pair<string,int> b) {
    return a.second > b.second;
}

int main() {
    vector<pair<string,int>> students = {{"Ali",88}, {"Sara",95}, {"Omar",72}};
    sort(students.begin(), students.end(), cmpByScoreDesc);
    for (auto &s : students)
        cout << s.first << ":" << s.second << "  ";
}
Sara:95 Ali:88 Omar:72

The comparator compares a.second with b.second (the score), and uses > instead of < to sort in descending order.

Glossary

SortingSorting

Rearranging the elements of a data set into a specific sequence, ascending or descending.

Selection SortSelection Sort

A sorting algorithm that finds the smallest remaining element and places it in its correct position, with O(n²) complexity.

sort()Built-in sort function

A function from the <algorithm> library in C++ that sorts any range with O(n log n) complexity.

ComparatorComparator

A custom function passed to sort to define the desired order between two elements.

Ascending / DescendingAscending / Descending

The direction of sorting: from smallest to largest, or from largest to smallest.

Lexicographic OrderLexicographic Order

The default order for strings in C++, character by character, like dictionary order.
