Sets

Now that you've mastered the fundamentals of C++ in Level 1, it's time to move on to the Standard Template Library (STL), which makes your life as a programmer much easier. In this chapter you'll meet the first STL container: the set, how you use it to store unique, automatically sorted values, and how you use it to solve real competitive-programming problems such as removing duplicates and finding intersections between sets.

What is a set?

A set is a container in C++ that stores values of the same type, and it has three key properties: every value appears exactly once (no duplicates), the values are always sorted (by default from smallest to largest), and you can quickly check whether an element exists in it.

set_intro.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> numbers = {5, 2, 9, 2, 1};
    for (int x : numbers)
        cout << x << " ";
}
1 2 5 9

Notice that the second 2 disappeared — because a set doesn't allow duplicate values — and notice too that the elements appear sorted in ascending order even though we inserted them in random order.

Creating a set

To use a set, add the following header:

#include <set>

Then you can create a set in several ways:

set_declare.cpp
set<int> mySet;              // empty set of integers
set<string> names;           // set of strings
set<char> letters = {'a','b','c'};

You can also initialize it with values directly using curly braces { }, just like we did with numbers above.

Example: Using a set

set_operations.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s;
    s.insert(3);
    s.insert(1);
    s.insert(4);
    s.insert(3); // duplicate ignored

    cout << "Elements: ";
    for (int x : s) cout << x << " ";
    cout << endl;

    if (s.count(3))
        cout << "3 is in the set" << endl;

    s.erase(1);
    cout << "After removing 1: ";
    for (int x : s) cout << x << " ";
}
Elements: 1 3 4 3 is in the set After removing 1: 3 4

Iterating Over Set Elements

You can go through the elements of a set using a range-based for loop or an iterator:

range_based.cpp
for (int x : s)
    cout << x << " ";

Or:

iterator.cpp
for (auto it = s.begin(); it != s.end(); it++)
    cout << *it << " ";

Since a set is always sorted, the elements will appear in the same ascending order no matter which method you use to go through them.

Types of Sets

TypeSorted?Allows Duplicates?Speed (approx.)Notes
setYesNoO(log n)Internally implemented with a balanced tree
multisetYesYesO(log n)Keeps multiple copies of the same value
unordered_setNoNoO(1) on averageUses hashing, faster but the order is random

If order matters — use set. If you need to store duplicates — use multiset. If speed is your only concern and order doesn't matter — use unordered_set.

Example: multiset allows duplicates

multiset_demo.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    multiset<int> ms = {4, 2, 2, 7, 4, 4};

    cout << "Elements: ";
    for (int x : ms) cout << x << " ";
    cout << endl;

    cout << "count(4) = " << ms.count(4) << endl;

    ms.erase(ms.find(4)); // erases only ONE occurrence of 4
    cout << "After erasing one 4: ";
    for (int x : ms) cout << x << " ";
}
Elements: 2 2 4 4 4 7 count(4) = 3 After erasing one 4: 2 2 4 4 7

Watch the difference: ms.erase(4) (passing the value directly) removes all copies of 4 from the multiset at once, while ms.erase(ms.find(4)) (passing an iterator) removes only one copy. This is an important difference that causes common bugs for beginners.

Example: Removing Duplicates

One of the most famous uses of a set is removing duplicate values from an array or vector quickly and simply:

remove_duplicates.cpp
#include <iostream>
#include <set>
#include <vector>
using namespace std;

int main() {
    vector<int> nums = {1, 2, 2, 3, 4, 3, 1};
    set<int> unique;

    for (int x : nums)
        unique.insert(x);

    for (int x : unique)
        cout << x << " ";
}
1 2 3 4

Additional Examples

Additional Example 1: Intersection of Two Sets

We can find the common elements between two sets by going through the elements of the first and checking whether they exist in the second using count():

intersection.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> a = {1, 2, 3, 4, 5};
    set<int> b = {3, 4, 5, 6, 7};

    set<int> common;
    for (int x : a) {
        if (b.count(x)) common.insert(x);
    }

    cout << "Common elements: ";
    for (int x : common) cout << x << " ";
}
Common elements: 3 4 5

Additional Example 2: Union of Two Sets

To find the union of two sets, we start with a copy of the first and then insert the elements of the second into it — the set will automatically ignore any duplicates:

union.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> a = {1, 2, 3};
    set<int> b = {3, 4, 5};

    set<int> merged = a;
    for (int x : b) merged.insert(x);

    cout << "Union: ";
    for (int x : merged) cout << x << " ";
}
Union: 1 2 3 4 5

Homework Exercises

1) Count Distinct Elements in an Array

Read an integer n then n integers, and print the number of distinct values among them (without repetition).

hw1.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    int n;
    cin >> n;

    set<int> s;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        s.insert(x);
    }

    cout << s.size();
}
Input: 7 / 1 2 2 3 4 3 1 → Output: 4

2) Remove a Specific Value if it Exists

We have set<int> s = {10, 20, 30, 40, 50};. Read a value target, remove it from the set if it exists, then print an appropriate message and the remaining elements.

hw2.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s = {10, 20, 30, 40, 50};
    int target;
    cin >> target;

    if (s.count(target)) {
        s.erase(target);
        cout << "Removed. Remaining: ";
    } else {
        cout << "Not found. Set stays: ";
    }

    for (int x : s) cout << x << " ";
}
Input: 20 → Removed. Remaining: 10 30 40 50 Input: 99 → Not found. Set stays: 10 20 30 40 50

3) Checking for Duplicate Words

Read an integer n then n words, and print "Yes" if there is a duplicate word, or "No" if all the words are distinct.

hw3.cpp
#include <iostream>
#include <set>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    set<string> seen;
    bool hasDuplicate = false;

    for (int i = 0; i < n; i++) {
        string word;
        cin >> word;
        if (seen.count(word)) hasDuplicate = true;
        seen.insert(word);
    }

    cout << (hasDuplicate ? "Yes" : "No");
}
Input: apple banana apple cherry banana → Yes Input: apple banana cherry → No

Glossary

SetSet

A container that stores unique, automatically sorted values.

MultisetMultiset

Like a set but allows the same value to repeat more than once.

Unordered_setUnordered Set

A set of unique elements but with no guaranteed order, faster on average via hashing.

InsertInsertion

Adding a new element to the container.

EraseDeletion

Removing an element (or the element an iterator points to) from the container.

IteratorIterator

A pointer-like object used to refer to an element's position inside a container and move between them.

Balanced TreeBalanced Tree

The internal data structure that set and multiset rely on to keep elements ordered and fast to access.

HashingHashing

A technique used internally in unordered_set to achieve fast access without needing to maintain order.
