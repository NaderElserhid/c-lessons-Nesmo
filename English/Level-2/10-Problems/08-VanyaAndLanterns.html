Vanya and Lanterns

A street of length l has lanterns at various positions, and each lantern lights up a distance d to its right and left. We need the smallest d that lights the whole street — and the solution relies on sorting and computing the largest gap between neighboring lanterns.

Medium Codeforces 492B

Problem Statement

You have a line (street) of length l, with n points (lanterns) at positions a₁, a₂, ..., a_n. Each point can "cover" a distance d to the left and d to the right, where d is a positive number shared by every lantern. Find the smallest d such that every point on the line from 0 to l is covered by at least one lantern.

Note: to print a double variable named x in decimal format, you can use: cout << fixed << x;

Constraints

  • 1 ≤ n ≤ 1000

  • 1 ≤ l ≤ 10⁹

  • 0 ≤ a_i ≤ l (more than one lantern can share the same position)

Examples

Input:
7 15
15 5 3 7 9 14 0
Output:
2.5000000000
Input:
2 5
2 5
Output:
2.0000000000

Solving Methodology: How Do We Think About This Problem?

  • Understand the problem: we want the smallest shared lighting radius that covers the whole street.

  • Try small examples by hand: try the second example, l=5 with lanterns 2, 5, yourself.

  • Look for a pattern: where does the hardest point to cover lie? Usually in the middle of the gap between two neighboring lanterns.

  • Do not forget the edges: the start and end of the street are covered by only one lantern from a single side, not from two sides.

  • Write the code and verify: sort the lanterns, then compute the largest of all these distances.

  • Check the edge cases: what if there is only a single lantern? Or two lanterns at the same position?

Step 1: The Key Insight

First, we sort the lanterns from left to right so their order in the array matches their actual positions on the line.

To guarantee full coverage of the line, every point must be covered by at least half the distance to its neighbor, which is (a[i+1] - a[i]) / 2 for every neighboring pair — because each of the two lanterns must cover half the gap between them (the midpoint of the gap is the farthest point from both).

The first lantern must also cover the distance from the start of the line (0) to itself, namely a[0], and the last lantern must cover the distance from itself to the end of the line, namely l - a[n-1].

The smallest d that guarantees full coverage of the line is the largest of all these distances.

Step 2: The Full Solution

vanya_and_lanterns.cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n, l;
    cin >> n >> l;

    int a[n];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    sort(a, a + n);

    double d = max(a[0] - 0, l - a[n - 1]);

    for (int i = 0; i < n - 1; i++) {
        d = max(d, (a[i + 1] - a[i]) / 2.0);
    }

    cout << fixed << d << "\n";
}
Input: 7 15 / 15 5 3 7 9 14 0 → Output: 2.500000
Input: 2 5 / 2 5 → Output: 2.000000

Step 3: Checking the Edge Cases

A single lantern (n=1): there are no gaps between lanterns, so the answer becomes the larger of the distance from the start to it and from it to the end of the street.

Lanterns at the same position: the gap between them equals zero, so it does not affect the result — the code handles this automatically with no special case.

Lanterns exactly at the street's ends: if a lantern sits at 0 or l, the corresponding edge distance becomes zero.

Notice the use of / 2.0 rather than / 2 — writing it as integer division would lose the decimal fraction (for example 5 / 2 = 2 instead of 2.5).

This problem is an excellent example of the power of sorting in simplifying seemingly complex problems: once the lanterns are sorted, the problem becomes simply "the largest gap between two neighboring elements" — a very common pattern in competitive programming problems.
