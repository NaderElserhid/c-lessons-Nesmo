$CATEGORY: المستوى الأول C++/الدوال

::سؤال 1: أجزاء الدالة::ما الأجزاء الأربعة الرئيسية لأي دالة في <bdi>C++</bdi>؟ {
=الاسم، المحتوى، المعاملات، نوع القيمة المرجعة
~الاسم، النوع، الحجم، العنوان
~المتغيّر، الثابت، الحلقة، الشرط
}

::سؤال 2: نوع القيمة الفارغة::ماذا يجب أن يكون نوع القيمة المرجعة إذا كانت الدالة لا تُرجع أي قيمة؟ {
=<bdi>void</bdi>
~<bdi>int</bdi>
~<bdi>null</bdi>
}

::سؤال 3: صياغة الدالة::في الصياغة التالية، ماذا يمثّل الجزء return_type؟<br><pre dir\="ltr">return_type function_name(parameters) \{ ... \}</pre> {
=نوع القيمة التي ترجعها الدالة (مثل <bdi>int</bdi> أو <bdi>void</bdi>)
~اسم الدالة الذي يُستخدم عند الاستدعاء
~عدد المعاملات فقط
}

::سؤال 4: استدعاء دالة::ما الصيغة الصحيحة لاستدعاء دالة في <bdi>C++</bdi>؟ {
=<bdi>function_name(value1, value2);</bdi>
~<bdi>call function_name();</bdi>
~<bdi>function_name;</bdi>
}

::سؤال 5: تتبّع دالة بدون معاملات::ما ناتج تنفيذ البرنامج التالي؟<br><pre dir\="ltr">void f() \{<br>    cout &lt;&lt; "Hello Function" &lt;&lt; endl;<br>\}<br>int main() \{<br>    f();<br>    cout &lt;&lt; "Hello Main" &lt;&lt; endl;<br>    f();<br>\}</pre> {
=<bdi>Hello Function<br>Hello Main<br>Hello Function</bdi>
~<bdi>Hello Main<br>Hello Function<br>Hello Function</bdi>
~<bdi>Hello Function<br>Hello Function<br>Hello Main</bdi>
}

::سؤال 6: المعاملات::في الكود التالي، ماذا يمثّل x وy؟<br><pre dir\="ltr">void multiply(int x, int y) \{<br>    cout &lt;&lt; x * y &lt;&lt; endl;<br>\}</pre> {
=معاملان (Parameters) يستقبلان قيمتين عند استدعاء الدالة
~متغيّران عامّان في البرنامج بأكمله
~اسما الدالة ونوعها
}

::سؤال 7: ترتيب تمرير القيم::عند استدعاء الدالة بالشكل التالي، ما القيمة التي تُسنَد إلى المعامل الأول؟<br><pre dir\="ltr">multiply(5, 3);</pre> {
=5
~3
~8
}

::سؤال 8: تمرير بالقيمة::ما قيمة n بعد تنفيذ الكود التالي؟<br><pre dir\="ltr">void addOneByValue(int x) \{<br>    x \= x + 1;<br>\}<br>int main() \{<br>    int n \= 5;<br>    addOneByValue(n);<br>    cout &lt;&lt; n;<br>\}</pre> {
=5
~6
~1
}

::سؤال 9: تمرير بالمرجع::ما قيمة n بعد تنفيذ الكود التالي؟<br><pre dir\="ltr">void addOneByReference(int &amp;x) \{<br>    x \= x + 1;<br>\}<br>int main() \{<br>    int n \= 5;<br>    addOneByReference(n);<br>    cout &lt;&lt; n;<br>\}</pre> {
=6
~5
~1
}

::سؤال 10: رمز المرجع::أي رمز يُستخدم لجعل تمرير المعامل بالمرجع بدل القيمة؟ {
=<bdi>&amp;</bdi>
~<bdi>*</bdi>
~<bdi>#</bdi>
}

::سؤال 11: القيمة المرجعة::ما القيمة التي يُرجعها استدعاء الدالة التالية؟<br><pre dir\="ltr">int add(int a, int b) \{<br>    return a + b;<br>\}<br>// add(5, 3)</pre> {
=8
~15
~53
}

::سؤال 12: كلمة الإرجاع::ما الكلمة المفتاحية المستخدمة لإرجاع قيمة من دالة؟ {
=<bdi>return</bdi>
~<bdi>output</bdi>
~<bdi>send</bdi>
}

::سؤال 13: تتبّع سلسلة استدعاءات::ما ناتج تنفيذ البرنامج التالي؟<br><pre dir\="ltr">void m() \{<br>    cout &lt;&lt; "third" &lt;&lt; endl;<br>\}<br>void f() \{<br>    cout &lt;&lt; "second" &lt;&lt; endl;<br>    m();<br>    cout &lt;&lt; "fourth" &lt;&lt; endl;<br>\}<br>int main() \{<br>    cout &lt;&lt; "first" &lt;&lt; endl;<br>    f();<br>    cout &lt;&lt; "fifth" &lt;&lt; endl;<br>\}</pre> {
=<bdi>first<br>second<br>third<br>fourth<br>fifth</bdi>
~<bdi>first<br>second<br>fourth<br>third<br>fifth</bdi>
~<bdi>third<br>second<br>first<br>fourth<br>fifth</bdi>
}

::سؤال 14: العودة بعد الاستدعاء::بعد انتهاء تنفيذ الدالة m() داخل f()، إلى أين يعود التنفيذ؟ {
=إلى <bdi>f()</bdi>، ليكمل تنفيذ ما تبقّى من أوامرها
~إلى <bdi>main()</bdi> مباشرة، متجاوزاً باقي f()
~لا يعود التنفيذ، وينتهي البرنامج فوراً
}

::سؤال 15: تتبّع دالة عودية::ما القيمة التي يُرجعها استدعاء factorial(4) في الكود التالي؟<br><pre dir\="ltr">int factorial(int x) \{<br>    if (x &lt;\= 1) \{<br>        return 1;<br>    \} else \{<br>        return factorial(x - 1) * x;<br>    \}<br>\}</pre> {
=24
~4
~10
}

::سؤال 16: مفهوم العودية::ما المقصود بالدالة العَودية <bdi>(Recursive Function)</bdi>؟ {
=دالة تستدعي نفسها أثناء تنفيذها
~دالة لا يمكن استدعاؤها إلا مرة واحدة فقط
~دالة ليس لها اسم محدد
}

::سؤال 17: أهمية حالة الأساس::لماذا يُعدّ الشرط التالي (حالة الأساس) ضرورياً داخل دالة عودية؟<br><pre dir\="ltr">if (x &lt;\= 1) return 1;</pre> {
=لإيقاف الاستدعاء الذاتي ومنع استمراره إلى ما لا نهاية
~لتسريع تنفيذ الدالة فقط
~لتغيير نوع القيمة المرجعة للدالة
}

::سؤال 18: قيمة حالة الأساس::ما القيمة التي تُرجعها factorial(1) مباشرة دون أي استدعاء إضافي؟ {
=1
~0
~لا تُرجع أي قيمة
}

::سؤال 19: مكدّس الاستدعاءات::ماذا يحدث لمكدّس الاستدعاءات <bdi>(Call Stack)</bdi> عندما تستدعي دالة أخرى؟ {
=تُضاف (تُدفع) الدالة الجديدة إلى أعلى المكدّس
~يُحذف المكدّس بالكامل ويبدأ من جديد
~لا يتأثّر المكدّس إطلاقاً
}

::سؤال 20: مصطلح Argument::ما المقصود بمصطلح <bdi>Argument</bdi> (الوسيط)؟ {
=القيمة الفعلية التي تُمرَّر للدالة عند استدعائها
~اسم الدالة نفسها
~نوع القيمة المرجعة للدالة
}
