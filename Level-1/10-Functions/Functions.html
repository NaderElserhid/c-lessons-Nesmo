ما هي الدالة؟

الدالة (Function) هي مجموعة من الأوامر مجمّعة تحت اسم معيّن. يمكن استدعاء هذا الاسم لتنفيذ الأوامر عند الحاجة، بدل إعادة كتابتها في كل مرة.

تتكوّن الدالة في C++ من أربعة أجزاء رئيسية:

1

اسم الدالة (Function name)

الاسم الذي سيتم استخدامه لاستدعاء الدالة.

2

محتوى الدالة (Function body)

المكان الذي تكتب فيه أوامر الدالة.

3

المعاملات (Parameters)

القيم التي تُمرَّر إلى الدالة عند استدعائها. يمكن أن تحتوي الدالة على أي عدد من المعاملات (بما في ذلك صفر).

4

نوع القيمة المرجعة (Return type)

الدوال يمكن أن تُرجع قيمة إلى الموضع الذي استُدعيت منه. نوع القيمة المرجعة يحدّد نوع هذه القيمة. إذا لم تُرجع الدالة أي شيء، يجب أن يكون نوعها void.

صيغة الدوال

طريقة كتابة دالة:

تُكتب الدوال عادةً خارج الدالة main() بالصورة التالية:

function_syntax.cpp
return_type function_name(parameter1, parameter2, ... , parameterN) {
    // محتوى الدالة
}
العنصرالشرح
return_typeنوع القيمة التي سترجعها الدالة (مثل int، long long، string...). إذا كان void، فلن تُرجع الدالة أي قيمة.
function_nameالاسم الذي تستدعي به الدالة.
parameter1, ..., parameterNمعاملات الدالة.

طريقة استدعاء دالة:

لاستدعاء دالة نستخدم الصيغة التالية:

function_call.cpp
function_name(value1, value2, ... , valueN);

مثال أول: دالة بدون معاملات وبدون قيمة مرجعة

مثال على برنامج يحتوي على دالة لا تُرجع أي قيمة (return_type = void) ولا تحتوي على معاملات:

hello_function.cpp 
#include<iostream>
using namespace std;

void f() {
    cout << "Hello Function" << endl;
}

int main() {
    f();
    cout << "Hello Main" << endl;
    f();
}

الناتج:

Hello Main
Hello Function

هذا البرنامج يحتوي على دالتين: f() وmain(). تنفّذ C++ main() فقط، ومن داخلها يتم استدعاء باقي الدوال.

هكذا ينتقل التنفيذ ذهاباً وإياباً بين main() وf():

مخطط الاستدعاء (Call Stack)
main() → استدعاء f() الأولى
f() تطبع: "Hello Function"
العودة إلى main()
main() تطبع: "Hello Main"
main() → استدعاء f() الثانية
f() تطبع: "Hello Function"
العودة إلى main() — نهاية البرنامج

المعاملات (Parameters)

تعريف دالة بمعاملات:

المعاملات هي متغيّرات تستقبل قيمة عند استدعاء الدالة. تُعرَّف بالشكل التالي: parameter_type parameter_name. مثال:

multiply.cpp
void multiply(int x, int y) {
    cout << x * y << endl;
}
اضغط على أي سطر لعرض شرحه هنا...

هنا قمنا بتعريف دالة multiply() التي تستقبل معاملين (x وy) وتطبع حاصل ضربهما.

تمرير المعاملات:

لاستدعاء multiply() نضع القيم التي نريد تمريرها داخل الأقواس عند الاستدعاء. يجب أن يتطابق ترتيب القيم الممرَّرة مع ترتيب المعاملات في التعريف:

multiply_call.cpp
multiply(5, 3);

هكذا تُربط القيم الممرَّرة بالمعاملات داخل الدالة:

الدالة
int multiply(int x, int y)
x = 5
y = 3
استدعاء
multiply(5, 3)

جرّب بنفسك: غيّر القيمتين وشاهد المخطط والناتج يتحدّثان مباشرة:

x = y =

مثال إضافي: دالة بمعامل واحد ترجع قيمة (مربّع عدد)، لتوضيح أن نفس فكرة تمرير المعاملات تنطبق حتى مع معامل واحد فقط:

square.cpp
int square(int n) {
    return n * n;
}
// الاستدعاء:
int result = square(6); // result = 36

تمرير المعاملات بالقيمة والمرجع

عند تمرير متغيّر إلى دالة، تُنسخ قيمته ويتم إسنادها إلى المعامل الخاص بالدالة. أي تعديل يحصل للمعامل داخل الدالة لا يؤثّر على المتغيّر الأصلي. هذا يُسمّى تمرير بالقيمة (Pass by value).

لكن يمكن تمرير المتغيّر بالمرجع (Pass by reference) بحيث يصبح المعامل هو نفسه المتغيّر الذي تم تمريره، وأي تعديل يحصل للمعامل يغيّر قيمة المتغيّر الأصلي. لتمرير المعامل بالمرجع نضيف & قبل اسم المعامل:

value_vs_reference.cpp
void addOneByValue(int x) {
    x = x + 1;
}
void addOneByReference(int &x) {
    x = x + 1;
}

مثال يستخدم كلا الطريقتين معاً:

ref_example.cpp 
#include<iostream>
using namespace std;
void addOneByReference(int &x) {
    x = x + 1;
}
void addOneByValue(int x) {
    x = x + 1;
}
int main() {
    int n = 5;
    addOneByValue(n);
    cout << n << endl;
    addOneByReference(n);
    cout << n << endl;
}
اضغط على أي سطر لعرض شرحه هنا...

الناتج:

5
6

عند استدعاء addOneByValue(n); تم نسخ قيمة n إلى x، فالتعديل على x لم يغيّر قيمة n. وعند استدعاء addOneByReference(n); أصبح x هو n نفسه، فالتعديل على x غيّر قيمة n.

قاعدة سريعة: بدون & = نسخة منفصلة (تمرير بالقيمة). مع & = نفس المتغيّر بالضبط (تمرير بالمرجع).

القيم المرجعة (Return Values)

بعد انتهاء أي دالة، يمكنها إرجاع قيمة للموضع الذي استُدعيت فيه بكتابة return. لكتابة دالة ترجع قيمة معيّنة يجب تحديد نوع القيمة المرجعة قبل اسم الدالة:

add.cpp
int add(int a, int b) {
    return a + b;
}
int main() {
    int result = add(5, 3);
}
اضغط على أي سطر لعرض شرحه هنا...
الجزءالشرح
int قبل addالدالة ترجع عدداً من نوع int.
return a + bتُرجع ناتج الجمع إلى مكان الاستدعاء.
int result = add(5, 3)تخزّن القيمة المرجعة في المتغيّر result (تصبح قيمته 8).

مسار التنفيذ الكامل خطوة بخطوة:

مخطط الاستدعاء والإرجاع
main() → استدعاء add(5, 3)
داخل add(): حساب a + b = 5 + 3 = 8
add() → return 8 (تعود إلى main())
main(): result = 8

الاستدعاء في الدوال

يمكن استدعاء دالة داخل دالة أخرى. عند انتهاء الدالة المستدعاة يعود التنفيذ إلى الدالة التي استدعتها:

call_chain.cpp 
#include<bits/stdc++.h>
using namespace std;

void m() {
    cout << "third" << endl;
}

void f() {
    cout << "second" << endl;
    m();
    cout << "fourth" << endl;
}

int main() {
    cout << "first" << endl;
    f();
    cout << "fifth" << endl;
}

fifth

البرنامج يبدأ بتنفيذ main()، وينتقل التنفيذ عبر ثلاث دوال متداخلة قبل أن يعود:

main() ← f() ← m()

main() → استدعاء f()

m() تنتهي → عودة إلى f()
f(): "fourth"
f() تنتهي → عودة إلى main()
main(): "fifth"

الدوال العودية (Recursive Functions)

الدوال العَودية (أو دوال الاستدعاء الذاتي) هي دوال تستدعي نفسها أثناء تنفيذها. مثال: حساب المضروب n! ويُحسب كالتالي:

factorial_formula.txt
n! = 1 * 2 * 3 .... * (n - 1) * n

إذن فإن مضروب الرقم 4 (4!) هو:

factorial_4.txt
4! = 4 * 3 * 2 * 1 = 24

ملحوظة: مضروب الرقم n هو حاصل ضرب مضروب n - 1 بـ n (أي n! = (n - 1)! * n).

factorial.cpp 
#include<bits/stdc++.h>
using namespace std;

int factorial(int x) {
    if (x <= 1) {
        return 1;
    } else {
        return factorial(x - 1) * x;
    }
}

int main() {
    int n;
    cin >> n;
    cout << factorial(n) << endl;
}
اضغط على أي سطر لعرض شرحه هنا...

في هذا البرنامج قمنا بكتابة دالة factorial() التي تستدعي نفسها لحساب مضروب رقم معيّن. إذا أدخلنا الرقم 3، سيتم استدعاء factorial(3) التي تستدعي factorial(2) والتي تستدعي factorial(1). تُرجع factorial(1) القيمة 1، فتُرجع factorial(2) القيمة 1 * 2 = 2، وأخيراً تُرجع factorial(3) القيمة 2 * 3 = 6 إلى main() لتُطبع.

ملحوظة مهمة: الشرط if (x <= 1) يُسمّى حالة الأساس (Base case) وهو ضروري جداً لتجنّب استدعاء الدالة لنفسها إلى ما لا نهاية.

مخطط استدعاءات factorial(3) — لاحظ كيف تتوقف الاستدعاءات عند حالة الأساس، ثم تعود القيم للأعلى مضروبة في كل مستوى:

Call Stack — factorial(3)
factorial(3) → استدعاء
factorial(2) → استدعاء
factorial(1) → استدعاء (حالة الأساس)
factorial(1) → return 1
factorial(2) → return 1 * 2 = 2
factorial(3) → return 2 * 3 = 6

جرّب بنفسك: أدخل أي رقم من 1 إلى 8، وشاهد مخطط الاستدعاءات الكامل يُبنى تلقائياً:

n =
Call Stack

مثال إضافي: نفس فكرة العودية، لكن لحساب مجموع الأعداد من 1 إلى n بدل حاصل الضرب:

recursive_sum.cpp
int sumTo(int n) {
    if (n <= 1) {
        return n; // حالة الأساس
    } else {
        return sumTo(n - 1) + n; // استدعاء عودي
    }
}
// sumTo(4) = sumTo(3) + 4 = sumTo(2) + 3 + 4 = ... = 1+2+3+4 = 10

الاسم، المحتوى، المعاملات، نوع القيمة المرجعة

٢. ماذا يجب أن يكون نوع القيمة المرجعة إذا كانت الدالة لا تُرجع أي شيء؟

void

٣. في تمرير المعاملات بالقيمة (Pass by value)، ماذا يحدث عند تعديل المعامل داخل الدالة؟

return

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

Functionدالة

مجموعة أوامر مجمّعة تحت اسم معيّن يمكن استدعاؤها عند الحاجة.

Parameterمعامل

متغيّر يُعرَّف في رأس الدالة لاستقبال قيمة عند الاستدعاء.

Argumentوسيط (قيمة مُمرَّرة)

القيمة الفعلية التي تُمرَّر للدالة عند استدعائها.

Return typeنوع القيمة المرجعة

نوع القيمة التي تُرجعها الدالة إلى مكان استدعائها.

voidبلا قيمة

نوع خاص يعني أن الدالة لا تُرجع أي قيمة.

Pass by valueتمرير بالقيمة

نسخ قيمة المتغيّر إلى المعامل؛ التعديل لا يؤثّر على الأصل.

Pass by referenceتمرير بالمرجع

المعامل هو نفسه المتغيّر الأصلي؛ التعديل يؤثّر عليه مباشرة.

Call stackمكدّس الاستدعاءات

التسلسل الذي تُستدعى وتعود به الدوال أثناء تنفيذ البرنامج.

Recursionالعَودية (الاستدعاء الذاتي)

أن تستدعي الدالة نفسها لحل جزء أصغر من نفس المسألة.

Base caseحالة الأساس

الشرط الذي يوقف الاستدعاء الذاتي في الدالة العودية.
