$CATEGORY: المستوى الأول C++/حلقة for

::سؤال 1: متى تُستخدم for::متى تُستخدم حلقة <bdi>for</bdi> غالباً بدلاً من <bdi>while</bdi>؟ {
=عندما يكون عدد التكرارات معلوماً مسبقاً
~عندما نحتاج قراءة إدخال من المستخدم فقط
~عندما لا نحتاج إلى أي شرط توقّف إطلاقاً
}

::سؤال 2: الأجزاء الثلاثة::ما الأجزاء الثلاثة الأساسية في رأس حلقة <bdi>for</bdi>؟ {
=التهيئة، الشرط، التحديث
~المدخل، المعالجة، المخرج
~الاسم، النوع، القيمة
}

::سؤال 3: توقيت التهيئة::متى تُنفَّذ التهيئة <bdi>(Initialization)</bdi> في حلقة <bdi>for</bdi>؟ {
=مرة واحدة فقط، قبل بداية الحلقة تماماً
~بعد كل تكرار
~قبل كل تكرار
}

::سؤال 4: توقيت الشرط::متى يُفحص شرط حلقة <bdi>for</bdi>؟ {
=قبل كل تكرار
~بعد كل تكرار فقط
~مرة واحدة فقط في بداية البرنامج
}

::سؤال 5: توقيت التحديث::متى يُنفَّذ جزء التحديث <bdi>(Update)</bdi> في حلقة <bdi>for</bdi>؟ {
=بعد كل تكرار، ثم يعود التنفيذ لفحص الشرط
~قبل كل تكرار، قبل فحص الشرط
~مرة واحدة فقط بعد انتهاء الحلقة بالكامل
}

::سؤال 6: الأجزاء الاختيارية::هل يمكن حذف أحد أجزاء رأس <bdi>for</bdi> (كالتهيئة أو التحديث)؟ {
=نعم، كل جزء اختياري بشكل منفرد، لكن الفواصل المنقوطة إلزامية
~لا، يجب كتابة الأجزاء الثلاثة دائماً بدون استثناء
~لا، وحذف أي جزء يمنع البرنامج من الترجمة نهائياً
}

::سؤال 7: إهمال الشرط::ماذا يحدث إذا تُرك شرط حلقة <bdi>for</bdi> فارغاً تماماً؟ {
=يُعامَل كأنه <bdi>true</bdi> دائماً، فتصبح الحلقة لا نهائية
~يُعامَل كأنه <bdi>false</bdi> دائماً، فلا تُنفَّذ الحلقة إطلاقاً
~يظهر خطأ ترجمة فوراً
}

::سؤال 8: تتبّع العدّ التنازلي::ما آخر قيمة لـ n تجعل شرط الحلقة التالية صحيحاً، فيُنفَّذ الأمر من أجلها؟<br><pre dir\="ltr">for (int n \= 10; n &gt; 0; n--)</pre> {
=1
~0
~10
}

::سؤال 9: عدد مرات التنفيذ::كم مرة يُنفَّذ الأمر داخل الحلقة التالية؟<br><pre dir\="ltr">for (int i \= 1; i &lt;\= 10; i++)</pre> {
=10 مرات
~9 مرات
~11 مرة
}

::سؤال 10: مفهوم Range-Based for::ما وظيفة حلقة <bdi>for</bdi> المبنية على المجال <bdi>(Range-Based for)</bdi>؟ {
=المرور تلقائياً على كل عنصر في مجال، مثل سلسلة نصية أو مصفوفة
~تنفيذ الحلقة عدداً غير محدود من المرات
~تعريف دوال جديدة تلقائياً
}

::سؤال 11: بنية Range-Based for::في الكود <bdi>for (char c : str)</bdi>، ماذا يمثّل <bdi>c</bdi>؟ {
=كل حرف من أحرف <bdi>str</bdi>، واحداً تلو الآخر في كل تكرار
~طول السلسلة النصية <bdi>str</bdi>
~عدد مرات تكرار الحلقة فقط
}

::سؤال 12: كلمة auto::ما دور الكلمة <bdi>auto</bdi> في <bdi>for (auto c : str)</bdi>؟ {
=تجعل المترجم يحدّد نوع العنصر تلقائياً من سياق الكود
~تحوّل <bdi>str</bdi> إلى عدد صحيح
~تُنهي الحلقة بعد أول عنصر فقط
}

::سؤال 13: ناتج Range-Based for::ما ناتج الكود التالي، إذا كانت <bdi>str</bdi> تساوي <bdi>"Hi"</bdi>؟<br><pre dir\="ltr">for (char c : str) cout &lt;&lt; "[" &lt;&lt; c &lt;&lt; "]";</pre> {
=<bdi>[H][i]</bdi>
~<bdi>[H, i]</bdi>
~<bdi>Hi</bdi>
}

::سؤال 14: الفواصل المنقوطة الإلزامية::في رأس حلقة <bdi>for</bdi>، حتى لو حُذفت الأجزاء الثلاثة جميعها، ماذا يبقى إلزامياً؟ {
=الفاصلتان المنقوطتان الفاصلتان بين الأجزاء الثلاثة
~الأقواس المعقوفة <bdi>\{ \}</bdi>
~الكلمة المفتاحية <bdi>while</bdi>
}

::سؤال 15: for مقابل while::أي عبارة صحيحة حول العلاقة بين <bdi>for</bdi> و<bdi>while</bdi>؟ {
=<bdi>for</bdi> تجمع التهيئة والشرط والتحديث في رأس واحد، بينما <bdi>while</bdi> تتطلب كتابتها في أماكن منفصلة
~<bdi>for</bdi> و<bdi>while</bdi> لا يمكن أبداً أن تؤديا نفس الوظيفة
~<bdi>while</bdi> أسرع من <bdi>for</bdi> في التنفيذ دائماً
}
