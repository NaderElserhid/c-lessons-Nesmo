الثوابت (Constants)

هذا الشرح مقدم من منصة تويت كود

لماذا نحتاج الثوابت؟

أحياناً نحتاج إلى قيمة لا تتغيّر أثناء تشغيل البرنامج، وهذا بالضبط هو دور الثوابت (Constants). تساعد الثوابت في منع الأخطاء (مثل تغيير رقم بالخطأ) وتجعل الكود أسهل في الفهم.

constants.cpp 
#include <iostream>
using namespace std;

int main() {
    int age = 15;
    age = 16; // we can change it

    const double PI = 3.14159;
    // PI = 3.14;  Error! cannot change a constant

    cout << "PI is " << PI << endl;
    return 0;
}

PI is 3.14159

لماذا نستخدم الثوابت؟

1

حماية القيم المهمة

تمنع الثوابت تغيير قيمة مهمة عن طريق الخطأ في مكان آخر من الكود.

2

وضوح الكود

المتغيّر PI أكثر وضوحاً من كتابة الرقم 3.14159 مباشرة في كل مكان يُستخدم فيه.

3

سهولة التحديث

إذا احتجت لتغيير القيمة لاحقاً (وإن كان ذلك نادراً مع PI)، يمكنك تعديلها في مكان واحد فقط بدل البحث عنها في كل الملف.

تعريف الثوابت

يتم إنشاء ثابت في C++ بإضافة الكلمة المفتاحية const قبل نوع البيانات:

define_const.cpp
const int DAYS_IN_WEEK = 7;
const double GRAVITY = 9.81;
const char GRADE = 'A';

يجب أن تُعطى الثوابت قيمة لحظة تعريفها، ولا يمكن تركها دون تهيئة (Initialization) لتُملأ لاحقاً كما نفعل مع المتغيرات العادية أحياناً.

الثوابت الحرفية (Literal Constants)

الثوابت الحرفية هي القيم التي تظهر مباشرة في الكود، وتُسمى أيضاً قيماً خام (raw values) تُكتب مباشرة دون تخزينها أولاً في متغير منفصل:

literals.cpp
int x = 5;          // 5 is an integer literal
double pi = 3.14;   // 3.14 is a double literal
char letter = 'A';  // 'A' is a character literal
string word = "Hi"; // "Hi" is a string literal

يمكنك أن تخبر C++ بنوع القيمة العددية باستخدام اللواحق (suffixes) التالية:

إذا لم تُضِف لاحقة، فإن C++ تفترض النوع int للأعداد الصحيحة، وdouble للأعداد العشرية تلقائياً.

الثوابت باستخدام #define (الطريقة القديمة)

قبل ظهور الكلمة المفتاحية const، كان المبرمجون يستخدمون #define لتعريف الثوابت:

define_old.cpp
#define PI 3.14159
#define GREETING "Hello"

ما زالت هذه الطريقة تعمل، ولكن const تُعَدّ أكثر أماناً ومُفضّلة في C++ الحديثة — لأنها تحترم نوع البيانات وتخضع لفحص المترجم، بعكس #define الذي يقوم فقط باستبدال نصي بسيط قبل الترجمة.

خلاصة سريعة

1

2

استخدم اللواحق مثل LL أو f لاختيار النوع العددي المناسب.

3

تجنّب #define للثوابت إلا عند قراءة كود قديم.

باستخدام الثوابت، يصبح الكود أكثر أماناً، وأوضح، وأسهل في الصيانة!

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

Constantثابت

قيمة تُحدَّد مرة واحدة ولا يمكن تغييرها بعد ذلك أثناء تشغيل البرنامج.

Literalقيمة حرفية

قيمة خام تُكتب مباشرة في الكود، مثل الرقم 5 أو النص "Hi".

Suffixلاحقة

رمز يُضاف بعد القيمة العددية لتحديد نوعها بدقة، مثل LL أو f.

Unsignedبدون إشارة (غير سالب)

نوع بيانات يُخزّن الأعداد الموجبة فقط بدون قيم سالبة.

Initializeتهيئة

إعطاء متغير أو ثابت قيمته الأولى لحظة تعريفه.

Read-onlyللقراءة فقط

قيمة يمكن الاطلاع عليها واستخدامها، لكن لا يمكن تعديلها.

Macroماكرو

استبدال نصي يُنفَّذ بواسطة #define قبل مرحلة الترجمة الفعلية.

Preprocessor directiveتوجيه للمعالج القبلي

أمر يبدأ بـ # يُنفَّذ قبل ترجمة الكود نفسه، مثل #define أو #include.

Single / double precisionدقة مفردة / دقة مزدوجة

مستوى دقة تمثيل الأعداد العشرية، float بدقة مفردة وdouble بدقة مزدوجة.
