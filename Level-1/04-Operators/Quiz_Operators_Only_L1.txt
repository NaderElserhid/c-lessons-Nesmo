::س1_عامل_الإسناد::ما وظيفة عامل الإسناد = في لغة C++؟ {
=تعيين قيمة محددة إلى متغير
~مقارنة قيمتين لمعرفة هل هما متساويتان
~جمع قيمتين معاً
~تعريف نوع المتغير
}

::س2_عامل_الضرب::أي رمز يُستخدم لإجراء عملية الضرب بين عددين في C++؟ {
=*
~x
~^
~%
}

::س3_باقي_القسمة::ماذا يُرجع عامل باقي القسمة % عند تنفيذ 7 % 2؟ {
=1
~3.5
~14
~0
}

::س4_أولوية_الضرب_والجمع::إذا كان x = 5 ثم كتبنا y = 3 + 2 * x؛ فما قيمة y؟ {
=13
~25
~16
~10
}

::س5_الإسناد_المركب::ما التعبير المكافئ للصيغة المركبة x += y؟ {
=x = x + y
~x = y
~x = x - y
~x = x * y
}

::س6_الزيادة::إذا كان x = 0 ثم نُفِّذ السطر x++؛ فما قيمة x بعد التنفيذ؟ {
=1
~0
~-1
~2
}

::س7_سابقة_ولاحقة::إذا كان x = 1، ما الفرق بين y = ++x وy = x++؟ {
=++x تزيد قيمة x أولاً ثم تُسند القيمة الجديدة إلى y
~كلاهما يعطي نفس النتيجة تماماً في كل الحالات
~x++ تزيد قيمة x أولاً ثم تُسند القيمة الجديدة إلى y
~++x لا يغيّر قيمة x إطلاقاً
}

::س8_عامل_المساواة::أي عامل يُستخدم في C++ للتحقق من أن قيمتين متساويتان (وليس لإسناد قيمة)؟ {
=\=\=
~\=
~!\=
~<\=
}

::س9_نوع_نتيجة_المقارنة::ما نوع البيانات الذي تُرجعه عوامل المقارنة مثل == و< و>؟ {
=bool
~int
~double
~string
}

::س10_النفي_المنطقي::إذا كانت قيمة a تساوي true، فماذا تكون قيمة !a؟ {
=false
~true
~0.5
~غير معرّفة (undefined)
}

::س11_AND::متى يُرجع العامل && (AND) القيمة true؟ {
=فقط إذا كانت كلتا القيمتين true
~إذا كانت إحدى القيمتين true فقط
~دائماً بغض النظر عن القيم
~أبداً لا يُرجع true
}

::س12_OR::متى يُرجع العامل || (OR) القيمة true؟ {
=إذا كانت إحدى القيمتين على الأقل true
~فقط إذا كانت كلتا القيمتين true معاً
~فقط إذا كانت كلتا القيمتين false
~لا يُستخدم مع القيم المنطقية إطلاقاً
}

::س13_التقييم_القصير::في التعبير A && B، إذا كانت A تساوي false، ماذا يحدث للجزء B؟ {
=لا يتم تقييمه إطلاقاً لأن النتيجة النهائية معروفة مسبقاً
~يتم تقييمه دائماً بغض النظر عن قيمة A
~يتحول تلقائياً إلى true
~يُسبب خطأ في الترجمة
}

::س14_العامل_الثلاثي::ما الصيغة الصحيحة لاستخدام العامل الثلاثي الشرطي في C++؟ {
=condition ? expression_true : expression_false
~condition : expression_true ? expression_false
~if condition then expression_true else expression_false
~condition -> expression_true , expression_false
}
