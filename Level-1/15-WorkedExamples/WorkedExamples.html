Medium

رقم واحد بالضبط

تتكوّن كلمة مرور من ثلاثة رموز. كل رمز إما حرف إنجليزي كبير أو رقم. كم كلمة مرور تحتوي رقمًا واحدًا بالضبط؟

المختبر التفاعلي: شاهد الحالات الثلاث المنفصلة

1

نلاحظ أن الرقم الوحيد يمكن أن يقع في أحد ثلاثة مواضع: الأول أو الثاني أو الثالث.

2

نحسب عدد كلمات المرور في كل حالة: الموضع الذي فيه الرقم له 10 اختيارات، والموضعان الآخران (حرفان) لهما 26 اختيارًا لكل منهما.

3

الحالات الثلاث منفصلة تمامًا؛ كل كلمة مرور تنتمي لحالة واحدة بالضبط بحسب موضع رقمها الوحيد.

4

بما أن الحالات لا تتداخل، نجمعها حسب قاعدة الجمع. وبما أن كل حالة تعطي نفس القيمة (10×26×26)، فالمجموع هو 3 × (10×26×26).

3 · 10 · 26² = 20280

verify_ex3.cpp
bool isDigit(int s) { return s < 10; } // 0-9 أرقام، 10-35 حروف

long long count = 0;
for(int s1 = 0; s1 < 36; s1++)
for(int s2 = 0; s2 < 36; s2++)
for(int s3 = 0; s3 < 36; s3++) {
    int digits = isDigit(s1) + isDigit(s2) + isDigit(s3);
    if(digits == 1) count++;
}
cout << count;
20280

verify_ex6.cpp
long long count = 0;
for(int d1 = 0; d1 <= 9; d1++)
for(int d2 = 0; d2 <= 9; d2++) if(d2 != d1)
for(int d3 = 0; d3 <= 9; d3++) if(d3 != d1 && d3 != d2)
for(int d4 = 0; d4 <= 9; d4++) if(d4 != d1 && d4 != d2 && d4 != d3) {
    int digs[4] = {d1, d2, d3, d4};
    int zeroCount = 0, evenNonZeroCount = 0;
    for(int x : digs) {
        if(x == 0) zeroCount++;
        else if(x % 2 == 0) evenNonZeroCount++;
    }
    if(zeroCount == 1 && evenNonZeroCount == 1) count++;
}
cout << count;
960
Hard

التلوين الدائري

توجد أربعة مقاعد مرقمة حول طاولة دائرية. يُلوّن كل مقعد بالأحمر أو الأخضر أو الأزرق، ويجب أن يختلف لون كل مقعد عن لون المقعدين المجاورين له. كم تلوينًا صحيحًا يوجد؟

المختبر التفاعلي: جرّب تلوين المقاعد بنفسك

1
3
4

اضغط على أي مقعد لتغيير لونه، وحاول إيجاد تلوين صحيح بنفسك!

لوّن جميع المقاعد الأربعة لبدء الفحص...
1

نختار لون المقعد الأول: 3 اختيارات.

2

نختار لون المقعد الثاني بحيث يختلف عن الأول: اختياران.

3

ننظر إلى المقعد الثالث عبر تقسيم الحالات: إذا طابق لون الأول، فله اختيار واحد، وللرابع اختياران. وإذا اختلف عن الأول والثاني معًا، فله اختيار واحد، ويصبح لون الرابع محددًا (اختيار واحد).

4

نجمع نتيجتَي الحالتين: 1×2 + 1×1 = 3 طرق لتلوين المقعدين الثالث والرابع.

5

نضرب ذلك في عدد طرق اختيار المقعدين الأول والثاني: 3 × 2 × 3 = 18.

1·2 + 1·1 = 3

3 · 2 · 3 = 18

verify_ex7.cpp
long long count = 0;
for(int s1 = 0; s1 < 3; s1++)
for(int s2 = 0; s2 < 3; s2++) if(s2 != s1)
for(int s3 = 0; s3 < 3; s3++) if(s3 != s2)
for(int s4 = 0; s4 < 3; s4++) if(s4 != s3 && s4 != s1)  // s4 مجاور لـ s3 وأيضًا لـ s1 (دائرية)
    count++;
cout << count;
18

لاحظ التقنية المشتركة بين المسائل الصعبة: عندما لا يمكن كتابة صيغة ضرب مباشرة، نُقسّم المسألة إلى حالات منفصلة (Casework)، نحسب عدد الطرق داخل كل حالة بالضرب، ثم نجمع نتائج الحالات. هذه بالضبط قاعدتا الجمع والضرب مجتمعتين.

تحقق من فهمك

١. لماذا نضرب 9 × 10 × 10 في مثال "رموز من ثلاثة أرقام"؟

لأن اختيار كل رقم هو خطوة متتابعة مستقلة عن الأخرى (قاعدة الضرب)
لأن الأرقام الثلاثة حالات منفصلة يُختار من بينها رقم واحد فقط
لا يوجد سبب رياضي محدد

٢. في مثال "رموز بلا أرقام مكررة"، لماذا أصبح للرقم الثاني 9 اختيارات وليس 10؟

لأن رقمًا واحدًا (المستخدَم في الموضع الأول) لم يعد متاحًا
لأن الصفر ممنوع في كل المواضع
لأن الرقم الثاني يجب أن يكون زوجيًا

٣. في مثال "رقم واحد بالضبط"، لماذا جمعنا الحالات الثلاث بدلًا من ضربها؟

لأنها حالات منفصلة تمامًا؛ الرقم يقع في موضع واحد فقط من الثلاثة، فلا تتداخل
لأن الجمع يُعطي دائمًا نتيجة أكبر من الضرب
لأن كلمة المرور تحتوي حرفًا واحدًا فقط

٤. في مثال الشرائط الأربعة، لماذا كان لكل شريط بعد الأول اختياران فقط بدلًا من ثلاثة؟

لأن لونه يجب أن يختلف عن لون الشريط الذي يسبقه مباشرة، فيُستبعد لون واحد
لأن الألوان المسموحة أصلًا اثنان فقط
لأن الشريط الأول يُعاد استخدامه دائمًا

٥. ما اسم التقنية التي استخدمناها في مسألتَي "رقم التعريف الشخصي" و"التلوين الدائري" عندما تعذّر وجود صيغة ضرب مباشرة؟

تقسيم الحالات (Casework)
التكرار العشوائي (Random Sampling)
الفرز (Sorting)

٦. في مثال التلوين الدائري، لماذا كان للمقعد الرابع أحيانًا اختياران وأحيانًا اختيار واحد فقط؟

لأن عدد الألوان المتاحة له يعتمد على لون المقعد الثالث بالنسبة للمقعدين السابقين
لأن المقعد الرابع دائمًا حر تمامًا في اختيار أي لون
لأن ترقيم المقاعد يتغيّر بين المحاولات

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

Caseworkتقسيم الحالات

أسلوب لحل مسائل العد بتقسيمها إلى حالات منفصلة، ثم جمع نتائج كل حالة.

Brute forceالقوة الغاشمة / التحقق الشامل

تجربة كل الاحتمالات فعليًا عبر الكود للتحقق من صحة صيغة رياضية.

Constraintقيد / شرط

شرط يحدّ من الاختيارات المسموحة، مثل منع تكرار الأرقام.

Adjacentمتجاور

عنصران متتاليان مباشرة، مثل شريطين متجاورين في العلم أو مقعدين متجاورين حول الطاولة.
