$CATEGORY: المستوى الأول C++/عبارة if

::سؤال 1: مفهوم if::ما وظيفة عبارة <bdi>if</bdi> في <bdi>C++</bdi>؟ {
=تنفيذ جزء من الكود فقط إذا تحقق شرط معيّن
~تعريف متغير جديد في البرنامج
~تكرار تنفيذ نفس الكود إلى الأبد
}

::سؤال 2: البنية الأساسية::ما الذي يوضع بين القوسين في البنية التالية؟<br><pre dir\="ltr">if (condition) statement;</pre> {
=الشرط <bdi>(condition)</bdi> الذي سيتم فحصه
~اسم المتغير الذي سيُطبع
~عدد مرات التكرار
}

::سؤال 3: نتيجة الشرط::إلى ماذا يُقيَّم الشرط <bdi>(condition)</bdi> داخل <bdi>if</bdi>؟ {
=إمّا <bdi>true</bdi> أو <bdi>false</bdi>
~إلى رقم صحيح فقط
~إلى نص <bdi>(string)</bdi> دائماً
}

::سؤال 4: عندما يكون الشرط صحيحاً::إذا كان شرط <bdi>if</bdi> يساوي <bdi>true</bdi>، ماذا يحدث؟ {
=يتم تنفيذ الأمر <bdi>(statement)</bdi> المرتبط بـ <bdi>if</bdi>
~يتوقف البرنامج فوراً
~يُعاد فحص الشرط مرة أخرى تلقائياً
}

::سؤال 5: عندما يكون الشرط خاطئاً بدون else::إذا كان شرط <bdi>if</bdi> يساوي <bdi>false</bdi> ولا يوجد <bdi>else</bdi>، ماذا يحدث؟ {
=يتم تجاهل الأمر، ويستمر البرنامج في التنفيذ بعد عبارة <bdi>if</bdi>
~يتوقف البرنامج عن العمل
~يُنفَّذ الأمر مرة واحدة رغم ذلك
}

::سؤال 6: عامل المقارنة \=\=::ماذا تعني العلامة \=\= في الكود التالي؟<br><pre dir\="ltr">if (x \=\= 100)</pre> {
=مقارنة (هل <bdi>x</bdi> تساوي 100؟) وليست عملية إسناد
~إسناد قيمة 100 إلى <bdi>x</bdi>
~طباعة قيمة <bdi>x</bdi> على الشاشة
}

::سؤال 7: متى تُطبع الرسالة::متى تُطبع الرسالة في الكود التالي؟<br><pre dir\="ltr">if (x \=\= 100) cout &lt;&lt; "x is 100";</pre> {
=فقط عندما تكون قيمة <bdi>x</bdi> تساوي 100 بالضبط
~في كل مرة يُشغَّل فيها البرنامج بغض النظر عن <bdi>x</bdi>
~فقط عندما تكون <bdi>x</bdi> أكبر من 100
}

::سؤال 8: تنفيذ أكثر من أمر::لتنفيذ أكثر من أمر واحد عند تحقق شرط <bdi>if</bdi>، ماذا نستخدم؟ {
=نجمعها بين الأقواس المعقوفة <bdi>\{ \}</bdi>
~نفصلها بفواصل عادية <bdi>,</bdi>
~نكررها داخل أقواس عادية <bdi>( )</bdi>
}

::سؤال 9: معاملة الكتلة المركّبة::كيف تُعامَل الكتلة المركّبة <bdi>\{ \}</bdi> داخل <bdi>if</bdi>؟ {
=كأنها أمر واحد
~كأنها عدة برامج منفصلة
~لا تُعامَل كأمر إطلاقاً
}

::سؤال 10: تأثير المسافات البادئة::هل تؤثّر المسافات البادئة <bdi>(indentation)</bdi> وتنسيق الأسطر على طريقة تنفيذ البرنامج؟ {
=لا، لا تؤثّر على التنفيذ إطلاقاً
~نعم، تغيّر نتيجة البرنامج دائماً
~نعم، لكن فقط داخل الحلقات
}

::سؤال 11: عدد الأوامر داخل الكتلة::كم أمراً يوجد داخل الكتلة المركّبة في الكود التالي؟<br><pre dir\="ltr">if (x \=\= 100) \{ cout &lt;&lt; "x is "; cout &lt;&lt; x; \}</pre> {
=أمران (<bdi>cout</bdi> الأول و<bdi>cout</bdi> الثاني)
~أمر واحد فقط
~ثلاثة أوامر
}

::سؤال 12: وظيفة else::ما وظيفة <bdi>else</bdi> في <bdi>C++</bdi>؟ {
=تحديد ما يحدث عندما يكون شرط <bdi>if</bdi> غير صحيح
~تكرار نفس الشرط مرة أخرى
~إلغاء عبارة <bdi>if</bdi> بالكامل من الكود
}

::سؤال 13: شرط تنفيذ else::متى يُنفَّذ الجزء الموجود بعد <bdi>else</bdi>؟ {
=فقط عندما يكون شرط <bdi>if</bdi> السابق له <bdi>false</bdi>
~دائماً، بغض النظر عن نتيجة الشرط
~فقط عندما يكون شرط <bdi>if</bdi> صحيحاً
}

::سؤال 14: تتبّع كود else::لو كانت <bdi>x</bdi> تساوي 50 في الكود التالي، ماذا يُطبع؟<br><pre dir\="ltr">if (x \=\= 100) cout &lt;&lt; "x is 100"; else cout &lt;&lt; "x is not 100";</pre> {
=<bdi>x is not 100</bdi>
~<bdi>x is 100</bdi>
~لا يُطبع أي شيء
}

::سؤال 15: وظيفة else if::ما الغرض من استخدام <bdi>else if</bdi>؟ {
=ربط عدّة شروط متتالية للاختيار من بين أكثر من بديلين
~تعريف دالة جديدة في البرنامج
~إنهاء البرنامج عند تحقق شرط معيّن
}

::سؤال 16: طبيعة else if::هل <bdi>else if</bdi> كلمة مفتاحية جديدة ومستقلة في <bdi>C++</bdi>؟ {
=لا، هي ببساطة <bdi>else</bdi> يتبعها <bdi>if</bdi> جديدة
~نعم، وهي مختلفة تماماً عن <bdi>if</bdi> و<bdi>else</bdi>
~نعم، ولا يمكن استخدامها إلا مرة واحدة فقط
}

::سؤال 17: عدد الفروع المنفَّذة::في سلسلة <bdi>else if</bdi>، كم فرعاً يُنفَّذ عادةً عند تحقق أكثر من شرط في السلسلة؟ {
=فرع واحد فقط - أول شرط يتحقق
~كل الفروع التي تتحقق شروطها
~آخر فرع في السلسلة دائماً
}
