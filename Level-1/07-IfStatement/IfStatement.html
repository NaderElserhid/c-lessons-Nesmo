عبارة if — اتخاذ القرارات

تُستخدم عبارة if لاتخاذ القرارات داخل البرنامج — فهي تجعل البرنامج ينفّذ جزءاً معيّناً فقط إذا كان الشرط المحدّد صحيحاً. بهذا تنتقل من برنامج ينفّذ نفس الأوامر دائماً، إلى برنامج "يفكّر" ويختار ما يفعله حسب الحالة.

البنية الأساسية:

if_syntax.cpp
if (condition)
    statement;
اضغط على أي سطر لعرض شرحه هنا...
  • condition هي تعبير (expression) يتم تقييمه إلى إمّا true أو false.
  • إذا كان الشرط صحيحاً (true)، يتم تنفيذ الأمر (statement).
  • إذا كان الشرط غير صحيح (false)، يتم تجاهل الأمر، ويستمر البرنامج في التنفيذ بعد عبارة if.

مثال:

if_example.cpp
if (x == 100)
    cout << "x is 100";
اضغط على أي سطر لعرض شرحه هنا...

إذا كانت قيمة x تساوي بالضبط 100، سيتم طباعة الرسالة "x is 100". وإلا، لن يحدث شيء وسيُكمل البرنامج التنفيذ بشكل طبيعي.

عدّة أوامر داخل if — الكتلة المركّبة

إذا أردت تنفيذ أكثر من أمر واحد عندما يكون الشرط صحيحاً، قم بتجميعها بين الأقواس المعقوفة { } لتكوين كتلة (block):

if_block.cpp
if (x == 100)
{
    cout << "x is ";
    cout << x;
}
اضغط على أي سطر لعرض شرحه هنا...

تُعامَل هذه الكتلة كأنها أمر واحد في سياق التحكم في التدفق (flow control).

المسافات البادئة (indentation) وتنسيق الأسطر لا يؤثّران على طريقة تنفيذ البرنامج. لذلك الكود التالي مكافئ تماماً للكود أعلاه، رغم اختلاف الشكل:

if_block_oneline.cpp
if (x == 100) { cout << "x is "; cout << x; }

استخدام else

يمكنك إضافة جزء else لتحديد ما يحدث عندما يكون الشرط غير صحيح:

if_else.cpp
if (x == 100)
    cout << "x is 100";
else
    cout << "x is not 100";
اضغط على أي سطر لعرض شرحه هنا...
  • إذا كان الشرط صحيحاً، تُنفَّذ الأمر الأولى.
  • إذا كان غير صحيح، تُنفَّذ الأمر بعد else بدلاً منها.

جرّب بنفسك: أدخل قيمة لـ x وشاهد أي فرع سيُنفَّذ:

x =

سلاسل else if

يمكنك ربط عدّة شروط باستخدام else if للتعامل مع عدّة حالات. يفحص البرنامج الشروط بالترتيب من الأعلى للأسفل، وينفّذ أول فرع يتحقق شرطه فقط، ثم يتجاهل بقية السلسلة بالكامل:

else_if_chain.cpp
if (x > 0)
    cout << "x is positive";
else if (x < 0)
    cout << "x is negative";
else
    cout << "x is 0";
اضغط على أي سطر لعرض شرحه هنا...

هذا التركيب يسمح للبرنامج بالاختيار بين عدّة بدائل: إذا كانت x أكبر من صفر → يطبع "x is positive". إذا كانت x أقل من صفر → يطبع "x is negative". خلاف ذلك (أي x تساوي صفر بالضبط) → يطبع "x is 0".

لاحظ أن else if ليست كلمة مفتاحية جديدة في C++ — هي ببساطة else يتبعها if جديدة. يمكنك ربط أي عدد من else if متتالية قبل else الأخيرة (الاختيارية).

جرّب بنفسك: أدخل أي قيمة لـ x وشاهد أي فرع من السلسلة يُنفَّذ فعلياً (سيتم تمييز السطر المطابق في الكود أعلاه):

x =
في انتظار التشغيل...

تحقق من فهمك

١. ما وظيفة عبارة if في C++؟

تنفيذ جزء من الكود فقط إذا تحقق شرط معيّن
تعريف متغير جديد في البرنامج
تكرار تنفيذ نفس الكود إلى الأبد

٢. إذا كان شرط if غير صحيح (false) ولا يوجد else، ماذا يحدث؟

يتم تجاهل الأمر، ويستمر البرنامج بعد عبارة if
يتوقف البرنامج عن العمل فوراً
يُنفَّذ الأمر مرة واحدة إجبارياً

٣. ما الغرض من else؟

تحديد ما يحدث عندما يكون شرط if غير صحيح
تكرار الشرط نفسه مرة أخرى
إلغاء عبارة if بالكامل

٤. في سلسلة else if، كم فرعاً يُنفَّذ عادةً عند تحقق أكثر من شرط؟

فرع واحد فقط — أول شرط يتحقق
كل الفروع التي تتحقق شروطها
آخر فرع في السلسلة دائماً

٥. في السلسلة: if (x > 0) ... else if (x < 0) ... else ...، ماذا يُطبع عندما x = 0؟

x is positive
x is negative
x is 0

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

ifإذا (عبارة شرطية)

تنفّذ جزءاً من الكود فقط إذا تحقق شرط معيّن.

elseوإلا

تحدّد ما يحدث عندما يكون شرط if غير صحيح.

else ifوإلا إذا

ربط عدّة شروط متتالية للاختيار من بين أكثر من بديلين.

Conditionشرط

تعبير يتم تقييمه إلى true أو false، ويحدّد أي فرع يُنفَّذ.

Boolean expressionتعبير منطقي

تعبير قيمته الوحيدة إمّا true أو false.

Selection statementعبارة اختيار

اسم عام لعبارات مثل if وswitch التي تختار مساراً من بين عدّة مسارات.

Blockكتلة

مجموعة أوامر بين { } تُعامَل كأمر واحد داخل if.

Branchفرع

أحد المسارات الممكنة التي قد يسلكها تنفيذ البرنامج.
