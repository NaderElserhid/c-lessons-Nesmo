ما هو النطاق (Scope)؟

في C++، الموضع الذي يتم فيه تعريف المتغيّر يؤثّر على الأماكن التي يمكن استخدامه فيها. النطاق (Scope) هو الجزء من البرنامج الذي يمكن تعريف المتغيّر فيه والوصول إليه مباشرة باستخدام اسمه. إذا تم تعريف متغيّر في نطاق معيّن، فإننا نقول إن الاسم مرئي (Visible) في هذا النطاق.

أغلب النطاقات هي المناطق المحاطة بالأقواس المعقوفة { }. المنطقة خارج أي نطاق تُسمى النطاق العام (Global Scope)، وأي منطقة أخرى تُسمى نطاقاً محلياً (Local Scope).

مثال شامل على النطاقات

اضغط على أي سطر تعريف متغيّر لمعرفة النطاق الذي ينتمي إليه:

scope_example.cpp 
#include<iostream>
using namespace std;

int x = 5; // نطاق عام
int main() {
    int y = 4; // نطاق محلي 1

    for (int i = 0; i < 5; i++) {
        int z = 20; // نطاق محلي 2
        if (i % 2 == 0) {
            // نطاق محلي 3
            cout << z + x << ' ' << z + y << endl;
        }
        else {
            // نطاق محلي 4
            cout << z - y << ' ' << z - x << endl;
        }
    }
}

أين يكون المتغيّر مرئياً؟

المتغيّرات المعرَّفة بشكل عام (متغيّرات عامة) تكون مرئية في جميع النطاقات بعد تعريفها. المتغيّرات المعرَّفة محلياً (متغيّرات محلية) تكون مرئية فقط داخل النطاق الذي تم تعريفها فيه، ويشمل ذلك النطاقات الداخلية فيه.

لاحظ أن المتغيّرات التي تُعرَّف داخل رأس حلقة for (مثل i) تنتمي إلى نطاق الحلقة نفسه، حتى لو كان التعريف قبل القوس المعقوف مباشرة.

تحذير: استخدام متغيّر خارج نطاقه

استخدام متغيّر خارج النطاق الذي تم تعريفه فيه يؤدي إلى خطأ في الترجمة (Compilation Error). بمجرد الخروج من النطاق (أي بعد القوس المعقوف الذي يُغلقه)، يتوقف المتغيّر عن الوجود.

مثال: محاولة استخدام z بعد نهاية حلقة for التي عُرِّفت داخلها:

scope_error.cpp
for (int i = 0; i < 5; i++) {
    int z = 20;
    // ...
}
cout << z; // z غير موجودة هنا، خارج نطاقها

التسمية داخل النطاق

في النطاق الواحد، يمكن للاسم أن يمثّل متغيّراً واحداً فقط:

duplicate_name.cpp
int main() {
    int x = 5;
    string x = "Hello world"; // خطأ ترجمة! x معرَّف مسبقاً في نفس النطاق
}

لكن يمكننا تعريف متغيّر في نطاق ما، ثم تعريف متغيّر آخر بالاسم نفسه في نطاق داخلي مختلف. في هذه الحالة، عند استخدام هذا الاسم داخل النطاق الداخلي، سيُستخدم المتغيّر الداخلي (يُسمّى هذا حجب الاسم — Name Shadowing):

name_shadowing.cpp
int x = 5;
int main() {
    int x;
    cin >> x;

    if (x == 5) {
        string x = "Hello world";
        cout << x << endl;
    }
    else {
        cout << x << endl;
    }
}
اضغط على أي سطر تعريف متغيّر لعرض شرحه هنا...

هذا مسموح لأن كل تعريف يقع في نطاق مختلف: int x; داخل نطاق main()، وstring x داخل نطاق if الداخلي.

أمثلة إضافية

مثال 1 — نفس الاسم في دالتين مختلفتين لا يسبّب أي تعارض:

كل دالة لها نطاقها المحلي الخاص، حتى لو تشابهت أسماء المتغيّرات:

two_functions.cpp
void printSquare() {
    int result = 4 * 4; // result هنا محلية لهذه الدالة فقط
    cout << result << endl;
}

void printCube() {
    int result = 3 * 3 * 3; // result مختلفة تماماً، نطاق آخر
    cout << result << endl;
}
16
27

المتغيّران يحملان الاسم نفسه result، لكن كل واحد منهما موجود في نطاق دالته فقط، فلا يحدث أي تعارض ولا خطأ ترجمة.

مثال 2 — إعادة استخدام اسم عدّاد الحلقة في حلقة أخرى:

بما أن كل حلقة for تفتح نطاقها الخاص، يمكن استخدام i في أكثر من حلقة بأمان طالما لم تتداخلا:

two_loops.cpp
for (int i = 0; i < 3; i++) {
    cout << "A" << i << ' ';
}
// نهاية نطاق i الأولى هنا
for (int i = 0; i < 3; i++) {
    cout << "B" << i << ' ';
}
A0 A1 A2 B0 B1 B2

مثال 3 — متغيّر عام يُستخدم داخل عدّة دوال:

global_counter.cpp
int counter = 0; // نطاق عام

void increment() {
    counter = counter + 1; // counter مرئية هنا لأنها عامة
}

int main() {
    increment();
    increment();
    cout << counter << endl;
}
2

بما أن counter عامة، فهي مرئية داخل الدالة increment() ودالة main() معاً دون الحاجة لتمريرها كمعامل.

تحقق من فهمك

١. ما المقصود بالنطاق (Scope)؟

الجزء من البرنامج الذي يمكن تعريف المتغيّر فيه والوصول إليه باسمه
نوع خاص من أنواع البيانات
اسم آخر للدالة الرئيسية main()

٢. أين تكون المتغيّرات العامة مرئية؟

في جميع النطاقات بعد تعريفها
داخل النطاق الذي عُرِّفت فيه فقط
لا يمكن استخدامها إطلاقاً

٣. ماذا يحدث عند استخدام متغيّر خارج نطاقه؟

خطأ في الترجمة (Compilation Error)
يأخذ المتغيّر القيمة صفر تلقائياً
يعمل البرنامج بشكل طبيعي دون مشاكل

٤. هل يمكن لاسمين مختلفين في النطاق نفسه أن يمثّلا نفس المتغيّر؟ وهل يمكن للاسم نفسه أن يمثّل متغيّرين في نفس النطاق؟

لا يمكن للاسم نفسه أن يمثّل أكثر من متغيّر واحد في النطاق نفسه
يمكن للاسم نفسه أن يمثّل عدة متغيّرات في نفس النطاق دون مشاكل
هذا غير مسموح إطلاقاً حتى في نطاقات مختلفة

٥. ما اسم الظاهرة التي يُستخدم فيها الاسم نفسه لمتغيّر في نطاق داخلي، فيُستخدم الأقرب عند التعارض؟

حجب الاسم (Name Shadowing)
تحويل النوع (Type Casting)
التمرير بالمرجع (Pass by Reference)

٦. إلى أي نطاق ينتمي متغيّر عدّاد حلقة for المُعرَّف داخل رأسها، مثل i في for (int i = 0; ...)؟

نطاق الحلقة نفسها، حتى لو كان التعريف قبل القوس المعقوف
النطاق العام دائماً
لا ينتمي لأي نطاق

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

Scopeنطاق

الجزء من البرنامج الذي يمكن الوصول لمتغيّر فيه باسمه مباشرة.

Visibilityمرئية

القدرة على الوصول إلى متغيّر باسمه من موضع معيّن في الكود.

Global scopeنطاق عام

المنطقة خارج أي دالة أو كتلة؛ المتغيّرات هنا مرئية في كل مكان بعدها.

Local scopeنطاق محلي

أي منطقة محاطة بأقواس معقوفة داخل دالة أو كتلة؛ متغيّراتها مرئية داخلها فقط.

Blockكتلة

مجموعة أوامر محاطة بـ { }، وغالباً ما تُشكّل نطاقاً محلياً جديداً.

Name shadowingحجب الاسم

استخدام نفس الاسم لمتغيّر في نطاق داخلي، فيُستخدم الأقرب عند التعارض.

Compilation errorخطأ ترجمة

خطأ يمنع المترجم من إنتاج برنامج قابل للتشغيل، مثل استخدام متغيّر خارج نطاقه.
