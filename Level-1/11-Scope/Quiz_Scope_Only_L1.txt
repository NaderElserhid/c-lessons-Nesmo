$CATEGORY: المستوى الأول C++/مرئية الأسماء

::سؤال 1: مفهوم النطاق::ما المقصود بـ <bdi>النطاق (Scope)</bdi> في <bdi>C++</bdi>؟ {
=الجزء من البرنامج الذي يمكن تعريف المتغيّر فيه والوصول إليه مباشرة باسمه
~نوع خاص من أنواع البيانات في اللغة
~الوقت الذي يستغرقه البرنامج في التنفيذ
}

::سؤال 2: النطاق العام::ما هو <bdi>النطاق العام (Global Scope)</bdi>؟ {
=المنطقة خارج أي دالة أو كتلة، وتكون المتغيّرات المُعرَّفة فيها مرئية في كل مكان بعد تعريفها
~المنطقة الموجودة داخل دالة <bdi>main()</bdi> فقط
~المنطقة المخصّصة للتعليقات فقط
}

::سؤال 3: النطاق المحلي::ما هو <bdi>النطاق المحلي (Local Scope)</bdi>؟ {
=أي منطقة محاطة بأقواس معقوفة <bdi>\{ \}</bdi>، وتكون متغيّراتها مرئية داخلها فقط
~نفس النطاق العام تماماً بلا أي فرق
~منطقة خاصة بالمتغيّرات الثابتة <bdi>(const)</bdi> فقط
}

::سؤال 4: تتبّع مثال النطاقات (زوجي)::ما أول سطر يُطبع عند تنفيذ البرنامج التالي؟<br><pre dir\="ltr">int x \= 5;<br>int main() \{<br>    int y \= 4;<br>    for (int i \= 0; i &lt; 5; i++) \{<br>        int z \= 20;<br>        if (i % 2 \=\= 0) \{<br>            cout &lt;&lt; z + x &lt;&lt; ' ' &lt;&lt; z + y &lt;&lt; endl;<br>        \}<br>        else \{<br>            cout &lt;&lt; z - y &lt;&lt; ' ' &lt;&lt; z - x &lt;&lt; endl;<br>        \}<br>    \}<br>\}</pre> {
=<bdi>25 24</bdi>
~<bdi>16 15</bdi>
~<bdi>20 5</bdi>
}

::سؤال 5: تتبّع مثال النطاقات (فردي)::في نفس البرنامج السابق، ما ثاني سطر يُطبع (عند i تساوي 1)؟<br><pre dir\="ltr">int x \= 5;<br>int main() \{<br>    int y \= 4;<br>    for (int i \= 0; i &lt; 5; i++) \{<br>        int z \= 20;<br>        if (i % 2 \=\= 0) \{<br>            cout &lt;&lt; z + x &lt;&lt; ' ' &lt;&lt; z + y &lt;&lt; endl;<br>        \}<br>        else \{<br>            cout &lt;&lt; z - y &lt;&lt; ' ' &lt;&lt; z - x &lt;&lt; endl;<br>        \}<br>    \}<br>\}</pre> {
=<bdi>16 15</bdi>
~<bdi>25 24</bdi>
~<bdi>24 16</bdi>
}

::سؤال 6: رؤية متغيّر عام::متغيّر مُعرَّف في النطاق العام مثل <bdi>x</bdi>، أين يكون مرئياً؟ {
=في جميع النطاقات، العام منها والمحلية كلها بعد تعريفه
~داخل النطاق العام فقط
~داخل حلقة <bdi>for</bdi> فقط
}

::سؤال 7: رؤية متغيّرات حلقة for::متغيّرات مثل <bdi>i</bdi> و<bdi>z</bdi> المُعرَّفتان داخل حلقة <bdi>for</bdi>، أين تكونان مرئيتين؟ {
=داخل حلقة <bdi>for</bdi> والنطاقات الداخلية <bdi>if</bdi> و<bdi>else</bdi> فقط
~في جميع أنحاء البرنامج بما في ذلك خارج <bdi>main()</bdi>
~داخل <bdi>if</bdi> فقط دون <bdi>else</bdi>
}

::سؤال 8: استخدام متغيّر خارج نطاقه::ماذا يحدث عند استخدام متغيّر خارج النطاق الذي عُرِّف فيه؟ {
=خطأ في الترجمة <bdi>(Compilation Error)</bdi>
~يأخذ المتغيّر القيمة صفر تلقائياً
~يعمل البرنامج بشكل طبيعي دون أي مشاكل
}

::سؤال 9: تعريف اسم مكرر في نفس النطاق::ماذا يحدث عند تنفيذ الكود التالي؟<br><pre dir\="ltr">int main() \{<br>    int x \= 5;<br>    string x \= "Hello world";<br>\}</pre> {
=خطأ في الترجمة، لأن الاسم <bdi>x</bdi> معرَّف مرتين في نفس النطاق
~يُطبع <bdi>Hello world</bdi> مباشرة دون أي مشاكل
~يُهمَل السطر الثاني ويكمل البرنامج بشكل طبيعي
}

::سؤال 10: مفهوم حجب الاسم::ماذا يُسمّى استخدام نفس اسم المتغيّر في نطاق داخلي، بحيث يُستخدم التعريف الأقرب عند التعارض؟ {
=حجب الاسم <bdi>(Name Shadowing)</bdi>
~تحويل النوع <bdi>(Type Casting)</bdi>
~التمرير بالمرجع <bdi>(Pass by Reference)</bdi>
}
