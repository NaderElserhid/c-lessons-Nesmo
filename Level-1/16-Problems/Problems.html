عدد بشروط

تم الحل

كم عددًا صحيحًا موجبًا من أربعة أرقام تكون أرقامه مختلفة ويحتوي رقمًا زوجيًا واحدًا بالضبط؟

المختبر التفاعلي: قارن بين حالتَي الرقم الزوجي

1

الصفر أيضًا رقم زوجي، فنقسّم المسألة إلى حالتين حسب قيمة الرقم الزوجي الوحيد.

2

الحالة الأولى — الرقم الزوجي هو صفر: لا يمكن أن يكون في الموضع الأول، فله 3 مواضع ممكنة. الأرقام الثلاثة الباقية فردية ومختلفة من {1,3,5,7,9}: 5×4×3=60 ترتيبًا. مجموع الحالة: 3×60=180.

3

الحالة الثانية — الرقم الزوجي أحد {2,4,6,8}: 4 اختيارات لقيمته، ويمكن أن يوضع في أي من المواضع الأربعة (لأنه لا يساوي صفرًا): 4 اختيارات لموضعه. الأرقام الثلاثة الباقية فردية ومختلفة: 5×4×3=60 ترتيبًا. مجموع الحالة: 4×4×60=960.

4

الحالتان منفصلتان تمامًا (تُحددان بقيمة الرقم الزوجي)، فنجمعهما حسب قاعدة الجمع.

180 + 960 = 1140

verify_p10.cpp
long long count = 0;
for(int d1 = 1; d1 <= 9; d1++)
for(int d2 = 0; d2 <= 9; d2++) if(d2 != d1)
for(int d3 = 0; d3 <= 9; d3++) if(d3 != d1 && d3 != d2)
for(int d4 = 0; d4 <= 9; d4++) if(d4 != d1 && d4 != d2 && d4 != d3) {
    int digs[4] = {d1, d2, d3, d4};
    int evenCount = 0;
    for(int x : digs) if(x % 2 == 0) evenCount++;
    if(evenCount == 1) count++;
}
cout << count;
1140

    map<char,int> freq;

رحلة الذهاب: نختار طريقًا من A إلى B (3 اختيارات) ثم طريقًا من B إلى C (4 اختيارات): 3×4=12 رحلة ذهاب ممكنة.

2

رحلة العودة يجب ألا تستخدم أيًا من الطريقين المستخدَمين في الذهاب: فمن C إلى B يتبقى 4−1=3 طرق متاحة، ومن B إلى A يتبقى 3−1=2 طريق متاح.

4

الذهاب والعودة خطوتان متتابعتان، فنضرب عدد رحلات الذهاب في عدد رحلات العودة الممكنة لكل منها.

(3 · 4) · (3 · 2) = 12 · 6 = 72

verify_p12.cpp
int goWays = 3 * 4;      // A إلى B ثم B إلى C
int returnWays = 3 * 2;  // C إلى B وB إلى A بتجنّب المستخدَم
cout << goWays * returnWays;
72
