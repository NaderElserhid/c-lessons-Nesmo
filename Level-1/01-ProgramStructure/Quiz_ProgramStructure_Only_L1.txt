::س1_تضمين_المكتبات::ما وظيفة السطر \#include <iostream> الذي يوضع في بداية أي برنامج C++؟ {
=يخبر المترجم بإضافة أوامر الإدخال والإخراج قبل الترجمة
~يطبع النص "Hello World" مباشرة على الشاشة
~يُنهي تنفيذ البرنامج
~يُعرّف متغيراً جديداً
}

::س2_مساحة_الاسم::ماذا تفعل العبارة using namespace std؛ الموجودة في بداية أغلب البرامج؟ {
=تتيح كتابة cout وcin مباشرة دون كتابة اسم المساحة قبلهما
~تُضيف مكتبة الإدخال والإخراج إلى البرنامج
~تُنهي البرنامج بنجاح
~تُعرّف الدالة الرئيسية للبرنامج
}

::س3_الدالة_الرئيسية::من أين يبدأ تنفيذ أي برنامج مكتوب بلغة C++؟ {
=من الدالة main()
~من أول سطر مكتوب في الملف مباشرة
~من السطر الذي يحتوي على return
~من أي مكان يحدده المبرمج بحرية داخل الملف
}

::س4_الأقواس_المعقوفة::ما وظيفة الأقواس المعقوفة \{ \} في لغة C++؟ {
=تجميع مجموعة من التعليمات البرمجية في كتلة واحدة
~إنهاء كل جملة برمجية على حدة
~كتابة التعليقات داخل البرنامج
~تعريف نوع المتغير المستخدم
}

::س5_الفاصلة_المنقوطة::ماذا يحدث إذا نسي المبرمج وضع الفاصلة المنقوطة ; بعد أحد الأوامر؟ {
=يظهر خطأ عند الترجمة (Compile Error)
~يتجاهل المترجم السطر تلقائياً ويكمل التنفيذ
~يعمل البرنامج بشكل طبيعي دون أي مشاكل
~يتحول السطر تلقائياً إلى تعليق
}

::س6_أمر_الإرجاع::ما الذي يشير إليه السطر return 0؛ الموجود في نهاية الدالة main؟ {
=أن البرنامج انتهى تنفيذه بنجاح دون أخطاء
~أن البرنامج سيبدأ من جديد من أول سطر
~أن هناك خطأ حدث أثناء تنفيذ البرنامج
~أن قيمة أحد المتغيرات أصبحت صفراً
}

::س7_التعليقات_تنفيذ::يقوم الحاسوب بتنفيذ التعليقات (Comments) كجزء فعلي من البرنامج عند التشغيل. {FALSE}

::س8_أنواع_التعليقات::ما الفرق بين التعليق // والتعليق الذي يبدأ بـ /* وينتهي بـ */ ؟ {
=// لتعليق سطر واحد فقط، بينما التعليق الآخر يمتد لعدة أسطر
~// لتعليق عدة أسطر، بينما الآخر لسطر واحد فقط
~لا يوجد فرق بينهما إطلاقاً
~// يُستخدم فقط داخل الدالة main دون غيرها
}

::س9_الإزاحة::تُغيّر المسافات البادئة (Indentation) من طريقة تنفيذ البرنامج فعلياً، وليست فقط لتحسين القراءة. {FALSE}

::س10_تعريف_IDE::ما المقصود بمصطلح IDE؟ {
=برنامج يجمع محرر الكود والمترجم وأدوات التشغيل في مكان واحد
~لغة برمجة جديدة مشابهة لـ C++
~نوع من أنواع المتغيرات
~اسم آخر للمترجم Compiler فقط
}

::س11_MinGW::عند تثبيت بيئة Code Blocks على نظام Windows مع خيار MinGW، ماذا يعني ذلك؟ {
=أن الإصدار يتضمن مترجماً جاهزاً، فلا حاجة لتثبيت مترجم منفصل
~أن البرنامج سيعمل فقط على أنظمة macOS
~أن هذا الإصدار لا يدعم كتابة الكود بلغة C++
~أن التثبيت سيحذف أي برامج تطوير أخرى موجودة على الجهاز
}

::س12_macOS_مترجم::ماذا يجب تثبيته أولاً على نظام macOS قبل استخدام بيئة Code Blocks؟ {
=أدوات سطر الأوامر من Apple للحصول على مترجم Clang
~نظام تشغيل Windows بجانب macOS
~محرر نصوص خارجي مثل Notepad
~لا حاجة لتثبيت أي شيء إضافي على macOS
}

::س13_Build_and_run::ماذا يحدث عند الضغط على زر Build and run في بيئة التطوير؟ {
=يتم استدعاء المترجم لتحويل الكود إلى ملف تنفيذي ثم تشغيله
~يُحفظ الملف فقط دون أي تنفيذ
~تُحذف كل التعليقات الموجودة في الكود تلقائياً
~يُعاد تسمية الملف تلقائياً
}

::س14_دور_المترجم::ما الدور الأساسي للمترجم (Compiler)؟ {
=تحويل الشيفرة المصدرية التي يكتبها المبرمج إلى ملف تنفيذي يفهمه الحاسوب
~كتابة الكود نيابة عن المبرمج تلقائياً
~تصحيح الأخطاء الإملائية في التعليقات
~تشغيل نظام التشغيل نفسه
}
