التعليمة البسيطة (Simple Statement)

التعليمة (statement) البسيطة في C++ هي واحدة من الأوامر الفردية في البرنامج — مثل تعريف متغير أو تعبير حسابي (expression). كل تعليمة بسيطة تنتهي بفاصلة منقوطة ;، وتُنفَّذ بالترتيب الذي تظهر به في الكود، من الأعلى إلى الأسفل.

simple_statements.cpp 
int x = 5;
x = x + 2;
cout << x;

اضغط على كل سطر لترى ترتيب تنفيذه:

اضغط على سطر من الكود لعرض شرحه هنا...

الناتج:

7

مثال إضافي — نفس الفكرة بسياق مختلف (تسجيل نقاط لاعب):

score_example.cpp
int score = 0;
score = score + 10;
cout << "Score: " << score;

الناتج:

Score: 10

في كلا المثالين، كل سطر هو تعليمة بسيطة تنتهي بـ ; ويتم تنفيذها بالتسلسل من الأعلى إلى الأسفل دون أي تفرّع أو تكرار.

ما بعد التنفيذ الخطي

البرامج لا تقتصر على تسلسل خطي من التعليمات فقط. في الواقع، قد يقوم البرنامج بـ:

1

تكرار جزء معيّن من الكود

باستخدام حلقات التكرار (loops) لتنفيذ نفس التعليمات عدة مرات دون إعادة كتابتها.

2

اتخاذ قرارات لتنفيذ مسار مختلف

باستخدام الشروط (conditionals) لتنفيذ جزء معيّن من الكود فقط عند تحقق شرط ما.

لتحقيق ذلك، توفّر C++ عبارات التحكم في المسار (flow control) — أدوات تخبر البرنامج: ماذا يفعل، ومتى يفعله، وتحت أي شروط. سنتعرّف على كل أداة منها بالتفصيل في الدروس القادمة:

قريباًif / else

تفرّع شرطي — تنفيذ جزء من الكود فقط إذا تحقق شرط معيّن.

قريباًswitch

اختيار مسار من بين عدّة حالات محتملة بشكل أوضح من سلسلة طويلة من if.

قريباًwhile، for، وdo-while

حلقات تكرار — تنفيذ نفس مجموعة التعليمات عدة مرات طالما تحقق شرط معيّن.

العبارات المركّبة (Compound Statements)

العبارة المركّبة هي مجموعة من التعليمات محصورة بين أقواس معقوفة { }، وتُعامَل هذه المجموعة كأنها كتلة واحدة (block). تبدو العبارة المركّبة بهذا الشكل:

compound_syntax.cpp
{
    statement1;
    statement2;
    statement3;
}

كل تعليمة داخل الكتلة تنتهي بفاصلة منقوطة خاصة بها، بينما تُعتبر الكتلة كاملة بمثابة تعليمة واحدة في سياق التحكم في المسار — وهذا بالضبط ما يسمح لاحقاً بوضع عدة تعليمات داخل جسم if أو while واحد.

مثال إضافي واقعي:

compound_example.cpp
{
    int temp = 5;
    temp = temp * 2;
    cout << temp;
}

هذه الكتلة الكاملة (بتعليماتها الثلاث) ستكون لاحقاً — مثلاً — جسم عبارة if واحدة، تُنفَّذ بأكملها معاً أو لا تُنفَّذ إطلاقاً حسب تحقق الشرط.

جرّب بنفسك الفكرة بصرياً — شاهد كيف تتحول 3 تعليمات منفصلة إلى كتلة واحدة:

{ كتلة واحدة (Block) }
int temp = 5;
temp = temp * 2;
cout << temp;
حالياً: 3 تعليمات منفصلة، كل واحدة تُحسب بمفردها.

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

Statementتعليمة

أمر مفرد في البرنامج، مثل تعريف متغير أو طباعة قيمة.

Expressionتعبير

مزيج من القيم والعوامل ينتج قيمة واحدة، مثل x + 2.

Sequential executionتنفيذ تسلسلي (خطي)

تنفيذ التعليمات بالترتيب الذي كُتبت به، من الأعلى إلى الأسفل.

Flow controlالتحكم في المسار

أدوات تُغيّر مسار تنفيذ البرنامج عبر التكرار أو الشروط بدل التسلسل الخطي فقط.

Conditionalشرطي

تعليمة تُنفَّذ فقط إذا تحقق شرط معيّن، مثل if.

Loopحلقة تكرارية

أداة تُكرر تنفيذ مجموعة تعليمات عدة مرات، مثل while وfor.

Compound statementعبارة مركّبة

مجموعة تعليمات محصورة بين { } تُعامَل ككتلة واحدة.

Blockكتلة

اسم آخر للعبارة المركّبة؛ وحدة تجميع للتعليمات بين قوسين معقوفين.
