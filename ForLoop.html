متى نستخدم حلقة for؟

تُستخدم حلقة for غالباً في الحالات التي يكون فيها عدد التكرارات معلوماً مسبقاً — مثل تكرار عملية عدداً محدداً من المرات، أو المرور على كل عنصر في مجموعة. ميزتها الأساسية أنها تسمح بكتابة ثلاثة أجزاء أساسية معاً في سطر واحد: التهيئة (initialization)، والشرط (condition)، والتحديث (update) — بعكس حلقة while التي تتطلب كتابة كل جزء في مكان منفصل من الكود.

الصياغة (Syntax):

for_syntax.cpp
for (initialization; condition; update)
    statement;

اضغط على كل جزء ملوّن من رأس الحلقة أدناه لمعرفة دوره بالتحديد:

for_annotated.cpp
for (int n = 10; n > 0; n--)
    cout << n << ", ";

كيف تعمل حلقة for؟ — خطوة بخطوة:

1

التهيئة (Initialization)

تُنفَّذ مرة واحدة فقط، قبل بداية الحلقة تماماً — مثل: int n = 10;.

2

الشرط (Condition)

يُفحص قبل كل تكرار — مثل: n > 0. إذا كان صحيحاً يُنفَّذ الأمر، وإذا كان خاطئاً تتوقّف الحلقة فوراً.

3

الأمر (Statement)

يُنفَّذ فقط إذا كان الشرط صحيحاً — مثل: cout << n << ", ";.

4

التحديث (Update)

يُنفَّذ بعد كل تكرار، ثم يعود التنفيذ لفحص الشرط من جديد — مثل: n--.

الأجزاء الاختيارية في رأس الحلقة

الأجزاء الثلاثة في رأس حلقة for (التهيئة، الشرط، التحديث) اختيارية بشكل منفرد — يمكن حذف أي منها أو أكثر من واحد — لكن الفواصل المنقوطة ; التي تفصل بينها تبقى إلزامية دائماً:

optional_parts.cpp
for (; n < 10; )    // بدون تهيئة أو تحديث
for (; n < 10; ++n) // مع تحديث فقط، بدون تهيئة

هذا مفيد مثلاً عندما يكون المتغيّر معرّفاً مسبقاً قبل الحلقة، فلا حاجة لتهيئته مرة أخرى داخل رأس for.

تحذير: إهمال الشرط يعني حلقة لا نهائية

بما أن الشرط اختياري، فإن إهماله تماماً (تركه فارغاً) يجعل الحلقة تعتبره دائماً true — أي أنها لن تتوقف أبداً ما لم يوجد أمر خاص داخلها لكسرها.

infinite_for.cpp — لا تُشغّل هذا الكود فعلياً!
for (int i = 0; ; i++) {
    cout << i << " ";
    // لا يوجد شرط توقّف هنا — حلقة لا نهائية!
}

حلقة for المبنية على المجال (Range-Based for)

نوع خاص من حلقة for يُستخدم للتكرار تلقائياً على كل عنصر في مجال (range) — مثل المصفوفات أو السلاسل النصية (strings) — دون الحاجة لكتابة تهيئة أو شرط أو تحديث يدوياً:

range_based.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string str {"Hello!"};
    for (char c : str)
        cout << "[" << c << "]";
    cout << '\n';
}

واجب منزلي

التمرين:

اكتب برنامج C++ باستخدام حلقة for يطبع كل الأعداد الزوجية من 2 إلى 20 (أي: 2, 4, 6, ..., 20)، ثم يطبع رسالة "تم!" في سطر جديد بعد انتهاء الحلقة.

تلميح: يمكنك جعل التحديث في رأس الحلقة يزيد المتغيّر بمقدار 2 في كل مرة بدلاً من 1.

homework_solution.cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 2; i <= 20; i += 2) {
        cout << i << " ";
    }
    cout << "\nتم!";
}

تحقق من فهمك

١. ما الأجزاء الثلاثة الأساسية في رأس حلقة for؟

التهيئة، الشرط، التحديث
المدخل، المعالجة، المخرج
الاسم، النوع، القيمة

٢. متى تُنفَّذ التهيئة (Initialization) في حلقة for؟

مرة واحدة فقط، قبل بداية الحلقة
بعد كل تكرار
قبل كل تكرار

٣. هل يمكن حذف أحد الأجزاء الثلاثة في رأس for (مثل الشرط) وترك الفاصلة المنقوطة؟

نعم، كل جزء اختياري لكن الفواصل المنقوطة إلزامية
لا، يجب كتابة الأجزاء الثلاثة دائماً بدون استثناء
لا، وحذف أي جزء يسبب خطأ في الترجمة فوراً

٤. ماذا يحدث إذا تُرك شرط حلقة for فارغاً تماماً؟

يُعامَل كأنه true دائماً، فتصبح الحلقة لا نهائية
يُعامَل كأنه false دائماً، فلا تُنفَّذ الحلقة إطلاقاً
يظهر خطأ ترجمة فوراً

٥. ما وظيفة حلقة for المبنية على المجال (Range-Based for)؟

المرور تلقائياً على كل عنصر في مجال، مثل سلسلة نصية أو مصفوفة
تنفيذ الحلقة عدداً غير محدود من المرات
تعريف متغيّرات ثابتة فقط

٦. ما دور الكلمة auto في for (auto c : str)؟

تجعل المترجم يحدّد نوع العنصر تلقائياً
تحوّل str إلى عدد صحيح
تُنهي الحلقة بعد أول عنصر فقط

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

forحلقة for

حلقة تكرار تجمع التهيئة والشرط والتحديث في رأس واحد.

Initializationتهيئة

الجزء الذي يُنفَّذ مرة واحدة فقط قبل بداية الحلقة.

Updateتحديث

الجزء الذي يُنفَّذ بعد كل تكرار، مثل زيادة أو إنقاص متغيّر.

Loop headerرأس الحلقة

السطر الذي يحتوي على for والأقواس بالتهيئة والشرط والتحديث.

Range-based forfor مبنية على المجال

autoتلقائي (استنتاج النوع)

كلمة مفتاحية تجعل المترجم يحدّد نوع المتغيّر تلقائياً من سياق الكود.
