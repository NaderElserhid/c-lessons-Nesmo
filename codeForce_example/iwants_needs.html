درس تفاعلي لشرح البرمجة الديناميكية والخوارزميات الجشعة (Knapsack & Greedy)

القصة: صندوق الكنز السري

تخيل أنك في لعبة فيديو، وهدفك هو جمع K من النقاط لتفوز. أمامك عدة صناديق سحرية، كل صندوق يحتوي على نوعين من الجواهر:

🔵 جواهر عادية (الأساس): سعرها عملة واحدة، وتعطيك نقطة واحدة. (عددها A)
🟡 جواهر نادرة (إضافية): سعرها عملة واحدة أيضاً، لكنها تعطيك نقطتين! (عددها B-A)

⚠️ المشكلة: الجواهر النادرة (الصفراء) مغلقة بقفل سحري! لا يمكنك شراؤها إلا إذا قمت بشراء كل الجواهر العادية (الزرقاء) الموجودة في نفس الصندوق أولاً.

سؤال التحدي: كيف تدفع أقل عدد ممكن من العملات للوصول للهدف؟ هل تشتري الجواهر العادية فقط؟ أم تستثمر لفتح الأقفال للوصول للجواهر النادرة؟

كيف يفكر المبرمج المحترف؟ (خطوات الحل)

لحل هذه المشكلة برمجياً، ندمج بين أسلوبين: حقيبة الظهر (Knapsack DP) و الطمع (Greedy).

  • 1
    تحديد تكلفة "فتح القفل":
    لكل صندوق، نعرف كم عملة نحتاج لفتحه (وهي عدد الجواهر الزرقاء A). وبالمقابل، نعرف كم جوهرة صفراء سنحصل عليها إذا فتحناه.
  • 2
    استخدام البرمجة الديناميكية (DP):
    نسأل أنفسنا: "لو قررنا التضحية بعدد معين من العملات (ولنسمه W) لفتح الأقفال، ما هو أكبر عدد ممكن من الجواهر الصفراء التي يمكننا كشفها؟". نحسب هذا لكل احتمال ممكن لقيمة W (من 0 إلى K).
  • 3
    استخدام الجشع (Greedy Strategy):
    الآن، لكل خطة وضعناها في الخطوة 2، نقوم بالآتي:
    - نحن صرفنا W عملة (وحصلنا على W نقطة من الجواهر الزرقاء).
    - نرى كم نقطة متبقية للوصول للهدف K.
    - (الجشع): نشتري أكبر قدر ممكن من الجواهر الصفراء المتاحة لأنها تعطي نقطتين بعملة واحدة!
    - إذا احتجنا المزيد من النقاط ولم تكفِ الجواهر الصفراء، نشتري جواهر زرقاء عادية من الصناديق التي لم نفتحها.
  • 4
    اختيار الأفضل:
    نقارن التكلفة النهائية لكل الخطط الممكنة، ونطبع الخطة التي كلفتنا أقل عدد من العملات!

💻 كود الحل البرمجي (C++)

هذا هو الكود الذي ينفذ الخطوات التي شرحناها في الأعلى باستخدام لغة C++ ومفاهيم البرمجة الديناميكية:

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    // تسريع عمليات الإدخال والإخراج
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    long long k;
    if (!(cin >> n >> k)) return 0;

    vector<long long> a(n), b(n);
    long long total_a = 0; // إجمالي الجواهر الزرقاء المتوفرة في اللعبة
    
    for (int i = 0; i < n; i++) {
        cin >> a[i] >> b[i];
        total_a += a[i];
    }

    // dp[w] = أقصى عدد من الجواهر الصفراء التي يمكن فتحها بتكلفة w عملة
    vector<long long> dp(k + 1, -1);
    dp[0] = 0;

    // 1. خوارزمية حقيبة الظهر (Knapsack DP) لحساب تكلفة فتح الأقفال
    for (int i = 0; i < n; i++) {
        long long w = a[i];             // تكلفة فتح الصندوق (عملات)
        long long v = b[i] - a[i];      // الجواهر الصفراء التي سنكسبها

        if (w > k) continue;

        for (long long j = k; j >= w; j--) {
            if (dp[j - w] != -1) {
                dp[j] = max(dp[j], dp[j - w] + v);
            }
        }
    }

    long long ans = -1;

    // 2. خوارزمية الجشع (Greedy) لتكملة النقاط المتبقية بأرخص طريقة
    for (long long w = 0; w <= k; w++) {
        long long m = dp[w]; // عدد الجواهر الصفراء المتاحة لنا الآن
        if (m == -1) continue; // مسار مستحيل

        long long r = k - w; // النقاط المتبقية للوصول للهدف
        
        // نحسب كم جوهرة صفراء نحتاج (كل واحدة تعطي نقطتين)
        long long needed_2 = (r > 0) ? (r + 1) / 2 : 0; 
        long long y = min(m, needed_2); // نأخذ المتاح أو ما نحتاجه فقط
        
        long long rem_points = r - 2 * y;
        long long current_cost = -1;

        if (rem_points <= 0) {
            // الجواهر الصفراء كانت كافية للوصول للهدف
            current_cost = w + y;
        } else {
            // نحتاج نكمل الباقي بجواهر زرقاء من الصناديق التي لم نفتحها
            if (total_a - w >= rem_points) {
                current_cost = w + y + rem_points;
            }
        }

        // تحديث أقل تكلفة نهائية وجدناها
        if (current_cost != -1) {
            if (ans == -1 || current_cost < ans) {
                ans = current_cost;
            }
        }
    }

    cout << ans << "\n";
    return 0;
}
