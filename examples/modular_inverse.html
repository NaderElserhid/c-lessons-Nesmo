المعكوس المعياري (Modular Inverse)

دليلك الشامل لقسمة الأرقام الضخمة تحت المودولو برمجياً ورياضياً

1. المشكلة: القسمة تكسر القواعد!

عند التعامل مع الأرقام الضخمة جداً، نستخدم معامل باقي القسمة (% MOD) لمنع تجاوز سعة الذاكرة. عمليات الجمع والطرح والضرب تعمل بشكل مباشر، ولكن القسمة لا تعمل.

القاعدة التالية خاطئة تماماً برمجياً ورياضياً:
(A / B) % MOD ≠ ((A % MOD) / (B % MOD)) % MOD
2. الحل: نظرية فيرما الصغرى

بدلاً من القسمة على رقم B، نقوم بالضرب في "معكوسه". المعكوس المعياري هو رقم إذا ضربناه في B يكون الناتج 1 تحت المودولو.

تنص نظرية فيرما الصغرى على أنه إذا كان المودولو (MOD) رقماً أولياً، فإن المعكوس يحسب برفع الرقم للأس MOD - 2:

B-1 ≡ B(MOD - 2) % MOD
لذا، تتحول عملية القسمة (A / B) إلى عملية ضرب آمنة:
Result = (A * (BMOD-2 % MOD)) % MOD
3. التطبيق البرمجي (++C)

نحتاج أولاً إلى دالة "الأس السريع" (Modular Exponentiation) لحساب الأس بكفاءة O(log N)، ثم نستخدمها لحساب المعكوس.

// 1. دالة الأس السريع long long modpow(long long base, long long exp, long long mod) { long long res = 1; base = base % mod; while (exp > 0) { if (exp % 2 == 1) res = (res * base) % mod; base = (base * base) % mod; exp /= 2; } return res; } // 2. عملية القسمة تحت المودولو (A / B) % MOD long long modDivide(long long a, long long b, long long mod) { long long inverse = modpow(b, mod - 2, mod); return (a % mod * inverse) % mod; }

الملخص السريع للعمليات المعيارية
  • الجمع: (a + b) % MOD
  • الضرب: (a * b) % MOD
  • الطرح: ((a - b) % MOD + MOD) % MOD (نضيف المودولو لتجنب النتائج السالبة)
  • القسمة: نضرب المقسوم في المعكوس المعياري للمقسوم عليه a * modpow(b, MOD - 2, MOD) % MOD
