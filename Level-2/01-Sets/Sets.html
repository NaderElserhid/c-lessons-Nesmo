المجموعات (Sets)

بعد أن أتقنت أساسيات ++C في Level 1، حان الوقت للانتقال إلى مكتبة الأنماط القياسية (STL) التي تجعل حياتك كمبرمج أسهل بكثير. في هذا الفصل ستتعرّف على أول حاوية من حاويات STL: الـ set، وكيف تخزّن به قيمًا فريدة ومرتّبة تلقائيًا، وكيف تستخدمه لحل مسائل حقيقية في البرمجة التنافسية مثل إزالة المكررات وإيجاد التقاطعات بين المجموعات.

ما هو الـ set؟

الـ set هو حاوية (container) في ++C تخزّن قيمًا من نفس النوع، وله ثلاث خصائص أساسية: كل قيمة تظهر مرة واحدة فقط (لا مكررات)، القيم مرتّبة دائمًا (افتراضيًا من الأصغر إلى الأكبر)، ويمكنك التحقق بسرعة مما إذا كان عنصر ما موجودًا فيها.

set_intro.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> numbers = {5, 2, 9, 2, 1};
    for (int x : numbers)
        cout << x << " ";
}
1 2 5 9

لاحظ أنّ الـ 2 الثانية اختفت — لأنّ الـ set لا يسمح بالقيم المكررة — ولاحظ أيضًا أنّ العناصر ظهرت مرتّبة تصاعديًا رغم أننا أدخلناها بترتيب عشوائي.

نشاط: مراجعة سريعة لخصائص الـ set

قبل أن نتقدّم خطوة جديدة، لنراجع بسرعة ما تعلّمناه للتو عن خصائص الـ set. حدّد إن كانت كل عبارة صحيحة أم خاطئة.

القيمة 2 يمكن أن تظهر أكثر من مرة في نفس الـ set.

عناصر الـ set تُرتَّب تلقائيًا من الأصغر إلى الأكبر افتراضيًا.

s.insert(5) تضيف نسخة جديدة من 5 حتى لو كانت موجودة مسبقًا.

يمكنك التحقق من وجود عنصر في set بسرعة باستخدام count() أو find().

إنشاء set

لاستخدام الـ set، أضف الـ header التالي:

#include <set>

ثم يمكنك إنشاء set بعدة طرق:

set_declare.cpp
set<int> mySet;              // empty set of integers
set<string> names;           // set of strings
set<char> letters = {'a','b','c'};

يمكنك أيضًا تهيئته بقيم مباشرةً باستخدام الأقواس المعقوفة { }، تمامًا كما فعلنا مع numbers أعلاه.

العمليات الأساسية

العمليةمثالالشرح
insert(x)s.insert(5);يضيف 5 إلى الـ set. إذا كان موجودًا مسبقًا، لا يحدث شيء.
erase(x)s.erase(5);يحذف 5 إن كان موجودًا.
find(x)if (s.find(5) != s.end())يتحقق من وجود 5، ويُعيد iterator (يشبه المؤشر).
count(x)if (s.count(5))يُعيد 1 إن وُجد، و0 إن لم يوجد. أسهل للمبتدئين.
size()s.size();عدد العناصر.
empty()s.empty();يتحقق مما إذا كان الـ set فارغًا.
clear()s.clear();يحذف جميع العناصر من الـ set.

ملعب تفاعلي: جرّب عمليات الـ set بنفسك

مثال: استخدام الـ set

set_operations.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s;
    s.insert(3);
    s.insert(1);
    s.insert(4);
    s.insert(3); // duplicate ignored

    cout << "Elements: ";
    for (int x : s) cout << x << " ";
    cout << endl;

    if (s.count(3))
        cout << "3 is in the set" << endl;

    s.erase(1);
    cout << "After removing 1: ";
    for (int x : s) cout << x << " ";
}
Elements: 1 3 4 3 is in the set After removing 1: 3 4

التنقل عبر عناصر الـ set

يمكنك المرور على عناصر الـ set باستخدام حلقة range-based for أو باستخدام iterator:

range_based.cpp
for (int x : s)
    cout << x << " ";

أو:

iterator.cpp
for (auto it = s.begin(); it != s.end(); it++)
    cout << *it << " ";

بما أنّ الـ set مرتّب دائمًا، فستظهر العناصر بنفس الترتيب التصاعدي مهما كانت الطريقة التي استخدمتها للمرور عليها.

أنواع الـ sets

النوعمرتّب؟يسمح بالمكررات؟السرعة (تقريبًا)ملاحظات
setنعملاO(log n)يعمل داخليًا بشجرة متوازنة
multisetنعمنعمO(log n)يحتفظ بنسخ متعددة من نفس القيمة
unordered_setلالاO(1) متوسطًايستخدم الـ hashing، أسرع لكن الترتيب عشوائي

إذا كان الترتيب مهمًا — استخدم set. إذا احتجت لتخزين مكررات — استخدم multiset. إذا كانت السرعة هي همّك الوحيد ولا يهمك الترتيب — استخدم unordered_set.

مثال: multiset يسمح بالمكررات

multiset_demo.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    multiset<int> ms = {4, 2, 2, 7, 4, 4};

    cout << "Elements: ";
    for (int x : ms) cout << x << " ";
    cout << endl;

    cout << "count(4) = " << ms.count(4) << endl;

    ms.erase(ms.find(4)); // erases only ONE occurrence of 4
    cout << "After erasing one 4: ";
    for (int x : ms) cout << x << " ";
}
Elements: 2 2 4 4 4 7 count(4) = 3 After erasing one 4: 2 2 4 4 7

انتبه للفرق: ms.erase(4) (بتمرير القيمة مباشرة) تحذف جميع نُسخ 4 من الـ multiset دفعة واحدة، بينما ms.erase(ms.find(4)) (بتمرير iterator) تحذف نسخة واحدة فقط. هذا فرق مهم يسبّب أخطاء شائعة للمبتدئين.

نشاط: مراجعة سريعة لأنواع الـ sets

لنراجع الآن الفروقات بين set وmultiset وunordered_set. حدّد إن كانت كل عبارة صحيحة أم خاطئة.

multiset يسمح بتخزين نفس القيمة أكثر من مرة.

unordered_set يحافظ دائمًا على ترتيب تصاعدي لعناصره.

unordered_set أسرع في المتوسط من set العادي بسبب استخدامه للـ hashing.

ms.erase(4) في multiset تحذف نسخة واحدة فقط من القيمة 4 وتترك الباقي.

مثال: إزالة المكررات

من أشهر استخدامات الـ set هو إزالة القيم المكررة من مصفوفة أو vector بسرعة وبساطة:

remove_duplicates.cpp
#include <iostream>
#include <set>
#include <vector>
using namespace std;

int main() {
    vector<int> nums = {1, 2, 2, 3, 4, 3, 1};
    set<int> unique;

    for (int x : nums)
        unique.insert(x);

    for (int x : unique)
        cout << x << " ";
}
1 2 3 4

أمثلة إضافية

مثال إضافي 1: تقاطع مجموعتين (Intersection)

يمكننا إيجاد العناصر المشتركة بين مجموعتين بالمرور على عناصر الأولى والتحقق من وجودها في الثانية باستخدام count():

intersection.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> a = {1, 2, 3, 4, 5};
    set<int> b = {3, 4, 5, 6, 7};

    set<int> common;
    for (int x : a) {
        if (b.count(x)) common.insert(x);
    }

    cout << "Common elements: ";
    for (int x : common) cout << x << " ";
}
Common elements: 3 4 5

مثال إضافي 2: اتحاد مجموعتين (Union)

ولإيجاد اتحاد مجموعتين، نبدأ بنسخة من الأولى ثم نُدرج عليها عناصر الثانية — الـ set سيتكفّل تلقائيًا بتجاهل أي مكررات:

union.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> a = {1, 2, 3};
    set<int> b = {3, 4, 5};

    set<int> merged = a;
    for (int x : b) merged.insert(x);

    cout << "Union: ";
    for (int x : merged) cout << x << " ";
}
Union: 1 2 3 4 5

تمارين منزلية

1) عدّ العناصر المميّزة في مصفوفة

اقرأ عددًا صحيحًا n ثم n عددًا صحيحًا، واطبع عدد القيم المختلفة بينها (بدون تكرار).

hw1.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    int n;
    cin >> n;

    set<int> s;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        s.insert(x);
    }

    cout << s.size();
}
Input: 7 / 1 2 2 3 4 3 1 → Output: 4

2) حذف قيمة معيّنة إن وُجدت

لدينا set<int> s = {10, 20, 30, 40, 50};. اقرأ قيمة target، واحذفها من المجموعة إن كانت موجودة، ثم اطبع رسالة مناسبة والعناصر المتبقية.

hw2.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s = {10, 20, 30, 40, 50};
    int target;
    cin >> target;

    if (s.count(target)) {
        s.erase(target);
        cout << "Removed. Remaining: ";
    } else {
        cout << "Not found. Set stays: ";
    }

    for (int x : s) cout << x << " ";
}
Input: 20 → Removed. Remaining: 10 30 40 50 Input: 99 → Not found. Set stays: 10 20 30 40 50

3) التحقّق من الكلمات المكرّرة

اقرأ عددًا صحيحًا n ثم n كلمة، واطبع "Yes" إن كانت هناك كلمة مكرّرة، أو "No" إن كانت جميع الكلمات مختلفة.

hw3.cpp
#include <iostream>
#include <set>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;

    set<string> seen;
    bool hasDuplicate = false;

    for (int i = 0; i < n; i++) {
        string word;
        cin >> word;
        if (seen.count(word)) hasDuplicate = true;
        seen.insert(word);
    }

    cout << (hasDuplicate ? "Yes" : "No");
}
Input: apple banana apple cherry banana → Yes Input: apple banana cherry → No

تحقق من فهمك

١. ماذا يحدث عند إدراج قيمة موجودة مسبقًا في set باستخدام insert()؟

تُضاف نسخة ثانية من نفس القيمة
لا يحدث شيء، ويبقى الـ set كما هو
يحدث خطأ في التشغيل (runtime error)

٢. ما الفرق بين find() و count() في الـ set؟

find() يُعيد iterator يشير إلى العنصر (أو end() إن لم يوجد)، بينما count() يُعيد 0 أو 1 مباشرة
لا فرق بينهما إطلاقًا
count() أبطأ بكثير من find() دائمًا

٣. أي نوع من الحاويات يسمح بتخزين قيم مكرّرة؟

set
multiset
unordered_set

٤. أيّ نوع يمنحك أسرع أداء تقريبًا لكن بدون أي ترتيب مضمون للعناصر؟

set
multiset
unordered_set

٥. ما تعقيد عمليات insert وerase وfind في set العادي؟

O(1) دائمًا
O(log n) تقريبًا، لأنه يعمل داخليًا بشجرة متوازنة
O(n) دائمًا

٦. في multiset، ما الفرق بين ms.erase(4) وms.erase(ms.find(4))؟

الأولى تحذف جميع نسخ 4، والثانية تحذف نسخة واحدة فقط
كلاهما يحذف نسخة واحدة فقط
كلاهما يحذف جميع النسخ

٧. لماذا يُعتبر الـ set أداة مناسبة لإزالة المكررات من مصفوفة؟

لأنه يرفض تلقائيًا إدراج أي قيمة موجودة مسبقًا فيه
لأنه يُرتّب المصفوفة الأصلية مباشرة دون الحاجة لحاوية جديدة
لأنه يسمح بالمكررات فقط إذا كانت متجاورة

٨. أي header يجب تضمينه لاستخدام set في ++C؟

#include <vector>
#include <set>
#include <array>

٩. عند المرور على عناصر set باستخدام range-based for، بأي ترتيب تظهر العناصر؟

بنفس ترتيب إدخالها بالضبط
مرتّبة تصاعديًا دائمًا بغض النظر عن ترتيب الإدخال
بترتيب عشوائي مختلف في كل مرة

١٠. ماذا تفعل الدالة empty() على set؟

تُفرغ المجموعة من جميع عناصرها
تتحقق مما إذا كانت المجموعة فارغة، وتُعيد true أو false
تُعيد عدد العناصر الفارغة داخل المجموعة

قاموس المصطلحات

Setمجموعة

حاوية تخزّن قيمًا فريدة ومرتّبة تلقائيًا.

Multisetمجموعة متعددة

مثل set لكنها تسمح بتكرار نفس القيمة أكثر من مرة.

Unordered_setمجموعة غير مرتّبة

مجموعة فريدة العناصر لكن دون ترتيب مضمون، أسرع في المتوسط باستخدام الـ hashing.

Insertإدراج

إضافة عنصر جديد إلى الحاوية.

Eraseحذف

إزالة عنصر (أو عنصر يشير إليه iterator) من الحاوية.

Iteratorمكرِّر

كائن يشبه المؤشر، يُستخدم للإشارة إلى موضع عنصر داخل حاوية والتنقل بينها.

Balanced Treeشجرة متوازنة

بنية البيانات الداخلية التي يعتمد عليها set وmultiset للحفاظ على الترتيب والسرعة.

Hashingالتجزئة

تقنية تُستخدم داخليًا في unordered_set لتحقيق سرعة وصول عالية دون الحاجة للترتيب.
