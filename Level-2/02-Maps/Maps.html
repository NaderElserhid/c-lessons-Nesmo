الفصل الثاني: الخرائط (Maps)

بعد أن تعلّمت كيف تخزّن قيمًا فريدة باستخدام الـ set، حان الوقت لتتعلّم كيف تربط كل قيمة بمعلومة إضافية باستخدام الـ map. في هذا الفصل ستكتشف كيف تُخزَّن البيانات على شكل مفتاح وقيمة، وكيف تتجنّب أشهر فخّ يقع فيه المبتدئون عند الوصول إلى العناصر، وستستخدم ما تتعلّمه لبناء أدوات عملية مثل عدّاد تكرار الكلمات.

ما هو الـ map؟

الـ map هو حاوية في ++C تُخزّن أزواجًا من العناصر بهذا الشكل: key -> value، وتقوم بترتيبها حسب المفتاح (key) تلقائيًا.

map_intro.cpp
#include <iostream>
#include <map>
using namespace std;

int main() {
    map<string, int> ages;
    ages["Alice"] = 25;
    ages["Bob"] = 30;
    ages["Charlie"] = 22;

    for (auto p : ages)
        cout << p.first << ": " << p.second << endl;
}
Alice: 25 Bob: 30 Charlie: 22

لاحظ أنّ الأسماء طُبعت بالترتيب الأبجدي، رغم أننا أدخلناها بترتيب مختلف — لأنّ map يرتّب المفاتيح تلقائيًا.

إنشاء خريطة (Creating a map)

لاستخدام الخريطة، أضف الـ header التالي:

#include <map>

ثم يمكنك إعلانها بعدة طرق حسب نوع المفتاح والقيمة:

map_declare.cpp
map<int, string> students;     // المفتاح: int، القيمة: string
map<string, double> prices;    // المفتاح: string، القيمة: double
map<char, int> frequency;      // المفتاح: char، القيمة: int

إضافة والوصول للعناصر

map_access.cpp
map<string, int> scores;
scores["Mark"] = 90;          // الإضافة باستخدام []
cout << scores["Mark"];       // يطبع 90
90

إذا حاولت الوصول لمفتاح غير موجود باستخدام []، سيتم إنشاؤه تلقائيًا بقيمة افتراضية (مثل 0 للأعداد الصحيحة)، حتى لو كنت تنوي فقط قراءته وليس تعديله!

cout << scores["Unknown"]; — ينشئ المفتاح "Unknown" بقيمة 0، ويصبح جزءًا من الخريطة فعليًا من الآن فصاعدًا.

إذا كنت لا تريد هذا السلوك، استخدم count() للتحقق أولًا من وجود المفتاح دون إنشائه:

safe_check.cpp
if (scores.count("Tom"))
    cout << "Tom found!";

نشاط: مراجعة سريعة للوصول إلى عناصر الـ map

لنراجع بسرعة السلوك المهم (والفخّ الشائع!) الذي تعلّمناه للتو عند الوصول إلى عناصر map. حدّد إن كانت كل عبارة صحيحة أم خاطئة.

الوصول لمفتاح غير موجود باستخدام [] ينشئ ذلك المفتاح تلقائيًا بقيمة افتراضية.

استخدام count(key) للتحقق من وجود مفتاح يُنشئ ذلك المفتاح إذا لم يكن موجودًا.

cout << scores["Unknown"]; لن يغيّر حجم (size) الخريطة إطلاقًا.

count() هي الطريقة الآمنة للتحقق من وجود مفتاح دون التسبب بإنشائه.

العمليات الشائعة

العمليةالمثالالوصف
m[key]m["Bob"]الوصول إلى العنصر أو إنشاؤه إن لم يكن موجودًا.
erase(key)m.erase("Bob")إزالة المفتاح والقيمة المرتبطة به.
count(key)if (m.count("Bob"))1 إذا كان المفتاح موجودًا، 0 إذا لم يكن — دون إنشائه.
size()m.size();إعادة عدد العناصر.
clear()m.clear();حذف جميع العناصر.
empty()m.empty();التحقق مما إذا كانت الخريطة فارغة.

ملعب تفاعلي: جرّب عمليات الـ map بنفسك

جرّب زر cout << m[key] بمفتاح غير موجود في الملعب أعلاه — ستلاحظ أنّه يُنشئ المفتاح فعليًا بقيمة 0 بدلًا من مجرد "عدم العثور عليه"! هذا بالضبط السلوك الذي حذّرنا منه سابقًا.

مثال: عدّ تكرار الكلمات

من أكثر استخدامات الـ map شيوعًا هو عدّ عدد مرات ظهور كل عنصر (كلمة، حرف، رقم...) داخل بيانات معيّنة:

word_frequency.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    string text = "apple banana apple orange banana apple";
    map<string, int> freq;
    string word;

    for (auto c : text) {
        if (c == ' ') {
            if (!word.empty()) freq[word]++;
            word.clear();
        } else {
            word += c;
        }
    }
    if (!word.empty()) freq[word]++; // آخر كلمة

    for (auto p : freq)
        cout << p.first << ": " << p.second << endl;
}
apple: 3 banana: 2 orange: 1

لاحظ الحيلة الأنيقة هنا: freq[word]++ تستفيد من سلوك الإنشاء التلقائي بقيمة 0 — فأول مرة تظهر فيها كلمة، يُنشئ map إدخالًا لها بقيمة 0 ثم يزيدها فورًا إلى 1، دون الحاجة لأي كود إضافي للتحقق من وجودها مسبقًا!

التكرار عبر الخريطة

يمكنك التكرار باستخدام حلقة for بنطاق (range-based for):

range_based.cpp
for (auto p : myMap)
    cout << p.first << " -> " << p.second << endl;

أو باستخدام المؤشرات (iterators):

iterator.cpp
for (auto it = myMap.begin(); it != myMap.end(); it++)
    cout << it->first << ": " << it->second << endl;

first = المفتاح (key)، وsecond = القيمة (value)، سواء استخدمت p.first أو it->first.

أنواع الخرائط

النوعيحافظ على الترتيب؟يسمح بالمفاتيح المكررة؟السرعة (متوسط)ملاحظات
mapنعملاO(log n)يخزن المفاتيح مرتّبة (شجرة متوازنة)
unordered_mapلالاO(1) متوسطًاسريع، لكن الترتيب عشوائي

مثال: unordered_map

unordered_map_demo.cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    unordered_map<string, int> age;
    age["Bob"] = 30;
    age["Alice"] = 25;
    age["Tom"] = 28;

    for (auto p : age)
        cout << p.first << ": " << p.second << endl;
}
(الترتيب قد يكون عشوائيًا، على سبيل المثال) Tom: 28 Alice: 25 Bob: 30

لذلك unordered_map عادةً أسرع، لكنه لا يرتّب المفاتيح — استخدمه فقط عندما لا يهمّك ترتيب الإخراج.

نشاط: مراجعة سريعة لـ map وunordered_map

لنراجع الآن الفرق بين map وunordered_map. حدّد إن كانت كل عبارة صحيحة أم خاطئة.

unordered_map يرتّب مفاتيحه أبجديًا/تصاعديًا تمامًا مثل map.

unordered_map أسرع في المتوسط من map بسبب استخدامه للـ hashing.

map يعتمد داخليًا على شجرة متوازنة للحفاظ على ترتيب المفاتيح.

لا يمكن استخدام string كنوع بيانات للمفتاح في map.

أمثلة إضافية

مثال إضافي 1: العثور على المفتاح صاحب أكبر قيمة

يمكننا المرور على عناصر الخريطة والاحتفاظ بأكبر قيمة رأيناها حتى الآن مع مفتاحها:

find_max.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> ages;
    ages["Alice"] = 25;
    ages["Bob"] = 30;
    ages["Charlie"] = 22;

    string bestName = "";
    int bestAge = -1;
    for (auto p : ages) {
        if (p.second > bestAge) {
            bestAge = p.second;
            bestName = p.first;
        }
    }

    cout << bestName << " is the oldest at " << bestAge;
}
Bob is the oldest at 30

مثال إضافي 2: التكرار الحديث باستخدام structured bindings

في ++C17 وما بعده، يمكنك تفكيك الزوج p.first وp.second مباشرة إلى اسمين واضحين، مما يجعل الكود أسهل قراءةً:

structured_bindings.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> ages = {{"Alice", 25}, {"Bob", 30}, {"Charlie", 22}};

    for (auto& [name, age] : ages)
        cout << name << " -> " << age << endl;
}
Alice -> 25 Bob -> 30 Charlie -> 22

تمارين منزلية

1) عدّ تكرار كل حرف في نص

اقرأ سطرًا نصيًا، واطبع عدد مرات ظهور كل حرف فيه (باستثناء المسافات)، باستخدام map<char, int>.

hw1.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    string text;
    getline(cin, text);

    map<char, int> freq;
    for (char c : text) {
        if (c != ' ') freq[c]++;
    }

    for (auto p : freq)
        cout << p.first << ": " << p.second << endl;
}
Input: aabbbc Output: a: 2 b: 3 c: 1

2) التحقق من وجود مفتاح دون إنشائه بالخطأ

لدينا map<string, int> stock تحتوي بعض المنتجات. اقرأ عددًا من الاستعلامات، ولكل استعلام اطبع "Yes" إن كان المنتج موجودًا في المخزون أو "No" إن لم يكن — دون أن يتسبب الاستعلام نفسه في إضافة المنتج بالخطأ.

hw2.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> stock;
    stock["apple"] = 10;
    stock["banana"] = 5;

    int q;
    cin >> q;
    while (q--) {
        string item;
        cin >> item;
        if (stock.count(item))  // count() لا يُنشئ المفتاح، بعكس []
            cout << "Yes" << endl;
        else
            cout << "No" << endl;
    }

    cout << "Final size: " << stock.size();
}
Input: 3 / apple mango banana Output: Yes No Yes Final size: 2

3) دمج خريطتين

لدينا خريطتان a وb تمثّلان تكرار عناصر من مصدرين مختلفين. اجمعهما في خريطة واحدة merged، بحيث إذا تكرر نفس المفتاح في الخريطتين، تُجمَع قيمتاه معًا.

hw3.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> a = {{"apple", 3}, {"banana", 2}};
    map<string, int> b = {{"banana", 4}, {"cherry", 1}};

    map<string, int> merged = a;
    for (auto p : b) {
        merged[p.first] += p.second; // يُنشئ المفتاح بقيمة 0 أولًا إذا لم يكن موجودًا، ثم يضيف
    }

    for (auto p : merged)
        cout << p.first << ": " << p.second << endl;
}
apple: 3 banana: 6 cherry: 1

تحقق من فهمك

١. ماذا يحدث عند الوصول لمفتاح غير موجود باستخدام []؟

يحدث خطأ في التشغيل (runtime error)
يتم إنشاء المفتاح تلقائيًا بقيمة افتراضية (مثل 0)
لا يحدث شيء، ويُعاد -1

٢. كيف تتحقق من وجود مفتاح دون إنشائه بالخطأ؟

باستخدام m[key] مباشرة
باستخدام count(key)
لا توجد طريقة آمنة لذلك

٣. بأي ترتيب يطبع map عناصره عند التكرار عليها؟

بترتيب الإدخال (نفس الترتيب الذي أضفت به العناصر)
مرتّبة تصاعديًا حسب المفتاح
بترتيب عشوائي دائمًا

٤. في عبارة p (حيث p زوج من map)، ماذا يمثّل p.second؟

المفتاح
القيمة
موضع العنصر في الخريطة

٥. متى تفضّل unordered_map على map؟

عندما تريد أسرع أداء ممكن ولا يهمّك ترتيب المفاتيح
عندما تحتاج طباعة العناصر مرتّبة
unordered_map لا يمكن استخدامه مع النصوص

٦. لماذا تعمل freq[word]++ بشكل صحيح حتى لو كانت "word" تظهر للمرة الأولى؟

لأنّ [] تُنشئ المفتاح تلقائيًا بقيمة 0 أولًا، ثم ++ تزيدها إلى 1
لأنّ map يتجاهل العناصر غير الموجودة
هذا خطأ برمجي يجب تجنّبه دائمًا

٧. ما الفرق الأساسي بين set وmap؟

set يخزّن قيمًا فقط، بينما map يخزّن أزواج مفتاح-قيمة
لا فرق بينهما إطلاقًا
map لا يمكنه تخزين الأعداد الصحيحة

٨. ماذا يمثّل p.first في زوج ناتج عن map؟

المفتاح (key)
القيمة (value)
موضع العنصر داخل الخريطة

٩. ما تعقيد عمليات الإدراج والحذف والبحث في map العادي؟

O(1) دائمًا
O(log n) تقريبًا، لأنه يعتمد على شجرة متوازنة
O(n) دائمًا

١٠. أي دالة تحذف كل عناصر الخريطة دفعة واحدة؟

erase()
clear()
empty()

قاموس المصطلحات

Mapخريطة

حاوية تخزّن أزواج مفتاح-قيمة مرتّبة تلقائيًا حسب المفتاح.

Keyمفتاح

المعرّف الفريد الذي يُستخدم للوصول إلى القيمة المرتبطة به.

Valueقيمة

البيانات المخزّنة والمرتبطة بمفتاح معيّن.

Unordered_mapخريطة غير مرتّبة

مثل map لكن بدون ترتيب مضمون، وأسرع في المتوسط باستخدام الـ hashing.

pairزوج

الوحدة الأساسية داخل map، تحتوي على first (المفتاح) وsecond (القيمة).

Structured Bindingsالتفكيك البنيوي

ميزة في ++C17 تسمح بتفكيك pair أو struct إلى متغيرات منفصلة بأسماء واضحة.
