الترتيب (Sorting)

في الفصل الماضي تعلّمت كيف تقيس سرعة الخوارزميات بلغة Big O، ورأيت أنّ خوارزميات مثل البحث الثنائي لا تعمل إلا على بيانات مرتّبة. في هذا الفصل سنتعلّم كيف نرتّب البيانات فعليًا: أولًا بأيدينا عبر خوارزمية ترتيب الاختيار، ثم بالطريقة الاحترافية التي يستخدمها المبرمجون فعليًا في البرمجة التنافسية — الدالة الجاهزة sort() — وسنقارن سرعة الطريقتين رقميًا لنرى الفرق الحقيقي الذي يصنعه اختيار الخوارزمية المناسبة.

ما هو الترتيب؟

الترتيب (Sorting) يعني إعادة ترتيب عناصر مجموعة بيانات ضمن تسلسل محدد، عادة من الأصغر إلى الأكبر (تصاعديًا)، أو أبجديًا إذا كانت العناصر نصية.

الترتيب يجعل البيانات أسهل في البحث والمقارنة والمعالجة بكفاءة. العديد من الخوارزميات المهمة — مثل البحث الثنائي (Binary Search) الذي درسته في الفصل الماضي — لا تعمل بشكل صحيح إلا إذا كانت البيانات مرتّبة مسبقًا.

تذكّر أنّ البحث الثنائي يعمل بتعقيد O(log n)، لكنه يفترض أنّ المصفوفة مرتّبة أصلًا. لهذا الترتيب هو غالبًا "الخطوة التمهيدية" قبل استخدام خوارزميات أسرع بكثير.

ترتيب الاختيار (Selection Sort)

الفكرة: ترتيب الاختيار يجد بشكل متكرر أصغر عنصر من الجزء غير المرتّب من المصفوفة، وينقله إلى بداية ذلك الجزء.

خطوة بخطوة

  • إيجاد أصغر عنصر في المصفوفة كاملة.

  • تبديله (swap) مع العنصر الأول.

  • إيجاد أصغر عنصر في الجزء المتبقي، وتبديله مع العنصر الثاني.

  • الاستمرار بنفس الطريقة حتى تصبح المصفوفة كاملة مرتّبة.

مثال

لنفترض أنّ لدينا المصفوفة:

[5, 8, 3, 4, 2]

نجد أصغر عنصر وهو 2، ونبدّله مع أول عنصر 5. تصبح المصفوفة:

[2, 8, 3, 4, 5]

الآن نريد وضع ثاني أصغر عنصر في الموقع الثاني. نجد الأصغر بين 8, 3, 4, 5 وهو 3، ونبدّله مع العنصر الثاني 8. تصبح المصفوفة:

[2, 3, 8, 4, 5]

نجد ثالث أصغر عنصر بين 8, 4, 5 وهو 4، ونبدّله مع العنصر الثالث 8:

[2, 3, 4, 8, 5]

في الخطوة الأخيرة، نجد رابع أصغر عنصر بين 8, 5 وهو 5، ونبدّله مع العنصر الرابع 8:

[2, 3, 4, 5, 8]

أصبحت المصفوفة مرتّبة بالكامل!

الكود

selection_sort.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {5, 8, 3, 4, 2};
    int n = arr.size();

    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex])
                minIndex = j;
        }
        swap(arr[i], arr[minIndex]);
    }

    for (int x : arr)
        cout << x << ' ';
    cout << '\n';
}
2 3 4 5 8

ترتيب الاختيار سهل الفهم، لكنه غير فعّال جدًا للمصفوفات الكبيرة.

التعقيد الزمني

هناك حلقتان متداخلتان: الخارجية تعمل n مرة، والداخلية تعمل حتى n مرة أيضًا. لذا يستغرق تقريبًا n² خطوة → زمن O(n²).

نشاط: مراجعة سريعة لترتيب الاختيار

حدّد إن كانت كل عبارة صحيحة أم خاطئة.

ترتيب الاختيار يجد أكبر عنصر في كل مرة وينقله إلى النهاية.

التعقيد الزمني لترتيب الاختيار هو O(n²) بسبب الحلقتين المتداخلتين.

البحث الثنائي (Binary Search) يمكن استخدامه بشكل صحيح على مصفوفة غير مرتّبة.

استخدام الدالة الجاهزة sort

في البرامج الحقيقية وفي البرمجة التنافسية، نادرًا ما نكتب الترتيب يدويًا. توفّر C++ دالة ترتيب سريعة جدًا في مكتبتها القياسية داخل <algorithm>.

ترتيب vector

sort_vector.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {5, 8, 3, 4, 2};
    sort(arr.begin(), arr.end());

    for (int x : arr)
        cout << x << ' ';
    cout << '\n';
}
2 3 4 5 8

السطر sort(arr.begin(), arr.end()); يرتّب الـ vector بأكمله تصاعديًا.

ترتيب array عادي

يمكن استخدام نفس sort مع المصفوفات العادية أيضًا:

sort_array.cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n = 5;
    int arr[] = {5, 8, 3, 4, 2};

    sort(arr, arr + n);

    for (int i = 0; i < n; i++)
        cout << arr[i] << ' ';
    cout << '\n';
}
2 3 4 5 8

sort(arr, arr + n); يعني: رتّب المصفوفة ابتداءً من arr وحتى arr + n (أي بعد آخر عنصر مباشرة).

الترتيب تنازليًا

إذا أردت الترتيب من الأكبر إلى الأصغر، استخدم مقارنة مخصّصة:

لـ vector

sort_desc.cpp
sort(arr.begin(), arr.end(), greater<int>());
// أو باستخدام iterators مع العكس:
sort(arr.rbegin(), arr.rend());

للمصفوفة العادية

sort_desc_array.cpp
sort(arr, arr + n, greater<int>());

وكل الطرق الثلاث تنتج، على المصفوفة {5, 8, 3, 4, 2}، نفس الناتج:

8 5 4 3 2

ترتيب أنواع أخرى

الدالة نفسها تعمل مع string أو double أو أي نوع قابل للمقارنة:

sort_strings.cpp
vector<string> names = {"Bob", "Alice", "Charlie"};
sort(names.begin(), names.end());

for (auto &s : names) cout << s << ' ';
Alice Bob Charlie

لاحظ أنّ ترتيب النصوص افتراضيًا يكون أبجديًا (lexicographic)، وليس حسب الطول.

الترتيب بمقارنة مخصّصة (Comparator)

يمكنك ترتيب مصفوفة حسب شروط خاصة بكتابة دالة comparator تأخذ عنصرين a وb وتعيد true إذا كان يجب أن يأتي a قبل b.

مثال: ترتيب النصوص حسب طولها

sort_comparator.cpp
bool comparator_by_length(string a, string b) {
    int len_a = a.length();
    int len_b = b.length();

    if (len_a < len_b)
        return 1;
    else
        return 0;
}

ثم نستخدمها مع sort كوسيط ثالث:

use_comparator.cpp
vector<string> names = {"Bob", "Alice", "Charlie"};
sort(names.begin(), names.end(), comparator_by_length);

for (auto &s : names) cout << s << ' ';
Bob Alice Charlie

لاحظ الفرق: بينما الترتيب الافتراضي أعطى Alice Bob Charlie (أبجديًا)، أعطانا comparator الطول Bob Alice Charlie (من الأقصر 3 أحرف، إلى 5 أحرف، إلى 7 أحرف).

ملاحظة مهمة: يجب أن تتصرّف دالة المقارنة مثل عملية "أصغر من" (less than) حقيقية: يجب ألّا تتناقض مع نفسها، ويجب ألّا تحتوي على دورات مثل a < b ثم b < c ثم c < a في آن واحد. إذا كانت المقارنة غير متّسقة، فإنّ سلوك sort يصبح غير معرّف (undefined behavior) وقد يتعطّل البرنامج.

نشاط: مراجعة سريعة لدالة sort والمقارنة المخصّصة

حدّد إن كانت كل عبارة صحيحة أم خاطئة.

sort(arr.begin(), arr.end(), greater<int>()) يرتّب المصفوفة تنازليًا.

يمكن أن تحتوي دالة المقارنة (comparator) على دورة تناقض مثل a<b وb<c وc<a في نفس الوقت دون أي مشكلة.

دالة sort الجاهزة في C++ تعمل فقط مع الأعداد الصحيحة (int)، ولا تعمل مع النصوص.

التعقيد الزمني للترتيب

دالة sort الجاهزة في المكتبة القياسية تستخدم خوارزمية محسّنة (مزيج من quicksort وheapsort وinsertion sort)، وتعقيدها الزمني O(n log n) — أسرع بكثير من O(n²) الخاص بترتيب الاختيار عندما يكون n كبيرًا.

nترتيب الاختيار O(n²)sort الجاهزة O(n log n)
10100≈ 33
10010,000≈ 664
1,0001,000,000≈ 9,966

عند n = 1000: ترتيب الاختيار يقوم بحوالي 1,000,000 عملية، بينما دالة sort تقوم بحوالي 10,000 عملية فقط — أسرع حوالي 100 مرة! وكلما كبر n، كلما اتّسعت الفجوة أكثر (تذكّر جدول مقارنة معدلات النمو من الفصل الماضي).

لهذا السبب، في البرمجة التنافسية نستخدم دالة sort الجاهزة دائمًا تقريبًا بدلًا من كتابة ترتيب الاختيار يدويًا — فهي أسرع وأقل عرضة للأخطاء.

تمارين منزلية

1) رتّب تنازليًا باستخدام comparator

لديك المصفوفة {9, 1, 7, 3, 5}. اكتب كودًا يرتّبها تنازليًا باستخدام greater<int>().

hw1.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> arr = {9, 1, 7, 3, 5};
    sort(arr.begin(), arr.end(), greater<int>());
    for (int x : arr) cout << x << ' ';
}
9 7 5 3 1

2) رتّب حسب أول حرف فقط

لديك المصفوفة {"Cherry", "Apple", "Banana", "Date"}. اكتب دالة comparator ترتّب النصوص حسب أول حرف فقط (وليس النص كاملًا).

hw2.cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

bool cmpFirstLetter(string a, string b) {
    return a[0] < b[0];
}

int main() {
    vector<string> words = {"Cherry", "Apple", "Banana", "Date"};
    sort(words.begin(), words.end(), cmpFirstLetter);
    for (auto &w : words) cout << w << ' ';
}
Apple Banana Cherry Date

نقارن فقط a[0] مع b[0] بدلًا من مقارنة النص كاملًا.

3) رتّب طلابًا حسب الدرجة تنازليًا

لديك مصفوفة من الأزواج pair<string, int> تمثّل كل واحدة (اسم الطالب، درجته): {{"Ali",88}, {"Sara",95}, {"Omar",72}}. رتّبها تنازليًا حسب الدرجة.

hw3.cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

bool cmpByScoreDesc(pair<string,int> a, pair<string,int> b) {
    return a.second > b.second;
}

int main() {
    vector<pair<string,int>> students = {{"Ali",88}, {"Sara",95}, {"Omar",72}};
    sort(students.begin(), students.end(), cmpByScoreDesc);
    for (auto &s : students)
        cout << s.first << ":" << s.second << "  ";
}
Sara:95 Ali:88 Omar:72

الـ comparator يقارن a.second مع b.second (الدرجة)، ويستخدم > بدلًا من < لجعل الترتيب تنازليًا.

تحقق من فهمك

١. ما الذي يفعله ترتيب الاختيار (Selection Sort) في كل خطوة؟

يجد أصغر عنصر في الجزء غير المرتّب وينقله إلى بداية ذلك الجزء
يبدّل كل عنصرين متجاورين إذا كانا غير مرتّبين
يقسّم المصفوفة إلى نصفين ويرتّب كل نصف على حدة
