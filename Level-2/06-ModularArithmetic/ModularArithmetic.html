الفصل السادس: الحسابيات المعيارية (Modular Arithmetic)

خلال هذا المستوى تعاملت مع مصفوفات، رتّبتها، وبحثت فيها بسرعة. لكن ماذا يحدث عندما تصبح الأرقام في مسألة ما ضخمة جدًا لدرجة أنها لا تتّسع حتى في متغيّر long long؟ في هذا الفصل ستتعلّم "الحسابيات المعيارية" — أداة أساسية في البرمجة التنافسية تُبقي الأرقام صغيرة ومُدارة عن طريق أخذ الباقي دائمًا عند القسمة على عدد معيّن، تمامًا كما تدور عقارب الساعة كل 12 أو 24 ساعة.

ما معنى mod؟

الحسابيات المعيارية (Modular Arithmetic) هي طريقة للقيام بالعمليات الحسابية حيث "تدور" الأعداد بعد الوصول إلى قيمة معيّنة تُسمّى المعامل (modulus).

فكّر بها مثل الساعة: بعد مرور 24 ساعة، تعود الساعة لنفس الوقت من جديد. هذه هي بالضبط عملية mod 24!

عندما نقول a mod m، فهذا يعني الباقي عند قسمة a على m.

التعبيرالمعنىالنتيجة
7 mod 37 ÷ 3 → الباقي1
10 mod 410 ÷ 4 → الباقي2
15 mod 615 ÷ 6 → الباقي3
12 mod 1212 ÷ 12 → الباقي0

في C++ نستخدم عامل % لحساب الباقي:

basic_mod.cpp
#include <iostream>
using namespace std;

int main() {
    cout << 7 % 3 << endl;    // 1
    cout << 10 % 4 << endl;   // 2
    cout << 10 % 5 << endl;   // 0
}
1 2 0

المختبر التفاعلي: ساعة العدّ (Clock of mod 12)

شاهد كيف "تدور" الأرقام حول الساعة عند العد للأمام 15 خطوة بدءًا من 0 — تمامًا مثل mod 12.

اضغط "ابدأ العدّ" للعدّ للأمام 15 خطوة بدءًا من 0.

لماذا نستخدم الحسابيات المعيارية في البرمجة؟

عند التعامل مع أعداد كبيرة جدًا (مثلًا في التوافقيات أو التشفير)، قد تصبح النتائج أكبر من أن تتّسع لأنواع البيانات العادية، بل وحتى لـ long long. الحل: نأخذ الباقي (mod) بعد كل عملية لنُبقي الأرقام صغيرة طوال الوقت.

المعامل الشائع في البرمجة التنافسية:

constant.cpp
const int MOD = 1'000'000'007; // عدد أولي كبير

لماذا نستخدمه بالتحديد؟

  • يناسب الأعداد 64-بت بأمان (لا يسبّب تجاوز سعة عند ضرب رقمين أصغر منه).

  • يتجنّب تجاوز السعة (overflow) عند الجمع أو الضرب المتكرر.

  • لأنه عدد أولي، له خصائص رياضية مفيدة (مثل إمكانية حساب المعكوس المعياري، كما سنرى لاحقًا).

مثال: جمع أعداد كبيرة

big_sum.cpp
#include <iostream>
using namespace std;

int main() {
    const int MOD = 1'000'000'007;
    long long a = 1e12, b = 1e12;
    cout << (a + b) % MOD << endl;
}
999986007

بدون أخذ mod، كان الناتج سيكون 2,000,000,000,000 — رقم كبير جدًا قد يسبّب مشاكل في بعض العمليات اللاحقة. بأخذ mod، حافظنا على النتيجة ضمن نطاق صغير وآمن.

قواعد أساسية

الجمع

(a + b) % m = (a % m + b % m) % m

الطرح

(a - b) % m = ((a % m - b % m) + m) % m

نضيف + m لضمان عدم الحصول على نتيجة سالبة (سنرى السبب بالتفصيل بعد قليل).

الضرب

(a * b) % m = (a % m * b % m) % m

مثال

rules_example.cpp
int a = 7, b = 5, m = 3;
cout << (a + b) % m << endl;   // 0
cout << (a * b) % m << endl;   // 2
0 2

نشاط: مراجعة سريعة لمفهوم mod والقواعد الأساسية

حدّد إن كانت كل عبارة صحيحة أم خاطئة.

12 mod 12 يساوي 12.

الساعة (تدور كل 12 أو 24 ساعة) مثال جيد على فكرة mod.

نستخدم المعامل 1,000,000,007 لأنه عدد أولي كبير يناسب الأعداد 64-بت ويساعد على تجنّب تجاوز السعة.

(a * b) % m تساوي دائمًا (a % m * b % m) % m.

التعامل مع الأعداد السالبة

في C++، عامل % قد يعطي نتيجة سالبة عندما يكون أحد الطرفين سالبًا:

negative_mod.cpp
cout << (-5) % 3; // -2
-2

هذا يخالف التعريف الرياضي المعتاد لـ mod الذي يفترض أن تكون النتيجة دائمًا بين 0 وm-1. هذا قد يسبّب أخطاء دقيقة عند استخدام النتيجة كفهرس في مصفوفة، مثلًا.

لحل هذه المشكلة، نضيف m ثم نأخذ mod مرة أخرى:

((a % m) + m) % m

fixed_negative_mod.cpp
int a = -5, m = 3;
cout << ((a % m) + m) % m; // 1
1

الأسس المعيارية (Modular Exponentiation)

لحساب (a^b) mod m بطريقة سريعة، لا نضرب a بنفسها b مرة (فهذا سيكون بتعقيد O(b) وبطيء جدًا لأعداد كبيرة). بدلًا من ذلك، نستخدم الأس السريع (Fast/Binary Exponentiation):

  • إذا كان b زوجيًا: a^b = (a^(b/2))²

  • إذا كان b فرديًا: a^b = (a^(b/2))² × a

modpow.cpp
long long modpow(long long a, long long b, long long m) {
    if (b == 0) return 1;
    long long half = modpow(a, b / 2, m);
    long long res = (half * half) % m;
    if (b % 2 == 1)
        res = (res * (a % m)) % m;

    return res;
}

بما أنّ b يُقسَّم إلى النصف في كل مرة يُستدعى فيها التكرار، فإنّ العدد الإجمالي للاستدعاءات التكرارية هو تقريبًا log₂(b) — تمامًا مثل حلقة المضاعفة التي درسناها في فصل التعقيد الزمني. لذا فإنّ تعقيد هذه الدالة هو O(log b).

modpow(2, 10, 1000) → 24

المختبر التفاعلي: تتبّع استدعاءات modpow(3, 13, 17)

اضغط الزر عدة مرات لكشف خطوات النزول (الاستدعاءات) ثم الصعود (النتائج) واحدة تلو الأخرى.

نشاط: مراجعة سريعة للأس السريع والمعكوس المعياري

حدّد إن كانت كل عبارة صحيحة أم خاطئة.

التعقيد الزمني لدالة modpow السريعة هو O(log b).

لحساب a^b mod m بطريقة الأس السريع، نضرب a بنفسها b مرة بشكل متكرر.

يمكن حساب المعكوس المعياري لعدد a باستخدام modpow(a, MOD-2, MOD) فقط إذا كان MOD عددًا أوليًا.

المعكوس المعياري (Modular Inverse)

عند الحاجة للقيام بعملية قسمة تحت المودولو، لا يمكننا فقط كتابة (a / b) % m — فالقسمة العادية لا تتوافق مع خصائص الحسابيات المعيارية. بدلًا من ذلك، نستخدم المعكوس المعياري.

إذا كان MOD عددًا أوليًا، فإنّ معكوس a يُحسب بـ:

modular_inverse.cpp
long long inverse = modpow(a, MOD - 2, MOD);

وبالتالي فإنّ القسمة a / b mod m تصبح:

modular_division.cpp
(a * modpow(b, MOD - 2, MOD)) % MOD

مثال للتحقق: معكوس 5 بالنسبة لـ MOD = 1,000,000,007 هو 400,000,003. يمكننا التأكد من صحّته لأنّ:

(5 * 400000003) % 1000000007 = 1

وهذا بالضبط تعريف المعكوس المعياري: عدد إذا ضربته بالعدد الأصلي تحت نفس المودولو، تحصل على 1.

هذه الطريقة (استخدام modpow(a, MOD-2, MOD)) تعتمد على مبرهنة صغيرة تُسمّى "مبرهنة فيرما الصغرى"، وتعمل فقط عندما يكون MOD عددًا أوليًا وa غير قابل للقسمة على MOD.

الملخّص السريع

% يعطي الباقي عند القسمة.
استخدم (a + b) % MOD، (a * b) % MOD، و((a - b) % MOD + MOD) % MOD.
للأسس الكبيرة، استخدم الأس السريع (modular exponentiation) بتعقيد O(log b).
للقسمة، استخدم المعكوس المعياري (modular inverse) إذا كان المودولو عددًا أوليًا.

تمارين منزلية

1) الطرح الآمن تحت المودولو

لديك a = 3، b = 8، m = 7. احسب (a - b) % m بالطريقة العادية، ثم احسبها بالطريقة الآمنة التي لا تعطي نتيجة سالبة.

hw1.cpp
int a = 3, b = 8, m = 7;
cout << (a - b) % m << endl;             // -5
cout << ((a - b) % m + m) % m << endl;    // 2
-5 2

الطريقة العادية تعطي -5 لأنّ 3 - 8 = -5، والحاصل سالب أصلًا. بإضافة m قبل أخذ mod الثانية، نحصل على النتيجة الصحيحة 2.

2) استخدام الأس السريع

احسب 3^13 mod 17 باستخدام دالة modpow.

hw2.cpp
cout << modpow(3, 13, 17) << endl;
12

يمكنك التحقق يدويًا: 3^13 = 1,594,323، و1,594,323 mod 17 = 12. الأس السريع يصل لنفس النتيجة في عدد خطوات أقل بكثير (تقريبًا log₂(13) ≈ 4 استدعاءات فقط، بدلًا من 13 عملية ضرب).

3) القسمة باستخدام المعكوس المعياري

احسب (10 / 3) mod 1,000,000,007 باستخدام المعكوس المعياري.

hw3.cpp
long long MOD = 1000000007;
long long a = 10, b = 3;
long long result = (a % MOD * modpow(b, MOD - 2, MOD)) % MOD;
cout << result << endl;
333333339

للتحقق: (333,333,339 * 3) % 1,000,000,007 = 10 — أي أنّ القسمة عادت للعدد الأصلي بنجاح، تمامًا كما تتوقع من عملية قسمة صحيحة.
