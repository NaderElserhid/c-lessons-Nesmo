الفصل الثامن: العمل على الحالات (Casework)

في فصل المحاكاة تعلّمت اتّباع القواعد خطوة بخطوة. أحيانًا مع ذلك، لا تتصرّف كل المدخلات بنفس الطريقة — بعضها زوجي وبعضها فردي، بعضها موجب وبعضها سالب. في هذا الفصل ستتعلّم "العمل على الحالات": أسلوب تفكير (وليس خوارزمية جديدة) يعلّمك كيف تقسّم مسألة معقّدة إلى مواقف أبسط، تحلّ كل واحدة على حدة، ثم تجمع النتائج معًا.

ما هو العمل على الحالات؟

مشاكل العمل على الحالات (Casework) هي تلك التي يُوجد حلّها عبر تقسيم المسألة إلى حالات مختلفة، حلّ كل واحدة منها بشكل منفصل، ثم دمج النتائج.

في العديد من المسائل قد تحاول كتابة صيغة واحدة أو حلقة واحدة تغطي كل شيء. لكن في مسائل العمل على الحالات، تلاحظ أنّ المواقف المختلفة تتصرّف بشكل مختلف. لذا بدلًا من قاعدة واحدة عامة، تقول:

  • إذا حدثت الحالة A، افعل هذا.

  • إذا حدثت الحالة B، افعل ذاك.

  • وربما أيضًا الحالة C، الحالة D، وهكذا.

ثم إما تجمع إجابات كل الحالات معًا، أو تختار الأفضل بينها.

لماذا نستخدم العمل على الحالات؟

  • يسمح لك بالتعامل مع الحالات الخاصة بوضوح (عندما لا تكفي المنطقية البسيطة).

  • يساعدك في تقسيم مشكلة صعبة إلى أجزاء سهلة التعامل.

  • يظهر كثيرًا في مسائل العدّ أو المسائل ذات النتائج المتعددة.

كيف نقوم بالعمل على الحالات

  • اقرأ المسألة بعناية وابحث عن الأماكن التي يحدث فيها تغيير (مثل صغير/كبير، موجب/سالب، زوجي/فردي).

  • حدّد جميع الحالات المختلفة التي تغطي كل الاحتمالات دون تداخل.

  • لكل حالة، اكتشف كيف تحسب النتيجة.

  • اجمع النتائج إن لزم الأمر (إما بجمعها أو بأخذ الأصغر/الأكبر).

  • تأكّد أنك لم تفوّت أي حالة، ولم تحسب شيئًا مرّتين.

مثال: مجموع زوجي أو فردي (Even or Odd Sum)

لديك عددان a وb. احسب عدد الأزواج (i, j) بحيث 1 ≤ i ≤ a و1 ≤ j ≤ b ويكون i + j زوجيًا.

ملاحظة: يكون i + j زوجيًا إذا كان كلاهما زوجيًا أو كلاهما فرديًا. إذًا هناك حالتان:

  • الحالة 1: i زوجي وj زوجي.

  • الحالة 2: i فردي وj فردي.

نحسب كل حالة على حدة، ثم نجمعهما معًا.

even_odd_sum.cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    int evenA = a / 2;
    int oddA = a - evenA;
    int evenB = b / 2;
    int oddB = b - evenB;

    int pairs = evenA * evenB + oddA * oddB;
    cout << pairs;
}

مثال: إذا كان a = 5 وb = 4، فإنّ الأعداد من 1 إلى 5 تحتوي على 2 زوجي و3 فردي، والأعداد من 1 إلى 4 تحتوي على 2 زوجي و2 فردي. إذن: pairs = 2×2 + 3×2 = 4 + 6 = 10.

نشاط: مراجعة سريعة لمفهوم العمل على الحالات

حدّد إن كانت كل عبارة صحيحة أم خاطئة.

لحساب عدد الأزواج التي مجموعها زوجي، نحسب حالة (زوجي مع زوجي) وحالة (فردي مع فردي) ثم نجمعهما.

إذا كان a = 5، فإنّ عدد الأعداد الفردية بين 1 و a هو 2.

العمل على الحالات يعني كتابة صيغة رياضية واحدة تغطي كل الحالات دفعة واحدة.

عند a=5, b=4، عدد الأزواج التي مجموعها زوجي هو 10.

مثال: صلاحية المثلث (Triangle Validity)

معطى لك ثلاثة أطوال أضلاع a, b, c، حدّد إن كانت تستطيع تشكيل مثلث.

يمكننا اختبار كل حالة عبر التحقق من أنّ مجموع أي ضلعين أكبر من الضلع الثالث:

  • b + c > a

  • a + c > b

  • a + b > c

إذا كانت جميع هذه المتباينات صحيحة، فإنّ تكوين مثلث ممكن. نتحقق من كل واحدة من هذه المتباينات، وفي حال أي متباينة لم تتحقق، فالإجابة هي "NO"، وإلا فالإجابة هي "YES".

triangle.cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;

    bool ok = true;
    if (b + c <= a) ok = false;
    if (a + c <= b) ok = false;
    if (a + b <= c) ok = false;

    cout << (ok ? "YES" : "NO");
}

هذا يفحص كل حالة بشكل مستقل — مثال مباشر على العمل على الحالات.

المختبر التفاعلي: تحقّق من صلاحية مثلثات مختلفة

مثال: ربع الإحداثيات (Coordinate Quadrant)

معطى لك إحداثيات نقطة (x, y)، اطبع أي ربع تنتمي إليه.

الحالةالربع
x > 0 وy > 0Quadrant I
x < 0 وy > 0Quadrant II
x < 0 وy < 0Quadrant III
x > 0 وy < 0Quadrant IV
x = 0 أو y = 0على أحد المحاور
quadrant.cpp
#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;

    if (x > 0 && y > 0) cout << "Quadrant I";
    else if (x < 0 && y > 0) cout << "Quadrant II";
    else if (x < 0 && y < 0) cout << "Quadrant III";
    else if (x > 0 && y < 0) cout << "Quadrant IV";
    else cout << "On an axis";
}

لاحظ أنّ الحالة الأخيرة (else) تلتقط كل النقاط التي لا تقع بشكل صريح في أي ربع من الأرباع الأربعة — أي عندما يكون x = 0 أو y = 0. هذا مثال جيّد على "الانتباه للحدود" الذي ذكرناه في نصائح المحاكاة.

نشاط: مراجعة سريعة للمثلث وربع الإحداثيات

حدّد إن كانت كل عبارة صحيحة أم خاطئة.

لتكوين مثلث بأضلاع a, b, c، يجب أن يكون مجموع أي ضلعين أكبر تمامًا من الضلع الثالث (وليس أكبر أو يساوي).

الأضلاع 2, 2, 4 يمكنها تشكيل مثلث صالح.

النقطة (0, 5) تقع في الربع الأول (Quadrant I).

في مسائل ربع الإحداثيات، يجب معالجة حالة وقوع النقطة على أحد المحاور كحالة منفصلة.

نصائح للعمل على الحالات

  • تأكّد أنّ حالاتك لا تتداخل.

  • تأكّد أنّ كل الاحتمالات مغطاة.

  • انتبه للحدود (مثل 0 أو المساواة).

  • حافظ على المنطق واضحًا وبسيطًا.

خلاصة سريعة

العمل على الحالات يعني تقسيم المسألة إلى مواقف أبسط.
حلّ كل حالة مستقلًا ثم دمج النتائج.
هو أسلوب تفكير، وليس خوارزمية خاصة.
ممتاز لمراحل البداية في حلّ المشاكل.

نصيحة: عندما تكون غير متأكد من نقطة البداية، فكّر: "ما هي الحالات الممكنة؟" — هذه بداية العمل على الحالات.

تمارين منزلية

1) عدّ الأزواج ذات المجموع الفردي

بنفس فكرة "مجموع زوجي أو فردي"، عدّل الكود لحساب عدد الأزواج (i, j) التي يكون مجموعها فرديًا بدلًا من زوجي (لنفس a=5, b=4).

hw1_odd_sum.cpp
int evenA = a / 2, oddA = a - evenA;
int evenB = b / 2, oddB = b - evenB;
int oddPairs = evenA * oddB + oddA * evenB; // حالة: زوجي مع فردي، أو فردي مع زوجي
cout << oddPairs;
10

يكون i + j فرديًا عندما يكون أحدهما زوجيًا والآخر فرديًا — حالتان جديدتان تمامًا مثل المثال الأصلي. لاحظ أنّ 10 (زوجي) + 10 (فردي) = 20 = a × b، وهذا تحقّق جيد لأنّ كل الأزواج الممكنة إما زوجية المجموع أو فردية المجموع، بلا تداخل ولا نقصان — بالضبط ما تعنيه "تغطية كل الاحتمالات دون تداخل".

2) تصنيف نوع المثلث

وسّع كود صلاحية المثلث ليحدّد أيضًا نوع المثلث إن كان صالحًا: متساوي الأضلاع (Equilateral) إذا تساوت كل الأضلاع، متساوي الساقين (Isosceles) إذا تساوى ضلعان فقط، أو مختلف الأضلاع (Scalene) إذا اختلفت جميعها.

hw2_triangle_type.cpp
string classify(int a, int b, int c) {
    bool valid = (a+b>c) && (b+c>a) && (a+c>b);
    if (!valid) return "Not a triangle";
    if (a==b && b==c) return "Equilateral";
    if (a==b || b==c || a==c) return "Isosceles";
    return "Scalene";
}
classify(5, 5, 5) → Equilateral classify(3, 4, 5) → Scalene classify(5, 5, 8) → Isosceles classify(1, 1, 5) → Not a triangle

لاحظ ترتيب الحالات: تحقّقنا أولًا من الصلاحية (وإلا لا معنى للتصنيف)، ثم فحصنا الحالة الأكثر تحديدًا (تساوي الثلاثة) قبل الحالة الأقل تحديدًا (تساوي ضلعين فقط) — ترتيب الحالات من الأخص إلى الأعم مهم جدًا هنا لتجنّب تصنيف مثلث متساوي الأضلاع خطأً على أنه متساوي الساقين فقط.

3) إضافة حالة نقطة الأصل

وسّع كود ربع الإحداثيات ليميّز حالة خاصة: إذا كانت النقطة بالضبط عند نقطة الأصل (0, 0)، اطبع "Origin" بدلًا من "On an axis".

hw3_origin.cpp
string classify(int x, int y) {
    if (x==0 && y==0) return "Origin";
    if (x==0 || y==0) return "On an axis";
    if (x>0 && y>0) return "Quadrant I";
    if (x<0 && y>0) return "Quadrant II";
    if (x<0 && y<0) return "Quadrant III";
    return "Quadrant IV";
}
classify(0, 0) → Origin classify(0, 5) → On an axis classify(3, 5) → Quadrant I

هذا مثال ممتاز على "لا تفوّت أي حالة" — نقطة الأصل هي حالة خاصة داخل حالة "على أحد المحاور"، لذا يجب فحصها أولًا (الأخص قبل الأعم)، وإلا سيلتقطها شرط x==0 || y==0 قبل أن تصل إلى الشرط الأدق.

Caseworkالعمل على الحالات

أسلوب حلّ مسائل عبر تقسيمها إلى حالات مختلفة، وحلّ كل واحدة على حدة.

Case Splitتقسيم الحالات

عملية تحديد المواقف المختلفة التي يجب معالجتها بشكل منفصل داخل مسألة واحدة.

Mutually Exclusiveحالات غير متداخلة

خاصية تعني أنّ كل موقف يقع في حالة واحدة فقط، دون تكرار العدّ.

Exhaustive Casesتغطية شاملة للحالات

خاصية تعني أنّ كل الاحتمالات الممكنة مغطاة بحالة واحدة على الأقل.

موقف خاص عند حدود المسألة (مثل الصفر أو المساواة التامة) يسهل نسيانه.
