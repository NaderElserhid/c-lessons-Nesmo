Modular Exponentiation (الأس المعياري)

احسب m mod 2n دون أن يتجاوز الحساب حدود النوع int.

Easy Codeforces 913A

نص المسألة

لديك عددان صحيحان n وm. اطبع m mod 2n.

ملحوظة: بالنسبة لرقمين x وy حيث y > x، فإن x % y == x.

القيود

1 ≤ n ≤ 10⁸   |   1 ≤ m ≤ 10⁸

أمثلة

nmالناتج
44210
1580
987654322345678923456789

مختبر تفاعلي: شاهد متى تتوقف حلقة المضاعفة

جرّب المثال n = 10, m = 5 وشاهد power يتضاعف (2، 4، 8...) حتى يتجاوز m، عندها تتوقف الحلقة فورًا دون الحاجة لإكمال العشر تكرارات:

اضغط "شغّل المحاكاة" لبدء التضاعف.

الحل

حساب 2n مباشرة قد يؤدي إلى تجاوز حدود النوع int (خصوصًا أن n قد يصل إلى 10⁸). لتجنّب ذلك، نستخدم متغيّرًا power يبدأ بـ 1 ونضاعفه في حلقة تتكرر n مرة. في كل تكرار، إذا أصبح power أكبر من m، فبناءً على الملحوظة أعلاه يكون الناتج m مباشرة، ونتوقف فورًا. إذا اكتملت الحلقة دون أن يتجاوز power قيمة m، فلا يوجد تجاوز لحدود int، ويكون الناتج m % power.

modular_exponentiation.cpp
#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    int power = 1;

    for (int i = 0; i < n; i++) {
        power *= 2;

        if (power > m) {
            cout << m << endl;
            break;
        }
    }

    if (power <= m) {
        cout << m % power << endl;
    }
}
n=4, m=42 → 10
n=1, m=58 → 0
n=98765432, m=23456789 → 23456789

بما أنّ m ≤ 10⁸، فإنّ power يتجاوز m خلال حوالي 27 تكرارًا كحد أقصى (لأنّ 2²⁵ > 10⁸) — حتى لو كان n يصل إلى 10⁸. لذلك تتوقف الحلقة عمليًا بسرعة كبيرة جدًا، ولا يحدث أي تجاوز لحدود int.
