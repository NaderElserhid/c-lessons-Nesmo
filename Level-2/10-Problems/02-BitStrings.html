Bit Strings (سلاسل البت)

مسألة كلاسيكية من CSES تجمع بين مبدأ الضرب الذي درسته في العدّ (Counting) بمستوانا الأول، والحسابيات المعيارية التي تعلّمتها للتو في هذا المستوى — رافعة ضخمة الحجم (2 مرفوعة لأس كبير) يجب حسابها بأمان تحت باقي القسمة على عدد أولي كبير.

Easy CSES 1617

نص المسألة

مهمتك هي حساب عدد سلاسل البت بطول n. سلسلة البت هي تسلسل بطول n، كل خانة منه إما 0 أو 1.

على سبيل المثال، إذا كان n = 3، فإنّ سلاسل البت هي [000, 001, 010, 011, 100, 101, 110, 111]، أي أنّ عددها 8.

الإدخال

عدد صحيح واحد n.

المخرجات

اطبع العدد الكلي لسلاسل البت بطول n، بتطبيق باقي القسمة على 10⁹ + 7.

راقب كيف تتضاعف قيمة ans في كل تكرار، وكيف تتطابق تمامًا مع كل سلاسل البت الممكنة لذلك الطول.

منهجية الحل: كيف نفكّر في هذه المسألة؟

  • افهم المسألة: نريد عدد كل التسلسلات الممكنة بطول n مكوّنة من 0 و1 فقط.

  • جرّب أمثلة صغيرة يدويًا: ماذا لو كان n=1؟ أو n=2؟ عدّها بنفسك.

  • ابحث عن نمط: كم خيارًا لدى كل خانة؟ كيف يرتبط ذلك بالعدد الكلي؟

  • انتبه للمخرجات: المطلوب الإجابة بعد أخذ باقي القسمة على عدد كبير — لماذا؟

  • اكتب الكود وتحقّق: جرّب الكود على المثال المعطى (n=3 → 8).

  • افحص الحالات الحدّية: ماذا يحدث عند n كبير جدًا؟ هل حلّك سريع بما يكفي؟

هل لاحظت النمط؟ في كل مرة نزيد فيها الطول بمقدار خانة واحدة، يتضاعف عدد السلاسل! هذا لأنّ كل سلسلة قديمة يمكن أن تنتهي إما بـ 0 أو 1، فينشأ ضِعف عدد السلاسل الجديدة.

الخطوة 2: الصيغة العامة — مبدأ الضرب

كل خانة من خانات السلسلة ذات الطول n لديها خياران مستقلان: 0 أو 1. لذلك، حسب مبدأ الضرب الذي درسناه في مبادئ العدّ بالمستوى الأول، يكون عدد سلاسل البت مساويًا لـ:

2 × 2 × ... × 2 (n مرة) = 2ⁿ

علينا طباعة هذه القيمة بتطبيق باقي القسمة على 10⁹ + 7.

الخطوة 3: لماذا نحتاج mod؟ والحل بحلقة تدريجية

القيمة 2ⁿ يمكن أن تكون ضخمة جدًا — أكبر بكثير مما يتّسع له حتى long long. لهذا تطلب المسألة الإجابة بعد أخذ الباقي على المعامل الشائع 10⁹ + 7 الذي درسناه في فصل الحسابيات المعيارية.

يمكننا حساب 2ⁿ mod M تدريجيًا باستخدام حلقة بسيطة، مضاعِفين النتيجة وأخذ mod في كل خطوة (تمامًا كحلقة المضاعفة من فصل التعقيد الزمني):

bit_strings.cpp
#include <iostream>
using namespace std;

const long long MOD = 1000000007LL;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n;
    cin >> n;

    long long ans = 1;
    for (long long i = 0; i < n; ++i) {
        ans = (ans * 2) % MOD;
    }

    cout << ans << "\n";
    return 0;
}

نبدأ بـ ans = 1 (يمثّل 2⁰ = 1، أي السلسلة الفارغة). في كل تكرار، نضاعف ans ونأخذ باقي القسمة، تمامًا كما يتضاعف عدد السلاسل عند إضافة خانة جديدة. بعد n تكرارات، تصبح قيمة ans مساوية لـ 2ⁿ mod M.

Input: 3 → Output: 8

ملحوظة حول الأسّ السريع (خيار بديل عند n الكبيرة جدًا)

في هذه المسألة، حلقة بزمن O(n) كافية وسريعة لأنّ n ليس كبيرًا جدًا. لكن في مسائل أخرى قد تكون قيمة n ضخمة جدًا (مثلًا حتى 10¹⁸)، ولا يمكننا حينها تكرار الحلقة n مرة — فذلك سيستغرق وقتًا طويلًا جدًا.

في تلك الحالات، نستخدم دالة الأس السريع (modpow) التي بنيناها في فصل الحسابيات المعيارية، والتي تحسب aᵉ mod m بتعقيد O(log n) بدلًا من O(n):

bit_strings_fast.cpp
long long modpow(long long a, long long b, long long m) {
    if (b == 0) return 1;
    long long half = modpow(a, b / 2, m);
    long long res = (half * half) % m;
    if (b % 2 == 1)
        res = (res * (a % m)) % m;
    return res;
}

int main() {
    long long n;
    cin >> n;
    cout << modpow(2, n, 1000000007LL) << "\n";
}

كلتا الطريقتين تعطيان نفس النتيجة بالضبط (تحقّقنا من ذلك على أمثلة عديدة)، لكن عند n = 1,000,000، تحتاج الحلقة البسيطة مليون خطوة بينما يحتاج الأس السريع نحو 20 خطوة فقط — فرق هائل يصبح حاسمًا كلما كبرت القيود في المسألة.
