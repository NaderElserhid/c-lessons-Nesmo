# Image Generation Prompt — TweetKod C++ Level 2 Cover

Use this with any AI image generator (Midjourney, DALL·E, Stable Diffusion, Ideogram, etc.) to create a cover/banner image representing **Level 2** of the TweetKod C++ competitive-programming course.

## Main Prompt (universal — works for most tools)

```
A sleek, modern digital cover illustration for an online programming course titled "Level 2." Flat-vector tech-education style, clean and professional, similar to premium coding-bootcamp or competitive-programming platform branding.

Composition: a large bold stylized numeral "2" as the visual centerpiece, made of glowing geometric blue and orange light, positioned slightly off-center. Around it, abstract icons representing intermediate C++ / competitive-programming concepts float in a balanced arrangement: overlapping translucent circles (representing sets), a small connected node-and-key diagram (representing maps/dictionaries), a row of ascending bar shapes (representing sorting), a magnifying glass over a split line of dots (representing binary search), a minimal clock/gear icon (representing time complexity and modular arithmetic), and a simple branching path icon (representing decision-making and greedy algorithms).

Background: deep dark-navy (#0f172a) gradient, with a subtle soft grid or circuit-pattern texture, and soft glowing accent light in bright cyan-blue (#00adef) and warm orange (#f7941e), matching a tech brand palette.

Style: flat 2.5D / isometric illustration, minimal line work, soft glow and subtle depth shadows, no clutter, plenty of negative space, high contrast, crisp vector-like edges, premium SaaS / edtech aesthetic. No readable body text, no logos, no watermarks, no photorealistic humans, no keyboard or laptop clichés.

Format: wide 16:9 landscape banner, high resolution, suitable as a course thumbnail/cover image.
```

## Notes for use

- The brand colors are: primary blue `#00adef`, primary orange/yellow `#f7941e`, dark navy background `#0f172a` — keep these consistent so the cover matches the rest of the TweetKod course pages.
- Most image models render text poorly — the numeral "2" is described as a *stylized graphic shape*, not literal typed text, to avoid garbled output. If the tool supports adding clean text afterward, overlay "Level 2 — C++" separately in a design tool once the image is generated.
- If you want a matching cover for Level 1 later, reuse this same prompt but swap the numeral to "1" and simplify the icon set to beginner topics (variables, loops, arrays) for visual consistency across levels.
