Prime Factorization

Breaking a number into its atoms

What will you learn in this lesson?

  • Understand that every number has a unique prime factorization
  • Write trial-division factoring and explain why we divide by each factor as many times as possible
  • Compute the divisor count, the gcd and the lcm from the exponents
  • Build the smallest-prime-factor sieve spf to factor many numbers quickly
  • Solve perfect-square and largest-prime-factor problems

The atoms of numbers

In chemistry, matter is made of indivisible atoms. The same happens in arithmetic: every number greater than 1 can be written in exactly one way as a product of primes. This fact is called the Fundamental Theorem of Arithmetic.

NumberIts prime factorization
122 × 2 × 3 = 22 × 3
6022 × 3 × 5
36023 × 32 × 5
9797 (prime, it does not break down)
100000026 × 56

Think of a tree: write the number at the root, split it into two factors, then split each composite factor, until every branch ends in a prime. Whatever splits you choose you always reach the same leaves. Try it yourself: 12 = 3 × 4 = 3 × 2 × 2 or 12 = 6 × 2 = 2 × 3 × 2, and the leaves are always 2, 2 and 3.

Why does this matter? Because the prime factors reveal the number's secrets: how many divisors it has, their sum, its gcd and lcm with other numbers, and whether it is a perfect square. All of these problems come up again and again in contests.

Factoring with trial division

The idea is simple: we try the divisors d = 2, 3, 4, ..., and whenever d divides the number we divide by it as many times as possible and record how many times. At the end, if anything greater than 1 is left in the number, it is one large prime factor.

factorize.cpp
#include <iostream>#include <vector>using namespace std; vector<pair<long long, int>> factorize(long long n) {    vector<pair<long long, int>> result;    for (long long d = 2; d * d <= n; d++) {        int count = 0;        while (n % d == 0) {            n /= d;            count++;        }        if (count > 0) {            result.push_back({d, count});        }    }    if (n > 1) {        result.push_back({n, 1});    }    return result;} void show(long long n) {    cout << n << " =";    vector<pair<long long, int>> f = factorize(n);    for (size_t i = 0; i < f.size(); i++) {        cout << (i == 0 ? " " : " * ") << f[i].first;        if (f[i].second > 1) {            cout << "^" << f[i].second;        }    }    cout << endl;} int main() {    show(360);    show(97);    show(1001);    show(1000000);    show(123456789);    show(999999999989LL);    return 0;}

Notice the two questions you may be asking:

Could we divide by a composite number like 4 or 6? No. By the time we reach d = 4 we have already pulled every factor 2 out of the number, so 4 cannot divide it. By the same logic no composite number ever divides it, so every d that divides the number is automatically prime.

Why is a remainder greater than 1 prime? If it were composite it would have a factor no larger than its root, and that factor would have been pulled out before the loop ended.

And what about speed? The condition d * d <= n uses the n that keeps shrinking. Try three numbers near a trillion:

factor_rounds.cpp
long long tests[3] = {549755813888LL, 1000000LL, 999999999989LL};for (long long n : tests) {    long long original = n, rounds = 0;    for (long long d = 2; d * d <= n; d++) {        rounds++;        while (n % d == 0) {            n /= d;        }    }    cout << original << ": rounds = " << rounds << endl;}
Click any highlighted line of code to read its explanation here...
549755813888: rounds = 1 1000000: rounds = 4 999999999989: rounds = 999998

The number 239 finished in one round because all its factors are 2. And 1000000 finished after about 4 rounds. But the huge prime used every round up to its root (about a million). So the worst cases are primes, or products of two large primes, and their time is O(√n).

What do the exponents tell us?

When we know the factorization n = p1e1 × p2e2 × ... we get beautiful results:

#include <iostream>#include <map>#include <algorithm>using namespace std; map<long long, int> factorize(long long n) {    map<long long, int> f;    for (long long d = 2; d * d <= n; d++) {        while (n % d == 0) {            f[d]++;            n /= d;        }    }    if (n > 1) {        f[n]++;    }    return f;} int main() {    map<long long, int> f = factorize(360);    long long divisors = 1;    for (auto& entry : f) {        divisors *= entry.second + 1;    }    cout << "360 has " << divisors << " divisors" << endl;     map<long long, int> a = factorize(12), b = factorize(18);    long long g = 1, l = 1;    for (long long p : {2LL, 3LL}) {        int ea = a[p], eb = b[p];        for (int k = 0; k < min(ea, eb); k++) {            g *= p;        }        for (int k = 0; k < max(ea, eb); k++) {            l *= p;        }    }    cout << "gcd(12, 18) = " << g << ", lcm(12, 18) = " << l << endl;    return 0;}

360 = 23 × 32 × 5, so its divisor count is 4 × 3 × 2 = 24. For 12 = 22 × 3 and 18 = 2 × 32 the gcd is 21 × 31 = 6 and the lcm is 22 × 32 = 36.

When there are many requests: the smallest prime factor

If you must factor tens of thousands of small numbers (say below a million), repeating trial division is slow. The solution: build a sieve once that records for every number its smallest prime factor (called spf, short for smallest prime factor). After that, factoring becomes a short chain of divisions by spf.

spf.cpp
#include <iostream>#include <vector>using namespace std; int main() {    const int N = 1000000;    vector<int> spf(N + 1, 0);    for (int i = 2; i <= N; i++) {        if (spf[i] == 0) {            for (int j = i; j <= N; j += i) {                if (spf[j] == 0) {                    spf[j] = i;                }            }        }    }     int tests[3] = {84, 720720, 999983};    for (int n : tests) {        cout << n << " =";        int m = n;        while (m > 1) {            cout << " " << spf[m];            m /= spf[m];        }        cout << endl;    }    return 0;}
Click any highlighted line of code to read its explanation here...
84 = 2 2 3 7 720720 = 2 2 2 2 3 3 5 7 11 13 999983 = 999983

We needed no trial-division loop at all: we read spf[m] to learn the factor, divide, and repeat. The number of rounds never exceeds log₂ n (about 20 for a number near a million).

Lesson project: the factor card

We build a complete factorization card for any number.

The idea

The math club wants a "DNA" for every number: its prime factorization, the count of different prime factors, the total count of prime factors (with repeats), and its number of divisors. We want a program that prints all this for any number up to 1012.

What you need to do
  1. Read the number n.
  2. Factor it by trial division, and keep each factor with its exponent.
  3. Print Factors: and then the factors in the form 2^3 * 3^2 * 5 (do not write exponent 1).
  4. Print Distinct primes:, Total prime factors: and Divisors:.
  5. If the number is 1, print Factors: 1 and zero counts.
Two sample runs

First run:

360
Factors: 2^3 * 3^2 * 5 Distinct primes: 3 Total prime factors: 6 Divisors: 24

Second run (a prime number):

97
Factors: 97 Distinct primes: 1 Total prime factors: 1 Divisors: 2

Check it in your head: 360 = 23 × 32 × 5 has three different factors, a total of 3 + 2 + 1 = 6 prime factors, and 4 × 3 × 2 = 24 divisors. But 97 is prime: one factor and two divisors.

After you try it yourself: show the solution
factor_card.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    long long n;
    cin >> n;

    vector<pair<long long, int>> f;
    long long m = n;
    for (long long d = 2; d * d <= m; d++) {
        int count = 0;
        while (m % d == 0) {
            m /= d;
            count++;
        }
        if (count > 0) {
            f.push_back({d, count});
        }
    }
    if (m > 1) {
        f.push_back({m, 1});
    }

    int total = 0;
    long long divisors = 1;
    cout << "Factors:";
    if (f.empty()) {
        cout << " 1";
    }
    for (size_t i = 0; i < f.size(); i++) {
        cout << (i == 0 ? " " : " * ") << f[i].first;
        if (f[i].second > 1) {
            cout << "^" << f[i].second;
        }
        total += f[i].second;
        divisors *= f[i].second + 1;
    }
    cout << endl;
    cout << "Distinct primes: " << f.size() << endl;
    cout << "Total prime factors: " << total << endl;
    cout << "Divisors: " << divisors << endl;
    return 0;
}

The largest prime factor

Medium

Read the number n (from 2 up to 1012) and print its largest prime factor.

Requirements
  • Factor the number by trial division.
  • Keep the last prime factor you found.
  • If n > 1 remains at the end, it is the largest factor.
  • Print the largest factor.
Example input and expected output
13195
29
Hints
  • 13195 = 5 × 7 × 13 × 29 and the largest is 29.
  • Use long long for all the variables.
Sample solution (after you try)
largest_factor.cpp
// Challenge 1: the largest prime factor
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    long long largest = 1;
    for (long long d = 2; d * d <= n; d++) {
        while (n % d == 0) {
            largest = d;
            n /= d;
        }
    }
    if (n > 1) {
        largest = n;
    }
    cout << largest << endl;
    return 0;
}
2

Make it a perfect square

Medium

Read the number n (up to 1012). What is the smallest positive integer k such that n × k is a perfect square?

Requirements
  • Factor n into primes with their exponents.
  • Every factor with an odd exponent needs one more copy of itself to make the exponent even.
  • Multiply those odd-exponent factors together to get k.
  • Do not forget the large prime factor that may remain at the end.
Example input and expected output
72
2
Hints
  • 72 = 2³ × 3²: the exponent 3 is odd and the exponent 2 is even, so we only need 2. And 72 × 2 = 144 = 12².
  • The answer for the example is 2.
Sample solution (after you try)
make_square.cpp
// Challenge 2: make it a perfect square
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    long long k = 1;
    for (long long d = 2; d * d <= n; d++) {
        int count = 0;
        while (n % d == 0) {
            n /= d;
            count++;
        }
        if (count % 2 == 1) {
            k *= d;
        }
    }
    if (n > 1) {
        k *= n;
    }
    cout << k << endl;
    return 0;
}

Quick summary

  • Every number greater than 1 has a unique factorization into primes (the Fundamental Theorem of Arithmetic).
  • Trial-division factoring: for each d from 2 while d * d <= n, divide by d as many times as possible and count the exponent.
  • If n > 1 remains after the loop, it is one large prime factor.
  • The condition uses the shrinking n, so we stop early; the worst cases are primes, in O(√n).
  • Divisor count = product of (exponent + 1); the gcd uses the smaller exponents and the lcm the larger.
  • To factor many small numbers we build an spf sieve, and factoring takes O(log n) per number.
  • The total number of prime factors is never smaller than the number of different ones.

Glossary

The most important terms in this lesson:

Prime factor

A prime number that divides the number.

Factorization

Writing a number as a product of primes.

Fundamental theorem of arithmetic

Every number greater than 1 has a unique prime factorization.

Exponent

The number of times a factor repeats.

Trial division

Trying the divisors one after another.

Factor tree

A drawing that splits a number into factors until only primes remain.

Smallest prime factor

The smallest prime that divides the number.

Perfect square

A number all of whose exponents are even.

Divisor count

The product of (exponent + 1).

Distinct primes

The different primes in the factorization.

map

A container that stores ordered (key, value) pairs.

Sieve

An algorithm that fills a table by walking over multiples.
