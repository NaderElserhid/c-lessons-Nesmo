Rectangular Geometry

Axis-aligned rectangles in one and two dimensions

What will you learn in this lesson?

  • Represent points and rectangles with struct and compute width, height and area
  • Test whether two rectangles intersect by checking separation on both axes
  • Compute the intersection rectangle and its area with the largest lower limits and smallest upper limits
  • Handle intervals in one dimension and turn two-dimensional problems into two one-dimensional ones
  • Compute the covered area and the bounding rectangle, and avoid the common mistakes

Rectangles on a coordinate plane

In many problems we deal with rectangles whose sides are parallel to the axes (axis-aligned rectangles): windows on a screen, billboards on a wall, plots of land, regions on a map. This kind of rectangle is very easy, because all the information is simple numbers on two axes.

We agree that the x axis points right and the y axis points up. One rectangle is determined by two corners: the bottom-left corner (the smallest x and smallest y) and the top-right corner (the largest x and largest y).

And the idea that will keep coming back in this lesson: as long as the rectangle is parallel to the axes, every geometry problem splits into two separate one-dimensional problems: one on the horizontal axis and one on the vertical axis. Then we combine the two results.

Representing points and rectangles

We use a struct to group the coordinates. Click the highlighted lines to read their explanation:

rectangles.cpp
#include <iostream>using namespace std; struct Point {    int x;    int y;}; struct Rect {    Point lo;    Point hi;}; int width(Rect r) {    return r.hi.x - r.lo.x;} int height(Rect r) {    return r.hi.y - r.lo.y;} int area(Rect r) {    return width(r) * height(r);} int main() {    Rect r = {{1, 1}, {5, 4}};    cout << "width " << width(r) << ", height " << height(r);    cout << ", area " << area(r) << endl;    return 0;}
Click any highlighted line of code to read its explanation here...

We assumed that every rectangle is normalized: that is, lo.x ≤ hi.x and lo.y ≤ hi.y. If the two corners reach you in random order from the input, swap the values first (you will see this in the lesson project), otherwise you get negative lengths.

Do two rectangles intersect?

The easiest way is to ask the opposite question: when do they not intersect? It is enough that they are separated horizontally (one is entirely to the left of the other) or separated vertically (one is entirely below the other). Otherwise they intersect with positive area:

overlap_test.cpp
#include <iostream>using namespace std; struct Point {    int x;    int y;}; struct Rect {    Point lo;    Point hi;}; bool overlaps(Rect a, Rect b) {    bool apartX = a.hi.x <= b.lo.x || b.hi.x <= a.lo.x;    bool apartY = a.hi.y <= b.lo.y || b.hi.y <= a.lo.y;    return !apartX && !apartY;} int main() {    Rect a = {{2, 2}, {6, 5}};    Rect inside = {{3, 3}, {4, 4}};    Rect cross = {{5, 4}, {8, 8}};    Rect edge = {{6, 2}, {9, 5}};    Rect corner = {{6, 5}, {9, 9}};    Rect far = {{10, 10}, {12, 12}};     cout << "inside: " << overlaps(a, inside) << endl;    cout << "cross:  " << overlaps(a, cross) << endl;    cout << "edge:   " << overlaps(a, edge) << endl;    cout << "corner: " << overlaps(a, corner) << endl;    cout << "far:    " << overlaps(a, far) << endl;    return 0;}
Click any highlighted line of code to read its explanation here...
inside: 1 cross: 1 edge: 0 corner: 0 far: 0

Watch out for touching: the rectangle edge touches a along a whole side, and corner at a point, yet there is no intersection because the shared area is zero. That is why we used <= and not < in the separation condition. Using < would make touching rectangles look as if they intersect.

The intersection rectangle itself

If two rectangles intersect, the shared part is another rectangle. Its left edge is the larger of the two left edges (because it cannot start before both have started), and its right edge is the smaller of the two right edges (because it ends when either one ends). Likewise vertically:

intersection.cpp
#include <iostream>#include <algorithm>using namespace std; struct Point {    int x;    int y;}; struct Rect {    Point lo;    Point hi;}; Rect intersection(Rect a, Rect b) {    Rect c;    c.lo.x = max(a.lo.x, b.lo.x);    c.lo.y = max(a.lo.y, b.lo.y);    c.hi.x = min(a.hi.x, b.hi.x);    c.hi.y = min(a.hi.y, b.hi.y);    return c;} int main() {    Rect a = {{1, 1}, {6, 5}};    Rect b = {{4, 3}, {9, 8}};    Rect c = intersection(a, b);    cout << "(" << c.lo.x << ", " << c.lo.y << ") to (" << c.hi.x << ", " << c.hi.y << ")" << endl;    cout << "area " << (c.hi.x - c.lo.x) * (c.hi.y - c.lo.y) << endl;    return 0;}

What intersection area will the program print?

6

The shared width is min(5, 8) - max(0, 2) = 3 and the shared height is min(3, 6) - max(0, 1) = 2, so the area is 3 × 2 = 6.

Call the intersection function only after making sure the rectangles really intersect; otherwise you get an "inverted" rectangle with a negative width or height. In the next sections we will see a trick that makes this check unnecessary when computing the area.

One dimension: intervals

Everything above breaks down into two problems on intervals: an interval on x and an interval on y. An interval is simply two numbers: a start and an end. Its length is the difference between them, and the shared length of two intervals is:

intervals.cpp
#include <iostream>#include <algorithm>using namespace std; struct Interval {    int l;    int r;}; int length(Interval s) {    return s.r - s.l;} int overlapLength(Interval a, Interval b) {    return max(0, min(a.r, b.r) - max(a.l, b.l));} int main() {    Interval a = {2, 9}, b = {6, 12}, c = {10, 14};    cout << "a and b share " << overlapLength(a, b) << endl;    cout << "a and c share " << overlapLength(a, c) << endl;    cout << "a and b cover " << length(a) + length(b) - overlapLength(a, b) << endl;    return 0;}
Click any highlighted line of code to read its explanation here...
a and b share 3 a and c share 0 a and b cover 10

Look at the expression min(a.r, b.r) - max(a.l, b.l): when the intervals overlap it is positive and equals the shared length, and when they are separate it is negative or zero. So it is enough to wrap it in max(0, …) to get zero automatically instead of writing an if.

The area covered by two rectangles

We hang two posters on a wall, and some area is shared between them. How much of the wall is actually covered? If we only add the areas of the two posters, we counted the shared part twice, so we subtract it once. And since the intersection area = (shared width) × (shared height), and both are zero when the rectangles are apart, we never need to check for intersection:

union_area.cpp
#include <iostream>#include <algorithm>using namespace std; struct Point {    int x;    int y;}; struct Rect {    Point lo;    Point hi;}; int area(Rect r) {    return (r.hi.x - r.lo.x) * (r.hi.y - r.lo.y);} int overlapArea(Rect a, Rect b) {    int w = max(0, min(a.hi.x, b.hi.x) - max(a.lo.x, b.lo.x));    int h = max(0, min(a.hi.y, b.hi.y) - max(a.lo.y, b.lo.y));    return w * h;} int main() {    Rect a = {{1, 1}, {6, 5}};    Rect b = {{4, 3}, {9, 8}};    Rect far = {{10, 10}, {12, 12}};     cout << "overlap(a, b) = " << overlapArea(a, b) << endl;    cout << "overlap(a, far) = " << overlapArea(a, far) << endl;    cout << "covered by a and b = " << area(a) + area(b) - overlapArea(a, b) << endl;    return 0;}
Click any highlighted line of code to read its explanation here...
overlap(a, b) = 4 overlap(a, far) = 0 covered by a and b = 41
What we needThe formula
area of a rectangle(hi.x - lo.x) * (hi.y - lo.y)
width of the intersectionmax(0, min(a.hi.x, b.hi.x) - max(a.lo.x, b.lo.x))
height of the intersectionmax(0, min(a.hi.y, b.hi.y) - max(a.lo.y, b.lo.y))
area of the intersectionwidth × height
area coveredarea(a) + area(b) - overlap(a, b)

This style (add, then subtract what repeats) is called the inclusion-exclusion principle. With three rectangles it gets subtler, because the part shared by all three has to be added back, so be careful not to generalize the formula without thinking.

The bounding box and the position of points

A recurring problem: what is the smallest axis-aligned rectangle that contains all the points? The left edge is the smallest x, the right edge is the largest x, the bottom is the smallest y, and the top is the largest y:

bounding_box.cpp
#include <iostream>#include <vector>#include <algorithm>using namespace std; int main() {    vector<int> xs = {3, -2, 5, 0};    vector<int> ys = {7, 4, 1, 9};     int x1 = *min_element(xs.begin(), xs.end());    int x2 = *max_element(xs.begin(), xs.end());    int y1 = *min_element(ys.begin(), ys.end());    int y2 = *max_element(ys.begin(), ys.end());     cout << "(" << x1 << ", " << y1 << ") to (" << x2 << ", " << y2 << ")" << endl;    cout << "area " << (x2 - x1) * (y2 - y1) << endl;    return 0;}

The point (2,2) is on the bottom-left corner so it is inside, while (6,5) is on the top-right corner so it is outside. If the problem asks for something else, read the statement carefully to learn which edges count.

Common mistakes in rectangular geometry

The mistakeThe remedy
Giving the corners in reversed orderSwap the values so that x1 ≤ x2 and y1 ≤ y2 right after reading
Treating touching rectangles as intersectingUse <= in the separation conditions, and check the problem statement
Mixing up min and max in the intersectionIntersection: the largest of the lower limits and the smallest of the upper limits
Overflowing int in the areaIf the coordinates are large, use long long
Calling the intersection without checking for intersectionUse max(0, …) or check first
Lesson project: two posters on the school wall

We compute the shared area and the area actually covered.

The idea

The school will hang two rectangular posters on a wall, and they may overlap. The principal wants to know the area of the part where the posters overlap, and also the area of the wall that the two posters cover together.

What you need to do
  1. Read two posters, each as four numbers x1 y1 x2 y2 for two opposite corners (they may come in any order).
  2. Reorder the coordinates of each poster so that the smaller ones come first.
  3. Compute the intersection area with the trick max(0, …) × max(0, …).
  4. Print Overlap: and the shared area, and on a second line Covered: and the covered area.
Two sample runs

First run (overlapping posters):

1 1 5 4 3 2 8 6
Overlap: 4 Covered: 28

Second run (posters far apart):

0 0 2 2 5 5 7 7
Overlap: 0 Covered: 8

Check it in your head: in the first run the first poster is 4 × 3 = 12 and the second is 5 × 4 = 20. The shared part has width from 3 to 5, which is 2, and height from 2 to 4, which is 2, so its area is 4. The covered area is 12 + 20 - 4 = 28.

After you try it yourself: show the solution
posters.cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Rect {
    long long x1, y1, x2, y2;
};

Rect readRect() {
    Rect r;
    cin >> r.x1 >> r.y1 >> r.x2 >> r.y2;
    if (r.x1 > r.x2) {
        swap(r.x1, r.x2);
    }
    if (r.y1 > r.y2) {
        swap(r.y1, r.y2);
    }
    return r;
}

long long area(Rect r) {
    return (r.x2 - r.x1) * (r.y2 - r.y1);
}

long long overlapArea(Rect a, Rect b) {
    long long w = max(0LL, min(a.x2, b.x2) - max(a.x1, b.x1));
    long long h = max(0LL, min(a.y2, b.y2) - max(a.y1, b.y1));
    return w * h;
}

int main() {
    Rect a = readRect();
    Rect b = readRect();
    long long common = overlapArea(a, b);
    cout << "Overlap: " << common << endl;
    cout << "Covered: " << area(a) + area(b) - common << endl;
    return 0;
}

The bounding rectangle of points

Easy

Read n and then n points (each point is x y). Print the smallest axis-aligned rectangle that contains all the points, and its area.

Requirements
  • Start with very large minimum values and very small maximum values.
  • Update the smallest and largest x and the smallest and largest y with every point.
  • Print Rectangle: and then x1 y1 x2 y2, and on a second line Area: and the area.
  • Use long long for the area.
Example input and expected output
4 3 7 -2 4 5 1 0 9
Rectangle: -2 1 5 9 Area: 56
Hints
  • The coordinates may be negative; do not start the minimum values from zero.
  • With the example the left edge is -2, the right is 5, the bottom is 1 and the top is 9, and the area is 7 × 8 = 56.
Sample solution (after you try)
bounding_rectangle.cpp
// Challenge 1: the smallest rectangle around the points
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int x1 = 1000000000, y1 = 1000000000, x2 = -1000000000, y2 = -1000000000;
    for (int i = 0; i < n; i++) {
        int x, y;
        cin >> x >> y;
        x1 = min(x1, x);
        y1 = min(y1, y);
        x2 = max(x2, x);
        y2 = max(y2, y);
    }
    cout << "Rectangle: " << x1 << " " << y1 << " " << x2 << " " << y2 << endl;
    cout << "Area: " << 1LL * (x2 - x1) * (y2 - y1) << endl;
    return 0;
}
2

Covering with tape

Medium

You placed n pieces of tape on a straight line, each piece covers from l to r. The pieces may overlap. What is the total length covered by tape (without counting the overlapping part twice)?

Requirements
  • Read n and then the intervals.
  • Sort the intervals by their start.
  • Walk through them while keeping a current merged interval; if the next interval starts inside it, extend the end, otherwise add the length of the current one and start a new one.
  • Print the total length.
Example input and expected output
4 1 4 3 6 8 10 9 12
9
Hints
  • The intervals [1,4] and [3,6] merge into [1,6].
  • With the example: merging gives [1,6] and [8,12], so the answer is 5 + 4 = 9.
Sample solution (after you try)
tape_cover.cpp
// Challenge 2: the total length covered by tape strips
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<pair<int, int>> tape(n);
    for (int i = 0; i < n; i++) {
        cin >> tape[i].first >> tape[i].second;
    }
    sort(tape.begin(), tape.end());

    long long total = 0;
    int start = tape[0].first, end = tape[0].second;
    for (int i = 1; i < n; i++) {
        if (tape[i].first <= end) {
            end = max(end, tape[i].second);
        } else {
            total += end - start;
            start = tape[i].first;
            end = tape[i].second;
        }
    }
    total += end - start;
    cout << total << endl;
    return 0;
}

Quick summary

  • An axis-aligned rectangle is determined by two corners, bottom-left and top-right, and it should be normalized.
  • Width = hi.x - lo.x, height = hi.y - lo.y, and area = width × height.
  • Two rectangles do not intersect if they are separated horizontally or vertically; touching without area does not count as intersecting.
  • Intersection: the largest of the lower limits and the smallest of the upper limits on each axis.
  • The shared length of two intervals = max(0, min(ends) - max(starts)), and the intersection area is the product of the shared lengths of the axes.
  • The area covered by two rectangles = the sum of their areas − the intersection area.
  • The bounding rectangle of points takes the smallest and largest x and y.

Glossary

The most important terms in this lesson:

Axis-aligned rectangle

A rectangle whose sides are parallel to the coordinate axes.

Point

A pair of coordinates (x, y).

Corner

The point where two sides meet; we need two opposite corners.

Normalized

A rectangle whose first corner has the small coordinates and the second the large ones.

Width / Height

The difference between the coordinates on the horizontal / vertical axis.

Area

Width × height.

Intersection

The part shared by two shapes.

Interval

A segment of a line with a start and an end.

Overlap

Having a shared part between two intervals or rectangles.

Bounding box

The smallest axis-aligned rectangle that contains all the points.

Union

Everything two shapes cover together, without repetition.

Inclusion-exclusion

We add, then subtract what we counted twice.
