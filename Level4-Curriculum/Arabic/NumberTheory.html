Number Theory — القاسم المشترك الأكبر GCD والمضاعف المشترك الأصغر LCM

ماذا ستتعلم في هذا الدرس؟

  • تفهم معنى القاسم المشترك الأكبر والمضاعف المشترك الأصغر بأمثلة من الحياة
  • تكتب خوارزمية إقليدس وتفهم لماذا هي سريعة
  • تستعمل gcd وlcm الجاهزتين وتحسب المضاعف بأمان من التجاوز
  • تطبق الأداتين على الكسور والأحداث الدورية والتبليط
  • تمدد الفكرة إلى أكثر من عددين بالناتج التراكمي

توزيع عادل ولقاء متكرر

لديك 12 قطعة شوكولاتة و18 قطعة بسكويت، وتريد أن تصنع أكياسًا متطابقة تمامًا، في كل كيس نفس العدد من الشوكولاتة ونفس العدد من البسكويت، ولا يتبقى شيء. ما أكبر عدد من الأكياس يمكنك صنعه؟ الجواب 6 أكياس (في كل كيس قطعتا شوكولاتة وثلاث قطع بسكويت). العدد 6 هو القاسم المشترك الأكبر (GCD) للعددين 12 و18.

وفي مثال آخر، ضوءان يومضان: الأول كل 4 ثوانٍ والثاني كل 6 ثوانٍ، وقد وَمَضا معًا الآن. متى يومضان معًا من جديد؟ بعد 12 ثانية، وهو أصغر عدد يقبل القسمة على 4 وعلى 6. هذا هو المضاعف المشترك الأصغر (LCM).

نظرية الأعداد (number theory) اسم كبير للعبة بسيطة: اللعب بالأعداد الصحيحة وبالقسمة وبالباقي. القاسم المشترك الأكبر يجيب «ما أكبر شيء يقسم الاثنين؟»، والمضاعف المشترك الأصغر يجيب «ما أول مكان يلتقي فيه مضاعفاهما؟».

المصطلحمثال بالعددين 12 و18
قواسم 121، 2، 3، 4، 6، 12

الطريقة البدائية وكلفتها

أبسط طريقة لإيجاد القاسم المشترك الأكبر أن نجرب كل عدد من 1 حتى الأصغر من الرقمين، ونحتفظ بآخر عدد قسمهما معًا:

gcd_brute.cpp
#include <iostream>#include <algorithm>using namespace std; int main() {    int a = 36, b = 60;    int tries = 0;    int best = 1;    for (int d = 1; d <= min(a, b); d++) {        tries++;        if (a % d == 0 && b % d == 0) {            best = d;        }    }    cout << "gcd = " << best << " after " << tries << " tries" << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
gcd = 12 after 36 tries

الطريقة صحيحة، لكنها تحتاج إلى عدد محاولات يساوي الرقم الأصغر. للأرقام الصغيرة لا مشكلة، أما إن كان الرقمان بحجم مليار فسنجرب مليار عدد! نحتاج إلى فكرة أذكى.

خوارزمية إقليدس: حيلة عمرها أكثر من ألفي سنة

لاحظ إقليدس أن أي عدد يقسم الرقمين a وb فهو يقسم أيضًا a - b (وما يتبع ذلك من طرح متكرر، أي a % b). أي أن القواسم المشتركة لا تتغير حين نستبدل الأكبر بباقي قسمته على الأصغر:

gcd(a, b) = gcd(b, a % b) وعندما يصير الثاني صفرًا يكون الأول هو الجواب: gcd(a, 0) = a.

euclid.cpp
#include <iostream>using namespace std; int gcd2(int a, int b) {    cout << "gcd(" << a << ", " << b << ")" << endl;    if (b == 0) {        return a;    }    return gcd2(b, a % b);} int main() {    int g = gcd2(252, 105);    cout << "answer " << g << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
gcd(252, 105) gcd(105, 42) gcd(42, 21) gcd(21, 0) answer 21

لاحظ كيف انهارت الأرقام بسرعة: من 252 و105 إلى 105 و42، ثم 42 و21، ثم 21 و0. أربع خطوات فقط. والأروع أن عدد الخطوات يبقى صغيرًا حتى مع الأرقام الضخمة:

euclid_steps.cpp
long long pairs[3][2] = {{832040, 514229}, {1000000000, 640000000}, {1000000000, 1}};for (auto& p : pairs) {    long long a = p[0], b = p[1];    int steps = 0;    while (b != 0) {        a %= b;        swap(a, b);        steps++;    }    cout << p[0] << " and " << p[1] << ": steps = " << steps << endl;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
832040 and 514229: steps = 28 1000000000 and 640000000: steps = 5 1000000000 and 1: steps = 1

مع رقمين قرب المليار لم نحتاج إلا إلى بضع خطوات. وأسوأ الحالات هي أعداد فيبوناتشي المتتالية (مثل الحالة الأولى: 28 خطوة)، وحتى هناك يكون عدد الخطوات تقريبًا log n. لذلك نقول إن زمن الخوارزمية O(log min(a, b)).

مختبر تفاعلي (1): إقليدس بالمربعات

هناك صورة هندسية جميلة لإقليدس: خذ مستطيلًا طوله a وعرضه b واقطع منه أكبر عدد ممكن من المربعات التي ضلعها هو الضلع الأقصر. يتبقى شريط أصغر، فاقطع منه مربعات بالطريقة نفسها، وكرر حتى لا يبقى شيء. ضلع آخر مربع هو القاسم المشترك الأكبر! اكتب رقمين (حتى 99) واضغط «الخطوة التالية».

ما الذي سيطبعه البرنامج؟ (gcd(48, 180) ثم lcm(4, 10))

48 = 2^4 × 3 و180 = 2^2 × 3^2 × 5، فالقاسم المشترك الأكبر 2^2 × 3 = 12. والمضاعف المشترك الأصغر لـ 4 و10 هو 20 (فهو أول رقم يظهر في جدولي الضرب معًا).

الدوال الجاهزة gcd وlcm

لا نحتاج في العادة أن نكتب إقليدس بأنفسنا، فمنذ C++17 توجد الدالتان gcd وlcm في الترويسة <numeric>. (في المترجمات القديمة استعمل __gcd(a, b) وهي توفر القاسم فقط.)

builtin_gcd.cpp
#include <iostream>#include <numeric>using namespace std; int main() {    cout << gcd(84, 36) << endl;    cout << lcm(4, 6) << endl;    cout << gcd(0, 5) << endl;    cout << gcd(17, 5) << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
12 12 5 1

انتبه إلى نوع الأرقام: إذا مررت int مع long long إلى gcd فقد لا يُترجم البرنامج أو يعطيك نوعًا غير متوقع. اجعل النوعين متطابقين، وفضّل long long عندما تكون الأرقام كبيرة.

المضاعف المشترك الأصغر وعلاقته بالقاسم

لا نحتاج إلى حلقة لإيجاد المضاعف المشترك الأصغر: يكفي استعمال القاسم المشترك الأكبر، لأن gcd(a, b) × lcm(a, b) = a × b. ومنها:

lcm(a, b) = a / gcd(a, b) * b — نقسم أولًا ثم نضرب حتى لا يكبر الناتج الوسيط فيتجاوز حد النوع.

lcm_demo.cpp
#include <iostream>#include <numeric>using namespace std; long long lcm2(long long a, long long b) {    return a / gcd(a, b) * b;} int main() {    long long all = 1;    for (int k = 1; k <= 10; k++) {        all = lcm2(all, k);    }    cout << "lcm of 1..10 = " << all << endl;    cout << "gcd * lcm = " << gcd(12, 18) * lcm2(12, 18) << ", a * b = " << 12 * 18 << endl;    cout << "lights meet after " << lcm2(lcm2(12, 15), 20) << " seconds" << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
lcm of 1..10 = 2520 gcd * lcm = 216, a * b = 216 lights meet after 60 seconds

ولثلاثة أعداد أو أكثر نطبق الدالة على الناتج التراكمي: lcm(lcm(12, 15), 20) = lcm(60, 20) = 60. وكذلك للقاسم: gcd(a, b, c) = gcd(gcd(a, b), c).

مختبر تفاعلي (2): ومضات الضوء

ضوءان يومضان كل p ثانية وكل q ثانية. كل خلية ثانية واحدة: الأزرق يومض فيه الأول، والبرتقالي يومض فيه الثاني، والأخضر يومضان معًا. أول خلية خضراء هي المضاعف المشترك الأصغر.

مشروع الدرس: بلاط الأرضية

نختار أكبر بلاط مربع يغطي الأرضية بلا كسر.

الفكرة

ستبلّط المدرسة أرضية قاعة مستطيلة بقطع بلاط مربعة متماثلة. تريد أكبر بلاط ممكن بحيث يغطي الأرضية كاملة دون قص أي قطعة، ثم تريد أن تعرف عدد القطع اللازمة.

المطلوب منك
  1. اقرأ عرض القاعة وطولها (أعداد صحيحة بالسنتيمتر).
  2. ضلع أكبر مربع يملأ المستطيل بلا كسر هو القاسم المشترك الأكبر للبعدين.
  3. عدد القطع = (العرض ÷ الضلع) × (الطول ÷ الضلع).
  4. اطبع Tile side: ثم الضلع، وفي سطر ثانٍ Tiles: ثم العدد.
مثالان على التشغيل

التشغيل الأول:

360 240
Tile side: 120 Tiles: 6

التشغيل الثاني (بعدان متباينان، أول بينهما):

7 13
Tile side: 1 Tiles: 91

تحقق ذهنيًا: 360 و240 يقبلان القسمة على 120، فالبلاط 120 × 120 يغطي الأرضية بثلاث قطع في الطول (360÷120) واثنتين في العرض (240÷120)، أي 6 قطع. أما 7 و13 فلا يقسمهما إلا العدد 1، فالبلاط 1 × 1 و91 قطعة.

بعد أن تجرّب بنفسك: اعرض الحل
tiles.cpp
#include <iostream>
#include <numeric>
using namespace std;

int main() {
    long long width, length;
    cin >> width >> length;

    long long side = gcd(width, length);
    long long tiles = (width / side) * (length / side);

    cout << "Tile side: " << side << endl;
    cout << "Tiles: " << tiles << endl;
    return 0;
}

جمع كسرين

متوسط

اقرأ كسرين p1/q1 وp2/q2 (أعداد موجبة، مقاماتها حتى 1000). اطبع مجموعهما مختصرًا على الشكل بسط/مقام.

المطلوب
  • احسب المقام المشترك الأصغر بالمضاعف المشترك الأصغر للمقامين.
  • حوّل كل بسط إلى المقام الجديد وجمعهما.
  • اختصر الناتج بالقسمة على القاسم المشترك الأكبر للبسط والمقام.
  • اطبع الكسر الناتج.
مثال على الإدخال والناتج المتوقع
1 6 3 10
7/15
تلميحات
  • استعمل long long لتأمن من التجاوز.
  • مع المثال 1/6 + 3/10 يكون المقام 30 والبسط 5 + 9 = 14، فالنتيجة 14/30 = 7/15.
نموذج الحل (بعد المحاولة)
add_fractions.cpp
// Challenge 1: add two fractions
#include <iostream>
#include <numeric>
using namespace std;

int main() {
    long long p1, q1, p2, q2;
    cin >> p1 >> q1 >> p2 >> q2;

    long long den = lcm(q1, q2);
    long long num = p1 * (den / q1) + p2 * (den / q2);
    long long g = gcd(num, den);

    cout << num / g << "/" << den / g << endl;
    return 0;
}

alarms.cpp
// Challenge 2: when do all the alarms ring together?
#include <iostream>
#include <numeric>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long all = 1;
    for (int i = 0; i < n; i++) {
        long long period;
        cin >> period;
        all = all / gcd(all, period) * period;
    }
    cout << all << endl;
    return 0;
}

ملخص سريع

  • القاسم المشترك الأكبر gcd(a, b) أكبر عدد يقسم الرقمين، والمضاعف المشترك الأصغر lcm(a, b) أصغر عدد يقبل القسمة عليهما.
  • الطريقة البدائية تجرب كل الأعداد، وكلفتها بحجم الرقم الأصغر.
  • قاعدة إقليدس: gcd(a, b) = gcd(b, a % b) وgcd(a, 0) = a، وزمنها O(log n).
  • منذ C++17 تتوفر gcd وlcm في <numeric> (وقبلها __gcd).
  • lcm(a, b) = a / gcd(a, b) * b: نقسم أولًا حتى لا يتجاوز الناتج الوسيط الحد.
  • gcd(a, b) × lcm(a, b) = a × b.
  • لعدة أعداد نطبق الدالة على الناتج التراكمي.
