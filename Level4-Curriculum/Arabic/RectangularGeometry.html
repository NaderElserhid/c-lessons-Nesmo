Rectangular Geometry — مستطيلات موازية للمحورين في بُعد وبعدين

ماذا ستتعلم في هذا الدرس؟

  • تمثل النقاط والمستطيلات بـ struct وتحسب العرض والارتفاع والمساحة
  • تفحص تقاطع مستطيلين بفحص الانفصال على المحورين
  • تحسب مستطيل التقاطع ومساحته بأكبر الحدود الدنيا وأصغر الحدود العليا
  • تعالج الفترات في بُعد واحد وتحول مسائل البعدين إلى مسألتين في بعد واحد
  • تحسب المساحة المغطاة والمستطيل المحيط وتتجنب الأخطاء الشائعة

مستطيلات على لوحة الإحداثيات

في كثير من المسائل نتعامل مع مستطيلات أضلاعها موازية للمحورين (axis-aligned rectangles): نوافذ على الشاشة، لوحات إعلانات على جدار، قطع أرض، مناطق على خريطة. هذا النوع من المستطيلات سهل جدًا لأن كل المعلومات فيه أرقام بسيطة على محورين.

نتفق على أن المحور x يتجه يمينًا وأن المحور y يتجه إلى الأعلى. ومستطيل واحد يكفي لتحديده ركنان: ركن أسفل-يسار (أصغر x وأصغر y) وركن أعلى-يمين (أكبر x وأكبر y).

والفكرة التي ستتكرر في الدرس: ما دام المستطيل موازيًا للمحورين، فكل مسألة هندسية تتحول إلى مسألتين منفصلتين في بُعد واحد: واحدة على المحور الأفقي وواحدة على المحور الرأسي. ثم نجمع النتيجتين.

تمثيل النقاط والمستطيلات

نستعمل struct لتجميع الإحداثيات. اضغط على السطور المضيئة لتقرأ شرحها:

rectangles.cpp
#include <iostream>using namespace std; struct Point {    int x;    int y;}; struct Rect {    Point lo;    Point hi;}; int width(Rect r) {    return r.hi.x - r.lo.x;} int height(Rect r) {    return r.hi.y - r.lo.y;} int area(Rect r) {    return width(r) * height(r);} int main() {    Rect r = {{1, 1}, {5, 4}};    cout << "width " << width(r) << ", height " << height(r);    cout << ", area " << area(r) << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
width 4, height 3, area 12

افترضنا أن كل مستطيل معياري (normalized): أي lo.x ≤ hi.x وlo.y ≤ hi.y. إذا جاءك الركنان بترتيب عشوائي من المدخلات فبدّل القيم أولًا (سترى ذلك في مشروع الدرس) وإلا خرجت أطوال سالبة.

هل يتقاطع مستطيلان؟

أسهل طريقة أن نسأل السؤال المعاكس: متى لا يتقاطعان؟ يكفي أن يكونا منفصلين أفقيًا (أحدهما كله على يسار الآخر) أو منفصلين رأسيًا (أحدهما كله تحت الآخر). وما عدا ذلك فهما يتقاطعان بمساحة موجبة:

overlap_test.cpp
#include <iostream>using namespace std; struct Point {    int x;    int y;}; struct Rect {    Point lo;    Point hi;}; bool overlaps(Rect a, Rect b) {    bool apartX = a.hi.x <= b.lo.x || b.hi.x <= a.lo.x;    bool apartY = a.hi.y <= b.lo.y || b.hi.y <= a.lo.y;    return !apartX && !apartY;} int main() {    Rect a = {{2, 2}, {6, 5}};    Rect inside = {{3, 3}, {4, 4}};    Rect cross = {{5, 4}, {8, 8}};    Rect edge = {{6, 2}, {9, 5}};    Rect corner = {{6, 5}, {9, 9}};    Rect far = {{10, 10}, {12, 12}};     cout << "inside: " << overlaps(a, inside) << endl;    cout << "cross:  " << overlaps(a, cross) << endl;    cout << "edge:   " << overlaps(a, edge) << endl;    cout << "corner: " << overlaps(a, corner) << endl;    cout << "far:    " << overlaps(a, far) << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
inside: 1 cross: 1 edge: 0 corner: 0 far: 0

انتبه للتلامس: المستطيل edge يلامس a عند ضلع كامل، وcorner عند نقطة، ومع ذلك لا تقاطع لأن المساحة المشتركة صفر. لهذا استعملنا <= وليس < في شرط الانفصال. استعمال < سيجعل المتلامسين يبدوان متقاطعين.

مستطيل التقاطع نفسه

إذا تقاطع المستطيلان فالجزء المشترك مستطيل آخر. حافته اليسرى هي الأكبر بين الحافتين اليسريين (لأنه لا يبدأ إلا بعد أن يبدأ الاثنان)، وحافته اليمنى هي الأصغر بين الحافتين اليمنيين (لأنه ينتهي حين ينتهي أحدهما). وكذلك رأسيًا:

intersection.cpp
#include <iostream>#include <algorithm>using namespace std; struct Point {    int x;    int y;}; struct Rect {    Point lo;    Point hi;}; Rect intersection(Rect a, Rect b) {    Rect c;    c.lo.x = max(a.lo.x, b.lo.x);    c.lo.y = max(a.lo.y, b.lo.y);    c.hi.x = min(a.hi.x, b.hi.x);    c.hi.y = min(a.hi.y, b.hi.y);    return c;} int main() {    Rect a = {{1, 1}, {6, 5}};    Rect b = {{4, 3}, {9, 8}};    Rect c = intersection(a, b);    cout << "(" << c.lo.x << ", " << c.lo.y << ") to (" << c.hi.x << ", " << c.hi.y << ")" << endl;    cout << "area " << (c.hi.x - c.lo.x) * (c.hi.y - c.lo.y) << endl;    return 0;}

لا تستدعِ دالة التقاطع إلا بعد التأكد أن المستطيلين متقاطعان فعلًا؛ وإلا حصلت على مستطيل «مقلوب» بعرض أو ارتفاع سالب. وفي الفقرات التالية سنرى حيلة تجعل هذا الفحص غير ضروري عند حساب المساحة.

مختبر تفاعلي: مستطيلان على اللوحة

غيّر الإحداثيات (من 0 إلى 12) وراقب المستطيلين. المنطقة الخضراء هي التقاطع. تحت المحور الأفقي وإلى يسار المحور الرأسي ترى مسقط كل مستطيل على المحور (أزرق وبرتقالي)، ومسقط التقاطع بالأخضر: لا يوجد تقاطع إلا إذا وُجد مسقطان مشتركان معًا. جرّب تقريب المستطيلين حتى يتلامسا.

بُعد واحد: الفترات

كل ما سبق يتفكك إلى مسألتين على فترات (intervals): فترة على x وفترة على y. والفترة ببساطة رقمان: بداية ونهاية. الطول هو الفرق بينهما، ومشترك الطول بين فترتين:

intervals.cpp
#include <iostream>#include <algorithm>using namespace std; struct Interval {    int l;    int r;}; int length(Interval s) {    return s.r - s.l;} int overlapLength(Interval a, Interval b) {    return max(0, min(a.r, b.r) - max(a.l, b.l));} int main() {    Interval a = {2, 9}, b = {6, 12}, c = {10, 14};    cout << "a and b share " << overlapLength(a, b) << endl;    cout << "a and c share " << overlapLength(a, c) << endl;    cout << "a and b cover " << length(a) + length(b) - overlapLength(a, b) << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
a and b share 3 a and c share 0 a and b cover 10

تأمل المقدار min(a.r, b.r) - max(a.l, b.l): حين تتداخل الفترتان يكون موجبًا وهو طول المشترك، وحين تنفصلان يصبح سالبًا أو صفرًا. لذلك يكفي أن نلفّه بـ max(0, …) لنحصل على الصفر تلقائيًا بدلًا من كتابة if.

المساحة المغطاة بمستطيلين

نضع لوحتين على جدار، وبعض المساحة مشترك بينهما. كم مساحة الجدار المغطاة فعلًا؟ إذا جمعنا مساحتي اللوحتين فقط فقد عددنا الجزء المشترك مرتين، فنطرحه مرة. وبما أن مساحة التقاطع = (عرض مشترك) × (ارتفاع مشترك)، وكلاهما صفر عند الانفصال، فلا نحتاج إلى فحص التقاطع أبدًا:

union_area.cpp
#include <iostream>#include <algorithm>using namespace std; struct Point {    int x;    int y;}; struct Rect {    Point lo;    Point hi;}; int area(Rect r) {    return (r.hi.x - r.lo.x) * (r.hi.y - r.lo.y);} int overlapArea(Rect a, Rect b) {    int w = max(0, min(a.hi.x, b.hi.x) - max(a.lo.x, b.lo.x));    int h = max(0, min(a.hi.y, b.hi.y) - max(a.lo.y, b.lo.y));    return w * h;} int main() {    Rect a = {{1, 1}, {6, 5}};    Rect b = {{4, 3}, {9, 8}};    Rect far = {{10, 10}, {12, 12}};     cout << "overlap(a, b) = " << overlapArea(a, b) << endl;    cout << "overlap(a, far) = " << overlapArea(a, far) << endl;    cout << "covered by a and b = " << area(a) + area(b) - overlapArea(a, b) << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
overlap(a, b) = 4 overlap(a, far) = 0 covered by a and b = 41
المطلوبالصيغة
مساحة مستطيل(hi.x - lo.x) * (hi.y - lo.y)
عرض التقاطعmax(0, min(a.hi.x, b.hi.x) - max(a.lo.x, b.lo.x))
ارتفاع التقاطعmax(0, min(a.hi.y, b.hi.y) - max(a.lo.y, b.lo.y))
مساحة التقاطعالعرض × الارتفاع
المساحة المغطاةarea(a) + area(b) - overlap(a, b)

هذا الأسلوب (اجمع ثم اطرح المكرر) اسمه مبدأ الإدراج والاستبعاد. ومع ثلاثة مستطيلات يصبح أدق لأن تقاطع الثلاثة معًا يحتاج إلى أن يُضاف من جديد، لذلك اتّبع الحذر ولا تعمّم الصيغة دون تفكير.

المستطيل المحيط ومواقع النقاط

مسألة متكررة: ما أصغر مستطيل موازٍ للمحورين يحتوي كل النقاط؟ الحافة اليسرى هي أصغر x، واليمنى أكبر x، والسفلى أصغر y، والعليا أكبر y:

bounding_box.cpp
#include <iostream>#include <vector>#include <algorithm>using namespace std; int main() {    vector<int> xs = {3, -2, 5, 0};    vector<int> ys = {7, 4, 1, 9};     int x1 = *min_element(xs.begin(), xs.end());    int x2 = *max_element(xs.begin(), xs.end());    int y1 = *min_element(ys.begin(), ys.end());    int y2 = *max_element(ys.begin(), ys.end());     cout << "(" << x1 << ", " << y1 << ") to (" << x2 << ", " << y2 << ")" << endl;    cout << "area " << (x2 - x1) * (y2 - y1) << endl;    return 0;}

مشروع الدرس: لوحتان على جدار المدرسة

نحسب المساحة المشتركة والمساحة المغطاة فعلًا.

الفكرة

ستعلّق المدرسة لوحتين مستطيلتين على جدار، وقد تتداخلان. يريد مدير المدرسة أن يعرف مساحة الجزء الذي تتداخل فيه اللوحتان، وكذلك مساحة الجدار التي تغطيها اللوحتان معًا.

المطلوب منك
  1. اقرأ لوحتين، كل منهما بأربعة أعداد x1 y1 x2 y2 لركنين متقابلين (قد يأتيان بأي ترتيب).
  2. رتّب إحداثيات كل لوحة بحيث تكون الصغرى أولًا.
  3. احسب مساحة التقاطع بالحيلة max(0, …) × max(0, …).
  4. اطبع Overlap: ثم المساحة المشتركة، وفي سطر ثانٍ Covered: ثم المساحة المغطاة.
مثالان على التشغيل

التشغيل الأول (لوحتان متداخلتان):

1 1 5 4 3 2 8 6
Overlap: 4 Covered: 28

التشغيل الثاني (لوحتان متباعدتان):

0 0 2 2 5 5 7 7
Overlap: 0 Covered: 8

تحقق ذهنيًا: في التشغيل الأول اللوحة الأولى 4 × 3 = 12 والثانية 5 × 4 = 20. الجزء المشترك عرضه من 3 إلى 5 أي 2، وارتفاعه من 2 إلى 4 أي 2، فمساحته 4. المغطاة 12 + 20 - 4 = 28.

بعد أن تجرّب بنفسك: اعرض الحل
posters.cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Rect {
    long long x1, y1, x2, y2;
};

Rect readRect() {
    Rect r;
    cin >> r.x1 >> r.y1 >> r.x2 >> r.y2;
    if (r.x1 > r.x2) {
        swap(r.x1, r.x2);
    }
    if (r.y1 > r.y2) {
        swap(r.y1, r.y2);
    }
    return r;
}

long long area(Rect r) {
    return (r.x2 - r.x1) * (r.y2 - r.y1);
}

long long overlapArea(Rect a, Rect b) {
    long long w = max(0LL, min(a.x2, b.x2) - max(a.x1, b.x1));
    long long h = max(0LL, min(a.y2, b.y2) - max(a.y1, b.y1));
    return w * h;
}

int main() {
    Rect a = readRect();
    Rect b = readRect();
    long long common = overlapArea(a, b);
    cout << "Overlap: " << common << endl;
    cout << "Covered: " << area(a) + area(b) - common << endl;
    return 0;
}

المستطيل المحيط بالنقاط

سهل

اقرأ n ثم n نقطة (كل نقطة x y). اطبع أصغر مستطيل موازٍ للمحورين يحتوي كل النقاط، ومساحته.

المطلوب
  • ابدأ بقيم صغرى كبيرة جدًا وقيم عظمى صغيرة جدًا.
  • حدّث أصغر وأكبر x وأصغر وأكبر y مع كل نقطة.
  • اطبع Rectangle: ثم x1 y1 x2 y2، وفي سطر ثانٍ Area: والمساحة.
  • استعمل long long للمساحة.
مثال على الإدخال والناتج المتوقع
4 3 7 -2 4 5 1 0 9
Rectangle: -2 1 5 9 Area: 56
تلميحات
  • الإحداثيات قد تكون سالبة؛ لا تبدأ القيم الصغرى من صفر.
  • مع المثال تكون الحافة اليسرى -2 واليمنى 5 والسفلى 1 والعليا 9، والمساحة 7 × 8 = 56.
نموذج الحل (بعد المحاولة)
bounding_rectangle.cpp
// Challenge 1: the smallest rectangle around the points
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int x1 = 1000000000, y1 = 1000000000, x2 = -1000000000, y2 = -1000000000;
    for (int i = 0; i < n; i++) {
        int x, y;
        cin >> x >> y;
        x1 = min(x1, x);
        y1 = min(y1, y);
        x2 = max(x2, x);
        y2 = max(y2, y);
    }
    cout << "Rectangle: " << x1 << " " << y1 << " " << x2 << " " << y2 << endl;
    cout << "Area: " << 1LL * (x2 - x1) * (y2 - y1) << endl;
    return 0;
}

تغطية الشريط اللاصق

متوسط

وضعتَ n قطعة من الشريط اللاصق على خط مستقيم، كل قطعة تغطي من l إلى r. قد تتداخل القطع. ما الطول الكلي المغطى بالشريط (دون عدّ الجزء المتداخل مرتين)؟

المطلوب
  • اقرأ n ثم الفترات.
  • رتّب الفترات بحسب البداية.
  • امشِ على الفترات مع الاحتفاظ بفترة مدمجة حالية؛ إذا بدأت الفترة التالية داخلها فوسّع النهاية، وإلا أضف طول الحالية وابدأ فترة جديدة.
  • اطبع الطول الكلي.
مثال على الإدخال والناتج المتوقع
4 1 4 3 6 8 10 9 12
9
تلميحات
  • الفترتان [1,4] و[3,6] تُدمجان في [1,6].
  • مع المثال: الدمج يعطي [1,6] و[8,12]، فالجواب 5 + 4 = 9.
نموذج الحل (بعد المحاولة)
tape_cover.cpp
// Challenge 2: the total length covered by tape strips
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<pair<int, int>> tape(n);
    for (int i = 0; i < n; i++) {
        cin >> tape[i].first >> tape[i].second;
    }
    sort(tape.begin(), tape.end());

    long long total = 0;
    int start = tape[0].first, end = tape[0].second;
    for (int i = 1; i < n; i++) {
        if (tape[i].first <= end) {
            end = max(end, tape[i].second);
        } else {
            total += end - start;
            start = tape[i].first;
            end = tape[i].second;
        }
    }
    total += end - start;
    cout << total << endl;
    return 0;
}

ملخص سريع

  • المستطيل الموازي للمحورين يُحدَّد بركنين: أسفل-يسار وأعلى-يمين، بشرط أن يكون معياريًا.
  • العرض = hi.x - lo.x، والارتفاع = hi.y - lo.y، والمساحة = العرض × الارتفاع.
  • لا يتقاطع مستطيلان إذا انفصلا أفقيًا أو رأسيًا؛ والتلامس بلا مساحة لا يُحسب تقاطعًا.
  • التقاطع: أكبر الحدود الدنيا وأصغر الحدود العليا على كل محور.
  • مشترك الطول بين فترتين = max(0, min(النهايتين) - max(البدايتين))، ومساحة التقاطع هي حاصل ضرب مشتركي المحورين.
  • المساحة المغطاة بمستطيلين = مجموع مساحتيهما − مساحة التقاطع.
  • المستطيل المحيط بنقاط يأخذ أصغر وأكبر x وy.
