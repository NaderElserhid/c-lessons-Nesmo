Structure of a Program — كيف يُبنى برنامج C++ من الداخل

ماذا ستتعلم في هذا الدرس؟

  • تتعرف على الأجزاء الأساسية لأي برنامج C++ وتحدد دور كل جزء
  • تفهم لماذا تُعد الدالة main نقطة البداية، وماذا يعني return 0;

ماذا يوجد داخل برنامج C++؟

أي برنامج بسيط تقريبًا يتكون من أربع طبقات مرتبة: ملفات نستعين بها، ثم تصريحات عامة، ثم الدالة الرئيسية، ثم التعليمات داخلها. في هذا البرنامج الصغير ستجد كل شيء في مكانه، فاضغط على الأسطر لتفهم دور كلٍّ منها:

الدالة main: نقطة البداية

حين تشغّل برنامجك، يبحث النظام عن دالة اسمها main ويبدأ التنفيذ منها، ولا يبدأ من أي مكان آخر. لهذا السبب:

القواعد
  • يجب أن يحتوي البرنامج على main واحدة بالضبط
  • نوع إرجاعها int
  • جسمها محصور بين { و}
  • التعليمات داخلها تُنفَّذ بالترتيب من الأعلى إلى الأسفل
ممنوعات
  • تغيير الاسم إلى Main أو start
  • تعريف دالتين باسم main
  • استدعاء main من داخل البرنامج

صيغتا main المعتمدتان

الصيغةمتى نستخدمها
int main() { ... }برنامج لا يحتاج وسائط من سطر الأوامر (حالتنا الآن)
int main(int argc, char* argv[]) { ... }برنامج يستقبل وسائط عند تشغيله من الطرفية

ماذا تعني return 0;

القيمة التي تُرجعها main تصل إلى نظام التشغيل ويسمّى رمز الخروج (exit code). القيمة 0 تعني أن كل شيء تمّ بنجاح، وأي قيمة أخرى تدل عادةً على وجود مشكلة. ومن الميزات الخاصة بـ main أنك لو نسيت كتابة return 0; في آخرها فإن C++ تضيفها لك ضمنيًا.

رغم ذلك نكتب return 0; صراحةً في دروسنا لأن ذلك يوضح نية الكاتب، ولأن هذه الميزة الضمنية تخص main وحدها بين كل الدوال.

ملفات الترويسة (#include)

لغة C++ صغيرة في نواتها، وكل أدواتها الجاهزة تأتي في مكتبات. نستعير أداة بكتابة السطر #include متبوعًا باسم ملف الترويسة بين < >. قبل الترجمة يستبدل المعالج المسبق هذا السطر بمحتوى الملف كاملًا.

الترويسةماذا تعطيناأمثلة
<iostream>الإدخال والإخراجcin, cout
<string>التعامل مع النصوصstring
<cmath>الدوال الرياضيةsqrt, pow
<vector>مصفوفات قابلة للتمددvector
<algorithm>خوارزميات جاهزةsort, max

ما هو using namespace std؟

أسماء المكتبة القياسية كلها تعيش داخل «حيّ» اسمه std. فإما أن نكتب اسم الحيّ في كل مرة (std::cout)، أو نعلن مرة واحدة أننا سنستخدم أسماء هذا الحيّ مباشرة بالسطر using namespace std;. في المسابقات والتمارين القصيرة نفضّل الثانية لاختصارها.

ستجد بعض المبرمجين يكتبون #include <bits/stdc++.h> ليضمّنوا كل المكتبات دفعة واحدة. هذه الترويسة خاصة بمترجم GCC وليست جزءًا من المعيار، وقد لا تعمل في مترجمات أخرى. في دروسنا نستدعي كل ترويسة بالاسم لنتعلم ما نحتاجه فعلًا.

المسافات والتنسيق: للبشر لا للآلة

المترجم لا يهتم بعدد المسافات أو الأسطر الفارغة أو التزحيف خارج النصوص. البرنامجان التاليان يؤديان نفس العمل تمامًا:

منسّق ومقروء
#include <iostream>
using namespace std;

int main() {
    int a = 2;
    int b = 5;
    cout << a + b;
    return 0;
}
يعمل لكنه صعب القراءة
#include <iostream>
using namespace std;
int main(){int a=2;int b=5;
cout<<a+b;
        return 0;}

ناتج كل منهما هو:

7

تحقّقنا بترجمة الصيغتين وتشغيلهما؛ الناتج واحد. لكن الفارق عندما تعود إلى الكود بعد أسبوع أو يقرأه زميلك: الأول واضح من النظرة الأولى، والثاني يحتاج إلى فك رموز.

قواعد تنسيق بسيطة تكفيك الآن: تعليمة واحدة في كل سطر، وأربع مسافات (أو tab واحدة) أمام كل سطر داخل { }، وسطر فارغ يفصل بين أجزاء البرنامج المنطقية.

استثناء واحد مهم: الأسطر التي تبدأ بـ # تُكتب كل واحدة في سطر مستقل، لأن المعالج المسبق يعمل سطرًا بسطر.

الترتيب مهم: مختبر التنفيذ

يقرأ الحاسوب التعليمات من الأعلى إلى الأسفل ولا يقفز بينها. غيّر ترتيب الأسطر الثلاثة التالية بالأسهم، وشاهد كيف يتغير الناتج:

order.cpp
cout << "Fuel the rocket" << endl;
cout << "Count down" << endl;
cout << "Launch!" << endl;

من الملف النصي إلى البرنامج: ماذا يفعل g++؟

حين تكتب أمر الترجمة، يمرّ ملفك بثلاث مراحل متتالية:

1

المعالجة المسبقة (preprocessing)

تُنفَّذ أسطر #: يُلصق محتوى ملفات الترويسة في مكان #include، وتُزال التعليقات.

2

الترجمة (compilation)

يفحص المترجم القواعد ويحوّل كل ملف إلى شيفرة آلة جزئية. هنا تظهر أخطاء مثل نسيان ;.

3

الربط (linking)

تُجمع الأجزاء مع شيفرة المكتبات القياسية في ملف تنفيذي واحد. ومن أخطاء هذه المرحلة ألا يجد المترجم الدالة main.

الأوامر المعتادة في الطرفية:

terminal
# compile trip.cpp into an executable named trip
g++ -std=c++17 trip.cpp -o trip

# run it
./trip

الخيار -std=c++17 يحدد إصدار اللغة، و-o trip يحدد اسم الملف التنفيذي الناتج. على ويندوز يكون الناتج عادةً trip.exe.

مشروع الدرس: أصلح برنامج المكتبة

مهمتك هذه المرة أن تكون «المترجم»: تقرأ الكود وتجد ما يمنع بناءه.

الفكرة

موظف في مكتبة عامة كتب برنامجًا يطبع إعلان الإغلاق على شاشة الدخول، لكن برنامجه لا يُترجم أصلًا. تصلك نسخته كما هي، وعليك أن تصلحها.

المطلوب منك
  1. اقرأ البرنامج المعطى أدناه سطرًا سطرًا، وابحث عن الأخطاء (يوجد أربعة).
  2. اضغط على زر كل خطأ وجدته لتقرأ تفسيره.
  3. أعد كتابة البرنامج صحيحًا بحيث يُترجم ويطبع الناتج المطلوب.
الناتج الذي يجب أن يطبعه البرنامج بعد إصلاحه
Library closes at 9 PM Please return your books

البرنامج المعطى (فيه أخطاء)

library.cpp
#include <iostream>
using namespace std

int Main() {
    cout << "Library closes at " << 9 << " PM" << endl
    cout << "Please return your books" << endl;
    return 0
}

واجبات بعد الدرس

لوحة القطارات

سهل

موظف كتب برنامج لوحة قطارات في سطر مزدحم وبدون تنسيق، وأنت مطلوب منك تنظيفه وإكماله. هذا هو الكود المعطى:

train_messy.cpp
#include <iostream>
using namespace std;int main(){cout<<"Train 7"<<endl;
cout<<"Platform 3"<<endl;
      return 0;}

المطلوب
  • أعد كتابة البرنامج بتنسيق مقروء: تعليمة واحدة في كل سطر، وتزحيف أربع مسافات داخل main.
  • أضف سطرًا ثالثًا يطبع Departs 09:30.
  • أضف تعليقًا في أول الملف يحمل اسم البرنامج.
  • تأكد أنه يُترجم ويطبع الناتج المتوقع.
الناتج المتوقع
Train 7 Platform 3 Departs 09:30
تلميحات
  • فصل using namespace std; عن int main() بسطر فارغ.
  • ضع القوس { في نهاية سطر int main() والقوس } وحده في آخر سطر.
نموذج الحل (بعد المحاولة)
train.cpp
// Train board
#include <iostream>
using namespace std;

int main() {
    cout << "Train 7" << endl;
    cout << "Platform 3" << endl;
    cout << "Departs 09:30" << endl;
    return 0;
}
2

رتّب الوصفة

متوسط

هذا برنامج يطبع خطوات تحضير الشاي، لكن المبرمج كتب الخطوات بترتيب خاطئ. البرنامج يعمل ويُترجم، غير أن الناتج غير منطقي. أصلحه دون أن تغيّر نص أي خطوة:

tea_jumbled.cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Serve the tea" << endl;
    cout << "Add the tea leaves" << endl;
    cout << "Wait three minutes" << endl;
    cout << "Boil the water" << endl;
    cout << "Pour the water" << endl;
    return 0;
}

المطلوب
  • أعد ترتيب أسطر cout بحيث تظهر الخطوات بالترتيب المنطقي الموضح في الناتج المتوقع.
  • لا تغيّر نصوص الخطوات ولا تحذف أي منها.
  • أضف تعليقًا في أول الملف يذكر اسم الوصفة.
الناتج المتوقع
Boil the water Add the tea leaves Pour the water Wait three minutes Serve the tea
تلميحات
  • تذكّر أن الحاسوب ينفّذ التعليمات من الأعلى إلى الأسفل بالترتيب الذي كتبته.
  • ابدأ بتحديد الخطوة الأولى المنطقية ثم رتّب البقية خلفها.
نموذج الحل (بعد المحاولة)
tea.cpp
// Tea recipe
#include <iostream>
using namespace std;

int main() {
    cout << "Boil the water" << endl;
    cout << "Add the tea leaves" << endl;
    cout << "Pour the water" << endl;
    cout << "Wait three minutes" << endl;
    cout << "Serve the tea" << endl;
    return 0;
}

ملخص سريع

  • #include يستدعي الأدوات اللازمة، وusing namespace std; يختصر كتابة std::.
  • الدالة main هي نقطة البداية، وreturn 0; تعني أن البرنامج انتهى بنجاح.
  • المسافات والأسطر الفارغة للقارئ لا للمترجم، فنسّق الكود ليسهل فهمه.
  • يمر البرنامج بثلاث مراحل: معالجة مسبقة ثم ترجمة ثم ربط.
  • أخطاء البنية الشائعة: نسيان ; أو قوس أو ترويسة.
