Arrays — صف من الخانات تحت اسم واحد

ماذا ستتعلم في هذا الدرس؟

  • تفهم لماذا نحتاج المصفوفات وتعرّفها وتصل إلى عناصرها بالفهرس
  • تتذكر أن الفهرس يبدأ من 0 وتتجنب الخروج عن الحدود
  • تمر على المصفوفة بحلقة for وتحسب المجموع والمتوسط والأكبر والأصغر
  • تقرأ مصفوفة من المستخدم وتمررها إلى الدوال مع حجمها
  • تتعرف على المصفوفات ثنائية الأبعاد وعلى فهرسة النصوص

خمس علامات.. هل نصنع خمسة متغيرات؟

أراد معلمك حساب مجموع علامات خمسة طلاب. بالطريقة التي نعرفها، سنصنع متغيرًا لكل علامة:

five_variables.cpp
int score1 = 80;
int score2 = 95;
int score3 = 70;
int score4 = 88;
int score5 = 100;
cout << score1 + score2 + score3 + score4 + score5 << endl;
433

ماذا لو كان في الفصل ثلاثون طالبًا؟ سنكتب ثلاثين متغيرًا ونجمعها واحدًا واحدًا، ولن نستطيع استخدام حلقة لأن لكل متغير اسمًا مختلفًا! الحل هو المصفوفة (array).

تخيّل صفًّا من الخزائن المتجاورة في المدرسة، كلها من النوع نفسه، ولكل خزانة رقم يبدأ من صفر. المصفوفة هي صف من الخانات المتشابهة تحت اسم واحد، وتصل إلى كل خانة برقمها.

80[0]
95[1]
70[2]
88[3]
100[4]

مصفوفة من خمس خانات اسمها scores. الأرقام الصغيرة أسفل كل خانة هي الفهرس (index).

تعريف المصفوفة والوصول لعناصرها

الصيغة: type name[size] = { values }; فنكتب النوع، ثم الاسم، ثم عدد الخانات بين [ ]، ثم القيم الابتدائية بين { }. وللوصول إلى خانة نكتب الاسم ثم فهرسها بين قوسين مربعين:

array_basics.cpp
int scores[5] = {80, 95, 70, 88, 100};

cout << "First: " << scores[0] << endl;
cout << "Third: " << scores[2] << endl;
cout << "Last:  " << scores[4] << endl;

scores[2] = 75;
cout << "Third after update: " << scores[2] << endl;
First: 80 Third: 70 Last: 100 Third after update: 75

الفهرس يبدأ من الصفر! في مصفوفة من 5 خانات فهارسها هي 0 1 2 3 4، أي أن آخر فهرس صحيح هو size - 1 وليس size. الخانة الأولى هي scores[0].

توقّع قبل أن تشغّل
index_quiz.cpp
int a[5] = {2, 4, 6, 8, 10};
cout << a[1] + a[3] << endl;

ما الذي سيطبعه هذا الكود؟ (تذكّر أن الفهرس يبدأ من 0)

12

الفهرس 1 هو العنصر الثاني (4)، والفهرس 3 هو العنصر الرابع (8). فالناتج 4 + 8 = 12. من يخلط يظن أن a[1] هو العنصر الأول.

مختبر تفاعلي: خزائن المصفوفة

هذه مصفوفة int arr[5]. اكتب فهرسًا ثم اقرأ أو اكتب. جرّب فهارس مثل 5 أو -1 لترى لماذا يحذّر المبرمجون من الخروج عن الحدود:

المصفوفات والحلقات: ثنائي لا يفترق

قوة المصفوفة الحقيقية تظهر مع for: يصبح العدّاد i هو الفهرس، فنمر على كل الخانات بسطرين فقط. تتبّع هذا الكود الذي يجمع عناصر مصفوفة:

تتبّع التنفيذ خطوة بخطوة
1int a[4] = {5, 3, 8, 2};
2int sum = 0;
3for (int i = 0; i < 4; i++) {
4 sum = sum + a[i];
5}
6cout << "Sum: " << sum << endl;
المتغيرات
الناتج حتى الآن

اكتب شرط الحلقة دائمًا i < size وليس i <= size. فالمصفوفة من 4 خانات لا تحتوي على a[4].

إذا أعطيت قيمًا أقل من الحجم

الخانات التي لم تُعطَ قيمة في القائمة الابتدائية تُملأ بالأصفار تلقائيًا:

partial_init.cpp
int a[5] = {1, 2};
for (int i = 0; i < 5; i++) {
    cout << a[i] << " ";
}
cout << endl;
1 2 0 0 0

أما إذا صرّحت عن مصفوفة محلية بلا أي قائمة (int a[5];) فخاناتها تحمل قيمًا عشوائية، تمامًا كالمتغيرات المحلية العادية.

نمط الأعلى والأدنى

من أشهر المسائل: إيجاد أكبر قيمة وأصغرها. الفكرة: نفترض أن العنصر الأول هو الأكبر والأصغر، ثم نمر على الباقي ونحدّث عندما نجد أفضل منه. لدينا حرارة أسبوع كامل:

max_min.cpp
constexpr int DAYS = 7;
int temps[DAYS] = {31, 28, 35, 30, 27, 33, 29};

int hottest = temps[0];
int coldest = temps[0];
for (int i = 1; i < DAYS; i++) {
    if (temps[i] > hottest) {
        hottest = temps[i];
    }
    if (temps[i] < coldest) {
        coldest = temps[i];
    }
}
cout << "Hottest: " << hottest << ", Coldest: " << coldest << endl;
Hottest: 35, Coldest: 27

انتبه إلى أن الحلقة بدأت من i = 1 لأن الفهرس 0 استُخدم كقيمة بداية. واستخدمنا constexpr للحجم DAYS ليسهل تغييره في مكان واحد (تذكّر درس الثوابت).

لماذا لا نبدأ hottest بصفر؟ لأن الحرارة قد تكون سالبة في بلد بارد فنخطئ. البدء بالعنصر الأول يعمل مع أي قيم.

قراءة المصفوفة من المستخدم

نملأ المصفوفة بحلقة تقرأ كل خانة بـ cin >> nums[i]، ونطبعها معكوسة بحلقة تنزل من آخر فهرس إلى الصفر:

read_reverse.cpp
constexpr int N = 5;
int nums[N];

for (int i = 0; i < N; i++) {
    cin >> nums[i];
}
for (int i = N - 1; i >= 0; i--) {
    cout << nums[i] << " ";
}
cout << endl;
10 20 30 40 50
50 40 30 20 10

حجم المصفوفة يجب أن يكون معروفًا وقت الترجمة (عدد مكتوب أو ثابت constexpr). لا تكتب int a[n]; بمتغير n يُقرأ من المستخدم؛ فهذا ليس مسموحًا في المعيار حتى لو قبله بعض المترجمات. وسنتعلم الحل المرن في الدرس التالي (المتجهات).

الخروج عن حدود المصفوفة

هذا من أخطر أخطاء C++. لو كتبت scores[10] لمصفوفة من 5 خانات، فلن يمنعك المترجم ولن يتوقف البرنامج لحظتها، بل ستقرأ أو تكتب في ذاكرة لا تخص المصفوفة. النتيجة: قيم غريبة، أو برنامج ينهار بعد حين، أو بيانات تفسد دون علمك. نسمي هذا سلوكًا غير معرّف (undefined behavior).

أخطاء متكررة
  • حلقة i <= size بدل i < size
  • استخدام a[size] كآخر خانة
  • فهرس سالب ناتج عن حساب خاطئ
عادات تحميك
  • عرّف الحجم في ثابت واحد واستخدمه في كل مكان
  • اجعل شرط الحلقة i < SIZE دائمًا
  • جرّب برنامجك مع أول عنصر وآخر عنصر

المصفوفات مع الدوال

تذكّر أن الدوال تنسخ معاملاتها العادية. أما المصفوفة فلا تُنسخ كاملة؛ تستلم الدالة وصولًا إلى المصفوفة الأصلية نفسها. لذلك تستطيع تعديلها. وبما أن الدالة لا تعرف طولها، يجب أن نمرر الحجم معها دائمًا:

arrays_and_functions.cpp
#include <iostream>
using namespace std;

int sumArray(int arr[], int size) {
    int total = 0;
    for (int i = 0; i < size; i++) {
        total = total + arr[i];
    }
    return total;
}

void doubleAll(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        arr[i] = arr[i] * 2;
    }
}

int main() {
    int data[4] = {1, 2, 3, 4};
    cout << "Sum: " << sumArray(data, 4) << endl;

    doubleAll(data, 4);
    for (int i = 0; i < 4; i++) {
        cout << data[i] << " ";
    }
    cout << endl;
    return 0;
}
Sum: 10 2 4 6 8

الدالة doubleAll غيّرت عناصر data الأصلية (1 2 3 4 صارت 2 4 6 8) دون أي مرجع &، لأن المصفوفة تُمرَّر دائمًا بهذه الطريقة.

كم عنصرًا في المصفوفة؟

في المكان الذي عُرّفت فيه المصفوفة، يمكن حساب عدد عناصرها بقسمة حجمها الكلي على حجم عنصر واحد:

count_elements.cpp
int primes[] = {2, 3, 5, 7, 11, 13};
int count = sizeof(primes) / sizeof(primes[0]);
cout << "Elements: " << count << endl;
Elements: 6

لكن هذه الحيلة لا تصلح داخل دالة استقبلت المصفوفة، فهناك لا تعرف الدالة طولها، ولهذا مررنا size يدويًا.

مصفوفة ثنائية الأبعاد: جدول كامل

أحيانًا تكون البيانات جدولًا: صفوف وأعمدة، كمقاعد قاعة سينما أو رقعة شطرنج. نصنع مصفوفة بقوسين مربعين: الأول للصفوف والثاني للأعمدة، ونمر عليها بحلقتين متداخلتين:

grid.cpp
int seats[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        cout << seats[row][col] << " ";
    }
    cout << endl;
}
cout << "seats[1][2] = " << seats[1][2] << endl;
1 2 3 4 5 6 seats[1][2] = 6

العنصر seats[1][2] هو في الصف الثاني (فهرس 1) والعمود الثالث (فهرس 2)، وقيمته 6. عدد العناصر = الصفوف × الأعمدة = 2 × 3 = 6.

معلومة: النصوص تُفهرَس أيضًا

string_index.cpp
string name = "Sara";
cout << name[0] << name[3] << endl;
name[0] = 'M';
cout << name << endl;
Sa Mara

النص يشبه صفًّا من الحروف، ولذلك يمكنك قراءة حرف منه أو تغييره بالفهرس نفسه.

خطأ: نسخ مصفوفة بالإسناد

لا يمكنك نسخ مصفوفة في مصفوفة أخرى بعلامة =:

copy_error.cpp
#include <iostream>
using namespace std;

int main() {
    int a[3] = {1, 2, 3};
    int b[3];
    b = a;
    cout << b[0] << endl;
    return 0;
}
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:7:7: error: invalid array assignment
    7 |     b = a;
      |     ~~^~~

لنسخ المصفوفة عليك أن تنسخ عناصرها واحدًا واحدًا بحلقة. (وستجد في الدرس القادم أن المتجه vector يتيح النسخ بالإسناد مباشرة.) وكذلك مقارنة مصفوفتين بـ == لا تقارن محتواهما.

مشروع الدرس: محلل علامات الاختبار

برنامج يقرأ خمس علامات ويحلّلها إحصائيًا.

الفكرة

معلّمك يريد برنامجًا بسيطًا يساعده في تحليل علامات اختبار قصير لخمسة طلاب. يكتب العلامات الخمس، فيعرض البرنامج المجموع والمتوسط وأعلى علامة وأدناها، وكم طالبًا تجاوز علامته المتوسط.

المطلوب منك
  1. عرّف ثابتًا N بقيمة 5 ومصفوفة scores بحجم N، واملأها بحلقة تقرأ من cin.
  2. في حلقة واحدة احسب المجموع وأعلى علامة وأدنى علامة.
  3. احسب المتوسط كعدد عشري (تذكّر التحويل قبل القسمة!).
  4. بحلقة ثانية عُدّ العلامات الأكبر من المتوسط.
  5. اطبع الأسطر الخمسة كما في المثال، والمتوسط بخانة عشرية واحدة.
مثال على التشغيل
70 85 90 60 95
Total: 400 Average: 80.0 Highest: 95 Lowest: 60 Above average: 3

تحقق ذهنيًا: المجموع 70 + 85 + 90 + 60 + 95 = 400، فالمتوسط 80. والعلامات الأكبر من 80 هي 85 و90 و95، أي ثلاث علامات.

بعد أن تجرّب بنفسك: اعرض الحل
score_analyzer.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    constexpr int N = 5;
    int scores[N];
    for (int i = 0; i < N; i++) {
        cin >> scores[i];
    }

    int sum = 0;
    int highest = scores[0];
    int lowest = scores[0];
    for (int i = 0; i < N; i++) {
        sum = sum + scores[i];
        if (scores[i] > highest) {
            highest = scores[i];
        }
        if (scores[i] < lowest) {
            lowest = scores[i];
        }
    }
    double average = static_cast<double>(sum) / N;

    int above = 0;
    for (int i = 0; i < N; i++) {
        if (scores[i] > average) {
            above++;
        }
    }

    cout << fixed << setprecision(1);
    cout << "Total: " << sum << endl;
    cout << "Average: " << average << endl;
    cout << "Highest: " << highest << endl;
    cout << "Lowest: " << lowest << endl;
    cout << "Above average: " << above << endl;
    return 0;
}

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

اطبعها بالمقلوب

سهل

اكتب برنامجًا يقرأ ستة أعداد صحيحة من المستخدم ويخزنها في مصفوفة، ثم يطبعها بترتيب معكوس في سطر واحد.

المطلوب
  • عرّف ثابتًا N بقيمة 6 ومصفوفة بحجمه.
  • املأ المصفوفة بحلقة for تقرأ بـ cin.
  • اطبع العناصر بحلقة ثانية تبدأ من آخر فهرس وتنزل إلى الصفر.
مثال على الإدخال والناتج المتوقع
3 1 4 1 5 9
9 5 1 4 1 3
تلميحات
  • آخر فهرس صحيح هو N - 1.
  • حلقة التنازل: for (int i = N - 1; i >= 0; i--).
نموذج الحل (بعد المحاولة)
reverse.cpp
// Challenge 1: reverse
#include <iostream>
using namespace std;

int main() {
    constexpr int N = 6;
    int nums[N];
    for (int i = 0; i < N; i++) {
        cin >> nums[i];
    }
    for (int i = N - 1; i >= 0; i--) {
        cout << nums[i] << " ";
    }
    cout << endl;
    return 0;
}
2

البحث عن رقم

متوسط

لدينا المصفوفة {12, 7, 25, 3, 18}. اقرأ عددًا من المستخدم، وابحث عنه فيها عنصرًا بعنصر. إن وجدته اطبع فهرسه، وإلا اطبع أنه غير موجود.

المطلوب
  • استخدم متغيرًا found يبدأ بالقيمة -1 (أي «لم يُوجد بعد»).
  • مر على المصفوفة بحلقة، وإذا تساوى عنصر مع المطلوب خزّن فهرسه في found وأوقف الحلقة.
  • بعد الحلقة اطبع Found at index N أو Not found بحسب قيمة found.
مثال على الإدخال والناتج المتوقع
25
Found at index 2
تلميحات
  • -1 اختيار ذكي لأنه ليس فهرسًا صحيحًا أبدًا.
  • استخدم break بعد العثور على العنصر لتوفير باقي الدورات.
  • جرّب برنامجك مع قيمة غير موجودة مثل 99 ومع أول عنصر 12 وآخر عنصر 18.
نموذج الحل (بعد المحاولة)
search.cpp
// Challenge 2: linear search
#include <iostream>
using namespace std;

int main() {
    int data[5] = {12, 7, 25, 3, 18};
    int target;
    cin >> target;

    int found = -1;
    for (int i = 0; i < 5; i++) {
        if (data[i] == target) {
            found = i;
            break;
        }
    }

    if (found == -1) {
        cout << "Not found" << endl;
    } else {
        cout << "Found at index " << found << endl;
    }
    return 0;
}

ملخص سريع

  • المصفوفة صف من الخانات من النوع نفسه تحت اسم واحد، ويُوصَل إلى كل خانة بفهرسها.
  • الفهرس يبدأ من 0، وآخر فهرس هو size - 1.
  • عدّاد for هو الفهرس عادةً، وشرط الحلقة الصحيح i < size.
  • الخانات التي لا قيمة لها في القائمة الابتدائية تُملأ بأصفار.
  • الخروج عن حدود المصفوفة سلوك غير معرّف، ولا يمنعه المترجم.
  • تُمرَّر المصفوفة إلى الدالة دون نسخ (فتعدّل الأصل)، ويجب تمرير حجمها معها.
  • المصفوفة الثنائية جدول بصفوف وأعمدة: arr[row][col].

تحقق من فهمك

اقرأ كل عبارة ثم اختر صحيح أو خطأ. سيظهر التفسير مباشرة بعد إجابتك.
