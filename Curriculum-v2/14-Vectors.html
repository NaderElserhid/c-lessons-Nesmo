Vectors — مصفوفة تكبر وتصغر

ماذا ستتعلم في هذا الدرس؟

  • تفهم لماذا نحتاج المتجه بدل المصفوفة ثابتة الحجم
  • تنشئ متجهًا وتستخدم push_back وpop_back وsize وempty
  • تمر على المتجه بحلقة بالفهرس أو بحلقة for المبسّطة وتفرّق بين النسخة والمرجع
  • تستخدم at() للوصول الآمن وتقرأ عددًا غير معروف من القيم
  • تمرر المتجه للدوال وتنسخه وترتّبه بـ sort

المصفوفة ثابتة.. والحياة ليست كذلك

في الدرس الماضي تعلّمنا أن حجم المصفوفة يجب أن يكون معروفًا قبل تشغيل البرنامج. لكن ماذا لو لم نعرف كم عنصرًا سيدخله المستخدم؟ ربما يكتب 3 علامات وربما 300! لو جعلنا المصفوفة صغيرة امتلأت، ولو جعلناها ضخمة أهدرنا الذاكرة.

فكّر بقطار يُضاف إليه عربات كلما زاد الركاب، وتُزال منه العربات الفارغة. هذا هو المتجه (vector): مصفوفة تكبر وتصغر وحدها أثناء تشغيل البرنامج، ويعرف دائمًا كم عنصرًا فيه.

10[0]
20[1]
30[2]
+push_back

كل push_back تضيف عربة جديدة في النهاية.

أول متجه لنا

المتجه يعيش في مكتبة اسمها <vector>، فنضيفها بـ #include. وعند التعريف نكتب بين < > نوع العناصر التي سيخزنها: vector<int> متجه أعداد صحيحة، وvector<string> متجه نصوص.

vector_basics.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> scores;

    scores.push_back(80);
    scores.push_back(95);
    scores.push_back(70);

    cout << "Size: " << scores.size() << endl;
    cout << "First: " << scores[0] << endl;
    cout << "Last: " << scores[2] << endl;
    return 0;
}
Size: 3 First: 80 Last: 70

المتجه بدأ فارغًا، ثم أضفنا ثلاث علامات بـ push_back. والأمر size() يعطينا عدد العناصر الحالي. وللوصول إلى عنصر نستخدم الفهرس [ ] تمامًا كالمصفوفة، وما زال الفهرس يبدأ من 0.

مختبر تفاعلي: قطار المتجه

جرّب بنفسك: أضف عناصر وأزلها وراقب كيف يتغير الحجم. ثم جرّب at(i) بفهرس غير موجود.

صندوق أدوات المتجه

الأمرماذا يفعل؟

v.pop_back()يحذف آخر عنصر

methods.cpp
vector<string> team = {"Sara", "Omar", "Lina"};

cout << "front: " << team.front() << endl;
cout << "back:  " << team.back() << endl;
cout << "empty? " << team.empty() << endl;

team.pop_back();
team.push_back("Yazan");
cout << "size:  " << team.size() << endl;
cout << "last now: " << team.back() << endl;

لاحظ أن empty() طبعت 1 للصحيح و0 للخطأ، لأن cout يطبع القيمة المنطقية رقمًا.

لا تستدعِ back() أو pop_back() على متجه فارغ؛ فلا يوجد عنصر أخير أصلًا، والنتيجة سلوك غير معرّف. افحص empty() أولًا إن لم تكن متأكدًا.

المرور على المتجه

هناك طريقتان: حلقة for بالفهرس، أو حلقة for المبسّطة التي تمر على كل عنصر مباشرة (قرأنا عنها في درس الحلقة):

vector_loops.cpp
vector<int> v = {4, 8, 15};

for (size_t i = 0; i < v.size(); i++) {
    cout << "v[" << i << "] = " << v[i] << endl;
}

int total = 0;
for (int x : v) {
    total = total + x;
}
cout << "total = " << total << endl;
v[0] = 4 v[1] = 8 v[2] = 15 total = 27

الأمر size() يعيد نوعًا لا يقبل قيمًا سالبة (يسمى size_t)، ولذلك جعلنا i من النوع نفسه لنتجنب تحذير المترجم. وإن كنت لا تحتاج الفهرس فالحلقة المبسّطة أسهل وأكثر أمانًا.

فخ مشهور: إذا كان المتجه فارغًا فإن v.size() - 1 لا تعطي -1 بل رقمًا ضخمًا جدًا (لأن النوع لا يعرف السالب). احذر من كتابة شروط تعتمد على طرح 1 من الحجم دون فحص empty().

هل نعدّل العناصر أثناء الحلقة؟

في for (int x : v) تأخذ الحلقة نسخة من كل عنصر. جرّب أن تتوقع الناتج:

توقّع قبل أن تشغّل
copy_loop_quiz.cpp
vector<int> v = {1, 2, 3};
for (int x : v) {
    x = x * 10;
}
cout << v[0] << " " << v[1] << " " << v[2] << endl;

ما الذي سيطبعه هذا الكود؟ (انتبه لشكل المتغير x في الحلقة)

1 2 3

كتبنا int x بدون &، فالحلقة تعمل على نسخة من كل عنصر، وتعديل النسخة لا يغيّر المتجه. لتعديل الأصل نكتب int& x.

ولتعديل العناصر الأصلية نضع & بعد النوع، فنعمل على العنصر نفسه لا على نسخته (تذكّر المرجع من درس الدوال):

ref_loop.cpp
vector<int> v = {1, 2, 3};
for (int& x : v) {
    x = x * 10;
}
cout << v[0] << " " << v[1] << " " << v[2] << endl;
10 20 30

الأمان: at() بدل []

مثل المصفوفة، لا يفحص v[i] الحدود؛ فالفهرس الخاطئ سلوك غير معرّف. أما v.at(i) فيفحص، وإذا كان الفهرس خارج الحدود يعلن خطأً واضحًا بدل أن يفسد الذاكرة بصمت. هذا الخطأ يسمى استثناءً (exception) ويمكننا التقاطه بـ try وcatch:

at_safe.cpp
vector<int> v = {5, 6, 7};

try {
    cout << v.at(10) << endl;
} catch (const out_of_range&) {
    cout << "Index 10 is out of range" << endl;
}
cout << "The program is still alive" << endl;
Index 10 is out of range The program is still alive

فكّر في try وcatch كشبكة أمان لبهلوان: نجرّب الحركة الخطرة داخل try، فإن سقط الكود (حدث خطأ) تلتقطه catch ويتابع البرنامج بدل أن ينهار. لا تحتاج حفظ التفاصيل الآن؛ يكفي أن تعرف أن at() أكثر أمانًا من [].

بدون catch سيتوقف البرنامج برسالة خطأ عند فهرس خاطئ. فاستخدم [] حين تتأكد أن الفهرس صحيح، وat() حين تريد حماية إضافية أثناء التعلم والاختبار.

قراءة عدد غير معروف من القيم

هنا تتألق المتجهات: لا نعرف كم رقمًا سيكتب المستخدم، فنقرأ حتى يكتب القيمة الحارسة -1 (تذكّر حلقة الحارس في درس while) ونضيف كل رقم إلى المتجه:

read_unknown.cpp
vector<int> v;
int x;
while (cin >> x && x != -1) {
    v.push_back(x);
}
cout << "Read " << v.size() << " numbers" << endl;
cout << "Last one: " << v.back() << endl;

Read 4 numbers Last one: 90

مع المصفوفة كنا سنضطر لتخمين حجم كبير. أما هنا فالمتجه يكبر بقدر ما نحتاج بالضبط.

المتجهات مع الدوال

على عكس المصفوفة، المتجه يُنسخ كاملًا إذا مررناه بالقيمة العادية. وهذا بطيء للمتجهات الكبيرة ولا يسمح بتعديل الأصل. لذلك نمرره عادة بمرجع &:

  • للقراءة فقط: const vector<int>& v (بلا نسخ، وبلا تعديل).
  • للتعديل: vector<int>& v.
vector_functions.cpp
#include <iostream>
#include <vector>
using namespace std;

void printAll(const vector<int>& v) {
    for (int x : v) {
        cout << x << " ";
    }
    cout << endl;
}

void addBonus(vector<int>& v, int bonus) {
    for (int& x : v) {
        x = x + bonus;
    }
}

int main() {
    vector<int> points = {10, 20, 30};
    printAll(points);
    addBonus(points, 5);
    printAll(points);
    return 0;
}
10 20 30 15 25 35

لا حاجة لتمرير الحجم هنا، فالدالة تسأل المتجه نفسه بـ v.size(). هذه ميزة كبيرة على المصفوفة.

نسخ المتجه ومقارنته

ما لا تفعله المصفوفة يفعله المتجه: يمكن نسخه بـ = فينتج متجه مستقل تمامًا، ويمكن مقارنة محتوى متجهين بـ ==:

vector_copy.cpp
vector<int> a = {1, 2, 3};
vector<int> b = a;
b.push_back(4);

cout << a.size() << " " << b.size() << endl;
cout << (a == b ? "same" : "different") << endl;
b.pop_back();
cout << (a == b ? "same" : "different") << endl;
3 4 different same

تعديل b لم يغيّر a، لأنها نسخة كاملة.

ترتيب المتجه وعكسه

المكتبة <algorithm> تقدّم أدوات جاهزة. sort ترتّب تصاعديًا، وreverse تعكس الترتيب. نعطيها بداية المتجه ونهايته: v.begin() وv.end():

sort_reverse.cpp
vector<int> v = {40, 10, 30, 20};

sort(v.begin(), v.end());
for (int x : v) {
    cout << x << " ";
}
cout << endl;

reverse(v.begin(), v.end());
for (int x : v) {
    cout << x << " ";
}
cout << endl;
10 20 30 40 40 30 20 10

الفكرة

أقمتم مسابقة ألعاب في المدرسة، ولا تعرفون كم لاعبًا سيشارك. أنت مسؤول عن لوحة النتائج: تُدخل نقاط اللاعبين واحدًا واحدًا، وتكتب -1 عند الانتهاء، فيعلن البرنامج عدد المشاركين ومتوسط النقاط وأعلى ثلاث نتائج.

المطلوب منك
  1. اقرأ النقاط في حلقة وخزّنها في vector<int> حتى القيمة -1 (دون تخزينها).
  2. إذا كان المتجه فارغًا اطبع No scores entered وأنهِ البرنامج.
  3. احسب المتوسط كعدد عشري (تذكّر static_cast).
  4. رتّب المتجه بـ sort.
  5. اطبع عدد المشاركين والمتوسط وأعلى ثلاث نتائج (الأكبر أولًا). إن كان العدد أقل من 3 فاطبع ما يوجد.
مثالان على التشغيل

التشغيل الأول:

50 80 65 90 70 -1
Scores entered: 5 Average: 71 Top 3: 90 80 70

التشغيل الثاني (لم يشارك أحد):

-1
No scores entered

تحقق ذهنيًا: 50 + 80 + 65 + 90 + 70 = 355، ومتوسطها 71. وبعد الترتيب تصبح 50 65 70 80 90، فآخر ثلاثة هم 90 و80 و70.

بعد أن تجرّب بنفسك: اعرض الحل
score_board.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> scores;
    int x;
    while (cin >> x && x != -1) {
        scores.push_back(x);
    }

    if (scores.empty()) {
        cout << "No scores entered" << endl;
        return 0;
    }

    int sum = 0;
    for (int s : scores) {
        sum = sum + s;
    }
    double average = static_cast<double>(sum) / scores.size();

    sort(scores.begin(), scores.end());

    cout << "Scores entered: " << scores.size() << endl;
    cout << "Average: " << average << endl;
    cout << "Top 3:";
    for (size_t k = 0; k < scores.size() && k < 3; k++) {
        cout << " " << scores[scores.size() - 1 - k];
    }
    cout << endl;
    return 0;
}

العدّ والعكس

سهل

اقرأ أعدادًا من المستخدم حتى يكتب 0، وخزّنها في متجه. ثم اطبع عددها وبعدها اطبعها بترتيب معكوس.

المطلوب
  • استخدم vector<int> وحلقة while (cin >> x && x != 0).
  • اطبع Count: متبوعة بعدد العناصر.
  • اطبع Reversed: ثم العناصر من الأخير إلى الأول، يسبق كل عنصر مسافة.
مثال على الإدخال والناتج المتوقع
4 8 15 16 0
Count: 4 Reversed: 16 15 8 4
تلميحات
  • لا تضف الصفر الحارس إلى المتجه.
  • للمرور العكسي استخدم فهرسًا من نوع int، وابدأ من static_cast<int>(v.size()) - 1.
نموذج الحل (بعد المحاولة)
count_reverse.cpp
// Challenge 1: count and reverse
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    int x;
    while (cin >> x && x != 0) {
        v.push_back(x);
    }

    cout << "Count: " << v.size() << endl;
    cout << "Reversed:";
    for (int i = static_cast<int>(v.size()) - 1; i >= 0; i--) {
        cout << " " << v[i];
    }
    cout << endl;
    return 0;
}

أطول كلمة

متوسط

اقرأ أربع كلمات وخزّنها في vector<string>، ثم اطبع أطولها.

المطلوب
  • اقرأ كل كلمة بـ cin >> w ثم أضفها بـ push_back.
  • احتفظ بمتغير longest يبدأ بالكلمة الأولى.
  • مر على الكلمات وحدّث longest كلما وجدت كلمة أطول (استخدم .size() للنص).
  • اطبع Longest: ثم الكلمة.
مثال على الإدخال والناتج المتوقع
sun galaxy moon star
Longest: galaxy
تلميحات
  • طول النص نحصل عليه بـ s.size() (تذكّر أن النص يعمل كصف حروف).
  • هذا هو نمط «الأكبر» نفسه الذي تعلمناه في المصفوفات، لكن بمقارنة الأطوال.
نموذج الحل (بعد المحاولة)
longest_word.cpp
// Challenge 2: longest word
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    vector<string> words;
    string w;
    for (int i = 0; i < 4; i++) {
        cin >> w;
        words.push_back(w);
    }

    string longest = words[0];
    for (string s : words) {
        if (s.size() > longest.size()) {
            longest = s;
        }
    }
    cout << "Longest: " << longest << endl;
    return 0;
}

ملخص سريع

  • المتجه vector مصفوفة تكبر وتصغر تلقائيًا، ويحتاج #include <vector>.
  • نحدد نوع عناصره عند التعريف: vector<int> أو vector<string>.
  • push_back تضيف في النهاية وpop_back تحذف الأخير، وsize() تعطي العدد.
  • نصل للعنصر بـ v[i] (بلا فحص) أو v.at(i) (مع فحص يعلن خطأً عند الخروج عن الحدود).
  • في حلقة for (int x : v) نعمل على نسخة، ولتعديل الأصل نكتب int& x.
  • نمرر المتجه إلى الدوال بمرجع: const & للقراءة و& للتعديل.
  • المتجه يُنسخ بـ = ويُقارن بـ ==، ويمكن ترتيبه بـ sort.
