المتغيرات والأنواع

Variables and Types — كيف يتذكر البرنامج بياناته

ماذا ستتعلم في هذا الدرس؟

  • تفهم ما هو المتغير، وتفرّق بين التصريح والتهيئة والإسناد
  • تختار النوع المناسب لكل بيان: int وlong long وdouble وchar وbool وstring
  • تعرف حدود الأعداد الصحيحة ومتى يجب استخدام long long
  • تفهم لماذا تكون الأعداد العشرية تقريبية وما الفرق بين float وdouble
  • تتعامل بصواب مع القسمة الصحيحة والتحويل بين الأنواع
  • تسمّي المتغيرات بأسماء صحيحة ومقروءة

المتغير: صندوق له اسم ونوع

كل برنامج يحتاج أن «يتذكر» معلومات أثناء عمله: درجة الحرارة التي قُرئت، اسم اللاعب، عدد المحاولات المتبقية. الوسيلة لذلك هي المتغير (variable): خانة محجوزة في ذاكرة الحاسوب، لها ثلاث خصائص:

اسم

نختاره نحن، ونستعمله للوصول إلى الخانة.

نوع

يحدد ما يمكن تخزينه (عدد صحيح؟ نص؟ كسر؟) وكم من الذاكرة تُحجز.

قيمة

المحتوى الحالي للخانة، ويمكن تغييره أثناء تشغيل البرنامج.

انظر إلى هذا المثال الذي يخزّن معلومات عن كوكب المريخ بأربعة أنواع مختلفة:

planet.cpp
#include <iostream>#include <string>using namespace std; int main() {    int moons = 2;    double gravity = 3.71;    char symbol = 'M';    string planet = "Mars";     cout << planet << " has " << moons << " moons." << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...

اضغط على الأسطر المضيئة:

Mars has 2 moons.

الصيغة العامة للتصريح مع التهيئة هي: type name = value;. نكتب النوع أولًا، ثم الاسم، ثم علامة =، ثم القيمة الأولى، وتنتهي التعليمة بفاصلة منقوطة.

التصريح والتهيئة والإسناد

المصطلحمثالالمعنى
تصريح (declaration)int fuel;إنشاء المتغير بنوعه واسمه
تهيئة (initialization)int fuel = 100;إنشاء المتغير مع قيمته الأولى
إسناد (assignment)fuel = 75;وضع قيمة جديدة في متغير موجود

العلامة = في البرمجة ليست «يساوي» بالمعنى الرياضي، بل أمر: «احسب ما على اليمين ثم ضعه في المتغير على اليسار». لهذا يصح السطر fuel = fuel - 20; رغم أنه مستحيل رياضيًا:

reassign.cpp
int fuel = 100;
cout << fuel << endl;
fuel = 75;
cout << fuel << endl;
fuel = fuel - 20;
cout << fuel << endl;
100 75 55

احذر المتغيرات غير المهيّأة: إذا صرّحت عن متغير محلي دون قيمة (int x;) ثم قرأته، فستحصل على قيمة عشوائية غير متوقعة. اعتد أن تعطي كل متغير قيمة أولى عند إنشائه.

الأنواع الأساسية

النوعيخزّنأمثلةالحجم النموذجي
intعددًا صحيحًا0, 42, -174 بايت
long longعددًا صحيحًا كبيرًا50000000008 بايت
doubleعددًا عشريًا بدقة عالية0.75, -2.58 بايت
floatعددًا عشريًا بدقة أقل0.75f4 بايت
charحرفًا واحدًا'q', '7', '#'1 بايت
boolصح أو خطأtrue, false1 بايت
stringنصًا"Riyadh"يتغير بطول النص

الأحجام في الجدول هي القيم المعتادة على الحواسيب الحديثة، لكن المعيار لا يفرضها حرفيًا. لذلك نقيسها بالأداة sizeof بدل أن نفترضها:

sizes.cpp
cout << "int:       " << sizeof(int) << endl;
cout << "long long: " << sizeof(long long) << endl;
cout << "float:     " << sizeof(float) << endl;
cout << "double:    " << sizeof(double) << endl;
cout << "bool:      " << sizeof(bool) << endl;
cout << "char:      " << sizeof(char) << endl;
int: 4 long long: 8 float: 4 double: 8 bool: 1 char: 1

الصورة الذهنية المفيدة: كلما زاد حجم النوع اتسع لقيم أكبر أو لدقة أعلى، لكنه يستهلك ذاكرة أكثر.

حدود الأعداد الصحيحة: متى نستخدم long long؟

خانة int ذات 4 بايت تتسع لقيم تقارب من -2.1 مليار إلى +2.1 مليار (الحد الأعلى المعتاد 2147483647). أما long long فتتسع إلى نحو 9.2 كوينتيليون (9223372036854775807). إذا كان حاصل عمليتك قد يتجاوز المليارين فاستخدم long long من البداية:

bigint.cpp
long long speed = 299792458;          // light speed in meters per second
long long perHour = speed * 3600;     // meters light travels in one hour
cout << perHour << endl;
1079252848800

الناتج أكبر من تريليون، وهو يفوق حد int بمئات المرات.

الفيضان (overflow): عندما يتجاوز ناتج عملية على int الحد المسموح به، لا يتوقف البرنامج ولا يعرض تنبيهًا، بل تصبح النتيجة غير موثوقة. وفي التسابق البرمجي يكون هذا أحد أشهر أسباب الإجابات الخاطئة، فاقرأ حدود المسألة أولًا ثم اختر النوع.

الأعداد العشرية والدقة

يخزّن الحاسوب الأعداد العشرية بصيغة ثنائية تقريبية، ولذلك فكثير من الكسور لا تُمثَّل بدقة كاملة. الفرق بين float وdouble هو عدد الخانات الموثوقة:

النوعالدقة التقريبية
floatنحو 6 إلى 7 أرقام معنوية
doubleنحو 15 إلى 16 رقمًا معنويًا

لنكشف الأرقام المخفية بطباعة عدد كبير من الخانات باستخدام setprecision من الترويسة <iomanip>:

precision.cpp
cout << setprecision(17);
cout << 0.1 + 0.2 << endl;

float pf = 3.14159265358979;
double pd = 3.14159265358979;
cout << setprecision(15);
cout << pf << endl;
cout << pd << endl;
0.30000000000000004 3.14159274101257 3.14159265358979

الملاحظتان: حاصل 0.1 + 0.2 ليس 0.3 تمامًا، ونفس العدد 3.14159265358979 يخرج من float مشوّهًا بعد الرقم السابع تقريبًا، بينما يحتفظ به double كاملًا.

القاعدة العملية: استخدم double افتراضيًا للأعداد العشرية، ولا تعتمد على المقارنة بـ == بين عددين عشريين ناتجين عن عمليات حسابية.

الحروف: char وأرقامها السرية

الحاسوب لا يعرف الحروف، بل يخزّن لكل حرف رقمًا (ضمن جدول ASCII). لذلك يمكن التعامل مع char كحرف أو كرقم صغير حسب ما نطلب:

chars.cpp
char letter = 'A';
cout << letter << endl;
cout << static_cast<int>(letter) << endl;
cout << char(letter + 2) << endl;
A 65 C

الحرف 'A' رمزه 65، وبإضافة 2 نصل إلى الحرف الثالث في الأبجدية 'C'. ولاحظ الفرق المهم:

صحيح
char grade = 'B';
string city = "Jeddah";
خطأ
char grade = "B";
string city = 'Jeddah';

علامة التنصيص المفردة لحرف واحد، والمزدوجة لنص كامل.

القسمة بين الأعداد الصحيحة والعشرية

الأمر المربك الأول لكل مبتدئ: ناتج قسمة عددين صحيحين عدد صحيح دائمًا، فيُحذف الكسر. ولحساب الباقي نستخدم العامل %:

division.cpp
cout << 17 / 5 << endl;
cout << 17 % 5 << endl;
cout << 17 / 5.0 << endl;
3 2 3.4

يكفي أن يكون أحد الطرفين عشريًا (5.0) حتى يصبح الناتج عشريًا. وعندما يكون الطرفان متغيرين صحيحين نحوّل أحدهما صراحةً قبل القسمة:

cast.cpp
int total = 17;
int people = 5;
double average = static_cast<double>(total) / people;
cout << average << endl;
3.4

التعبير static_cast<double>(total) يُنشئ نسخة عشرية مؤقتة من total، دون أن يغيّر المتغير نفسه.

وماذا عن وضع عدد عشري في متغير صحيح؟

truncate.cpp
int whole = 3.9;
cout << whole << endl;
3

يُحذف الجزء الكسري ولا يُقرَّب. فالعدد 3.9 أصبح 3، وهذا يسمى البتر (truncation).

النوع bool: قرارات صح وخطأ

المتغير المنطقي يحمل قيمة واحدة من اثنتين: true أو false، وغالبًا نحصل عليه من مقارنة. وعند الطباعة تظهر 1 و0، إلا إذا استخدمنا boolalpha:

bools.cpp
int altitude = 1200;
bool aboveClouds = altitude > 2000;
bool inRange = altitude >= 500;
cout << aboveClouds << " " << inRange << endl;
cout << boolalpha << inRange << endl;
0 1 true

سنستخدم هذا النوع كثيرًا مع الجمل الشرطية والحلقات في الدروس القادمة.

تسمية المتغيرات

الاسم الجيد يشرح الغرض: batteryLevel أوضح من x. أما القواعد الإلزامية فهي:

يُسمح
  • حروف إنجليزية وأرقام وشرطة سفلية _
  • البدء بحرف أو بشرطة سفلية
  • الحروف الكبيرة والصغيرة معًا
يُمنع
  • البدء برقم مثل 2ndPlace
  • المسافات مثل best time
  • الرموز مثل speed-max أو cost$
  • الكلمات المحجوزة مثل double أو return

وحالة الأحرف مهمة: BestTime وbestTime متغيران مختلفان تمامًا. أما الأسماء التالية فكلها صحيحة (ترجمنا الملف للتأكد):

names.cpp
int lap2 = 1;
int _temp = 2;
int best_time = 3;
int bestTime = 4;
int BestTime = 5;
النمطالشكلملاحظة
snake_casebest_timeكلمات صغيرة تفصل بينها شرطة سفلية
camelCasebestTimeالكلمة الأولى صغيرة وكل كلمة بعدها تبدأ بحرف كبير

اختر نمطًا واحدًا والتزم به في المشروع كله. فالاتساق أهم من النمط نفسه.

اختياري: auto

بدل أن نكتب النوع، نترك المترجم يستنتجه من القيمة الأولى. يفيد في الأنواع الطويلة لاحقًا، أما الآن فالأفضل أن تكتب النوع صراحةً لتتدرب عليه:

auto.cpp
auto a = 7;        // int
auto b = 2.5;      // double
auto c = 'x';      // char
auto d = true;     // bool
cout << a << " " << b << " " << c << " " << d << endl;
7 2.5 x 1

لا بد من قيمة أولية عند استخدام auto، لأن المترجم يعتمد عليها في الاستنتاج.

مختبر تفاعلي: أي نوع أختار؟

اكتب قيمة كما تكتبها في الكود (مثل 42 أو 3.5 أو 'k' أو "Hello" أو true أو 5000000000)، وسيقترح المحاكي النوع المناسب.

مشروع الدرس: بطاقة حالة الروبوت

نجمع الأنواع الخمسة في برنامج واحد يعرض بطاقة منسقة.

الفكرة

فريق يشغّل روبوت استكشاف عن بُعد، ويريد شاشة صغيرة تعرض حالته بوضوح كلما تغيّرت بياناته. بيانات الروبوت متنوعة: اسمه نص، وبطاريته عدد صحيح، وسرعته عدد عشري، ووضع تشغيله حرف واحد، واتصاله بالشبكة قيمة صح أو خطأ.

المطلوب منك
  1. أنشئ خمسة متغيرات بالأنواع المناسبة، وأعطِ كلًا منها قيمة أولية: الاسم Rover-7، البطارية 82، السرعة 1.5، الوضع E، متصل true.
  2. اطبع عنوان البطاقة ثم خمسة أسطر، سطر لكل متغير، مع كلمة وصفية قبل كل قيمة.
  3. اطبع علامة % بعد البطارية، والوحدة m/s بعد السرعة.
  4. اجعل القيمة المنطقية تظهر كلمة true أو false لا رقمًا (تذكّر boolalpha).
الشكل المطلوب للناتج
=== Rover Status Card === Name: Rover-7 Battery: 82% Speed: 1.5 m/s Mode: E Online: true

قبل أن تكتب: اسأل نفسك عن كل قيمة: هل هي نص؟ حرف واحد؟ عدد صحيح؟ عدد بكسر؟ صح أو خطأ؟ اختيار النوع الصحيح هو نصف الحل.

بعد أن تجرّب بنفسك: اعرض الحل
rover.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Rover-7";
    int battery = 82;
    double speed = 1.5;
    char mode = 'E';
    bool online = true;

    cout << "=== Rover Status Card ===" << endl;
    cout << "Name:    " << name << endl;
    cout << "Battery: " << battery << "%" << endl;
    cout << "Speed:   " << speed << " m/s" << endl;
    cout << "Mode:    " << mode << endl;
    cout << "Online:  " << boolalpha << online << endl;
    return 0;
}

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

متوسط سرعة الرحلة

سهل

قطعت سيارة مسافة 450 كيلومترًا في 4 ساعات. المسافة والساعات عددان صحيحان، لكن المتوسط قد يحتوي كسرًا. احسب المتوسط واطبعه.

المطلوب
  • عرّف متغيرين صحيحين: distance بقيمة 450 وhours بقيمة 4.
  • عرّف متغيرًا عشريًا speed يحمل ناتج قسمة المسافة على الساعات.
  • اطبع الجملة كما في الناتج المتوقع.
  • تحقق أن ناتجك 112.5 وليس 112.
الناتج المتوقع
Average speed: 112.5 km/h
تلميحات
  • قسمة عددين صحيحين تحذف الكسر، فحوّل أحدهما إلى double قبل القسمة.
  • استخدم static_cast<double>(distance).
نموذج الحل (بعد المحاولة)
speed.cpp
// Challenge 1: average speed
#include <iostream>
using namespace std;

int main() {
    int distance = 450;
    int hours = 4;
    double speed = static_cast<double>(distance) / hours;
    cout << "Average speed: " << speed << " km/h" << endl;
    return 0;
}
2

فاتورة المتجر

متوسط

اشترى عميل 3 قطع من منتج سعر الواحدة 24.5 ريالًا. يمنح المتجر الشحن المجاني إذا بلغ المجموع 70 ريالًا فأكثر.

المطلوب
  • عرّف price من النوع المناسب لسعر عشري، وquantity للكمية.
  • احسب المجموع في متغير total.
  • عرّف متغيرًا منطقيًا freeShipping يحمل نتيجة مقارنة المجموع بالعدد 70.
  • اطبع المجموع وحالة الشحن المجاني بصيغة true أو false.
الناتج المتوقع
Total: 73.5 SAR Free shipping: true
تلميحات
  • نتيجة المقارنة total >= 70 قيمة من النوع bool.
  • اكتب boolalpha قبل طباعة القيمة المنطقية.
نموذج الحل (بعد المحاولة)
shop.cpp
// Challenge 2: shop total
#include <iostream>
using namespace std;

int main() {
    double price = 24.5;
    int quantity = 3;
    double total = price * quantity;
    bool freeShipping = total >= 70;
    cout << "Total: " << total << " SAR" << endl;
    cout << "Free shipping: " << boolalpha << freeShipping << endl;
    return 0;
}

ملخص سريع

  • المتغير صندوق له اسم ونوع يحفظ قيمة قابلة للتغيير.
  • الأنواع الأساسية: int وlong long للصحيح، وdouble للعشري، وchar للحرف، وbool لصح/خطأ، وstring للنص.
  • التصريح هو إنشاء المتغير، والتهيئة هي أول قيمة، والإسناد هو تغيير القيمة لاحقًا.
  • الأعداد الصحيحة لها حدود، فاستخدم long long للقيم الكبيرة.
  • قسمة عددين صحيحين تعطي عددًا صحيحًا؛ حوّل أحدهما إلى double إن أردت الكسر.
  • اختر أسماء واضحة تصف القيمة المخزنة.

تحقق من فهمك

اقرأ كل عبارة ثم اختر صحيح أو خطأ. سيظهر التفسير مباشرة بعد إجابتك.
