Operators — كيف نحسب ونقارن ونقرر

ماذا ستتعلم في هذا الدرس؟

  • تتوقع ترتيب تنفيذ العوامل وتستعمل الأقواس لتوضيحه

ما هو العامل؟

العامل (operator) رمز يطلب من الحاسوب تنفيذ عملية، والقيم التي تُجرى عليها العملية تسمى المعاملات (operands). في التعبير 7 + 2 العامل هو + والمعاملان هما 7 و2. تنقسم العوامل التي سنتعلمها اليوم إلى خمس مجموعات:

المجموعةالعواملتعطينا
حسابية+ - * / %عددًا
إسناد= += -= *= /= %=تخزين قيمة في متغير
زيادة ونقصان++ --تغيير القيمة بمقدار واحد
مقارنة== != < > <= >=قيمة bool
منطقية&& || !قيمة bool

العوامل الحسابية

لنجرب العوامل الخمسة على a = 29 وb = 6:

arithmetic.cpp
int a = 29;int b = 6;cout << "a + b = " << a + b << endl;cout << "a - b = " << a - b << endl;cout << "a * b = " << a * b << endl;cout << "a / b = " << a / b << endl;cout << "a % b = " << a % b << endl;cout << "a / b (real) = " << static_cast<double>(a) / b << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...

اضغط على الأسطر المضيئة لقراءة شرحها:

a + b = 35 a - b = 23 a * b = 174 a / b = 4 a % b = 5 a / b (real) = 4.83333

تذكّر: ناتج قسمة عددين صحيحين عدد صحيح. وإذا قسمت على صفر فإن البرنامج يتعطل أو ينتج نتيجة غير معرّفة، فتأكد أن المقسوم عليه ليس صفرًا قبل القسمة.

الباقي مع الأعداد السالبة

الناتج الصحيح من القسمة يُقرَّب نحو الصفر، والباقي يأخذ إشارة المقسوم:

negative.cpp
cout << -7 / 2 << " " << -7 % 2 << endl;
cout << 7 / -2 << " " << 7 % -2 << endl;
-3 -1 -3 1

في كل سطر العدد الأول هو ناتج القسمة والثاني هو الباقي. تحقق أن -7 = (-3) × 2 + (-1).

الإسناد والإسناد المركّب

العامل = يخزّن القيمة الموجودة على يمينه في المتغير الذي على يساره. وللاختصار توجد صيغ مركّبة: بدل كتابة x = x + 5 نكتب x += 5:

compound.cpp
int x = 20;
x += 5;
cout << "after += 5  : " << x << endl;
x -= 3;
cout << "after -= 3  : " << x << endl;
x *= 2;
cout << "after *= 2  : " << x << endl;
x /= 4;
cout << "after /= 4  : " << x << endl;
x %= 5;
cout << "after %= 5  : " << x << endl;
after += 5 : 25 after -= 3 : 22 after *= 2 : 44 after /= 4 : 11 after %= 5 : 1

تابع القيم: 20، ثم 20+5=25، ثم 25-3=22، ثم 22×2=44، ثم 44÷4=11، ثم 11 % 5 = 1.

الزيادة والنقصان: ++ و--

العامل ++ يزيد المتغير بمقدار واحد، والعامل -- ينقصه بمقدار واحد. لكل منهما صيغتان تختلفان في وقت تغيير القيمة:

الصيغةالاسمماذا يحدث؟
++aبادئة (prefix)تزيد القيمة أولًا ثم تُستخدم
a++لاحقة (postfix)تُستخدم القيمة الحالية أولًا ثم تزيد
increment.cpp
int a = 5;
int b = a++;
int c = ++a;
cout << "a=" << a << " b=" << b << " c=" << c << endl;
a=7 b=5 c=7

تتبّع السطر: a تبدأ 5. في b = a++ تُنسخ القيمة 5 إلى b ثم تصير a تساوي 6. وفي c = ++a تصير a تساوي 7 أولًا ثم تُنسخ إلى c.

إذا استخدمت ++ في سطر مستقل مثل count++; فلا فرق بين الصيغتين. وتجنّب استخدام المتغير نفسه مرتين في تعبير واحد مع ++ مثل a + a++، لأن نتيجته غير مضمونة في C++.

عوامل المقارنة

تقارن عددين وتعطي true أو false:

comparison.cpp
int age = 17;
cout << boolalpha;
cout << (age == 17) << endl;
cout << (age != 17) << endl;
cout << (age >= 18) << endl;
cout << (age < 18) << endl;
true false false true

أشهر خطأ للمبتدئين: الخلط بين = (إسناد) و== (مقارنة). انظر ماذا يحدث:

eq_vs_assign.cpp
int x = 3;
cout << (x == 5) << endl;
cout << (x = 5) << endl;
cout << x << endl;
0 5 5

السطر الأول سأل «هل x تساوي 5؟» فجاء الجواب 0 (خطأ). أما السطر الثاني (x = 5) فقد غيّر قيمة x إلى 5 وأعطانا القيمة المسندة، ولذلك طُبع 5 وبقيت x تساوي 5 بعده.

العوامل المنطقية

تجمع بين شروط bool لتكوّن شرطًا مركّبًا:

العاملالاسميكون true عندما...
&&و (AND)يكون الشرطان معًا true
||أو (OR)يكون أحد الشرطين على الأقل true
!نفي (NOT)يكون الشرط false (يعكس القيمة)
logic.cpp
int age = 20;
bool hasTicket = true;
bool canEnter = age >= 18 && hasTicket;
bool needsHelp = age < 12 || age > 70;
cout << boolalpha;
cout << canEnter << endl;
cout << needsHelp << endl;
cout << !canEnter << endl;
true false false

التقييم المختصر (short-circuit)

عند استخدام &&، إذا كان الشرط الأول false فلن يقيّم C++ الشرط الثاني أبدًا لأن النتيجة صارت معروفة. وكذلك || إذا كان الأول true. وهذا مفيد لحمايتك من أخطاء مثل القسمة على صفر:

short_circuit.cpp
int d = 0;
bool ok = (d != 0) && (10 / d > 1);
cout << boolalpha << ok << endl;
false

لم يعطنا القسمة على صفر خطأً لأن d != 0 كانت false فلم يُقيَّم ما بعدها.

الأولوية: من يُنفَّذ أولًا؟

مثلما يسبق الضرب الجمع في الرياضيات، لكل عامل في C++ أولوية (precedence). وعند تساوي الأولوية يكون التنفيذ عادةً من اليسار إلى اليمين. هذا ترتيب مبسّط من الأعلى إلى الأدنى:

المستوىالعوامل
1 (الأعلى)++ -- (اللاحقة) ثم ! و++ -- (البادئة)
2* / %
3+ -
4< <= > >=
5== !=
6&&
7||
8 (الأدنى)= += -= *= /= %=
precedence.cpp
cout << 2 + 3 * 4 << endl;
cout << (2 + 3) * 4 << endl;
cout << 10 - 4 - 3 << endl;
cout << 100 / 10 * 5 << endl;
cout << boolalpha << (1 + 2 > 2 && 5 % 2 == 1) << endl;
14 20 3 50 true

راجع الأسطر: الضرب قبل الجمع فالناتج 14، والأقواس تغيّر الترتيب فتصير 20، و10 - 4 - 3 تُنفَّذ من اليسار فتساوي 3، و100 / 10 * 5 تساوي 50. وفي السطر الأخير تُحسب العمليات الحسابية، ثم المقارنات، وأخيرًا &&.

لا تعتمد على حفظ الجدول. عندما يكون التعبير معقدًا فضع أقواسًا ليتضح قصدك للقارئ، فهي لا تكلّف شيئًا.

مختبر تفاعلي: جرّب العوامل

أدخل عددين صحيحين a وb وشاهد نتيجة كل عامل كما يحسبها C++. جرّب قيمًا سالبة، وجرّب b = 0:

مشروع الدرس: صرّاف آلي (ATM)

نستخدم القسمة الصحيحة والباقي لتوزيع مبلغ على فئات الأوراق النقدية.

الفكرة

عميل يسحب 870 ريالًا من صرّاف آلي. يوزّع الصرّاف المبلغ على أقل عدد ممكن من الأوراق، مبتدئًا بأكبر فئة: 500 ثم 100 ثم 50 ثم 10 ريالات. فكرة الحل: قسمة المبلغ على الفئة تعطي عدد الأوراق، والباقي هو ما يزال يحتاج توزيعًا على الفئات الأصغر.

المطلوب منك
  1. عرّف متغيرًا صحيحًا amount بقيمة 870.
  2. لكل فئة (بالترتيب من 500 إلى 10): احسب عدد الأوراق بالقسمة الصحيحة، ثم حدّث amount بالباقي باستخدام %.
  3. اطبع عدد الأوراق من كل فئة، ثم المبلغ المتبقي الذي لا يغطيه شيء.
الشكل المطلوب للناتج
500 SAR x 1 100 SAR x 3 50 SAR x 1 10 SAR x 2 Remaining: 0 SAR

تحقق ذهنيًا: 870 / 500 = 1 والباقي 370. ثم 370 / 100 = 3 والباقي 70. أكمل بنفسك قبل أن تكتب الكود.

بعد أن تجرّب بنفسك: اعرض الحل
atm.cpp
#include <iostream>
using namespace std;

int main() {
    int amount = 870;

    int notes500 = amount / 500;
    amount = amount % 500;

    int notes100 = amount / 100;
    amount = amount % 100;

    int notes50 = amount / 50;
    amount = amount % 50;

    int notes10 = amount / 10;
    amount = amount % 10;

    cout << "500 SAR x " << notes500 << endl;
    cout << "100 SAR x " << notes100 << endl;
    cout << " 50 SAR x " << notes50 << endl;
    cout << " 10 SAR x " << notes10 << endl;
    cout << "Remaining: " << amount << " SAR" << endl;
    return 0;
}

محوّل الوقت

سهل

لدينا مدة زمنية قدرها 7384 ثانية، ونريد عرضها بصيغة ساعات ودقائق وثوانٍ.

المطلوب
  • عرّف متغيرًا صحيحًا total بقيمة 7384.
  • احسب الساعات بقسمة المجموع على 3600.
  • احسب الدقائق من الباقي بعد الساعات، ثم الثواني من الباقي بعد الدقائق.
  • اطبع الناتج بالصيغة الموضحة.
الناتج المتوقع
7384 seconds = 2h 3m 4s
تلميحات
  • الباقي بعد استخراج الساعات هو total % 3600.
  • اقسم هذا الباقي على 60 لتحصل على الدقائق، وخذ باقيه على 60 لتحصل على الثواني.
نموذج الحل (بعد المحاولة)
time_convert.cpp
// Challenge 1: seconds to h m s
#include <iostream>
using namespace std;

int main() {
    int total = 7384;

    int hours = total / 3600;
    int rest = total % 3600;
    int minutes = rest / 60;
    int seconds = rest % 60;

    cout << total << " seconds = " << hours << "h " << minutes << "m " << seconds << "s" << endl;
    return 0;
}

ألاعيب الأرقام

متوسط

خذ العدد 47 وأجرِ عليه أربع عمليات تستخدم القسمة والباقي والمقارنات.

المطلوب
  • اطبع رقم الآحاد.
  • اطبع رقم العشرات.
  • اطبع هل العدد زوجي بصيغة true أو false.
  • اطبع هل العدد أكبر من 40 وأصغر من 50 معًا.
الناتج المتوقع
Last digit: 7 Tens digit: 4 Even: false Between 40 and 50: true
تلميحات
  • رقم الآحاد هو n % 10، أما رقم العشرات فهو n / 10 % 10.
  • العدد زوجي إذا كان باقي قسمته على 2 يساوي صفرًا.
  • استخدم boolalpha قبل طباعة أول قيمة منطقية.
نموذج الحل (بعد المحاولة)
digits.cpp
// Challenge 2: number tricks
#include <iostream>
using namespace std;

int main() {
    int n = 47;

    cout << "Last digit: " << n % 10 << endl;
    cout << "Tens digit: " << n / 10 % 10 << endl;
    cout << "Even: " << boolalpha << (n % 2 == 0) << endl;
    cout << "Between 40 and 50: " << (n > 40 && n < 50) << endl;
    return 0;
}

ملخص سريع

  • العوامل الحسابية: + - * / %، والقسمة على صحيحين تعطي صحيحًا و% تعطي الباقي.
  • الإسناد المركّب += وأخواته، و++ و-- يزيدان أو ينقصان بواحد.
  • = للإسناد و== للمقارنة؛ خلط الاثنين خطأ شائع.
  • العوامل المنطقية && و|| و! تجمع الشروط، والتقييم المختصر يتوقف عند أول حاسم.
  • الأقواس تضمن ترتيب التنفيذ الذي تريده.
