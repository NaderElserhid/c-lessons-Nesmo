Hello World — أول برنامج لك بلغة C++

ماذا ستتعلم في هذا الدرس؟

  • تفهم كيف يتحول الكود المكتوب إلى برنامج يعمل على الحاسوب
  • تكتب وتشغّل أول برنامج C++ وتعرف وظيفة كل سطر فيه
  • تستخدم cout وعامل الإدراج << لطباعة النصوص والأرقام
  • تتحكم في الأسطر الجديدة والمسافات باستخدام endl و\n و\t
  • تكتب تعليقات مفيدة، وتقرأ رسائل أخطاء المترجم الأولى

من الفكرة إلى برنامج يعمل

الحاسوب لا يفهم الجمل الإنجليزية التي نكتبها، بل يفهم تعليمات رقمية بسيطة تُسمّى لغة الآلة. لذلك نكتب برنامجنا بلغة قريبة منا هي C++، ثم نستعين ببرنامج وسيط يترجمه. هذه هي الرحلة كاملة:

1

نكتب الكود المصدري

ملف نصي عادي بامتداد .cpp يحتوي تعليماتنا. يسمّى source code.

2

يترجمه المترجم

برنامج اسمه compiler (مثل g++) يقرأ الكود، يتأكد من سلامة قواعده، ثم يحوّله إلى لغة الآلة. إن وجد خطأ في القواعد توقف وأخبرنا به.

3

نحصل على ملف تنفيذي

ملف جاهز للتشغيل يُسمّى executable، لا يحتاج بعد ذلك إلى الكود ولا إلى المترجم.

4

نشغّل البرنامج

ينفّذ الحاسوب التعليمات واحدة تلو الأخرى، ونرى النتيجة على الشاشة.

الكتابة والترجمة والتشغيل تتكرر مئات المرات أثناء أي مشروع. لا تقلق من الأخطاء؛ هي جزء طبيعي من العمل، والمترجم يخبرك بمكانها.

برنامجك الأول

اتفق المبرمجون منذ عقود على أن أول برنامج يكتبه أي متعلّم يطبع عبارة ترحيب بسيطة. هذا هو برنامجنا الأول، ثمانية أسطر فقط:

hello.cpp
#include <iostream>using namespace std; int main() {    cout << "Hello, World!" << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...

اضغط على الأسطر المضيئة لتعرف وظيفة كل منها:

عند تشغيل البرنامج يظهر:

Hello, World!

لاحظ أن علامتي التنصيص لا تظهران في الناتج؛ وظيفتهما فقط أن تحدّدا بداية النص ونهايته داخل الكود.

cout و<<: تدفّق النص إلى الشاشة

تخيّل cout مجرى مائيًّا يصبّ في الشاشة، والرمز << سهمًا يدفع ما على يمينه داخل ذلك المجرى. لذلك نسمّي << عامل الإدراج (insertion operator). ويمكن وضع عدة أشياء في تعليمة واحدة بتكرار السهم:

chain.cpp
cout << "Score: " << 90 << " points" << endl;
Score: 90 points

هنا أرسلنا ثلاثة أشياء إلى الشاشة بالترتيب: نصًا، ثم الرقم 90، ثم نصًا آخر، ثم endl.

انتبه: لا يوجد سطر جديد تلقائي

الأمر cout يطبع ما نعطيه فقط ولا ينتقل إلى سطر جديد من تلقاء نفسه. جرّب هذا البرنامج:

no_newline.cpp
#include <iostream>
using namespace std;

int main() {
    cout << "First part";
    cout << "Second part";
    return 0;
}
First partSecond part

التصق النصّان في سطر واحد دون فاصل. إن أردت الانتقال إلى سطر جديد فعليك أن تطلب ذلك صراحةً.

الانتقال إلى سطر جديد

توجد طريقتان شائعتان: endl أو الرمز الخاص \n داخل النص.

newline.cpp
cout << "Packing list" << endl;
cout << "Tent\n";
cout << "Compass\n" << "Torch\n";
cout << "Water bottle" << endl;
Packing list Tent Compass Torch Water bottle
الطريقةالمعنىملاحظة
endlينهي السطر ويفرّغ ذاكرة الإخراج المؤقتةمناسب للبرامج الصغيرة وللتعلّم
\nيضيف سطرًا جديدًا فقطأسرع عند طباعة كميات كبيرة من النتائج

في مسابقات البرمجة التي تتطلب طباعة آلاف الأسطر، يُفضَّل استخدام '\n' لأن endl يفرّغ الذاكرة المؤقتة في كل مرة فيُبطئ البرنامج.

الرموز الخاصة داخل النص

العلامة \ داخل النص تعني: «الحرف التالي له معنى خاص». نسمّي هذه التركيبات escape sequences. أهمها:

الرمزما يفعله
\nسطر جديد
\tمسافة جدولة (tab) لمحاذاة الأعمدة
\"طباعة علامة تنصيص مزدوجة داخل النص
\\طباعة شرطة مائلة عكسية واحدة
escape.cpp
cout << "Name:\tNora\n";
cout << "She said: \"Hello\"\n";
cout << "Folder: C:\\games\\saves\n";
Name: Nora She said: "Hello" Folder: C:\games\saves

السبب في وجود \" أن علامة التنصيص العادية تُنهي النص؛ فلو كتبناها دون شرطة لظنّ المترجم أن النص انتهى عندها.

التعليقات: ملاحظات للبشر

التعليق جزء من الكود يتجاهله المترجم تمامًا، نكتبه لنشرح لأنفسنا أو لزملائنا لماذا كتبنا الكود بهذا الشكل. له صيغتان:

comments.cpp
// This whole line is ignored by the compiler
cout << "Visible" << endl;      // a note can follow code
/* A longer note
   written on two lines */
cout << "Also visible" << endl;
Visible Also visible

الصيغة // تعلّق ما بقي من السطر، أما /* ... */ فتعلّق كل ما بينهما ولو امتد على عدة أسطر.

اكتب تعليقًا يشرح السبب لا ما هو واضح أصلًا. التعليق «اطبع الاسم» فوق سطر يطبع الاسم لا يفيد أحدًا.

مختبر تفاعلي: اطبع رسالتك

اكتب أي نص، واختر عدد مرات الطباعة، ثم شاهد الكود الذي يكافئه والنتيجة. جرّب أن تكتب علامة تنصيص " داخل نصك وراقب كيف يضيف المحاكي الشرطة المائلة تلقائيًا.

// الكود والناتج سيظهران هنا

أخطاء المبتدئين الشائعة

سترتكب هذه الأخطاء، وكل مبرمج محترف ارتكبها. الجميل أن المترجم يشير إلى مكان المشكلة. تعلّم قراءة رسائله من الآن.

1) نسيان الفاصلة المنقوطة

كود فيه خطأ
cout << "Hello"
return 0;
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:5:20: error: expected ‘;’ before ‘return’
    5 |     cout << "Hello"
      |                    ^
      |                    ;
    6 |     return 0;
      |     ~~~~~~

انظر إلى رقم السطر في الرسالة. المترجم يقول إنه توقّع ; قبل return، أي أن الخطأ في السطر السابق له.

2) خطأ في حالة الأحرف

كود فيه خطأ
Cout << "Hello";
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:5:5: error: ‘Cout’ was not declared in this scope
    5 |     Cout << "Hello";
      |     ^~~~

C++ تفرّق بين الحروف الكبيرة والصغيرة؛ Cout اسم مختلف عن cout ولا وجود له.

3) نسيان علامات التنصيص

كود فيه خطأ
cout << Hello;
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:5:13: error: ‘Hello’ was not declared in this scope; did you mean ‘ftello’?
    5 |     cout << Hello;
      |             ^~~~~
      |             ftello

بدون علامات التنصيص يظن المترجم أن Hello اسم لشيء عرّفناه سابقًا (مثل متغير)، فلا يجده.

صيغة الرسائل تختلف قليلًا من مترجم لآخر ومن إصدار لآخر، لكن المبدأ واحد: رقم السطر، ثم وصف المشكلة. عند ظهور عدة أخطاء، أصلح الأول ثم أعد الترجمة، فكثيرًا ما تختفي البقية معه.

مشروع الدرس: لوحة قائمة المقهى

اقرأ فكرة المشروع أولًا، وحاول تنفيذه بنفسك، ثم قارن بالحل.

الفكرة

صاحب مقهى صغير اسمه «Byte Cafe» يريد لوحة قائمة تُطبع على الشاشة: عنوان بين خطين من علامات المساواة، ثم ثلاثة أصناف أمام كل منها سعره، ثم سطر يذكر ساعات العمل.

المطلوب منك
  1. اطبع الإطار العلوي والعنوان والإطار السفلي للعنوان، كل منها في سطر مستقل.
  2. اطبع ثلاثة أصناف، وضع السعر أمام كل صنف بحيث تقع الأسعار الثلاثة في عمود واحد منتظم (استخدم \t).
  3. اطبع خطًا فاصلًا ثم سطر ساعات العمل.
  4. تأكد أن كل تعليمة تنتهي بفاصلة منقوطة، وأن البرنامج ينتهي بـ return 0;.
الشكل المطلوب للناتج

يجب أن يطبع برنامجك الشكل التالي بالضبط:

======================= BYTE CAFE MENU ======================= Espresso 8 SAR Latte 12 SAR Cheesecake 15 SAR ----------------------- Open daily: 7am - 11pm

تلميح قبل أن تبدأ: الأسماء تختلف في الطول، لذلك تحتاج بعد Espresso إلى عدد من علامات \t يختلف عمّا تحتاجه بعد Cheesecake. جرّب وعدّل حتى تتحاذى الأسعار.

بعد أن تجرّب بنفسك: اعرض الحل
cafe_menu.cpp
#include <iostream>
using namespace std;

int main() {
    cout << "=======================" << endl;
    cout << "     BYTE CAFE MENU    " << endl;
    cout << "=======================" << endl;
    cout << "Espresso\t\t8 SAR\n";
    cout << "Latte\t\t\t12 SAR\n";
    cout << "Cheesecake\t\t15 SAR\n";
    cout << "-----------------------\n";
    cout << "Open daily: 7am - 11pm\n";
    return 0;
}

استخدمنا \t\t بعد Espresso وCheesecake، و\t\t\t بعد Latte لأنه أقصر، فتلتقي الأسعار عند نفس الموضع.

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

بطاقة تعريف

سهل

اكتب برنامجًا يطبع بطاقة تعريف شخصية داخل إطار من الرموز، تحمل اسمك ومدينتك وشعارك المفضل.

المطلوب
  • اطبع الإطار العلوي والسفلي بالرمزين + و- كما في المثال.
  • اطبع ثلاثة أسطر بيانات (الاسم، المدينة، الشعار) بحيث تنتهي كلها بالرمز | عند العمود نفسه.
  • اكتب الشعار بين علامتي تنصيص مزدوجتين تظهران في الناتج.
  • ابدأ الملف بتعليق يذكر اسم التحدي.
الناتج المتوقع
+----------------------+ | Name: Sara | | City: Jeddah | | Motto: "Code daily" | +----------------------+
تلميحات
  • علامة التنصيص التي تريد ظهورها تُكتب \" داخل النص.
  • احسب عدد المسافات بعد كل قيمة بحيث تتساوى أطوال الأسطر الخمسة.
  • يمكنك استبدال البيانات ببياناتك أنت، المهم أن يبقى الإطار منتظمًا.
نموذج الحل (بعد المحاولة)
id_card.cpp
// Challenge 1: ID card
#include <iostream>
using namespace std;

int main() {
    cout << "+----------------------+" << endl;
    cout << "| Name:  Sara          |" << endl;
    cout << "| City:  Jeddah        |" << endl;
    cout << "| Motto: \"Code daily\"  |" << endl;
    cout << "+----------------------+" << endl;
    return 0;
}
2

الهرم

متوسط

اكتب برنامجًا يرسم هرمًا صغيرًا من النجوم على أربعة أسطر، بحيث يزداد عدد النجوم في كل سطر بمقدار اثنتين.

المطلوب
  • استخدم cout فقط (لم ندرس الحلقات بعد).
  • السطر الأول فيه نجمة واحدة، والثاني ثلاث، والثالث خمس، والرابع سبع.
  • ضع قبل النجوم مسافات بحيث يظهر الشكل متماثلًا كالهرم.
الناتج المتوقع
* *** ***** *******
تلميحات
  • السطر الأول يحتاج ثلاث مسافات قبل النجمة، والثاني اثنتين، والثالث واحدة، والرابع صفر.
  • اكتب المسافات داخل علامتي التنصيص مع النجوم، مثل " *".
نموذج الحل (بعد المحاولة)
pyramid.cpp
// Challenge 2: pyramid
#include <iostream>
using namespace std;

int main() {
    cout << "   *" << endl;
    cout << "  ***" << endl;
    cout << " *****" << endl;
    cout << "*******" << endl;
    return 0;
}

ملخص سريع

  • الكود المكتوب يُترجم بالمترجم إلى برنامج تنفذه الحاسوب.
  • كل برنامج C++ يبدأ بـ main، وتنتهي كل جملة بفاصلة منقوطة ;.
  • cout << ... تطبع على الشاشة، وendl أو \n تنقل إلى سطر جديد.
  • التعليقات // و/* */ للبشر فقط ولا ينفذها المترجم.
  • رسالة المترجم تدلّك على السطر والخطأ، فاقرأ أول رسالة أولًا.

تحقق من فهمك

اقرأ كل عبارة ثم اختر صحيح أو خطأ. سيظهر التفسير مباشرة بعد إجابتك.
