جملة if الشرطية

The if Statement — حين يتعلم البرنامج أن يقرر

ماذا ستتعلم في هذا الدرس؟

  • تكتب if وelse وelse if وتتتبّع أي كتلة ستُنفَّذ
  • تفرّق بين سلسلة else if وجملتي if منفصلتين
  • تبني شروطًا مركّبة باستخدام && و|| و!
  • تتجنب الأخطاء الشائعة: = بدل ==، والفاصلة بعد الشرط، ونسيان الأقواس
  • تبني برنامجًا يقرأ مدخلات ويقرر بناءً عليها

البرنامج يقرر

إلى الآن كانت برامجنا تنفّذ كل شيء بالترتيب دون اختيار. لكن الألعاب والتطبيقات الحقيقية تقرر باستمرار: «هل بقي للاعب حياة؟ هل كلمة المرور صحيحة؟ هل العمر يسمح بدخول اللعبة؟». أداة اتخاذ القرار في C++ هي الجملة الشرطية if.

فكّر في إشارة المرور: إذا كانت خضراء فتحرّك، وإلا فقف. هذه هي if وelse بعينهما.

الشرط صحيح؟
نعم: نفّذ كتلة if
لا: نفّذ كتلة else أو تخطَّ

جملة if البسيطة

الصيغة: نكتب if، ثم الشرط بين قوسين، ثم الكتلة التي تُنفَّذ فقط إذا كان الشرط صحيحًا:

simple_if.cpp
int lives = 0;
if (lives == 0) {
    cout << "Game over" << endl;
}
cout << "Thanks for playing" << endl;
Game over Thanks for playing

بما أن lives == 0 صحيحة، دخل البرنامج الكتلة وطبع Game over. أما السطر الأخير فهو خارج الكتلة، فيُنفَّذ دائمًا. جرّب أن تغيّر lives إلى 3 وستختفي الجملة الأولى.

ضع الكتلة بين { و} دائمًا، حتى لو كانت فيها جملة واحدة. ستفهم السبب بعد قليل عندما نرى أخطاء المبتدئين.

if وelse: طريقان لا ثالث لهما

إذا أردت تنفيذ شيء عندما لا يتحقق الشرط، أضف else. سيُنفَّذ أحد الطريقين دائمًا، ولن يُنفَّذ الاثنان معًا:

if_else.cpp
int age = 11;
if (age >= 13) {
    cout << "You can create an account." << endl;
} else {
    cout << "Ask a parent to help you." << endl;
}
Ask a parent to help you.

العمر 11 ليس أكبر من أو يساوي 13، فذهب البرنامج إلى كتلة else.

سلسلة else if: أكثر من خيارين

عندما تكون الخيارات أكثر من اثنين نربط الشروط في سلسلة. يفحص البرنامج الشروط من الأعلى إلى الأسفل، وأول شرط صحيح تُنفَّذ كتلته ثم يخرج من السلسلة كلها. أما else الأخيرة فتعمل إذا فشلت كل الشروط قبلها.

راقب هذا التتبع لتحويل درجة 72 إلى علامة حرفية. لاحظ أي الأسطر تُنفَّذ وأيها يُقفز عنه:

تتبّع التنفيذ خطوة بخطوة
1int score = 72;
2char grade = '?';
3if (score >= 90) {
4 grade = 'A';
5} else if (score >= 80) {
6 grade = 'B';
7} else if (score >= 70) {
8 grade = 'C';
9} else {
10 grade = 'F';
11}
12cout << "Grade: " << grade << endl;
المتغيرات
الناتج حتى الآن
توقّع قبل أن تشغّل
weather.cpp
int temp = 30;
if (temp > 35) {
    cout << "Very hot";
} else if (temp > 25) {
    cout << "Warm";
} else if (temp > 15) {
    cout << "Mild";
} else {
    cout << "Cold";
}
cout << endl;

ما الكلمة التي ستظهر؟

Warm

في السلسلة نبدأ من الأعلى: 30 > 35 خطأ، ثم 30 > 25 صحيح، فتُنفَّذ كتلة Warm ونتوقف فورًا. لا نفحص الشروط التي بعدها حتى لو كانت صحيحة (30 > 15 صحيح أيضًا لكنه لا يُفحص).

الترتيب مهم: لو كتبت score >= 70 قبل score >= 90 لحصل كل من تجاوز 90 على علامة C، لأن أول شرط صحيح يفوز. رتّب الشروط من الأضيق إلى الأوسع.

جملتا if منفصلتان لا تساويان سلسلة

هذه نقطة يخلط فيها كثيرون. إذا كتبت if ثم if أخرى تحتها (بدون else بينهما) فهما سؤالان مستقلان، وقد يصح الاثنان معًا:

توقّع قبل أن تشغّل
two_ifs.cpp
int n = 10;
if (n > 5) {
    cout << "X";
}
if (n > 8) {
    cout << "Y";
}
cout << endl;

ما الذي سيُطبع؟

XY

هاتان جملتا if منفصلتان وليستا سلسلة واحدة. الأولى صحيحة (10 > 5) فطُبعت X، والثانية صحيحة (10 > 8) فطُبعت Y. كل جملة if تُفحص مستقلة عن الأخرى.

الشكلكم كتلة قد تُنفَّذ؟
if ... else if ... elseكتلة واحدة فقط على الأكثر
if ... ثم if ... منفصلتانكلاهما أو إحداهما أو لا شيء

شروط مركّبة بـ && و|| و!

تذكّر العوامل المنطقية من الدرس السابق. نستخدمها لبناء سؤال أذكى داخل if. لنفترض أن لعبة «الصاروخ» تشترط طولًا 120 سم فأكثر و عمرًا 8 فأكثر:

logic_if.cpp
int height = 130;
int age = 7;
bool hasTicket = true;

if (height >= 120 && age >= 8) {
    cout << "Rocket: allowed" << endl;
}
if (age < 8 || height < 120) {
    cout << "Rocket: not allowed" << endl;
}
if (!hasTicket) {
    cout << "Buy a ticket first" << endl;
}
cout << "Done" << endl;
Rocket: not allowed Done

الطفل ذو الطول 130 والعمر 7 فشل في شرط العمر، فلم يُسمح له رغم أن طوله كافٍ. وجملة if (!hasTicket) لم تعمل لأن لديه تذكرة (!true تساوي false). وأخيرًا طُبعت Done لأنها خارج أي شرط.

جمل if متداخلة

يمكن وضع if داخل كتلة if أخرى، فتصبح القرارات على مراحل. مثال: نتحقق أولًا من اسم المستخدم، وبعدها فقط نتحقق من كلمة المرور:

login.cpp
string user = "sara";
string pass = "1234";

if (user == "sara") {
    if (pass == "1234") {
        cout << "Welcome back, Sara!" << endl;
    } else {
        cout << "Wrong password." << endl;
    }
} else {
    cout << "Unknown user." << endl;
}
Welcome back, Sara!

التداخل أداة جيدة، لكن لا تبالغ فيه. كلما زادت المستويات صار الكود أصعب في القراءة. وغالبًا يمكن تبسيط شرطين متداخلين بشرط واحد مركّب باستخدام && إذا كانت النتيجة واحدة.

مختبر تفاعلي: من يفوز في السلسلة؟

اكتب درجة بين 0 و100، وشاهد كيف يفحص البرنامج الشروط واحدًا بعد الآخر حتى يجد الشرط الصحيح:

chain.cpp
if (score >= 90) { grade = 'A'; }else if (score >= 80) { grade = 'B'; }else if (score >= 70) { grade = 'C'; }else if (score >= 60) { grade = 'D'; }else { grade = 'F'; }

ثلاثة أخطاء يقع فيها كل مبتدئ

1) الإسناد بدل المقارنة: = مكان ==

assign_bug.cpp
int x = 3;
if (x = 5) {
    cout << "x is five" << endl;
}
cout << "x now holds " << x << endl;
x is five x now holds 5

العلامة = داخل الشرط تغيّر x إلى 5 ثم تعيد القيمة 5 (وهي غير صفر، أي صحيحة). فدخل البرنامج الكتلة رغم أن x كانت 3 أصلًا! ينبّهك المترجم أحيانًا إن شغّلته بالخيار -Wall، فاعتمد عليه دائمًا.

2) فاصلة منقوطة بعد الشرط

semicolon_bug.cpp
int score = 10;
if (score > 50); {
    cout << "Passed!" << endl;
}
Passed!

الدرجة 10 لا تتجاوز 50، لكن Passed! ظهرت! السبب أن الفاصلة المنقوطة بعد ) جعلت جسم if جملة فارغة، وصارت الكتلة التي بعدها كتلة عادية تُنفَّذ دائمًا.

3) نسيان الأقواس المجموعة

no_braces.cpp
int hp = 5;
if (hp == 0)
    cout << "Game over" << endl;
    cout << "Restarting..." << endl;
Restarting...

بدون { } تتبع if جملة واحدة فقط هي التالية لها مباشرة. أما السطر الثاني (Restarting...) فمستقل، ولذلك ظهر رغم أن hp لا تساوي صفرًا، والتزحيف لا يخدع المترجم أبدًا. وهذا سبب نصيحتنا بكتابة الأقواس دائمًا.

اختياري: المعامل الثلاثي

للقرارات القصيرة التي تختار قيمة بين اثنتين، يوجد اختصار: condition ? valueIfTrue : valueIfFalse:

ternary.cpp
int age = 16;
string label = (age >= 18) ? "adult" : "teen";
cout << label << endl;
int bigger = (7 > 3) ? 7 : 3;
cout << bigger << endl;
teen 7

استخدمه عندما يكون القرار بسيطًا فقط، وإلا فاستخدم if ليبقى الكود واضحًا.

مشروع الدرس: حارس مدينة الألعاب

برنامج يقرر من يركب لعبة الصاروخ وكم يدفع.

الفكرة

أنت تبرمج بوابة لعبة «الصاروخ» في مدينة ألعاب. يكتب الزائر طوله بالسنتيمتر وعمره، ثم يخبره البرنامج إن كان مسموحًا له بالركوب، وكم يدفع.

قواعد اللعبة
  1. يُسمح بالركوب إذا كان الطول 120 فأكثر و العمر 8 فأكثر.
  2. إذا سُمح له: تذكرة من هم دون 12 سنة 20 ريالًا، وغيرهم 35 ريالًا.
  3. إذا لم يُسمح: إن كان طوله أقل من 120 اطبع Sorry, you are too short.، وإلا اطبع Sorry, you are too young.
  4. اقرأ الطول والعمر بتعليمة cin واحدة بهذا الترتيب.
أمثلة على التشغيل

زائر طوله 135 وعمره 9:

135 9
You can ride the Rocket! Ticket: 20 SAR

زائر طوله 110 وعمره 10:

110 10
Sorry, you are too short.

زائر طوله 150 وعمره 7:

150 7
Sorry, you are too young.

زائر طوله 170 وعمره 15:

170 15
You can ride the Rocket! Ticket: 35 SAR

فكّر قبل أن تكتب: ارسم مخططًا انسيابيًا صغيرًا بالقلم. أي سؤال تطرحه أولًا؟ وما الذي ينتج عن كل إجابة؟ ثم حوّل المخطط إلى كود.

بعد أن تجرّب بنفسك: اعرض الحل
ride_checker.cpp
#include <iostream>
using namespace std;

int main() {
    int height, age;
    cin >> height >> age;

    if (height >= 120 && age >= 8) {
        cout << "You can ride the Rocket!" << endl;
        if (age < 12) {
            cout << "Ticket: 20 SAR" << endl;
        } else {
            cout << "Ticket: 35 SAR" << endl;
        }
    } else if (height < 120) {
        cout << "Sorry, you are too short." << endl;
    } else {
        cout << "Sorry, you are too young." << endl;
    }
    return 0;
}

لاحظ أن جملة if الخاصة بالتذكرة موجودة داخل كتلة السماح، فلا تُفحص إلا لمن سُمح له.

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

مصنّف الأعداد

سهل

اكتب برنامجًا يقرأ عددًا صحيحًا ثم يخبرك إن كان سالبًا أو صفرًا أو موجبًا، ثم يخبرك إن كان زوجيًا أو فرديًا.

المطلوب
  • اقرأ العدد بـ cin.
  • استخدم سلسلة if / else if / else لتصنيف الإشارة (Negative أو Zero أو Positive).
  • استخدم جملة if / else أخرى منفصلة لتصنيف الزوجي (Even) والفردي (Odd).
مثال على الإدخال والناتج المتوقع
7
Positive Odd
تلميحات
  • العدد زوجي إذا كان n % 2 == 0.
  • لاحظ أن الجملتين مستقلتان، فتُطبع نتيجتان: واحدة من كل جملة.
  • العدد صفر زوجي أيضًا، فجرّب برنامجك مع 0 ومع عدد سالب.
نموذج الحل (بعد المحاولة)
classifier.cpp
// Challenge 1: number classifier
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    if (n < 0) {
        cout << "Negative" << endl;
    } else if (n == 0) {
        cout << "Zero" << endl;
    } else {
        cout << "Positive" << endl;
    }

    if (n % 2 == 0) {
        cout << "Even" << endl;
    } else {
        cout << "Odd" << endl;
    }
    return 0;
}
2

السنة الكبيسة

متوسط

السنة الكبيسة (366 يومًا) لها قاعدة: تقبل القسمة على 4، لكن إذا كانت من القرون (تقبل القسمة على 100) فلا تكون كبيسة إلا إذا قبلت القسمة على 400 أيضًا. مثال: 2024 كبيسة، و1900 ليست كبيسة، و2000 كبيسة.

المطلوب
  • اقرأ السنة كعدد صحيح.
  • ابنِ شرطًا واحدًا مركّبًا يطبّق القاعدة بالعوامل && و|| والباقي %.
  • اطبع 2024 is a leap year أو 2024 is not a leap year بحسب السنة المُدخلة.
  • جرّب برنامجك مع 1900 و2000 و2023 وتأكد من صحة الإجابات.
مثال على الإدخال والناتج المتوقع
2024
2024 is a leap year
تلميحات
  • الحالة الأولى: تقبل القسمة على 4 ولا تقبل القسمة على 100.
  • الحالة الثانية: تقبل القسمة على 400.
  • الشرط الكامل: (year % 4 == 0 && year % 100 != 0) || year % 400 == 0.
نموذج الحل (بعد المحاولة)
leap_year.cpp
// Challenge 2: leap year
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;

    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        cout << year << " is a leap year" << endl;
    } else {
        cout << year << " is not a leap year" << endl;
    }
    return 0;
}

ملخص سريع

  • الجملة if تنفّذ كتلتها إذا كان الشرط true، وتتخطاها إذا كان false.
  • تضيف else طريقًا بديلًا يعمل حين يفشل الشرط.
  • في سلسلة else if يُنفَّذ أول شرط صحيح فقط ثم يخرج البرنامج من السلسلة.
  • جملتا if المنفصلتان تُفحصان كلٌّ على حدة، وقد تعملان معًا.
  • ثلاثة أخطاء شهيرة: = بدل ==، وفاصلة منقوطة بعد الشرط، ونسيان الأقواس المجموعة.
  • اكتب الأقواس المجموعة دائمًا، ورتّب شروط السلسلة من الأضيق إلى الأوسع.
