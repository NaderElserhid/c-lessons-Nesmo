حلقة while

The while Loop — كيف يكرر الحاسوب العمل دون ملل

ماذا ستتعلم في هذا الدرس؟

  • تفهم فكرة التكرار وتكتب حلقة while بأجزائها الثلاثة
  • تتتبّع تنفيذ الحلقة دورةً دورة وتتوقع الناتج
  • تطبّق أنماط التجميع والعدّ وتفكيك الأرقام
  • تتجنب الحلقات اللانهائية وأخطاء الواحد
  • تستخدم break وcontinue وdo-while وتقرأ المدخلات في حلقة

لماذا نكرر؟

لو طلبت منك أن تكتب الأعداد من 1 إلى 1000 على الشاشة، هل ستكتب ألف جملة cout؟ بالطبع لا! الحاسوب ممتاز في شيء واحد: تكرار العمل نفسه بدقة ومن دون ملل. وأداتنا لذلك هي الحلقة (loop).

تخيّل أنك تملأ كوب ماء: ما دام الكوب غير ممتلئ، أضف قليلًا من الماء. هذا هو تمامًا معنى الحلقة while بالعربية: «ما دام الشرط صحيحًا، كرّر».

الشرط صحيح؟
نعم: نفّذ جسم الحلقة
لا: اخرج من الحلقة

تشريح حلقة while

كل حلقة while سليمة تتكون من ثلاثة أجزاء، ونسمّيها «العدّاد الثلاثي»:

الجزءأين؟ماذا يفعل؟
1) التهيئةقبل الحلقةيعطي المتغير قيمته الأولى (int n = 3;)
2) الشرطبين قوسي whileيُفحص قبل كل دورة، فإن صح بدأت دورة جديدة
3) التحديثداخل الجسميقرّب الحلقة من نهايتها (n = n - 1;)

مثال: عدّ تنازلي لإطلاق صاروخ. اضغط «التالي» في المتتبّع لترى كيف يعود التنفيذ إلى سطر الشرط بعد كل دورة، ولاحظ تغيّر n في لوحة المتغيرات:

تتبّع التنفيذ خطوة بخطوة
1int n = 3;
2while (n > 0) {
3 cout << n << endl;
4 n = n - 1;
5}
6cout << "Liftoff!" << endl;

الناتج حتى الآن

الناتج الكامل للبرنامج:

اختبر فهمك: تتبّع الحلقة

أهم مهارة مع الحلقات: أن تتبّع القيم بالورقة دورةً دورة. جرّب مع هذه المسألة:

توقّع قبل أن تشغّل
sum_quiz.cpp
int i = 1;
int sum = 0;
while (i <= 4) {
    sum = sum + i;
    i++;
}
cout << sum << endl;

ما الناتج؟ تتبّع i وsum في كل دورة.

10

الدورات: i=1 فتصير sum=1، ثم i=2 فتصير sum=3، ثم i=3 فتصير sum=6، ثم i=4 فتصير sum=10. بعدها تصير i=5 فيفشل الشرط i <= 4 وتنتهي الحلقة.

نمط التجميع: حكاية غاوس

يُحكى أن معلّم الرياضيات طلب من الطالب الصغير غاوس أن يجمع الأعداد من 1 إلى 100 ليشغله، فأجاب في دقائق. نحن لدينا الآن طريقة أسرع من الدقائق: حلقة تجمع الأعداد وتحتفظ بالمجموع في متغير يسمى المُجمِّع (accumulator):

gauss.cpp
int i = 1;
int sum = 0;
while (i <= 100) {
    sum = sum + i;
    i++;
}
cout << "1 + 2 + ... + 100 = " << sum << endl;
1 + 2 + ... + 100 = 5050

فكرة المُجمِّع: نبدأ بصفر، ثم نضيف إليه شيئًا جديدًا في كل دورة. استخدم النمط نفسه لحساب الجداء (ابدأ بـ 1)، أو لعدّ الأشياء (أضف 1 كل مرة).

تفكيك الأعداد: رقمًا رقمًا

تذكّر أن n % 10 تعطي الرقم الأخير، وأن n / 10 تحذف هذا الرقم. فإذا كررنا العمليتين حتى يصبح العدد صفرًا، نكون قد مررنا بكل أرقامه:

digit_sum.cpp
int n = 4729;
int digitSum = 0;
while (n > 0) {
    int lastDigit = n % 10;
    digitSum = digitSum + lastDigit;
    n = n / 10;
}
cout << "Digit sum: " << digitSum << endl;
Digit sum: 22

تتبّع العدد 4729: الأرقام 9 ثم 2 ثم 7 ثم 4، ومجموعها 22. وفي كل دورة صار العدد أقصر برقم واحد: 4729 ثم 472 ثم 47 ثم 4 ثم 0 فتوقفت الحلقة.

الحلقة اللانهائية وخطأ الواحد

الحلقة التي لا تنتهي

إذا لم يصبح الشرط خاطئًا أبدًا، فلن تتوقف الحلقة. هذا يحدث عادةً بسبب نسيان التحديث:

infinite.cpp (لا تشغّله!)
int n = 3;
while (n > 0) {
    cout << n << endl;
    // forgot: n = n - 1;
}

سيطبع هذا الكود الرقم 3 إلى ما لا نهاية. إن علق برنامجك هكذا فاضغط Ctrl + C في الطرفية لإيقافه. ومن أسباب الحلقة اللانهائية أيضًا كتابة فاصلة منقوطة بعد الشرط: while (n > 0); فتصبح الحلقة فارغة ولا تتغير n أبدًا.

خطأ الواحد (off-by-one)

الفرق بين < و<= يكفي لتخسر أو تربح دورة كاملة. أراد برنامجان طباعة الأعداد من 1 إلى 5:

الشرط i < 5
int i = 1;
while (i < 5) {
    cout << i << " ";
    i++;
}
cout << endl;
الشرط i <= 5
int i = 1;
while (i <= 5) {
    cout << i << " ";
    i++;
}
cout << endl;

ناتج الأول: 1 2 3 4 فنقص 5. وناتج الثاني: 1 2 3 4 5 وهو المطلوب. اختبر حلقتك دائمًا عند الحدود: أول قيمة وآخر قيمة.

مختبر تفاعلي: صمّم حلقتك

حدّد القيمة الابتدائية والحد والخطوة، واختر المعامل، وشاهد ما الذي ستفعله الحلقة. جرّب أن تجعل الخطوة سالبة مع < لترى حلقة لا نهائية (سيوقفها المحاكي):

الحلقات والمدخلات

الحلقات مع cin تصنع برامج تتفاعل مع المستخدم. هناك نمطان شائعان:

1) القيمة الحارسة (sentinel): نقرأ حتى يكتب المستخدم قيمة معينة

هنا يكتب المستخدم أعدادًا ويضع 0 ليعلن النهاية:

sentinel.cpp
int x, sum = 0;
cin >> x;
while (x != 0) {
    sum = sum + x;
    cin >> x;
}
cout << "Sum: " << sum << endl;
5 8 2 0
Sum: 15

لاحظ أننا قرأنا قيمة قبل الحلقة، ثم قرأنا القيمة التالية في آخر كل دورة، فيُفحص الشرط على قيمة جديدة دائمًا.

2) القراءة حتى نهاية الإدخال

التعبير cin >> x نفسه يصلح شرطًا: يكون صحيحًا ما دامت القراءة نجحت، ويصبح خاطئًا عندما ينتهي الإدخال. وهذا النمط شائع جدًا في المسابقات:

read_all.cpp
int x, sum = 0;
while (cin >> x) {
    sum = sum + x;
}
cout << "Sum: " << sum << endl;
4 6 10
Sum: 20

عندما تكتب بنفسك في الطرفية، تنهي الإدخال بالضغط على Ctrl + D (لينكس وماك) أو Ctrl + Z ثم Enter (ويندوز).

break وcontinue: تحكّم دقيق في الدورة

الأمرماذا يفعل؟
break;يُنهي الحلقة كلها فورًا ويخرج منها
continue;يتخطى بقية الدورة الحالية وينتقل إلى الدورة التالية
break_continue.cpp
int i = 0;
while (i < 10) {
    i++;
    if (i % 3 == 0) {
        continue;
    }
    if (i == 8) {
        break;
    }
    cout << i << " ";
}
cout << endl;
توقّع قبل أن تشغّل
break_continue.cpp
int i = 0;
while (i < 10) {
    i++;
    if (i % 3 == 0) {
        continue;
    }
    if (i == 8) {
        break;
    }
    cout << i << " ";
}
cout << endl;

ما الأعداد التي ستُطبع؟

1 2 4 5 7

continue تتخطى بقية الدورة عند المضاعفات (3 و6)، فلا تُطبع. وعند i == 8 تنفّذ break فتتوقف الحلقة كلها قبل أن تُطبع 8.

لاحظ أننا زدنا i في بداية الجسم، قبل continue. لو وضعنا الزيادة في آخر الجسم لتخطّاها continue وصارت الحلقة لا نهائية!

do-while: نفّذ أولًا ثم اسأل

في while يُفحص الشرط قبل الدورة، فقد لا يُنفَّذ الجسم أبدًا. أما do ... while فتنفّذ الجسم مرة واحدة على الأقل، ثم تفحص الشرط في النهاية. مناسبة لطلب إدخال صحيح من المستخدم:

do_while.cpp
int choice;
do {
    cout << "Choose 1-5: ";
    cin >> choice;
} while (choice < 1 || choice > 5);
cout << "You chose " << choice << endl;
9 0 3
Choose 1-5: Choose 1-5: Choose 1-5: You chose 3

المستخدم أخطأ مرتين (9 ثم 0) فكرّر البرنامج الطلب، وعندما كتب 3 اجتاز الشرط. لاحظ الفاصلة المنقوطة بعد while (...) في هذه الصيغة، وهي مطلوبة هنا فقط.

مشروع الدرس: متى أشتري السماعة؟

برنامج ادخار يحسب عدد الأسابيع اللازمة للوصول إلى هدفك.

الفكرة

تريد شراء سماعات سعرها 250 ريالًا. معك الآن 40 ريالًا، وتستطيع ادخار 30 ريالًا كل أسبوع. نريد برنامجًا يخبرك بالمبلغ الذي ستملكه في نهاية كل أسبوع، وكم أسبوعًا تحتاج لتصل إلى هدفك.

المطلوب منك
  1. اقرأ ثلاثة أعداد صحيحة بهذا الترتيب: سعر الهدف، والمبلغ الحالي، والادخار الأسبوعي.
  2. استخدم حلقة while تستمر ما دام المبلغ أقل من الهدف.
  3. في كل دورة: أضف الادخار الأسبوعي، وزد عدّاد الأسابيع، ثم اطبع سطرًا مثل Week 1: 70 SAR (رقم الأسبوع ثم المبلغ الحالي).
  4. بعد الحلقة اطبع Goal reached in N weeks!
مثال على التشغيل
250 40 30
Week 1: 70 SAR Week 2: 100 SAR Week 3: 130 SAR Week 4: 160 SAR Week 5: 190 SAR Week 6: 220 SAR Week 7: 250 SAR Goal reached in 7 weeks!

فكّر قبل أن تكتب: ما الذي يتغير في كل دورة؟ (المبلغ، وعدّاد الأسابيع). وما الشرط الذي يجعل الحلقة تتوقف؟

بعد أن تجرّب بنفسك: اعرض الحل
piggy_bank.cpp
#include <iostream>
using namespace std;

int main() {
    int target, saved, weekly;
    cin >> target >> saved >> weekly;

    int weeks = 0;
    while (saved < target) {
        saved = saved + weekly;
        weeks++;
        cout << "Week " << weeks << ": " << saved << " SAR" << endl;
    }
    cout << "Goal reached in " << weeks << " weeks!" << endl;
    return 0;
}

تحذير: لو كان الادخار الأسبوعي صفرًا فلن يتغير المبلغ أبدًا وتصبح الحلقة لا نهائية. هل تستطيع حماية برنامجك من هذه الحالة باستخدام if؟

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

كم رقمًا في العدد؟

سهل

اكتب برنامجًا يقرأ عددًا صحيحًا موجبًا ويحسب كم رقمًا يتكون منه، باستخدام حلقة while فقط.

المطلوب
  • اقرأ العدد بـ cin.
  • استخدم عدّادًا يبدأ من صفر.
  • في كل دورة احذف الرقم الأخير من العدد وزد العدّاد.
  • اطبع النتيجة بالصيغة الموضحة.
مثال على الإدخال والناتج المتوقع
90210
Digits: 5
تلميحات
  • الحلقة تستمر ما دام العدد أكبر من صفر.
  • احذف الرقم الأخير بالقسمة على 10: n = n / 10;.
  • العدد 90210 يتكون من 5 أرقام، فاختبر برنامجك به.
نموذج الحل (بعد المحاولة)
count_digits.cpp
// Challenge 1: count digits
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int count = 0;
    while (n > 0) {
        n = n / 10;
        count++;
    }
    cout << "Digits: " << count << endl;
    return 0;
}
2

لعبة التخمين

متوسط

الرقم السري هو 37. يكتب اللاعب تخمينات متتالية، وبعد كل تخمين يخبره البرنامج إن كان التخمين كبيرًا أو صغيرًا، حتى يصيب. ثم يطبع عدد المحاولات.

المطلوب
  • عرّف secret بقيمة 37، وattempts يبدأ من صفر.
  • كرّر القراءة والفحص ما دام آخر تخمين لا يساوي الرقم السري.
  • اطبع Too high أو Too low بعد كل تخمين خاطئ.
  • بعد الحلقة اطبع Correct! Attempts: N.
مثال على الإدخال والناتج المتوقع
50 20 37
Too high Too low Correct! Attempts: 3
تلميحات
  • ابدأ guess بقيمة لا تساوي السري (مثل 0) ليدخل البرنامج الحلقة.
  • استخدم if / else if داخل الحلقة للمقارنة.
  • زد attempts بعد كل قراءة.
نموذج الحل (بعد المحاولة)
guess_game.cpp
// Challenge 2: guessing game
#include <iostream>
using namespace std;

int main() {
    int secret = 37;
    int guess = 0;
    int attempts = 0;

    while (guess != secret) {
        cin >> guess;
        attempts++;
        if (guess > secret) {
            cout << "Too high" << endl;
        } else if (guess < secret) {
            cout << "Too low" << endl;
        }
    }
    cout << "Correct! Attempts: " << attempts << endl;
    return 0;
}

ملخص سريع

  • الحلقة while تكرر جسمها ما دام الشرط true، وتفحص الشرط قبل كل دورة.
  • كل حلقة تحتاج ثلاثة أشياء: تهيئة قبلها، وشرطًا، وتحديثًا داخلها.
  • إن لم يصبح الشرط false أبدًا فالحلقة لا نهائية، وتُوقَف بالضغط على Ctrl + C.
  • تأكد من الحدود دائمًا: الفرق بين < و<= يغيّر عدد الدورات.
  • break تنهي الحلقة كلها، وcontinue تتخطى الدورة الحالية فقط.
  • do-while تنفّذ الجسم مرة على الأقل ثم تفحص الشرط.
