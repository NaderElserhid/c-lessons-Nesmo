Statements and Control Flow — كيف يسير البرنامج من سطر إلى آخر

برنامجك روبوت مطيع جدًا

تخيّل أنك كتبت لروبوت صغير ورقة فيها تعليمات: «اخطُ خطوتين، ثم انعطف يمينًا، ثم التقط الكرة». الروبوت لا يفكر ولا يخمّن، بل ينفّذ كل سطر بالترتيب كما كتبته تمامًا. وبرنامج C++ يتصرف بالطريقة نفسها.

كل سطر تعليمات في برنامجك اسمه في عالم البرمجة جملة (statement). في هذا الدرس سنعرف أنواع الجمل، وكيف تُجمع في مجموعات، وكيف نغيّر مسار الروبوت بدل أن يمشي في خط مستقيم دائمًا.

أنواع الجمل

لن نحتاج إلى حفظ مصطلحات كثيرة، يكفي أن تميّز أربعة أنواع:

النوعماذا يفعل؟مثال
جملة تصريح (declaration)تنشئ متغيرًا جديدًاint coins = 5;
جملة تعبير (expression statement)تحسب شيئًا أو تغيّر قيمة أو تطبعcoins = coins + 3;
جملة مركّبة (block)تجمع عدة جمل بين قوسين مجموعين{ ... }
جملة فارغة (empty statement)لا تفعل شيئًا إطلاقًا;

لنرَ الأنواع الأربعة معًا في برنامج واحد:

kinds.cpp
int coins = 5;           // declaration statement
coins = coins + 3;       // expression statement (assignment)
coins++;                 // expression statement (increment)
cout << coins << endl;   // expression statement (output)
;                        // empty statement: does nothing
9

قيمة coins بدأت 5، وزادت 3 فصارت 8، ثم زادت 1 فصارت 9، ثم طبعنا 9. أما السطر الأخير ; فلم يفعل شيئًا، وهذا مقصود.

الكتلة: صندوق يجمع الجمل

إذا وضعت عدة جمل بين { و} فإنها تتحول إلى كتلة واحدة. جسم main نفسه كتلة! ويمكنك أن تصنع كتلة داخل كتلة:

block.cpp
int coins = 5;
{
    int bonus = 10;
    coins = coins + bonus;
    cout << "Inside the block: " << coins << endl;
}
cout << "Outside the block: " << coins << endl;
Inside the block: 15 Outside the block: 15

انتبه إلى أمرين مهمين:

ما تستطيعه الكتلة
  • تقرأ المتغيرات التي صُرّح عنها قبلها
  • تغيّر قيم تلك المتغيرات (انظر coins)
  • تنشئ متغيراتها الخاصة (مثل bonus)
ما لا تستطيعه
  • متغيراتها الخاصة تختفي عند إغلاقها }
  • لا يمكن استخدامها خارج الكتلة

لنرَ ماذا يقول المترجم لو حاولنا استخدام bonus خارج كتلتها:

block_error.cpp
#include <iostream>
using namespace std;

int main() {
    int coins = 5;
    {
        int bonus = 10;
        coins = coins + bonus;
    }
    cout << bonus << endl;
    return 0;
}
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:10:13: error: ‘bonus’ was not declared in this scope
   10 |     cout << bonus << endl;
      |             ^~~~~

فكرة «أين يعيش المتغير؟» تسمى النطاق (scope)، وسنخصص لها درسًا كاملًا لاحقًا. تكفيك الآن القاعدة: المتغير يعيش داخل أقرب كتلة تحيط به.

توقّع قبل أن تشغّل
block_quiz.cpp
int n = 1;
{
    n = n + 5;
    int m = 100;
}
cout << n << endl;

ما الذي سيطبعه هذا الكود؟

6

الكتلة تستطيع قراءة المتغيرات التي قبلها وتعديلها، فصارت n تساوي 6. أما m فتُنشأ داخل الكتلة وتختفي عند إغلاقها، لكننا لم نستخدمها خارجها فلا مشكلة.

التدفق المتسلسل: سطر بعد سطر

الوضع الافتراضي في أي برنامج أن تُنفَّذ الجمل واحدة بعد الأخرى من الأعلى إلى الأسفل، وتحتفظ كل جملة بنتائج التي قبلها. هذا يسمى التدفق المتسلسل (sequential flow).

لنفحص برنامجًا صغيرًا عن لاعب في لعبة، ونراقب كيف تتغير قيم المتغيرات مع كل خطوة. اضغط «التالي» وتابع:

تتبّع التنفيذ خطوة بخطوة
1int health = 100;
2int shield = 30;
3health = health - 20;
4shield = shield + 10;
5int total = health + shield;
6cout << "Total: " << total << endl;
المتغيرات
الناتج حتى الآن
توقّع قبل أن تشغّل
order_quiz.cpp
int x = 4;
x = x * 3;
x = x - 2;
cout << x << endl;

ما الذي سيطبعه هذا الكود؟

10

تتبّع القيمة سطرًا بسطر: تبدأ x بـ 4، ثم تصير 4 × 3 = 12، ثم 12 - 2 = 10. كل سطر يعمل على القيمة التي تركها السطر السابق.

الترتيب يغيّر النتيجة: لو كانت x = 5 ثم ضاعفتها ثم أضفت 1 تحصل على 11، ولو أضفت 1 ثم ضاعفت تحصل على 12. الحاسوب لا يعرف ما قصدته، بل ما كتبته فقط.

خريطة التحكم: ثلاثة أشكال فقط

مهما بلغ حجم البرنامج، يمكن بناؤه من ثلاثة أشكال لتدفق التنفيذ. تعالَ نرسمها كمخططات انسيابية (flowchart):

1) التسلسل: خطوات تتبع بعضها

اغسل يديك
افتح الكتاب
ابدأ الدراسة

2) الاختيار: طريق يُختار حسب سؤال

هل السماء ماطرة؟
نعم: خذ المظلة
لا: خذ النظارة

هذا هو شكل الجملة الشرطية if التي سنتعلمها لاحقًا.

3) التكرار: خطوات تُعاد ما دام الشرط صحيحًا

هل شربت أقل من 3 أكواب؟
نعم: اشرب كوبًا
لا: توقف

وهذا هو شكل الحلقات while وfor التي سنتعلمها لاحقًا.

الشكلالسؤال الذي يجيب عنهأدوات C++ له
التسلسلما الذي يأتي بعد ماذا؟الجمل المرتبة (ما نعرفه الآن)
الاختيارأي طريق أسلك؟if وelse
التكراركم مرة أعيد؟while وfor

الشرط: سؤال جوابه نعم أو لا

أي قرار في البرنامج يبدأ بسؤال إجابته true أو false، ونسميه شرطًا (condition). تذكّر أننا بنيناه من عوامل المقارنة والعوامل المنطقية:

السؤال بالكلماتالشرط في C++
هل عمرك 13 فأكثر؟age >= 13
هل وصلت للمستوى الأخير؟level == 10
هل لديك تذكرة وعمرك مناسب؟hasTicket && age >= 8
هل الحياة ليست صفرًا؟lives != 0

قبل أن تكتب أي if أو حلقة، اكتب السؤال بالعربية أولًا، ثم حوّله إلى شرط. فهذا يوفر عليك كثيرًا من الأخطاء.

أخطاء شائعة في الجمل والكتل

1) نسيان قوس الإغلاق

كل { يحتاج إلى } يقابله. إذا نسيت واحدًا يشتكي المترجم عند نهاية الملف:

brace_error.cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Level 1" << endl;
    {
        cout << "Bonus room" << endl;
    return 0;
}
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:9:2: error: expected ‘}’ at end of input
    9 | }
      |  ^
main.cpp:4:12: note: to match this ‘{’
    4 | int main() {
      |            ^

الخطأ ظهر في آخر الملف، لكن سببه قوس فُتح في الأعلى ولم يُغلق. لذلك احرص على التزحيف (إزاحة الأسطر داخل كل كتلة)، فهو يكشف لك الأقواس الناقصة بالنظر.

2) الخلط بين الكتلة والجملة الواحدة

الكتلة تُعامَل كجملة واحدة كبيرة. هذه الفكرة ستحل مشكلات كثيرة في الدروس القادمة عندما نريد تنفيذ عدة أوامر معًا بعد شرط أو داخل حلقة.

الفاصلة المنقوطة تأتي بعد الجمل، لكنها لا تأتي بعد قوس الإغلاق } الخاص بالكتلة أو الدالة.

مشروع الدرس: تقرير جولة قتال

لعبة بسيطة: بطل ووحش يتبادلان الضربات.

الفكرة

في لعبة مغامرات، يخوض البطل جولة قتال مع وحش. يبدأ البطل بـ 100 نقطة صحة، والوحش بـ 80. يوجّه البطل ضربة قوتها 40، ثم يرد الوحش بضربة قوتها 30. نريد تقريرًا يعرض الصحة المتبقية بعد الجولة.

المطلوب منك
  1. اصنع أربعة متغيرات صحيحة: heroHealth وmonsterHealth وheroDamage وmonsterDamage بالقيم المذكورة.
  2. أنقص صحة الوحش بمقدار ضربة البطل، ثم أنقص صحة البطل بمقدار ضربة الوحش (جملتان متتاليتان).
  3. اطبع عنوان التقرير ثم سطرين يعرضان صحة كل منهما.
الشكل المطلوب للناتج
=== Round Report === Hero health: 70 Monster health: 40

قبل أن تكتب: احسب بالورقة: صحة الوحش بعد الضربة = 80 - 40، وصحة البطل بعد الرد = 100 - 30. هل تطابق الناتج المطلوب؟

بعد أن تجرّب بنفسك: اعرض الحل
round_report.cpp
#include <iostream>
using namespace std;

int main() {
    int heroHealth = 100;
    int monsterHealth = 80;
    int heroDamage = 40;
    int monsterDamage = 30;

    monsterHealth = monsterHealth - heroDamage;
    heroHealth = heroHealth - monsterDamage;

    cout << "=== Round Report ===" << endl;
    cout << "Hero health:    " << heroHealth << endl;
    cout << "Monster health: " << monsterHealth << endl;
    return 0;
}

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

مصروف الأسبوع

سهل

معك 100 ريال. اشتريت وجبة خفيفة بـ 15 ريالًا، ثم مشروبًا بـ 12 ريالًا، ثم أعطتك أمك مصروفًا إضافيًا 20 ريالًا. كم بقي معك؟

المطلوب
  • اصنع متغيرًا صحيحًا money بقيمة 100.
  • نفّذ العمليات الثلاث كجمل متتالية، كل واحدة تعدّل money.
  • اطبع المتبقي بالصيغة الموضحة.
الناتج المتوقع
Money left: 93 SAR
تلميحات
  • كل عملية تُكتب هكذا: money = money - 15;
  • لا تحسب الناتج بيدك داخل الكود؛ اجعل الحاسوب يحسبه جملة بعد جملة.
نموذج الحل (بعد المحاولة)
money.cpp
// Challenge 1: shopping money
#include <iostream>
using namespace std;

int main() {
    int money = 100;

    money = money - 15;
    money = money - 12;
    money = money + 20;

    cout << "Money left: " << money << " SAR" << endl;
    return 0;
}
2

تبديل قيمتين

متوسط

لديك متغيران: a بقيمة 7 وb بقيمة 12. أنت تريد أن تتبادل القيمتان بحيث تصير a تحمل 12 وb تحمل 7. هذه مسألة كلاسيكية يقابلها كل مبرمج.

المطلوب
  • اصنع المتغيرين بقيمتيهما الأوليتين.
  • بدّل القيمتين دون كتابة الأرقام 7 و12 مرة أخرى في الجمل التي تقوم بالتبديل.
  • اطبع قيمتي a وb بعد التبديل.
الناتج المتوقع
a = 12 b = 7
تلميحات
  • لو كتبت a = b; مباشرة فستضيع القيمة القديمة لـ a.
  • احتفظ بالقيمة القديمة لـ a في متغير ثالث مؤقت اسمه temp قبل أن تغيّرها.
  • الترتيب: احفظ في temp، ثم انسخ b إلى a، ثم انسخ temp إلى b.
نموذج الحل (بعد المحاولة)
swap.cpp
// Challenge 2: swap
#include <iostream>
using namespace std;

int main() {
    int a = 7;
    int b = 12;

    int temp = a;
    a = b;
    b = temp;

    cout << "a = " << a << endl;
    cout << "b = " << b << endl;
    return 0;
}

ملخص سريع

  • الجملة (statement) هي تعليمة كاملة، ومعظمها ينتهي بفاصلة منقوطة.
  • أنواع الجمل: تصريح، وتعبير، ومركّبة (كتلة)، وفارغة.
  • الكتلة هي مجموعة جمل بين { و}، وتُعامل كجملة واحدة، والمتغير الذي ينشأ داخلها يختفي عند إغلاقها.
  • الوضع الافتراضي هو التدفق المتسلسل: الجمل تُنفَّذ بالترتيب من الأعلى إلى الأسفل.
  • ثلاثة أشكال لبناء أي برنامج: تسلسل، واختيار (if)، وتكرار (while وfor).
  • الشرط سؤال جوابه true أو false.

تحقق من فهمك

اقرأ كل عبارة ثم اختر صحيح أو خطأ. سيظهر التفسير مباشرة بعد إجابتك.

قاموس المصطلحات

المصطلحات الإنجليزية الأهم في هذا الدرس ومقابلها بالعربية:

Statementجملة

تعليمة كاملة في البرنامج، ومعظمها ينتهي بفاصلة منقوطة.

Declarationجملة تصريح

جملة تنشئ متغيرًا جديدًا.

Expression statementجملة تعبير

جملة تحسب قيمة أو تغيّرها أو تطبعها.

Blockكتلة

مجموعة جمل محصورة بين { و} وتُعامل كجملة واحدة.

Empty statementجملة فارغة

جملة مكوّنة من ; فقط ولا تفعل شيئًا.

Control flowتدفق التحكم

ترتيب تنفيذ الجمل في البرنامج.

Sequential flowتدفق متسلسل

تنفيذ الجمل واحدة بعد أخرى من الأعلى إلى الأسفل.

Selectionاختيار

اختيار طريق من عدة طرق بحسب شرط.

Repetitionتكرار

إعادة تنفيذ جمل عدة مرات.

Conditionشرط

Flowchartمخطط انسيابي

رسم يوضح خطوات البرنامج وقراراته.

Scopeنطاق

Indentationتزحيف

إزاحة أسطر الكتلة لتوضيح بنية البرنامج.
