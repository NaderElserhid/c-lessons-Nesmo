للتعلم البرمجي التفاعلي

الدرس 4

الثوابت

Constants — قيم لا تتغير ولا ينبغي لها أن تتغير

ماذا ستتعلم في هذا الدرس؟

  • تفهم الفرق بين المتغير والثابت ولماذا نحتاج الثوابت
  • تستخدم const وconstexpr وتفرّق بينهما
  • تتجنب الأرقام السحرية بإعطائها أسماء واضحة
  • تتعرف على #define وتعرف عيوبه ولماذا نتجنبه
  • تفهم القيم الحرفية ولواحقها مثل f وLL

لماذا نحتاج الثوابت؟

في الدرس السابق تعلمنا أن قيمة المتغير يمكن أن تتغير. لكن في كل برنامج قيم لا نريدها أن تتغير أبدًا: نسبة ضريبة القيمة المضافة، وعدد ثواني الساعة، وقيمة الثابت الرياضي π. هذه القيم نسمّيها ثوابت (constants).

انظر إلى الكود التالي. الرقم 0.15 يتكرر بلا اسم، ويسميه المبرمجون رقمًا سحريًا (magic number) لأن القارئ لا يعرف ما هو:

magic_number.cpp
double vatA = 120.0 * 0.15;
double vatB = 80.0 * 0.15;
cout << vatA << " " << vatB << endl;
18 12

الآن لو تغيرت النسبة، عليك أن تبحث عن كل مكان كتبت فيه 0.15 وتغيّره، وقد تنسى واحدًا فيختلف الحساب بين مكان وآخر. الحل أن نعطي القيمة اسمًا واضحًا في مكان واحد:

named_constant.cpp
const double VAT_RATE = 0.15;

double vatA = 120.0 * VAT_RATE;
double vatB = 80.0 * VAT_RATE;
cout << vatA << " " << vatB << endl;
18 12

الناتج هو نفسه، لكن الكود صار أوضح (VAT_RATE تشرح نفسها)، وأسهل في التعديل (تغيّر القيمة في سطر واحد).

الكلمة const

نضع الكلمة const قبل النوع لنجعل المتغير للقراءة فقط. بعدها يمنعنا المترجم من تغييره:

seats.cpp
#include <iostream>
using namespace std;

int main() {
    const int MAX_SEATS = 40;
    MAX_SEATS = 50;
    cout << MAX_SEATS << endl;
    return 0;
}
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:6:15: error: assignment of read-only variable ‘MAX_SEATS’
    6 |     MAX_SEATS = 50;
      |     ~~~~~~~~~~^~~~

الرسالة تقول بوضوح إننا نحاول الإسناد إلى متغير للقراءة فقط. أي أن const يحميك من أخطائك أنت.

القاعدة الثانية: لا بد من قيمة عند التصريح

بما أن الثابت لا يتغير، فلا معنى لأن نصرّح عنه دون قيمة ثم نعطيه قيمة لاحقًا:

no_init.cpp
#include <iostream>
using namespace std;

int main() {
    const int LIMIT;
    cout << LIMIT << endl;
    return 0;
}
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:5:15: error: uninitialized ‘const LIMIT’ [-fpermissive]
    5 |     const int LIMIT;
      |               ^~~~~

عرف التسمية: يكتب المبرمجون أسماء الثوابت غالبًا بأحرف كبيرة تفصل بينها شرطة سفلية مثل MAX_SEATS وVAT_RATE، ليعرف القارئ من النظرة الأولى أنها ثوابت. هذا عرف شائع وليس قاعدة تفرضها اللغة.

constexpr: ثوابت تُحسب أثناء الترجمة

الكلمة constexpr تعني أن قيمة الثابت معروفة وقت الترجمة (compile time)، أي قبل أن يبدأ البرنامج العمل. وهذا يسمح بالبناء على ثوابت أخرى:

constexpr_demo.cpp
constexpr int SECONDS_PER_MINUTE = 60;
constexpr int SECONDS_PER_HOUR = SECONDS_PER_MINUTE * 60;
constexpr int SECONDS_PER_DAY = SECONDS_PER_HOUR * 24;

cout << "One hour = " << SECONDS_PER_HOUR << " seconds" << endl;
cout << "One day  = " << SECONDS_PER_DAY << " seconds" << endl;
One hour = 3600 seconds One day = 86400 seconds

المترجم حسب كل الأرقام بنفسه قبل التشغيل. لكن إذا اعتمدت قيمة الثابت على شيء لا يُعرف إلا أثناء التشغيل، فلن يقبل ذلك:

constexpr_error.cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    constexpr int DOUBLE_N = n * 2;
    cout << DOUBLE_N << endl;
    return 0;
}
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:6:34: error: the value of ‘n’ is not usable in a constant expression
    6 |     constexpr int DOUBLE_N = n * 2;
      |                                  ^
main.cpp:5:9: note: ‘int n’ is not const
    5 |     int n = 5;
      |         ^

المتغير n ليس ثابتًا، فقيمته مجهولة للمترجم. أما const العادية فتقبل قيمة تُحسب أثناء التشغيل:

const_runtime.cpp
int n = 5;
const int DOUBLE_N = n * 2;
cout << DOUBLE_N << endl;
10
الكلمةمتى تُعرف القيمة؟متى نستخدمها؟
constقد تُعرف عند التشغيلقيمة لا نريد تغييرها بعد تحديدها
constexprيجب أن تُعرف عند الترجمةثوابت حقيقية مثل π وعدد ثواني اليوم

القاعدة العملية: اجعل الثوابت المعروفة سلفًا constexpr، واستخدم const لما سواها.

الطريقة القديمة: #define

قبل ظهور const وconstexpr كان المبرمجون يستخدمون التوجيه #define. ستراه كثيرًا في الأكواد القديمة، لذلك يجب أن تعرفه وتعرف عيوبه:

define_demo.cpp
#include <iostream>
using namespace std;

#define MAX_SCORE 100
#define SQUARE(x) x * x

int main() {
    cout << MAX_SCORE << endl;
    cout << SQUARE(2 + 3) << endl;
    return 0;
}
100 11

انتبه إلى الناتج الثاني! توقعنا 25 لأن (2+3) تربيعها 25، لكن حصلنا على 11.

السبب أن #define ليس متغيرًا ولا دالة، بل استبدال نصي يجريه المعالج المسبق قبل الترجمة. فصار التعبير 2 + 3 * 2 + 3، والضرب يسبق الجمع فيعطي 11. المعالج المسبق لا يضيف أقواسًا ولا يتحقق من الأنواع.

الجانب#defineconst / constexpr
النوعبلا نوع (نص فقط)له نوع يتحقق منه المترجم
النطاقيسري من مكان تعريفه حتى نهاية الملفيلتزم بنطاق المتغيرات العادية
نهاية السطرلا تنتهي بفاصلة منقوطةتنتهي بفاصلة منقوطة
الخطأ الأشهرنتائج غريبة كمثال التربيعأخطاء واضحة يكتشفها المترجم

البديل الحديث للمثال السابق هو دالة constexpr (ستدرس الدوال لاحقًا):

square_fn.cpp
#include <iostream>
using namespace std;

constexpr int square(int x) { return x * x; }

int main() {
    cout << square(2 + 3) << endl;
    return 0;
}
25

في كود C++ الجديد فضّل دائمًا const وconstexpr على #define.

القيم الحرفية ولواحقها

القيمة المكتوبة مباشرة في الكود مثل 42 أو 2.5 أو 'x' أو "Hi" أو true تسمى قيمة حرفية (literal). وهي أيضًا ثوابت بطبيعتها، فلا يمكنك أن تكتب 5 = x;. ولكل قيمة حرفية نوع يحدده شكلها:

الشكلنوعهامثال
عدد بلا كسرint42
عدد بكسر عشريdouble2.5
عدد بكسر ومعه ffloat2.5f
عدد ومعه LLlong long9000000000LL
حرف بين علامتين مفردتينchar'x'
نص بين علامتين مزدوجتيننص حرفي"Hi"

لنتحقق من نوع العدد العشري ومن أثر شكل القيمة الحرفية في القسمة:

literals.cpp
cout << sizeof(2.5) << " " << sizeof(2.5f) << endl;
cout << 7 / 2 << " " << 7 / 2.0 << endl;
8 4 3 3.5

السطر الأول يؤكد أن 2.5 تشغل 8 بايت (double) بينما 2.5f تشغل 4 بايت (float). والسطر الثاني يذكّرنا بقسمة الأعداد الصحيحة: 7 / 2 تعطي 3، أما 7 / 2.0 فتعطي 3.5.

مختبر تفاعلي: فاتورة بثابت واحد

هذا المحاكي يستخدم ثابتًا واحدًا هو نسبة ضريبة القيمة المضافة VAT_RATE = 0.15 (15%). غيّر السعر والكمية وشاهد كيف يستخدم الكود الثابت نفسه في كل الحسابات:

مشروع الدرس: فاتورة المطعم

نتعلم كيف يجعل الثابت الحساب واضحًا وسهل التعديل.

الفكرة

مطعم وجبات سريعة يحتاج برنامجًا يحسب فاتورة طاولة طلبت وجبة برغر وبطاطس وعصيرًا. نسبة الضريبة 15% تُضاف إلى المجموع، وقد تتغير مستقبلًا، لذلك لا نريدها مكتوبة في أكثر من مكان.

المطلوب منك
  1. عرّف الثابت VAT_RATE بالقيمة 0.15.
  2. عرّف ثلاثة متغيرات عشرية لأسعار الأصناف: البرغر 32.0، والبطاطس 12.0، والعصير 9.5.
  3. احسب المجموع قبل الضريبة، ثم مبلغ الضريبة، ثم الإجمالي النهائي، كل منها في متغير.
  4. اطبع الأسطر الثلاثة الموضحة أدناه.
الشكل المطلوب للناتج
Subtotal: 53.5 SAR VAT (15%): 8.025 SAR Total: 61.525 SAR
بعد أن تجرّب بنفسك: اعرض الحل
restaurant_bill.cpp
#include <iostream>
using namespace std;

int main() {
    const double VAT_RATE = 0.15;

    double burger = 32.0;
    double fries = 12.0;
    double juice = 9.5;

    double subtotal = burger + fries + juice;
    double vat = subtotal * VAT_RATE;
    double total = subtotal + vat;

    cout << "Subtotal:  " << subtotal << " SAR" << endl;
    cout << "VAT (15%): " << vat << " SAR" << endl;
    cout << "Total:     " << total << " SAR" << endl;
    return 0;
}

لو قررت الدولة تغيير النسبة، فستعدّل سطرًا واحدًا فقط في بداية البرنامج بدل البحث عن الرقم في كل مكان.

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

دائرة بثابت π

سهل

نريد حساب مساحة دائرة ومحيطها لنصف قطر معروف. القيمة π ثابت رياضي لا ينبغي أن تتغير، فاجعلها ثابتًا بدل كتابتها في كل مكان.

المطلوب
  • عرّف ثابتًا PI بقيمة 3.14159.
  • عرّف متغيرًا عشريًا radius بقيمة 7.
  • احسب المساحة PI * radius * radius والمحيط 2 * PI * radius في متغيرين.
  • اطبع النتيجتين كما في الناتج المتوقع.
الناتج المتوقع
Area: 153.938 Circumference: 43.9823
تلميحات
  • ضع كلمة const قبل double PI.
  • لا تكتب الرقم 3.14159 إلا مرة واحدة في البرنامج كله.
نموذج الحل (بعد المحاولة)
circle.cpp
// Challenge 1: circle
#include <iostream>
using namespace std;

int main() {
    const double PI = 3.14159;
    double radius = 7;

    double area = PI * radius * radius;
    double circumference = 2 * PI * radius;

    cout << "Area: " << area << endl;
    cout << "Circumference: " << circumference << endl;
    return 0;
}
2

كم ثانية في عدة أيام؟

متوسط

نريد تحويل عدد من الأيام إلى ثوانٍ. ابنِ الثوابت بعضها على بعض باستخدام constexpr، ثم استخدم الثابت الأخير في الحساب.

المطلوب
  • عرّف ثوابت constexpr لعدد ثواني الدقيقة ودقائق الساعة وساعات اليوم.
  • عرّف ثابتًا رابعًا SECONDS_PER_DAY يضرب الثلاثة الأولى.
  • عرّف days بقيمة 3، وخزّن الناتج في متغير من النوع long long.
  • اطبع الجملة كما في الناتج المتوقع.
الناتج المتوقع
3 days = 259200 seconds
تلميحات
  • constexpr int SECONDS_PER_DAY = SECONDS_PER_MINUTE * MINUTES_PER_HOUR * HOURS_PER_DAY;
  • حوّل days إلى long long قبل الضرب باستخدام static_cast<long long>.
نموذج الحل (بعد المحاولة)
days_to_seconds.cpp
// Challenge 2: days to seconds
#include <iostream>
using namespace std;

int main() {
    constexpr int SECONDS_PER_MINUTE = 60;
    constexpr int MINUTES_PER_HOUR = 60;
    constexpr int HOURS_PER_DAY = 24;
    constexpr int SECONDS_PER_DAY = SECONDS_PER_MINUTE * MINUTES_PER_HOUR * HOURS_PER_DAY;

    int days = 3;
    long long seconds = static_cast<long long>(days) * SECONDS_PER_DAY;

    cout << days << " days = " << seconds << " seconds" << endl;
    return 0;
}

ملخص سريع

  • الثابت قيمة لا تتغير بعد تعريفها، ونعرّفه بـ const أو constexpr.
  • constexpr قيمته معروفة وقت الترجمة، فيصلح مثلًا لحجم مصفوفة.
  • الأرقام السحرية تُستبدل بثوابت لها أسماء توضح معناها.
  • نتجنب #define لأنه نص يُستبدل بلا نوع ولا حماية.
  • اللواحق مثل f وLL تحدد نوع القيمة الحرفية.

قاموس المصطلحات

المصطلحات الإنجليزية الأهم في هذا الدرس ومقابلها بالعربية:

Constantثابت

قيمة لا تتغير أثناء تشغيل البرنامج.

constللقراءة فقط

كلمة تجعل المتغير غير قابل للتغيير بعد تهيئته.

constexprثابت وقت الترجمة

ثابت تُحسب قيمته أثناء الترجمة قبل تشغيل البرنامج.

Literalقيمة حرفية

قيمة مكتوبة مباشرة في الكود مثل 42 أو "Hi".

Magic numberرقم سحري

رقم يظهر في الكود دون اسم يوضح معناه.

Macroماكرو

اسم يستبدله المعالج المسبق بنص قبل الترجمة، مثل #define.

Compile timeوقت الترجمة

المرحلة التي يفحص فيها المترجم الكود قبل التشغيل.

Run timeوقت التشغيل

المرحلة التي ينفّذ فيها الحاسوب البرنامج فعليًا.

Read-onlyللقراءة فقط

قيمة يمكن قراءتها ولا يمكن تغييرها.

Naming conventionعرف التسمية

اتفاق على شكل الأسماء، مثل كتابة الثوابت بأحرف كبيرة.

Suffixلاحقة

حرف يُضاف لآخر الرقم لتحديد نوعه، مثل f وLL.
