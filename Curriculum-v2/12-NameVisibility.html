الدرس 12

ظهور الأسماء (النطاق)

Name Visibility — أين يعيش كل متغير ومن يستطيع رؤيته

ماذا ستتعلم في هذا الدرس؟

  • تفهم النطاق وتحدد أين يُرى كل اسم في البرنامج
  • تفرّق بين المتغيرات المحلية والعامة وتعرف متى تتجنب العامة
  • تفهم التظليل وتتجنب الأخطاء الناتجة عنه
  • تعرف عمر المتغير وتستخدم static عند الحاجة
  • تبني برنامجًا يوزّع الأسماء على نطاقاتها بشكل صحيح

من يرى من؟

في مدرستك، السبورة يراها كل من في الفصل، لكن دفتر زميلك داخل حقيبته لا يراه أحد غيره. وكذلك الأسماء في البرنامج: لكل اسم منطقة يُرى فيها، وخارجها يكون كأنه غير موجود. هذه المنطقة تُسمى النطاق (scope)، ودرسنا اليوم يُسمى «ظهور الأسماء» (name visibility).

القاعدة الذهبية: الاسم يُرى من لحظة التصريح عنه حتى نهاية الكتلة { } التي صُرّح عنه داخلها. إن كان خارج كل الدوال فهو يُرى حتى نهاية الملف.

المتغيرات المحلية: كل دالة لها عالمها

المتغير الذي تصرّح عنه داخل دالة يسمى متغيرًا محليًا (local variable). لا يراه إلا كود تلك الدالة، ولذلك يمكن لدالتين أن تستعملا الاسم نفسه دون أي تعارض:

separate_locals.cpp
#include <iostream>
using namespace std;

void first() {
    int count = 10;
    cout << "first: " << count << endl;
}

void second() {
    int count = 99;
    cout << "second: " << count << endl;
}

int main() {
    first();
    second();
    return 0;
}
first: 10 second: 99

المتغيران count منفصلان تمامًا، كأنهما في غرفتين مختلفتين. أما محاولة قراءة متغير محلي من دالة أخرى فيرفضها المترجم:

local_error.cpp
#include <iostream>
using namespace std;

void secret() {
    int code = 1234;
    cout << "Secret code set: " << code << endl;
}

int main() {
    secret();
    cout << code << endl;
    return 0;
}
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:11:13: error: ‘code’ was not declared in this scope
   11 |     cout << code << endl;
      |             ^~~~

الأشعة السينية للنطاق

هذا برنامج فيه خمسة أسماء في مواضع مختلفة: g عام، وs داخل دالة، وa داخل main، وb داخل كتلة، وi في رأس حلقة. اضغط على اسم لترى الأسطر التي يُرى فيها (الأسطر المضيئة):

scope_xray.cpp
#include <iostream>using namespace std; int g = 1; void show() {    int s = 2;    cout << g + s << endl;} int main() {    int a = 10;    {        int b = 20;        cout << a + b << endl;    }    for (int i = 0; i < 2; i++) {        cout << a + i << endl;    }    show();    return 0;}
اختر اسمًا من الأزرار أعلاه...

ولكي تتأكد أن البرنامج يعمل فعلًا، هذا ناتجه (الأعداد: a + b ثم a + i مرتين ثم g + s):

30 10 11 3

المتغيرات العامة

المتغير الذي يُصرَّح عنه خارج كل الدوال يسمى عامًّا (global variable)، ويراه كل ما يأتي بعده في الملف:

global_score.cpp
#include <iostream>
using namespace std;

int score = 0;

void addPoints(int points) {
    score = score + points;
}

int main() {
    cout << "Start: " << score << endl;
    addPoints(10);
    addPoints(25);
    cout << "Now: " << score << endl;
    return 0;
}
Start: 0 Now: 35

لماذا يتجنبها المحترفون؟ لأن أي دالة تستطيع أن تغيّر المتغير العام دون علمك. وعندما تكبر البرامج يصبح الكشف عن «من غيّر القيمة؟» كابوسًا. الأفضل أن تمرّر القيم عبر المعاملات وتستقبل النتائج عبر return. أما الثوابت العامة (const) فلا مشكلة فيها لأن قيمتها لا تتغير.

معلومة غريبة: القيمة الافتراضية

المتغيرات العامة غير المهيّأة تبدأ بالقيمة صفر تلقائيًا. أما المتغيرات المحلية غير المهيّأة فتحمل قيمة عشوائية لا يُعتمد عليها:

global_default.cpp
#include <iostream>
using namespace std;

int globalNumber;

int main() {
    cout << "global: " << globalNumber << endl;
    return 0;
}
global: 0

التخفّي: عندما يحجب اسمٌ اسمًا

ماذا لو صرّحت داخل كتلة عن متغير له اسم متغير خارجي؟ تنشأ ظاهرة تسمى التظليل (shadowing): المتغير الداخلي «يحجب» الخارجي داخل الكتلة، ثم يعود الخارجي للظهور بعد انتهائها:

shadowing.cpp
int x = 5;
{
    int x = 99;
    cout << "inner x: " << x << endl;
}
cout << "outer x: " << x << endl;
inner x: 99 outer x: 5
توقّع قبل أن تشغّل
shadow_quiz.cpp
int x = 5;
{
    int x = 99;
    x = x + 1;
}
cout << x << endl;

ما الذي سيطبعه هذا الكود؟

5

داخل الكتلة نشأ متغير جديد اسمه x يخفي الأصلي. زدناه إلى 100، لكنه اختفى عند إغلاق الكتلة. أما x الخارجية فلم يلمسها أحد، فبقيت 5.

وإذا حجب متغير محلي متغيرًا عامًا بالاسم نفسه، فيمكنك الوصول للعام بالعامل :: قبل الاسم:

scope_operator.cpp
#include <iostream>
using namespace std;

int score = 100;

void show() {
    int score = 5;
    cout << "local: " << score << ", global: " << ::score << endl;
}

int main() {
    show();
    return 0;
}
local: 5, global: 100

التظليل مسموح لكنه يسبب أخطاء مربكة لأن القارئ يظن أنه يعدّل المتغير الخارجي. تجنّبه بإعطاء المتغيرات أسماء مختلفة.

الخطأ الأشهر مع التظليل

نريد جمع الأعداد 1 و2 و3 في total، لكن ارتكبنا خطأ دقيقًا. جرّب أن تكتشفه:

توقّع قبل أن تشغّل
shadow_loop_bug.cpp
int total = 0;
for (int i = 1; i <= 3; i++) {
    int total = i;
}
cout << total << endl;

ما الذي سيطبعه هذا الكود؟ (المطلوب أصلًا كان جمع الأعداد)

0

الكلمة int داخل الحلقة صنعت متغيرًا جديدًا اسمه total في كل دورة، فاختفى مع نهايتها، وبقيت total الخارجية على 0. لو أردنا تعديل الأصل لكتبنا total = total + i; بلا كلمة int.

عمر المتغير: يُولد ويموت

المتغير المحلي يُنشأ عند الوصول إلى سطر تصريحه، ويُدمَّر عند الخروج من كتلته. ولذلك فكل استدعاء للدالة يبدأ بمتغيراتها من جديد:

fresh_local.cpp
#include <iostream>
using namespace std;

void tick() {
    int count = 0;
    count++;
    cout << count << " ";
}

int main() {
    tick();
    tick();
    tick();
    cout << endl;
    return 0;
}
1 1 1

في كل استدعاء وُلد count جديد بقيمة 0، فزاد إلى 1 ثم مات. وإذا أردت متغيرًا محليًا يتذكر قيمته بين الاستدعاءات فاكتب قبله الكلمة static، فيُنشأ مرة واحدة فقط:

static_local.cpp
#include <iostream>
using namespace std;

void tick() {
    static int count = 0;
    count++;
    cout << count << " ";
}

int main() {
    tick();
    tick();
    tick();
    cout << endl;
    return 0;
}
1 2 3

هو ما زال محليًا (لا يراه إلا كود tick)، لكن عمره صار أطول من الاستدعاء الواحد. وهذا بديل آمن للمتغير العام عندما تحتاج دالة إلى ذاكرة.

أخطاء النطاق الشائعة

1) تصريح الاسم مرتين في النطاق نفسه

redeclare_error.cpp
#include <iostream>
using namespace std;

int main() {
    int lives = 3;
    int lives = 5;
    cout << lives << endl;
    return 0;
}
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:6:9: error: redeclaration of ‘int lives’
    6 |     int lives = 5;
      |         ^~~~~
main.cpp:5:9: note: ‘int lives’ previously declared here
    5 |     int lives = 3;
      |         ^~~~~

التظليل يكون بين نطاقين مختلفين (داخلي وخارجي). أما في النطاق الواحد فلا يسمح المترجم بالاسم نفسه مرتين.

2) استخدام اسم قبل تصريحه

الاسم يُرى بعد التصريح فقط. لا يمكنك قراءة int total = total + 1; داخل نطاق لم تُنشئ فيه total قبلها.

3) الاعتماد على متغير عام للتواصل بين الدوال

جرّب أن تستبدله بمعامل ونتيجة return، ستجد أن الكود يصير أوضح وأسهل في الاختبار.

مشروع الدرس: جامع العملات

لعبة صغيرة تستخدم النطاقات بشكل صحيح

ثابت عام، ومتغيرات محلية، ودالة تعدّل الأصل.

الفكرة

لاعب في المستوى الثاني من لعبة يجمع عملات ويصطدم بعقبات. يبدأ بثلاث حيوات. كل عملة تعطيه نقاطًا بحسب المستوى، وكل اصطدام يُنقص حياة. تنتهي اللعبة عندما تنفد الحيوات.

المطلوب منك
  1. عرّف ثابتًا عامًا MAX_LIVES بقيمة 3 (الثوابت العامة آمنة).
  2. اكتب دالة levelBonus(level) تعيد level * 10، ودالة hit(lives) تُنقص الحياة بمقدار 1 في المتغير الأصلي (فكّر: أي نوع تمرير تحتاج؟).
  3. في main اجعل level وlives وscore متغيرات محلية.
  4. اقرأ أحداث اللعبة حرفًا حرفًا: الحرف c يعني عملة، والحرف h يعني اصطدامًا. استمر في القراءة ما دامت الحيوات أكبر من صفر.
  5. اطبع بعد كل حدث Coin! Score: ... أو Hit! Lives: ...، وفي النهاية Game over. Final score: ...
مثال على التشغيل
c c h c h h c
Coin! Score: 20 Coin! Score: 40 Hit! Lives: 2 Coin! Score: 60 Hit! Lives: 1 Hit! Lives: 0 Game over. Final score: 60

لاحظ أن آخر حدث (c) لم يُقرأ لأن الحيوات نفدت قبل الوصول إليه.

قبل أن تكتب: أين يعيش كل اسم؟ MAX_LIVES عام. lives في main. فكيف تستطيع hit أن تغيّر lives دون أن تراه؟ الجواب في التمرير بالمرجع.

بعد أن تجرّب بنفسك: اعرض الحل
coin_game.cpp
#include <iostream>
using namespace std;

const int MAX_LIVES = 3;

int levelBonus(int level) {
    return level * 10;
}

void hit(int& lives) {
    lives = lives - 1;
}

int main() {
    int level = 2;
    int lives = MAX_LIVES;
    int score = 0;
    char event;

    while (lives > 0 && cin >> event) {
        if (event == 'c') {
            score = score + levelBonus(level);
            cout << "Coin! Score: " << score << endl;
        } else if (event == 'h') {
            hit(lives);
            cout << "Hit! Lives: " << lives << endl;
        }
    }
    cout << "Game over. Final score: " << score << endl;
    return 0;
}

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

أصلح مجموع الأعداد الزوجية

سهل

كتب زميلك برنامجًا يجمع الأعداد 2 و4 و6 و8 (أي i * 2 لـ i من 1 إلى 4)، لكنه يطبع صفرًا بدل 20! هذا كوده:

buggy_sum.cpp
int main() {
    int sum = 0;
    for (int i = 1; i <= 4; i++) {
        int sum = i * 2;
    }
    cout << "Sum: " << sum << endl;
    return 0;
}

المطلوب
  • ابحث عن سبب ظهور الصفر (تلميح: كم متغيرًا اسمه sum في البرنامج؟).
  • أصلح الكود ليجمع القيم فعلًا ويطبع Sum: 20.
  • اشرح بجملة في تعليق ما كان الخطأ.
الناتج المتوقع
Sum: 20
تلميحات
  • الكلمة int داخل الحلقة صنعت متغيرًا جديدًا يحجب sum الخارجي.
  • احذف int واجعل السطر sum = sum + i * 2; ليتغير المتغير الأصلي.
نموذج الحل (بعد المحاولة)
fixed_sum.cpp
// Challenge 1: fixed version
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 4; i++) {
        sum = sum + i * 2;
    }
    cout << "Sum: " << sum << endl;
    return 0;
}
2

مولّد الأرقام التسلسلية

متوسط

أنت تبرمج نظام تذاكر. كل مرة تُستدعى الدالة nextId() يجب أن تعيد رقمًا جديدًا يزيد عن السابق: 1 ثم 2 ثم 3. الدالة يجب أن «تتذكر» آخر رقم أعطته.

المطلوب
  • اكتب الدالة int nextId() دون استخدام متغير عام.
  • في main استدعِها ثلاث مرات واطبع النتائج في سطر واحد تفصل بينها مسافات.
الناتج المتوقع
1 2 3
تلميحات
  • متغير محلي عادي سيبدأ من جديد في كل استدعاء، فتحتاج إلى متغير يحتفظ بقيمته.
  • عرّف داخل الدالة static int id = 0; ثم زده بمقدار 1 وأعده.
  • تذكّر أن سطر static يُنفَّذ مرة واحدة فقط عند أول استدعاء.
نموذج الحل (بعد المحاولة)
next_id.cpp
// Challenge 2: ID generator
#include <iostream>
using namespace std;

int nextId() {
    static int id = 0;
    id++;
    return id;
}

int main() {
    cout << nextId() << " " << nextId() << " " << nextId() << endl;
    return 0;
}

ملخص سريع

  • النطاق هو المنطقة التي يُرى فيها الاسم: من تصريحه حتى نهاية الكتلة التي صُرّح عنه داخلها.
  • المتغير المحلي لا يراه إلا كود دالته أو كتلته، ويُدمَّر عند الخروج منها.
  • المتغير العام يُصرَّح عنه خارج كل الدوال ويراه كل ما بعده، لكننا نتجنبه ونفضّل المعاملات وreturn، أما الثوابت العامة فمقبولة.
  • التظليل: متغير داخلي بالاسم نفسه يحجب الخارجي. لا يسمح بتكرار الاسم في النطاق الواحد.
  • المتغيرات العامة تبدأ بصفر، أما المحلية غير المهيّأة فعشوائية.
  • static داخل دالة تجعل المتغير يحتفظ بقيمته بين الاستدعاءات.
