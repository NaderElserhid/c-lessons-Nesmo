مسألة A. Exponents (الرفع السريع للأس)

شرح المسألة:
المطلوب هو حساب النتيجة لـ AB % M. بما أن الأس B يمكن أن يصل إلى مليون (106)، فإن ضرب الرقم في نفسه مليون مره باستخدام حلقة تكرار عادية يعتبر حلاً جيداً وسريعاً بما يكفي لهذه المسألة المحددة.
ولكن، الطريقة الاحترافية والتي تعمل حتى لو كان الأس بمليارات (1018) هي خوارزمية الرفع السريع للأس (Binary Exponentiation). تعتمد الفكرة على أنه بدلاً من ضرب الأساس في نفسه B مرة، نقوم بتقسيم الأس على 2 وتربيع الأساس في كل خطوة.

1. الرسوم التفاعلية (المحاكي)

أدخل قيم A و B و M واضغط على "ابدأ المحاكاة"، ثم استخدم زر "الخطوة التالية" لترى كيف تتغير المتغيرات برمجياً:

الأساس (A) الحالي-
الأس (B) الحالي-
النتيجة (Res)-
اضغط على "ابدأ المحاكاة" لتهيئة المتغيرات...

2. الكود البرمجي (C++) بأبسط صيغة

#include <iostream>
using namespace std;

int main() {
    long long A, B, M;
    cin >> A >> B >> M;
    
    // تهيئة النتيجة
    long long res = 1 % M;
    A %= M;
    
    // خوارزمية الرفع السريع
    while (B > 0) {
        // إذا كان الأس فردياً، اضرب النتيجة في الأساس
        if (B % 2 != 0) res = (res * A) % M;
        
        // ربع الأساس للمرحلة القادمة
        A = (A * A) % M;
        
        // اقسم الأس على 2
        B /= 2;
    }
    
    cout << res << "\n";
    return 0;
}
