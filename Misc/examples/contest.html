مرحباً بكم يا أبطال البرمجة! في هذا التحدي، سنستخدم كل ما تعلمناه (Sorting, Greedy, Maps, Binary Search, Modular Arithmetic) لفتح البوابة العظيمة. المسائل الثلاث مترابطة؛ مخرجات المسألة الأولى ستساعدك في فهم الثانية، والثانية تقودك للثالثة. انتبه جيداً للتعقيد الزمني (Time Complexity)!

المسألة الأولى: ثروة التوائم (تجميع الطاقة)

Sorting Greedy Algorithms Time Complexity O(N log N)

القصة (مستوحاة من Twins): وجد توأمان صندوقاً يحوي N من العملات السحرية، لكل عملة قيمة طاقة معينة. التوأم الأول (الجشع) يريد أن يأخذ أقل عدد ممكن من العملات، بحيث يكون مجموع طاقة عملاته أكبر تماماً من مجموع طاقة العملات المتبقية لأخيه.

المطلوب: اكتب برنامجاً يستقبل عدد العملات N، ثم قيم هذه العملات. اطبع أقل عدد من العملات يجب أن يأخذها التوأم الأول.

تلميح: هذه مشكلة تعتمد على الخوارزمية الجشعة (Greedy). أفضل طريقة لجمع أكبر قيمة بأقل عدد من العملات هي ترتيب (Sorting) المصفوفة تنازلياً. ثم استمر في أخذ العملات من الأكبر إلى الأصغر حتى يصبح مجموعك أكبر من نصف المجموع الكلي للعملات. 
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

using namespace std;

int main() {
    int n; cin >> n;
    vector<int> coins(n);
    int total_sum = 0;
    
    for(int i = 0; i < n; i++) {
        cin >> coins[i];
        total_sum += coins[i];
    }
    
    // الترتيب تنازلياً
    sort(coins.rbegin(), coins.rend());
    
    int my_sum = 0, count = 0;
    for(int i = 0; i < n; i++) {
        my_sum += coins[i];
        count++;
        // الشرط الجشع
        if(my_sum > total_sum - my_sum) {
            break;
        }
    }
    
    cout << count << endl;
    return 0;
}

المسألة الثانية: أزواج الطاقة المفقودة

Sets / Maps Binary Search Time Complexity O(N) or O(N log N)

القصة (مستوحاة من Sum of Two Values): العملات المتبقية مع التوأم الثاني تشكل مصفوفة ضخمة جداً (قد تصل إلى 200,000 عملة). لفتح القفل الأول للبوابة، يجب عليه العثور على عملتين فقط من عملاته يكون مجموع طاقتهما مساوياً للرقم السري X. الحل البطيء سيفشل (Time Limit Exceeded).

المطلوب: ابحث في مصفوفة العملات عما إذا كان يوجد رقمان يجمعان للقيمة X. اطبع "YES" أو "NO".

تلميح: لا تستخدم حلقتين متداخلتين (Nested Loops) لأن التعقيد سيكون O(N^2). بدلاً من ذلك، استخدم std::map أو std::set لتخزين القيم التي مررت عليها والبحث عن القيمة المكملة X - current_value في وقت O(log N). أو رتب المصفوفة واستخدم مؤشرين (Two Pointers) من البداية والنهاية أو البحث الثنائي. 
#include <iostream>
#include <vector>
#include <map>

using namespace std;

int main() {
    int n, target; 
    cin >> n >> target;
    vector<int> a(n);
    map<int, bool> seen; // لاستخدام الخرائط للبحث السريع
    
    bool found = false;
    for(int i = 0; i < n; i++) {
        cin >> a[i];
        int complement = target - a[i];
        
        // التحقق مما إذا كانت القيمة المكملة موجودة مسبقاً
        if(seen.count(complement)) {
            found = true;
            break;
        }
        seen[a[i]] = true; // حفظ القيمة الحالية
    }
    
    if(found) cout << "YES\n";
    else cout << "NO\n";
    
    return 0;
}

المسألة الثالثة: شيفرة الدومينو والحساب المعياري

Modular Arithmetic Domino Piling Simulation

القصة (مستوحاة من Domino Piling و Modular Exponentiation): للعبور من البوابة العظيمة، وجد التوأم لوحة حجرية بأبعاد M × N. يجب تغطيتها بالكامل بأحجار دومينو من حجم 2 × 1. ليكن الحد الأقصى لعدد أحجار الدومينو التي يمكن وضعها هو D.

البوابة تطلب إدخال كلمة السر النهائية، وهي عبارة عن ناتج المعادلة: (D ^ K) موديلو (10^9 + 7). حيث K هو رقم ضخم جداً يُعطى كمدخل.

المطلوب: احسب أولاً عدد الدومينو D (وهو مساحة اللوحة مقسومة على 2). ثم استخدم الخوارزمية السريعة لحساب الأس مع باقي القسمة.

تلميح:
1. إيجاد D: مساحة اللوحة هي M * N، وكل حجر دومينو يغطي مربعين، لذا D = (M * N) / 2.
2. لحساب الأسس الكبيرة مع باقي القسمة (Modulo)، يجب كتابة دالة (Fast Power) تعتمد على التقسيم الثنائي (Bitwise Shift أو القسمة على 2) ليكون التعقيد O(log K). تذكر تطبيق % MOD في كل خطوة ضرب لتجنب الـ Overflow. 
#include <iostream>
using namespace std;

const long long MOD = 1e9 + 7;

// دالة الرفع السريع للأس (Modular Exponentiation)
long long fastPower(long long base, long long exp) {
    long long res = 1;
    base = base % MOD;
    
    while (exp > 0) {
        // إذا كان الأس فردياً، نضرب الأساس في النتيجة
        if (exp % 2 == 1) res = (res * base) % MOD;
        // نربع الأساس ونقسم الأس على 2
        base = (base * base) % MOD;
        exp /= 2;
    }
    return res;
}

int main() {
    long long M, N, K;
    cin >> M >> N >> K;
    
    // حساب أقصى عدد من أحجار الدومينو
    long long D = (M * N) / 2;
    
    // حساب كلمة السر النهائية
    long long password = fastPower(D, K);
    
    cout << password << endl;
    return 0;
}
