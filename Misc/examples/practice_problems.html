المسألة 1: البحث عن الزوج المثالي (Sum of Two Values)

متوسط

لديك مصفوفة تحتوي على $N$ عدد صحيح، ولديك رقم مستهدف $X$. مهمتك هي العثور على موقعين (Indices) لرقمين مختلفين في المصفوفة بحيث يكون مجموعهما يساوي $X$.

إذا كان هناك أكثر من حل، اطبع أي واحد منها. وإذا لم يوجد حل، اطبع "IMPOSSIBLE".
ملاحظة: المواقع تبدأ من 1 (1-based index).

Input:
4 8
2 7 5 1

Output:
2 4
(لأن 7 + 1 = 8، ومواقعهما هي 2 و 4) 
#include <iostream>
#include <vector>
#include <map>
using namespace std;

int main() {
    int n, x;
    cin >> n >> x;
    
    // استخدام الخريطة لتخزين (الرقم ، موقعه)
    map<int, int> positions;
    
    for (int i = 0; i < n; i++) {
        int current_val;
        cin >> current_val;
        
        int needed_val = x - current_val;
        
        // هل الرقم المطلوب موجود مسبقاً في الخريطة؟
        if (positions.count(needed_val)) {
            cout << positions[needed_val] << " " << i + 1 << endl;
            return 0;
        }
        
        // إذا لم يكن موجوداً، أضف الرقم الحالي للخريطة للبحث عنه لاحقاً
        positions[current_val] = i + 1;
    }
    
    cout << "IMPOSSIBLE" << endl;
    return 0;
}
💡 فكرة الحل (استخدام std::map):
بدلاً من استخدام حلقتين متداخلتين للبحث بتعقيد $O(N^2)$ مما يسبب خطأ TLE، نمر على المصفوفة مرة واحدة. في كل خطوة، نحسب الرقم الذي ينقصنا للوصول للهدف ($X - current$). نتحقق مما إذا كنا قد رأينا هذا الرقم سابقاً باستخدام الخريطة (Map). إذا وجدناه، نطبع المواقع ونتوقف. التعقيد الزمني هو $O(N \log N)$، وهو سريع جداً!

المسألة 2: أعمدة الإنارة (Vanya and Lanterns)

متوسط

يوجد شارع طويل طوله $L$. في هذا الشارع يوجد $N$ عمود إنارة متوزعة في مواقع مختلفة. جميع الأعمدة تضيء بنفس نصف القطر $D$ (تشع نوراً لليمين واليسار).

مهمتك هي إيجاد أصغر نصف قطر $D$ ممكن للأعمدة بحيث يتم إنارة الشارع بالكامل من بدايته (0) وحتى نهايته ($L$).

Input: (N L)
7 15
15 5 3 7 9 14 0

Output:
2.5000000000 
#include <iostream>
#include <vector>
#include <algorithm>
#include <iomanip> // من أجل التحكم في طباعة الفواصل العشرية
using namespace std;

int main() {
    int n;
    long long l;
    cin >> n >> l;
    
    vector<double> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    
    // 1. ترتيب مواقع الأعمدة تصاعدياً
    sort(a.begin(), a.end());
    
    // 2. حساب المسافة المبدئية عند الأطراف
    double max_dist = max(a[0] - 0, l - a[n - 1]);
    
    // 3. البحث عن أقصى مسافة بين أي عمودين متجاورين
    for (int i = 1; i < n; i++) {
        double current_gap = (a[i] - a[i - 1]) / 2.0;
        max_dist = max(max_dist, current_gap);
    }
    
    // طباعة الناتج بدقة 10 أرقام عشرية
    cout << fixed << setprecision(10) << max_dist << endl;
    return 0;
}
💡 فكرة الحل (استخدام std::sort):
لا يمكننا حساب المسافات بين الأعمدة وهي عشوائية! أول خطوة دائماً هي الترتيب (Sorting). بعد الترتيب، نبحث عن أطول مسافة مظلمة في الشارع. المسافة المظلمة بين أي عمودين متجاورين تحتاج أن يغطي كل عمود نصفها (لذلك نقسم المسافة على 2.0). ولا ننسى التحقق من أطراف الشارع (من 0 لأول عمود، ومن آخر عمود إلى $L$) لأنها تضاء من جهة واحدة فقط، لذا لا نقسم مسافتها.

المسألة 3: السلاسل الثنائية (Bit Strings)

متوسط

مهمتك هي حساب عدد السلاسل الثنائية (مكونة من 0 و 1) الممكنة التي يكون طولها $N$.

بما أن الناتج قد يكون رقماً فلكياً لا يتسع في المتغيرات العادية، قم بطباعة الناتج Modulo $10^9 + 7$.

Input:
3

Output:
8
(لأن السلاسل هي: 000, 001, 010, 011, 100, 101, 110, 111) أي $2^3 = 8$ 
#include <iostream>
using namespace std;

const int MOD = 1000000007;

// دالة الأس السريع (Binary Exponentiation)
long long fast_power(long long base, long long exp) {
    if (exp == 0) return 1;
    
    long long half = fast_power(base, exp / 2);
    long long res = (half * half) % MOD;
    
    if (exp % 2 == 1) {
        res = (res * base) % MOD;
    }
    
    return res;
}

int main() {
    long long n;
    cin >> n;
    
    // المطلوب ببساطة هو حساب (2 أس N) تحت المودولو
    cout << fast_power(2, n) << endl;
    
    return 0;
}
💡 فكرة الحل (الحسابيات المعيارية والأس السريع):
كل خانة في السلسلة لها خياران إما (0 أو 1). بالتالي، لعدد $N$ من الخانات، عدد الخيارات هو $2^N$. بما أن $N$ قد تصل لمليون (في المسابقة الأصلية)، استدعاء حلقة تكرارية عادية سيأخذ وقتاً. لذا نستخدم دالة الأس السريع (Fast Exponentiation) المرفقة مع تطبيق المودولو $10^9+7$ في كل خطوة ضرب لتجنب الـ Overflow. التعقيد الزمني هو $O(\log N)$ فقط!
