1️⃣ بطاقة الترحيب (مقدمة بسيطة)

اكتب برنامجاً يطلب من المستخدم إدخال اسمه الأول، ثم يقوم البرنامج بالترحيب به وطباعة رسالة مخصصة.
💡 تلميح: استخدم المتغير النصي (string) وكلمتي الإدخال والطباعة (cin و cout).
Input: Nadir
Output: Hello, Nadir! Welcome to C++ 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    cin >> name; // قراءة الاسم
    
    // طباعة الترحيب مع ترك مسافات
    cout << "Hello, " << name << "! Welcome to C++" << endl;
    
    return 0;
}

2️⃣ حاسبة المساحة (العمليات الحسابية)

تخيل أنك مهندس وتملك غرفة مستطيلة الشكل. اكتب برنامجاً يقرأ من المستخدم رقمين: (الطول) و (العرض). ثم يقوم البرنامج بحساب مساحة الغرفة وطباعتها.
💡 تلميح: المساحة = الطول × العرض. استخدم علامة النجمة (*) للضرب.
Input: 5 4
Output: Area = 20 
#include <iostream>
using namespace std;

int main() {
    int length, width;
    cin >> length >> width; // قراءة الطول والعرض
    
    int area = length * width; // حساب المساحة
    
    cout << "Area = " << area << endl;
    
    return 0;
}

3️⃣ حارس البوابة (الشروط البسيطة If/Else)

في مدينة الملاهي، يُسمح فقط للأشخاص الذين يبلغ طولهم 120 سم أو أكثر بركوب "القطار السريع". اكتب برنامجاً يقرأ طول الشخص، فإذا كان طوله 120 أو أكثر يطبع "YES"، وإذا كان أقل يطبع "NO".
💡 تلميح: استخدم الجملة الشرطية (if) مع علامة أكبر من أو يساوي (>=).
Input 1:
135

Input 2:
110
Output 1:
YES

Output 2:
NO 
#include <iostream>
using namespace std;

int main() {
    int height;
    cin >> height;
    
    if (height >= 120) {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
    
    return 0;
}

4️⃣ لغز الأرقام الزوجية والفردية

اكتب برنامجاً يقرأ رقماً صحيحاً من المستخدم، ويخبرنا ما إذا كان هذا الرقم "زوجياً" (Even) أم "فردياً" (Odd).
💡 تلميح: الرقم الزوجي يقبل القسمة على 2 بدون باقي. استخدم معامل باقي القسمة (%).
Input 1:
8

Input 2:
7
Output 1:
Even

Output 2:
Odd 
#include <iostream>
using namespace std;

int main() {
    int number;
    cin >> number;
    
    // إذا كان باقي القسمة على 2 يساوي صفراً فهو زوجي
    if (number % 2 == 0) {
        cout << "Even" << endl;
    } else {
        cout << "Odd" << endl;
    }
    
    return 0;
}

5️⃣ جدول الضرب الذكي (حلقات التكرار Loops)

بدلاً من كتابة جدول الضرب يدوياً، دع الكمبيوتر يقوم بذلك! اكتب برنامجاً يقرأ رقماً واحداً، ثم يقوم بطباعة جدول الضرب لهذا الرقم من 1 إلى 10.
💡 تلميح: استخدم حلقة التكرار (for loop) تبدأ من 1 وتنتهي عند 10 لتكرار عملية الطباعة.
Input:
5
Output:
5 * 1 = 5
5 * 2 = 10
...
5 * 10 = 50 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    // حلقة تتكرر 10 مرات
    for (int i = 1; i <= 10; i++) {
        cout << n << " * " << i << " = " << (n * i) << endl;
    }
    
    return 0;
}
