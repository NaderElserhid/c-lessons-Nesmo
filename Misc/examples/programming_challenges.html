1️⃣ مفكك الشفرات (مجموع الخانات) - مستوى: متوسط

اكتب برنامجاً يقرأ رقماً صحيحاً (مثلاً 245)، ويقوم بحساب مجموع خاناته (أي 2+4+5 = 11).
💡 الشرح: استخدم حلقة while. لأخذ آخر خانة استخدم المودولو N % 10. ولحذفها من الرقم استخدم القسمة N / 10.
245 ➡️ 2 + 4 + 5 = 11
Input: 245
Output: 11 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int sum = 0;
    
    // استمر في تكسير الرقم حتى يصبح صفراً
    while (n > 0) {
        sum = sum + (n % 10); // جمع آخر خانة
        n = n / 10;           // حذف آخر خانة
    }
    
    cout << sum << endl;
    return 0;
}

2️⃣ صائد حروف العلة (Vowels Hunter) - مستوى: سهل

اكتب برنامجاً يقرأ كلمة (String) باللغة الإنجليزية، ويقوم بعدّ كم حرف عِلّة (Vowel) تحتويه هذه الكلمة. حروف العلة هي: (a, e, i, o, u).
💡 الشرح: استخدم حلقة for للمرور على حروف الكلمة حرفاً بحرف، وإذا كان الحرف يطابق أحد حروف العلة، قم بزيادة العداد.
hello ➡️ Count = 2
Input: hello
Output: 2 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    
    int count = 0;
    
    for (int i = 0; i < s.length(); i++) {
        char c = s[i];
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            count++;
        }
    }
    
    cout << count << endl;
    return 0;
}

3️⃣ كاشف السنوات الكبيسة (Leap Year) - مستوى: متوسط

السنة الكبيسة (التي تحتوي على 366 يوماً) هي السنة التي تقبل القسمة على 4. ولكن، إذا كانت تقبل القسمة على 100 فهي ليست كبيسة، إلا إذا كانت تقبل القسمة على 400! اكتب برنامجاً يفحص هل السنة المدخلة كبيسة أم لا.
💡 الشرح: هذه مسألة تعتمد على ربط الشروط المنطقية (AND `&&`) و (OR `||`). الشرط هو: (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0).
Year = 2024
⬇️
% 4 == 0 ✅ % 100 != 0 ✅ ➡️ Leap Year
Input 1:
2024

Input 2:
1900
Output 1:
Leap

Output 2:
Not Leap 
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;
    
    // تطبيق الشروط المنطقية المذكورة
    if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
        cout << "Leap" << endl;
    } else {
        cout << "Not Leap" << endl;
    }
    
    return 0;
}

4️⃣ جهاز كشف الأعداد الأولية (Prime Detector) - مستوى: متوسط

العدد الأولي (Prime) هو العدد الذي لا يقبل القسمة إلا على 1 وعلى نفسه (مثل 7). اكتب برنامجاً يقرأ رقماً، ويطبع "Prime" إذا كان أولياً، أو "Not Prime" إذا لم يكن كذلك.
💡 الشرح: استخدم حلقة من 2 وحتى N-1. إذا وجدت أي رقم يقبل القسمة عليه (باقي القسمة = 0)، فهو ليس أولياً. يمكنك إيقاف الحلقة بـ `break`.
7 ÷ 2,3,4,5,6? ❌ ➡️ Prime
Input 1:
7

Input 2:
9
Output 1:
Prime

Output 2:
Not Prime 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    if (n <= 1) {
        cout << "Not Prime" << endl;
        return 0;
    }
    
    bool isPrime = true;
    
    // نتحقق من الأرقام بين 2 وما قبل الرقم نفسه
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            isPrime = false; // وجدنا قاسماً، إذن ليس أولياً
            break;           // نوقف البحث فوراً
        }
    }
    
    if (isPrime) cout << "Prime" << endl;
    else cout << "Not Prime" << endl;
    
    return 0;
}

5️⃣ البحث عن الكنز المفقود (Minimum in Array) - مستوى: متوسط

لديك مجموعة من الصناديق كل منها يحتوي على عدد من العملات. اكتب برنامجاً يقرأ عدد الصناديق (N)، ثم يقرأ الأرقام بداخلها، ويطبع أصغر رقم بينهم.
💡 الشرح: اقرأ الرقم الأول واعتبره هو الأصغر. ثم في حلقة التكرار، اقرأ باقي الأرقام، وإذا وجدت رقماً أصغر مما تملك، قم بتحديث قيمة المتغير الأصغر.
[5, 2, 9, 1] 🔍 Min: 1
Input:
4
5 2 9 1
Output:
1 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int min_val;
    cin >> min_val; // نعتبر أول رقم هو الأصغر مبدئياً
    
    // الحلقة تبدأ من 1 لأننا قرأنا الرقم رقم 0
    for (int i = 1; i < n; i++) {
        int current;
        cin >> current;
        if (current < min_val) {
            min_val = current; // تحديث القيمة الأصغر
        }
    }
    
    cout << min_val << endl;
    
    return 0;
}
