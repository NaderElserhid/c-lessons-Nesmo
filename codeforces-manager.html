🚀 كيفية استخدام Codeforces مع منصتك التعليمية

1

إنشاء حساب على Codeforces

اذهب إلى codeforces.com وأنشئ حساباً لمنصتك. سجّل كـ Coordinator لتتمكن من إنشاء مسابقات.

🔗 سجّل الآن على Codeforces
2

إنشاء Mashup Contest (امتحان مخصص)

اذهب إلى Gym → New Contest → Mashup، ثم أضف المسائل من أرشيف Codeforces واختر المستوى المناسب لطلابك.

🔗 إنشاء Mashup Contest
3

طلب الطلاب إنشاء حسابات CF

كل طالب يحتاج حساباً على Codeforces. اجمع handles الطلاب (أسماء المستخدمين) وأدخلها في هذه المنصة.

4

إضافة الطلاب للامتحان

في إعدادات المسابقة على Codeforces، أضف handles الطلاب إلى قائمة المشاركين. يمكن استخدام API لجلب النتائج تلقائياً.

GET https://codeforces.com/api/user.status?handle={student_handle}&count=20
5

متابعة النتائج عبر Codeforces API

استخدم Codeforces API لجلب نتائج الطلاب تلقائياً. الـ API مجاني ولا يحتاج مصادقة للبيانات العامة.

GET https://codeforces.com/api/contest.standings?contestId={id}&handles={h1;h2;h3}
