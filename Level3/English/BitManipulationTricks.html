Bit Manipulation Tricks

Masks and quick tricks for controlling cells

What will you learn in this lesson?

  • Understand how the left and right shifts move the cells and how the number changes
  • Understand the idea of the mask 1 << k and use it to check, set, clear and toggle
  • See each of the four tasks carried out step by step
  • Follow how the cells of a number change after a series of tasks

A quick refresher

A number is stored in the computer as a row of bits, and each bit is either 0 or 1. We number the cells from the right starting at 0, and cell number k is worth 2k. So the number 12 is 1100, because it is 8 + 4. These are the six operators that everything else is built on:

OperatorNameWhat it does in each cell
&ANDgives 1 only if both cells are 1
|ORgives 1 if at least one of the cells is 1
^XORgives 1 if the two cells differ
~NOTflips every cell: 0 becomes 1 and 1 becomes 0
<<left shiftslides the cells to the left, doubling the number for each place
>>right shiftslides the cells to the right, halving the number for each place and dropping the remainder

A left shift by k equals multiplying by 2k, and a right shift by k equals dividing by 2k and dropping the remainder. Every lit cell that leaves the edge of the number is lost for good.

A toolbox for bits

In this lesson we use the bit operators to do useful things. Almost every trick in this lesson is built on one idea called the mask: a small number we make with 1 << k, which has a single lit cell, cell number k, and then combine with the original number using the right operator.

A mask is like a sheet of paper with a single hole laid over a panel of lamps: you can only see and touch the lamp under the hole. And 1 << k is the sheet whose hole sits above lamp number k.

TaskCodeThe operator doing the work
Is cell k lit?(x >> k) & 1shift, then cut
Light cell kx |= (1 << k)| lights
Switch off cell kx &= ~(1 << k)& with an inverted mask
Flip cell kx ^= (1 << k)^ flips

Remember that k starts at 0, and that the number 1 has type int: for large numbers (more than 31 cells) write 1LL << k.

The second method (x & (1 << k)) does not give 1; it gives the mask value itself, that is 2k, or 0. So use its result only as a condition (!= 0), and do not assume it is 0 or 1:

mask_value.cpp
int x = 13;
cout << (x & (1 << 3)) << " " << ((x >> 3) & 1) << " " << ((x & (1 << 1)) != 0) << endl;

Shorten the rule like this: | to light, & ~ to switch off, and ^ to flip. If you want several cells at once, combine masks with |: for example x |= (1 << 0) | (1 << 4).

Lesson project: the lamp panel

A panel with 16 lamps stored in a single number, receiving commands to light, switch off, flip and ask.

The idea

You are building a control panel for the school corridor lamps, which has 16 lamps numbered 0 to 15. Instead of an array of 16 boolean values, you will keep their whole state in one number: a lit cell means the lamp is on.

What you must do
  1. Read q (the number of commands). All lamps start off.
  2. The command ON k lights lamp k, OFF k switches it off, and FLIP k flips its state.
  3. The command ASK k prints ON or OFF according to the state of lamp k.
  4. At the end print the complete state as sixteen bits, then a line in the form Lamps on: count that shows how many lamps are on. Write a function countBits for this that goes through the sixteen cells and checks each one with (x >> k) & 1.
Two sample runs

First run:

7 ON 0 ON 3 FLIP 3 ON 5 ASK 3 ASK 5 OFF 0
OFF ON 0000000000100000 Lamps on: 1

Second run:

4 FLIP 15 FLIP 14 ASK 15 FLIP 15
ON 0100000000000000 Lamps on: 1

Check it in your head (first run): we lit 0 and 3, then flipped 3 so it went off, and lit 5. Asking about 3 gives OFF and about 5 gives ON. After switching off 0 only lamp 5 remains, so we get a single lit cell.

After you have tried it yourself: show the solution
lamp_panel.cpp
#include <iostream>
#include <string>
#include <bitset>
using namespace std;

int countBits(unsigned int x) {
    int count = 0;
    for (int k = 0; k < 16; k++) {
        if ((x >> k) & 1) {
            count++;
        }
    }
    return count;
}

int main() {
    int q;
    cin >> q;
    unsigned int lamps = 0;

    for (int i = 0; i < q; i++) {
        string cmd;
        int k;
        cin >> cmd >> k;
        if (cmd == "ON") {
            lamps |= (1u << k);
        } else if (cmd == "OFF") {
            lamps &= ~(1u << k);
        } else if (cmd == "FLIP") {
            lamps ^= (1u << k);
        } else if (cmd == "ASK") {
            cout << (((lamps >> k) & 1) ? "ON" : "OFF") << endl;
        }
    }

    cout << bitset<16>(lamps) << endl;
    cout << "Lamps on: " << countBits(lamps) << endl;
    return 0;
}

Is the cell lit?

Easy

Read a positive number x and the number of queries q, then q cell numbers. For each k print 1 if cell k of x is lit, otherwise print 0.

Requirements
  • Read x as an unsigned int.
  • Use (x >> k) & 1 for each query.
  • Print each answer on its own line.
Example input and expected output
22 5 0 1 2 3 4
0 1 1 0 1
Hints
  • Cell 0 is the first one from the right.
  • With x = 22, that is 10110: cell 1 is lit and cell 3 is off.
Sample solution (after you try)

// Challenge 1: is the cell lit?
#include <iostream>
using namespace std;

int main() {
    unsigned int x;
    int q;
    cin >> x >> q;
    while (q--) {
        int k;
        cin >> k;
        cout << ((x >> k) & 1) << endl;
    }
    return 0;
}
2

How many cells differ?

Medium

Read two numbers a and b. Print the number of cells in which their binary forms differ (that is, the number of positions with bit 0 in one and 1 in the other).

Requirements
  • Read the two numbers as unsigned int.
  • Compute d = a ^ b, whose lit cells are the positions of difference.
  • Go through the thirty-two cells and count the lit ones with (d >> k) & 1.
  • Print the count only.
Example input and expected output
29 15
2
Hints
  • Exclusive or lights a cell only where the two numbers differ.
  • With 29 and 15, 29 ^ 15 = 18, which is 10010 and has two lit cells, so the answer is 2.
Sample solution (after you try)
hamming.cpp
// Challenge 2: different bits
#include <iostream>
using namespace std;

int main() {
    unsigned int a, b;
    cin >> a >> b;
    unsigned int d = a ^ b;
    int count = 0;
    for (int k = 0; k < 32; k++) {
        if ((d >> k) & 1) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}

Quick summary

  • A left shift x << k multiplies the number by 2^k, and a right shift x >> k divides it and drops the remainder. Whatever leaves the edge of the number is lost.
  • The mask 1 << k has a single lit cell; we combine it with a number to control cell k alone.
  • Check (x >> k) & 1, set x |= (1 << k), clear x &= ~(1 << k), toggle x ^= (1 << k).
  • The result of x & (1 << k) is 0 or the mask value itself, so we use it as a condition, not as a 0-or-1 value.
  • Toggling a cell twice with ^= brings it back to how it was.

Glossary

The most important terms in this lesson:

Bit

The smallest unit of storage: one cell whose value is 0 or 1.

Mask

A number we build to control particular cells, such as 1 << k.

Set a bit

Making the cell 1.

Clear a bit

Making the cell 0.

Toggle

Turning the cell into the opposite of its state.

Shift

Moving all the cells of a number one place or more to the left or to the right.

Bit index

The position of a cell, starting from 0 at the low end of the number.
