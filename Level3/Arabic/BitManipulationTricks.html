Bit Manipulation Tricks — أقنعة وحيل سريعة للتحكم في الخانات

ماذا ستتعلم في هذا الدرس؟

  • تفهم كيف تحرّك الإزاحة اليسرى واليمنى الخانات وكيف يتغير العدد
  • تفهم فكرة القناع 1 << k وتستعمله للفحص والضبط والتصفير والقلب
  • ترى كل مهمة من المهام الأربع تُنفَّذ خطوة بخطوة
  • تتتبع تغيّر خانات عدد بعد سلسلة من المهام

تذكير سريع بالأساسيات

العدد في الحاسوب يُخزَّن كصف من البتات (bit)، كل بت إما 0 وإما 1. نرقّم الخانات من اليمين ابتداءً من 0، وللخانة رقم k قيمة 2k. فالعدد 12 هو 1100 لأنه 8 + 4. وهذه المعاملات الستة التي سنبني عليها كل شيء:

المعاملاسمهماذا يفعل في كل خانة
&و (AND)يعطي 1 فقط إذا كانت الخانتان 1
|أو (OR)يعطي 1 إذا كانت إحدى الخانتين 1 على الأقل
^الحصري (XOR)يعطي 1 إذا اختلفت الخانتان
~النفي (NOT)يقلب كل خانة: 0 إلى 1 و1 إلى 0
<<إزاحة لليساريزحزح الخانات لليسار، فيتضاعف العدد بقدر كل خانة
>>إزاحة لليمينيزحزح الخانات لليمين، ويقسم العدد بقدر كل خانة ويسقط الباقي

جرّب بنفسك على a = 12 (1100) وb = 10 (1010). اضغط على أي سطر مضيء لتقرأ شرحه:

refresher.cpp
int a = 12;int b = 10;cout << (a & b) << endl;cout << (a | b) << endl;cout << (a ^ b) << endl;cout << (a << 1) << endl;cout << (a >> 2) << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
8 14 6 24 3

مختبر تفاعلي: كيف تتحرك الخانات في الإزاحة؟

اكتب عددًا من 0 إلى 255، ثم اضغط زر الإزاحة مرة بعد مرة. في كل ضغطة تتحرك كل الخانات مكانًا واحدًا، وسترى الخانة الجديدة التي تظهر (بالأصفر) والخانة التي تسقط من الحافة.

وزن كل خانة
الخانات الآن

الإزاحة لليسار بمقدار k تساوي الضرب في 2k، والإزاحة لليمين بمقدار k تساوي القسمة على 2k مع إسقاط الباقي. وكل خانة مضيئة تخرج من حافة العدد تضيع إلى الأبد.

حقيبة أدوات البتات

في هذا الدرس نستعمل معاملات البتات لفعل أشياء مفيدة. تقريبًا كل حيلة في هذا الدرس مبنية على فكرة واحدة اسمها القناع (mask): عدد صغير نصنعه بـ 1 << k، فيه خانة مضيئة واحدة هي الخانة رقم k، ثم ندمجه مع العدد الأصلي بالمعامل المناسب.

القناع كورقة مثقوبة بثقب واحد توضع فوق لوحة المصابيح: لا ترى ولا تلمس إلا المصباح الذي تحت الثقب. و1 << k هو الورقة التي ثقبها فوق المصباح رقم k.

المهمةالكودالمعامل الذي يقوم بالعمل
هل الخانة k مضيئة؟(x >> k) & 1الإزاحة ثم الاقتطاع
أضئ الخانة kx |= (1 << k)| يضيء
أطفئ الخانة kx &= ~(1 << k)& مع قناع معكوس
اقلب الخانة kx ^= (1 << k)^ يقلب

تذكّر أن k يبدأ من 0، وأن الرقم 1 من نوع int: للأعداد الكبيرة (أكثر من 31 خانة) اكتب 1LL << k.

رسم تفاعلي: كيف تعمل كل مهمة خطوة بخطوة؟

اختر إحدى المهام الأربع، واكتب العدد x ورقم الخانة k، ثم اضغط «الخطوة التالية» لترى كيف تُبنى النتيجة صفًّا بعد صف. الخانات الملونة بالأصفر هي الخانات التي تغيّرت.

الفحص: هل الخانة مضيئة؟

check_bit.cpp
int x = 10;for (int k = 0; k < 4; k++) {    cout << "bit " << k << " = " << ((x >> k) & 1) << endl;}cout << bool(x & (1 << 3)) << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
bit 0 = 0 bit 1 = 1 bit 2 = 0 bit 3 = 1 1

الطريقة الثانية (x & (1 << k)) لا تعطي 1 بل تعطي قيمة القناع نفسه، أي 2k، أو 0. فاستعمل نتيجتها كشرط فقط (!= 0)، ولا تظن أنها 0 أو 1:

mask_value.cpp
int x = 13;
cout << (x & (1 << 3)) << " " << ((x >> 3) & 1) << " " << ((x & (1 << 1)) != 0) << endl;
8 1 0

الضبط والتصفير والقلب

جرّب العمليات الثلاث على عدد واحد وراقب كيف تتغير خانة واحدة فقط في كل مرة. اضغط على أي سطر مضيء لشرحه:

four_moves.cpp

اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
00001101 13 00001111 15 00000111 7 00000011 3 00000111 7

اختصر القاعدة هكذا: | للإضاءة، و& ~ للإطفاء، و^ للقلب. وإذا أردت أكثر من خانة في الوقت نفسه فادمج الأقنعة بـ |: مثلًا x |= (1 << 0) | (1 << 4).

توقّع قبل أن تشغّل
predict_moves.cpp
int x = 9;
x |= (1 << 1);
x &= ~(1 << 0);
x ^= (1 << 3);
cout << x << endl;

ما الذي سيطبعه البرنامج؟ (العدد 9 هو 1001، وتتبّع كل سطر على حدة)

2

نتتبع العدد خطوة خطوة: 1001 (9). الضبط |= (1 << 1) يضيء الخانة 1 فيصبح 1011 (11). التصفير &= ~(1 << 0) يطفئ الخانة 0 فيصبح 1010 (10). القلب ^= (1 << 3) يطفئ الخانة 3 لأنها كانت مضيئة فيصبح 0010. الناتج 2.

مختبر تفاعلي: صندوق الحيل

اضغط على الخانات لتبني عددًا، ثم اختر رقم الخانة k وجرّب المهام الأربع بحرية. العمليات التي تغيّر العدد تتغير فيها الخانات الملونة بالأصفر.

x
مشروع الدرس: لوحة المصابيح

لوحة فيها 16 مصباحًا مخزّنة في عدد واحد، تستقبل أوامر الإضاءة والإطفاء والقلب والسؤال.

الفكرة

تبني لوحة تحكم لمصابيح ممر المدرسة، وفيها 16 مصباحًا مرقمة من 0 إلى 15. بدل مصفوفة من 16 قيمة منطقية، ستحفظ حالتها كلها في عدد واحد: الخانة المضيئة تعني أن المصباح مشتعل.

المطلوب منك
  1. اقرأ q (عدد الأوامر). تبدأ كل المصابيح مطفأة.
  2. الأمر ON k يضيء المصباح k، وOFF k يطفئه، وFLIP k يقلب حالته.
  3. الأمر ASK k يطبع ON أو OFF بحسب حالة المصباح k.
  4. في النهاية اطبع الحالة الكاملة بستة عشر بتًا، ثم سطرًا بالشكل Lamps on: عدد يبين عدد المصابيح المضيئة. اكتب لهذا دالة countBits تمرّ على الخانات الست عشرة وتفحص كل واحدة بـ (x >> k) & 1.
مثالان على التشغيل

التشغيل الأول:

7 ON 0 ON 3 FLIP 3 ON 5 ASK 3 ASK 5 OFF 0
OFF ON 0000000000100000 Lamps on: 1

التشغيل الثاني:

4 FLIP 15 FLIP 14 ASK 15 FLIP 15
ON 0100000000000000 Lamps on: 1

تحقق ذهنيًا (التشغيل الأول): أضأنا 0 و3 ثم قلبنا 3 فانطفأ، وأضأنا 5. السؤال عن 3 يعطي OFF وعن 5 يعطي ON. بعد إطفاء 0 لا يبقى إلا المصباح 5، فنحصل على خانة مضيئة واحدة.

بعد أن تجرّب بنفسك: اعرض الحل
lamp_panel.cpp
#include <iostream>
#include <string>
#include <bitset>
using namespace std;

int countBits(unsigned int x) {
    int count = 0;
    for (int k = 0; k < 16; k++) {
        if ((x >> k) & 1) {
            count++;
        }
    }
    return count;
}

int main() {
    int q;
    cin >> q;
    unsigned int lamps = 0;

    for (int i = 0; i < q; i++) {
        string cmd;
        int k;
        cin >> cmd >> k;
        if (cmd == "ON") {
            lamps |= (1u << k);
        } else if (cmd == "OFF") {
            lamps &= ~(1u << k);
        } else if (cmd == "FLIP") {
            lamps ^= (1u << k);
        } else if (cmd == "ASK") {
            cout << (((lamps >> k) & 1) ? "ON" : "OFF") << endl;
        }
    }

    cout << bitset<16>(lamps) << endl;
    cout << "Lamps on: " << countBits(lamps) << endl;
    return 0;
}

1

هل الخانة مضيئة؟

سهل

اقرأ عددًا موجبًا x ثم عدد الأسئلة q، ثم q رقمًا لخانات. لكل رقم k اطبع 1 إن كانت الخانة k في x مضيئة، وإلا اطبع 0.

المطلوب
  • اقرأ x من نوع unsigned int.
  • استعمل (x >> k) & 1 لكل سؤال.
  • اطبع كل جواب في سطر.
مثال على الإدخال والناتج المتوقع
22 5 0 1 2 3 4
0 1 1 0 1
تلميحات
  • الخانة 0 هي الأولى من اليمين.
  • مع x = 22 أي 10110: الخانة 1 مضيئة والخانة 3 مطفأة.
نموذج الحل (بعد المحاولة)
cell_query.cpp
// Challenge 1: is the cell lit?
#include <iostream>
using namespace std;

int main() {
    unsigned int x;
    int q;
    cin >> x >> q;
    while (q--) {
        int k;
        cin >> k;
        cout << ((x >> k) & 1) << endl;
    }
    return 0;
}
2

كم خانة تختلف؟

متوسط

اقرأ عددين a وb. اطبع عدد الخانات التي تختلف فيها صيغتاهما الثنائيتان (أي عدد المواقع التي فيها بت 0 في أحدهما و1 في الآخر).

المطلوب
  • اقرأ العددين من نوع unsigned int.
  • احسب العدد d = a ^ b، فخاناته المضيئة هي مواضع الاختلاف.
  • مرّ على الخانات الاثنتين والثلاثين وعُدّ المضيئة منها بـ (d >> k) & 1.
  • اطبع العدد فقط.
مثال على الإدخال والناتج المتوقع
29 15
2
تلميحات
  • الحصري يضيء الخانة فقط حين يختلف العددان فيها.
  • مع 29 و15 يكون 29 ^ 15 = 18 أي 10010 وفيه خانتان مضيئتان، فالجواب 2.
نموذج الحل (بعد المحاولة)
hamming.cpp
// Challenge 2: different bits
#include <iostream>
using namespace std;

int main() {
    unsigned int a, b;
    cin >> a >> b;
    unsigned int d = a ^ b;
    int count = 0;
    for (int k = 0; k < 32; k++) {
        if ((d >> k) & 1) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}

ملخص سريع

  • الإزاحة لليسار x << k تضاعف العدد k مرة، واليمين x >> k تقسمه وتُسقط الباقي. وما يخرج من حافة العدد يضيع.
  • القناع 1 << k فيه خانة واحدة مضيئة؛ وندمجه مع العدد لنتحكم في الخانة k وحدها.
  • الفحص (x >> k) & 1، والضبط x |= (1 << k)، والتصفير x &= ~(1 << k)، والقلب x ^= (1 << k).
  • الناتج x & (1 << k) هو 0 أو قيمة القناع نفسها، فنستعمله شرطًا لا قيمةً من 0 و1.
  • قلب الخانة مرتين بـ ^= يعيدها كما كانت.
