TweetKod Academy · Informatics

C++ Foundations: Learn to Code

A friendly, hands-on first course in C++ for students in Grades 7–8 (ages 12–14).

Start from zero and finish by writing real programs: games, calculators, score boards and more. Every lesson is short, visual and interactive, and every program shown here was compiled and tested, so the output you see is the output you will get.

What you will learn

  • Write, compile and run your first C++ programs
  • Store data in variables, constants and arrays
  • Make decisions with if and repeat work with loops
  • Organize code into functions and use vectors
  • Read compiler errors and fix bugs with confidence

How each lesson works

1Learn
A clear explanation with a live example, a step-by-step tracer and small labs to experiment with.
2Build
A mini project with a goal, requirements and a hidden solution to check yourself against.
3Practice
Two homework challenges (easy and medium) with hints, then a True/False check and a 10-question quiz.
4Review
A glossary of key terms and a one-card summary to revise before the lesson quiz.
Tip: try every challenge before opening the hint or the solution. Mistakes are how programmers learn.

Part 1 section summary

Paste into: Section 1 → Edit settings → Summary. Section name: Part 1 · Your First Programs

Part 1 · Lessons 1–6

Your First Programs

Print messages, store data and read input from the keyboard.

In this part you meet the building blocks of every C++ program: how a program is structured, how to keep values in variables and constants, how to calculate with operators, and how to talk to the user with input and output.

01Hello World Program
Write and run your first program, print text and fix your first errors.
02Program Structure
What main, headers and braces do, and how code becomes a program.
03Variables & Data Types
Store whole numbers, decimals, characters, text and true/false values.
04Constant Values
Protect values that must never change with const and constexpr.
05Basic Operators
Calculate, compare and combine conditions.
06Input & Output
Read what the user types and format what the program prints.
Goal: by the end of Part 1 you can write a program that asks questions, calculates an answer and prints a neat result.

Part 2 section summary

Paste into: Section 2 → Edit settings → Summary. Section name: Part 2 · Decisions and Loops

Part 2 · Lessons 7–10

Making Decisions and Repeating

Teach your program to choose a path and to repeat work without getting bored.

Real programs react to the situation and repeat tasks. You will learn how a program flows from line to line, how if picks between choices, and how while and for loops repeat actions.

07Control Flow
Statements, blocks and the three shapes every program is built from.
08if Statements
Decide with if, else and compound conditions.
09while Loops
Repeat while a condition is true, and avoid infinite loops.
10for Loops
The tidy counting loop, nested loops and patterns.
Goal: by the end of Part 2 you can build small games and tools such as a guessing game or a savings planner.

Part 3 section summary

Paste into: Section 3 → Edit settings → Summary. Section name: Part 3 · Functions and Data

Part 3 · Lessons 11–14

Functions and Data

Split big problems into small functions and store many values at once.

The last part turns you into a programmer who organizes code. You will write your own functions, understand where names live, and store lists of values with arrays and vectors.

11Using Functions
Write once, use many times: parameters, return values and references.
12Scope & Visibility
Where each variable lives, and who can see it.
13Basic Arrays
A row of values under one name, indexes and boundaries.
14Dynamic Vectors
Arrays that grow and shrink, safe access and sorting.
Goal: by the end of Part 3 you can write a complete program made of functions that analyzes a list of data.
