Lesson 3

Variables and Types

Variables and Types — how a program remembers its data

What will you learn in this lesson?

  • Understand what a variable is, and tell declaration, initialization and assignment apart
  • Choose the right type for each piece of data: int, long long, double, char, bool and string
  • Know the limits of integers and when long long is needed
  • Understand why decimal numbers are approximate and what the difference between float and double is
  • Handle integer division and conversion between types correctly
  • Name variables with valid and readable names

The Variable: A Box with a Name and a Type

Every program needs to "remember" information while it works: the temperature that was read, the player's name, the number of attempts left. The tool for this is the variable: a slot reserved in the computer's memory, with three properties:

A name

We choose it, and we use it to reach the slot.

A type

It decides what can be stored (a whole number? text? a fraction?) and how much memory is reserved.

A value

The current content of the slot, which can be changed while the program runs.

Look at this example, which stores information about the planet Mars using four different types:

planet.cpp
#include <iostream>#include <string>using namespace std; int main() {    int moons = 2;    double gravity = 3.71;    char symbol = 'M';    string planet = "Mars";     cout << planet << " has " << moons << " moons." << endl;    return 0;}

Click the highlighted lines:

Mars has 2 moons.

The general form of a declaration with initialization is: type name = value;. We write the type first, then the name, then the = sign, then the first value, and the statement ends with a semicolon.

Declaration, Initialization and Assignment

TermExampleMeaning
Declarationint fuel;Creating the variable with its type and name
Initializationint fuel = 100;Creating the variable together with its first value
Assignmentfuel = 75;Putting a new value into an existing variable

The = sign in programming is not "equals" in the mathematical sense. It is a command: "calculate what is on the right, then put it into the variable on the left". That is why the line fuel = fuel - 20; is valid even though it would be impossible in mathematics:

reassign.cpp
int fuel = 100;
cout << fuel << endl;
fuel = 75;
cout << fuel << endl;
fuel = fuel - 20;
cout << fuel << endl;
100 75 55

Beware of uninitialized variables: if you declare a local variable without a value (int x;) and then read it, you will get an unpredictable random value. Get into the habit of giving every variable a first value when you create it.

The sizes in the table are the usual values on modern computers, but the standard does not strictly require them. That is why we measure them with the sizeof tool instead of assuming:

sizes.cpp
cout << "int:       " << sizeof(int) << endl;
cout << "long long: " << sizeof(long long) << endl;
cout << "float:     " << sizeof(float) << endl;
cout << "double:    " << sizeof(double) << endl;
cout << "bool:      " << sizeof(bool) << endl;
cout << "char:      " << sizeof(char) << endl;
int: 4 long long: 8 float: 4 double: 8 bool: 1 char: 1

A useful mental picture: the bigger the type, the larger the values or the higher the precision it can hold, but the more memory it uses.

The Limits of Integers: When Do We Use long long?

A 4-byte int slot holds values from about -2.1 billion to +2.1 billion (the usual upper limit is 2147483647). A long long, on the other hand, holds up to about 9.2 quintillion (9223372036854775807). If the result of your operation might exceed two billion, use long long from the start:

bigint.cpp
long long speed = 299792458;          // light speed in meters per second
long long perHour = speed * 3600;     // meters light travels in one hour
cout << perHour << endl;
1079252848800

The result is larger than a trillion, which is hundreds of times beyond the limit of int.

Overflow: when the result of an operation on int goes beyond the allowed limit, the program does not stop and does not show a warning. The result simply becomes unreliable. In competitive programming this is one of the most famous causes of wrong answers, so read the limits of the problem first and then choose the type.

Decimal Numbers and Precision

The computer stores decimal numbers in an approximate binary form, so many fractions cannot be represented with perfect accuracy. The difference between float and double is the number of reliable digits:

TypeApproximate precision
floatAbout 6 to 7 significant digits
doubleAbout 15 to 16 significant digits

Let's reveal the hidden digits by printing many places with setprecision from the <iomanip> header:

precision.cpp
cout << setprecision(17);
cout << 0.1 + 0.2 << endl;

float pf = 3.14159265358979;
double pd = 3.14159265358979;
cout << setprecision(15);
cout << pf << endl;
cout << pd << endl;
0.30000000000000004 3.14159274101257 3.14159265358979

Two observations: the result of 0.1 + 0.2 is not exactly 0.3, and the same number 3.14159265358979 comes out of a float distorted after about the seventh digit, while a double keeps it complete.

The practical rule: use double by default for decimal numbers, and do not rely on comparing two decimal numbers that came out of calculations with ==.

Characters: char and Its Secret Numbers

The computer does not know letters. It stores a number for every character (in a table called ASCII). That is why a char can be treated as a letter or as a small number, depending on what we ask for:

chars.cpp
char letter = 'A';
cout << letter << endl;
cout << static_cast<int>(letter) << endl;
cout << char(letter + 2) << endl;
A 65 C

The character 'A' has the code 65, and adding 2 brings us to the third letter of the alphabet, 'C'. Notice the important difference:

Correct
char grade = 'B';
string city = "Jeddah";
Wrong
char grade = "B";
string city = 'Jeddah';

Single quotation marks are for one character, and double quotation marks are for complete text.

Division Between Integers and Decimals

The first confusing thing for every beginner: dividing two integers always gives an integer, so the fraction is dropped. To get the remainder we use the % operator:

division.cpp
cout << 17 / 5 << endl;
cout << 17 % 5 << endl;
cout << 17 / 5.0 << endl;
3 2 3.4

It is enough for one side to be a decimal (5.0) for the result to become a decimal. When both sides are integer variables, we explicitly convert one of them before dividing:

cast.cpp
int total = 17;
int people = 5;
double average = static_cast<double>(total) / people;
cout << average << endl;
3.4

The expression static_cast<double>(total) creates a temporary decimal copy of total without changing the variable itself.

And what about putting a decimal number into an integer variable?

truncate.cpp
int whole = 3.9;
cout << whole << endl;
3

The fractional part is dropped, not rounded. The number 3.9 became 3, and this is called truncation.

The bool Type: True and False Decisions

A boolean variable holds one of two values: true or false, and we usually get it from a comparison. When printed, they appear as 1 and 0, unless we use boolalpha:

bools.cpp
int altitude = 1200;
bool aboveClouds = altitude > 2000;
bool inRange = altitude >= 500;
cout << aboveClouds << " " << inRange << endl;
cout << boolalpha << inRange << endl;
0 1 true

We will use this type a lot with conditional statements and loops in the coming lessons.

Naming Variables

A good name explains the purpose: batteryLevel is clearer than x. The mandatory rules are:

Allowed
  • English letters, digits and the underscore _
  • Starting with a letter or an underscore
  • Capital and small letters together
Not allowed
  • Starting with a digit, like 2ndPlace
  • Spaces, like best time
  • Symbols, like speed-max or cost$
  • Reserved words, like double or return

Letter case matters: BestTime and bestTime are two completely different variables. All of the following names are valid (we compiled the file to make sure):

names.cpp
int lap2 = 1;
int _temp = 2;
int best_time = 3;
int bestTime = 4;
int BestTime = 5;
StyleFormNote
snake_casebest_timeSmall words separated by an underscore
camelCasebestTimeThe first word is small and every word after it starts with a capital letter
PascalCaseBestTimeEvery word starts with a capital letter; usually used for type names

Choose one style and stick to it throughout the project. Consistency matters more than the style itself.

Optional: auto

Instead of writing the type, we let the compiler work it out from the first value. It helps with long types later on, but for now it is better to write the type explicitly so you practice it:

auto.cpp
auto a = 7;        // int
auto b = 2.5;      // double
auto c = 'x';      // char
auto d = true;     // bool
cout << a << " " << b << " " << c << " " << d << endl;
7 2.5 x 1

You must give an initial value when using auto, because the compiler relies on it to deduce the type.

Lesson Project: A Robot Status Card

We bring the five types together in one program that shows a neatly formatted card.

The idea

A team operates an exploration robot remotely, and wants a small screen that clearly shows its status whenever its data changes. The robot's data is varied: its name is text, its battery is a whole number, its speed is a decimal number, its operating mode is a single character, and its network connection is a true-or-false value.

What you need to do
  1. Create five variables with suitable types and give each one an initial value: the name Rover-7, the battery 82, the speed 1.5, the mode E, online true.
  2. Print the title of the card and then five lines, one line per variable, with a descriptive word before each value.
  3. Print a % sign after the battery, and the unit m/s after the speed.
  4. Make the boolean value appear as the word true or false, not as a number (remember boolalpha).
The expected output
=== Rover Status Card === Name: Rover-7 Battery: 82% Speed: 1.5 m/s Mode: E Online: true

Before you write: ask yourself about each value: is it text? One character? A whole number? A number with a fraction? True or false? Choosing the right type is half of the solution.

After you have tried it yourself: show the solution
rover.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Rover-7";
    int battery = 82;
    double speed = 1.5;
    char mode = 'E';
    bool online = true;

    cout << "=== Rover Status Card ===" << endl;
    cout << "Name:    " << name << endl;
    cout << "Battery: " << battery << "%" << endl;
    cout << "Speed:   " << speed << " m/s" << endl;
    cout << "Mode:    " << mode << endl;
    cout << "Online:  " << boolalpha << online << endl;
    return 0;
}

Average Trip Speed

Easy

A car covered a distance of 450 kilometers in 4 hours. The distance and the hours are integers, but the average may contain a fraction. Calculate the average and print it.

Requirements
  • Define two integer variables: distance with the value 450 and hours with the value 4.
  • Define a decimal variable speed that holds the result of dividing the distance by the hours.
  • Print the sentence as shown in the expected output.
  • Check that your result is 112.5 and not 112.
Expected output
Average speed: 112.5 km/h
Hints
  • Dividing two integers drops the fraction, so convert one of them to double before dividing.

Sample solution (after you try)
speed.cpp
// Challenge 1: average speed
#include <iostream>
using namespace std;

int main() {
    int distance = 450;
    int hours = 4;
    double speed = static_cast<double>(distance) / hours;
    cout << "Average speed: " << speed << " km/h" << endl;
    return 0;
}

Shop Receipt

A customer bought 3 pieces of a product that costs 24.5 riyals each. The shop gives free shipping if the total reaches 70 riyals or more.

  • Define price with a type suitable for a decimal price, and quantity for the amount.
  • Calculate the total in a variable named total.
  • Define a boolean variable freeShipping that holds the result of comparing the total with the number 70.
  • Print the total and the free-shipping status as true or false.

// Challenge 2: shop total

using namespace std;

    int quantity = 3;

Quick summary

  • A variable is a box with a name and a type that keeps a value which can change.
  • The basic types: int and long long for whole numbers, double for decimals, char for a character, bool for true/false, and string for text.
  • Declaration creates the variable, initialization is its first value, and assignment changes the value later.
  • Integers have limits, so use long long for large values.
  • Dividing two integers gives an integer; convert one of them to double if you want the fraction.
  • Choose clear names that describe the stored value.

Glossary

The most important terms in this lesson:

Variable

A slot in memory with a name, a type and a value that can be changed.

Declaration

Creating a variable by specifying its type and name.

Initialization

Giving a variable its first value when it is created.

Assignment

Putting a new value into an existing variable using =.

Data type

Decides what can be stored in a variable and how much memory is reserved.

Integer

A number without a fraction, such as int and long long.

Floating-point

A number with a fractional part, such as double and float.

Precision

The number of significant digits that a type keeps reliably.

Character

A single symbol stored in a char, written between single quotation marks.

String

A sequence of characters stored in a string, written between double quotation marks.

Boolean

A true or false value stored in a bool.

Overflow

When the result of an operation exceeds the upper limit of the type, so the result becomes unreliable.

Truncation

Dropping the fractional part when a decimal number is converted to an integer.

Type casting

Converting a value from one type to another using static_cast.

Identifier

The name we choose for a variable or a function.

Keyword

A word with a special meaning in the language that cannot be used as a variable name.

Case-sensitive

Distinguishes between capital and small letters, so Id is different from id.

sizeof

An operator that returns the size of a type or a variable in bytes.
