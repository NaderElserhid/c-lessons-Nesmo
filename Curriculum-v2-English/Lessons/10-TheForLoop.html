The for Loop

The for Loop — the tidy counting loop

What will you learn in this lesson?

  • Write a for loop with its three parts and understand when each part runs
  • Count up, count down, count in different steps and use characters
  • Build product patterns such as the factorial and control the scope of the loop variable
  • Write nested loops to draw shapes and tables
  • Use the simplified for to go through the characters of a text, and choose between for and while

The Tidy Counting Loop

In the previous lesson, we wrote the counting loop with three scattered parts: an initialization before the loop, a condition in its head, and an update inside its body. Forgetting any part leads to mistakes. That is why C++ offers the for loop, which gathers the three parts in one visible line. Compare the two forms, both of which give the same output:

With while (three pieces)
int i = 1;
while (i <= 5) {
    cout << i << " ";
    i++;
}
cout << endl;
With for (one piece)
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
cout << endl;

The output in both cases:

1 2 3 4 5

Anatomy of a for Loop

The head of the loop has three parts separated by two semicolons:

anatomy
for ( int i = 1 ;  i <= 5 ;  i++ ) {
        // 1) init       2) condition    3) update
}

1) InitializationOnly once, before the first iterationint i = 1

When you see for (int i = 1; i <= 3; i++), read it like this: "for every i that starts at 1 and goes up by one each time as long as i does not exceed 3".

Counting in Different Ways

We do not have to start from 1, and we do not have to go up by one. You can count down or in bigger steps, even with characters:

variants.cpp
for (int i = 10; i >= 0; i -= 5) {
    cout << i << " ";
}
cout << endl;

for (int i = 2; i <= 10; i += 2) {
    cout << i << " ";
}
cout << endl;

for (char c = 'a'; c <= 'e'; c++) {
    cout << c << " ";
}
cout << endl;
10 5 0 2 4 6 8 10 a b c d e

Notice that the comparison uses >= when counting down, that i -= 5 decreases by 5 every time, and that characters can be counted because every character is a number in the computer.

Predict before you run
zero_start.cpp
for (int i = 0; i < 5; i++) {
    cout << i;
}
cout << endl;

Which numbers will be printed?

01234

The counter starts at 0 and continues as long as i is less than 5, so 0, 1, 2, 3 and 4 are printed (five iterations). In programming we often count from zero.

The Product Pattern: The Factorial

The factorial of the number 5, for example, is written 5! and equals 5 × 4 × 3 × 2 × 1. To calculate it, we start the accumulator with 1 (because zero would make every result zero) and multiply into it in every iteration:

factorial.cpp
long long result = 1;
for (int i = 1; i <= 10; i++) {
    result = result * i;
}
cout << "10! = " << result << endl;
10! = 3628800

We used long long because factorials grow at a tremendous speed: the factorial of 13 already exceeds the limit of int.

The Counter Variable Lives Only Inside the Loop

The variable we create in the head of for becomes part of the scope of the loop only, and it disappears after the loop ends (remember the lesson about blocks). If you try to use it afterwards:

loop_scope_error.cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        cout << i << endl;
    }
    cout << "Last i: " << i << endl;
    return 0;
}
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:8:27: error: ‘i’ was not declared in this scope
    8 |     cout << "Last i: " << i << endl;
      |                           ^

If you need the value of the counter after the loop, declare it before the loop and write for (i = 1; ...) in the head without the word int.

Loops Inside Loops

A loop can be placed inside a loop. The outer loop is like the rows, and the inner one is like the columns: in every iteration of the outer loop, the inner loop runs all its iterations from the start. Let's draw a triangle of stars:

triangle.cpp
for (int row = 1; row <= 4; row++) {
    for (int star = 1; star <= row; star++) {
        cout << "*";
    }
    cout << endl;
}
* ** *** ****

The multiplication table

The two loops also nest to produce a table. We used setw(4) to align the columns:

table.cpp
for (int a = 1; a <= 4; a++) {
    for (int b = 1; b <= 4; b++) {
        cout << setw(4) << a * b;
    }
    cout << endl;
}
1 2 3 4 2 4 6 8 3 6 9 12 4 8 12 16

The number of iterations of a nested loop equals the product of the numbers of iterations of the two loops. A thousand outer iterations and a thousand inner ones mean a million operations, so think before you use it with large numbers.

Walking Through the Characters of a Text: The Simplified for

When you want to visit every element in a text, there is a short form called the range-based for: for (char c : word). Read it: "for every character c in word":

range_for.cpp
string word = "banana";
int count = 0;
for (char c : word) {
    if (c == 'a') {
        count++;
    }
}
cout << "The letter a appears " << count << " times" << endl;
The letter a appears 3 times

You will use the same form later with arrays and vectors.

for or while?

SituationThe best fitWhy
I know the number of iterations in advance (from 1 to 100)forThe whole counter is in one line
I do not know: I read until the input endswhileThe condition depends on an event, not on counting
I repeat until something happens (a correct guess)whileThe number of attempts is unknown
I go through every character in a textThe simplified forShorter and clearer

A common mistake: a semicolon after the loop head

semicolon_bug.cpp
for (int i = 0; i < 3; i++);
{
    cout << "Hi" << endl;
}
Hi

We expect three times, but Hi appeared once! The semicolon made the loop spin three times over an empty body, and then the block was printed once after it.

Lesson Project: The Homework Helper

A program that prints the multiplication table of any number you choose and calculates the sum of its results.

The idea

You are helping your little brother memorize the multiplication table. He types a number, and the program prints its table from 1 to 10 in a tidy way, and then shows the sum of all the results.

What you need to do
  1. Read the number n with a cin statement.
  2. Using a for loop that runs from 1 to 10: calculate n × i, and print it in the same format as the example, such as 7 x 1 = 7.
  3. Add up all the products in a variable total and print it after the loop.
An example run
7
7 x 1 = 7 7 x 2 = 14 7 x 3 = 21 7 x 4 = 28 7 x 5 = 35 7 x 6 = 42 7 x 7 = 49 7 x 8 = 56 7 x 9 = 63 7 x 10 = 70 Total: 385

Check in your head: the sum of the results of the table of 7 equals 7 × (1 + 2 + ... + 10) = 7 × 55 = 385. Does it match your output?

After you have tried it yourself: show the solution
times_table.cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int total = 0;
    for (int i = 1; i <= 10; i++) {
        int product = n * i;
        cout << n << " x " << i << " = " << product << endl;
        total = total + product;
    }
    cout << "Total: " << total << endl;
    return 0;
}

Sum of the Even Numbers

Easy

Write a program that adds up the even numbers from 2 to 50 and prints the sum, using a single for loop.

Requirements
  • Use an accumulator that starts from zero.
  • Make the counter start at 2 and advance with a step of 2.
  • Print the result in the format shown.
Expected output
Even sum: 650
Hints
  • The third part of the loop head is i += 2.
  • Check in your head: 2 + 4 + ... + 50 = 2 × (1 + 2 + ... + 25) = 650.
Sample solution (after you try)
even_sum.cpp
// Challenge 1: sum of evens
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 2; i <= 50; i += 2) {
        sum = sum + i;
    }
    cout << "Even sum: " << sum << endl;
    return 0;
}

The Number Triangle

Medium

Read a number n and then draw a triangle of numbers: the first row holds 1, the second holds 12, the third holds 123, and so on up to n rows.

Requirements
  • Read n with cin.
  • Use two nested loops: the outer one for the rows and the inner one to print the numbers in every row.
  • Move to a new line after every row.
Example input and expected output
4
1 12 123 1234
Hints
  • The number of digits in row number row is exactly row.
  • The inner loop starts from 1 and ends at row, and it prints the value of its counter.
  • Put cout << endl; after the inner loop and inside the outer one.
Sample solution (after you try)
number_triangle.cpp
// Challenge 2: number triangle
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    for (int row = 1; row <= n; row++) {
        for (int num = 1; num <= row; num++) {
            cout << num;
        }
        cout << endl;
    }
    return 0;
}

Quick summary

  • The head of for has three parts: initialization (once), condition (before every iteration) and update (after every iteration).
  • A variable declared in the head of for lives only inside the loop.
  • You can count down (i--), in steps (i += 2), or with characters.
  • In nested loops, the inner one runs all its iterations for every iteration of the outer one.
  • for (char c : word) goes through every element in a text.
  • Use for when you know the number of iterations, and while when you do not.

Glossary

The most important terms in this lesson:

for

A loop that gathers the initialization, the condition and the update in one head.

Initialization

The first part of for, which runs once.

Update expression

The third part of for, which runs after every iteration.

Loop variable

The variable that changes with every iteration, such as i.

Nested loop

A loop located inside the body of another loop.

Range-based for

A loop that goes through every element in a text or a collection.

Factorial

The product of the numbers from 1 to n, written n!.

Pattern

A repeated shape drawn by a program, such as a triangle of stars.

Step

The amount by which the counter changes in every iteration.

Iteration

One single run of the body of a loop.

Zero-based counting

Starting the count from 0, which is common in programming.

Inclusive

The last limit is included in the count when <= is used.
