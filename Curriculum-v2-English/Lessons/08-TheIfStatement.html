Lesson 8

The if Statement

The if Statement — when a program learns to decide

What will you learn in this lesson?

  • Write if, else and else if and trace which block will run
  • Tell an else if chain apart from two separate if statements
  • Build compound conditions using &&, || and !
  • Avoid the common mistakes: = instead of ==, a semicolon after the condition, and forgetting the braces
  • Build a program that reads input and decides based on it

The Program Decides

Until now our programs carried out everything in order with no choices. But real games and apps decide all the time: "Does the player have any lives left? Is the password correct? Does the age allow entry to the game?". The tool for making decisions in C++ is the if statement.

Think of a traffic light: if it is green, go, otherwise stop. This is exactly if and else.

Is the condition true?
Yes: run the if block
No: run the else block or skip

The Simple if Statement

The form: we write if, then the condition between parentheses, then the block that runs only if the condition is true:

simple_if.cpp
int lives = 0;
if (lives == 0) {
    cout << "Game over" << endl;
}
cout << "Thanks for playing" << endl;
Game over Thanks for playing

Since lives == 0 is true, the program entered the block and printed Game over. The last line is outside the block, so it always runs. Try changing lives to 3 and the first sentence will disappear.

Always put the block between { and }, even if it holds only one statement. You will understand why in a moment when we look at beginner mistakes.

if and else: Two Paths and No Third

If you want something to run when the condition is not met, add else. One of the two paths always runs, and the two never run together:

if_else.cpp
int age = 11;
if (age >= 13) {
    cout << "You can create an account." << endl;
} else {
    cout << "Ask a parent to help you." << endl;
}
Ask a parent to help you.

The age 11 is not greater than or equal to 13, so the program went to the else block.

The else if Chain: More Than Two Options

When there are more than two options, we link the conditions in a chain. The program checks the conditions from top to bottom, and the first true condition has its block run and then the program leaves the whole chain. The final else runs if all the conditions before it failed.

weather.cpp
int temp = 30;
if (temp > 35) {
    cout << "Very hot";
} else if (temp > 25) {
    cout << "Warm";

    cout << "Mild";

Which word will appear?

Warm

In a chain we start from the top: 30 > 35 is false, then 30 > 25 is true, so the Warm block runs and we stop immediately. We do not check the conditions after it even if they are true (30 > 15 is also true, but it is never checked).

Order matters: if you wrote score >= 70 before score >= 90, everyone who passed 90 would get a C, because the first true condition wins. Arrange the conditions from the narrowest to the widest.

Two Separate if Statements Are Not a Chain

This is a point that many people mix up. If you write an if and then another if below it (with no else between them), they are two independent questions, and both may be true together:

Predict before you run
two_ifs.cpp
int n = 10;
if (n > 5) {
    cout << "X";
}
if (n > 8) {
    cout << "Y";
}
cout << endl;

What will be printed?

XY

These are two separate if statements, not one chain. The first is true (10 > 5), so X was printed, and the second is true (10 > 8), so Y was printed. Every if statement is checked independently of the other.

Compound Conditions with &&, || and !

Remember the logical operators from the previous lesson. We use them to build a smarter question inside if. Suppose the "Rocket" ride requires a height of 120 cm or more and an age of 8 or more:

logic_if.cpp
int height = 130;
int age = 7;
bool hasTicket = true;

if (height >= 120 && age >= 8) {
    cout << "Rocket: allowed" << endl;
}
if (age < 8 || height < 120) {
    cout << "Rocket: not allowed" << endl;
}
if (!hasTicket) {
    cout << "Buy a ticket first" << endl;
}
cout << "Done" << endl;
Rocket: not allowed Done

The child with a height of 130 and an age of 7 failed the age condition, so he was not allowed even though his height is enough. The if (!hasTicket) statement did not run because he has a ticket (!true equals false). Finally, Done was printed because it is outside any condition.

Nested if Statements

You can put an if inside the block of another if, so the decisions come in stages. Example: we first check the username, and only after that we check the password:

login.cpp
string user = "sara";
string pass = "1234";

if (user == "sara") {
    if (pass == "1234") {
        cout << "Welcome back, Sara!" << endl;
    } else {
        cout << "Wrong password." << endl;
    }
} else {
    cout << "Unknown user." << endl;
}
Welcome back, Sara!

Nesting is a good tool, but do not overdo it. The more levels there are, the harder the code is to read. Often two nested conditions can be simplified into one compound condition using && if the result is the same.

Three Mistakes Every Beginner Makes

1) Assignment instead of comparison: = in place of ==

assign_bug.cpp
int x = 3;
if (x = 5) {
    cout << "x is five" << endl;
}
cout << "x now holds " << x << endl;
x is five x now holds 5

The = sign inside the condition changes x to 5 and then returns the value 5 (which is non-zero, that is, true). So the program entered the block even though x was 3 to begin with! The compiler sometimes warns you if you run it with the -Wall option, so always rely on it.

2) A semicolon after the condition

semicolon_bug.cpp
int score = 10;
if (score > 50); {
    cout << "Passed!" << endl;
}
Passed!

The score 10 does not exceed 50, but Passed! appeared! The reason is that the semicolon after ) made the body of the if an empty statement, and the block after it became an ordinary block that always runs.

3) Forgetting the curly braces

no_braces.cpp
int hp = 5;
if (hp == 0)
    cout << "Game over" << endl;
    cout << "Restarting..." << endl;
Restarting...

Without { }, the if is followed by only one statement, the one that comes right after it. The second line (Restarting...) is independent, so it appeared even though hp is not zero, and indentation never fools the compiler. This is why we advise always writing the braces.

Optional: The Ternary Operator

For short decisions that choose a value between two, there is a shortcut: condition ? valueIfTrue : valueIfFalse:

ternary.cpp
int age = 16;
string label = (age >= 18) ? "adult" : "teen";
cout << label << endl;
int bigger = (7 > 3) ? 7 : 3;
cout << bigger << endl;
teen 7

Use it only when the decision is simple, otherwise use if so that the code stays clear.

Lesson Project: The Amusement Park Gatekeeper

A program that decides who may ride the Rocket and how much they pay.

The idea

You are programming the gate of the "Rocket" ride in an amusement park. The visitor types their height in centimeters and their age, and then the program tells them whether they are allowed to ride and how much they pay.

The rules of the ride
  1. Riding is allowed if the height is 120 or more and the age is 8 or more.
  2. If allowed: the ticket for those under 12 years old is 20 riyals, and for everyone else it is 35 riyals.
  3. If not allowed: if the height is less than 120, print Sorry, you are too short., otherwise print Sorry, you are too young.
  4. Read the height and the age with a single cin statement in this order.
Example runs

A visitor with a height of 135 and an age of 9:

135 9
You can ride the Rocket! Ticket: 20 SAR

A visitor with a height of 110 and an age of 10:

110 10
Sorry, you are too short.

A visitor with a height of 150 and an age of 7:

150 7
Sorry, you are too young.

A visitor with a height of 170 and an age of 15:

170 15
You can ride the Rocket! Ticket: 35 SAR

Think before you write: draw a small flowchart with a pencil. Which question do you ask first? And what comes out of each answer? Then turn the flowchart into code.

After you have tried it yourself: show the solution
ride_checker.cpp
#include <iostream>
using namespace std;

int main() {
    int height, age;
    cin >> height >> age;

    if (height >= 120 && age >= 8) {
        cout << "You can ride the Rocket!" << endl;
        if (age < 12) {
            cout << "Ticket: 20 SAR" << endl;
        } else {
            cout << "Ticket: 35 SAR" << endl;
        }
    } else if (height < 120) {
        cout << "Sorry, you are too short." << endl;
    } else {
        cout << "Sorry, you are too young." << endl;
    }
    return 0;
}

Notice that the if statement for the ticket sits inside the block of permission, so it is only checked for those who were allowed.

Number Classifier

Easy

Write a program that reads an integer and then tells you whether it is negative, zero or positive, and then tells you whether it is even or odd.

Requirements
  • Read the number with cin.
  • Use an if / else if / else chain to classify the sign (Negative, Zero or Positive).
  • Use another, separate if / else statement to classify even (Even) and odd (Odd).
Example input and expected output
7
Positive Odd
Hints
  • A number is even if n % 2 == 0.
  • Notice that the two statements are independent, so two results are printed: one from each statement.
  • Zero is even too, so test your program with 0 and with a negative number.
Sample solution (after you try)
classifier.cpp
// Challenge 1: number classifier
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    if (n < 0) {
        cout << "Negative" << endl;
    } else if (n == 0) {
        cout << "Zero" << endl;
    } else {
        cout << "Positive" << endl;
    }

    if (n % 2 == 0) {
        cout << "Even" << endl;
    } else {
        cout << "Odd" << endl;
    }
    return 0;
}

The Leap Year

Medium

A leap year (366 days) has a rule: it is divisible by 4, but if it is a century year (divisible by 100) it is a leap year only if it is also divisible by 400. Example: 2024 is a leap year, 1900 is not a leap year, and 2000 is a leap year.

Requirements
  • Read the year as an integer.
  • Build one compound condition that applies the rule using the operators && and || and the remainder %.
  • Print 2024 is a leap year or 2024 is not a leap year according to the year entered.
  • Test your program with 1900, 2000 and 2023 and make sure the answers are correct.
Example input and expected output
2024
2024 is a leap year
Hints
  • The first case: divisible by 4 and not divisible by 100.
  • The second case: divisible by 400.
  • The full condition: (year % 4 == 0 && year % 100 != 0) || year % 400 == 0.
Sample solution (after you try)
leap_year.cpp
// Challenge 2: leap year
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;

    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        cout << year << " is a leap year" << endl;
    } else {
        cout << year << " is not a leap year" << endl;
    }
    return 0;
}

Quick summary

  • The if statement runs its block if the condition is true, and skips it if it is false.
  • else adds an alternative path that runs when the condition fails.
  • In an else if chain, only the first true condition runs and then the program leaves the chain.
  • Two separate if statements are each checked on their own, and they may both run.
  • Three famous mistakes: = instead of ==, a semicolon after the condition, and forgetting the curly braces.
  • Always write the curly braces, and arrange the conditions of a chain from the narrowest to the widest.

Glossary

The most important terms in this lesson:

if

A conditional statement that runs its block when the condition is true.

else

An alternative block that runs when the condition fails.

else if

An additional condition in a chain of options.

Condition

An expression whose result is true or false.

Branch

One of the paths that a program may take.

Nested if

An if statement inside the block of another if.

Ternary operator

The ? : shortcut for choosing a value out of two.

Comparison

Operators such as == and < that produce true or false.

Logical AND

The && operator, which holds when both conditions are true.

Logical OR

The || operator, which holds when at least one of the conditions is true.

Logical NOT

The ! operator, which reverses a boolean value.

Leap year

A year with 366 days, which follows special rules in the calculation.
