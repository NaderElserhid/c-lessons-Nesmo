Hello World

Hello World — your first program in C++

What will you learn in this lesson?

  • Understand how written code becomes a program that runs on the computer
  • Write and run your first C++ program and know what every line does
  • Use cout and the insertion operator << to print text and numbers
  • Control new lines and spacing with endl, \n and \t
  • Write useful comments and read the compiler's first error messages

From an Idea to a Running Program

A computer cannot understand the English sentences we type. It only understands very simple numeric instructions called machine code. So we write our program in a language that is closer to us, C++, and then use a helper program to translate it. This is the whole journey:

1

We write the source code

An ordinary text file with the extension .cpp that holds our instructions. It is called source code.

2

The compiler translates it

A program called a compiler (such as g++) reads the code, checks that its rules are respected, and converts it to machine code. If it finds a rule that was broken, it stops and tells us about it.

3

We get an executable file

A file that is ready to run, called an executable. From then on it needs neither the source code nor the compiler.

4

We run the program

The computer carries out the instructions one after another, and we see the result on the screen.

Writing, compiling and running repeat hundreds of times during any project. Don't worry about errors: they are a normal part of the work, and the compiler tells you where they are.

Your First Program

For decades, programmers have agreed that the first program a learner writes should print a simple greeting. Here is ours, only eight lines long:

hello.cpp
#include <iostream>using namespace std; int main() {    cout << "Hello, World!" << endl;    return 0;}

Notice that the quotation marks do not appear in the output. Their only job is to mark where the text starts and ends inside the code.

cout and <<: Text Flowing to the Screen

Picture cout as a stream of water that pours into the screen, and the symbol << as an arrow that pushes whatever is on its right into that stream. That is why << is called the insertion operator. You can put several things into one statement by repeating the arrow:

chain.cpp
cout << "Score: " << 90 << " points" << endl;
Score: 90 points

Here we sent three things to the screen in order: some text, then the number 90, then more text, and finally endl.

Careful: there is no automatic new line

cout prints only what we give it and never moves to a new line by itself. Try this program:

no_newline.cpp
#include <iostream>
using namespace std;

int main() {
    cout << "First part";
    cout << "Second part";
    return 0;
}
First partSecond part

The two texts stuck together on one line with no gap. If you want a new line, you have to ask for it explicitly.

Moving to a New Line

There are two common ways: endl, or the special symbol \n inside the text.

newline.cpp
cout << "Packing list" << endl;
cout << "Tent\n";
cout << "Compass\n" << "Torch\n";
cout << "Water bottle" << endl;
Packing list Tent Compass Torch Water bottle
MethodMeaningNote
endlEnds the line and flushes the output bufferGood for small programs and for learning
\nOnly adds a new lineFaster when printing large amounts of output

In programming contests that require printing thousands of lines, '\n' is preferred, because endl flushes the buffer every single time and slows the program down.

Special Symbols Inside Text

The backslash \ inside a text means: "the next character has a special meaning". These combinations are called escape sequences. The most important ones are:

SymbolWhat it does
\nNew line
\tA tab space, for aligning columns
\"Prints a double quotation mark inside the text
\\Prints a single backslash
escape.cpp
cout << "Name:\tNora\n";
cout << "She said: \"Hello\"\n";
cout << "Folder: C:\\games\\saves\n";
Name: Nora She said: "Hello" Folder: C:\games\saves

\" exists because an ordinary quotation mark ends the text. If we typed it without the backslash, the compiler would think the text had finished right there.

Comments: Notes for Humans

A comment is a part of the code that the compiler ignores completely. We write it to explain to ourselves or to teammates why the code looks the way it does. It comes in two forms:

comments.cpp
// This whole line is ignored by the compiler
cout << "Visible" << endl;      // a note can follow code
/* A longer note
   written on two lines */
cout << "Also visible" << endl;
Visible Also visible

// comments out the rest of the line, while /* ... */ comments out everything between the markers, even across several lines.

Write a comment that explains the reason, not what is already obvious. A comment saying "print the name" above a line that prints the name helps nobody.

Common Beginner Mistakes

You will make these mistakes, and every professional programmer has made them too. The nice thing is that the compiler points to where the problem is. Learn to read its messages from today.

1) Forgetting the semicolon

Code with an error
cout << "Hello"
return 0;
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:5:20: error: expected ‘;’ before ‘return’
    5 |     cout << "Hello"
      |                    ^
      |                    ;
    6 |     return 0;
      |     ~~~~~~

Look at the line number in the message. The compiler says it expected ; before return, which means the mistake is on the line before it.

2) A letter-case mistake

Code with an error
Cout << "Hello";
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:5:5: error: ‘Cout’ was not declared in this scope
    5 |     Cout << "Hello";
      |     ^~~~

C++ distinguishes between capital and small letters. Cout is a different name from cout, and it does not exist.

3) Forgetting the quotation marks

Code with an error
cout << Hello;
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:5:13: error: ‘Hello’ was not declared in this scope; did you mean ‘ftello’?
    5 |     cout << Hello;
      |             ^~~~~
      |             ftello

Without quotation marks, the compiler thinks Hello is the name of something we defined earlier (such as a variable), and it cannot find it.

The wording of messages differs a little between compilers and between versions, but the principle is the same: a line number, then a description of the problem. When several errors appear, fix the first one and compile again, because the rest often disappear with it.

Lesson Project: A Cafe Menu Board

Read the project idea first, try to build it yourself, then compare with the solution.

The idea

The owner of a small cafe called "Byte Cafe" wants a menu board printed on the screen: a title between two lines of equals signs, then three items with a price next to each, and finally a line with the opening hours.

What you need to do
  1. Print the top border, the title and the bottom border of the title, each on its own line.
  2. Print three items and put the price next to each one so that the three prices line up in one neat column (use \t).
  3. Print a separator line, then the opening-hours line.
  4. Make sure every statement ends with a semicolon and that the program ends with return 0;.
The expected output

Your program must print exactly this:

======================= BYTE CAFE MENU ======================= Espresso 8 SAR Latte 12 SAR Cheesecake 15 SAR ----------------------- Open daily: 7am - 11pm

A hint before you start: the names differ in length, so after Espresso you need a different number of \t characters than after Cheesecake. Experiment and adjust until the prices line up.

After you have tried it yourself: show the solution
cafe_menu.cpp
#include <iostream>
using namespace std;

int main() {
    cout << "=======================" << endl;
    cout << "     BYTE CAFE MENU    " << endl;
    cout << "=======================" << endl;
    cout << "Espresso\t\t8 SAR\n";
    cout << "Latte\t\t\t12 SAR\n";
    cout << "Cheesecake\t\t15 SAR\n";
    cout << "-----------------------\n";
    cout << "Open daily: 7am - 11pm\n";
    return 0;
}

We used \t\t after Espresso and Cheesecake, and \t\t\t after Latte because it is shorter, so the prices meet at the same position.

Homework challenges

Two short challenges to solve on your own after the lesson. Write your solution in a .cpp file, compile and run it, and compare your output with the expected output. Try first, open a hint only if you get stuck, and look at the sample solution only after a serious attempt.

1

ID Card

Easy

Write a program that prints a personal ID card inside a frame of symbols, showing your name, your city and your favorite motto.

Requirements
  • Print the top and bottom borders with the symbols + and - as in the example.
  • Print three data lines (name, city, motto) so that all of them end with the symbol | in the same column.
  • Write the motto between double quotation marks that appear in the output.
  • Start the file with a comment that names the challenge.
Expected output
+----------------------+ | Name: Sara | | City: Jeddah | | Motto: "Code daily" | +----------------------+
Hints
  • A quotation mark that you want to appear is written \" inside the text.
  • Count the spaces after each value so that all five lines have the same length.
  • You can replace the data with your own, as long as the frame stays neat.
Sample solution (after you try)
id_card.cpp
// Challenge 1: ID card
#include <iostream>
using namespace std;

int main() {
    cout << "+----------------------+" << endl;
    cout << "| Name:  Sara          |" << endl;
    cout << "| City:  Jeddah        |" << endl;
    cout << "| Motto: \"Code daily\"  |" << endl;
    cout << "+----------------------+" << endl;
    return 0;
}
2

The Pyramid

Medium

Write a program that draws a small pyramid of stars on four lines, where the number of stars grows by two on every line.

Requirements
  • Use only cout (we have not studied loops yet).
  • The first line has one star, the second three, the third five and the fourth seven.
  • Put spaces before the stars so that the shape looks symmetrical, like a pyramid.
Expected output
* *** ***** *******
Hints
  • The first line needs three spaces before the star, the second two, the third one and the fourth none.
  • Write the spaces inside the quotation marks together with the stars, like " *".
Sample solution (after you try)
pyramid.cpp
// Challenge 2: pyramid
#include <iostream>
using namespace std;

int main() {
    cout << "   *" << endl;
    cout << "  ***" << endl;
    cout << " *****" << endl;
    cout << "*******" << endl;
    return 0;
}

Quick summary

  • Code you write is translated by the compiler into a program the computer can run.
  • Every C++ program starts at main, and every statement ends with a semicolon ;.
  • cout << ... prints to the screen, and endl or \n moves to a new line.
  • Comments (// and /* */) are for humans only and are never executed.
  • The compiler message points you to the line and the error, so read the first message first.

Glossary

The most important terms in this lesson:

Source code

The text a programmer writes in a programming language, before it is translated.

Compiler

A program that converts source code into an executable file and detects syntax errors.

Executable

The file produced by compilation, ready to run.

Statement

One complete instruction that ends with a semicolon.

Output

What a program shows to the user, such as text on the screen.

Stream

A channel that data travels through, such as cout for the screen.

Insertion operator

The symbol <<, which pushes values into an output stream.

String literal

Text written between double quotation marks, such as "Hello".

Escape sequence

A combination that starts with \ and has a special meaning, such as \n.

Comment

A part of the code that the compiler ignores, written by the programmer as an explanation.

Header

A file that defines ready-made tools which we bring in with #include.

Syntax error

A violation of the language rules that prevents compilation, such as a forgotten ;.

Debugging

The process of finding and fixing errors in a program.
