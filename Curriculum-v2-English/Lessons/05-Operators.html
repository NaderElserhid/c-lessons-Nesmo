Operators

Operators — how we calculate, compare and decide

What will you learn in this lesson?

  • Use the arithmetic operators and understand integer division and the remainder
  • Write compound assignment operations and the increment and decrement operators
  • Compare values and clearly tell = and == apart
  • Combine conditions with the logical operators and understand short-circuit evaluation
  • Predict the order in which operators run and use parentheses to make it clear

What Is an Operator?

An operator is a symbol that asks the computer to carry out an operation, and the values the operation works on are called operands. In the expression 7 + 2, the operator is + and the operands are 7 and 2. The operators we will learn today fall into five groups:

GroupOperatorsGives us
Arithmetic+ - * / %A number
Assignment= += -= *= /= %=Storing a value in a variable
Increment and decrement++ --Changing the value by one
Comparison== != < > <= >=A bool value
Logical&& || !A bool value

Remember: the result of dividing two integers is an integer. And if you divide by zero, the program crashes or produces an undefined result, so make sure the divisor is not zero before dividing.

The remainder with negative numbers

The integer result of a division is rounded toward zero, and the remainder takes the sign of the dividend:

negative.cpp
cout << -7 / 2 << " " << -7 % 2 << endl;
cout << 7 / -2 << " " << 7 % -2 << endl;
-3 -1 -3 1

In each line the first number is the quotient and the second is the remainder. Check that -7 = (-3) × 2 + (-1).

Assignment and Compound Assignment

The = operator stores the value on its right in the variable on its left. For brevity there are compound forms: instead of writing x = x + 5 we write x += 5:

compound.cpp
int x = 20;
x += 5;
cout << "after += 5  : " << x << endl;
x -= 3;
cout << "after -= 3  : " << x << endl;
x *= 2;
cout << "after *= 2  : " << x << endl;
x /= 4;
cout << "after /= 4  : " << x << endl;
x %= 5;
cout << "after %= 5  : " << x << endl;
after += 5 : 25 after -= 3 : 22 after *= 2 : 44 after /= 4 : 11 after %= 5 : 1

Follow the values: 20, then 20+5=25, then 25-3=22, then 22×2=44, then 44÷4=11, then 11 % 5 = 1.

Increment and Decrement: ++ and --

The ++ operator increases a variable by one, and the -- operator decreases it by one. Each has two forms that differ in when the value changes:

FormNameWhat happens?
++aPrefixThe value increases first, then it is used
a++PostfixThe current value is used first, then it increases
increment.cpp
int a = 5;
int b = a++;
int c = ++a;
cout << "a=" << a << " b=" << b << " c=" << c << endl;
a=7 b=5 c=7

Trace the lines: a starts at 5. In b = a++ the value 5 is copied to b and then a becomes 6. In c = ++a, a becomes 7 first and then it is copied to c.

If you use ++ on a line of its own, like count++;, there is no difference between the two forms. And avoid using the same variable twice in one expression together with ++, such as a + a++, because its result is not guaranteed in C++.

Comparison Operators

They compare two values and give true or false:

comparison.cpp
int age = 17;
cout << boolalpha;
cout << (age == 17) << endl;
cout << (age != 17) << endl;
cout << (age >= 18) << endl;
cout << (age < 18) << endl;
true false false true

The most famous beginner mistake: mixing up = (assignment) and == (comparison). See what happens:

eq_vs_assign.cpp
int x = 3;
cout << (x == 5) << endl;
cout << (x = 5) << endl;
cout << x << endl;
0 5 5

The first line asked "is x equal to 5?" and the answer was 0 (false). The second line, (x = 5), changed the value of x to 5 and gave us the assigned value, so 5 was printed and x stayed 5 afterwards.

Logical Operators

They combine bool conditions to form a compound condition:

OperatorNameIt is true when...
&&ANDBoth conditions are true together
||ORAt least one of the conditions is true
!NOTThe condition is false (it reverses the value)
logic.cpp
int age = 20;
bool hasTicket = true;
bool canEnter = age >= 18 && hasTicket;
bool needsHelp = age < 12 || age > 70;
cout << boolalpha;
cout << canEnter << endl;
cout << needsHelp << endl;
cout << !canEnter << endl;
true false false

Short-circuit evaluation

When using &&, if the first condition is false, C++ never evaluates the second condition, because the result is already known. The same goes for || if the first is true. This is useful for protecting you from mistakes such as division by zero:

short_circuit.cpp
int d = 0;
bool ok = (d != 0) && (10 / d > 1);
cout << boolalpha << ok << endl;
false

The division by zero did not cause an error, because d != 0 was false, so what comes after it was never evaluated.

Precedence: Who Runs First?

Just as multiplication comes before addition in mathematics, every operator in C++ has a precedence. When precedence is equal, execution usually goes from left to right. Here is a simplified order from highest to lowest:

LevelOperators
1 (highest)++ -- (postfix), then ! and ++ -- (prefix)
2* / %
3+ -
4< <= > >=
5== !=
6&&
7||
8 (lowest)= += -= *= /= %=
precedence.cpp
cout << 2 + 3 * 4 << endl;
cout << (2 + 3) * 4 << endl;
cout << 10 - 4 - 3 << endl;
cout << 100 / 10 * 5 << endl;
cout << boolalpha << (1 + 2 > 2 && 5 % 2 == 1) << endl;
14 20 3 50 true

Review the lines: multiplication comes before addition, so the result is 14; the parentheses change the order, so it becomes 20; 10 - 4 - 3 runs from the left, so it equals 3; and 100 / 10 * 5 equals 50. In the last line the arithmetic is calculated first, then the comparisons, and finally &&.

Don't rely on memorizing the table. When an expression is complicated, add parentheses so your intention is clear to the reader. They cost nothing.

Lesson Project: An ATM

We use integer division and the remainder to split an amount into banknote denominations.

The idea

A customer withdraws 870 riyals from an ATM. The machine splits the amount into the fewest possible notes, starting with the largest denomination: 500, then 100, then 50, then 10 riyals. The idea of the solution: dividing the amount by the denomination gives the number of notes, and the remainder is what still needs to be split among the smaller denominations.

What you need to do
  1. Define an integer variable amount with the value 870.
  2. For each denomination (in order from 500 down to 10): calculate the number of notes with integer division, then update amount with the remainder using %.
  3. Print the number of notes of each denomination, then the remaining amount that nothing covers.
The expected output
500 SAR x 1 100 SAR x 3 50 SAR x 1 10 SAR x 2 Remaining: 0 SAR

Check in your head: 870 / 500 = 1 with a remainder of 370. Then 370 / 100 = 3 with a remainder of 70. Continue on your own before you write the code.

After you have tried it yourself: show the solution
atm.cpp
#include <iostream>
using namespace std;

int main() {
    int amount = 870;

    int notes500 = amount / 500;
    amount = amount % 500;

    int notes100 = amount / 100;
    amount = amount % 100;

    int notes50 = amount / 50;
    amount = amount % 50;

    int notes10 = amount / 10;
    amount = amount % 10;

    cout << "500 SAR x " << notes500 << endl;
    cout << "100 SAR x " << notes100 << endl;
    cout << " 50 SAR x " << notes50 << endl;
    cout << " 10 SAR x " << notes10 << endl;
    cout << "Remaining: " << amount << " SAR" << endl;
    return 0;
}

Time Converter

Easy

We have a duration of 7384 seconds, and we want to show it as hours, minutes and seconds.

Requirements
  • Define an integer variable total with the value 7384.
  • Calculate the hours by dividing the total by 3600.
  • Calculate the minutes from the remainder after the hours, then the seconds from the remainder after the minutes.
  • Print the result in the format shown.
Expected output
7384 seconds = 2h 3m 4s
Hints
  • The remainder after extracting the hours is total % 3600.
  • Divide this remainder by 60 to get the minutes, and take its remainder by 60 to get the seconds.
Sample solution (after you try)
time_convert.cpp
// Challenge 1: seconds to h m s
#include <iostream>
using namespace std;

int main() {
    int total = 7384;

    int hours = total / 3600;
    int rest = total % 3600;
    int minutes = rest / 60;
    int seconds = rest % 60;

    cout << total << " seconds = " << hours << "h " << minutes << "m " << seconds << "s" << endl;
    return 0;
}

Number Tricks

Medium

Take the number 47 and apply four operations to it that use division, remainder and comparisons.

Requirements
  • Print the ones digit.
  • Print the tens digit.
  • Print whether the number is even as true or false.
  • Print whether the number is greater than 40 and less than 50 at the same time.
Expected output
Last digit: 7 Tens digit: 4 Even: false Between 40 and 50: true
Hints
  • The ones digit is n % 10, while the tens digit is n / 10 % 10.
  • A number is even if the remainder of dividing it by 2 equals zero.
  • Use boolalpha before printing the first boolean value.
Sample solution (after you try)
digits.cpp
// Challenge 2: number tricks
#include <iostream>
using namespace std;

int main() {
    int n = 47;

    cout << "Last digit: " << n % 10 << endl;
    cout << "Tens digit: " << n / 10 % 10 << endl;
    cout << "Even: " << boolalpha << (n % 2 == 0) << endl;
    cout << "Between 40 and 50: " << (n > 40 && n < 50) << endl;
    return 0;
}

Quick summary

  • Arithmetic operators: + - * / %. Dividing two integers gives an integer, and % gives the remainder.
  • Compound assignment += and its relatives, and ++ and --, increase or decrease by one.
  • = is for assignment and == is for comparison; mixing them up is a common mistake.
  • The logical operators &&, || and ! combine conditions, and short-circuit evaluation stops at the first decisive part.
  • Parentheses guarantee the order of execution that you want.

Glossary

The most important terms in this lesson:

Operator

A symbol that asks for an operation to be carried out, such as + or ==.

Operand

The value that an operator works on.

Expression

A combination of values and operators that produces a value, such as 2 + 3 * 4.

Arithmetic

The operators for addition, subtraction, multiplication, division and remainder.

Modulo

The % operator, which gives what is left after integer division.

Integer division

Dividing two integers, which produces an integer by dropping the fraction.

Compound assignment

Forms such as += and *= that combine an operation with an assignment.

Increment

The ++ operator, which increases a variable by one.

Decrement

The -- operator, which decreases a variable by one.

Comparison

Operators that compare two values and produce true or false.

Logical operator

&&, || and !, used to combine conditions.

Precedence

The order in which operators are carried out inside a single expression.

Short-circuit

Stopping the evaluation of the rest of a condition once the result is known.
