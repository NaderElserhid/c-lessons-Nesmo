Lesson 13

Arrays

Arrays — a row of slots under one name

What will you learn in this lesson?

  • Understand why we need arrays, define them and reach their elements by index
  • Remember that the index starts from 0 and avoid going out of bounds
  • Go through an array with a for loop and calculate the total, the average, the biggest and the smallest
  • Read an array from the user and pass it to functions together with its size
  • Recognize two-dimensional arrays and the indexing of texts

Five Grades... Do We Make Five Variables?

Your teacher wanted to calculate the total of the grades of five students. With the way we know, we would make a variable for every grade:

five_variables.cpp
int score1 = 80;
int score2 = 95;
int score3 = 70;
int score4 = 88;
int score5 = 100;
cout << score1 + score2 + score3 + score4 + score5 << endl;
433

What if there were thirty students in the class? We would write thirty variables and add them one by one, and we could not use a loop because every variable has a different name! The solution is the array.

Imagine a row of neighboring lockers at school, all of the same kind, and every locker has a number that starts from zero. An array is a row of similar slots under a single name, and you reach every slot by its number.

80[0]
95[1]
70[2]
88[3]
100[4]

An array of five slots called scores. The small numbers under every slot are the index.

Defining an Array and Reaching Its Elements

The form: type name[size] = { values };, so we write the type, then the name, then the number of slots between [ ], then the initial values between { }. To reach a slot we write the name and then its index between square brackets:

array_basics.cpp
int scores[5] = {80, 95, 70, 88, 100};

cout << "First: " << scores[0] << endl;
cout << "Third: " << scores[2] << endl;
cout << "Last:  " << scores[4] << endl;

scores[2] = 75;
cout << "Third after update: " << scores[2] << endl;
First: 80 Third: 70 Last: 100 Third after update: 75

The index starts from zero! In an array of 5 slots the indexes are 0 1 2 3 4, which means the last valid index is size - 1 and not size. The first slot is scores[0].

Predict before you run
index_quiz.cpp
int a[5] = {2, 4, 6, 8, 10};
cout << a[1] + a[3] << endl;

What will this code print? (Remember that the index starts from 0)

12

Index 1 is the second element (4), and index 3 is the fourth element (8). So the output is 4 + 8 = 12. Whoever gets confused thinks a[1] is the first element.

Arrays and Loops: An Inseparable Pair

The real power of an array shows with for: the counter i becomes the index, so we walk through all the slots with just two lines. Trace this code, which adds up the elements of an array:

Step-by-step execution
1int a[4] = {5, 3, 8, 2};
2int sum = 0;
3for (int i = 0; i < 4; i++) {
4 sum = sum + a[i];
5}
6cout << "Sum: " << sum << endl;
Variables
Output so far

Always write the loop condition as i < size and not i <= size. An array of 4 slots does not contain a[4].

If you give fewer values than the size

The slots that were not given a value in the initializer list are filled with zeros automatically:

partial_init.cpp
int a[5] = {1, 2};
for (int i = 0; i < 5; i++) {
    cout << a[i] << " ";
}
cout << endl;
1 2 0 0 0

But if you declare a local array with no list at all (int a[5];), its slots hold random values, just like ordinary local variables.

The Highest and Lowest Pattern

One of the most famous problems: finding the biggest and the smallest value. The idea: we assume that the first element is both the biggest and the smallest, then we go through the rest and update whenever we find something better. We have the temperatures of a whole week:

max_min.cpp
constexpr int DAYS = 7;
int temps[DAYS] = {31, 28, 35, 30, 27, 33, 29};

int hottest = temps[0];
int coldest = temps[0];
for (int i = 1; i < DAYS; i++) {
    if (temps[i] > hottest) {
        hottest = temps[i];
    }
    if (temps[i] < coldest) {
        coldest = temps[i];
    }
}
cout << "Hottest: " << hottest << ", Coldest: " << coldest << endl;
Hottest: 35, Coldest: 27

Notice that the loop started from i = 1 because index 0 was used as the starting value. We also used constexpr for the size DAYS so it is easy to change in one place (remember the lesson about constants).

Why don't we start hottest at zero? Because the temperature may be negative in a cold country, and we would be wrong. Starting with the first element works with any values.

Reading an Array from the User

We fill the array with a loop that reads every slot with cin >> nums[i], and we print it reversed with a loop that goes down from the last index to zero:

read_reverse.cpp
constexpr int N = 5;
int nums[N];

for (int i = 0; i < N; i++) {
    cin >> nums[i];
}
for (int i = N - 1; i >= 0; i--) {
    cout << nums[i] << " ";
}
cout << endl;
10 20 30 40 50
50 40 30 20 10

The size of the array must be known at compile time (a written number or a constexpr constant). Do not write int a[n]; with a variable n that is read from the user; this is not allowed in the standard even if some compilers accept it. We will learn the flexible solution in the next lesson (vectors).

Going Out of the Bounds of an Array

This is one of the most dangerous mistakes in C++. If you write scores[10] for an array of 5 slots, the compiler will not stop you and the program will not stop at that moment. Instead you will read or write in memory that does not belong to the array. The result: strange values, or a program that crashes after a while, or data that is corrupted without your knowledge. We call this undefined behavior.

Frequent mistakes
  • A loop i <= size instead of i < size
  • Using a[size] as the last slot
  • A negative index that comes from a wrong calculation
Habits that protect you
  • Define the size in one constant and use it everywhere
  • Always make the loop condition i < SIZE
  • Test your program with the first element and the last element

Arrays with Functions

Remember that functions copy their ordinary parameters. An array, on the other hand, is not copied whole; the function receives access to the original array itself. That is why it can change it. And since the function does not know its length, we must always pass the size along with it:

arrays_and_functions.cpp
#include <iostream>
using namespace std;

int sumArray(int arr[], int size) {
    int total = 0;
    for (int i = 0; i < size; i++) {
        total = total + arr[i];
    }
    return total;
}

void doubleAll(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        arr[i] = arr[i] * 2;
    }
}

int main() {
    int data[4] = {1, 2, 3, 4};
    cout << "Sum: " << sumArray(data, 4) << endl;

    doubleAll(data, 4);
    for (int i = 0; i < 4; i++) {
        cout << data[i] << " ";
    }
    cout << endl;
    return 0;
}
Sum: 10 2 4 6 8

The function doubleAll changed the original elements of data (1 2 3 4 became 2 4 6 8) without any reference &, because an array is always passed this way.

How many elements are in the array?

In the place where the array was defined, you can calculate the number of its elements by dividing its total size by the size of one element:

count_elements.cpp
int primes[] = {2, 3, 5, 7, 11, 13};
int count = sizeof(primes) / sizeof(primes[0]);
cout << "Elements: " << count << endl;
Elements: 6

But this trick does not work inside a function that received the array, because there the function does not know its length, which is why we passed size by hand.

A Two-Dimensional Array: A Whole Table

Sometimes the data is a table: rows and columns, like the seats of a cinema hall or a chessboard. We create an array with two pairs of square brackets: the first for the rows and the second for the columns, and we walk through it with two nested loops:

grid.cpp
int seats[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        cout << seats[row][col] << " ";
    }
    cout << endl;
}
cout << "seats[1][2] = " << seats[1][2] << endl;
1 2 3 4 5 6 seats[1][2] = 6

The element seats[1][2] is in the second row (index 1) and the third column (index 2), and its value is 6. The number of elements = rows × columns = 2 × 3 = 6.

A fact: texts are indexed too

string_index.cpp
string name = "Sara";
cout << name[0] << name[3] << endl;
name[0] = 'M';
cout << name << endl;
Sa Mara

A text is like a row of characters, so you can read a character from it or change it using the same index.

A Mistake: Copying an Array by Assignment

You cannot copy an array into another array with the = sign:

copy_error.cpp
#include <iostream>
using namespace std;

int main() {
    int a[3] = {1, 2, 3};
    int b[3];
    b = a;
    cout << b[0] << endl;
    return 0;
}
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:7:7: error: invalid array assignment
    7 |     b = a;
      |     ~~^~~

To copy an array you have to copy its elements one by one with a loop. (You will find in the next lesson that the vector allows copying by assignment directly.) Likewise, comparing two arrays with == does not compare their contents.

Lesson Project: The Test Score Analyzer

A program that reads five scores and analyzes them statistically.

The idea

Your teacher wants a simple program that helps him analyze the scores of a short test for five students. He types the five scores, and the program shows the total, the average, the highest score and the lowest score, and how many students scored above the average.

What you need to do
  1. Define a constant N with the value 5 and an array scores of size N, and fill it with a loop that reads from cin.
  2. In a single loop, calculate the total, the highest score and the lowest score.
  3. Calculate the average as a decimal number (remember the conversion before the division!).
  4. With a second loop, count the scores that are greater than the average.
  5. Print the five lines as in the example, with the average to one decimal place.
An example run
70 85 90 60 95
Total: 400 Average: 80.0 Highest: 95 Lowest: 60 Above average: 3

Check in your head: the total 70 + 85 + 90 + 60 + 95 = 400, so the average is 80. And the scores greater than 80 are 85, 90 and 95, which is three scores.

After you have tried it yourself: show the solution
score_analyzer.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    constexpr int N = 5;
    int scores[N];
    for (int i = 0; i < N; i++) {
        cin >> scores[i];
    }

    int sum = 0;
    int highest = scores[0];
    int lowest = scores[0];
    for (int i = 0; i < N; i++) {
        sum = sum + scores[i];
        if (scores[i] > highest) {
            highest = scores[i];
        }
        if (scores[i] < lowest) {
            lowest = scores[i];
        }
    }
    double average = static_cast<double>(sum) / N;

    int above = 0;
    for (int i = 0; i < N; i++) {
        if (scores[i] > average) {
            above++;
        }
    }

    cout << fixed << setprecision(1);
    cout << "Total: " << sum << endl;
    cout << "Average: " << average << endl;
    cout << "Highest: " << highest << endl;
    cout << "Lowest: " << lowest << endl;
    cout << "Above average: " << above << endl;
    return 0;
}

1

Print It Backwards

Easy

Write a program that reads six integers from the user and stores them in an array, and then prints them in reverse order on a single line.

Requirements
  • Define a constant N with the value 6 and an array of that size.
  • Fill the array with a for loop that reads with cin.
  • Print the elements with a second loop that starts from the last index and goes down to zero.
Example input and expected output
3 1 4 1 5 9
9 5 1 4 1 3
Hints
  • The last valid index is N - 1.
  • The counting-down loop: for (int i = N - 1; i >= 0; i--).
Sample solution (after you try)
reverse.cpp
// Challenge 1: reverse
#include <iostream>
using namespace std;

int main() {
    constexpr int N = 6;
    int nums[N];
    for (int i = 0; i < N; i++) {
        cin >> nums[i];
    }
    for (int i = N - 1; i >= 0; i--) {
        cout << nums[i] << " ";
    }
    cout << endl;
    return 0;
}
2

Search for a Number

Medium

We have the array {12, 7, 25, 3, 18}. Read a number from the user and search for it in the array element by element. If you find it, print its index, otherwise print that it was not found.

Requirements
  • Use a variable found that starts with the value -1 (meaning "not found yet").
  • Go through the array with a loop, and if an element equals the required one, store its index in found and stop the loop.
  • After the loop, print Found at index N or Not found according to the value of found.
Example input and expected output
25
Found at index 2
Hints
  • -1 is a smart choice because it is never a valid index.
  • Use break after finding the element to save the remaining iterations.
  • Test your program with a value that does not exist, such as 99, and with the first element 12 and the last element 18.
Sample solution (after you try)
search.cpp
// Challenge 2: linear search
#include <iostream>
using namespace std;

int main() {
    int data[5] = {12, 7, 25, 3, 18};
    int target;
    cin >> target;

    int found = -1;
    for (int i = 0; i < 5; i++) {
        if (data[i] == target) {
            found = i;
            break;
        }
    }

    if (found == -1) {
        cout << "Not found" << endl;
    } else {
        cout << "Found at index " << found << endl;
    }
    return 0;
}

Quick summary

  • An array is a row of slots of the same type under one name, and each slot is reached by its index.
  • The index starts from 0, and the last index is size - 1.
  • The counter of for is usually the index, and the right loop condition is i < size.
  • Slots that have no value in the initializer list are filled with zeros.
  • Going out of the bounds of an array is undefined behavior, and the compiler does not prevent it.
  • An array is passed to a function without copying (so it changes the original), and its size must be passed along with it.
  • A two-dimensional array is a table with rows and columns: arr[row][col].

Glossary

The most important terms in this lesson:

Array

A group of elements of the same type stored under one name.

Element

A single slot inside the array.

Index

The number of the slot inside the array, which starts from 0.

Size

The number of slots in the array.

Zero-based

Numbering the indexes starting from 0.

Out of bounds

Using an index that the array does not have.

Undefined behavior

A situation in which the standard guarantees no result, and which may cause a crash.

Traversal

Visiting the elements of an array one by one.

2D array

An array with rows and columns, arr[row][col].

Initializer list

The initial values between { }.

Linear search

Checking the elements one by one until the required one is found.

Maximum / Minimum

The highest value and the lowest value in a group.
