Lesson 14

Vectors

Vectors — an array that grows and shrinks

What will you learn in this lesson?

  • Understand why we need a vector instead of a fixed-size array
  • Create a vector and use push_back, pop_back, size and empty
  • Go through a vector with an index loop or the simplified for loop, and tell a copy from a reference
  • Use at() for safe access and read an unknown number of values
  • Pass a vector to functions, copy it, and sort it with sort

An Array Is Fixed... and Life Is Not

In the last lesson we learned that the size of an array must be known before the program runs. But what if we do not know how many elements the user will enter? Maybe he will type 3 scores and maybe 300! If we make the array small it fills up, and if we make it huge we waste memory.

Think of a train to which carriages are added whenever there are more passengers, and from which empty carriages are removed. This is the vector: an array that grows and shrinks by itself while the program runs, and always knows how many elements it holds.

10[0]
20[1]
30[2]
+push_back

Every push_back adds a new carriage at the end.

Our First Vector

The vector lives in a library called <vector>, so we add it with #include. When we define it, we write between < > the type of elements that it will store: vector<int> is a vector of integers, and vector<string> is a vector of texts.

vector_basics.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> scores;

    scores.push_back(80);
    scores.push_back(95);
    scores.push_back(70);

    cout << "Size: " << scores.size() << endl;
    cout << "First: " << scores[0] << endl;
    cout << "Last: " << scores[2] << endl;
    return 0;
}
Size: 3 First: 80 Last: 70

The vector started empty, and then we added three scores with push_back. The command size() gives us the current number of elements. To reach an element we use the index [ ] exactly like an array, and the index still starts from 0.

Different ways to create a vector

constructors.cpp
vector<int> empty;
vector<int> zeros(5, 0);
vector<int> primes = {2, 3, 5, 7};
vector<string> names = {"Sara", "Omar", "Lina"};

cout << empty.size() << " " << zeros.size() << " "
     << primes.size() << " " << names.size() << endl;
cout << names[1] << " " << zeros[4] << endl;
0 5 4 3 Omar 0

You can create an empty vector, or one with a certain number of the same value vector<int> zeros(5, 0) (five zeros), or with a list of values directly between { }.

methods.cpp
vector<string> team = {"Sara", "Omar", "Lina"};

cout << "front: " << team.front() << endl;
cout << "back:  " << team.back() << endl;
cout << "empty? " << team.empty() << endl;

team.pop_back();
team.push_back("Yazan");
cout << "size:  " << team.size() << endl;
cout << "last now: " << team.back() << endl;

front: Sara back: Lina empty? 0 size: 3 last now: Yazan after clear, size: 0 empty? 1

Notice that empty() printed 1 for true and 0 for false, because cout prints a boolean value as a number.

Do not call back() or pop_back() on an empty vector; there is no last element at all, and the result is undefined behavior. Check empty() first if you are not sure.

Going Through a Vector

There are two ways: a for loop with the index, or the simplified for loop that goes through every element directly (we read about it in the lesson on the for loop):

vector_loops.cpp
vector<int> v = {4, 8, 15};

for (size_t i = 0; i < v.size(); i++) {
    cout << "v[" << i << "] = " << v[i] << endl;
}

int total = 0;
for (int x : v) {
    total = total + x;
}
cout << "total = " << total << endl;
v[0] = 4 v[1] = 8 v[2] = 15 total = 27

The command size() returns a type that does not accept negative values (called size_t), so we made i of the same type to avoid a compiler warning. And if you do not need the index, the simplified loop is easier and safer.

A famous trap: if the vector is empty, v.size() - 1 does not give -1 but a very huge number (because the type does not know negatives). Beware of writing conditions that rely on subtracting 1 from the size without checking empty().

Do we change the elements during the loop?

In for (int x : v) the loop takes a copy of every element. Try to predict the output:

Predict before you run
copy_loop_quiz.cpp
vector<int> v = {1, 2, 3};
for (int x : v) {
    x = x * 10;
}
cout << v[0] << " " << v[1] << " " << v[2] << endl;

What will this code print? (Pay attention to the form of the variable x in the loop)

1 2 3

We wrote int x without &, so the loop works on a copy of every element, and changing the copy does not change the vector. To change the original we write int& x.

To change the original elements we put & after the type, so we work on the element itself and not on its copy (remember the reference from the lesson on functions):

ref_loop.cpp
vector<int> v = {1, 2, 3};
for (int& x : v) {
    x = x * 10;
}
cout << v[0] << " " << v[1] << " " << v[2] << endl;
10 20 30

Safety: at() Instead of []

Like an array, v[i] does not check the bounds; a wrong index is undefined behavior. v.at(i), however, does check, and if the index is out of bounds it announces a clear error instead of silently corrupting memory. This error is called an exception, and we can catch it with try and catch:

at_safe.cpp
vector<int> v = {5, 6, 7};

try {
    cout << v.at(10) << endl;
} catch (const out_of_range&) {
    cout << "Index 10 is out of range" << endl;
}
cout << "The program is still alive" << endl;
Index 10 is out of range The program is still alive

Think of try and catch as an acrobat's safety net: we try the dangerous move inside try, and if the code falls (an error happens), catch catches it and the program carries on instead of crashing. You do not need to memorize the details now; it is enough to know that at() is safer than [].

Without catch, the program would stop with an error message at a wrong index. So use [] when you are sure the index is valid, and at() when you want extra protection while learning and testing.

Reading an Unknown Number of Values

This is where vectors shine: we do not know how many numbers the user will type, so we read until he types the sentinel value -1 (remember the sentinel loop in the while lesson) and we add every number to the vector:

read_unknown.cpp
vector<int> v;
int x;
while (cin >> x && x != -1) {
    v.push_back(x);
}
cout << "Read " << v.size() << " numbers" << endl;
cout << "Last one: " << v.back() << endl;
50 80 65 90 -1
Read 4 numbers Last one: 90

With an array we would have had to guess a big size. Here the vector grows by exactly as much as we need.

Vectors with Functions

Unlike an array, a vector is copied whole if we pass it in the ordinary by-value way. This is slow for big vectors and does not allow changing the original. That is why we usually pass it by reference &:

  • For reading only: const vector<int>& v (no copy, and no changing).
  • For changing: vector<int>& v.
vector_functions.cpp
#include <iostream>
#include <vector>
using namespace std;

void printAll(const vector<int>& v) {
    for (int x : v) {
        cout << x << " ";
    }
    cout << endl;
}

void addBonus(vector<int>& v, int bonus) {
    for (int& x : v) {
        x = x + bonus;
    }
}

int main() {
    vector<int> points = {10, 20, 30};
    printAll(points);
    addBonus(points, 5);
    printAll(points);
    return 0;
}
10 20 30 15 25 35

There is no need to pass the size here, because the function asks the vector itself with v.size(). This is a big advantage over the array.

Copying and Comparing a Vector

What an array does not do, a vector does: it can be copied with =, which produces a completely independent vector, and the contents of two vectors can be compared with ==:

vector_copy.cpp
vector<int> a = {1, 2, 3};
vector<int> b = a;
b.push_back(4);

cout << a.size() << " " << b.size() << endl;
cout << (a == b ? "same" : "different") << endl;
b.pop_back();
cout << (a == b ? "same" : "different") << endl;
3 4 different same

Changing b did not change a, because it is a full copy.

Sorting and reversing a vector

The <algorithm> library offers ready-made tools. sort arranges in ascending order, and reverse reverses the order. We give them the beginning and the end of the vector: v.begin() and v.end():

sort_reverse.cpp
vector<int> v = {40, 10, 30, 20};

sort(v.begin(), v.end());
for (int x : v) {
    cout << x << " ";
}
cout << endl;

reverse(v.begin(), v.end());
for (int x : v) {
    cout << x << " ";
}
cout << endl;
10 20 30 40 40 30 20 10

A Mistake: The Wrong Type

A vector stores only one type, which we set when defining it. Trying to add a text to a vector of numbers is rejected by the compiler:

wrong_type.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back("hello");
    cout << v.size() << endl;
    return 0;
}
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:7:16: error: no matching function for call to ‘push_back(const char [6])’
    7 |     v.push_back("hello");
      |     ~~~~~~~~~~~^~~~~~~~~

This is a feature: the compiler stops you from mixing types before the program even starts.

Lesson Project: The Game Champions Board

A program that collects the players' points without knowing their number in advance, and then announces the results.

The idea

You held a games competition at school, and you do not know how many players will take part. You are in charge of the scoreboard: you enter the players' points one by one, and type -1 when you are finished, and then the program announces the number of participants, the average of the points and the top three results.

What you need to do
  1. Read the points in a loop and store them in a vector<int> until the value -1 (without storing it).
  2. If the vector is empty, print No scores entered and end the program.
  3. Calculate the average as a decimal number (remember static_cast).
  4. Sort the vector with sort.
  5. Print the number of participants, the average and the top three results (the biggest first). If there are fewer than 3, print what exists.
Two example runs

The first run:

50 80 65 90 70 -1
Scores entered: 5 Average: 71 Top 3: 90 80 70

The second run (nobody took part):

-1
No scores entered

Check in your head: 50 + 80 + 65 + 90 + 70 = 355, and its average is 71. After sorting, it becomes 50 65 70 80 90, so the last three are 90, 80 and 70.

After you have tried it yourself: show the solution
score_board.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> scores;
    int x;
    while (cin >> x && x != -1) {
        scores.push_back(x);
    }

    if (scores.empty()) {
        cout << "No scores entered" << endl;
        return 0;
    }

    int sum = 0;
    for (int s : scores) {
        sum = sum + s;
    }
    double average = static_cast<double>(sum) / scores.size();

    sort(scores.begin(), scores.end());

    cout << "Scores entered: " << scores.size() << endl;
    cout << "Average: " << average << endl;
    cout << "Top 3:";
    for (size_t k = 0; k < scores.size() && k < 3; k++) {
        cout << " " << scores[scores.size() - 1 - k];
    }
    cout << endl;
    return 0;
}

1

Count and Reverse

Easy

Read numbers from the user until he types 0, and store them in a vector. Then print their count and after that print them in reverse order.

Requirements
  • Use vector<int> and a loop while (cin >> x && x != 0).
  • Print Count: followed by the number of elements.
  • Print Reversed: and then the elements from the last to the first, with a space before every element.
Example input and expected output
4 8 15 16 0
Count: 4 Reversed: 16 15 8 4
Hints
  • Do not add the sentinel zero to the vector.
  • For the backward walk, use an index of type int, and start from static_cast<int>(v.size()) - 1.
Sample solution (after you try)
count_reverse.cpp
// Challenge 1: count and reverse
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    int x;
    while (cin >> x && x != 0) {
        v.push_back(x);
    }

    cout << "Count: " << v.size() << endl;
    cout << "Reversed:";
    for (int i = static_cast<int>(v.size()) - 1; i >= 0; i--) {
        cout << " " << v[i];
    }
    cout << endl;
    return 0;
}
2

The Longest Word

Medium

Read four words and store them in a vector<string>, and then print the longest of them.

Requirements
  • Read every word with cin >> w and then add it with push_back.
  • Keep a variable longest that starts with the first word.
  • Go through the words and update longest whenever you find a longer word (use .size() for the text).
  • Print Longest: and then the word.
Example input and expected output
sun galaxy moon star
Longest: galaxy
Hints
  • We get the length of a text with s.size() (remember that a text works like a row of characters).
  • This is the same "biggest" pattern that we learned in arrays, but comparing lengths.
Sample solution (after you try)
longest_word.cpp
// Challenge 2: longest word
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    vector<string> words;
    string w;
    for (int i = 0; i < 4; i++) {
        cin >> w;
        words.push_back(w);
    }

    string longest = words[0];
    for (string s : words) {
        if (s.size() > longest.size()) {
            longest = s;
        }
    }
    cout << "Longest: " << longest << endl;
    return 0;
}

Quick summary

  • A vector is an array that grows and shrinks automatically, and it needs #include <vector>.
  • We set the type of its elements when defining it: vector<int> or vector<string>.
  • push_back adds at the end, pop_back deletes the last one, and size() gives the count.
  • We reach an element with v[i] (no check) or v.at(i) (with a check that announces an error when out of bounds).
  • In the loop for (int x : v) we work on a copy, and to change the original we write int& x.
  • We pass a vector to functions by reference: const & for reading and & for changing.
  • A vector is copied with = and compared with ==, and it can be sorted with sort.

Glossary

The most important terms in this lesson:

Vector

A flexible-size array that grows and shrinks while the program runs.

push_back

Adds a new element at the end of the vector.

pop_back

Deletes the last element of the vector.

size

The number of elements currently in the vector.

empty

Checks whether the vector has no elements.

clear

Deletes all the elements of the vector.

front / back

Give the first element and the last element.

at()

Reaches an element by its index with a bounds check.

Exception

An error that is announced while running and can be caught with try and catch.

Range-based for

A loop that goes directly through all the elements of a collection.

Reference

Another name for an existing variable, written with the & sign.

sort / reverse

Two ready-made functions in <algorithm> for sorting and reversing a vector.
