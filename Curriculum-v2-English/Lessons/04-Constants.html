Lesson 4

Constants

Constants — values that do not change and should not change

What will you learn in this lesson?

  • Understand the difference between a variable and a constant, and why we need constants
  • Use const and constexpr and tell them apart
  • Avoid magic numbers by giving them clear names
  • Recognize #define, know its drawbacks and why we avoid it
  • Understand literals and their suffixes such as f and LL

Why Do We Need Constants?

In the previous lesson we learned that the value of a variable can change. But every program has values that we never want to change: the rate of value-added tax, the number of seconds in an hour, the value of the mathematical constant π. We call these values constants.

Look at the following code. The number 0.15 repeats without a name, and programmers call it a magic number, because the reader cannot tell what it is:

magic_number.cpp
double vatA = 120.0 * 0.15;
double vatB = 80.0 * 0.15;
cout << vatA << " " << vatB << endl;
18 12

Now if the rate changes, you have to hunt down every place where you wrote 0.15 and change it, and you might forget one, so the calculation would differ from one place to another. The solution is to give the value a clear name in one place:

named_constant.cpp
const double VAT_RATE = 0.15;

double vatA = 120.0 * VAT_RATE;
double vatB = 80.0 * VAT_RATE;
cout << vatA << " " << vatB << endl;
18 12

The output is the same, but the code is clearer (VAT_RATE explains itself) and easier to modify (you change the value on a single line).

The const Keyword

We put the word const before the type to make the variable read-only. After that, the compiler stops us from changing it:

seats.cpp
#include <iostream>
using namespace std;

int main() {
    const int MAX_SEATS = 40;
    MAX_SEATS = 50;
    cout << MAX_SEATS << endl;
    return 0;
}
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:6:15: error: assignment of read-only variable ‘MAX_SEATS’
    6 |     MAX_SEATS = 50;
      |     ~~~~~~~~~~^~~~

The message says clearly that we are trying to assign to a read-only variable. In other words, const protects you from your own mistakes.

The second rule: a value is required at declaration

Since a constant never changes, it makes no sense to declare it without a value and give it one later:

no_init.cpp
#include <iostream>
using namespace std;

int main() {
    const int LIMIT;
    cout << LIMIT << endl;
    return 0;
}
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:5:15: error: uninitialized ‘const LIMIT’ [-fpermissive]
    5 |     const int LIMIT;
      |               ^~~~~

Naming convention: programmers usually write constant names in capital letters separated by underscores, such as MAX_SEATS and VAT_RATE, so the reader knows at first glance that they are constants. This is a common convention, not a rule enforced by the language.

constexpr: Constants Calculated During Compilation

The keyword constexpr means that the value of the constant is known at compile time, that is, before the program starts running. This allows us to build constants on top of other constants:

constexpr_demo.cpp
constexpr int SECONDS_PER_MINUTE = 60;
constexpr int SECONDS_PER_HOUR = SECONDS_PER_MINUTE * 60;
constexpr int SECONDS_PER_DAY = SECONDS_PER_HOUR * 24;

cout << "One hour = " << SECONDS_PER_HOUR << " seconds" << endl;
cout << "One day  = " << SECONDS_PER_DAY << " seconds" << endl;
One hour = 3600 seconds One day = 86400 seconds

The compiler worked out all the numbers itself before running. But if the value of the constant depends on something that is only known while the program runs, the compiler will not accept it:

constexpr_error.cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    constexpr int DOUBLE_N = n * 2;
    cout << DOUBLE_N << endl;
    return 0;
}
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:6:34: error: the value of ‘n’ is not usable in a constant expression
    6 |     constexpr int DOUBLE_N = n * 2;
      |                                  ^
main.cpp:5:9: note: ‘int n’ is not const
    5 |     int n = 5;
      |         ^

The variable n is not a constant, so its value is unknown to the compiler. An ordinary const, however, accepts a value that is calculated at run time:

const_runtime.cpp
int n = 5;
const int DOUBLE_N = n * 2;
cout << DOUBLE_N << endl;
10
KeywordWhen is the value known?When do we use it?
constIt may be known at run timeA value we do not want to change once it is set
constexprIt must be known at compile timeTrue constants such as π and the number of seconds in a day

The practical rule: make constants that are known in advance constexpr, and use const for everything else.

The Old Way: #define

Before const and constexpr appeared, programmers used the #define directive. You will see it a lot in old code, so you must know it and know its drawbacks:

define_demo.cpp
#include <iostream>
using namespace std;

#define MAX_SCORE 100
#define SQUARE(x) x * x

int main() {
    cout << MAX_SCORE << endl;
    cout << SQUARE(2 + 3) << endl;
    return 0;
}
100 11

Look at the second output! We expected 25, because (2+3) squared is 25, but we got 11.

The reason is that #define is neither a variable nor a function. It is a textual replacement carried out by the preprocessor before compilation. The expression became 2 + 3 * 2 + 3, and multiplication comes before addition, which gives 11. The preprocessor does not add parentheses and does not check types.

Aspect#defineconst / constexpr
TypeNo type (text only)Has a type that the compiler checks
ScopeApplies from where it is defined to the end of the fileFollows the scope of ordinary variables
End of lineDoes not end with a semicolonEnds with a semicolon
The most famous mistakeStrange results like the squaring exampleClear errors that the compiler detects

The modern alternative to the previous example is a constexpr function (you will study functions later):

square_fn.cpp
#include <iostream>
using namespace std;

constexpr int square(int x) { return x * x; }

int main() {
    cout << square(2 + 3) << endl;
    return 0;
}
25

In new C++ code, always prefer const and constexpr over #define.

Literals and Their Suffixes

A value written directly in the code, such as 42, 2.5, 'x', "Hi" or true, is called a literal. Literals are constants by nature too, so you cannot write 5 = x;. Every literal has a type decided by its form:

FormIts typeExample
A number without a fractionint42
A number with a decimal fractiondouble2.5
A fraction followed by ffloat2.5f
A number followed by LLlong long9000000000LL
A character between single quotation markschar'x'
Text between double quotation marksString literal"Hi"

Let's check the type of a decimal number and the effect of the form of a literal on division:

literals.cpp
cout << sizeof(2.5) << " " << sizeof(2.5f) << endl;
cout << 7 / 2 << " " << 7 / 2.0 << endl;
8 4 3 3.5

The first line confirms that 2.5 takes 8 bytes (double) while 2.5f takes 4 bytes (float). The second line reminds us of integer division: 7 / 2 gives 3, while 7 / 2.0 gives 3.5.

Lesson Project: The Restaurant Bill

We learn how a constant makes the calculation clear and easy to change.

The idea

A fast-food restaurant needs a program that calculates the bill of a table that ordered a burger, fries and a juice. A 15% tax rate is added to the total, and it may change in the future, so we do not want it written in more than one place.

What you need to do
  1. Define the constant VAT_RATE with the value 0.15.
  2. Define three decimal variables for the item prices: the burger 32.0, the fries 12.0, and the juice 9.5.
  3. Calculate the total before tax, then the tax amount, then the final total, each in its own variable.
  4. Print the three lines shown below.
The expected output
Subtotal: 53.5 SAR VAT (15%): 8.025 SAR Total: 61.525 SAR
After you have tried it yourself: show the solution
restaurant_bill.cpp
#include <iostream>
using namespace std;

int main() {
    const double VAT_RATE = 0.15;

    double burger = 32.0;
    double fries = 12.0;
    double juice = 9.5;

    double subtotal = burger + fries + juice;
    double vat = subtotal * VAT_RATE;
    double total = subtotal + vat;

    cout << "Subtotal:  " << subtotal << " SAR" << endl;
    cout << "VAT (15%): " << vat << " SAR" << endl;
    cout << "Total:     " << total << " SAR" << endl;
    return 0;
}

If the government decided to change the rate, you would edit a single line at the start of the program instead of looking for the number everywhere.

A Circle with a Constant π

Easy

We want to calculate the area and the circumference of a circle with a known radius. The value π is a mathematical constant that should not change, so make it a constant instead of writing it everywhere.

Requirements
  • Define a constant PI with the value 3.14159.
  • Define a decimal variable radius with the value 7.
  • Calculate the area PI * radius * radius and the circumference 2 * PI * radius in two variables.
  • Print the two results as shown in the expected output.
Expected output
Area: 153.938 Circumference: 43.9823
Hints
  • Put the word const before double PI.
  • Write the number 3.14159 only once in the entire program.
Sample solution (after you try)
circle.cpp
// Challenge 1: circle
#include <iostream>
using namespace std;

int main() {
    const double PI = 3.14159;
    double radius = 7;

    double area = PI * radius * radius;
    double circumference = 2 * PI * radius;

    cout << "Area: " << area << endl;
    cout << "Circumference: " << circumference << endl;
    return 0;
}
2

How Many Seconds in a Few Days?

Medium

We want to convert a number of days into seconds. Build the constants on top of each other using constexpr, then use the last constant in the calculation.

Requirements
  • Define constexpr constants for the seconds in a minute, the minutes in an hour and the hours in a day.
  • Define a fourth constant SECONDS_PER_DAY that multiplies the first three.
  • Define days with the value 3, and store the result in a variable of type long long.
  • Print the sentence as shown in the expected output.
Expected output
3 days = 259200 seconds
Hints
  • constexpr int SECONDS_PER_DAY = SECONDS_PER_MINUTE * MINUTES_PER_HOUR * HOURS_PER_DAY;
  • Convert days to long long before multiplying by using static_cast<long long>.
Sample solution (after you try)
days_to_seconds.cpp
// Challenge 2: days to seconds
#include <iostream>
using namespace std;

int main() {
    constexpr int SECONDS_PER_MINUTE = 60;
    constexpr int MINUTES_PER_HOUR = 60;
    constexpr int HOURS_PER_DAY = 24;
    constexpr int SECONDS_PER_DAY = SECONDS_PER_MINUTE * MINUTES_PER_HOUR * HOURS_PER_DAY;

    int days = 3;
    long long seconds = static_cast<long long>(days) * SECONDS_PER_DAY;

    cout << days << " days = " << seconds << " seconds" << endl;
    return 0;
}

Quick summary

  • A constant is a value that does not change after it is defined, and we define it with const or constexpr.
  • A constexpr value is known at compile time, so it works, for example, as the size of an array.
  • Magic numbers are replaced with constants whose names explain their meaning.
  • We avoid #define because it is text replacement with no type and no protection.
  • Suffixes such as f and LL set the type of a literal.

Glossary

The most important terms in this lesson:

Constant

A value that does not change while the program runs.

const

A keyword that makes a variable unchangeable after it is initialized.

constexpr

A constant whose value is calculated during compilation, before the program runs.

Literal

A value written directly in the code, such as 42 or "Hi".

Magic number

A number that appears in the code without a name that explains its meaning.

Macro

A name that the preprocessor replaces with text before compilation, such as with #define.

Compile time

The stage in which the compiler examines the code before it runs.

Run time

The stage in which the computer actually executes the program.

Read-only

A value that can be read but cannot be changed.

Naming convention

An agreement on the shape of names, such as writing constants in capital letters.

Suffix

A letter added to the end of a number to set its type, such as f and LL.
