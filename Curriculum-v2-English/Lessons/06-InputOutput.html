Input/Output

Input/Output — a program that listens and talks

What will you learn in this lesson?

  • Read values of different types from the user with cin
  • Read a whole line with getline and avoid the cin then getline trap
  • Format the output with setw, fixed and setprecision
  • Know the two fast input/output lines used in contests
  • Build a complete program that reads data and prints a formatted result

A Program That Talks Back: cin

Until now our programs only talked to us. Now we learn to listen: cin is the stream that matches cout, and it brings data in from the keyboard. Its arrow points the opposite way to the one in cout: >> pulls the value out of the stream and puts it into the variable.

StreamDirectionOperatorExample
coutFrom the program to the screen<<cout << x;
cinFrom the keyboard to the program>>cin >> x;
age.cpp
#include <iostream>using namespace std; int main() {    int age;    cout << "Enter your age: ";    cin >> age;    cout << "Next year you will be " << age + 1 << endl;    return 0;}

Reading Several Values

Several reads can be chained in one statement by repeating >>. cin separates the values at any whitespace: a space, a new line or a tab. It does not matter how the user typed them:

three_numbers.cpp
int a, b, c;
cin >> a >> b >> c;
cout << "Sum: " << a + b + c << endl;
cout << "Average: " << (a + b + c) / 3.0 << endl;

Here the user typed the first number on one line, and the other two numbers on the second line:

10 20 35
Sum: 65 Average: 21.6667

Reading different types

cin reads each value according to the type of the variable facing it. Text is read as a single word, and a character skips any whitespace before it:

mixed_types.cpp
string name;
int level;
double score;
char grade;
cin >> name >> level >> score >> grade;

cout << name << " | level " << level << " | score " << score << " | grade " << grade << endl;
Layla 3 87.5 B
Layla | level 3 | score 87.5 | grade B

Watch out: when reading into a string with >>, the reading stops at the first whitespace. The name Layla Ahmed will give only Layla, and Ahmed is left for the next read, which fails if it is a number. We deal with this using the getline function in the next section.

Reading a Whole Line: getline

If you want to read text that contains spaces, such as a full name or a sentence, use getline(cin, variable). It reads everything the user typed until they pressed Enter:

getline_demo.cpp
string fullName;
cout << "Your full name: ";
getline(cin, fullName);
cout << "Welcome, " << fullName << "!" << endl;
Noura Al-Harbi
Your full name: Welcome, Noura Al-Harbi!

The famous trap: cin followed by getline

When you read a number with cin >>, it takes only the number and leaves the press of Enter (the new-line character) in the stream. So if we call getline right after it, it reads only that new line and returns an empty text:

pitfall.cpp
int n;
string line;
cin >> n;
getline(cin, line);
cout << "n = " << n << endl;
cout << "Line: [" << line << "]" << endl;
5 Hello world
n = 5 Line: []

Notice that the words Hello world were not read. The cure: we get rid of the rest of the current line before getline by using cin.ignore:

pitfall_fixed.cpp
int n;
string line;
cin >> n;
cin.ignore(1000, '\n');
getline(cin, line);
cout << "n = " << n << endl;
cout << "Line: [" << line << "]" << endl;
n = 5 Line: [Hello world]

The function cin.ignore(1000, '\n') skips up to 1000 characters, or up to the first new line (whichever comes first).

Formatting the Output

The <iomanip> library gives us tools to format what we print. The most important are:

ToolWhat it does
setw(n)Reserves a width of n places for the next value only
left / rightAligns the value to the left or to the right inside the reserved width
fixedShows decimal numbers without scientific notation, and makes setprecision count the digits after the decimal point
setprecision(n)Sets the number of digits shown

A simple table with neatly arranged columns:

table.cpp
cout << left << setw(10) << "Item" << right << setw(8) << "Price" << endl;
cout << fixed << setprecision(2);
cout << left << setw(10) << "Tea" << right << setw(8) << 3.5 << endl;
cout << left << setw(10) << "Sandwich" << right << setw(8) << 12.0 << endl;
cout << left << setw(10) << "Water" << right << setw(8) << 1.25 << endl;
Item Price Tea 3.50 Sandwich 12.00 Water 1.25

The setw tool affects only the value that comes right after it, so we repeat it before every value. fixed and setprecision, on the other hand, keep their effect until we change them. Notice the difference between using fixed and not using it:

precision.cpp
double pi = 3.14159265;
cout << pi << endl;
cout << fixed << setprecision(2) << pi << endl;
cout << setprecision(4) << pi << endl;
3.14159 3.14 3.1416

Without fixed, the precision is the total number of significant digits (6 by default), and with it, the precision becomes the number of digits after the decimal point.

Fast Input and Output for Contests

In programming contests, programs may read hundreds of thousands of numbers, and this is where the cost of the default link between cin/cout and the old C library shows up. Contestants use two lines at the start of main to speed this up:

fast_io.cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int a, b;
    cin >> a >> b;
    cout << a + b << '\n';
    return 0;
}
120 80
200
LineWhat it does
ios::sync_with_stdio(false);Cuts the link with the C library, so input and output become faster
cin.tie(nullptr);Stops cout from being flushed automatically before every read

After using these two lines, do not mix cin/cout with C functions such as scanf/printf in the same program, and use '\n' instead of endl, because endl flushes the buffer every time. In interactive programs that wait for the user's reply, do not use them, or the messages will appear late.

Lesson Project: A Payslip

We read an employee's data from the user and then print it in a formatted statement.

The idea

A small company pays its employees by the hour. It wants a program that asks for the employee's name, the number of hours and the hourly rate, and then prints a neat statement with the total, using two decimal places as in financial calculations.

What you need to do
  1. Read three values in this order with a single cin statement: the name (one word), the number of hours (an integer), and the hourly rate (a decimal).
  2. Calculate the total by multiplying the hours by the rate.
  3. Print the statement shown below: the field labels are left-aligned in a width of 8 places, and all decimal numbers have two digits after the decimal point.
An example of the required run

If the user types the following line:

Huda 38 45.5
=== Payslip === Name: Huda Hours: 38 Rate: 45.50 SAR/h Total: 1729.00 SAR

Before you write: which formatting tools do you need? (setw, left, fixed, setprecision). And which header do you need for them?

After you have tried it yourself: show the solution
payslip.cpp
#include <iostream>
#include <iomanip>
#include <string>
using namespace std;

int main() {
    string name;
    int hours;
    double rate;
    cin >> name >> hours >> rate;

    double total = hours * rate;

    cout << fixed << setprecision(2);
    cout << "=== Payslip ===" << endl;
    cout << left << setw(8) << "Name:" << name << endl;
    cout << left << setw(8) << "Hours:" << hours << endl;
    cout << left << setw(8) << "Rate:" << rate << " SAR/h" << endl;
    cout << left << setw(8) << "Total:" << total << " SAR" << endl;
    return 0;
}

1

Two Numbers, Four Operations

Easy

Write a program that reads two integers from the user and then prints their sum, difference, product and average.

Requirements
  • Read the two numbers with a single cin statement.
  • Print the sum, the difference and the product, each on its own line.
  • Print the average with one decimal place (do not forget that dividing two integers by 2 drops the fraction).
Example input and expected output
7 10
Sum: 17 Difference: -3 Product: 70 Average: 8.5
Hints
  • Divide by 2.0 and not 2 to get a decimal result.
  • Use fixed and setprecision(1) with the header <iomanip>.
Sample solution (after you try)
two_numbers.cpp
// Challenge 1: two numbers
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    cout << "Sum: " << a + b << endl;
    cout << "Difference: " << a - b << endl;
    cout << "Product: " << a * b << endl;
    cout << fixed << setprecision(1);
    cout << "Average: " << (a + b) / 2.0 << endl;
    return 0;
}
2

Greeting with the Full Name

Medium

Write a program that reads a full name (which may contain spaces) and then an age, and prints a greeting that mentions the age next year.

Requirements
  • Read the full name with the function suited to reading a whole line.
  • Read the age as an integer.
  • Print the sentence in the format shown in the expected output.
Example input and expected output
Sara Al-Qahtani 14
Hello Sara Al-Qahtani! Next year you will be 15.
Hints
  • Read the name first with getline and then the age with cin >>, so the new-line problem does not appear.
  • If you read the age first and then the name, you will need cin.ignore between them.
Sample solution (after you try)
greeting.cpp
// Challenge 2: greeting
#include <iostream>
#include <string>
using namespace std;

int main() {
    string fullName;
    int age;

    getline(cin, fullName);
    cin >> age;

    cout << "Hello " << fullName << "! Next year you will be " << age + 1 << "." << endl;
    return 0;
}

Quick summary

  • getline reads a whole line, and after cin >> we may need cin.ignore().
  • setw, fixed and setprecision format the shape of the output.
  • The two fast input/output lines are used in contests.

Glossary

The most important terms in this lesson:

Input

The data that a program receives from the user.

Output

What a program shows to the user.

cin

The standard stream for reading data from the keyboard.

Extraction operator

The >> symbol, which pulls the value from the stream into the variable.

Whitespace

The space, the tab and the new line, which are what cin separates values at.

getline

A function that reads a whole line, including spaces.

Buffer

An area where data is stored temporarily before it is read or printed.

Flush

Forcing the buffer to send its contents immediately.

setw

Reserves a number of places for the next value.

setprecision

Sets the number of digits shown of a decimal number.

fixed

Shows a decimal number with a fixed number of digits after the decimal point.

Console

The text window where a program shows its output and receives its input.
