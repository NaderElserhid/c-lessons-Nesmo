Sorting — أقوى أداة في صندوق المبرمج

ماذا ستتعلم في هذا الدرس؟

  • تستخدم sort لترتيب المتجهات والمصفوفات تصاعديًا وتنازليًا
  • تكتب دالة مقارنة بلامدا وتكسر التعادل بين العناصر
  • تفرّق بين sort وstable_sort وتعرف متى تحتاج المستقر
  • تفهم كيف تعمل خوارزمية بسيطة مثل الفقاعات ولماذا هي O(n²)
  • تستفيد من الترتيب في حذف التكرار وإيجاد أقرب عددين والترتيب بالعدّ

طابور الصباح

في طابور المدرسة يقف الطلاب من الأقصر إلى الأطول. بعد هذا الترتيب تتغير كل الأسئلة: من الأقصر؟ بسيط، أول واحد. من الأطول؟ آخر واحد. هل يوجد طالبان بنفس الطول؟ سيقفان متجاورين! كثير من المسائل الصعبة تصبح سهلة جدًا بعد الترتيب، ولهذا يعدّ الترتيب (sorting) أهم أداة في صندوق المبرمج.

فكّر بترتيب أوراق اللعب في يدك: تلتقط ورقة وتضعها في مكانها بين الأوراق المرتّبة. هذه فكرة خوارزمية، وسنراها تعمل أمام عينيك في المختبر. أما في برامجك الحقيقية فلن تكتب الخوارزمية بنفسك، بل تستخدم sort الجاهزة السريعة جدًا (O(n log n)).

أول ترتيب: sort

الأداة تعيش في المكتبة <algorithm>. نعطيها بداية المتجه ونهايته:

first_sort.cpp
#include <iostream>#include <vector>#include <algorithm>#include <functional>using namespace std; int main() {    vector<int> v = {42, 7, 19, 3, 25};     sort(v.begin(), v.end());    for (int x : v) {        cout << x << " ";    }    cout << endl;     sort(v.begin(), v.end(), greater<int>());    for (int x : v) {        cout << x << " ";    }    cout << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...

ولترتيب مصفوفة عادية نعطيها عنوان البداية وعنوان ما بعد النهاية:

sort_array.cpp
int a[] = {5, 2, 9, 1};
sort(a, a + 4);
for (int x : a) {
    cout << x << " ";

الأداة sort تعمل فقط على الحاويات التي يمكن القفز فيها إلى أي موضع مثل vector والمصفوفات. أما set وmap فهي مرتّبة أصلًا ولا يجوز ترتيبها (جرّب وسترى رسالة الخطأ أدناه).

sort_a_set.cpp
#include <iostream>
#include <set>
#include <algorithm>
using namespace std;

int main() {
    set<int> s = {3, 1, 2};
    sort(s.begin(), s.end());
    cout << s.size() << endl;
    return 0;
}

خوارزمية الفقاعات خطوة بخطوة

  
أبسط خوارزمية: نقارن كل عنصر بجاره، فإن كان أكبر منه بدّلناهما. بعد كل جولة «يطفو» أكبر عنصر إلى مكانه الأخير مثل فقاعة في الماء:

vector<int> a = {5, 2, 4, 1};int n = a.size();for (int i = 0; i < n - 1; i++) {    for (int j = 0; j < n - 1 - i; j++) {        if (a[j] > a[j + 1]) {            swap(a[j], a[j + 1]);        }    }}for (int x : a) {    cout << x << " ";}cout << endl;

هذه الخوارزمية O(n²) لأن لها حلقتين متداخلتين. هي ممتازة للتعلم، لكن مع مئة ألف عنصر تحتاج عشرة مليارات عملية. لذلك نستخدم sort الجاهزة التي تعمل بطريقة أذكى (قسّم ثم رتّب كل جزء) وتصل إلى O(n log n).







  
قاعدتك الخاصة: دالة المقارنة

  
ماذا لو أردنا ترتيب النصوص بحسب الطول لا بحسب الحروف؟ نمرر إلى sort وسيطًا ثالثًا هو دالة المقارنة (comparator). أسهل طريقة لكتابتها داخل السطر نفسه هي اللامدا:

  
sort_strings.cpp
vector<string> words = {"pear", "apple", "fig", "banana"}; sort(words.begin(), words.end());for (const string& w : words) cout << w << " ";cout << endl; sort(words.begin(), words.end(), [](const string& a, const string& b) {    return a.size() < b.size();});for (const string& w : words) cout << w << " ";cout << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...

  
apple banana fig pear 
fig pear apple banana 

  
الشكل العام: [](const T& a, const T& b) { return ... ; } وتعيد true إذا كان a يجب أن يأتي قبل b. قاعدة المقارنة هي كل ما يلزم لتحديد الترتيب.

  
ترتيب الأزواج وكسر التعادل

  
الزوج pair يُقارَن تلقائيًا بعنصره الأول ثم بالثاني. ولو أردنا الدرجة الأعلى أولًا وعند التعادل الاسم الأبجدي نكتب القاعدة بأنفسنا:

  
sort_pairs.cpp
vector<pair<int, string>> v = {{90, "Omar"}, {85, "Sara"}, {90, "Lina"}}; sort(v.begin(), v.end());for (const auto& p : v) cout << p.first << " " << p.second << endl;cout << "---" << endl; sort(v.begin(), v.end(), [](const pair<int, string>& a, const pair<int, string>& b) {    if (a.first != b.first) {        return a.first > b.first;    }    return a.second < b.second;});for (const auto& p : v) cout << p.first << " " << p.second << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...

  
85 Sara
90 Lina
90 Omar
---
90 Lina
90 Omar
85 Sara

  
 توقّع قبل أن تشغّل
predict_abs.cpp
vector<int> v = {-5, 3, -1, 4};
sort(v.begin(), v.end(), [](int a, int b) {
    return abs(a) < abs(b);
});
for (int x : v) cout << x << " ";
cout << endl;
ماذا سيطبع هذا الكود؟ (المقارنة بالقيمة المطلقة)
-1 3 4 -5 
المقارنة تنظر إلى abs فقط: القيم المطلقة هي 5 و3 و1 و4. الترتيب التصاعدي لها 1 ثم 3 ثم 4 ثم 5، أي العناصر -1 ثم 3 ثم 4 ثم -5.

  
قاعدة ذهبية: دالة المقارنة يجب أن تكون صارمة، فاستخدم < أو > ولا تستخدم <= أو >= أبدًا. عند تساوي عنصرين يجب أن تعيد false للاتجاهين. مخالفة ذلك قد تسبب انهيار البرنامج أو دخوله في حلقة لا تنتهي.







  
مختبر تفاعلي (2): جرّب قواعد الترتيب

  
هذه قائمة طلاب. اختر قاعدة ترتيب ولاحظ النتيجة وكود اللامدا المقابل لها. انتبه لما يحدث عند تعادل الدرجات!

  

    

      

    

    

  







  
الترتيب المستقر: stable_sort

  
حين يتساوى عنصران بحسب القاعدة، قد يغيّر sort ترتيبهما النسبي. إن أردت أن يبقى كل متساويين بنفس ترتيبهما الأصلي فاستخدم stable_sort:

  
stable_sort.cpp
vector<pair<string, int>> jobs = {{"A", 2}, {"B", 1}, {"C", 2}, {"D", 1}};

stable_sort(jobs.begin(), jobs.end(), [](const pair<string, int>& a, const pair<string, int>& b) {
    return a.second < b.second;
});
for (const auto& j : jobs) cout << j.first << j.second << " ";
cout << endl;

  
B1 D1 A2 C2 

  
الاثنان B وD متساويان (1)، والاثنان A وC متساويان (2)، وبقي كل زوج بالترتيب الذي دخل به. هذا يسمى ترتيبًا مستقرًا (stable).

  
ترتيب الأرقام بدل القيم

  
أحيانًا تريد أن تعرف من صاحب أعلى درجة لا الدرجة فقط. الحيلة: رتّب أرقام الأماكن وقارنها بقيمها:

حيل ما بعد الترتيب

  
حيلة 1: حذف التكرار. بعد الترتيب تتجاور القيم المتساوية، فيحذفها unique. هي لا تحذف فعليًا بل تنقل التكرار إلى النهاية وتعيد مؤشر بدايته، فنقص منه بـ erase:

  
sort_unique.cpp
vector<int> v = {4, 2, 4, 9, 2, 7};
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
for (int x : v) cout << x << " ";
cout << endl;

  
2 4 7 9 

  
حيلة 2: أقرب عددين. بعد الترتيب لا تحتاج مقارنة كل عددين: يكفي الفرق بين كل عنصر وجاره. (هذا ما ستفعله في التحدي الثاني!)

  
حيلة 3: الترتيب بالعدّ. إن كانت القيم صغيرة (مثل أرقام من 0 إلى 3) فلا نحتاج sort أصلًا، بل نعدّ كم مرة ظهر كل رقم ثم نكتبها:

  
counting_sort.cpp
vector<int> v = {3, 1, 3, 0, 2, 1, 3};
int cnt[4] = {0, 0, 0, 0};

for (int x : v) {
    cnt[x]++;
}
for (int d = 0; d < 4; d++) {
    for (int k = 0; k < cnt[d]; k++) {
        cout << d << " ";
    }
}
cout << endl;

  
0 1 1 2 3 3 3 

  
هذا الأسلوب يسمى الترتيب بالعدّ (counting sort) وهو O(n + k) حيث k مدى القيم. أسرع من sort حين يكون المدى صغيرًا.

#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<pair<int, string>> runners;
    for (int i = 0; i < n; i++) {
        string name;
        int seconds;
        cin >> name >> seconds;
        runners.push_back({seconds, name});
    }

    sort(runners.begin(), runners.end());

    for (int i = 0; i < n; i++) {
        cout << i + 1 << ". " << runners[i].second << " " << runners[i].first << "s" << endl;
    }
    cout << "Gap between first and last: " << runners[n - 1].first - runners[0].first << "s" << endl;
    return 0;
}

ترتيب تنازلي
سهل
اقرأ n ثم n عددًا. اطبعها مرتّبة من الأكبر إلى الأصغر، يفصل بينها فراغ.
المطلوب
  • خزّن الأعداد في vector<int>.
  • رتّبها بـ sort مع greater<int>().
  • لا تطبع فراغًا بعد آخر عدد.
مثال على الإدخال والناتج المتوقع
6
12 5 40 7 5 19
40 19 12 7 5 5
 تلميحات
  • تحتاج #include <functional> لاستخدام greater.
  • يمكنك طباعة الفراغ بشرط i + 1 < n أو تستخدم متغير first كما فعلنا سابقًا.
 نموذج الحل (بعد المحاولة)
descending.cpp
// Challenge 1: sort numbers in descending order
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> v(n);
    for (int i = 0; i < n; i++) {
        cin >> v[i];
    }
    sort(v.begin(), v.end(), greater<int>());
    for (int i = 0; i < n; i++) {
        cout << v[i] << (i + 1 < n ? " " : "\n");
    }
    return 0;
}

أصغر فرق
متوسط
اقرأ n ≥ 2 ثم n عددًا. اطبع أصغر فرق موجب بين أي عددين منها.
المطلوب
  • رتّب الأعداد أولًا.
  • الفرق الأصغر دائمًا بين عددين متجاورين بعد الترتيب.
  • استخدم min لتحديث أفضل فرق وانتبه لحدود الحلقة.
مثال على الإدخال والناتج المتوقع
5
8 1 15 4 20
3
 تلميحات
  • ابدأ بـ best = v[1] - v[0] ثم قارن بقية الأزواج المتجاورة.
  • مع الأعداد 8 1 15 4 20 تصبح مرتّبة 1 4 8 15 20 والفروق 3 و4 و7 و5.
 نموذج الحل (بعد المحاولة)
min_difference.cpp
// Challenge 2: smallest difference between any two numbers
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> v(n);
    for (int i = 0; i < n; i++) {
        cin >> v[i];
    }
    sort(v.begin(), v.end());
    int best = v[1] - v[0];
    for (int i = 1; i + 1 < n; i++) {
        best = min(best, v[i + 1] - v[i]);
    }
    cout << best << endl;
    return 0;
}



ملخص سريع
  • sort(v.begin(), v.end()) ترتّب تصاعديًا، وتحتاج #include <algorithm>، وسرعتها O(n log n).
  • للترتيب التنازلي أضف greater<int>() كوسيط ثالث، أو اكتب قاعدتك بلامدا.
  • لامدا المقارنة تعيد true إذا كان a يجب أن يسبق b، ويجب أن تكون **صارمة** (< أو > وليس <=).
  • الأزواج pair تُقارَن بالعنصر الأول ثم الثاني، وهي مفيدة جدًا لكسر التعادل.
  • stable_sort تحافظ على الترتيب الأصلي للعناصر المتساوية.
  • لمعرفة «من» صاحب القيمة رتّب الأرقام (iota) وقارنها بقيمها.
  • بعد الترتيب: unique تحذف التكرار، والفرق بين الجيران يعطي أقرب عددين. وللقيم الصغيرة استعمل الترتيب بالعدّ.
