الطابور Queue

أول من يدخل هو أول من يخرج. في هذا المختبر ستبني طابورًا بيدك، وتتابع برامج C++ سطرًا بسطر، وتتعرّف على كل دالة في std::queue، ثم ترى كيف يُبنى الطابور من الداخل باستخدام مصفوفة دائرية.

القاعدة FIFO المكتبة #include <queue> زمن كل عملية O(1)
01

ما هو الطابور؟

الطابور (Queue) هيكل بيانات خطّي يحفظ العناصر بترتيب وصولها. نُضيف العناصر من طرف واحد اسمه المؤخرة (back)، ونحذفها من الطرف الآخر واسمه المقدمة (front). لذلك يخرج دائمًا العنصر الذي انتظر أطول مدة، تمامًا كطابور المخبز أو صرّاف البنك.

هذه القاعدة اسمها FIFO أي First In, First Out: «الداخل أولًا يخرج أولًا». لا يمكنك أن تتجاوز الدور، ولا أن تصل إلى عنصر في المنتصف.

الإضافة

إدخال عنصر جديد إلى المؤخرة. يصبح هو الـ back الجديد.

pop · dequeue

الحذف

إخراج العنصر الموجود في المقدمة. يصبح العنصر الذي يليه هو الـ front.

الطابور Queue · FIFO

الداخل أولًا يخرج أولًا. نضيف من طرف ونحذف من الطرف الآخر، مثل صف الانتظار.

المكدس Stack · LIFO

الداخل أخيرًا يخرج أولًا. نضيف ونحذف من الطرف نفسه، مثل كومة الأطباق.

أين يُستخدم الطابور؟
  • طابور أوامر الطباعة في الطابعة
  • جدولة العمليات في نظام التشغيل
  • البحث بالعرض BFS في الرسوم البيانية
  • المخزن المؤقت (buffer) للوحة المفاتيح والشبكات
  • أنظمة الحجز وخدمة العملاء

      04
      
دوال std::queue

      
هذه الدوال الأعضاء التي ستستخدمها في كل برنامج تقريبًا. جميعها تعمل في زمن ثابت O(1) مهما كان حجم الطابور. ابدأ بالتعريف:

    


    
#include <queue>        // المكتبة اللازمة
using namespace std;

queue<int> q;             // طابور أعداد صحيحة
queue<string> names;      // طابور نصوص
queue<double> prices;     // طابور أعداد عشرية


    

      

        
الدالةماذا تفعلتُعيدتعدّل الطابور؟

        
          
push(x)تضيف x إلى المؤخرةvoidنعم

          
pop()تحذف العنصر الأولvoidنعم

          
front()تقرأ العنصر الأولT&لا

          
back()تقرأ العنصر الأخيرT&لا

          
empty()هل الطابور فارغ؟boolلا

          
size()عدد العناصرsize_tلا

          
emplace(args)تبني عنصرًا في المؤخرة مباشرةvoidنعم

          
swap(other)تبادل محتوى طابورينvoidنعم

        
      

    


    

      

        
push(x)
تعدّل

        
void push(const T& x);

        
تضيف نسخة من القيمة x إلى مؤخرة الطابور، فيزيد الحجم بواحد ويصبح x هو الـ back الجديد. العنصر الأول لا يتغيّر.

        
queue<int> q;
q.push(5);
q.push(8);     // q = {5, 8}
q.push(3);     // q = {5, 8, 3}

        
      


      

        
pop()
تعدّل

        
void pop();

        
تحذف العنصر الموجود في المقدمة. انتبه: لا تُعيد أي قيمة. إذا احتجت العنصر فاقرأه أولًا بـ front() ثم احذفه.

        
int first = q.front();   // نقرأ أولًا
q.pop();                 // ثم نحذف

        
استدعاء pop() على طابور فارغ سلوك غير معرّف (Undefined Behavior)، وقد يتعطّل البرنامج.

        
      


      

        
front()
تقرأ

        
T& front();

        
تُعيد مرجعًا (reference) إلى العنصر الأول دون حذفه. لأنها مرجع، يمكنك أيضًا تعديل العنصر الأول مباشرة.

        
// q = {5, 8, 3}
cout << q.front();   // 5
q.front() = 50;      // q = {50, 8, 3}

        
      


      

        
back()
تقرأ

        
T& back();

        
تُعيد مرجعًا إلى آخر عنصر أُضيف. مفيدة عندما تريد معرفة آخر قيمة دخلت دون أن تحفظها في متغير.

        
q.push(9);
cout << q.back();    // 9

        
      


      

        
empty()
تقرأ

        
bool empty() const;

        
تُعيد true إذا لم يكن في الطابور أي عنصر. هي حارس الأمان: استخدمها قبل front() وback() وpop()، وهي شرط الحلقة المعتاد لتفريغ الطابور.

        
while (!q.empty()) {
    cout << q.front() << " ";
    q.pop();
}

        
ملاحظة: cout << q.empty() يطبع 1 أو 0، لأن cout يطبع القيم المنطقية كأرقام ما لم تستخدم boolalpha.

        
      


      

        
size()
تقرأ

        
size_t size() const;

        
تُعيد عدد العناصر الموجودة حاليًا. النوع size_t عدد صحيح بلا إشارة، فلا يمكن أن يكون سالبًا.

        
// q = {5, 8, 3}
cout << q.size();    // 3

        
      


      

        
emplace(args...)
تعدّل

        
void emplace(Args&&... args);

        
مثل push، لكنها تبني العنصر في مكانه مباشرة من وسائط المُنشئ (constructor) بدل إنشائه ثم نسخه. تظهر فائدتها مع الأنواع المركّبة مثل pair والـ struct.

        
queue<pair<int, string>> tasks;
tasks.emplace(1, "print");
tasks.push({2, "save"});   // المكافئ بـ push

      


      

        
swap(other)
تعدّل

        
void swap(queue& other);

        
تبادل محتويات طابورين من النوع نفسه في زمن ثابت، دون نسخ العناصر واحدًا واحدًا. طريقة سريعة أيضًا لتفريغ طابور: بادله مع طابور فارغ.

        
queue<int> a, b;
a.push(1);
a.swap(b);       // a = {}, b = {1}

      

    

  


  
  

    

      05
      
أخطاء شائعة

      
هذه الأخطاء تتكرر كثيرًا في الواجبات والامتحانات. اقرأ الخطأ وصحّحه قبل أن تنظر إلى الحل.

    

    

      

        
توقّع أن pop() تُعيد العنصر
في C++ الدالة pop() نوعها void. هذا السطر لا يُترجم أصلًا. القراءة والحذف خطوتان منفصلتان.

        

          خطأ
int x = q.pop();

          صحيح
int x = q.front();
q.pop();

        

      

      

        
القراءة أو الحذف من طابور فارغ
البرنامج يُترجم بلا أخطاء، لكن عند التشغيل يكون السلوك غير معرّف: قيمة عشوائية أو تعطّل. تحقّق دائمًا بـ empty().

        

          خطأ
cout << q.front();
q.pop();

          صحيح
if (!q.empty()) {
    cout << q.front();
    q.pop();
}

        

      

      

        
محاولة الوصول بالفهرس أو المرور على العناصر
الطابور لا يدعم q[i] ولا حلقة for (int x : q). ترى فقط المقدمة والمؤخرة. لطباعة كل العناصر مرّر الطابور إلى دالة بالقيمة (نسخة)، ثم فرّغ النسخة فيبقى الأصل كما هو.

        

          خطأ
cout << q[1];

          صحيح
void printQueue(queue<int> q) {   // نسخة
    while (!q.empty()) {
        cout << q.front() << " ";
        q.pop();
    }
}

        

      

      

        
نسيان المكتبة
بدون #include <queue> سيقول المترجم إن queue غير معرّف. بعض المترجمات تقبلها صدفةً عبر مكتبات أخرى، فلا تعتمد على ذلك.

        

          صحيح
#include <iostream>
#include <queue>
using namespace std;

كيف يُبنى الطابور من الداخل؟

      
std::queue في الحقيقة «مُكيِّف حاويات» (container adaptor): يلتف حول حاوية أخرى، وهي deque افتراضيًا، ويسمح لك فقط بعمليات الطابور. أما في المقررات فيُطلب منك غالبًا بناء طابور بنفسك باستخدام مصفوفة دائرية.

    

    

      
لماذا دائرية؟ لو استخدمنا مصفوفة عادية وحرّكنا frontIdx إلى الأمام مع كل حذف، ستبقى الخانات في بداية المصفوفة فارغة ولن نستخدمها مرة أخرى. الحل: عندما يصل المؤشر إلى آخر المصفوفة يعود إلى الخانة 0 باستخدام باقي القسمة: (index + 1) % CAP.

      
المختبر يبدأ بحالة مثال: أضفنا 12 و7 و31 و5 ثم حذفنا مرتين. أضف أربعة عناصر الآن وراقب rearIdx وهو يلتف إلى البداية.
