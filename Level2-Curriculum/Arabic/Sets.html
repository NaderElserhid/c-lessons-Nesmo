Sets — قيم بلا تكرار ومرتّبة دائمًا

ماذا ستتعلم في هذا الدرس؟

  • تفهم متى نستخدم المجموعة بدل المتجه
  • تستخدم insert وerase وcount وfind وتتعامل مع end() بأمان
  • تجيب عن أسئلة «الأقرب» بـ lower_bound وupper_bound
  • تفرّق بين set وmultiset وunordered_set وتختار المناسب
  • تستعمل حيلة تحويل المتجه إلى مجموعة لحذف التكرار وعدّ القيم المختلفة

مشكلة بوابة الحفلة

تخيّل أنك تقف على بوابة حفلة مدرسية، وكل ضيف يقول اسمه. مطلوب منك سؤالان فقط: «هل دخل هذا الاسم من قبل؟» و«كم شخصًا مختلفًا حضر؟». لو خزّنت الأسماء في vector فسيتكرر الاسم كلما جاء صاحبه، وللبحث عن اسم ستفحص القائمة كلها واحدًا واحدًا.

المجموعة (set) كدفتر ضيوف ذكي: لا يقبل الاسم مرتين، ويرتّب الأسماء من تلقاء نفسه، ويجيب عن «هل هذا الاسم موجود؟» بسرعة خارقة دون أن يقلّب كل الصفحات.

ثلاث خصائص تجعل المجموعة أداة أساسية في المسابقات: لا تكرار، وترتيب دائم، وبحث وإضافة وحذف بسرعة O(log n) (سنفهم معنى هذا الرمز بالتفصيل في درس تحليل التعقيد).

أول مجموعة لنا

نضيف المكتبة <set> ثم نكتب نوع العناصر بين < > كما فعلنا مع المتجه. اضغط على أي سطر مضيء لتقرأ شرحه:

first_set.cpp
#include <iostream>#include <set>using namespace std; int main() {    set<int> s;    s.insert(30);    s.insert(10);    s.insert(20);    s.insert(10);     cout << "size = " << s.size() << endl;    for (int x : s) {        cout << x << " ";    }    cout << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
size = 3 10 20 30

أضفنا أربع مرات لكن الحجم ثلاثة، لأن الإضافة الرابعة كانت للعدد 10 الموجود أصلًا. ولاحظ أن الطباعة خرجت مرتّبة رغم أننا أضفنا 30 أولًا.

لا توجد في المجموعة فهارس: لا يمكنك كتابة s[0]. العنصر في المجموعة لا يُعرَف بموقعه بل بقيمته، وهذا ما نسأل عنه.

مختبر تفاعلي: جرّب المجموعة بنفسك

أضف أعدادًا بأي ترتيب وراقب كيف ترتّب المجموعة نفسها. جرّب إضافة عدد مكرر، ثم اسأل عن lower_bound وupper_bound لترى أي عنصر يعيدان.

صندوق أدوات المجموعة

الأمرماذا يفعل؟السرعة
s.insert(x)يضيف x إن لم يكن موجودًاO(log n)
s.erase(x)يحذف القيمة x إن وُجدتO(log n)
s.count(x)يعطي 1 إن وُجدت و0 إن لم توجدO(log n)
s.find(x)يعيد مؤشرًا للعنصر أو s.end() إن لم يوجدO(log n)
s.lower_bound(x)أول عنصر ≥ xO(log n)
s.upper_bound(x)أول عنصر > xO(log n)
s.size() / s.empty()العدد / هل هي فارغة؟O(1)
*s.begin() / *s.rbegin()أصغر عنصر / أكبر عنصرO(1)
membership.cpp
set<string> guests = {"Sara", "Omar", "Lina"};

cout << guests.count("Omar") << " " << guests.count("Zaid") << endl;

if (guests.find("Lina") != guests.end()) {
    cout << "Lina is here" << endl;
}

guests.erase("Omar");
cout << guests.size() << endl;
1 0 Lina is here 2

الأمر find لا يعيد قيمة بل مؤشرًا (iterator) يشير إلى مكان العنصر. فإن لم يوجد العنصر يعيد s.end()، وهو «موقع بعد النهاية» لا يجوز قراءته. لذلك نقارنه دائمًا بـ end() قبل أن نستخدمه. وإن أردنا الجواب «موجود أم لا» فقط، فـ count أقصر وأوضح.

هل نجحت الإضافة؟

الأمر insert يعيد زوجًا (pair) ثانيه second يخبرنا هل أُضيف العنصر فعلًا:

insert_result.cpp
set<int> s;
bool first = s.insert(5).second;
bool again = s.insert(5).second;
cout << first << " " << again << endl;
1 0

الإضافة الأولى نجحت (1)، والثانية رُفضت لأن 5 موجود (0).

الأقرب إلى قيمة: lower_bound و upper_bound

لأن المجموعة مرتّبة دائمًا، نستطيع أن نسألها أسئلة «الأقرب»: ما أصغر عنصر لا يقل عن 25؟ هذا هو سر قوتها مقارنة بالمتجه غير المرتّب.

bounds.cpp
set<int> s = {10, 20, 30, 40}; auto a = s.lower_bound(25);cout << *a << endl; auto b = s.upper_bound(30);cout << *b << endl; auto c = s.lower_bound(30);cout << *c << endl; auto d = s.lower_bound(50);cout << (d == s.end() ? "end" : "found") << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
30 40 30 end

استعمل دالة المجموعة نفسها s.lower_bound(x) وليس lower_bound(s.begin(), s.end(), x). الثانية تعمل لكنها تمشي على العناصر واحدًا واحدًا فتصبح بطيئة O(n). الدالة العضو وحدها تستفيد من بنية المجموعة وتبقى O(log n).

العنصر الأكبر الأقل من x (السابق)

لا توجد دالة جاهزة للسابق، لكن الحيلة بسيطة: نأخذ lower_bound(x) ثم نتراجع خطوة واحدة بشرط ألا نكون عند begin():

predecessor.cpp
set<int> s = {10, 20, 30, 40};
int x = 25;

auto it = s.lower_bound(x);
if (it != s.begin()) {
    --it;
    cout << "largest below " << x << " is " << *it << endl;
}
largest below 25 is 20

الترتيب والمرور

المرور على المجموعة بحلقة for المبسّطة يعطيك العناصر من الأصغر إلى الأكبر. وأصغر عنصر هو *s.begin() وأكبر عنصر هو *s.rbegin() (المؤشر العكسي). ولو أردت ترتيبًا تنازليًا فاكتب المقارنة greater<int> في تعريف النوع:

order.cpp
set<int> s = {5, 1, 9, 3};
cout << *s.begin() << " " << *s.rbegin() << endl;

set<int, greater<int>> big = {5, 1, 9, 3};
for (int x : big) {
    cout << x << " ";
}
cout << endl;
1 9 9 5 3 1
توقّع قبل أن تشغّل
predict_size.cpp
set<int> s;
for (int x : {3, 1, 3, 2, 1}) {
    s.insert(x);
}
cout << s.size() << endl;

ممنوع تعديل عنصر داخل المجموعة

موقع كل عنصر يعتمد على قيمته، فلو غيّرنا القيمة من الخارج لانهار الترتيب. لذلك المترجم يمنعك:

#include <iostream>

أفراد العائلة: multiset و unordered_set

تتفرع من المجموعة العادية ثلاث نسخ مفيدة:

النوعالتكرارالترتيبالسرعة
setممنوعمرتّبO(log n)
multisetمسموحمرتّبO(log n)
unordered_setممنوعبلا ترتيب مضمونمتوسطها O(1)
multiset.cpp
multiset<int> ms = {3, 1, 3, 2, 3};
cout << ms.size() << " " << ms.count(3) << endl;

ms.erase(ms.find(3));
cout << ms.count(3) << endl;

ms.erase(3);
cout << ms.count(3) << " " << ms.size() << endl;
5 3 2 0 2

انتبه للفرق: erase(3) بالقيمة تحذف كل النسخ، أما erase(ms.find(3)) بالمؤشر فتحذف نسخة واحدة فقط.

unordered.cpp
unordered_set<int> u = {7, 3, 9};
cout << u.count(3) << u.count(4) << " " << u.size() << endl;
10 3

اختر unordered_set حين تحتاج فقط «موجود أم لا» ولا تهتم بالترتيب. واختر set حين تحتاج الترتيب أو lower_bound أو أصغر وأكبر عنصر. في أسوأ الحالات قد تتباطأ unordered_set (عند كثرة التصادمات)، لذلك يفضّل كثيرون set الأضمن أداءً.

حيلة التنظيف: تحويل المتجه إلى مجموعة

أسرع طريقة لحذف التكرار من متجه هي تمريره لمجموعة، فتخرج القيم مرتّبة وبلا تكرار. ويمكن بعدها إرجاعها إلى متجه:

remove_duplicates.cpp
vector<int> v = {4, 2, 4, 9, 2, 2, 7};
set<int> s(v.begin(), v.end());

cout << "distinct: " << s.size() << endl;

vector<int> cleaned(s.begin(), s.end());
for (int x : cleaned) {
    cout << x << " ";
}
cout << endl;
distinct: 4 2 4 7 9

هذه الحيلة تحسب «عدد القيم المختلفة» في سطرين، وهي من أكثر استخدامات المجموعة شيوعًا في المسابقات.

مشروع الدرس: سجل الزوّار

برنامج يسجّل أسماء زوار المعرض دون تكرار ثم يجيب عن أسئلة «هل زارنا فلان؟».

الفكرة

تدير معرض الأعمال المدرسي، وبعض الزوار يمرّون على المعرض أكثر من مرة وتُسجَّل أسماؤهم في كل مرة. تريد معرفة عدد الزوار المختلفين فعلًا، وقائمة بأسمائهم مرتّبة، ثم الإجابة عن بعض الاستفسارات.

المطلوب منك
  1. اقرأ العدد n ثم n اسمًا، وخزّنها في set<string>.
  2. اطبع Distinct visitors: متبوعة بعدد الأسماء المختلفة.
  3. اطبع In order: ثم الأسماء مرتّبة، يسبق كل اسم مسافة.
  4. اقرأ العدد q ثم q اسمًا، واطبع لكل اسم YES إن كان قد زار المعرض وNO إن لم يزره، بالشكل Lina: YES.
مثالان على التشغيل

التشغيل الأول:

6 Sara Omar Sara Lina Omar Zaid 2 Lina Noor
Distinct visitors: 4 In order: Lina Omar Sara Zaid Lina: YES Noor: NO

التشغيل الثاني (الاسم نفسه ثلاث مرات):

3 Ali Ali Ali 1 Ali
Distinct visitors: 1 In order: Ali Ali: YES

تحقق ذهنيًا: في الأسماء Sara وOmar وLina وZaid أربعة مختلفة. والترتيب أبجدي بحسب حروف الأسماء الإنجليزية: Lina ثم Omar ثم Sara ثم Zaid.

بعد أن تجرّب بنفسك: اعرض الحل
visitors.cpp
#include <iostream>
#include <set>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    set<string> visitors;
    for (int i = 0; i < n; i++) {
        string name;
        cin >> name;
        visitors.insert(name);
    }

    cout << "Distinct visitors: " << visitors.size() << endl;
    cout << "In order:";
    for (const string& v : visitors) {
        cout << " " << v;
    }
    cout << endl;

    int q;
    cin >> q;
    for (int i = 0; i < q; i++) {
        string name;
        cin >> name;
        if (visitors.count(name)) {
            cout << name << ": YES" << endl;
        } else {
            cout << name << ": NO" << endl;
        }
    }
    return 0;
}

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

القيم المختلفة مرتّبة

سهل

اقرأ n ثم n عددًا (فيها تكرار). اطبع الأعداد المختلفة فقط، مرتّبة تصاعديًا ويفصل بينها فراغ.

المطلوب
  • استخدم set<int> لتخزين الأعداد.
  • اطبع عناصر المجموعة بحلقة for المبسّطة.
  • لا تضع فراغًا قبل أول عدد ولا بعد آخر عدد.
مثال على الإدخال والناتج المتوقع
7 4 2 4 9 2 2 7
2 4 7 9
تلميحات
  • لا تحتاج أي ترتيب يدوي، فالمجموعة مرتّبة أصلًا.
  • استخدم متغيرًا منطقيًا first لتعرف هل أنت أمام أول عنصر فلا تطبع قبله فراغًا.
نموذج الحل (بعد المحاولة)
distinct_sorted.cpp
// Challenge 1: distinct numbers, ascending
#include <iostream>
#include <set>
using namespace std;

int main() {
    int n;
    cin >> n;
    set<int> s;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        s.insert(x);
    }
    bool first = true;
    for (int x : s) {
        if (!first) {
            cout << " ";
        }
        cout << x;
        first = false;
    }
    cout << endl;
    return 0;
}
2

أقرب عدد لا يقل عن x

متوسط

اقرأ مجموعة أعداد، ثم q استعلامًا. لكل استعلام x اطبع أصغر عدد في المجموعة يساوي x أو أكبر منه، وإن لم يوجد اطبع NONE.

المطلوب
  • خزّن الأعداد في set<int>.
  • لكل استعلام استخدم s.lower_bound(x).
  • قارن النتيجة بـ s.end() قبل قراءة القيمة.
  • اطبع كل جواب في سطر.
مثال على الإدخال والناتج المتوقع
5 10 20 30 40 50 4 25 50 51 5
30 50 NONE 10
تلميحات
  • إن كانت النتيجة تساوي s.end() فلا تقرأها بـ * بل اطبع NONE.
  • اقرأ الاستعلامات في حلقة while (q--) أو for عادية.
نموذج الحل (بعد المحاولة)
next_value.cpp
// Challenge 2: smallest value that is >= x
#include <iostream>
#include <set>
using namespace std;

int main() {
    int n;
    cin >> n;
    set<int> s;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        s.insert(x);
    }
    int q;
    cin >> q;
    while (q--) {
        int x;
        cin >> x;
        auto it = s.lower_bound(x);
        if (it == s.end()) {
            cout << "NONE" << endl;
        } else {
            cout << *it << endl;
        }
    }
    return 0;
}

ملخص سريع

  • المجموعة set تخزّن قيمًا **بلا تكرار** وتُبقيها **مرتّبة** تلقائيًا، وتحتاج #include <set>.
  • insert وerase وcount وfind كلها بسرعة O(log n)، وsize وempty بسرعة O(1).
  • find تعيد مؤشرًا، فإن لم يوجد العنصر أعادت end() وهو لا يُقرأ أبدًا.
  • lower_bound(x) أول عنصر ≥ x، وupper_bound(x) أول عنصر > x. استعمل دالة المجموعة نفسها لا الدالة العامة.
  • لا يمكن تعديل عنصر داخل المجموعة؛ احذفه ثم أضف القيمة الجديدة.
  • multiset يسمح بالتكرار (وerase(قيمة) تحذف كل النسخ)، وunordered_set أسرع غالبًا لكن بلا ترتيب.
  • تحويل متجه إلى set يحذف تكراره ويرتّبه في خطوة واحدة.

قاموس المصطلحات

المصطلحات الإنجليزية الأهم في هذا الدرس ومقابلها بالعربية:

Setمجموعة

حاوية تخزّن قيمًا مختلفة (بلا تكرار) وتُبقيها مرتّبة.

Multisetمجموعة متعددة

مجموعة مرتّبة تسمح بتكرار القيمة نفسها.

Unordered setمجموعة غير مرتّبة

مجموعة بلا ترتيب مضمون، أسرع غالبًا في البحث.

Iteratorمؤشر

كائن يشير إلى عنصر داخل حاوية ويمكن تحريكه.

Duplicateتكرار

ظهور القيمة نفسها أكثر من مرة.

insertإضافة

تضيف قيمة إلى المجموعة إن لم تكن موجودة.

eraseحذف

تزيل قيمة أو عنصرًا من المجموعة.

countعدّ

تعطي عدد مرات ظهور القيمة (0 أو 1 في set).

findبحث

تعيد مؤشرًا للقيمة أو end() إن لم توجد.

lower_boundالحد الأدنى

أول عنصر أكبر من القيمة أو يساويها.

upper_boundالحد الأعلى

أول عنصر أكبر تمامًا من القيمة.

end()نهاية

موقع وهمي بعد آخر عنصر، لا يجوز قراءته.
