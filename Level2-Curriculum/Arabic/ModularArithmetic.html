Modular Arithmetic — الباقي يحكم كل شيء

ماذا ستتعلم في هذا الدرس؟

  • تفهم معنى الباقي % وتتعامل مع الأعداد السالبة بأمان
  • تأخذ الباقي في كل خطوة جمع وطرح وضرب لتجنب الفيضان
  • تحسب a^b mod m بالقوى السريعة في O(log b)
  • تستخدم معكوس الضرب لإجراء «القسمة» بترديد عدد أولي
  • تحلّ مسائل الدورات والتشفير بالباقي

حساب الساعة

إذا كانت الساعة العاشرة وبعد خمس ساعات... لا نقول «الخامسة عشرة» بل الثالثة. نحن نعدّ في دائرة: بعد الثانية عشرة نبدأ من جديد. وإذا كان اليوم السبت فبعد سبعة أيام نعود إلى السبت، وبعد مئة يوم نكون في اليوم الذي يبعد يومين. هذا هو الحساب النمطي (Modular Arithmetic): نهتم فقط بالباقي بعد القسمة.

remainders.cpp
cout << (10 + 5) % 12 << endl;cout << 17 % 5 << endl;cout << 100 % 7 << endl;cout << 6 % 10 << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
3 2 2 6

العامل % يعطي «الباقي». وكأنه ساعة حائط مقياسها m: مهما عددت لأبعد مدى، فعقرب الساعة يعود دائمًا ليشير إلى رقم بين 0 وm-1.

لماذا يهمنا هذا في المسابقات؟ لأن كثيرًا من المسائل جوابها ضخم جدًا لا يتسع في أي متغير، فتطلب المسألة: «اطبع الجواب مقسومًا على 10⁹ + 7 وأعطنا الباقي فقط». وتتعلق مسائل أخرى بالدورات والتكرار، كأيام الأسبوع والتشفير والأقفال الدوّارة.

مختبر تفاعلي (1): ساعة الباقي

اكتب أي عدد a (حتى السالب) والمقياس m. سترى ما يطبعه C++ بالعامل %، وما هو الباقي الرياضي «الحقيقي» الذي نريده، ومكانه على الساعة.

فخ الأعداد السالبة

في الرياضيات الباقي دائمًا بين 0 وm-1. لكن في C++ إذا كان العدد المقسوم سالبًا فالباقي يخرج سالبًا:

negative_remainder.cpp
cout << -7 % 3 << endl;cout << 7 % -3 << endl; int a = -7, m = 3;cout << ((a % m) + m) % m << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
-1 1 2
توقّع قبل أن تشغّل
predict_negative.cpp
int a = -10;
cout << a % 4 << " " << (a % 4 + 4) % 4 << endl;

ماذا سيطبع هذا الكود؟ (تذكّر ما يفعله % مع الأعداد السالبة)

-2 2

في C++ يأخذ الباقي إشارة المقسوم، فـ -10 % 4 يساوي -2. وبعد التصحيح (-2 + 4) % 4 نحصل على 2.

عندما تحسب شيئًا مثل (a - b) % M فقد يكون a < b فيخرج سالبًا! اكتب دائمًا ((a - b) % M + M) % M. ومن الأخطاء الشائعة أيضًا استخدام % مع الكسور؛ فهي للأعداد الصحيحة فقط (للكسور استخدم fmod):

mod_on_double.cpp
#include <iostream>
using namespace std;

int main() {
    double x = 5.5;
    cout << x % 2 << endl;
    return 0;
}
ما يعرضه المترجم (g++)

قواعد الباقي: اضرب واجمع بحرية

الهدية الكبرى: يمكنك أخذ الباقي في أي خطوة من الجمع والطرح والضرب دون أن تتغير النتيجة النهائية:

العمليةالصيغة الآمنة
الجمع(a + b) % M == ((a % M) + (b % M)) % M
الطرح(a - b) % M == ((a % M) - (b % M) + M) % M
الضرب(a * b) % M == ((a % M) * (b % M)) % M
القسمةممنوعة! (a / b) % M ليست (a % M) / (b % M). سنحل هذا بمعكوس الضرب بعد قليل

لنرى الفائدة: العدد 20! (حاصل ضرب 1 إلى 20) يتسع في long long:

factorial_20.cpp
long long f = 1;
for (int i = 1; i <= 20; i++) {
    f = f * i;
}
cout << f << endl;
2432902008176640000

لكن 21! يساوي 51090942171709440000 وهو أكبر من أكبر قيمة يخزنها long long (نحو 9.2 × 10¹⁸) فيحدث فيضان وتصبح النتيجة خاطئة. الحل: خذ الباقي بعد كل ضرب:

factorial_mod.cpp
const long long M = 1000000007;long long f = 1;for (int i = 1; i <= 25; i++) {    f = f * i % M;}cout << f << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
440732388

لماذا لا يفيض f * i % M ؟ لأن f < M ≈ 10⁹ وi صغير، فحاصل الضرب أقل بكثير من 9 × 10¹⁸. وكذلك ضرب عددين كل منهما أقل من 10⁹ + 7 يتسع في long long. لكن ضربهما في int سيفيض، فاستخدم long long دائمًا مع الباقي.

القوى السريعة: ab mod m

كيف نحسب 3²⁰⁰ mod M ؟ مئتا ضربة تكفي هنا، لكن إن كان الأس 10¹⁸ فلن ننتهي أبدًا! الحيلة: نكتب الأس بالنظام الثنائي. مثلًا a¹⁰ = a⁸ · a². فنحسب القوى a, a², a⁴, a⁸... بالتربيع المتكرر ونضرب منها فقط ما تحتاجه. عدد الخطوات O(log b):

fast_power.cpp
#include <iostream>using namespace std; long long powmod(long long base, long long exp, long long mod) {    long long result = 1;    base %= mod;    while (exp > 0) {        if (exp % 2 == 1) {            result = result * base % mod;        }        base = base * base % mod;        exp /= 2;    }    return result;} int main() {    const long long M = 1000000007;    cout << powmod(2, 10, 1000) << endl;    cout << powmod(3, 200, M) << endl;    cout << powmod(5, 0, 13) << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
24 136318165 1

تتبّع 210 mod 1000

power_trace.cpp
long long base = 2, exp = 10, mod = 1000, result = 1;
while (exp > 0) {
    if (exp % 2 == 1) {
        result = result * base % mod;
    }
    base = base * base % mod;
    exp /= 2;
}
cout << result << endl;

مختبر تفاعلي (2): القوى السريعة خطوة بخطوة

اختر الأساس والأس والمقياس، وراقب كيف يربّع الأساس ويقسم الأس وينمو الناتج فقط عند الأس الفردي.

القسمة بترديد: المعكوس

القسمة ممنوعة في الباقي، لكن لها بديل: الضرب في المعكوس. معكوس b بترديد M هو العدد الذي إذا ضُرب في b أعطى 1. وعندما يكون M عددًا أوليًا (مثل 10⁹ + 7) تعطينا نظرية فيرما الصغرى معكوس a بالقانون a^(M-2)، ونحسبه بالقوى السريعة:

modular_inverse.cpp
#include <iostream>using namespace std; long long powmod(long long base, long long exp, long long mod) {    long long result = 1;    base %= mod;    while (exp > 0) {        if (exp % 2 == 1) {            result = result * base % mod;        }        base = base * base % mod;        exp /= 2;    }    return result;} int main() {    const long long M = 1000000007;    long long inv2 = powmod(2, M - 2, M);    cout << inv2 << endl;    cout << 2 * inv2 % M << endl;    cout << 10 * inv2 % M << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
500000004 1 5

صار بإمكاننا قسمة a / b بترديد M بضرب a في powmod(b, M-2, M). (شرط أن يكون b ليس من مضاعفات M.)

حيلة الدورات: أيام الأسبوع

أي شيء يتكرر بدورة طولها m يمكن حساب موضعه بعد عدد هائل من الخطوات بالباقي فقط:

weekday.cpp
string days[] = {"Sat", "Sun", "Mon", "Tue", "Wed", "Thu", "Fri"};
int today = 0;
long long after = 100;
cout << days[(today + after) % 7] << endl;
Mon

والباقي على 10 يعطيك آخر رقم في أي عدد، والباقي على 2 يخبرك هل هو زوجي أم فردي. كلها حالات خاصة من الفكرة نفسها.

مشروع الدرس: شيفرة قيصر

أداة تشفير تزيح كل حرف عددًا ثابتًا من المواضع في الأبجدية.

الفكرة

يقال إن يوليوس قيصر كان يرسل رسائله السرّية بإزاحة كل حرف عدة مواضع في الأبجدية: مع إزاحة 3 يصبح A هو D وZ هو C (الأبجدية دائرة!). الباقي على 26 يحلّ مشكلة العودة من Z إلى A.

المطلوب منك
  1. اقرأ الإزاحة k (قد تكون سالبة لفك التشفير) ثم سطرًا كاملًا من النص بـ getline.
  2. احسب shift = ((k % 26) + 26) % 26 لتصبح بين 0 و25 حتى مع السالب.
  3. لكل حرف إنجليزي صغير أو كبير حرّكه بالإزاحة مع الحفاظ على حالته، وأبقِ الرموز والمسافات كما هي.
  4. اطبع النص الجديد.
مثالان على التشغيل

التشفير:

3 Hello, World!
Khoor, Zruog!

فك التشفير (إزاحة سالبة):

-3 Khoor, Zruog!
Hello, World!

تحقق ذهنيًا: الحرف W رقمه 22 في الأبجدية (من 0)، ومع الإزاحة 3 يصبح 25 وهو Z. والحرف o رقمه 14 فيصبح 17 وهو r. وتشفير x (رقمه 23) بإزاحة 3 يعطي (23+3) % 26 = 0 أي a.

بعد أن تجرّب بنفسك: اعرض الحل
caesar.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int k;
    string text;
    cin >> k >> ws;
    getline(cin, text);

    int shift = ((k % 26) + 26) % 26;
    for (char& c : text) {
        if (c >= 'a' && c <= 'z') {
            c = 'a' + (c - 'a' + shift) % 26;
        } else if (c >= 'A' && c <= 'Z') {
            c = 'A' + (c - 'A' + shift) % 26;
        }
    }
    cout << text << endl;
    return 0;
}

قفل الأرقام الدوّار

سهل

قفل قرصه مرقّم من 0 إلى 9 يقف على الرقم p. نُدخل n حركة، كل حركة عدد صحيح: الموجب يدير القرص للأمام والسالب للخلف، وبعد 9 يأتي 0 وقبل 0 يأتي 9. اطبع الرقم الأخير الذي يقف عنده القفل.

المطلوب
  • اقرأ p وn ثم n حركة.
  • حدّث p بعد كل حركة بصيغة تعالج السالب.
  • اطبع الموضع النهائي.
مثال على الإدخال والناتج المتوقع
3 4 5 -9 4 -6
7
تلميحات
  • الصيغة المطلوبة: p = ((p + step) % 10 + 10) % 10;
  • جرّب مثالًا بيدك: من 3 نضيف 5 فنصل إلى 8، ثم نطرح 9 فنصل إلى 9 (لأن 8 - 9 = -1 والتفاف القفل).
نموذج الحل (بعد المحاولة)
dial_lock.cpp
// Challenge 1: the dial lock
#include <iostream>
using namespace std;

int main() {
    int p, n;
    cin >> p >> n;
    for (int i = 0; i < n; i++) {
        int step;
        cin >> step;
        p = ((p + step) % 10 + 10) % 10;
    }
    cout << p << endl;
    return 0;
}
2

قوة بترديد

متوسط

اقرأ ثلاثة أعداد a وb وm (حيث b حتى 10¹⁸ وm حتى 10⁹ + 7). اطبع ab mod m.

المطلوب
  • استخدم long long لكل المتغيرات.
  • اكتب دالة powmod بالتربيع المتكرر.
  • خذ % mod بعد كل ضرب.
مثال على الإدخال والناتج المتوقع
3 200 1000000007
136318165
تلميحات
  • ابدأ بـ base %= mod لتصغير الأساس أولًا.
  • إن كان الأس فرديًا اضرب الناتج في الأساس الحالي، ثم ربّع الأساس واقسم الأس على 2 في كل دورة.
نموذج الحل (بعد المحاولة)
power_mod.cpp
#include <iostream>
using namespace std;

long long powmod(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp % 2 == 1) {
            result = result * base % mod;
        }
        base = base * base % mod;
        exp /= 2;
    }
    return result;
}

// Challenge 2: a^b mod m
int main() {
    long long a, b, m;
    cin >> a >> b >> m;
    cout << powmod(a, b, m) << endl;
    return 0;
}

ملخص سريع

  • العامل % يعطي باقي القسمة، ونتيجته بين 0 وm-1 مع الأعداد الموجبة.
  • في C++ يأخذ الباقي إشارة المقسوم: -7 % 3 يساوي -1. الإصلاح: ((a % m) + m) % m.
  • نأخذ الباقي في كل خطوة جمع أو طرح أو ضرب دون تغيير النتيجة، لتجنب فيضان long long.
  • القسمة لا تُرَدَّد مباشرة؛ نضرب في المعكوس powmod(b, M-2, M) حين يكون M أوليًا.
  • القوى السريعة: نربّع الأساس ونقسم الأس على 2 فتحتاج O(log b) خطوة فقط.
  • الثابت الشائع في المسابقات: M = 1000000007 (أولي) ويتسع حاصل ضرب عددين أقل منه في long long.
  • الباقي يحلّ مسائل الدورات: أيام الأسبوع وآخر رقم والتشفير والأقفال الدوّارة.

قاموس المصطلحات

المصطلحات الإنجليزية الأهم في هذا الدرس ومقابلها بالعربية:

Moduloالباقي / الترديد

العملية التي تعطي باقي القسمة، ونكتبها %.

Remainderباقي

ما يتبقى بعد قسمة عدد على آخر قسمة صحيحة.

Modulusالمقياس

العدد الذي نقسم عليه، ونرمز له m أو M.

Wrap-aroundالالتفاف

العودة إلى البداية بعد الوصول إلى النهاية، كعقارب الساعة.

Overflowفيضان

تجاوز النتيجة أكبر قيمة يتسع لها النوع.

Binary exponentiationالقوى السريعة

حساب a^b بالتربيع المتكرر في O(log b).

Modular inverseمعكوس الضرب

العدد الذي يضرب في b فيعطي 1 بالترديد.

Fermat little theoremنظرية فيرما الصغرى

إذا كان p أوليًا فإن a^(p-1) يعطي باقي 1 على p.

Primeعدد أولي

عدد أكبر من 1 لا يقبل القسمة إلا على نفسه وعلى 1.

Cycleدورة

نمط يتكرر بعد عدد ثابت من الخطوات.

1e9+7ثابت المسابقات
