تحليل الحالات

Casework — قسّم المسألة إلى حالات صغيرة

ماذا ستتعلم في هذا الدرس؟

  • تقسّم المسألة إلى حالات شاملة ومتنافية وتحلّ كلًّا منها
  • ترتّب الشروط: الاستثناءات أولًا ثم من الأخص إلى الأعم
  • تفرّق بين سلسلة else if وif المستقلة وتستخدم الأقواس دائمًا
  • تختصر الحالات الكثيرة بالعدّ أو بصيغة بالباقي
  • تتحقق من حلّك بالحدود وبمقارنته مع حل القوة الغاشمة

فرز البريد في صناديق

في مكتب البريد توضع كل رسالة في صندوق واحد بحسب المدينة. لا تُترك رسالة بلا صندوق، ولا توضع رسالة في صندوقين. بهذه الفكرة تُحلّ مسائل كثيرة: نقسّم كل الاحتمالات إلى حالات (cases)، ونحلّ كل حالة على حدة بطريقة بسيطة. هذا هو تحليل الحالات (Casework).

الحالات الجيدة تحقق شرطين: شاملة (exhaustive) لا يفلت منها احتمال، ومتنافية (mutually exclusive) لا يقع احتمال في حالتين. وإذا كان لكل حالة جوابها البسيط فقد حلّت المسألة الصعبة.

أدواتنا هنا قديمة معروفة: if / else if / else. الجديد هو طريقة التفكير: كيف نختار الحالات؟ وبأي ترتيب نفحصها؟ وكيف نتأكد أننا لم ننسَ حالة؟

المثال الأول: أنواع المثلثات

نعطيك ثلاثة أضلاع، ومطلوب أن تقول أي نوع هي. لاحظ ترتيب الحالات: نبدأ بالاستثناءات (ضلع غير موجب، لا يتكوّن مثلث)، ثم الحالات الأخص (متساوي الأضلاع) قبل الأعم (متساوي الساقين)، وأخيرًا «ما تبقى». اضغط على الأسطر المضيئة:

triangle_cases.cpp
#include <iostream>#include <string>using namespace std; string classify(int a, int b, int c) {    if (a <= 0 || b <= 0 || c <= 0) {        return "invalid";    }    if (a + b <= c || a + c <= b || b + c <= a) {        return "not a triangle";    }    if (a == b && b == c) {        return "equilateral";    }    if (a == b || b == c || a == c) {        return "isosceles";    }    return "scalene";} int main() {    cout << classify(3, 3, 3) << endl;    cout << classify(3, 3, 5) << endl;    cout << classify(3, 4, 5) << endl;    cout << classify(1, 2, 3) << endl;    cout << classify(0, 4, 4) << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
equilateral isosceles scalene not a triangle invalid

قاعدة الترتيب: ضع الشروط التي تُسقط المدخلات الغريبة أولًا، ثم الحالات من الأخص إلى الأعم. لو فحصنا «متساوي الساقين» قبل «متساوي الأضلاع» لصُنّفت كل المثلثات المتساوية الأضلاع خطأً.

مختبر تفاعلي (1): مصنّف المثلثات

حرّك أطوال الأضلاع الثلاثة وشاهد أي حالة تتحقق، وكيف يتغير الرسم. جرّب a=1, b=2, c=3 لترى الحد الفاصل: المجموع يساوي الضلع الثالث فلا مثلث!

المثال الثاني: السنة الكبيسة

السنة الكبيسة فيها 29 يومًا في شباط. قاعدتها ثلاث حالات مترتبة: تقبل القسمة على 400 فهي كبيسة، وإلا إن قبلت القسمة على 100 فليست كبيسة، وإلا تكون كبيسة إن قبلت القسمة على 4. شاهد أثر الترتيب:

leap_year.cpp
#include <iostream>using namespace std; bool isLeap(int y) {    if (y % 400 == 0) {        return true;    }    if (y % 100 == 0) {        return false;    }    return y % 4 == 0;} int daysInMonth(int y, int m) {    if (m == 2) {        return isLeap(y) ? 29 : 28;    }    if (m == 4 || m == 6 || m == 9 || m == 11) {        return 30;    }    return 31;} int main() {    int years[] = {1900, 2000, 2023, 2024};    for (int y : years) {        cout << y << ": february has " << daysInMonth(y, 2) << " days" << endl;    }    return 0;}

مختبر تفاعلي (2): شجرة قرار السنة الكبيسة

اكتب أي سنة وشاهد المسار الذي سلكه البرنامج في سلسلة الشروط (الخانة المضيئة هي الشرط الذي حسم الجواب).

else if مقابل if جديدة

سلسلة if / else if / else تضمن أن حالة واحدة فقط تُنفَّذ (الأولى الصحيحة). أما كتابة if جديدة فهي سؤال مستقل لا علاقة له بما قبله:

توقّع قبل أن تشغّل
predict_chain.cpp
int x = 15;
if (x % 3 == 0) {
    cout << "A";
} else if (x % 5 == 0) {
    cout << "B";
} else {
    cout << "C";
}
if (x % 5 == 0) {
    cout << "D";
}
cout << endl;

ماذا سيطبع هذا الكود؟ (انتبه إلى الفرق بين else if و if جديدة)

AD

السلسلة الأولى تدخل أول شرط صحيح فقط (A) وتتجاهل بقيتها. أما if الثانية فهي مستقلة وشرطها صحيح (15 تقبل القسمة على 5) فتطبع D. الناتج AD.

كيف تتأكد أنك لم تنسَ حالة؟

أخطر عيوب هذا الأسلوب أن تنسى حالة. أمامك ثلاث وسائل دفاع:

  1. الحدود: جرّب القيم الصغيرة والفاصلة: 0 و1 والقيم المتساوية والسالبة.
  2. الشمول: اسأل «ما الذي سيحدث لو لم تتحقق أي حالة؟» وأضف else أخيرة تلتقط الباقي.
  3. القوة الغاشمة: اكتب حلًا بطيئًا لكنه يجرّب كل الاحتمالات، وقارنه بحلّك السريع على جميع القيم الصغيرة:
check_by_brute_force.cpp
#include <iostream>using namespace std; // Can n be written as the sum of two positive even numbers?bool byCases(int n) {    return n % 2 == 0 && n >= 4;} bool byBrute(int n) {    for (int a = 2; a < n; a += 2) {        int b = n - a;        if (b >= 2 && b % 2 == 0) {            return true;        }    }    return false;} int main() {    int mismatches = 0;    for (int n = 1; n <= 50; n++) {        if (byCases(n) != byBrute(n)) {            mismatches++;            cout << "mismatch at n = " << n << endl;        }    }    cout << "checked 50 values, mismatches: " << mismatches << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
checked 50 values, mismatches: 0

هذه الحيلة (مقارنة حل ذكي بحل غبي على قيم صغيرة) تُسمى الاختبار المقارِن، وهي من أقوى عادات المبرمجين المحترفين. اجعلها عادتك قبل إرسال أي حل.

مشروع الدرس: حاسبة أسعار تذاكر الملاهي

برنامج يختار السعر المناسب بحسب العمر واليوم وبطاقة الطالب.

الفكرة

تدير شباك التذاكر في مدينة ألعاب، وأسعارك تعتمد على عمر الزائر ويوم الزيارة وهل معه بطاقة طالب. تريد برنامجًا يحسب السعر بلا أخطاء مهما كانت المدخلات.

المطلوب منك
  1. اقرأ ثلاثة أعداد: age العمر، وweekend (1 إن كان اليوم عطلة نهاية الأسبوع وإلا 0)، وstudent (1 إن كانت معه بطاقة طالب وإلا 0).
  2. السعر الأساسي بالريال: دون 4 سنوات 0، ومن 4 إلى 12 سنة 10، ومن 13 إلى 17 15، ومن 18 إلى 59 يكون 25 (أو 15 إن كان طالبًا)، و60 فما فوق 10.
  3. في عطلة نهاية الأسبوع يُضاف 20% من السعر (price / 5 بالقسمة الصحيحة).
  4. اطبع Ticket price: P SAR.
مثالان على التشغيل

التشغيل الأول (طفل في يوم عادي):

10 0 0
Ticket price: 10 SAR

التشغيل الثاني (طالب في العطلة):

30 1 1
Ticket price: 18 SAR

تحقق ذهنيًا: في الثاني العمر 30 فالأساس 25، لكن بطاقة الطالب تجعله 15، وفي العطلة نضيف 20% (3) فيصبح 18. لاحظ أن شرط العمر في سلسلة واحدة مرتّبة من الأصغر إلى الأكبر، فلا نحتاج كتابة حدّ أدنى لكل حالة (بل «ما لم يتحقق ما قبله»).

بعد أن تجرّب بنفسك: اعرض الحل
ticket_price.cpp
#include <iostream>
using namespace std;

int main() {
    int age, weekend, student;
    cin >> age >> weekend >> student;

    int price;
    if (age < 4) {
        price = 0;
    } else if (age <= 12) {
        price = 10;
    } else if (age <= 17) {
        price = 15;
    } else if (age <= 59) {
        price = student ? 15 : 25;
    } else {
        price = 10;
    }

    if (weekend == 1) {
        price = price + price / 5;
    }
    cout << "Ticket price: " << price << " SAR" << endl;
    return 0;
}

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

الوسيط بين ثلاثة

سهل

اقرأ ثلاثة أعداد صحيحة مختلفة أو متساوية. اطبع الوسيط منها: العدد الذي ليس الأصغر ولا الأكبر، دون استخدام sort.

المطلوب
  • استخدم سلسلة if / else if / else فقط.
  • العدد وسيط إن كان بين الآخرين (بصرف النظر عن أيهما أكبر).
  • اطبع الوسيط.
مثال على الإدخال والناتج المتوقع
7 2 9
7
تلميحات
  • العدد a وسيط إن تحقق (a >= b && a <= c) || (a <= b && a >= c).
  • إن لم يكن a ولا b وسيطًا فالوسيط هو c بالضرورة.
نموذج الحل (بعد المحاولة)
median_of_three.cpp
// Challenge 1: median of three numbers (no sorting)
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    int med;
    if ((a >= b && a <= c) || (a <= b && a >= c)) {
        med = a;
    } else if ((b >= a && b <= c) || (b <= a && b >= c)) {
        med = b;
    } else {
        med = c;
    }
    cout << med << endl;
    return 0;
}
2

قطع الكعكة

متوسط

كعكة دائرية نريد تقطيعها إلى s قطعة متساوية تمامًا بقطع مستقيمة كلها تمرّ بمركزها. كل قطع يقسم الكعكة بقطرٍ كامل. اقرأ s (حتى 10¹²) واطبع أقل عدد من القطوع.

المطلوب
  • فكّر في ثلاث حالات: s = 1 ولا حاجة لأي قطع.
  • عدد زوجي من القطع: كل قطع يعطي قطعتين فنحتاج s / 2.
  • عدد فردي أكبر من 1: لا يمكن القسمة المتساوية إلا بـ s قطعًا.
مثال على الإدخال والناتج المتوقع
7
7
تلميحات
  • استخدم long long لأن s كبير.
  • جرّب بيدك: ثمان قطع تحتاج 4 قطوع، وسبع قطع تحتاج 7.
نموذج الحل (بعد المحاولة)
cake_cuts.cpp
// Challenge 2: straight cuts through the center of a round cake
#include <iostream>
using namespace std;

int main() {
    long long s;
    cin >> s;
    long long cuts;
    if (s == 1) {
        cuts = 0;
    } else if (s % 2 == 0) {
        cuts = s / 2;
    } else {
        cuts = s;
    }
    cout << cuts << endl;
    return 0;
}

ملخص سريع

  • تحليل الحالات: نقسّم الاحتمالات إلى حالات **شاملة** (لا يفلت احتمال) و**متنافية** (لا يقع احتمال في حالتين) ونحلّ كل حالة بسهولة.
  • رتّب الشروط: الاستثناءات أولًا ثم من الأخص إلى الأعم ثم else للباقي.
  • سلسلة if / else if / else تنفّذ حالة واحدة فقط، وif الجديدة سؤال مستقل.
  • لا تهمل الأقواس { }، فبدونها يرتبط الشرط بسطر واحد فقط.
  • أحيانًا تُختصر الحالات الكثيرة في صيغة (مثل الباقي في حجر-ورقة-مقص) أو في العدّ (زوجي/فردي).
  • جرّب الحدود: 0 و1 والقيم المتساوية والسالبة، وأنهِ بـ else تلتقط ما لم تفكر فيه.
  • قارن حلّك على القيم الصغيرة مع حل القوة الغاشمة لتكتشف الحالات المنسية.

تحقق من فهمك

اقرأ كل عبارة ثم اختر صحيح أو خطأ. سيظهر التفسير مباشرة بعد إجابتك.
