البحث الثنائي

Binary Search — نصف الاحتمالات يختفي في كل خطوة

ماذا ستتعلم في هذا الدرس؟

  • تفهم لماذا يحتاج البحث الثنائي O(log n) خطوة وما شرطه
  • تكتب البحث الثنائي بنفسك وتتجنب الفخاخ الثلاثة الشائعة
  • تستخدم binary_search وlower_bound وupper_bound وتعدّ تكرار قيمة
  • تطبّق البحث الثنائي على الجواب حين يكون الشرط رتيبًا
  • تفرّق بين قالب «أول قيمة صادقة» وقالب «آخر قيمة صادقة» وتتعامل مع الأعداد العشرية

لعبة التخمين

صديقك يفكر بعدد بين 1 و100، وكلما خمّنت قال لك «أعلى» أو «أقل». كيف تضمن الوصول بأقل عدد تخمينات؟ ليس بأن تبدأ من 1 وتزيد واحدًا واحدًا، بل بأن تخمّن دائمًا المنتصف: 50. إن قال «أعلى» رميت نصف الاحتمالات كلها دفعة واحدة. في سبع تخمينات فقط ستصل إلى أي عدد من مئة!

البحث الثنائي (Binary Search) كمقص: كل نظرة تقصّ نصف الاحتمالات الباقية. بدل أن تقلّب ألف صفحة تقصّها عشر مرات فقط. شرطه الوحيد: البيانات مرتّبة، وإلا فلا معنى لقولنا «أعلى» أو «أقل».

guess_game.cpp
int secret = 73, lo = 1, hi = 100, tries = 0; while (lo <= hi) {    int mid = (lo + hi) / 2;    tries++;    cout << "guess " << mid << endl;    if (mid == secret) {        break;    }    if (mid < secret) {        lo = mid + 1;    } else {        hi = mid - 1;    }}cout << "found in " << tries << " tries" << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
guess 50 guess 75 guess 62 guess 68 guess 71 guess 73 found in 6 tries

ستة تخمينات فقط للوصول إلى 73. ومع مليون احتمال نحتاج 20 تخمينًا لا أكثر، ومع مليار احتمال 30 فقط! هذه هي قوة O(log n).

مختبر تفاعلي (1): شاهد المقص يعمل

اختر العدد الذي تبحث عنه واضغط «خطوة». الأعمدة الباهتة تعني أننا رميناها، والبنفسجي هو المنتصف الحالي mid. قارن عدد الخطوات مع البحث العادي!

كتابة البحث الثنائي

نحتفظ بمدى ممكن [lo, hi] ونقصّه نصفًا في كل دورة. اضغط على الأسطر المضيئة:

#include <iostream>#include <vector>using namespace std; int findIndex(const vector<int>& a, int x) {    int lo = 0, hi = (int)a.size() - 1;    while (lo <= hi) {        int mid = lo + (hi - lo) / 2;        if (a[mid] == x) {            return mid;        }        if (a[mid] < x) {            lo = mid + 1;        } else {            hi = mid - 1;        }    }    return -1;} int main() {    vector<int> a = {2, 5, 8, 12, 16, 23, 38, 56, 72, 91};    cout << findIndex(a, 23) << " " << findIndex(a, 40) << endl;    return 0;}

الناتج حتى الآن

ثلاثة فخاخ شائعة: (1) المصفوفة غير مرتّبة (النتيجة تصبح عشوائية). (2) الحلقة while (lo < hi) مع lo = mid قد لا تنتهي أبدًا. (3) كتابة (lo + hi) / 2 مع أعداد ضخمة قد تفيض؛ استعمل lo + (hi - lo) / 2.

الجاهز في C++: binary_search و lower_bound و upper_bound

لن تكتب الحلقة بنفسك في أغلب الأحيان؛ المكتبة <algorithm> تقدّم أدوات جاهزة تعمل على المتجه المرتّب بسرعة O(log n):

stl_binary_search.cpp
vector<int> v = {1, 3, 3, 3, 5, 8}; cout << binary_search(v.begin(), v.end(), 5) << binary_search(v.begin(), v.end(), 4) << endl; auto lo = lower_bound(v.begin(), v.end(), 3);auto hi = upper_bound(v.begin(), v.end(), 3);cout << "first 3 at index " << lo - v.begin() << endl;cout << "after last 3 at index " << hi - v.begin() << endl;cout << "count of 3 = " << hi - lo << endl;cout << "elements < 4: " << lower_bound(v.begin(), v.end(), 4) - v.begin() << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
10 first 3 at index 1 after last 3 at index 4 count of 3 = 3 elements < 4: 4
توقّع قبل أن تشغّل
predict_upper.cpp
vector<int> v = {1, 3, 3, 3, 5, 8};
cout << upper_bound(v.begin(), v.end(), 5) - v.begin() << endl;

ماذا يطبع هذا الكود؟ (تذكّر: upper_bound تعيد أول عنصر أكبر تمامًا)

5

المتجه {1, 3, 3, 3, 5, 8}. أول عنصر أكبر من 5 هو 8 وموقعه 5. وعندما نطرح v.begin() نحصل على رقم الموقع 5.

الأداةماذا تعيد؟
binary_search(b, e, x)true إن وُجد العنصر، false إن لم يوجد
lower_bound(b, e, x)مؤشر لأول عنصر ≥ x
upper_bound(b, e, x)مؤشر لأول عنصر > x
upper - lowerعدد مرات ظهور x
lower_bound(...) - v.begin()رقم الموقع (وهو عدد العناصر الأصغر من x)

وإن نسيت أن تعطيها بداية المدى ونهايته رفض المترجم:

الفكرة الكبرى: البحث الثنائي على الجواب

أجمل ما في البحث الثنائي أنه لا يبحث فقط داخل مصفوفة. إذا كان عندك سؤال من نوع «ما أصغر قيمة تحقق الشرط؟» وكان الشرط رتيبًا (كاذب ثم كاذب ثم ... ثم صادق ثم صادق للأبد) فيمكنك البحث بالمقص عن «الحد الفاصل» بين الكذب والصدق دون أن تبني أي مصفوفة:

first_true.cpp
int lo = 0, hi = 100;while (lo < hi) {    int mid = (lo + hi) / 2;    if (mid * mid >= 50) {        hi = mid;    } else {        lo = mid + 1;    }}cout << lo << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
8

الشرط x*x >= 50 كاذب لكل x ≤ 7 وصادق لكل x ≥ 8، فوجدنا الحد الفاصل 8 بسبع دورات تقريبًا بدل مئة. وهذا النمط يحل مسائل كثيرة. إليك القالبين اللذين تحتاجهما:

الهدفالقالب
أول قيمة صادقة (الأصغر)mid = (lo + hi) / 2; إن صدق: hi = mid; وإلا lo = mid + 1;
آخر قيمة صادقة (الأكبر)mid = (lo + hi + 1) / 2; إن صدق: lo = mid; وإلا hi = mid - 1;

انتبه للتقريب في القالب الثاني: لو كتبت (lo + hi) / 2 مع lo = mid فعندما يكون hi = lo + 1 يبقى mid = lo للأبد فتدور الحلقة بلا نهاية. لذلك نضيف 1 لتقريب المنتصف للأعلى.

وماذا عن الكسور؟

مع الأعداد العشرية لا نبحث عن «العدد الصحيح الفاصل» بل نكرر القصّ عددًا ثابتًا من المرات (مثل 50 أو 100) حتى تصبح الدقة كافية:

sqrt_by_search.cpp
double lo = 0, hi = 2;
for (int i = 0; i < 50; i++) {
    double mid = (lo + hi) / 2;
    if (mid * mid < 2) {
        lo = mid;
    } else {
        hi = mid;
    }
}
cout << fixed << setprecision(6) << lo << endl;
1.414214

وجدنا √2 ≈ 1.414214 دون استخدام sqrt أصلًا.

مختبر تفاعلي (2): البحث الثنائي على الجواب

عندك ثلاثة حبال أطوالها 20 و15 و9 سنتيمترات، وتريد سبع قطع متساوية الطول على الأقل. ما أطول قطعة ممكنة؟ حرّك الشريط لتجرّب طولًا، ثم اضغط «ابحث ثنائيًا» لترى كيف يصل المقص إلى الجواب بسرعة.

مشروع الدرس: قصّ الحبال

تقطيع حبال متفاوتة الطول إلى أطول قطع متساوية ممكنة.

الفكرة

يحتاج نادي الكشافة k قطعة حبل متساوية الطول لنصب الخيام، وعنده n حبلًا بأطوال مختلفة. يمكن قصّ كل حبل إلى قطع بالطول المطلوب (وما يتبقى منه يُهمل). المطلوب أطول طول صحيح للقطعة يحقق الحاجة.

المطلوب منك
  1. اقرأ n وk ثم أطوال الحبال (استخدم long long).
  2. الشرط «تكفي القطع بطول L» رتيب: إن كفى طول L كفى أي طول أصغر منه. فاستخدم قالب «آخر قيمة صادقة».
  3. في كل دورة احسب عدد القطع pieces بجمع x / mid لكل حبل.
  4. اطبع Best length: متبوعة بالجواب. وإن كان مستحيلًا (حتى الطول 1 لا يكفي) اطبع 0.
مثالان على التشغيل

التشغيل الأول:

3 7 20 15 9
Best length: 5

التشغيل الثاني (مستحيل):

2 100 3 4
Best length: 0

تحقق ذهنيًا: بالطول 5 نحصل على 4 + 3 + 1 = 8 قطع (تكفي السبع). وبالطول 6 نحصل على 3 + 2 + 1 = 6 قطع (لا تكفي). فالجواب 5.

بعد أن تجرّب بنفسك: اعرض الحل
rope_cutting.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    long long k;
    cin >> n >> k;
    vector<long long> len(n);
    for (int i = 0; i < n; i++) {
        cin >> len[i];
    }

    long long lo = 0, hi = 1000000000;
    while (lo < hi) {
        long long mid = (lo + hi + 1) / 2;
        long long pieces = 0;
        for (long long x : len) {
            pieces += x / mid;
        }
        if (pieces >= k) {
            lo = mid;
        } else {
            hi = mid - 1;
        }
    }
    cout << "Best length: " << lo << endl;
    return 0;
}

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

كم مرة يظهر x؟

سهل

اقرأ n ثم n عددًا (غير مرتّبة ومتكررة)، ثم q استعلامًا. لكل استعلام x اطبع عدد مرات ظهور x في الأعداد.

المطلوب
  • رتّب المتجه مرة واحدة قبل الاستعلامات.
  • لكل استعلام احسب upper_bound - lower_bound.
  • اطبع جواب كل استعلام في سطر.
مثال على الإدخال والناتج المتوقع
7 5 1 5 3 5 2 3 3 5 3 4
3 2 0
تلميحات
  • الفرق بين مؤشرين من vector هو عدد صحيح، فاطبعه مباشرة.
  • إن لم يكن العدد موجودًا فالمؤشران متساويان والفرق 0.

// Challenge 1: how many times does x appear?

#include <vector>
#include <algorithm>

    int q;

        int x;

الجذر التربيعي الصحيح

متوسط

اقرأ عددًا n حتى 10¹². اطبع أكبر عدد صحيح x يحقق x × x ≤ n دون استخدام sqrt.

المطلوب
  • استخدم long long في كل شيء.
  • ابحث ثنائيًا على x بين 0 و2000000.
  • الشرط mid * mid <= n رتيب (صادق ثم كاذب)، فاستخدم قالب «آخر قيمة صادقة».
مثال على الإدخال والناتج المتوقع
1000000000000
1000000
تلميحات
  • استخدم mid = (lo + hi + 1) / 2 مع lo = mid عند الصدق.
  • مع n = 10¹² يكون الجواب 1000000.
نموذج الحل (بعد المحاولة)
integer_sqrt.cpp
// Challenge 2: integer square root
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    long long lo = 0, hi = 2000000;
    while (lo < hi) {
        long long mid = (lo + hi + 1) / 2;
        if (mid * mid <= n) {
            lo = mid;
        } else {
            hi = mid - 1;
        }
    }
    cout << lo << endl;
    return 0;
}

ملخص سريع

  • البحث الثنائي يقصّ المدى نصفًا في كل خطوة فيحتاج O(log n)، وشرطه أن تكون البيانات **مرتّبة**.
  • نقسّم بـ mid = lo + (hi - lo) / 2 لتجنب الفيضان، ونرمي النصف الذي لا يحوي الهدف.
  • binary_search تجيب بصح/خطأ، وlower_bound أول عنصر ≥ x، وupper_bound أول عنصر > x.
  • عدد ظهور x يساوي upper_bound - lower_bound، ورقم الموقع يساوي المؤشر ناقص begin().
  • البحث الثنائي على الجواب يعمل عندما يكون الشرط **رتيبًا** (كاذب ... كاذب صادق ... صادق).
  • أول قيمة صادقة: hi = mid وlo = mid + 1. آخر قيمة صادقة: mid = (lo + hi + 1) / 2 ثم lo = mid.
  • في الأعداد العشرية نكرر القصّ 50 إلى 100 مرة بدل شرط lo < hi.
