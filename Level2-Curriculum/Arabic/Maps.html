القاموس: كل مفتاح له قيمة

في الدرس السابق كانت المجموعة تعرف فقط «هل هذا العنصر موجود؟». لكن في أغلب المسائل نريد أكثر من ذلك: كم مرة ظهرت هذه الكلمة؟ ما درجة هذا الطالب؟ أي رقم هاتف يخص هذا الاسم؟ نحتاج أن نربط كل عنصر بمعلومة تخصّه.

القاموس (map) كقاموس ورقي: تبحث عن الكلمة (المفتاح key) فتجد معناها (القيمة value). الكلمات لا تتكرر في القاموس، وهي مرتّبة أبجديًا، والبحث عنها سريع.

"Sara"→ 90
"Omar"→ 80
"Lina"→ 82

تقنيًا، القاموس مجموعة مفاتيح مرتّبة بلا تكرار، ولكل مفتاح قيمة تتبعه. وهو يعمل بالسرعة نفسها O(log n).

أول قاموس لنا

نكتب نوعين بين < >: نوع المفتاح ثم نوع القيمة. اضغط على الأسطر المضيئة لتقرأ شرحها:

first_map.cpp
#include <iostream>#include <map>#include <string>using namespace std; int main() {    map<string, int> scores;    scores["Sara"] = 90;    scores["Omar"] = 75;    scores["Lina"] = 82;    scores["Omar"] = 80;     cout << "size = " << scores.size() << endl;    for (const auto& p : scores) {        cout << p.first << " -> " << p.second << endl;    }    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
size = 3 Lina -> 82 Omar -> 80 Sara -> 90

الإسناد scores["Omar"] = 80 لم يضف مفتاحًا جديدًا بل غيّر قيمة المفتاح الموجود. والمرور على القاموس يعطينا أزواجًا مرتّبة بحسب المفتاح.

فخ الأقواس المربعة

أخطر ما في القاموس أن m[key] لا «تقرأ» فقط: إن لم يوجد المفتاح فإنها تنشئه. شاهد ماذا يحدث لحجم القاموس:

bracket_trap.cpp
map<string, int> stock = {{"apple", 5}, {"pear", 2}}; cout << stock["apple"] << endl;cout << stock["kiwi"] << endl;cout << stock.size() << endl; cout << stock.count("mango") << endl;cout << stock.size() << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
5 0 3 0 3

لو كنت تريد فقط أن تسأل «هل المفتاح موجود؟» فاستخدم count أو find ولا تستخدم m[key]. وإلا امتلأ قاموسك بمفاتيح وهمية، وقد يعطي برنامجك أجوبة خاطئة.

مختبر تفاعلي: القاموس أمامك

جرّب العمليات واحدة واحدة وراقب الجدول. ابدأ بالضغط على m[key] مع مفتاح جديد لترى الفخ بعينيك! ثم جرّب خانة «عدّ كلمات جملة».

صندوق أدوات القاموس

الأمرماذا يفعل؟
m[k] = vينشئ المفتاح أو يستبدل قيمته
m[k]يقرأ القيمة، وإن لم يوجد المفتاح ينشئه بقيمة افتراضية (0 للأعداد)
m.count(k)0 أو 1: هل المفتاح موجود؟ دون تغيير القاموس
m.find(k)مؤشر إلى الزوج أو m.end()
m.at(k)يقرأ القيمة، وإن لم يوجد المفتاح يعلن خطأ out_of_range
m.insert({k, v})يضيف فقط إن كان المفتاح غير موجود (لا يستبدل)
m.erase(k)يحذف المفتاح وقيمته
m.size() / m.empty()عدد الأزواج / هل هو فارغ؟
find_at_erase.cpp
map<int, string> id = {{3, "Lina"}, {1, "Omar"}};

auto it = id.find(3);
if (it != id.end()) {
    cout << it->second << endl;
}

id.erase(1);
cout << id.size() << endl;

try {
    cout << id.at(9) << endl;
} catch (const out_of_range&) {
    cout << "no key 9" << endl;
}
Lina 1 no key 9

المؤشر it يشير إلى زوج كامل، ولذلك نكتب it->second للوصول إلى القيمة (والسهم -> اختصار لـ (*it).second).

الإضافة بـ insert مقابل الإسناد بـ [ ]

insert_vs_bracket.cpp
map<string, int> m;
m["a"] = 1;
m.insert({"a", 2});
cout << m["a"] << endl;

m["a"] = 3;
cout << m["a"] << endl;
1 3

insert لا تبدّل قيمة مفتاح موجود، أما الإسناد بالأقواس فيبدّلها.

أشهر استعمال: عدّ التكرارات

في آلاف المسائل نريد معرفة تكرار كل شيء: الحروف والأرقام والكلمات. القاموس يفعل ذلك بسطر واحد هو freq[x]++:

frequency.cpp
vector<string> words = {"go", "stop", "go", "go", "wait", "stop"};map<string, int> freq; for (const string& w : words) {    freq[w]++;} for (const auto& p : freq) {    cout << p.first << ": " << p.second << endl;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
go: 3 stop: 2 wait: 1
توقّع قبل أن تشغّل
predict_letters.cpp
map<char, int> m;
string s = "banana";
for (char c : s) {
    m[c]++;
}
cout << m['a'] << m['n'] << m['b'] << m.size() << endl;

ماذا سيطبع هذا الكود؟ (عدّ مرات ظهور كل حرف في banana ثم عدد المفاتيح)

3213

حيلة المستويات: upper_bound على القاموس

لأن مفاتيح القاموس مرتّبة، يمكننا أن نبحث «أقرب مفتاح». هذه الحيلة تحل مسائل الدرجات والمستويات: كل مفتاح هو بداية مستوى، ونريد معرفة مستوى نقطة معينة:

tiers.cpp
map<int, string> tiers = {{0, "Bronze"}, {100, "Silver"}, {500, "Gold"}}; int points[] = {30, 100, 250, 999};for (int p : points) {    auto it = tiers.upper_bound(p);    --it;    cout << p << " points -> " << it->second << endl;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
30 points -> Bronze 100 points -> Silver 250 points -> Silver 999 points -> Gold

الفكرة: upper_bound(p) تعطي أول مستوى يبدأ بعد النقطة، فالمستوى الصحيح هو السابق مباشرة. هذا الأسلوب سيعود إلينا في درس البحث الثنائي.

قاموس قيمه قوائم

القيمة يمكن أن تكون أي نوع، حتى متجهًا. هذا يفيد في «تجميع» العناصر تحت مفتاح واحد:

grouping.cpp
map<string, vector<int>> marks;
marks["Sara"].push_back(90);
marks["Omar"].push_back(70);
marks["Sara"].push_back(80);

for (const auto& p : marks) {
    int sum = 0;
    for (int x : p.second) {
        sum += x;
    }
    cout << p.first << " avg " << sum / (int)p.second.size() << endl;
}
Omar avg 70 Sara avg 85

unordered_map وأخطاء المفاتيح

مثل المجموعة، للقاموس نسخة غير مرتّبة هي unordered_map: متوسط سرعتها O(1) لكن لا ترتيب للمفاتيح. وهناك أيضًا multimap الذي يسمح بتكرار المفتاح.

unordered_map.cpp
unordered_map<string, int> u;
u["a"] = 1;
u["b"] = 2;
u["a"] += 10;
cout << u["a"] << " " << u.count("b") << " " << u.count("z") << " " << u.size() << endl;
11 1 0 2

ونوع المفتاح ثابت؛ إن أعطيته نوعًا مختلفًا رفض المترجم:

wrong_key.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> m;
    m[1] = 5;
    cout << m.size() << endl;
    return 0;
}
ما يعرضه المترجم (g++)
main.cpp: In function ‘int main()’:
main.cpp:8:6: error: no match for ‘operator[]’ (operand types are ‘std::map<std::__cxx11::basic_string<char>, int>’ and ‘int’)
    8 |     m[1] = 5;
      |      ^

اختر map حين تريد الترتيب أو أسئلة «الأقرب»، وunordered_map حين تحتاج فقط البحث السريع. وتذكّر أن مفتاح unordered_map يجب أن يكون نوعًا يعرف المترجم كيف «يبعثره» (مثل الأعداد والنصوص).

مشروع الدرس: انتخابات مجلس الطلاب

برنامج يفرز الأصوات ويعلن الفائز.

الفكرة

أُجريت انتخابات مجلس الطلاب وجُمعت الأصوات في ورقة واحدة، كل سطر فيها اسم مرشح. مطلوب منك عدّ أصوات كل مرشح ثم إعلان الفائز.

المطلوب منك
  1. اقرأ العدد n ثم n اسمًا، واستخدم map<string, int> لعدّ أصوات كل اسم.
  2. اطبع كل مرشح بالشكل Sara: 3 مرتّبين أبجديًا.
  3. اطبع Winner: متبوعة باسم صاحب أكبر عدد أصوات.
  4. عند التعادل يفوز الاسم الأسبق أبجديًا (يحدث هذا تلقائيًا إن حدّثت الفائز فقط عند أصوات أكبر تمامًا).
مثالان على التشغيل

التشغيل الأول:

7 Sara Omar Sara Lina Omar Sara Lina
Lina: 2 Omar: 2 Sara: 3 Winner: Sara

التشغيل الثاني (تعادل):

4 Ali Zaid Ali Zaid
Ali: 2 Zaid: 2 Winner: Ali

تحقق ذهنيًا: في الأول: Sara 3 وOmar 2 وLina 2، فالفائزة Sara. وفي الثاني Ali وZaid لكل منهما 2، فيفوز Ali لأنه الأول في الترتيب.

بعد أن تجرّب بنفسك: اعرض الحل
election.cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    map<string, int> votes;
    for (int i = 0; i < n; i++) {
        string name;
        cin >> name;
        votes[name]++;
    }

    string winner;
    int best = 0;
    for (const auto& p : votes) {
        cout << p.first << ": " << p.second << endl;
        if (p.second > best) {
            best = p.second;
            winner = p.first;
        }
    }
    cout << "Winner: " << winner << endl;
    return 0;
}

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

تكرار الحروف

سهل

اقرأ كلمة واحدة. اطبع كل حرف ظهر فيها مع عدد مرات ظهوره، مرتّبة أبجديًا، في سطر لكل حرف بالشكل a 3.

المطلوب
  • استخدم map<char, int>.
  • مرّ على حروف الكلمة بحلقة for (char c : word).
  • اطبع الحرف ثم فراغ ثم العدد.
مثال على الإدخال والناتج المتوقع
banana
a 3 b 1 n 2
تلميحات
  • السطر cnt[c]++ يكفي للعدّ.
  • المرور على القاموس يعطيك الحروف مرتّبة دون أي عمل إضافي.
نموذج الحل (بعد المحاولة)
letter_count.cpp
// Challenge 1: letter frequencies
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    string word;
    cin >> word;
    map<char, int> cnt;
    for (char c : word) {
        cnt[c]++;
    }
    for (const auto& p : cnt) {
        cout << p.first << " " << p.second << endl;
    }
    return 0;
}
2

رقمان مجموعهما معروف

متوسط

اقرأ n وtarget ثم n عددًا. ابحث عن موقعين i < j (يبدأ العدّ من 1) مجموع العددين فيهما يساوي target، واطبعهما. وإن لم يوجد اطبع IMPOSSIBLE.

المطلوب
  • مرّ على الأعداد بالترتيب مع رقم الموقع j.
  • قبل تخزين العدد x اسأل: هل رأينا target - x سابقًا؟ استخدم count.
  • إن وُجد اطبع موقعه المخزّن ثم j وانتهِ.
  • وإلا خزّن seen[x] = j.
مثال على الإدخال والناتج المتوقع
5 9 2 7 11 15 1
1 2
تلميحات
  • القاموس هنا يربط «العدد» بـ «موقعه الذي رأيناه فيه».
  • اسأل بـ count قبل أن تقرأ بـ [ ] حتى لا تُنشئ مفاتيح وهمية.
نموذج الحل (بعد المحاولة)
two_sum.cpp
// Challenge 2: two numbers with a given sum
#include <iostream>
#include <map>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    map<int, int> seen;
    for (int j = 1; j <= n; j++) {
        int x;
        cin >> x;
        if (seen.count(target - x)) {
            cout << seen[target - x] << " " << j << endl;
            return 0;
        }
        seen[x] = j;
    }
    cout << "IMPOSSIBLE" << endl;
    return 0;
}

ملخص سريع

  • القاموس map<K, V> يربط **مفتاحًا** بـ **قيمة**: المفاتيح بلا تكرار ومرتّبة، ويحتاج #include <map>.
  • m[k] = v تنشئ أو تستبدل. وm[k] وحدها **تنشئ** المفتاح إن لم يوجد!
  • للسؤال دون تغيير استخدم count أو find، وللقراءة الآمنة استخدم at.
  • كل عنصر زوج: first هو المفتاح وsecond هو القيمة، ونمر عليهم بـ for (const auto& p : m).
  • عدّ التكرارات: freq[x]++ سطر واحد يكفي.
  • upper_bound على المفاتيح المرتّبة تحل مسائل المستويات: النتيجة ثم خطوة للخلف.
  • unordered_map أسرع غالبًا لكن بلا ترتيب، وmultimap يسمح بتكرار المفتاح.
