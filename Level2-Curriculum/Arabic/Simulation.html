Simulation — نفّذ القواعد خطوة بخطوة

ماذا ستتعلم في هذا الدرس؟

  • تفهم فكرة المحاكاة وتحدد متغيرات الحالة قبل كتابة الحل
  • تستخدم مصفوفتي dx وdy وحساب الباقي لتحريك روبوت على شبكة
  • تحسب الجيل التالي لشبكة في نسخة منفصلة كما في لعبة الحياة
  • تحاكي الدوائر والأدوار باستخدام الطابور queue
  • تكتشف الدورات بتخزين الحالات في set حين تطول المحاكاة

نفّذ اللعبة كما هي

بعض المسائل لا تطلب منك عبقرية رياضية، بل تقول لك: «هذه قواعد اللعبة، فماذا سيحدث في النهاية؟». حافلة تتوقف في مواقف، روبوت يتحرك على لوحة، أطفال في دائرة يخرج كل ثالث منهم. الحل هو أن تحاكي (Simulation) العملية بنفسك خطوة بخطوة داخل برنامجك، تمامًا كما تلعب لعبة لوحية بيدك لتعرف النتيجة.

فكّر في المحاكاة كأنك تشغّل لعبة بطيئة: تكتب على ورقة حالة اللعبة (أين كل قطعة؟ كم نقطة؟ دور من؟)، ثم تطبّق قاعدة واحدة وتحدّث الورقة، وتعيد ذلك. البرنامج هو الورقة والحلقة هي القواعد.

خطوات الحل الثابتة في كل مسألة محاكاة:

  1. اقرأ القواعد جيدًا (الأخطاء هنا أغلى من أي خطأ برمجي).
  2. اكتب متغيرات الحالة: ما الذي يتغير مع الزمن؟
  3. طبّق القاعدة بالترتيب نفسه الذي تذكره المسألة.
  4. اسأل: هل عدد الخطوات يسمح بالمحاكاة المباشرة؟ (تذكّر درس التعقيد!)

مختبر تفاعلي (1): الروبوت على اللوحة

الروبوت يبدأ في الزاوية العلوية اليسرى متجهًا شرقًا. أوامره: F للأمام، L لليسار، R لليمين. إن حاول الخروج من اللوحة يرتطم بالحافة ويبقى مكانه. اكتب أوامرك وشاهده يتحرك!

المثال الثاني: لعبة الحياة

لعبة الحياة اخترعها عالم الرياضيات جون كونواي. لها قواعد بسيطة جدًا: كل خلية على الشبكة إما حيّة أو ميتة، وتتغير في كل «جيل» بحسب جيرانها الثمانية: الحيّة تبقى إن كان لها جاران أو ثلاثة، والميتة تحيا إن كان لها ثلاثة بالضبط. ومن هذه القواعد تنشأ أشكال تتحرك وتتكاثر! الدرس الأهم برمجيًا: نحسب الجيل الجديد في نسخة منفصلة:

حين تطول المحاكاة: ابحث عن الدورة

ماذا لو طلبت المسألة نتيجة بعد 10¹² خطوة؟ المحاكاة المباشرة ستطول أبدًا. الحل غالبًا أن العملية تدخل دورة (cycle) تتكرر، فنكتشفها بتخزين الحالات التي مررنا بها في set، وعندما نرى حالة مكررة نعرف أن كل شيء بعدها يتكرر، فنستخدم الباقي (الدرس السابق!) لنقفز إلى النتيجة. مثال: لعبة «الأعداد السعيدة» (استبدل العدد بمجموع مربعات أرقامه):

detect_cycle.cpp

اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...

العدد 19 يصل إلى 1 فتتوقف اللعبة، أما العدد 4 فيدخل حلقة مفرغة (4 ← 16 ← 37 ← 58 ← 89 ← 145 ← 42 ← 20 ← 4) ولا يصل إلى 1 أبدًا. بدون كشف الدورة كان برنامجنا سيعمل بلا نهاية!

أخطاء المحاكاة الأشهر: (1) تعديل الحالة أثناء قراءتها (استخدم نسخة جديدة كما في لعبة الحياة). (2) تغيير ترتيب القواعد. (3) الخروج من حدود الشبكة. (4) نسيان أن البداية تُحسب (مثل أول خلية يزورها الروبوت). والعلاج الدائم: جرّب مثالًا صغيرًا بيدك ثم قارن مع برنامجك.

مشروع الدرس: الروبوت المنظّف

برنامج يحاكي روبوتًا على لوحة ويقدّم تقريرًا عن رحلته.

الفكرة

روبوت تنظيف يعمل على أرضية مستطيلة عرضها W وارتفاعها H. يبدأ في الخانة (0, 0) (الزاوية العليا اليسرى) متجهًا إلى الشرق، وتصله سلسلة أوامر. تريد تقريرًا بمكانه النهائي وعدد الخانات المختلفة التي نظّفها وعدد مرات ارتطامه بالجدار.

المطلوب منك
  1. اقرأ W وH ثم سلسلة الأوامر. الإحداثي x يزيد نحو الشرق وy يزيد نحو الجنوب.
  2. R يدور الروبوت يمينًا وL يسارًا، وF يتقدم خانة واحدة في اتجاهه.
  3. إن كانت الخانة الأمامية خارج اللوحة يرتطم الروبوت: يبقى مكانه ويزيد عدّاد الارتطام.
  4. خزّن الخانات التي زارها (بما فيها خانة البداية) في set<pair<int,int>>.
  5. اطبع ثلاثة أسطر: Final: x y D ثم Distinct cells: k ثم Bumps: b حيث D أحد الحروف N E S W.
مثالان على التشغيل

التشغيل الأول:

5 4 FFRFFLFFFFFF
Final: 4 2 E Distinct cells: 7 Bumps: 4

التشغيل الثاني (يرتطم بالجدار):

3 3 RRFFLL
Final: 0 0 E Distinct cells: 1 Bumps: 2

تحقق ذهنيًا: في الأول: FF إلى (2,0)، ثم R جنوبًا وFF إلى (2,2)، ثم L شرقًا وFFFFFF: خطوتان إلى (4,2) وأربع ارتطامات. الخانات المختلفة سبع. وفي الثاني يستدير يمينًا مرتين ليواجه الغرب فيرتطم مرتين، ثم يستدير يسارًا مرتين ليعود شرقًا.

بعد أن تجرّب بنفسك: اعرض الحل
robot.cpp
#include <iostream>
#include <set>
#include <string>
using namespace std;

int main() {
    int W, H;
    string cmds;
    cin >> W >> H >> cmds;

    const int dx[4] = {0, 1, 0, -1};
    const int dy[4] = {-1, 0, 1, 0};
    const char name[4] = {'N', 'E', 'S', 'W'};

    int x = 0, y = 0, d = 1, bumps = 0;
    set<pair<int, int>> visited;
    visited.insert({x, y});

    for (char c : cmds) {
        if (c == 'R') {
            d = (d + 1) % 4;
        } else if (c == 'L') {
            d = (d + 3) % 4;
        } else if (c == 'F') {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || nx >= W || ny < 0 || ny >= H) {
                bumps++;
            } else {
                x = nx;
                y = ny;
                visited.insert({x, y});
            }
        }
    }
    cout << "Final: " << x << " " << y << " " << name[d] << endl;
    cout << "Distinct cells: " << visited.size() << endl;
    cout << "Bumps: " << bumps << endl;
    return 0;
}

واجبات بعد الدرس

تحديان بسيطان تحلّهما بنفسك بعد انتهاء الدرس. اكتب الحل في ملف .cpp، ثم ترجمه وشغّله وقارن ناتجك بالناتج المتوقع. جرّب أولًا، ثم افتح التلميح إن علقت، ولا تفتح نموذج الحل إلا بعد المحاولة الجادة.

1

سعة الحافلة

سهل

تتوقف حافلة في n موقفًا. عند كل موقف يُعطى عدد النازلين ثم عدد الصاعدين (والنازلون لا يتجاوزون من في الحافلة). الحافلة تبدأ فارغة. اطبع أكبر عدد ركاب كان فيها في أي لحظة.

المطلوب
  • اقرأ n ثم لكل موقف leave وenter.
  • حدّث العدد الحالي: people = people - leave + enter.
  • حدّث الأكبر بعد كل موقف بـ max.
مثال على الإدخال والناتج المتوقع
4 0 3 2 5 4 2 4 0
6
تلميحات
  • حدّث الأكبر داخل الحلقة وليس بعدها.
  • مع المدخلات 0 3 و2 5 و4 2 و4 0 يصل العدد إلى 6 في الموقف الثاني.
نموذج الحل (بعد المحاولة)
tram_capacity.cpp
// Challenge 1: maximum people on the bus
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int people = 0, best = 0;
    for (int i = 0; i < n; i++) {
        int leave, enter;
        cin >> leave >> enter;
        people = people - leave + enter;
        best = max(best, people);
    }
    cout << best << endl;
    return 0;
}
2

دائرة الإقصاء

متوسط

يقف n طفلًا في دائرة مرقّمين من 1 إلى n. نعدّ من الطفل 1 وكل من يقع عليه الرقم k يخرج، ثم يبدأ العدّ من الطفل التالي له. اطبع أرقام الأطفال بترتيب خروجهم، يفصل بينها فراغ.

المطلوب
  • استخدم queue<int> وأضف الأرقام من 1 إلى n.
  • لكل إقصاء مرّر k-1 طفلًا إلى نهاية الطابور.
  • اطبع front ثم pop.
مثال على الإدخال والناتج المتوقع
7 3
3 6 2 7 5 1 4
تلميحات
  • لتمرير طفل: q.push(q.front()); q.pop();
  • مع n = 7 وk = 3 يكون الترتيب 3 6 2 7 5 1 4.
نموذج الحل (بعد المحاولة)
circle_order.cpp
// Challenge 2: elimination order in a circle
#include <iostream>
#include <queue>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    queue<int> q;
    for (int i = 1; i <= n; i++) {
        q.push(i);
    }
    bool first = true;
    while (!q.empty()) {
        for (int s = 1; s < k; s++) {
            q.push(q.front());
            q.pop();
        }
        if (!first) {
            cout << " ";
        }
        cout << q.front();
        first = false;
        q.pop();
    }
    cout << endl;
    return 0;
}

ملخص سريع

  • المحاكاة تعني تنفيذ قواعد المسألة خطوة بخطوة داخل البرنامج بالترتيب نفسه الذي تذكره المسألة.
  • ابدأ بتحديد **متغيرات الحالة** (ما الذي يتغير مع الزمن؟) ثم حدّثها داخل حلقة.
  • للاتجاهات نرقّمها ونستخدم dx وdy، والدوران حساب بالباقي: يمين (d+1)%4 ويسار (d+3)%4.
  • حين نحدّث شبكة يعتمد كل تغيير فيها على الباقي، نحسب الجيل الجديد في **نسخة منفصلة**.
  • الطابور queue مناسب للعدّ الدائري: ندفع من تجاوزناه إلى الخلف ونسحب من خرج.
  • إن كانت الخطوات أكثر من أن تُحاكى مباشرة فاكشف **الدورة** بتخزين الحالات في set ثم استعمل الباقي.
  • جرّب دائمًا مثالًا صغيرًا بيدك وقارن مع برنامجك، وانتبه لحدود الشبكة وللحالة الابتدائية.
