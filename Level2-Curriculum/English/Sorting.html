Sorting

The most powerful tool in a programmer's toolbox

What will you learn in this lesson?

  • Use sort to order vectors and arrays ascending and descending
  • Write a comparison function as a lambda and break ties between elements
  • Tell sort and stable_sort apart and know when you need the stable one
  • Understand how a simple algorithm such as bubble sort works and why it is O(n²)
  • Use sorting to remove duplicates, find the closest two numbers, and sort by counting

The morning line-up

In the school line, students stand from shortest to tallest. After this ordering every question changes: who is the shortest? Easy, the first one. Who is the tallest? The last one. Are there two students of the same height? They will be standing side by side! Many hard problems become very easy after sorting, which is why sorting is the most important tool in a programmer's toolbox.

Think of arranging playing cards in your hand: you pick up a card and slip it into its place among the cards already sorted. That is the idea of an algorithm, and we will see it working before your eyes in the lab. In your real programs, though, you will not write the algorithm yourself; you will use the ready-made and very fast sort (O(n log n)).

The first sort: sort

The tool sort works only on containers where you can jump to any position, such as vector and arrays. A set and a map are already sorted and must not be sorted (try it and you will see the error message below).

sort_a_set.cpp
#include <iostream>
#include <set>
#include <algorithm>
using namespace std;

int main() {
    set<int> s = {3, 1, 2};
    sort(s.begin(), s.end());
    cout << s.size() << endl;
    return 0;
}

Bubble sort step by step

  
The simplest algorithm: we compare each element with its neighbor, and if it is larger we swap them. After each pass the largest element "floats" to its final place like a bubble in water:

  
bubble_sort.cpp
vector<int> a = {5, 2, 4, 1};int n = a.size();for (int i = 0; i < n - 1; i++) {    for (int j = 0; j < n - 1 - i; j++) {        if (a[j] > a[j + 1]) {            swap(a[j], a[j + 1]);        }    }}for (int x : a) {    cout << x << " ";}cout << endl;

This algorithm is O(n²) because it has two nested loops. It is excellent for learning, but with a hundred thousand elements it needs ten billion operations. That is why we use the ready-made sort, which works in a smarter way (split, then sort each part) and reaches O(n log n).







  
Your own rule: the comparison function

  
What if we want to sort strings by length instead of by letters? We pass sort a third argument, the comparator. The easiest way to write one in the same line is a lambda:

  
sort_strings.cpp
vector<string> words = {"pear", "apple", "fig", "banana"}; sort(words.begin(), words.end());for (const string& w : words) cout << w << " ";cout << endl; sort(words.begin(), words.end(), [](const string& a, const string& b) {    return a.size() < b.size();});for (const string& w : words) cout << w << " ";cout << endl;
Click any highlighted line of code to read its explanation here...

  
apple banana fig pear 
fig pear apple banana 

  
The general form: [](const T& a, const T& b) { return ... ; }, and it returns true if a must come before b. The comparison rule is all that is needed to decide the order.

  
Sorting pairs and breaking ties

  
A pair is compared automatically by its first element and then its second. If we want the higher score first and, on a tie, the alphabetical name, we write the rule ourselves:

  
sort_pairs.cpp
vector<pair<int, string>> v = {{90, "Omar"}, {85, "Sara"}, {90, "Lina"}}; sort(v.begin(), v.end());for (const auto& p : v) cout << p.first << " " << p.second << endl;cout << "---" << endl; sort(v.begin(), v.end(), [](const pair<int, string>& a, const pair<int, string>& b) {    if (a.first != b.first) {        return a.first > b.first;    }    return a.second < b.second;});for (const auto& p : v) cout << p.first << " " << p.second << endl;

 Predict before you run
predict_abs.cpp
vector<int> v = {-5, 3, -1, 4};
sort(v.begin(), v.end(), [](int a, int b) {
    return abs(a) < abs(b);
});
for (int x : v) cout << x << " ";
cout << endl;
What will this code print? (the comparison uses the absolute value)
-1 3 4 -5 
The comparison looks only at abs: the absolute values are 5, 3, 1 and 4. Their ascending order is 1, then 3, then 4, then 5, that is the elements -1, then 3, then 4, then -5.

  
A golden rule: the comparison function must be strict, so use < or > and never <= or >=. When two elements are equal it must return false in both directions. Breaking this can crash the program or send it into an endless loop.

Stable sorting: stable_sort

  
When two elements are equal according to the rule, sort may change their relative order. If you want every pair of equals to keep its original order, use stable_sort:

  
stable_sort.cpp
vector<pair<string, int>> jobs = {{"A", 2}, {"B", 1}, {"C", 2}, {"D", 1}};

stable_sort(jobs.begin(), jobs.end(), [](const pair<string, int>& a, const pair<string, int>& b) {
    return a.second < b.second;
});
for (const auto& j : jobs) cout << j.first << j.second << " ";
cout << endl;

  
B1 D1 A2 C2 

  
B and D are equal (1), and A and C are equal (2), and each pair kept the order in which it came in. This is called a stable sort.

Tricks after sorting

  
Trick 1: removing duplicates. After sorting, equal values sit next to each other, so unique can remove them. It does not really delete; it moves the duplicates to the end and returns an iterator to where they start, so we cut them off with erase:

  
sort_unique.cpp
vector<int> v = {4, 2, 4, 9, 2, 7};
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
for (int x : v) cout << x << " ";
cout << endl;

  
2 4 7 9 

  
Trick 2: the closest two numbers. After sorting you do not need to compare every two numbers: the difference between each element and its neighbor is enough. (This is what you will do in the second challenge!)

  
Trick 3: counting sort. If the values are small (such as digits from 0 to 3), we do not need sort at all: we count how many times each digit appeared and then write them out:

  
counting_sort.cpp
vector<int> v = {3, 1, 3, 0, 2, 1, 3};
int cnt[4] = {0, 0, 0, 0};

for (int x : v) {
    cnt[x]++;
}
for (int d = 0; d < 4; d++) {
    for (int k = 0; k < cnt[d]; k++) {
        cout << d << " ";
    }
}
cout << endl;

  
0 1 1 2 3 3 3 

  
This method is called counting sort and it is O(n + k), where k is the range of the values. It is faster than sort when the range is small.







  
Lesson project: running race results
A program that sorts the runners by their times and announces the places.

  
 The idea

    
The school held a running race, and the supervisor wrote down each runner's name and time in seconds in the order they crossed the line. You must announce the places: the fastest first, and when times tie, the alphabetically earlier name goes first.

  
 What you must do

    
    
      
  1. Read n and then n runners, each with a name and a time.
    2. 
      
  2. Store them in a vector<pair<int, string>> with the time first and then the name (so the default ordering works the way we want).
    3. 
      
  3. Sort the vector with sort.
    4. 
      
  4. Print each place in the form 1. Zaid 11s.
    5. 
      
  5. Finally print Gap between first and last:  followed by the time difference of the last from the first, then s.
    6.

Check it in your head: Lina and Sara both have 14, so Lina goes ahead because her name comes first alphabetically. And the difference between the first (11) and the last (14) is 3 seconds.

  
 After you try it yourself: show the solution
    
race_results.cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<pair<int, string>> runners;
    for (int i = 0; i < n; i++) {
        string name;
        int seconds;
        cin >> name >> seconds;
        runners.push_back({seconds, name});
    }

    sort(runners.begin(), runners.end());

    for (int i = 0; i < n; i++) {
        cout << i + 1 << ". " << runners[i].second << " " << runners[i].first << "s" << endl;
    }
    cout << "Gap between first and last: " << runners[n - 1].first - runners[0].first << "s" << endl;
    return 0;
}

2
Smallest difference
Medium
Read n ≥ 2 and then n numbers. Print the smallest positive difference between any two of them.
Requirements
  • Sort the numbers first.
  • The smallest difference is always between two adjacent numbers after sorting.
  • Use min to update the best difference, and watch the loop bounds.
Example input and expected output
5
8 1 15 4 20
3
 Hints
  • Start with best = v[1] - v[0] and then compare the remaining adjacent pairs.
  • With the numbers 8 1 15 4 20, sorted they become 1 4 8 15 20 and the differences are 3, 4, 7 and 5.
 Sample solution (after you try)
min_difference.cpp
// Challenge 2: smallest difference between any two numbers
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> v(n);
    for (int i = 0; i < n; i++) {
        cin >> v[i];
    }
    sort(v.begin(), v.end());
    int best = v[1] - v[0];
    for (int i = 1; i + 1 < n; i++) {
        best = min(best, v[i + 1] - v[i]);
    }
    cout << best << endl;
    return 0;
}



Quick summary
  • sort(v.begin(), v.end()) sorts ascending, needs #include <algorithm>, and runs in O(n log n).
  • For descending order add greater<int>() as a third argument, or write your own rule as a lambda.
  • A comparison lambda returns true if a must come before b, and it must be **strict** (< or >, not <=).
  • Pairs are compared by the first element and then the second, which is very useful for breaking ties.
  • stable_sort keeps the original order of equal elements.
  • To find "who" owns a value, sort the positions (iota) and compare them by their values.
  • After sorting: unique removes duplicates, and the difference between neighbors gives the closest two numbers. For small values use counting sort.

Glossary

    
The most important terms in this lesson:

    
Sorting
Rearranging elements according to a given rule.
Ascending
From the smallest to the largest.
Descending
From the largest to the smallest.
Comparator
A function that decides whether the first element comes before the second.
Lambda
A small nameless function written in the same line.
Stable sort
A sort that keeps the original order of equal elements.
Tie-break
A secondary rule that settles the order when the first rule gives a tie.
Strict ordering
A comparison that returns false on equality, that is < not <=.
Bubble sort
A simple algorithm that swaps wrong neighbors; it is O(n²).
Counting sort
Sorting by counting how many times each small value appears.
iota
A function that fills a range with consecutive numbers starting from a given value.
unique
Moves adjacent repeated elements to the end.
