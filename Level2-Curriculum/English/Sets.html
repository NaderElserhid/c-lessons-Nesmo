Sets

Values with no duplicates, always sorted

What will you learn in this lesson?

  • Understand when to use a set instead of a vector
  • Use insert, erase, count and find, and handle end() safely
  • Answer "closest" questions with lower_bound and upper_bound
  • Tell set, multiset and unordered_set apart and pick the right one
  • Use the vector-to-set trick to remove duplicates and count distinct values

The party-gate problem

Imagine you are standing at the gate of a school party and every guest says their name. You only have to answer two questions: "Has this name come in before?" and "How many different people have shown up?" If you store the names in a vector, a name repeats every time its owner returns, and to look a name up you must check the whole list one by one.

A set is like a smart guest book: it never accepts a name twice, it keeps the names sorted by itself, and it answers "is this name here?" extremely fast without flipping through every page.

Three properties make the set a core tool in contests: no duplicates, permanent order, and search, insert and delete in O(log n) (we will understand this symbol in detail in the lesson on complexity analysis).

We inserted four times but the size is three, because the fourth insertion was the number 10, which was already there. Notice also that the output came out sorted even though we added 30 first.

A set has no indices: you cannot write s[0]. An element in a set is identified not by its position but by its value, and that is what we ask about.

The set toolbox

CommandWhat it doesSpeed
s.insert(x)Adds x if it is not already thereO(log n)
s.erase(x)Removes the value x if presentO(log n)
s.count(x)Gives 1 if present, 0 if notO(log n)
s.find(x)Returns an iterator to the element, or s.end() if absentO(log n)

membership.cpp
set<string> guests = {"Sara", "Omar", "Lina"};

cout << guests.count("Omar") << " " << guests.count("Zaid") << endl;

if (guests.find("Lina") != guests.end()) {
    cout << "Lina is here" << endl;
}

guests.erase("Omar");
cout << guests.size() << endl;
1 0 Lina is here 2

find does not return a value but an iterator that points to the element's place. If the element is missing it returns s.end(), an "after the last element" position that must never be read. That is why we always compare against end() before using the result. If you only need a yes/no answer, count is shorter and clearer.

Did the insertion succeed?

insert returns a pair whose second part, second, tells us whether the element was really added:

insert_result.cpp
set<int> s;
bool first = s.insert(5).second;
bool again = s.insert(5).second;
cout << first << " " << again << endl;
1 0

The first insertion succeeded (1), and the second was rejected because 5 already exists (0).

Closest to a value: lower_bound and upper_bound

Because the set is always sorted, we can ask it "closest" questions: what is the smallest element that is not less than 25? This is the secret of its power compared with an unsorted vector.

bounds.cpp
set<int> s = {10, 20, 30, 40}; auto a = s.lower_bound(25);cout << *a << endl; auto b = s.upper_bound(30);cout << *b << endl; auto c = s.lower_bound(30);cout << *c << endl; auto d = s.lower_bound(50);cout << (d == s.end() ? "end" : "found") << endl;
Click any highlighted line of code to read its explanation here...
30 40 30 end

Use the set's own member function s.lower_bound(x), not lower_bound(s.begin(), s.end(), x). The second one works but walks over the elements one by one, so it becomes slow, O(n). Only the member function takes advantage of the set's structure and stays O(log n).

The largest element below x (the predecessor)

There is no ready-made function for the predecessor, but the trick is simple: take lower_bound(x) and step back once, provided we are not at begin():

predecessor.cpp
set<int> s = {10, 20, 30, 40};
int x = 25;

auto it = s.lower_bound(x);
if (it != s.begin()) {
    --it;
    cout << "largest below " << x << " is " << *it << endl;
}
largest below 25 is 20

Order and traversal

Walking over a set with a range-based for loop gives you the elements from smallest to largest. The smallest element is *s.begin() and the largest is *s.rbegin() (the reverse iterator). If you want descending order, write the comparison greater<int> in the type definition:

order.cpp
set<int> s = {5, 1, 9, 3};
cout << *s.begin() << " " << *s.rbegin() << endl;

set<int, greater<int>> big = {5, 1, 9, 3};
for (int x : big) {
    cout << x << " ";
}
cout << endl;
1 9 9 5 3 1
Predict before you run
predict_size.cpp
set<int> s;

How many elements will the set hold when it is printed?

3

We inserted 3, 1, 3, 2, 1, but the set keeps one copy of each value: {1, 2, 3}. So the size is 3.

You may not modify an element inside a set

Each element's position depends on its value, so changing the value from outside would break the ordering. That is why the compiler stops you:

edit_element.cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s = {1, 2, 3};
    *s.begin() = 10;
    cout << s.size() << endl;
    return 0;
}
What the compiler (g++) says
main.cpp: In function ‘int main()’:
main.cpp:7:16: error: assignment of read-only location ‘s.std::set<int>::begin().std::_Rb_tree_const_iterator<int>::operator*()’
    7 |     *s.begin() = 10;
      |     ~~~~~~~~~~~^~~~

The fix: erase the old value with erase, then add the new value with insert.

The family: multiset and unordered_set

Three useful variants branch off the ordinary set:

TypeDuplicatesOrderSpeed
setNot allowedSortedO(log n)
multisetAllowedSortedO(log n)
unordered_setNot allowedNo guaranteed orderaverage O(1)
multiset.cpp
multiset<int> ms = {3, 1, 3, 2, 3};
cout << ms.size() << " " << ms.count(3) << endl;

ms.erase(ms.find(3));
cout << ms.count(3) << endl;

ms.erase(3);
cout << ms.count(3) << " " << ms.size() << endl;
5 3 2 0 2

Notice the difference: erase(3) by value removes all copies, while erase(ms.find(3)) by iterator removes only one copy.

unordered.cpp
unordered_set<int> u = {7, 3, 9};
cout << u.count(3) << u.count(4) << " " << u.size() << endl;
10 3

Choose unordered_set when you only need "present or not" and do not care about order. Choose set when you need order, lower_bound, or the smallest and largest element. In the worst case unordered_set can slow down (when there are many collisions), so many people prefer set, whose performance is more reliable.

The cleanup trick: turn a vector into a set

The fastest way to remove duplicates from a vector is to pass it to a set, so the values come out sorted and unique. You can then copy them back into a vector:

remove_duplicates.cpp
vector<int> v = {4, 2, 4, 9, 2, 2, 7};
set<int> s(v.begin(), v.end());

cout << "distinct: " << s.size() << endl;

vector<int> cleaned(s.begin(), s.end());
for (int x : cleaned) {
    cout << x << " ";
}
cout << endl;
distinct: 4 2 4 7 9

This trick computes "the number of distinct values" in two lines, and it is one of the most common uses of a set in contests.

Lesson project: the visitor log

A program that records the names of exhibition visitors without duplicates, then answers "did so-and-so visit?" questions.

The idea

You run the school projects exhibition, and some visitors pass through more than once, so their names get recorded every time. You want to know how many different visitors there really were, get a sorted list of their names, and then answer a few inquiries.

What you must do
  1. Read the number n, then n names, and store them in a set<string>.
  2. Print Distinct visitors: followed by the number of distinct names.
  3. Print In order: and then the names in sorted order, each preceded by a space.
  4. Read the number q, then q names, and for each one print YES if the person visited the exhibition and NO if not, in the form Lina: YES.
Two sample runs

First run:

6 Sara Omar Sara Lina Omar Zaid 2 Lina Noor
Distinct visitors: 4 In order: Lina Omar Sara Zaid Lina: YES Noor: NO

Second run (the same name three times):

3 Ali Ali Ali 1 Ali
Distinct visitors: 1 In order: Ali Ali: YES

Check it in your head: among the names Sara, Omar, Lina and Zaid there are four distinct ones. The order is alphabetical: Lina, then Omar, then Sara, then Zaid.

After you try it yourself: show the solution
visitors.cpp
#include <iostream>
#include <set>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    set<string> visitors;
    for (int i = 0; i < n; i++) {
        string name;
        cin >> name;
        visitors.insert(name);
    }

    cout << "Distinct visitors: " << visitors.size() << endl;
    cout << "In order:";
    for (const string& v : visitors) {
        cout << " " << v;
    }
    cout << endl;

    int q;
    cin >> q;
    for (int i = 0; i < q; i++) {
        string name;
        cin >> name;
        if (visitors.count(name)) {
            cout << name << ": YES" << endl;
        } else {
            cout << name << ": NO" << endl;
        }
    }
    return 0;
}

2

Nearest number not below x

Medium

Read a set of numbers, then q queries. For each query x, print the smallest number in the set that is equal to x or greater; if there is none, print NONE.

Requirements
  • Store the numbers in a set<int>.
  • For each query use s.lower_bound(x).
  • Compare the result with s.end() before reading the value.
  • Print each answer on its own line.
Example input and expected output
5 10 20 30 40 50 4 25 50 51 5
30 50 NONE 10
Hints
  • If the result equals s.end(), do not read it with *; print NONE instead.
  • Read the queries in a while (q--) loop or an ordinary for loop.
Sample solution (after you try)
next_value.cpp
// Challenge 2: smallest value that is >= x
#include <iostream>
#include <set>
using namespace std;

int main() {
    int n;
    cin >> n;
    set<int> s;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        s.insert(x);
    }
    int q;
    cin >> q;
    while (q--) {
        int x;
        cin >> x;
        auto it = s.lower_bound(x);
        if (it == s.end()) {
            cout << "NONE" << endl;
        } else {
            cout << *it << endl;
        }
    }
    return 0;
}

Quick summary

  • A set stores values **without duplicates** and keeps them **sorted** automatically. It needs #include <set>.
  • insert, erase, count and find all run in O(log n); size and empty run in O(1).
  • find returns an iterator. If the element is missing it returns end(), which must never be read.
  • lower_bound(x) is the first element >= x, and upper_bound(x) is the first element > x. Use the set's own member function, not the generic one.
  • You cannot modify an element inside a set; erase it and insert the new value.
  • multiset allows duplicates (and erase(value) removes all copies), while unordered_set is usually faster but has no order.
  • Converting a vector to a set removes its duplicates and sorts it in one step.

Glossary

The most important terms in this lesson:

Set

A container that stores distinct values (no duplicates) and keeps them sorted.

Multiset

A sorted set that allows the same value to appear more than once.

Unordered set

A set with no guaranteed order, usually faster at lookup.

Iterator

An object that points to an element inside a container and can be moved.

Duplicate

The same value appearing more than once.

insert

Adds a value to the set if it is not already present.

erase

Removes a value or an element from the set.

count

Gives the number of times a value appears (0 or 1 in a set).

find

Returns an iterator to the value, or end() if it is absent.

lower_bound

The first element greater than or equal to the value.

upper_bound

The first element strictly greater than the value.

end()

A fake position after the last element; it must never be read.
