::سؤال 1: مفهوم التعليمة البسيطة::ما هي التعليمة البسيطة (Simple Statement) في لغة C++؟ {
=أمر مفرد في البرنامج، مثل تعريف متغير أو تعبير حسابي
~مجموعة من الدوال المترابطة في ملف واحد
~نوع خاص من أنواع البيانات في C++
}

::سؤال 2: نهاية التعليمة البسيطة::بماذا تنتهي كل تعليمة بسيطة في C++؟ {
=بفاصلة منقوطة ;
~بقوس معقوف \}
~بنقطتين رأسيتين :
}

::سؤال 3: ترتيب التنفيذ الافتراضي::ما ترتيب تنفيذ التعليمات البسيطة المتتالية في البرنامج افتراضياً؟ {
=بالترتيب الذي تظهر به، من الأعلى إلى الأسفل (تنفيذ تسلسلي)
~بترتيب عشوائي في كل تشغيل للبرنامج
~من الأسفل إلى الأعلى دائماً
}

::سؤال 4: تتبع الكود::ما ناتج تنفيذ هذا الكود؟ int x = 5; x = x + 2; cout << x; {
=7
~5

}

::سؤال 5: مفهوم التعبير::ما هو التعبير (Expression) في C++؟ {
=مزيج من القيم والعوامل ينتج عنه قيمة واحدة، مثل x + 2
~تعليمة تحتوي دائماً على حلقة تكرارية
~اسم آخر لملف الكود المصدري
}

::سؤال 6: الغرض من حلقات التكرار::ما الغرض من استخدام حلقات التكرار (Loops) في البرنامج؟ {
=تكرار تنفيذ نفس التعليمات عدة مرات دون إعادة كتابتها
~تعريف متغيرات جديدة فقط
~طباعة نص واحد فقط على الشاشة
}

::سؤال 7: الغرض من الشروط::ما الغرض من استخدام الشروط (Conditionals) مثل if؟ {
=تنفيذ جزء معيّن من الكود فقط عند تحقق شرط ما
~تنفيذ كل أسطر الكود دائماً بدون استثناء
~حذف المتغيرات غير المستخدمة تلقائياً
}

::سؤال 8: مفهوم التحكم في المسار::ما المقصود بمصطلح Flow Control (التحكم في المسار)؟ {
=أدوات تخبر البرنامج ماذا يفعل، ومتى، وتحت أي شروط، بدلاً من التنفيذ الخطي فقط
~طريقة لتسمية المتغيرات في البرنامج
~نوع من أنواع الأخطاء البرمجية الشائعة
}

::سؤال 9: مفهوم العبارة المركّبة::ما المقصود بالعبارة المركّبة (Compound Statement)؟ {
=مجموعة تعليمات محصورة بين \{ \} تُعامَل ككتلة واحدة
~تعليمة واحدة تحتوي على أكثر من فاصلة منقوطة
~نوع خاص من أنواع المتغيرات
}

::سؤال 10: الاسم الآخر للعبارة المركّبة::ما الاسم الآخر الذي يُطلق على العبارة المركّبة؟ {
=كتلة (Block)
~دالة (Function)
~مصفوفة (Array)
}

::سؤال 11: الفاصلة المنقوطة داخل الكتلة::هل تحتاج كل تعليمة داخل العبارة المركّبة \{ \} إلى فاصلة منقوطة خاصة بها؟ {
=نعم، كل تعليمة داخل الكتلة تنتهي بفاصلة منقوطة خاصة بها
~لا، فاصلة منقوطة واحدة تكفي لكل الكتلة في النهاية
~لا، لا تحتاج التعليمات داخل الكتلة لأي فاصلة منقوطة
}

::سؤال 12: العبارة المركّبة كتعليمة واحدة::كيف تُعامَل العبارة المركّبة الكاملة في سياق التحكم بالمسار؟ {
=تُعامَل بمثابة تعليمة واحدة
~تُعامَل كعدة برامج منفصلة
~لا تُعامَل كتعليمة إطلاقاً
}

::سؤال 13: وظيفة if / else::ما وظيفة أداة if / else التي سنتعرّف عليها قريباً؟ {
=تفرّع شرطي - تنفيذ جزء من الكود فقط إذا تحقق شرط معيّن
~تكرار تنفيذ نفس الكود عدد لا نهائي من المرات
~طباعة قيمة متغير على الشاشة مباشرة
}

::سؤال 14: وظيفة switch::ما وظيفة أداة switch التي سنتعرّف عليها قريباً؟ {
=اختيار مسار من بين عدّة حالات محتملة بشكل أوضح من سلسلة طويلة من if
~حذف تعليمة من البرنامج نهائياً
~تعريف ثابت لا يمكن تغييره
}
