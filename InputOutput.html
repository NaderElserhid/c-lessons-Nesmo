الطرفية (Terminal)

عند تشغيل المستخدم لبرنامج ما، تظهر له شاشة تُسمّى الطرفية (terminal). من خلال هذه الشاشة يمكن للبرنامج عرض المعلومات أو استقبالها من المستخدم. نُطلق على عملية عرض المعلومات اسم الإخراج (output)، وعلى عملية استقبال المعلومات من المستخدم اسم الإدخال (input).

التيارات (Streams)

يُنفَّذ الإدخال والإخراج في لغة C++ من خلال ما يُسمّى التيارات (streams). التيار هو نوع بيانات (datatype) يمكنه استقبال البيانات أو إرسالها (أو كليهما). التياران الرئيسيان المستخدمان في C++ هما cin للإدخال وcout للإخراج.

للتعامل مع التيارات، نستخدم العاملين << و>>:

streams_syntax.cpp
stream << variable; // تُغذي قيمة المتغير إلى التيار
stream >> variable; // تأخذ البيانات من التيار وتخزنها في المتغير

في الحالة الأولى، لا يتغير المتغير؛ أما في الحالة الثانية فإن المتغير يحصل على قيمة جديدة.

ملحوظة: يشير مصطلح "Stream" هنا إلى نوع (type)، بينما cin وcout هما متغيران من هذا النوع. ولكي نتمكن من استخدامهما، يجب إضافة السطر #include <iostream> في بداية البرنامج.

cout

افترض أنك كتبت البرنامج التالي:

hidden_value.cpp
int x = 5;
// add 1 if x is divisible by 3 and add 2 otherwise
int y = x + (x % 3 == 0 ? 1 : 2);

المتغير y مخزَّن في الذاكرة، ولا توجد طريقة للمستخدم لمعرفة قيمته. إذا أردت أن تُظهر هذه القيمة له، فعليك إخراجها إلى الطرفية:

show_y.cpp
cout << y;

هذا السطر يطبع قيمة المتغير y على الطرفية مباشرة. لطباعة نص عادي، نستخدم علامتي تنصيص "...":

spacing_bug.cpp
cout << "The value of y is";
cout << y;

النتيجة ستكون:

The value of y is7

هذا لا يبدو صحيحاً تماماً، والسبب أن C++ لا تفهم ما يبدو مناسباً بصرياً، فهي تنفّذ التعليمات كما هي فقط. وبما أننا لم نحدد وجود مسافة بعد كلمة "is"، لم يُضف البرنامج واحدة تلقائياً.

لذا يجب أن نكتب المسافة صراحة داخل النص:

spacing_fixed.cpp
cout << "The value of y is ";
cout << y;

ويمكننا طباعة تعبيرات متعددة في السطر نفسه:

chained_cout.cpp
cout << "The value of y is " << y;

كما يمكننا طباعة رمز السطر الجديد '\n' للانتقال إلى سطر جديد:

newline.cpp
cout << "Hello" << '\n' << "World";

الناتج:

Hello

cin

نعرف الآن كيفية كتابة برنامج يُعرّف البيانات ويتعامل معها ويطبعها، لكن المشكلة أن البرنامج يقوم بالعمليات نفسها في كل مرة يُشغَّل فيها. قد نرغب أحياناً في كتابة برنامج يسمح للمستخدم بإدخال القيم في كل مرة — لهذا نستخدم cin:

cin_example.cpp
int x;
cin >> x;
cout << "You entered: " << x;

يتوقف تنفيذ البرنامج عند التعليمة cin >> x حتى يُدخل المستخدم قيمة في الطرفية ثم يضغط Enter. بعد ذلك تُخزَّن القيمة في المتغير x.

مثال على الإدخال:

5

الناتج المتوقع:

You entered: 5

ملحوظة: لاحظ أن العاملين المستخدمين مختلفان: >> مع cin، و<< مع cout.

الدالة getline

عند استخدام cin، يقرأ التيار حتى يجد فراغاً أبيض (مسافة) أو نهاية الإدخال. أحياناً قد نرغب في قراءة السطر كاملاً حتى لو احتوى على مسافات — لهذا نستخدم الدالة getline:

getline_example.cpp
string s;
getline(cin, s);

cout << "The line is: " << s;

لاستخدام getline يجب تمرير معاملين: التيار الذي نريد القراءة منه (cin)، والمتغير الذي سنخزّن فيه النتيجة (s).

تحذير: لا يُنصح باستخدام cin وgetline معاً في البرنامج نفسه؛ فقد يترك cin رمز سطر جديد متبقياً في التيار، فيقرأه getline التالي كسطر فارغ خطأً.

مسألة تدريبية محلولة

المسألة: اكتب برنامجاً يقرأ عددين صحيحين ويطبع أولاً الأصغر منهما ثم الأكبر، كل واحد في سطر منفصل.

خطوات الحل:

1

تعريف متغيرين من نوع عدد صحيح لتخزين المدخلات.

2

استخدام cin لقراءة القيم.

3

تعريف متغيرين إضافيين لتخزين الإجابات.

4

استخدام العامل الثلاثي (ternary operator) لتحديد الأصغر والأكبر.

5

استخدام cout لطباعة النتيجة.

min_max.cpp 
int a, b;
cin >> a >> b; // يمكن قراءة عدة متغيرات في السطر نفسه

int small = (a < b ? a : b);
int large = (a > b ? a : b);

cout << small << '\n' << large;

الإدخال والإخراج السريع (Fast I/O)

عند استخدام cout، قد لا تُعرَض البيانات مباشرة على الشاشة، إذ تُخزَّن أحياناً مؤقتاً في ذاكرة مؤقتة (buffer) لتسريع التنفيذ. بشكل افتراضي، كلما استُخدم cin، تُفرَّغ هذه الذاكرة، وهو ما قد يُبطئ الأداء أحياناً.

يمكننا فصل ارتباط cin بـ cout وجعل cout يفرّغ البيانات مرة واحدة فقط في نهاية التنفيذ بإضافة السطرين التاليين في بداية main():

fast_io.cpp
cin.tie(0); // tie the cin stream to stream (0) i.e no stream
cin.sync_with_stdio(0);

مهم: في المسابقات البرمجية، تُختبَر البرامج تلقائياً، ولا يُدخل المستخدم القيم يدوياً، بل تُقرأ من ملف قد يحتوي مدخلات ضخمة جداً (مئات الآلاف من الأرقام مثلاً). لذا عندما تحتوي المسألة على كمية ضخمة من الإدخال، من المهم وضع السطرين السابقين في بداية الكود لتجنّب بطء التنفيذ.

تمرين سريع — اكتبه يدوياً الآن

هذا التمرين مختلف عن سابقيه: لا تكتبه على الحاسوب، بل اكتب الكود يدوياً على ورقة أو دفترك خلال الحصة، ثم قارن إجابتك بالحل النموذجي بعد المحاولة.

المطلوب:

  1. اكتب برنامج C++ كاملاً (يبدأ بـ #include وينتهي بـ return 0;).
  2. يقرأ البرنامج اسم طالب (كنص بدون مسافات) ثم عمره (كعدد صحيح)، باستخدام cin فقط.
  3. يطبع البرنامج جملة ترحيبية واحدة بالضبط كما في المثال أدناه — انتبه جيداً للمسافات!

مثال على الإدخال:

Ali 15

الناتج المتوقع بالضبط:

Hello Ali, you are 15 years old.

تلميح: ستحتاج إلى متغير من نوع string للاسم، ومتغير من نوع int للعمر، ويمكنك قراءتهما معاً بسطر واحد كما فعلنا في المسألة السابقة: cin >> name >> age;

welcome_student.cpp
#include <iostream>
using namespace std;

int main() {
    string name;
    int age;
    cin >> name >> age;

    cout << "Hello " << name << ", you are " << age << " years old.";

    return 0;
}

لاحظ المسافات المتعمّدة داخل النصوص: بعد "Hello "، وبعد "you are "، وقبل " years old." — هذا بالضبط ما تعلمناه في مشكلة المسافات أعلاه.

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

Terminalالطرفية

النافذة النصية التي يتفاعل من خلالها المستخدم مع البرنامج أثناء تشغيله.

Streamتيار

نوع بيانات مسؤول عن نقل المعلومات من البرنامج أو إليه، مثل cin وcout.

Outputإخراج

عرض معلومات من البرنامج إلى المستخدم عبر الطرفية.

Inputإدخال

استقبال بيانات من المستخدم عبر الطرفية إلى داخل البرنامج.

Bufferذاكرة مؤقتة

مساحة تُخزَّن فيها البيانات مؤقتاً قبل عرضها فعلياً، لتحسين الأداء.

Whitespaceفراغ أبيض

أي مسافة أو سطر جديد أو تبويب يفصل بين القيم عند القراءة بـ cin.

Standard input/outputالإدخال/الإخراج القياسي

القنوات الافتراضية التي يتواصل بها البرنامج مع المستخدم عبر الطرفية.

Synchronizationمزامنة

ربط عمل أكثر من تيار معاً بحيث ينتظر أحدهما الآخر، مثل ربط cin بـ cout افتراضياً.

getlineقراءة سطر كامل

دالة تقرأ سطراً كاملاً من الإدخال حتى لو احتوى على مسافات، بعكس cin العادي.
