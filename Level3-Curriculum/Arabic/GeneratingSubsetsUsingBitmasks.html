Generating Subsets Using Bitmasks — كل اختيار ممكن في عدد واحد

ماذا ستتعلم في هذا الدرس؟

  • تفهم لماذا تُمثَّل المجموعة الجزئية بعدد ثنائي، وأن عددها 2^n
  • تكتب الحلقة التي تستعرض كل الأقنعة وتفك كل قناع إلى عناصره
  • تحل مسائل مجموع المجموعة الجزئية والعدّ والاختيار الأفضل عندما يكون n صغيرًا
  • تنفذ عمليات المجموعات (اتحاد وتقاطع ومتمم) بالمعاملات البتّية
  • تعرف حدود الطريقة وحلقة المجموعات الجزئية لقناع

كم طلبية مختلفة يمكنني أن أطلب؟

أمامك قائمة فيها ثلاثة أصناف: بيتزا وعصير وكعكة. يمكنك أن تطلب أي مجموعة منها: لا شيء، أو البيتزا وحدها، أو البيتزا مع العصير، وهكذا حتى تطلب الثلاثة. كل اختيار من هذه تسميه الرياضيات مجموعة جزئية (subset).

لكل صنف قرار واحد فقط: آخذه أو لا آخذه. وهذا قرار بين خيارين مثل المفتاح الكهربائي: مضاء أو مطفأ. فاختيارك الكامل صفّ من مفاتيح، أي عدد ثنائي نخزنه بالضبط كما تعلمنا.

لاحظ أن الأعداد من 0 إلى 7 هي كل الاختيارات بلا تكرار ولا نقص. وفي عدد من العناصر n لدينا 2n اختيارًا، ونمرّ عليها بحلقة واحدة من 0 إلى 2n - 1. نسمي العدد الذي يمثل اختيارًا قناعًا (bitmask).

مختبر تفاعلي: مستكشف المجموعات الجزئية

غيّر قيم العناصر الأربعة كما تحب، واضغط على عنصر ليدخل المجموعة أو يخرج منها، أو تنقّل بين الأقنعة بالأزرار. ضع هدفًا للمجموع وانظر أي الأقنعة تحققه في الجدول.

قوة هذه الطريقة وحدودها

العدّ على كل الاختيارات يعطي كل مجموعة جزئية، وهذا ينفع في أسئلة كثيرة: هل توجد مجموعة مجموعها كذا؟ كم مجموعة تحقق الشرط؟ ما أفضل مجموعة؟ نجرب مثلًا إيجاد المجموعات الجزئية للقائمة {3, 34, 4, 12, 5, 2} التي مجموعها 9:

الحل بسيط ومضمون، لكنه يتضخم بسرعة. عدد الأقنعة هو 2n ولكل قناع نمرّ على n عنصرًا:

for (int n : {1, 3, 5, 10, 20}) {
    cout << n << " items -> " << (1 << n) << " subsets" << endl;

1 items -> 2 subsets 3 items -> 8 subsets 5 items -> 32 subsets 10 items -> 1024 subsets 20 items -> 1048576 subsets

حتى n = 20 تقريبًا يعمل البرنامج بسرعة (نحو عشرين مليون عملية). أما n = 40 فيعني أكثر من تريليون قناع، وهذا مستحيل في ثانية. إذا كان n في السؤال أكبر من نحو 20 فابحث عن طريقة أذكى. تذكّر أيضًا أن 1 << n من نوع int لا يصلح لـ n بحجم 31 فما فوق.

المجموعات بحجم معيّن

أحيانًا نريد فقط المجموعات التي فيها k عنصرًا بالضبط. عدد الخانات المضيئة في القناع هو حجم المجموعة، فنرشح بسهولة:

fixed_size.cpp
int n = 4;
int shown = 0;
for (int mask = 0; mask < (1 << n); mask++) {
    if (__builtin_popcount(mask) == 2) {
        cout << bitset<4>(mask) << " ";
        shown++;
    }
}
cout << endl << shown << endl;
0011 0101 0110 1001 1010 1100 6

وجدنا ستة أقنعة، وهذا هو عدد طرق اختيار عنصرين من أربعة. ولو أردنا أن نتجنب المرور على الأقنعة كلها، توجد خوارزميات أسرع، لكن هذا الحل يكفي إذا كان n صغيرًا.

حيلة متقدمة: المجموعات الجزئية لقناع

أحيانًا نملك مجموعة (قناعًا) ونريد المرور على مجموعاتها الجزئية هي فقط، لا على كل الأقنعة. هناك حلقة قصيرة تقفز بين هذه الأقنعة مباشرة وبترتيب تنازلي:

submasks.cpp
int m = 13;for (int s = m; s > 0; s = (s - 1) & m) {    cout << bitset<4>(s) << " ";}cout << bitset<4>(0) << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
1101 1100 1001 1000 0101 0100 0001 0000

ثماني مجموعات جزئية بالضبط، لأن القناع 1101 فيه ثلاث خانات مضيئة و23 = 8. وإذا مررنا بهذه الطريقة على كل قناع وعلى كل مجموعاته الجزئية، فعدد الخطوات الكلي هو 3n (لأن لكل عنصر ثلاث حالات: ليس في القناع، أو في القناع وليس في الجزئي، أو في الاثنين)، وهي مفيدة جدًا في أسئلة متقدمة لاحقًا.

انتبه للصفر: بعد القناع 0 يعطي (0 - 1) & m القناع m نفسه من جديد، فتدور الحلقة إلى الأبد إن لم نوقفها عند الصفر. لذلك كتبنا شرطها s > 0 وعالجنا الصفر خارجها.

مشروع الدرس: صناديق الهدايا

نختار أفضل مجموعة من الهدايا بحيث لا يتجاوز مجموع أسعارها الميزانية.

الفكرة

تجمع تبرعات لشراء هدايا لزملاء الفصل، وأمامك قائمة بأسعار هدايا مختلفة، وميزانية محددة. تريد أن تشتري أكبر قيمة ممكنة دون تجاوز الميزانية، وأن تعرف أي هدايا اشتريت. وعدد الهدايا قليل (لا يزيد على 20).

المطلوب منك
  1. اقرأ n ثم budget، ثم أسعار n هدايا.
  2. جرّب كل المجموعات الجزئية بالأقنعة، واحسب مجموع أسعار كل واحدة.
  3. احتفظ بأكبر مجموع لا يتجاوز الميزانية، وإذا تساوى مجموعان فاحتفظ بالقناع الأصغر (الذي ظهر أولًا).
  4. اطبع Best total: القيمة ثم سطرًا بالشكل Items: يليه أرقام الهدايا المختارة من 1، يسبق كل رقم فراغ.
مثالان على التشغيل

التشغيل الأول:

5 20 8 5 12 7 3
Best total: 20 Items: 1 3

التشغيل الثاني (لا تكفي الميزانية لأي هدية):

3 4 5 6 9
Best total: 0 Items:

تحقق ذهنيًا: أسعار 8 و5 و12 و7 و3 والميزانية 20. الهديتان الأولى والثالثة مجموعهما 20 تمامًا، وهناك مجموعات أخرى تحقق 20 أيضًا لكن قناعها أكبر، لذلك تختار البرمجة بالشرط total > bestTotal (أكبر تمامًا) أول واحدة وجدتها.

بعد أن تجرّب بنفسك: اعرض الحل
gift_boxes.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, budget;
    cin >> n >> budget;
    vector<int> price(n);
    for (int i = 0; i < n; i++) {
        cin >> price[i];
    }

    int bestTotal = 0;
    int bestMask = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        int total = 0;
        for (int j = 0; j < n; j++) {
            if (mask & (1 << j)) {
                total += price[j];
            }
        }
        if (total <= budget && total > bestTotal) {
            bestTotal = total;
            bestMask = mask;
        }
    }

    cout << "Best total: " << bestTotal << endl;
    cout << "Items:";
    for (int j = 0; j < n; j++) {
        if (bestMask & (1 << j)) {
            cout << " " << j + 1;
        }
    }
    cout << endl;
    return 0;
}

1

عدّ المجموعات بمجموع معيّن

سهل

اقرأ n وtarget ثم n عددًا (n لا يزيد على 20). اطبع عدد المجموعات الجزئية (بما فيها الفارغة إن تحقق الشرط) التي يساوي مجموع عناصرها target.

المطلوب
  • اقرأ الأعداد في vector<int>.
  • استعرض كل الأقنعة من 0 إلى (1 << n) - 1.
  • احسب مجموع كل قناع بحلقة داخلية.
  • اطبع عدد الأقنعة التي مجموعها يساوي target.
مثال على الإدخال والناتج المتوقع
5 10 2 3 5 7 8
3
تلميحات
  • تذكّر أن القناع 0 هو المجموعة الفارغة، ومجموعها 0.
  • مع المدخلات المثال: المجموعات {2, 8} و{3, 7} و{2, 3, 5} مجموعها 10، فالجواب 3.
نموذج الحل (بعد المحاولة)
count_sums.cpp
// Challenge 1: count subsets with a given sum
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int ways = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        int sum = 0;
        for (int j = 0; j < n; j++) {
            if (mask & (1 << j)) {
                sum += a[j];
            }
        }
        if (sum == target) {
            ways++;
        }
    }
    cout << ways << endl;
    return 0;
}
2

اختيار فريق

متوسط

اقرأ n وk وneed، ثم مستوى مهارة كل واحد من n صديقًا. كم فريقًا من k أصدقاء بالضبط يبلغ مجموع مهاراتهم need أو أكثر؟

المطلوب
  • استعرض الأقنعة كلها.
  • تجاهل كل قناع عدد خاناته المضيئة لا يساوي k (استعمل continue).
  • احسب مجموع مهارات الفريق وعدّ الفرق التي تحقق الشرط.
  • اطبع العدد فقط.
مثال على الإدخال والناتج المتوقع
5 2 9 3 4 5 6 7
8
تلميحات
  • عدد الخانات المضيئة في القناع: __builtin_popcount(mask).
  • مع المدخلات المثال توجد 10 طرق لاختيار صديقين من 5، منها 8 فقط مجموعها 9 أو أكثر.
نموذج الحل (بعد المحاولة)
teams.cpp
// Challenge 2: teams of exactly k friends
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, k, need;
    cin >> n >> k >> need;
    vector<int> skill(n);
    for (int i = 0; i < n; i++) {
        cin >> skill[i];
    }

    int teams = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        if (__builtin_popcount(mask) != k) {
            continue;
        }
        int total = 0;
        for (int j = 0; j < n; j++) {
            if (mask & (1 << j)) {
                total += skill[j];
            }
        }
        if (total >= need) {
            teams++;
        }
    }
    cout << teams << endl;
    return 0;
}

ملخص سريع

  • لمجموعة من n عنصرًا بالضبط 2^n مجموعة جزئية، وكل واحدة تُمثَّل بقناع من 0 إلى (1 << n) - 1.
  • الخانة j المضيئة في القناع تعني أن العنصر j ضمن المجموعة الجزئية. نفحصها بـ mask & (1 << j).
  • الشكل المعتاد: حلقة خارجية على الأقنعة وداخلية على العناصر، وتكلفتها n × 2^n.
  • تنفع هذه الطريقة عندما يكون n صغيرًا (نحو 20 فما دون).
  • حجم المجموعة هو __builtin_popcount(mask)، فنرشح المجموعات ذات الحجم k بسهولة.
  • الاتحاد A | B، والتقاطع A & B، والفرق A & ~B، والمتمم full ^ A، والاحتواء (A & B) == A.
  • للمرور على المجموعات الجزئية لقناع m: for (s = m; s > 0; s = (s - 1) & m)، ثم عالج الصفر وحده.
