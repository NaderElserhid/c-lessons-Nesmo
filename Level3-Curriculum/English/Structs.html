Structures (struct)

Build your own types

What will you learn in this lesson?

  • Understand why we group related data in a struct instead of parallel lists
  • Define a struct, fill it, reach its members and copy it
  • Store objects in a vector and sort them with a comparison rule or by defining operator<
  • Tell apart passing a struct by value, by reference and by constant reference
  • Write simple member functions and a constructor

The problem of parallel lists

You want to store ten students, each with a name and a score. The solution you know so far is two vectors: names and scores. That works until you need to sort the students by score. Then you must move both vectors together with great care, and if a single line of code slips, one student's name ends up with another student's score!

A struct is like a student card: it gathers all the information about one thing in one card instead of spreading it over several sheets. You can move or sort the card and all its information travels with it.

A struct lets us make a new type by grouping variables of different types under one name. Once it is defined we use it like int and string: we make variables and vectors of it and pass it to functions.

Our first struct

We define the struct outside main so that every function in the program can see it. Click any highlighted line to read its explanation:

first_struct.cpp
#include <iostream>#include <string>using namespace std; struct Student {    string name;    int score;}; int main() {    Student s;    s.name = "Sara";    s.score = 92;     Student t = {"Omar", 85};     cout << s.name << ": " << s.score << endl;    cout << t.name << ": " << t.score << endl;    return 0;}

Notice that the word Student has become the name of a type, exactly like int. Each variable of this type is called an object and has its own copy of the members.

Forgetting the semicolon after the final brace is one of the most famous beginner mistakes with structs. This is how the compiler responds:

missing_semicolon.cpp
#include <iostream>
using namespace std;

struct Point {
    int x;
    int y;
}

int main() {
    Point p = {1, 2};
    cout << p.x << endl;
    return 0;
}
What the compiler (g++) says
main.cpp:7:2: error: expected ‘;’ after struct definition
    7 | }
      |  ^
      |  ;

The message is clear: "I expected a semicolon after the struct definition". Add it and the program works.

You have learned that a variable declared inside a function may hold a random value until we give it one. This applies to numeric struct members as well, so do not read a member you have not filled in. Write Student s{}; if you want the members to start at zero.

Ways to fill a struct

initialize.cpp
#include <iostream>using namespace std; struct Point {    int x;    int y;}; int main() {    Point a = {3, 4};    Point b{5, 6};    Point c{};    Point d{7};     cout << a.x << " " << a.y << endl;    cout << b.x << " " << b.y << endl;    cout << c.x << " " << c.y << endl;    cout << d.x << " " << d.y << endl;     auto [px, py] = a;    cout << px + py << endl;    return 0;}
Click any highlighted line of code to read its explanation here...
3 4 5 6 0 0 7 0 7

This example shows three facts: curly braces fill the members in order, whatever we do not mention is zeroed, and empty braces {} zero all the members. The last line unpacks the struct into two variables at once, a C++17 feature.

A vector of structs

The real power appears when we store thousands of objects in a vector. Each element has its name and score together, and we walk through it with a single loop:

vector_of_structs.cpp
#include <iostream>#include <string>#include <vector>using namespace std; struct Student {    string name;    int score;}; int main() {    vector<Student> v;    v.push_back({"Sara", 92});    v.push_back({"Omar", 85});    v.push_back(Student{"Lina", 97});     int total = 0;    Student best = v[0];    for (const Student& s : v) {        cout << s.name << " " << s.score << endl;        total += s.score;        if (s.score > best.score) {            best = s;        }    }    cout << "total: " << total << endl;    cout << "best: " << best.name << endl;    return 0;}
Click any highlighted line of code to read its explanation here...
Sara 92 Omar 85 Lina 97 total: 274 best: Lina

Notice that we added the students in three different forms, and all of them are valid. You can also make an ordinary array of structs: Point pts[3] = {{1, 2}, {3, 4}, {5, 6}};.

A struct resembles the pair we saw earlier. The difference is that a pair gives two fixed names, first and second, while a struct gives names that express the meaning (name and score) and has room for any number of members. A pair suits quick jobs, and a struct is clearer when the program grows.

Sorting objects

The function sort does not know how to compare two students, so we hand it a comparison rule as a small function that answers a single question: "should a come before b?":

sort_students.cpp
#include <iostream>#include <string>#include <vector>#include <algorithm>using namespace std; struct Student {    string name;    int score;}; int main() {    vector<Student> v = {{"Sara", 92}, {"Omar", 85}, {"Lina", 92}, {"Zaid", 70}};     sort(v.begin(), v.end(), [](const Student& a, const Student& b) {        if (a.score != b.score) {            return a.score > b.score;        }        return a.name < b.name;    });     for (const Student& s : v) {        cout << s.name << " " << s.score << endl;    }    return 0;}
Click any highlighted line of code to read its explanation here...
Lina 92 Sara 92 Omar 85 Zaid 70

The rule must be strict: write > or < and never >= or <=. When two elements are equal, such a rule says "each one comes before the other", which is a contradiction that can put the program into serious trouble (a crash or an endless loop). Remember too that sort is not stable: elements that compare equal may change their relative order, so add a secondary key (such as the name) when the order matters.

An alternative: teach the type to compare itself

If the type has one "natural" order, define the operator < once inside the struct, and sort, set and map will use it automatically:

operator_less.cpp
#include <iostream>#include <vector>#include <algorithm>using namespace std; struct Event {    int start;    int end;    bool operator<(const Event& other) const {        return end < other.end;    }}; int main() {    vector<Event> v = {{1, 5}, {2, 3}, {4, 9}, {3, 4}};    sort(v.begin(), v.end());    for (const Event& e : v) {        cout << e.start << "-" << e.end << " ";    }    cout << endl;    return 0;}
Click any highlighted line of code to read its explanation here...
2-3 3-4 1-5 4-9

Be aware that set relies on the operator < alone to decide "are these two elements equal?". If we compare events by their end time only, two events ending at the same time count as one element:

set_of_structs.cpp
#include <iostream>
#include <set>
using namespace std;

struct Event {
    int start;
    int end;
    bool operator<(const Event& other) const {
        return end < other.end;
    }
};

int main() {
    set<Event> s;
    s.insert({1, 5});
    s.insert({2, 5});
    s.insert({3, 6});
    cout << s.size() << endl;
    return 0;
}
2

We added three events but the size is two, because {1, 5} and {2, 5} are equal in the set's eyes. To avoid this, make the comparison include everything that tells the objects apart.

Functions inside a struct, and the constructor

A struct does not only hold data; it can hold the functions that work on that data. They are called member functions:

member_functions.cpp

"square" : "not square") << endl;    cout << q.area() << " " << (q.isSquare() ? "square" : "not square") << endl;    return 0;}

As soon as you write a constructor with parameters, C++ stops generating the empty constructor automatically, and it will no longer accept Point p; without values:

no_default.cpp
#include <iostream>
using namespace std;

struct Point {
    int x;
    int y;
    Point(int x_, int y_) : x(x_), y(y_) {}
};

int main() {
    Point p;
    cout << p.x << endl;
    return 0;
}

Structs and functions: by value or by reference?

When we pass a struct to a function, the parameter's type decides its fate: without & all its members are copied (which is slow if it is large, and does not affect the original), and with & the function works on the original itself. If you only want to read without copying, use const Student&:

by_reference.cpp
#include <iostream>using namespace std; struct Counter {    int hits;}; void bumpCopy(Counter c) {    c.hits++;} void bump(Counter& c) {    c.hits++;} int main() {    Counter c{0};    bumpCopy(c);    cout << c.hits << " ";    bump(c);    cout << c.hits << endl;    return 0;}

#include <iostream>using namespace std; struct Counter {    int hits;}; void bumpCopy(Counter c) {    c.hits++;} void bump(Counter& c) {    c.hits++;} int main() {    Counter c{0};    bumpCopy(c);    cout << c.hits << " ";    bump(c);    cout << c.hits << endl;    return 0;}

What will the program print?

0 1

bumpCopy changes a copy, and the result vanishes with it, so the value stays 0. But bump takes the object by reference & and truly changes it, so the value becomes 1. The output is 0 1.

Lesson project: the leaderboard

A program that ranks the contestants of a programming contest and prints their final order.

The idea

You are organizing a programming contest at school, and each contestant has a name and a score. You want a leaderboard showing the highest score first, and when scores tie the alphabetically earlier name goes first, with a final line showing the highest score and how many contestants earned it.

What you must do
  1. Define the struct Student with two members: name and score.
  2. Read the number n and then n lines, each with a name and a score, and store them in a vector<Student>.
  3. Sort by score descending, then by name ascending.
  4. Print each contestant in the form 1. Lina 92 (the rank, a dot, the name, the score).
  5. On the last line print Highest score: 92 (2 students) with the top score and the number of people who got it.
Two sample runs

First run:

5 Sara 92 Omar 85 Lina 92 Zaid 70 Noor 85
1. Lina 92 2. Sara 92 3. Noor 85 4. Omar 85 5. Zaid 70 Highest score: 92 (2 students)

Second run (two identical names with one score):

2 Ali 50 Ali 50
1. Ali 50 2. Ali 50 Highest score: 50 (2 students)

Check it in your head: Sara and Lina both have 92, and the alphabet puts Lina before Sara. Then Noor and Omar have 85 and Noor comes first, and finally Zaid has 70. After sorting, it is enough to count the students whose score equals the score of the first element.

After you have tried it yourself: show the solution
leaderboard.cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

struct Student {
    string name;
    int score;
};

int main() {
    int n;
    cin >> n;
    vector<Student> v(n);
    for (int i = 0; i < n; i++) {
        cin >> v[i].name >> v[i].score;
    }

    sort(v.begin(), v.end(), [](const Student& a, const Student& b) {
        if (a.score != b.score) {
            return a.score > b.score;
        }
        return a.name < b.name;
    });

    for (int i = 0; i < n; i++) {
        cout << i + 1 << ". " << v[i].name << " " << v[i].score << endl;
    }

    int top = 0;
    for (const Student& s : v) {
        if (s.score == v[0].score) {
            top++;
        }
    }
    cout << "Highest score: " << v[0].score << " (" << top << " students)" << endl;
    return 0;
}

The oldest person

Easy

Read n and then n people, each with a name and an age. Print the name of the oldest one; if two ages tie, print the one that appeared first in the input.

Requirements
  • Define a struct Person with two members: name and age.
  • Read the people in a single loop and keep the best person seen so far.
  • You do not need a vector or sorting.
  • Print only the name of the oldest.
Example input and expected output
4 Sara 15 Omar 17 Lina 17 Zaid 12
Omar
Hints
  • Use a strict condition p.age > best.age so that the first one stays when there is a tie.
  • When reading the first person there is no "best" before it, so handle this case with the condition i == 0.
Sample solution (after you try)
oldest.cpp
// Challenge 1: the oldest person
#include <iostream>
#include <string>
using namespace std;

struct Person {
    string name;
    int age;
};

int main() {
    int n;
    cin >> n;
    Person best;
    for (int i = 0; i < n; i++) {
        Person p;
        cin >> p.name >> p.age;
        if (i == 0 || p.age > best.age) {
            best = p;
        }
    }
    cout << best.name << endl;
    return 0;
}
2

Sorting points

Medium

Read n points, each with x and y. Sort them so that x increases, and when x ties the point with the larger y comes first. Print each point on its own line.

Requirements
  • Define a struct Point and store the points in a vector<Point>.
  • Write a lambda comparison rule and pass it to sort.
  • Use strict comparisons only.
  • Print x y for each point on a separate line.
Example input and expected output
5 3 1 1 5 3 7 1 2 2 2
1 5 1 2 2 2 3 7 3 1
Hints
  • Start with if (a.x != b.x) return a.x < b.x; and then compare y in the opposite direction.
  • With the sample input the points must come out in the order 1 5, 1 2, 2 2, 3 7, 3 1.
Sample solution (after you try)
sort_points.cpp
// Challenge 2: sort points
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

struct Point {
    int x;
    int y;
};

int main() {
    int n;
    cin >> n;
    vector<Point> v(n);
    for (int i = 0; i < n; i++) {
        cin >> v[i].x >> v[i].y;
    }
    sort(v.begin(), v.end(), [](const Point& a, const Point& b) {
        if (a.x != b.x) {
            return a.x < b.x;
        }
        return a.y > b.y;
    });
    for (const Point& p : v) {
        cout << p.x << " " << p.y << endl;
    }
    return 0;
}

Quick summary

  • A struct groups members of different types into a **new type** of your own, and its block ends with a semicolon ;.
  • We reach a member with a dot: s.score. We fill the members in order with curly braces {"Sara", 92}.
  • Copying q = p creates an independent object. To change the original inside a function use a reference &, and to read without copying use const T&.
  • vector<Student> stores thousands of objects and sorts them with a comparison rule passed to sort.
  • The comparison rule must be strict (< or >) and settle ties with a secondary key.
  • Define operator< inside the struct so it works with sort, set and map, and remember that set treats two elements that are equal under < as a single one.
  • Member functions and constructors add behavior: after you write a constructor with parameters, Point p; without values no longer works.

Glossary

The most important terms in this lesson:

Struct

A new type that groups several variables (members) under one name.

Member

A variable or function inside a struct.

Object

A variable made from the struct type, with its own copy of the members.

Dot operator

Links an object to a member name: s.score.

Initialization

Giving an object its first values when it is created.

Copy

Making a new object with the same values as another one.

Reference

Another name for an existing object, written with the symbol &.

Comparator

A function that decides which of two objects comes first in the order.

Lambda

A small nameless function written where it is used.

Constructor

A special function that runs when an object is created and initializes its members.

Member function

A function defined inside a struct that works on its data.

Strict weak ordering

A condition on comparison rules: they never return true for an element and itself.
