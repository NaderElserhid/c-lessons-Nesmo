Generating Subsets Using Bitmasks

Every possible choice inside a single number

What will you learn in this lesson?

  • Understand why a subset is represented by a binary number, and that there are 2^n of them
  • Write the loop that goes over all masks and unpacks each mask into its elements
  • Solve subset-sum, counting and best-choice problems when n is small
  • Perform set operations (union, intersection, complement) with bitwise operators
  • Know the limits of the method and the loop over the subsets of a mask

How many different orders can I place?

You have a menu with three items: pizza, juice and cake. You can order any group of them: nothing, the pizza alone, the pizza with the juice, and so on until you order all three. Mathematics calls each of these choices a subset.

For each item there is only one decision: take it or leave it. That is a decision between two options, like an electric switch: on or off. So your whole choice is a row of switches, that is, a binary number, which we store exactly as we have learned.

Mask (binary)NumberThe choice

0102juice
0113pizza + juice

1117all three together

Notice that the numbers 0 to 7 are all the choices, with no repetition and none missing. With n items we have 2n choices, and we visit them with a single loop from 0 to 2n - 1. The number that represents a choice is called a bitmask.

Our first subset generator

The idea uses two loops: the outer one goes over all the masks, and the inner one checks which items were chosen. Click any highlighted line to read its explanation:

The power of this method and its limits

Looping over all choices gives us every subset, and that helps with many questions: is there a subset with a given sum? How many subsets satisfy a condition? What is the best subset? Let us find the subsets of the list {3, 34, 4, 12, 5, 2} whose sum is 9:

subset_sum.cpp
int a[] = {3, 34, 4, 12, 5, 2};int n = 6;int target = 9;int ways = 0; for (int mask = 0; mask < (1 << n); mask++) {    int sum = 0;    for (int j = 0; j < n; j++) {        if (mask & (1 << j)) {            sum += a[j];        }    }    if (sum == target) {        ways++;        cout << "found:";        for (int j = 0; j < n; j++) {            if (mask & (1 << j)) {                cout << " " << a[j];            }        }        cout << endl;    }}cout << ways << " ways" << endl;
Click any highlighted line of code to read its explanation here...

The solution is simple and guaranteed, but it grows quickly. The number of masks is 2n, and for each mask we walk over n items:

how_many.cpp
for (int n : {1, 3, 5, 10, 20}) {
    cout << n << " items -> " << (1 << n) << " subsets" << endl;
}
1 items -> 2 subsets 3 items -> 8 subsets 5 items -> 32 subsets 10 items -> 1024 subsets 20 items -> 1048576 subsets

Up to about n = 20 the program runs fast (around twenty million operations). With n = 40 there are more than a trillion masks, which is impossible in one second. If n in a problem is bigger than about 20, look for a smarter approach. Remember also that 1 << n of type int does not work for n of 31 or more.

Subsets of a given size

Sometimes we only want the subsets with exactly k elements. The number of lit cells in the mask is the size of the subset, so filtering is easy:

fixed_size.cpp
int n = 4;
int shown = 0;
for (int mask = 0; mask < (1 << n); mask++) {
    if (__builtin_popcount(mask) == 2) {
        cout << bitset<4>(mask) << " ";
        shown++;
    }
}
cout << endl << shown << endl;
0011 0101 0110 1001 1010 1100 6

We found six masks, which is the number of ways to choose two items out of four. There are faster algorithms that avoid visiting all the masks, but this solution is enough when n is small.

An advanced trick: the subsets of a mask

Sometimes we have a set (a mask) and want to go through its own subsets only, not all the masks. A short loop jumps directly between these masks, in descending order:

submasks.cpp
int m = 13;for (int s = m; s > 0; s = (s - 1) & m) {    cout << bitset<4>(s) << " ";}cout << bitset<4>(0) << endl;
Click any highlighted line of code to read its explanation here...
1101 1100 1001 1000 0101 0100 0001 0000

Exactly eight subsets, because the mask 1101 has three lit cells and 23 = 8. And if we use this method on every mask and all its subsets, the total number of steps is 3n (because each element has three states: not in the mask, in the mask but not in the submask, or in both), which is very useful in advanced problems later.

Watch out for zero: after the mask 0, (0 - 1) & m gives m itself again, so the loop would spin forever if we did not stop it at zero. That is why we wrote the condition s > 0 and handled zero outside the loop.

Lesson project: gift boxes

We pick the best group of gifts so that the total of their prices does not exceed the budget.

The idea

You are collecting donations to buy gifts for your classmates, and you have a list of gift prices and a fixed budget. You want to buy the largest possible value without exceeding the budget, and to know which gifts you bought. The number of gifts is small (no more than 20).

What you must do
  1. Read n and budget, then the prices of n gifts.
  2. Try every subset with masks and compute the total price of each one.
  3. Keep the largest total that does not exceed the budget; if two subsets tie, keep the smaller mask (the one that appeared first).
  4. Print Best total: value and then a line in the form Items: followed by the numbers of the chosen gifts counted from 1, each preceded by a space.
Two sample runs

First run:

5 20 8 5 12 7 3
Best total: 20 Items: 1 3

Second run (the budget cannot buy any gift):

3 4 5 6 9
Best total: 0 Items:

Check it in your head: the prices are 8, 5, 12, 7 and 3, and the budget is 20. The first and third gifts total exactly 20, and other subsets also reach 20 but with a larger mask, so the program, using the condition total > bestTotal (strictly greater), keeps the first one it found.

After you have tried it yourself: show the solution
gift_boxes.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, budget;
    cin >> n >> budget;
    vector<int> price(n);
    for (int i = 0; i < n; i++) {
        cin >> price[i];
    }

    int bestTotal = 0;
    int bestMask = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        int total = 0;
        for (int j = 0; j < n; j++) {
            if (mask & (1 << j)) {
                total += price[j];
            }
        }
        if (total <= budget && total > bestTotal) {
            bestTotal = total;
            bestMask = mask;
        }
    }

    cout << "Best total: " << bestTotal << endl;
    cout << "Items:";
    for (int j = 0; j < n; j++) {
        if (bestMask & (1 << j)) {
            cout << " " << j + 1;
        }
    }
    cout << endl;
    return 0;
}

Counting subsets with a given sum

Easy

Read n and target, then n numbers (n is at most 20). Print the number of subsets (including the empty one if it qualifies) whose elements sum to target.

Requirements
  • Read the numbers into a vector<int>.
  • Go over all masks from 0 to (1 << n) - 1.
  • Compute the sum of each mask with an inner loop.
  • Print the number of masks whose sum equals target.
Example input and expected output
5 10 2 3 5 7 8
3
Hints
  • Remember that the mask 0 is the empty set, and its sum is 0.
  • With the sample input, the subsets {2, 8}, {3, 7} and {2, 3, 5} sum to 10, so the answer is 3.
Sample solution (after you try)
count_sums.cpp
// Challenge 1: count subsets with a given sum
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int ways = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        int sum = 0;
        for (int j = 0; j < n; j++) {
            if (mask & (1 << j)) {
                sum += a[j];
            }
        }
        if (sum == target) {
            ways++;
        }
    }
    cout << ways << endl;
    return 0;
}
2

Choosing a team

Medium

Read n, k and need, then the skill level of each of n friends. How many teams of exactly k friends have a total skill of need or more?

Requirements
  • Go over all the masks.
  • Skip every mask whose number of lit cells is not k (use continue).
  • Compute the team's total skill and count the teams that meet the condition.
  • Print the count only.
Example input and expected output
5 2 9 3 4 5 6 7
8
Hints
  • The number of lit cells in a mask: __builtin_popcount(mask).
  • With the sample input there are 10 ways to choose two friends out of 5, and only 8 of them total 9 or more.
Sample solution (after you try)
teams.cpp
// Challenge 2: teams of exactly k friends
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, k, need;
    cin >> n >> k >> need;
    vector<int> skill(n);
    for (int i = 0; i < n; i++) {
        cin >> skill[i];
    }

    int teams = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        if (__builtin_popcount(mask) != k) {
            continue;
        }
        int total = 0;
        for (int j = 0; j < n; j++) {
            if (mask & (1 << j)) {
                total += skill[j];
            }
        }
        if (total >= need) {
            teams++;
        }
    }
    cout << teams << endl;
    return 0;
}

Quick summary

  • A set of n elements has exactly 2^n subsets, and each is represented by a mask from 0 to (1 << n) - 1.
  • A lit cell j in the mask means element j is in the subset. We check it with mask & (1 << j).
  • The usual shape: an outer loop over the masks and an inner loop over the elements, costing n × 2^n.
  • This method works when n is small (around 20 or less).
  • The size of a subset is __builtin_popcount(mask), so we can filter the subsets of size k easily.
  • Union A | B, intersection A & B, difference A & ~B, complement full ^ A, containment (A & B) == A.
  • To go through the subsets of a mask m: for (s = m; s > 0; s = (s - 1) & m), then handle zero separately.

Glossary

The most important terms in this lesson:

Subset

A set made of some of the elements of another set (or all of them, or none).

Bitmask

A number whose binary cells are used to represent a choice of elements.

Enumeration

Going through all the possibilities one by one.

Brute force

A simple solution that tries every possibility.

Power set

The set of all subsets; its size is 2^n.

Union

The elements that are in at least one of the two sets: A | B.

Intersection

The elements that are in both sets: A & B.

Complement

All the elements that are not in the set.

Submask

A mask all of whose lit cells are also lit in another mask.

Subset sum

The sum of the values of the chosen elements.

Exponential growth

The work doubling with every extra element, like 2^n.

Popcount

The size of the subset represented by the mask.
