Bitwise Operations

Control numbers one cell at a time

What will you learn in this lesson?

  • Understand how an integer is stored as bits and how to read their weights
  • Use the operators &, |, ^, ~, << and >> and predict their results
  • Understand negative numbers, two's complement and their effect on shifts
  • Avoid precedence mistakes and the confusion between & and &&
  • Use bitset and the XOR tricks to solve small problems

A row of switches

Inside the computer, every integer is stored as a row of electric switches: each switch is either off (0) or on (1). A single switch is called a bit. Every switch has a weight equal to a power of 2: it starts at 1 on the right and doubles as we move left.

Imagine a panel with eight lamps worth 128, 64, 32, 16, 8, 4, 2 and 1. To know which number the panel shows, add the weights of the lamps that are on.

The lamps that are on here are 16, 4 and 2, so the number is 16 + 4 + 2 = 22, written in binary as 00010110. The small number under each cell is the bit number. We always count from the right and start from 0, so bit 0 is the last and least valuable one.

Computers love this representation because they can work on bits directly and extremely fast. In contests the trick is used to store a whole set of choices inside a single number, and that is exactly what we will do in later lessons.

Seeing the bits with your own eyes

We will not settle for imagining. First we write a small function that prints any number as eight bits, then we try the three basic operations on it. Click any highlighted line to read its explanation:

Compare the columns vertically in the output: the first bit of a and b decides the first bit of the result, the second decides the second, and so on. Bitwise operations work column by column, and no position affects another.

You do not have to write this function every time: the ready-made class bitset (from the <bitset> library) prints numbers in binary directly. Try the next example.

bitset_demo.cpp
bitset<8> x(22);
cout << x << endl;
cout << x.count() << " " << x.to_ulong() << endl;
cout << x[1] << x[2] << x[3] << endl;
00010110 3 22 110

The object bitset<8> represents eight bits: cout prints them in binary, count() counts the lit bits, to_ulong() returns the value of the number, and the brackets x[i] read bit number i (counting from the right). The number 22 has three lit bits, and bits 1, 2 and 3 are 1, 1 and 0.

The six tools

These are the bitwise operators in C++. All of them work on integers (int, long long and so on):

OperatorNameWhat it does at each position
a & bANDgives 1 only if both bits are 1
a | bORgives 1 if at least one bit is 1
a ^ bXOR (exclusive or)gives 1 if the bits are different
~aNOTflips every bit: 0 to 1 and 1 to 0
a << kleft shiftslides the bits k places left (multiplies by 2k)
a >> kright shiftslides the bits k places right (divides by 2k, dropping the fraction)

And this is the truth table for the three operators that take two bits:

Think of & as a gatekeeper: only the cells that are lit in both numbers get through. Think of | as someone who lights every cell that either number asked for. And think of ^ as someone who compares two panels and lights the cells where they disagree.

Shifts: fast multiplication and division

Sliding a number one place to the left doubles it, because every bit moves to a position worth twice as much. Sliding it right halves it, dropping the fraction:

shifts.cpp
int x = 5;
cout << (x << 1) << " " << (x << 3) << endl;
cout << (100 >> 2) << " " << (7 >> 1) << endl;
cout << (1 << 10) << " " << (1LL << 40) << endl;
10 40 25 3 1024 1099511627776

A shift by k equals multiplying or dividing by 2k. That is why the expression 1 << k gives 2k directly, and it is the expression you will use most in the next lessons.

The number 1 written alone has type int (32 bits). If you need a shift of 31 or more, write 1LL << k so the number is a long long. And shifting by an amount equal to or greater than the bit width of the type (such as 1 << 32 on an int) is undefined behavior that you must never write.

Negative numbers and two's complement

How does the computer store -5 when it only knows zeros and ones? Processors use a method called two's complement. The idea is that the weight of the top bit becomes negative: with eight bits it is -128 instead of +128. To get -x: flip all the bits of x, then add 1.

+500000101
flip11111010
+111111011
= -5-128+64+32+16+8+2+1
negatives.cpp
int x = 5;
cout << ~x << " " << -x << " " << (~x + 1) << endl;
cout << bitset<8>(x) << endl;
cout << bitset<8>(-x) << endl;
cout << (-4 >> 1) << endl;
-6 -5 -5 00000101 11111011 -2

This experiment teaches three facts. First, ~x always equals -x - 1 (which is why ~5 is -6). Second, -x equals ~x + 1. Third, on common compilers a right shift of a negative number keeps the sign, so -4 becomes -2 rather than a huge number.

When you only care about raw bits, the type unsigned (or unsigned long long) is clearer, because it has no sign bit at all. With ordinary signed numbers we will avoid left-shifting a negative value.

Three quick uses

1) Even and odd

The last bit of a number is the units bit (worth 1), and every other bit has an even weight. So a number is odd when its last bit is 1:

parity.cpp
for (int x : {10, 7, 0, 33}) {
    cout << x << (x & 1 ? " odd" : " even") << endl;
}
10 even 7 odd 0 even 33 odd

2) The rules of XOR

The operator ^ has three simple rules: x ^ x = 0, x ^ 0 = x, and it is commutative and associative, so the order of operations does not matter. From these we get a trick to swap two variables without a third one (it is for information only; in your programs prefer swap):

xor_rules.cpp
int a = 9, b = 14;
cout << (a ^ a) << " " << (a ^ 0) << " " << ((a ^ b) ^ b) << endl;

a ^= b;
b ^= a;
a ^= b;
cout << a << " " << b << endl;
0 9 9 14 9

3) The lonely number

If every number in a list appears twice except one, XOR-ing all of them cancels the pairs (because x ^ x = 0) and leaves the single number:

odd_one_out.cpp
int v[] = {4, 7, 4, 9, 9};
int x = 0;
for (int y : v) {
    x ^= y;
}
cout << x << endl;
7
Predict before you run
predict_ops.cpp
cout << (5 ^ 3) << " " << (5 | 3) << " " << (5 & 3) << endl;

What will this line print? (Think: 5 = 101 and 3 = 011)

6 7 1

Write 5 = 101 and 3 = 011. Exclusive or ^ gives 110, which is 6; | gives 111, which is 7; and & gives 001, which is 1. So the output is 6 7 1.

Mistakes you will often make

First: operator precedence

In C++, == is evaluated before &. So the expression x & 1 == 0 is read as x & (1 == 0), that is x & 0, which is always zero. See the funny result:

precedence.cpp
int x = 6;
if (x & 1 == 0) {
    cout << "even" << endl;
} else {
    cout << "odd" << endl;
}
if ((x & 1) == 0) {
    cout << "even" << endl;
} else {
    cout << "odd" << endl;
}
odd even

The number 6 is even, and yet the first attempt printed odd! The fix is to always put parentheses around bitwise operations: (x & 1) == 0.

Second: & is not &&

The operator && is logical and answers "true or false" about the two whole numbers, while & works on the bits:

and_vs_andand.cpp
cout << (6 & 1) << " " << (6 && 1) << endl;
0 1

Third: NOT and the number's type

The result of ~u fills all the bits of the type. On an unsigned int (32 bits), ~5 becomes a huge number; if you want just 8 bits, take them with a mask & 255:

not_unsigned.cpp
unsigned int u = 5;
cout << ~u << endl;
cout << (~u & 255) << endl;
4294967290 250
Lesson project: the permission card

An access card carries eight permissions inside a single number, and a gate checks whether the card is enough.

The idea

At the programming club building, each card carries eight permissions (the hardware room, the library, the lab, and so on). Each permission is one cell in a number between 0 and 255: a cell set to 1 means the permission is granted. Every door has a "mask" that says which permissions it requires. The gate must check the card and tell the staff member what is missing.

What you must do
  1. Read two numbers: card and need, both between 0 and 255.
  2. Print Card: followed by card as eight bits, and Needed: followed by need as eight bits.
  3. Print Access: YES if every needed permission is on the card, otherwise print Access: NO.
  4. Print Missing: followed by the missing permissions as eight bits.
Two sample runs

First run (the card is enough):

214 82
Card: 11010110 Needed: 01010010 Access: YES Missing: 00000000

Second run (something is missing):

37 45
Card: 00100101 Needed: 00101101 Access: NO Missing: 00001000

Think before you write: the card is enough when card lights every cell that need lights, that is, when card & need equals need itself. The missing permissions are the cells that are in need but not in card: need & ~card.

After you have tried it yourself: show the solution
keycard.cpp
#include <iostream>
using namespace std;

void show(int x) {
    for (int i = 7; i >= 0; i--) {
        cout << ((x >> i) & 1);
    }
}

int main() {
    int card, need;
    cin >> card >> need;

    cout << "Card:    ";
    show(card);
    cout << endl;
    cout << "Needed:  ";
    show(need);
    cout << endl;

    if ((card & need) == need) {
        cout << "Access: YES" << endl;
    } else {
        cout << "Access: NO" << endl;
    }

    int missing = need & ~card;
    cout << "Missing: ";
    show(missing);
    cout << endl;
    return 0;
}

1

The binary form

Easy

Read a number n and print it in binary without extra leading zeros. For example, the number 22 is printed as 10110.

Requirements
  • Read n as a long long.
  • Collect the bits of the number in a string using n & 1 and then n >>= 1.
  • Reverse the text before printing it, because the bits come out from lowest to highest.
  • If the number is zero, print 0.
Example input and expected output
22
10110
Hints
  • The first bit you get is the least valuable one, so it is the last one written. Use reverse from the <algorithm> library.
  • To turn a bit into a character: char('0' + (n & 1)).
Sample solution (after you try)
binary_form.cpp
// Challenge 1: binary form without leading zeros
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    long long n;
    cin >> n;
    if (n == 0) {
        cout << 0 << endl;
        return 0;
    }
    string s;
    while (n > 0) {
        s += char('0' + (n & 1));
        n >>= 1;
    }
    reverse(s.begin(), s.end());
    cout << s << endl;
    return 0;
}
2

Gray code

Medium

A Gray code is a numbering in which only one bit changes between two consecutive numbers. Its formula for the number i is i ^ (i >> 1). Read n and print the formula values for the numbers 0 to n-1, separated by spaces.

Requirements
  • Use a for loop from 0 to n - 1.
  • Print i ^ (i >> 1) for each i.
  • Do not put a space before the first number or after the last one.
Example input and expected output
8
0 1 3 2 6 7 5 4
Hints
  • Do not forget the parentheses around the expression when printing: cout << (i ^ (i >> 1)).
  • With n = 8 you should get 0 1 3 2 6 7 5 4. Notice how only one bit changes at each step.
Sample solution (after you try)
gray_code.cpp
// Challenge 2: Gray code
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        if (i > 0) {
            cout << " ";
        }
        cout << (i ^ (i >> 1));
    }
    cout << endl;
    return 0;
}

Quick summary

  • An integer is a row of **bits**; the weight of each bit is a power of 2, and we number the positions from the right starting at **0**.
  • & keeps a bit when it is 1 in both numbers, | when it is 1 in either, ^ when they differ, and ~ flips every bit.
  • x << k equals x times 2^k, and x >> k divides by it. Use 1LL << k for large shifts.
  • ~x equals -x - 1, and -x equals ~x + 1 (two's complement).
  • x & 1 tests for an odd number. x ^ x is 0, so we can find the lonely number among pairs.
  • Always put parentheses around bitwise operations: (x & 1) == 0, because == is evaluated before &.
  • bitset<8> prints and counts bits easily, and needs #include <bitset>.

Glossary

The most important terms in this lesson:

Bit

The smallest unit of information: either 0 or 1.

Binary

A counting system that uses only the digits 0 and 1.

Bitwise

An operation that works on each bit of the number separately.

AND

Gives 1 if both bits are 1.

OR

Gives 1 if at least one bit is 1.

XOR

Gives 1 if the bits differ.

NOT

Flips every bit in the number.

Shift

Moving the bits left or right by some number of places.

Two's complement

The way negative numbers are stored: flip the bits and add 1.

Sign bit

The top bit; its weight is negative in signed numbers.

Unsigned

A number type with no sign bit and no negative values.

bitset

A ready-made C++ class that represents a fixed number of bits.
