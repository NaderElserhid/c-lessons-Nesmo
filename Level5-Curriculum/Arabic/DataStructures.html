Data Structures — المكدس والطابور وطابور الأولوية والمجاميع التراكمية

ماذا ستتعلم في هذا الدرس؟

  • تعرف أن اختيار هيكل البيانات يعتمد على العمليات التي نحتاجها
  • تستعمل stack للأقواس وكل ما يحتاج «آخر داخل أول خارج»
  • تستعمل queue للمحاكاة وتعرف الفرق عن المكدس
  • تستعمل priority_queue للحصول على الأكبر أو الأصغر وتعرف كلفته
  • تبني المجاميع التراكمية وتجيب عن أسئلة المدى بعملية واحدة

اختر الصندوق المناسب لعملك

في المطبخ لا تحفظ كل شيء في درج واحد: الأطباق تُرصّ فوق بعضها وتأخذ أعلاها، والمعكرونة في وعاء تُسكب منه من الفتحة، وقائمة التسوق تُشطب منها الأهم أولًا. لكل غرض طريقة تخزين تجعل عملياته سريعة. كذلك في البرمجة: هيكل البيانات (Data Structure) هو طريقة لتنظيم البيانات تسهّل عمليات معينة.

القاعدة التي تحكم الاختيار: ما العمليات التي أحتاجها، وكم مرة؟ من الأدوات التي نعرفها vector وset وmap. وفي هذا الدرس نضيف ثلاثة هياكل جديدة، وحيلة مهمة للمجاميع:

الهيكلالعملية الأساسيةالزمنيصلح لـ

لا يوجد هيكل «أفضل» بذاته. المكدس سريع في شيء واحد (القمة) ولا يعطيك العنصر الأوسط. اختيار الهيكل هو أن تسأل أولًا: ماذا سأفعل بالبيانات؟

المكدس: آخر من يدخل أول من يخرج

تخيّل كومة أطباق: لا تأخذ إلا الأعلى ولا تضع إلا فوقه. هذا هو المكدس (stack) وعملياته: push للإضافة وtop لقراءة القمة وpop للحذف وempty وsize. كلها O(1). مثال كلاسيكي: التحقق من توازن الأقواس، فكل قوس مغلق يجب أن يطابق **آخر** قوس مفتوح:

brackets.cpp
#include <iostream>#include <stack>#include <string>using namespace std; bool balanced(const string& s) {    stack<char> st;    for (char c : s) {        if (c == '(' || c == '[' || c == '{') {            st.push(c);        } else {            if (st.empty()) {                return false;            }            char open = st.top();            st.pop();            if ((c == ')' && open != '(') || (c == ']' && open != '[') || (c == '}' && open != '{')) {                return false;            }        }    }    return st.empty();} int main() {    string tests[5] = {"([]{})", "(()", "([)]", "", "}{"};    for (const string& t : tests) {        cout << "\"" << t << "\" -> " << (balanced(t) ? "balanced" : "not balanced") << endl;    }    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
"([]{})" -> balanced "(()" -> not balanced "([)]" -> not balanced "" -> balanced "}{" -> not balanced

لاحظ أن ([)] ليس متوازنًا رغم أن كل قوس له زوج، لأن الأزواج متداخلة بشكل خاطئ. والمكدس هو الذي يكشف ذلك.

الطابور: أول من يدخل أول من يخرج

مثل طابور الخبز: من وصل أولًا يُخدم أولًا. الطابور (queue) يضيف من النهاية بـ push ويخدم من المقدمة بـ front وpop. كلها O(1). مثال: مسألة يوسف: 7 أشخاص في دائرة، وفي كل جولة يخرج كل ثالث شخص. نمرر الشخصين الأولين إلى النهاية ثم نُخرج الثالث:

circle_queue.cpp
#include <iostream>#include <queue>using namespace std; int main() {    int n = 7, k = 3;    queue<int> q;    for (int i = 1; i <= n; i++) {        q.push(i);    }     cout << "leaving order:";    while (!q.empty()) {        for (int i = 1; i < k; i++) {            q.push(q.front());            q.pop();        }        cout << " " << q.front();        q.pop();    }    cout << endl;    return 0;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
leaving order: 3 6 2 7 5 1 4

سبق أن استعملنا الطابور في BFS. وإذا أردت الإضافة والحذف من الطرفين فهناك deque.

مختبر تفاعلي (1): ملعب الهياكل

اختر هيكلًا، ثم أضف أرقامًا واحذف. الرقم الأول من اليسار هو التالي في الخروج (برتقالي). أضف الأرقام نفسها في كل هيكل وقارن من يخرج أولًا.

طابور الأولوية: الأهم دائمًا في القمة

في طوارئ المستشفى لا تُخدم الحالات بترتيب وصولها، بل حسب خطورتها. طابور الأولوية (priority_queue) يعطيك دائمًا الأكبر (أو الأصغر) بين ما أدخلت. top هو O(1)، أما push وpop فهما O(log n) لأن الهيكل من الداخل «كومة» (heap) مرتبة جزئيًا:

heaps.cpp
priority_queue<int> big;priority_queue<int, vector<int>, greater<int>> small;int a[6] = {5, 2, 8, 1, 9, 3};for (int x : a) {    big.push(x);    small.push(x);} cout << "max-heap order:";while (!big.empty()) {    cout << " " << big.top();    big.pop();}cout << endl; cout << "min-heap order:";while (!small.empty()) {    cout << " " << small.top();    small.pop();}cout << endl;
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
max-heap order: 9 8 5 3 2 1 min-heap order: 1 2 3 5 8 9

الافتراضي هو الكومة العظمى (الأكبر أولًا). للحصول على الأصغر أولًا اكتب priority_queue<int, vector<int>, greater<int>>. ولا يمكنك قراءة العناصر الأخرى أو البحث فيها: لا يعطيك الهيكل إلا القمة. إذا احتجت ذلك فاستعمل set.

المجاميع التراكمية: مدى بعملية واحدة

لدينا مصفوفة ثابتة وآلاف الأسئلة: «ما مجموع العناصر من l إلى r؟». جمع المدى في كل مرة يكلف O(n) للسؤال. الحيلة: نحسب مرة واحدة pre[i] مجموع أول i عنصرًا، وبعدها يكون كل سؤال طرحًا واحدًا:

prefix_sums.cpp
int a[10] = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3};int n = 10;vector<long long> pre(n + 1, 0);for (int i = 1; i <= n; i++) {    pre[i] = pre[i - 1] + a[i - 1];} int queries[3][2] = {{1, 10}, {3, 6}, {5, 5}};for (auto& q : queries) {    cout << "sum[" << q[0] << ".." << q[1] << "] = " << pre[q[1]] - pre[q[0] - 1] << endl;}
اضغط على أي سطر مضيء من الكود لقراءة شرحه هنا...
sum[1..10] = 39 sum[3..6] = 19 sum[5..5] = 5

مجموع المدى [l, r] هو pre[r] - pre[l - 1]: ما حتى r ناقصًا ما قبل l. البناء O(n) والسؤال O(1). والقيد الوحيد أن المصفوفة لا تتغير (إذا تغيرت العناصر فنحتاج هياكل أقوى مثل التقسيم إلى جذر التربيع وشجرة المقاطع).

مختبر تفاعلي (2): الجمع المباشر أمام المجاميع التراكمية

عدّل المصفوفة والمدى [l, r] (الترقيم من 1). ترى الصف الأول للمصفوفة والصف الثاني للمجاميع التراكمية. العناصر الخضراء هي المدى، والمجموعان البرتقاليان هما اللذان نطرح أحدهما من الآخر.

مشروع الدرس: طابور الطوارئ

نعالج المرضى حسب الخطورة وليس حسب الوصول.

الفكرة

في قسم الطوارئ يصل مرضى كل واحد باسمه ودرجة خطورة (رقم أكبر يعني أخطر). عندما يتفرغ الطبيب يعالج أخطر مريض ينتظر. المطلوب محاكاة سلسلة أوامر: ARRIVE name severity للوصول، وTREAT لعلاج المريض التالي.

المطلوب منك
  1. اقرأ عدد الأوامر q، ثم اقرأ كل أمر.
  2. عند ARRIVE أضف الزوج {severity, name} إلى priority_queue.
  3. عند TREAT اطبع Treating واسم صاحب القمة ثم احذفه، وإن كان الطابور فارغًا فاطبع Nobody waiting.
مثالان على التشغيل

التشغيل الأول:

7 ARRIVE Sara 3 ARRIVE Omar 9 TREAT ARRIVE Lina 5 TREAT TREAT TREAT
Treating Omar Treating Lina Treating Sara Nobody waiting

التشغيل الثاني (الطبيب يتفرغ قبل وصول أحد):

3 TREAT ARRIVE Adam 1 TREAT
Nobody waiting Treating Adam

تحقق ذهنيًا: في الأول وصل سارة (3) ثم عمر (9)، فيُعالج عمر أولًا. ثم تصل لينا (5)، فتعالج قبل سارة، وبعدها سارة، وأخيرًا لا أحد. الزوج يقارن أولًا بالخطورة، ولذلك نضعها في الأول.

بعد أن تجرّب بنفسك: اعرض الحل
emergency.cpp
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    int q;
    cin >> q;
    priority_queue<pair<int, string>> waiting;
    for (int i = 0; i < q; i++) {
        string cmd;
        cin >> cmd;
        if (cmd == "ARRIVE") {
            string name;
            int severity;
            cin >> name >> severity;
            waiting.push({severity, name});
        } else {
            if (waiting.empty()) {
                cout << "Nobody waiting" << endl;
            } else {
                cout << "Treating " << waiting.top().second << endl;
                waiting.pop();
            }
        }
    }
    return 0;
}

1

أمطار الأسبوع

سهل

سجّلنا كمية المطر في n أيام. اقرأ n وq ثم الكميات، ثم q سؤالًا كل منها l r. اطبع لكل سؤال مجموع الكميات من اليوم l إلى اليوم r (الترقيم من 1).

المطلوب
  • ابنِ مصفوفة المجاميع التراكمية pre من الأيام.
  • لكل سؤال اطبع pre[r] - pre[l - 1].
مثال على الإدخال والناتج المتوقع
6 3 4 0 7 2 5 1 1 6 2 4 5 5
19 9 5
تلميحات
  • استعمل long long إذا كانت الكميات كبيرة.
  • في المثال الأجوبة 19 ثم 9 ثم 5 (كل جواب في سطر).
نموذج الحل (بعد المحاولة)
rainfall.cpp
// Challenge 1: rainfall totals
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<long long> pre(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        pre[i] = pre[i - 1] + x;
    }
    for (int i = 0; i < q; i++) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << endl;
    }
    return 0;
}
2

ربط الحبال

متوسط

معك n حبلًا بأطوال معينة. تربط حبلين في كل مرة بكلفة تساوي مجموع طوليهما، ويصير حبلًا واحدًا بذلك الطول. اربط الجميع في حبل واحد بأقل كلفة كلية ممكنة، واطبع هذه الكلفة.

المطلوب
  • ضع كل الأطوال في priority_queue صغرى.
  • ما دام فيها أكثر من حبل: أخرج أصغر حبلين واجمعهما وأضف الكلفة إلى المجموع.
  • أعد الحبل الناتج إلى الطابور، واطبع المجموع في النهاية.
مثال على الإدخال والناتج المتوقع
4 4 3 2 6
29
تلميحات
  • ربط الأقصر أولًا يمنع تكرار حساب الأطوال الكبيرة مرات كثيرة.
  • في المثال الأطوال 4 3 2 6: 2+3=5 ثم 4+5=9 ثم 6+9=15، والمجموع 29.
نموذج الحل (بعد المحاولة)
ropes.cpp
// Challenge 2: joining ropes at the lowest cost
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    priority_queue<long long, vector<long long>, greater<long long>> pq;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        pq.push(x);
    }
    long long total = 0;
    while (pq.size() > 1) {
        long long a = pq.top();
        pq.pop();
        long long b = pq.top();
        pq.pop();
        total += a + b;
        pq.push(a + b);
    }
    cout << total << endl;
    return 0;
}

ملخص سريع

  • هيكل البيانات طريقة لتنظيم البيانات تسهّل عمليات معينة؛ نختاره حسب العمليات التي نحتاجها.
  • المكدس (stack) آخر داخل أول خارج، وعملياته O(1)، ويصلح للأقواس والتراجع.
  • الطابور (queue) أول داخل أول خارج، وعملياته O(1)، ويصلح للمحاكاة وBFS.
  • طابور الأولوية يعطيك الأكبر دائمًا (أو الأصغر بـ greater)، وpush/pop فيه O(log n).
  • المجاميع التراكمية: بناء O(n) ثم مجموع أي مدى بـ pre[r] - pre[l - 1] في O(1) لمصفوفة ثابتة.
  • لا يمكن قراءة عنصر عشوائي من المكدس أو الطابور أو طابور الأولوية: لا نرى إلا طرفًا واحدًا.
