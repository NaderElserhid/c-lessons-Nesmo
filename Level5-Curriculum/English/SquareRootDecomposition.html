Square Root Decomposition

Blocks of size √n make queries and updates fast together

What will you learn in this lesson?

  • Understand cutting an array into blocks of size √n with ready information per block
  • Compute the block index, the position of an element, and the number of blocks
  • Answer a range query with two partial blocks and full blocks in O(√n)
  • Update a value by adding the difference, and know when a block must be rebuilt
  • Explain why the square root balances single elements against the number of blocks

A building with floors: do not climb every stair

You ask for the total owned by the residents of apartments 3 to 57 in a huge building. Asking every apartment would take a long time. But if the caretaker writes the total of each floor on a board at the entrance, you read the full floors from the board and only ask about the apartments on the two partial floors at the ends. This is the idea of square root decomposition (Square Root Decomposition).

We cut an array of length n into blocks of length B ≈ √n and keep a ready-made piece of information for each block (its sum, say). A range query consists of: two partial blocks at the ends whose elements we read one by one (fewer than 2B elements), and full blocks between them whose ready information we read (fewer than n / B blocks). So the total is O(√n) instead of O(n).

OperationPlain arrayPrefix sums√n blocks
range sum queryO(n)O(1)O(√n)
update a valueO(1)O(n)O(1)

Prefix sums are excellent for queries and slow for updates; the plain array is the opposite. Blocks give a fair compromise for both, so they suit problems where updates are mixed with queries. (The segment tree gives O(log n) for both.)

Block arithmetic: block index and position

The rule: the element with index i (from 0) lies in block i / B at position i % B, and block b covers b * B to b * B + B - 1 (the last may be shorter):

The number of blocks is (n + B - 1) / B: this formula rounds the division up using integer division. Here 10 elements fit in 4 blocks, and the last has only one element.

Range sum with updates

We store the sum of each block. In a query we walk a pointer l from the left: if we are at the start of a block that is entirely inside the range, we jump over it using its ready sum; otherwise we read one element. In an update we add the difference to the sum of its block only:

sqrt_sum.cpp
#include <iostream>#include <vector>#include <cmath>using namespace std; struct SqrtSum {    int n, B, steps = 0;    vector<long long> a, block;     SqrtSum(const vector<long long>& v) {        n = v.size();        B = max(1, (int)sqrt((double)n));        a = v;        block.assign((n + B - 1) / B, 0);        for (int i = 0; i < n; i++) {            block[i / B] += a[i];        }    }     void update(int i, long long x) {        block[i / B] += x - a[i];        a[i] = x;    }     long long query(int l, int r) {        long long s = 0;        steps = 0;        while (l <= r) {            if (l % B == 0 && l + B - 1 <= r) {                s += block[l / B];                l += B;            } else {                s += a[l];                l++;            }            steps++;        }        return s;    }}; int main() {    SqrtSum ds({5, 2, 7, 1, 8, 3, 9, 4, 6, 2, 5, 1, 7, 3, 8, 6});    cout << "n = " << ds.n << ", block size = " << ds.B << endl;    cout << "block sums:";    for (long long b : ds.block) {        cout << " " << b;    }    cout << endl;    cout << "sum[2..13] = " << ds.query(2, 13) << " (steps " << ds.steps << ")" << endl;    ds.update(5, 10);    cout << "after a[5] = 10: sum[2..13] = " << ds.query(2, 13) << " (steps " << ds.steps << ")" << endl;    cout << "sum[0..15] = " << ds.query(0, 15) << " (steps " << ds.steps << ")" << endl;    return 0;}

We have 10 elements and a block size of 3. What will the program print?

4 2 1

The number of blocks is (10 + 3 - 1) / 3 = 12 / 3 = 4 (this formula rounds up with integer division). The element with index 7 is in block 7 / 3 = 2 at position 7 % 3 = 1. We print 4 2 1.

Why the square root? (lab 2)

If we make blocks bigger there are fewer of them, but the partial ends grow; if we make them smaller the opposite happens. The worst cost of a query is about 2(B - 1) + n / B. Pick n and see which B gives the lowest cost.

Minimum in a range: updates need a rebuild

With sums the update was O(1) because we knew the difference. With the minimum of a range it is not so: if the element that was the minimum of its block changes, we only learn the new minimum by looking at the block again, so an update costs O(B):

Click any highlighted line of code to read its explanation here...
min[1..10] = 1 after a[8] = 20: min[1..10] = 2

This is the general rule: each block stores a piece of information combined from its elements (sum, minimum, maximum, count...). If the information is "subtractable", like a sum, updates are fast; otherwise we recompute it from the elements of the block.

Lesson project: the shop sales

We answer sales questions and correct figures during the day.

The idea

A chain of shops recorded sales for n hours. The manager sometimes asks for the total sales between two hours (SUM l r), and the accountant sometimes corrects the figure of one hour (SET i x). We need a program that answers every question quickly.

What you need to do
  1. Read n and q and then the sales. Compute B = √n and the sum of each block.
  2. On SET i x add x - a[i] to the sum of that position's block and then update a[i].
  3. On SUM l r walk the pointer: a full block by its sum, otherwise element by element. Then print the total.
Two sample runs

First run:

8 5 5 3 8 1 9 2 7 4 SUM 1 8 SET 3 20 SUM 2 5 SUM 4 4 SET 4 0
39 33 1

Second run:

3 3 1 2 3 SUM 1 3 SET 2 10 SUM 1 3
6 14

Check it in your head: in the first run the grand total is 5+3+8+1+9+2+7+4 = 39. After changing the third value to 20, positions 2 to 5 total 3+20+1+9 = 33. Position 4 alone is 1. (The last SET prints nothing.)

After you try it yourself: show the solution
shop_sales.cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <string>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int B = max(1, (int)sqrt((double)n));
    vector<long long> block((n + B - 1) / B, 0);
    for (int i = 0; i < n; i++) {
        block[i / B] += a[i];
    }

    for (int k = 0; k < q; k++) {
        string cmd;
        cin >> cmd;
        if (cmd == "SET") {
            int i;
            long long x;
            cin >> i >> x;
            i--;
            block[i / B] += x - a[i];
            a[i] = x;
        } else {
            int l, r;
            cin >> l >> r;
            l--;
            r--;
            long long s = 0;
            while (l <= r) {
                if (l % B == 0 && l + B - 1 <= r) {
                    s += block[l / B];
                    l += B;
                } else {
                    s += a[l];
                    l++;
                }
            }
            cout << s << endl;
        }
    }
    return 0;
}

1

Block sums

Easy

Read n and then n numbers. Take the block size B to be the integer square root of n (rounded down). On the first line print B and the number of blocks, and on the second line the sum of each block.

Requirements
  • Compute B = (int)sqrt(n) and the number of blocks (n + B - 1) / B.
  • Add each element i to its block i / B.
  • Print B and the number of blocks, then the sums.
Example input and expected output
10 4 1 7 2 9 3 8 5 6 10
3 4 12 14 19 10
Hints
  • The last block may be shorter than B.
  • In the example (10 numbers) B = 3, there are 4 blocks, and the sums are 12 14 19 10.
Sample solution (after you try)
block_sums.cpp
// Challenge 1: block sums
#include <iostream>
#include <vector>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int B = max(1, (int)sqrt((double)n));
    int blocks = (n + B - 1) / B;
    vector<long long> sum(blocks, 0);
    for (int i = 0; i < n; i++) {
        sum[i / B] += a[i];
    }
    cout << B << " " << blocks << endl;
    for (int b = 0; b < blocks; b++) {
        cout << sum[b] << " ";
    }
    cout << endl;
    return 0;
}
2

Maximum with updates

Medium

Read n and q and then the array. Then q commands: SET i x changes element i to x, and MAX l r prints the largest element between l and r (numbered from 1).

Requirements
  • Split the array into blocks and keep the largest element of each block.
  • On SET change the element and recompute the maximum of its block only.
  • On MAX walk the pointer: a full block by its ready value, otherwise element by element.
Example input and expected output
6 4 3 8 2 9 4 7 MAX 1 6 SET 4 1 MAX 1 6 MAX 3 5
9 8 4
Hints
  • A difference is not enough here: a maximum cannot be fixed by subtraction, so rebuild the block with a loop over its elements.
  • In the example the answers are 9, then 8, then 4.
Sample solution (after you try)
range_max.cpp
// Challenge 2: range maximum with updates
#include <iostream>
#include <vector>
#include <cmath>
#include <string>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int B = max(1, (int)sqrt((double)n));
    int blocks = (n + B - 1) / B;
    vector<int> mx(blocks, -1000000000);
    auto rebuild = [&](int b) {
        mx[b] = -1000000000;
        for (int i = b * B; i < min(n, b * B + B); i++) {
            mx[b] = max(mx[b], a[i]);
        }
    };
    for (int b = 0; b < blocks; b++) {
        rebuild(b);
    }
    for (int k = 0; k < q; k++) {
        string cmd;
        cin >> cmd;
        if (cmd == "SET") {
            int i, x;
            cin >> i >> x;
            i--;
            a[i] = x;
            rebuild(i / B);
        } else {
            int l, r;
            cin >> l >> r;
            l--;
            r--;
            int best = -1000000000;
            while (l <= r) {
                if (l % B == 0 && l + B - 1 <= r) {
                    best = max(best, mx[l / B]);
                    l += B;
                } else {
                    best = max(best, a[l]);
                    l++;
                }
            }
            cout << best << endl;
        }
    }
    return 0;
}

Quick summary

  • We cut the array into blocks of length B ≈ √n and store a ready-made piece of information for each block.
  • Element i is in block i / B at position i % B, and the number of blocks is (n + B - 1) / B.
  • A range query reads single elements from the two partial blocks and full blocks in between, in O(√n).
  • A sum update is O(1) by adding the difference; minimum and maximum updates are O(B) by rebuilding the block.
  • The build is O(n) and the extra memory is O(√n).
  • Choosing B ≈ √n balances the single elements against the number of full blocks.

Glossary

The most important terms in this lesson:

Square root decomposition

Splitting an array into blocks of size √n.

Block

A run of consecutive elements with a ready-made piece of information.

Block size

The number of elements B in a block.

Block sum

The sum of the elements of a block, kept ready.

Partial block

A block of which only a part lies inside the range.

Full block

A block that lies entirely inside the range.

Point update

Changing the value of one element.

Range query

A question about consecutive elements.

Rebuild

Recomputing a block's information from its elements.

Preprocessing

Work done once before the queries.

Index

The number of an element's position.

Trade-off

Balancing two opposing costs.
