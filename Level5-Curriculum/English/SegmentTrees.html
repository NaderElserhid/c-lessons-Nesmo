Segment Trees

Range queries and updates together in logarithmic time

What will you learn in this lesson?

  • Understand splitting the array into repeated halves with a ready value for every segment
  • Build the tree, answer a range query and update a point in O(log n)
  • Tell the node cases apart: outside, inside and partial
  • Change the operation (sum, minimum, maximum) by changing the combine line and the identity
  • Write the short bottom-up version and understand a half-open range

A knockout tournament for numbers

In a knockout football tournament each match between two teams produces a winner, and the winners meet each other until the champion emerges. To find the strongest team in some part of the bracket we do not replay every match; we use the finished results. A segment tree (Segment Tree) is the same idea: we split the array into two halves, then each half into two halves, until a single element remains, and every segment in the tree holds a ready value (its sum, its minimum, its maximum...).

What sets it apart from block decomposition (square root decomposition) is that its height is log n and not √n, so both a query and an update are O(log n):

MethodBuildRange queryPoint update
plain array-O(n)O(1)
prefix sumsO(n)O(1)O(n)
√n blocksO(n)O(√n)O(1) for sums
segment treeO(n)O(log n)O(log n)

A segment tree works with any "combining" operation that can be applied to halves: sum, minimum, maximum, greatest common divisor, and more. Only one line changes: the line that combines the two children of a node.

How are the segments split?

The node node covers the range [l, r]. We split it at mid = (l + r) / 2: the left child 2 * node covers [l, mid] and the right child 2 * node + 1 covers [mid + 1, r]. We stop at the leaves (a range of one element). This is the same numbering used by the binary heap: the root is 1 and the parent of i is i / 2:

Notice that the range is halved each time, so the height is about log₂ n. The total number of nodes is less than 2n, but in the recursive tree we reserve 4n to cover every size.

Build, query and update

Three similar functions, each following the same rule: take the node (node, l, r) and look at how it relates to the target. In a query there are three cases: the node is outside the range (return the identity), entirely inside (return its value), or partly inside (ask both children). In an update we go down to the leaf and recompute the parents on the way up:

segment_tree.cpp
#include <iostream>#include <vector>using namespace std; struct SegTree {    int n;    vector<long long> t;     SegTree(const vector<long long>& a) {        n = a.size();        t.assign(4 * n, 0);        build(a, 1, 0, n - 1);    }     void build(const vector<long long>& a, int node, int l, int r) {        if (l == r) {            t[node] = a[l];            return;        }        int mid = (l + r) / 2;        build(a, 2 * node, l, mid);        build(a, 2 * node + 1, mid + 1, r);        t[node] = t[2 * node] + t[2 * node + 1];    }     void update(int node, int l, int r, int pos, long long val) {        if (l == r) {            t[node] = val;            return;        }        int mid = (l + r) / 2;        if (pos <= mid) {            update(2 * node, l, mid, pos, val);        } else {            update(2 * node + 1, mid + 1, r, pos, val);        }        t[node] = t[2 * node] + t[2 * node + 1];    }     long long query(int node, int l, int r, int ql, int qr) {        if (qr < l || r < ql) {            return 0;        }        if (ql <= l && r <= qr) {            return t[node];        }        int mid = (l + r) / 2;        return query(2 * node, l, mid, ql, qr) + query(2 * node + 1, mid + 1, r, ql, qr);    }}; int main() {    SegTree st({5, 2, 7, 1, 8, 3, 9, 4});    cout << "tree:";    for (int i = 1; i <= 15; i++) {        cout << " " << st.t[i];    }    cout << endl;    cout << "sum[2..5] = " << st.query(1, 0, 7, 2, 5) << endl;    cout << "sum[0..7] = " << st.query(1, 0, 7, 0, 7) << endl;    st.update(1, 0, 7, 3, 10);    cout << "after a[3] = 10: sum[2..5] = " << st.query(1, 0, 7, 2, 5) << endl;    return 0;}

The bottom-up version: shorter and faster

In many problems the segment tree is written without recursion: an array t of size 2n, with the leaves in t[n..2n-1] and the inner nodes before them. We build from the bottom, and answer a query on a half-open range [l, r) with a short loop. Here is a version for the minimum:

iterative_min.cpp
int n = 8;vector<int> a = {5, 2, 7, 1, 8, 3, 9, 4};vector<int> t(2 * n, 1000000000);for (int i = 0; i < n; i++) {    t[n + i] = a[i];}for (int i = n - 1; i >= 1; i--) {    t[i] = min(t[2 * i], t[2 * i + 1]);} auto query = [&](int l, int r) {    int best = 1000000000;    for (l += n, r += n; l < r; l /= 2, r /= 2) {        if (l % 2 == 1) {            best = min(best, t[l++]);        }        if (r % 2 == 1) {            best = min(best, t[--r]);        }    }    return best;};auto update = [&](int pos, int val) {    pos += n;    t[pos] = val;    for (pos /= 2; pos >= 1; pos /= 2) {        t[pos] = min(t[2 * pos], t[2 * pos + 1]);    }}; cout << "min[2..5] = " << query(2, 6) << endl;update(3, 10);cout << "after a[3] = 10: min[2..5] = " << query(2, 6) << endl;cout << "min of all = " << query(0, 8) << endl;

This version works directly for operations where the order of the ends does not matter (sum, minimum, maximum) and for any n. Ordered operations (such as multiplying matrices) need the recursive tree. Remember too that the query here is [l, r), so the range [2..5] is written query(2, 6).

Lesson project: the lowest price

We find the cheapest price in a stretch of shops while prices get corrected during the day.

The idea

A shopping platform tracks the price of a product in n shops. A customer asks for the lowest price between two shops (LOW l r), and a shop sometimes corrects its price (SET i x). We need to answer every query fast, even with many queries.

What you need to do
  1. Read n and q and then the prices into t[n..2n-1], and build the inner nodes with the minimum.
  2. On SET i x write into the leaf i - 1 + n, then climb and recompute the parents.
  3. On LOW l r run the query loop on the range [l - 1, r) shifted by n, and print the minimum.
Two sample runs

First run:

8 6 5 2 7 1 8 3 9 4 LOW 1 8 SET 4 10 LOW 3 6 LOW 1 2 SET 2 0 LOW 1 8
1 3 2 0

Second run:

3 3 9 4 6 LOW 1 3 SET 2 10 LOW 1 3
4 6

Check it in your head: in the first run the lowest price is 1. After raising the fourth shop to 10, the prices from 3 to 6 are 7, 10, 8, 3, so the lowest is 3. The first two shops are 5, 2, so the lowest is 2. After setting the second to 0, the lowest of all is 0.

After you try it yourself: show the solution
lowest_price.cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> t(2 * n);
    for (int i = 0; i < n; i++) {
        cin >> t[n + i];
    }
    for (int i = n - 1; i >= 1; i--) {
        t[i] = min(t[2 * i], t[2 * i + 1]);
    }

    for (int k = 0; k < q; k++) {
        string cmd;
        cin >> cmd;
        if (cmd == "SET") {
            int i, x;
            cin >> i >> x;
            int pos = i - 1 + n;
            t[pos] = x;
            for (pos /= 2; pos >= 1; pos /= 2) {
                t[pos] = min(t[2 * pos], t[2 * pos + 1]);
            }
        } else {
            int l, r;
            cin >> l >> r;
            int lo = l - 1 + n, hi = r + n;
            int best = 1000000000;
            for (; lo < hi; lo /= 2, hi /= 2) {
                if (lo % 2 == 1) {
                    best = min(best, t[lo++]);
                }
                if (hi % 2 == 1) {
                    best = min(best, t[--hi]);
                }
            }
            cout << best << endl;
        }
    }
    return 0;
}

1

The bank counters

Easy

A bank has n counters holding amounts. Read n and q and then the amounts, and then q commands: ADD i x adds x (possibly negative) to counter i, and SUM l r prints the total of counters l to r (numbered from 1).

Requirements
  • Build a segment tree for sums (recursive or bottom-up).
  • On ADD add x to the leaf and to each of its ancestors on the way up.
  • On SUM answer with the query loop.
Example input and expected output
5 5 10 20 30 40 50 SUM 1 5 ADD 3 5 SUM 2 4 ADD 1 -10 SUM 1 2
150 95 20
Hints
  • In the bottom-up version, climb with pos /= 2 and add x to every node on the path.
  • In the example the answers are 150, then 95, then 20.
Sample solution (after you try)
bank_counters.cpp
// Challenge 1: the bank counters
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<long long> t(2 * n, 0);
    for (int i = 0; i < n; i++) {
        cin >> t[n + i];
    }
    for (int i = n - 1; i >= 1; i--) {
        t[i] = t[2 * i] + t[2 * i + 1];
    }
    for (int k = 0; k < q; k++) {
        string cmd;
        cin >> cmd;
        if (cmd == "ADD") {
            int i;
            long long x;
            cin >> i >> x;
            for (int pos = i - 1 + n; pos >= 1; pos /= 2) {
                t[pos] += x;
            }
        } else {
            int l, r;
            cin >> l >> r;
            long long s = 0;
            for (int lo = l - 1 + n, hi = r + n; lo < hi; lo /= 2, hi /= 2) {
                if (lo % 2 == 1) {
                    s += t[lo++];
                }
                if (hi % 2 == 1) {
                    s += t[--hi];
                }
            }
            cout << s << endl;
        }
    }
    return 0;
}
2

The first large enough value

Medium

Read n and q and then the array, and then q commands: SET i v changes element i to v, and FIRST x prints the smallest position (from 1) whose value is x or more, or -1 if there is none.

Requirements
  • Build a maximum tree.
  • For FIRST x: if the maximum of the node is below x there is none; otherwise go down, to the left child if its maximum is at least x, else to the right child.
  • At the leaf print its position plus 1.
Example input and expected output
6 4 3 8 2 9 4 7 FIRST 8 SET 2 1 FIRST 8 FIRST 10
2 4 -1
Hints
  • You do not need a range query: descending from the root is enough, and it takes O(log n).
  • In the example the answers are 2, then 4, then -1.
Sample solution (after you try)
first_large.cpp
// Challenge 2: the first value that is large enough
#include <iostream>
#include <vector>
#include <string>
#include <functional>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    vector<int> t(4 * n, 0);
    function<void(int, int, int)> build = [&](int node, int l, int r) {
        if (l == r) {
            t[node] = a[l];
            return;
        }
        int mid = (l + r) / 2;
        build(2 * node, l, mid);
        build(2 * node + 1, mid + 1, r);
        t[node] = max(t[2 * node], t[2 * node + 1]);
    };
    function<void(int, int, int, int, int)> update = [&](int node, int l, int r, int pos, int val) {
        if (l == r) {
            t[node] = val;
            return;
        }
        int mid = (l + r) / 2;
        if (pos <= mid) {
            update(2 * node, l, mid, pos, val);
        } else {
            update(2 * node + 1, mid + 1, r, pos, val);
        }
        t[node] = max(t[2 * node], t[2 * node + 1]);
    };
    function<int(int, int, int, int)> first = [&](int node, int l, int r, int x) {
        if (t[node] < x) {
            return -1;
        }
        if (l == r) {
            return l;
        }
        int mid = (l + r) / 2;
        if (t[2 * node] >= x) {
            return first(2 * node, l, mid, x);
        }
        return first(2 * node + 1, mid + 1, r, x);
    };
    build(1, 0, n - 1);
    for (int k = 0; k < q; k++) {
        string cmd;
        int x;
        cin >> cmd >> x;
        if (cmd == "SET") {
            int v;
            cin >> v;
            update(1, 0, n - 1, x - 1, v);
        } else {
            int p = first(1, 0, n - 1, x);
            cout << (p == -1 ? -1 : p + 1) << endl;
        }
    }
    return 0;
}

Quick summary

  • A segment tree splits the array into repeated halves and keeps a ready value (sum, minimum, maximum...) for every segment.
  • The children of node node are 2 * node and 2 * node + 1; the root is 1; the recursive version reserves 4n nodes.
  • A range query: outside (return the identity), inside (return the value), partial (ask both children), in O(log n).
  • An update goes down to the leaf and recomputes the parents on the way up, in O(log n).
  • Changing the operation means changing only the combine line: +, min or max.
  • The bottom-up version with an array of size 2n and a query on [l, r) is shorter and faster for order-free operations.
  • The build is O(n).

Glossary

The most important terms in this lesson:

Segment tree

A tree that stores a ready value for each segment of the array.

Node

A segment in the tree.

Leaf

A node covering a single element.

Root

The node covering the whole array.

Merge

The function that combines the values of two children.

Identity element

A value that does not change the result when combined (0 for a sum).

Point update

Changing one element.

Range query

A combined value over a range of elements.

Half-open range

A range [l, r) that includes l and excludes r.

Bottom-up

A version that builds and answers from the leaves to the root without recursion.

Height

The number of levels, about log n.

Lazy propagation

An advanced technique for updating a whole range at once.
