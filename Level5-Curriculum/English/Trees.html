Trees

Graphs without cycles: roots, children, depths and diameters

What will you learn in this lesson?

  • Define a tree and use its facts: n - 1 edges and a unique path
  • Root a tree and compute parent, depth and subtree size with one DFS
  • Find the path between two vertices and the lowest common ancestor by lifting
  • Compute the diameter of a tree with two sweeps
  • Count leaves, height and the number of subordinates of every vertex

A family tree and a folder tree

Your computer has a main folder that holds folders, each holding more folders and files. In a family tree a grandfather has children who have children. This arrangement is a tree (Tree): a special graph built on two rules: it is connected (we can get from any vertex to any other) and it has no cycles.

These two rules give useful facts that we use all the time:

FactWhy?
A tree with n vertices has exactly n - 1 edgesFewer would disconnect it, more would create a cycle
Between any two vertices there is a unique path with no repeated vertexTwo paths would form a cycle
Removing any edge splits it into two connected piecesEach edge is the only route between its ends
Every tree with two or more vertices has at least two leavesThe two ends of a longest path cannot continue

We pick a vertex and call it the root (root), so every edge now points "downward". Every vertex except the root has one parent (parent): its neighbor closest to the root. Its other neighbors are its children (children). A vertex without children is a leaf (leaf).

A rooted tree with DFS

Two important terms: the depth (depth) of a vertex is the number of edges from the root to it, and the subtree (subtree) of v is v and all its descendants, with size sz[v]. The height (height) is the largest depth in the tree. One DFS from the root computes all of them:

rooted_tree.cpp
#include <iostream>#include <vector>#include <functional>using namespace std; int main() {    int n = 9;    int edges[8][2] = {{1, 2}, {1, 3}, {1, 4}, {2, 5}, {2, 6}, {4, 7}, {7, 8}, {7, 9}};    vector<vector<int>> adj(n + 1);    for (auto& e : edges) {        adj[e[0]].push_back(e[1]);        adj[e[1]].push_back(e[0]);    }     vector<int> parent(n + 1, 0), depth(n + 1, 0), sz(n + 1, 1);    function<void(int, int)> dfs = [&](int v, int p) {        parent[v] = p;        for (int u : adj[v]) {            if (u != p) {                depth[u] = depth[v] + 1;                dfs(u, v);                sz[v] += sz[u];            }        }    };    dfs(1, 0);     cout << "v parent depth size" << endl;    for (int v = 1; v <= n; v++) {        cout << v << "  " << parent[v] << "  " << depth[v] << "  " << sz[v] << endl;    }     int leaves = 0, height = 0;    for (int v = 1; v <= n; v++) {        if (v != 1 && adj[v].size() == 1) {            leaves++;        }        height = max(height, depth[v]);    }    cout << "leaves = " << leaves << ", height = " << height << endl;    return 0;}

v parent depth size 1 0 0 9 2 1 1 3 3 1 1 1 4 1 1 4 5 2 2 1 6 2 2 1 7 4 2 3 8 7 3 1 9 7 3 1 leaves = 5, height = 3

Look: the subtree of 7 has size 3 (itself and its children 8 and 9), the subtree of 4 has size 4 (4, 7, 8, 9), and the root's subtree has size 9, every vertex. A leaf always has size 1.

In a tree we do not need a visited array: passing the parent and ignoring it is enough, because a tree has no cycles and a vertex cannot be reached by two routes. And sz is computed after returning from the children. This way (children first, then the parent) is the basis of dynamic programming on trees.

The path between two vertices

Between any two vertices of a tree there is a single path. To find it we lift the deeper vertex until both depths are equal, then lift both together until they meet at the lowest common ancestor (LCA). The path climbs from the first vertex to the ancestor and then descends to the second:

tree_path.cpp
int n = 9;int edges[8][2] = {{1, 2}, {1, 3}, {1, 4}, {2, 5}, {2, 6}, {4, 7}, {7, 8}, {7, 9}};vector<vector<int>> adj(n + 1);for (auto& e : edges) {    adj[e[0]].push_back(e[1]);    adj[e[1]].push_back(e[0]);}vector<int> parent(n + 1, 0), depth(n + 1, 0);function<void(int, int)> dfs = [&](int v, int p) {    parent[v] = p;    for (int u : adj[v]) {        if (u != p) {            depth[u] = depth[v] + 1;            dfs(u, v);        }    }};dfs(1, 0); int a = 8, b = 6;vector<int> left, right;while (depth[a] > depth[b]) {    left.push_back(a);    a = parent[a];}while (depth[b] > depth[a]) {    right.push_back(b);    b = parent[b];}while (a != b) {    left.push_back(a);    right.push_back(b);    a = parent[a];    b = parent[b];}left.push_back(a);reverse(right.begin(), right.end());for (int x : right) {    left.push_back(x);}cout << "path 8 to 6:";for (int x : left) {    cout << " " << x;}cout << endl;cout << "length = " << left.size() - 1 << endl;

The diameter of a tree

The diameter (diameter) of a tree is the length of its longest path between any two vertices. A neat trick finds it with just two sweeps: starting from **any** vertex we find the farthest vertex x, then from x we find the farthest vertex y. The distance between them is the diameter:

tree_diameter.cpp
int n = 9;int edges[8][2] = {{1, 2}, {1, 3}, {1, 4}, {2, 5}, {2, 6}, {4, 7}, {7, 8}, {7, 9}};vector<vector<int>> adj(n + 1);for (auto& e : edges) {    adj[e[0]].push_back(e[1]);    adj[e[1]].push_back(e[0]);}auto farthest = [&](int s) {    vector<int> dist(n + 1, -1);    queue<int> q;    dist[s] = 0;    q.push(s);    int last = s;    while (!q.empty()) {        int v = q.front();        q.pop();        last = v;        for (int u : adj[v]) {            if (dist[u] == -1) {                dist[u] = dist[v] + 1;                q.push(u);            }        }    }    return make_pair(last, dist[last]);}; auto first = farthest(1);auto second = farthest(first.first);cout << "farthest from 1: " << first.first << " (distance " << first.second << ")" << endl;cout << "diameter = " << second.second << " edges, from " << first.first << " to " << second.first << endl;
Click any highlighted line of code to read its explanation here...
farthest from 1: 9 (distance 3) diameter = 5 edges, from 9 to 6

Why does it work? The farthest vertex from any starting point is always an **end** of some longest path, and from that end we find the other end. Remember that this is for trees only, not for general graphs.

Lesson project: company subordinates

We count the subordinates under every employee in a company hierarchy.

The idea

A company has n employees and employee 1 is the general manager. Every other employee has exactly one direct boss. The subordinates of an employee are everyone below them, directly or through a chain of bosses. We want the number of subordinates of every employee.

What you need to do
  1. Read n and then n - 1 numbers: the boss of employee 2, then 3, up to n. Store the list children of every boss.
  2. With a DFS from employee 1 compute sub[v]: after returning from each child u add sub[u] + 1 (the child itself and its subordinates).
  3. Print Subordinates: and then the counts for employees 1 to n.
Two sample runs

First run (the tree we saw):

9 1 1 1 2 2 4 7 7
Subordinates: 8 2 0 3 0 0 2 0 0

Second run (a chain of five employees):

5 1 2 3 4
Subordinates: 4 3 2 1 0

Check it in your head: the number of subordinates of a vertex is sz - 1, so the general manager has 8. In the chain each employee leads everyone after them, so the counts are 4, 3, 2, 1, 0.

After you try it yourself: show the solution
subordinates.cpp
#include <iostream>
#include <vector>
#include <functional>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> children(n + 1);
    for (int i = 2; i <= n; i++) {
        int boss;
        cin >> boss;
        children[boss].push_back(i);
    }

    vector<int> sub(n + 1, 0);
    function<void(int)> dfs = [&](int v) {
        for (int u : children[v]) {
            dfs(u);
            sub[v] += sub[u] + 1;
        }
    };
    dfs(1);

    cout << "Subordinates:";
    for (int v = 1; v <= n; v++) {
        cout << " " << sub[v];
    }
    cout << endl;
    return 0;
}

1

Leaves and height

Easy

Read a tree with n vertices and n - 1 edges, and take vertex 1 as the root. Print the number of leaves and then the height (largest depth), separated by a space.

Requirements
  • Build the adjacency list.
  • With a DFS from the root compute depth for every vertex.
  • A leaf is a vertex other than the root that has exactly one neighbor.
  • Print the number of leaves and the largest depth.
Example input and expected output
9 1 2 1 3 1 4 2 5 2 6 4 7 7 8 7 9
5 3
Hints
  • The root is not a leaf, even if it has only one neighbor.
  • In the example the answer is 5 3.
Sample solution (after you try)
leaves_height.cpp
// Challenge 1: leaves and height of a tree rooted at 1
#include <iostream>
#include <vector>
#include <functional>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < n - 1; i++) {
        int a, b;
        cin >> a >> b;
        adj[a].push_back(b);
        adj[b].push_back(a);
    }
    vector<int> depth(n + 1, 0);
    function<void(int, int)> dfs = [&](int v, int p) {
        for (int u : adj[v]) {
            if (u != p) {
                depth[u] = depth[v] + 1;
                dfs(u, v);
            }
        }
    };
    dfs(1, 0);
    int leaves = 0, height = 0;
    for (int v = 1; v <= n; v++) {
        if (v != 1 && adj[v].size() == 1) {
            leaves++;
        }
        height = max(height, depth[v]);
    }
    cout << leaves << " " << height << endl;
    return 0;
}
2

The longest road in the village

Medium

A village has n houses joined by n - 1 roads that form a tree. What is the largest number of roads you must cross between any two houses?

Requirements
  • Build the adjacency list.
  • Run BFS from vertex 1 and take the farthest vertex x.
  • Run BFS from x and print the largest distance.
Example input and expected output
8 1 2 2 3 3 4 4 5 3 6 6 7 7 8
5
Hints
  • The answer is the diameter of the tree, and it need not pass through the root.
  • In the example the answer is 5.
Sample solution (after you try)
longest_road.cpp
// Challenge 2: the longest road in a village
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < n - 1; i++) {
        int a, b;
        cin >> a >> b;
        adj[a].push_back(b);
        adj[b].push_back(a);
    }
    auto farthest = [&](int s) {
        vector<int> dist(n + 1, -1);
        queue<int> q;
        dist[s] = 0;
        q.push(s);
        int last = s;
        while (!q.empty()) {
            int v = q.front();
            q.pop();
            last = v;
            for (int u : adj[v]) {
                if (dist[u] == -1) {
                    dist[u] = dist[v] + 1;
                    q.push(u);
                }
            }
        }
        return make_pair(last, dist[last]);
    };
    int x = farthest(1).first;
    cout << farthest(x).second << endl;
    return 0;
}

Quick summary

  • A tree is a connected graph with no cycles, it has n - 1 edges, and any two vertices have a unique path.
  • Choosing a root gives every vertex a parent and children; a leaf is a vertex with no children.
  • Depth is the distance from the root, height is the largest depth, and a subtree contains a vertex and its descendants.
  • In a tree DFS we pass the parent and need no visited array.
  • We compute sizes **after** returning from the children (children first, then the parent).
  • The path between two vertices climbs to their lowest common ancestor and then descends.
  • The diameter takes two sweeps: the farthest vertex from any vertex, then the farthest vertex from that one.

Glossary

The most important terms in this lesson:

Tree

A connected graph with no cycles.

Root

The vertex we start from, from which edges point down.

Parent

The neighbor closest to the root.

Child

A neighbor of a vertex that is not its parent.

Leaf

A vertex with no children.

Depth

The number of edges from the root to the vertex.

Height

The largest depth in the tree.

Subtree

A vertex together with all its descendants.

Subtree size

The number of vertices in the subtree.

Ancestor

A vertex on the way from a vertex up to the root.

LCA

The deepest vertex that is an ancestor of two vertices.

Diameter

The longest path between two vertices of the tree.
