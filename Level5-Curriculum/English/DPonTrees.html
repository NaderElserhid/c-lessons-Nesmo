DP on Trees

Every vertex computes its answer from the answers of its children

What will you learn in this lesson?

  • Understand the state of a vertex, its transition from the children, and post-order
  • Compute the subtree sum with dynamic programming
  • Use two states, take and skip, to solve the maximum independent set
  • Compute the longest downward path and the tree diameter in one sweep
  • Decide for any problem: the meaning of the state, the base case, and the transition

Every manager asks their reports

A general manager wants to know the total output of the company branch. They do not visit every employee. They ask department managers, each department manager asks team leaders, and so on down to the leaves. Everyone adds up the answers from below and hands their own answer upward. This is dynamic programming on trees (Tree DP).

It is the same idea as dynamic programming in general: define a state (here: "what do we know about the subtree of vertex v?") and write a transition that computes it from the states of the children. Since children are computed before their parent, the order of computation is post-order (post-order) in a DFS: solve the children first, then combine the results in the parent.

Three steps repeat in every problem: (1) what does dp[v] mean? (2) what is its value for a leaf (the base case)? (3) how do I compute it from the dp of my children?

The simplest example: subtree sum

We give every vertex a value (gold in a region, say) and want, for every vertex, the sum of the values in its subtree. Meaning: sum[v] is the sum of the values of v and its descendants. Base case: the value of v itself. Transition: add sum[u] for every child u:

subtree_sum.cpp
#include <iostream>#include <vector>#include <functional>using namespace std; int main() {    int n = 9;    int edges[8][2] = {{1, 2}, {1, 3}, {1, 4}, {2, 5}, {2, 6}, {4, 7}, {7, 8}, {7, 9}};    int val[10] = {0, 5, 3, 8, 4, 2, 6, 7, 1, 9};    vector<vector<int>> adj(n + 1);    for (auto& e : edges) {        adj[e[0]].push_back(e[1]);        adj[e[1]].push_back(e[0]);    }     vector<long long> sum(n + 1, 0);    function<void(int, int)> dfs = [&](int v, int p) {        sum[v] = val[v];        for (int u : adj[v]) {            if (u != p) {                dfs(u, v);                sum[v] += sum[u];            }        }    };    dfs(1, 0);     for (int v = 1; v <= n; v++) {        cout << "sum[" << v << "] = " << sum[v] << endl;    }    return 0;}

Two states per vertex: the independent set

A set of vertices is independent (independent set) if no edge joins any two of them. We want the largest one. The decision at vertex v affects its children: if we take it, we cannot take any of its children. So we need two states:

StateMeaningTransition
take[v]the largest set in the subtree of v that includes v1 + sum of skip[u] over the children
skip[v]the largest set in the subtree of v that does not include itsum of max(take[u], skip[u])

The diameter with dynamic programming

We saw the diameter with two sweeps. With dynamic programming we find it in one sweep: define down[v] as the longest downward path from v. The longest path in the tree has a highest vertex; from it the path goes down into two branches (or one), so its length is best1 + best2, the two largest values of down[u] + 1 among the children:

tree_dp_diameter.cpp
int n = 9;int edges[8][2] = {{1, 2}, {1, 3}, {1, 4}, {2, 5}, {2, 6}, {4, 7}, {7, 8}, {7, 9}};vector<vector<int>> adj(n + 1);for (auto& e : edges) {    adj[e[0]].push_back(e[1]);    adj[e[1]].push_back(e[0]);}vector<int> down(n + 1, 0);int diameter = 0;function<void(int, int)> dfs = [&](int v, int p) {    int best1 = 0, best2 = 0;    for (int u : adj[v]) {        if (u != p) {            dfs(u, v);            int d = down[u] + 1;            if (d > best1) {                best2 = best1;                best1 = d;            } else if (d > best2) {                best2 = d;            }        }    }    down[v] = best1;    diameter = max(diameter, best1 + best2);};dfs(1, 0); cout << "down:";for (int v = 1; v <= n; v++) {    cout << " " << down[v];}cout << endl;cout << "diameter = " << diameter << endl;

This approach is stronger than the two sweeps because it generalizes: the same style (keeping the best two values from the children) solves problems where the "farthest vertex" trick fails, such as weighted trees with negative weights or sums along diameters.

Lesson project: the company party

We choose the guests to get the most fun possible.

The idea

A company has n employees. Employee 1 is the general manager and every other employee has a direct boss. Each employee has a "fun score" that they add by attending. Nobody wants to attend with their direct boss, so an employee and their direct boss cannot both be invited. We want the largest possible total fun.

What you need to do
  1. Read n, then the fun scores of employees 1 to n, then the boss of each employee from 2 to n.
  2. With a DFS from employee 1 compute the arrays take and skip: take[v] starts with the fun of v and adds skip[u] for each child, and skip[v] adds max(take[u], skip[u]).
  3. Print Maximum fun: and the larger of take[1] and skip[1].
Two sample runs

First run (the tree we saw):

9 5 3 8 4 2 6 7 1 9 1 1 1 2 2 4 7 7
Maximum fun: 30

Second run (a chain of five employees):

5 4 1 6 2 5 1 2 3 4
Maximum fun: 15

Check it in your head: in the chain we cannot invite two consecutive employees, so the best choice is employees 1, 3 and 5 with fun 4 + 6 + 5 = 15.

After you try it yourself: show the solution
company_party.cpp
#include <iostream>
#include <vector>
#include <functional>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> fun(n + 1);
    for (int v = 1; v <= n; v++) {
        cin >> fun[v];
    }
    vector<vector<int>> children(n + 1);
    for (int v = 2; v <= n; v++) {
        int boss;
        cin >> boss;
        children[boss].push_back(v);
    }

    vector<int> take(n + 1, 0), skip(n + 1, 0);
    function<void(int)> dfs = [&](int v) {
        take[v] = fun[v];
        for (int u : children[v]) {
            dfs(u);
            take[v] += skip[u];
            skip[v] += max(take[u], skip[u]);
        }
    };
    dfs(1);

    cout << "Maximum fun: " << max(take[1], skip[1]) << endl;
    return 0;
}

Gold in every region

Easy

A kingdom has n regions. Region 1 is the capital, and every other region has a parent region. Read the amount of gold in each region and then the parent of each region from 2 to n. Print, for every region, the total gold in it and in all the regions that belong to it.

Requirements
  • Store the list of children of each region.
  • With a DFS from the capital compute total[v] after returning from the children.
  • Print total for regions 1 to n separated by spaces.
Example input and expected output
9 5 3 8 4 2 6 7 1 9 1 1 1 2 2 4 7 7
45 11 8 21 2 6 17 1 9
Hints
  • Use long long because the totals may grow large.
  • In the example the answer is 45 11 8 21 2 6 17 1 9.
Sample solution (after you try)
regional_gold.cpp
// Challenge 1: gold in every region
#include <iostream>
#include <vector>
#include <functional>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> gold(n + 1);
    for (int v = 1; v <= n; v++) {
        cin >> gold[v];
    }
    vector<vector<int>> children(n + 1);
    for (int v = 2; v <= n; v++) {
        int boss;
        cin >> boss;
        children[boss].push_back(v);
    }
    vector<long long> total(n + 1, 0);
    function<void(int)> dfs = [&](int v) {
        total[v] = gold[v];
        for (int u : children[v]) {
            dfs(u);
            total[v] += total[u];
        }
    };
    dfs(1);
    for (int v = 1; v <= n; v++) {
        cout << total[v] << " ";
    }
    cout << endl;
    return 0;
}
2

The diameter with DP

Medium

Read a tree with n vertices and n - 1 edges. Print its diameter (the longest path between two vertices, counted in edges) without using BFS, by computing down in a single DFS.

Requirements
  • Define down[v] as the longest downward path from v.
  • For each vertex keep the two largest values best1 and best2 of down[u] + 1 over its children.
  • Update the diameter with best1 + best2 and store best1 in down[v].
Example input and expected output
6 1 2 1 3 3 4 3 5 5 6
4
Hints
  • A vertex with one child has best2 = 0, so the path simply ends there.
  • In the example the answer is 4.
Sample solution (after you try)
dp_diameter.cpp
// Challenge 2: the diameter with dynamic programming
#include <iostream>
#include <vector>
#include <functional>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < n - 1; i++) {
        int a, b;
        cin >> a >> b;
        adj[a].push_back(b);
        adj[b].push_back(a);
    }
    vector<int> down(n + 1, 0);
    int diameter = 0;
    function<void(int, int)> dfs = [&](int v, int p) {
        int best1 = 0, best2 = 0;
        for (int u : adj[v]) {
            if (u != p) {
                dfs(u, v);
                int d = down[u] + 1;
                if (d > best1) {
                    best2 = best1;
                    best1 = d;
                } else if (d > best2) {
                    best2 = d;
                }
            }
        }
        down[v] = best1;
        diameter = max(diameter, best1 + best2);
    };
    dfs(1, 0);
    cout << diameter << endl;
    return 0;
}

Quick summary

  • Tree DP: define a state for each vertex about its subtree and compute it from the states of its children.
  • The order of computation is post-order: children first, then the parent.
  • Decide three things: the meaning of dp[v], its value for a leaf, and its transition from the children.
  • Subtree sum: sum[v] = val[v] + the sum of sum[u].
  • For the independent set we need two states, take[v] and skip[v], and the answer is max(take[1], skip[1]).
  • The longest downward path is down[v], and the diameter is the largest best1 + best2 over all vertices.
  • These problems run in O(n) because each vertex and each edge is handled once.

Glossary

The most important terms in this lesson:

Tree DP

Dynamic programming where each vertex computes a state from its children.

Post-order

Processing a vertex after finishing its children.

State

What we define about the subtree of a vertex.

Transition

The rule that computes a state from the states of the children.

Base case

The value for a leaf, which has no children.

Subtree sum

The sum of the values of a vertex and its descendants.

Independent set

Vertices with no edge between any two of them.

Take

The state where the vertex belongs to the set.

Skip

The state where the vertex does not belong to the set.

Downward path

A path that starts at a vertex and goes down to its descendants.

Diameter

The longest path in the tree.

Optimal substructure

An optimal solution is built from optimal solutions of the parts.
