ممَّ يتكوَّن أي برنامج بلغة C++؟

قبل أن نكتب برامج معقدة، لا بد أن نفهم أولاً الهيكل العام الذي يتكرر في كل برنامج بلغة C++. لنلقِ نظرة على أبسط برنامج ممكن، ثم نفكك مكوناته سطراً سطراً.

main.cpp 
#include <iostream>

using namespace std;

// Your first program!

int main() {
    cout << "Hello, World!";
    return 0;
}

اضغط على أي سطر في الكود أعلاه لتظهر لك شرحاً مبسطاً له:

اضغط على سطر من الكود لعرض شرحه هنا...

وعند تشغيل هذا البرنامج، ستظهر لك النتيجة التالية على الشاشة:

Hello, World!

المكوّنات الأساسية

1

أوامر المترجم القبلي (Preprocessor commands)

تبدأ بالرمز # مثل #include <iostream>، وتُخبر المترجم بإضافة ملفات أو أدوات إضافية قبل ترجمة البرنامج.

2

مساحات الأسماء (Namespaces)

غالباً نكتب using namespace std;. لست بحاجة الآن لفهم مساحات الأسماء بعمق؛ فقط أضِف هذه العبارة في برامجك المبدئية لتتمكن من استخدام cout وcin بسهولة.

3

الدالة الرئيسية main()

هي النقطة التي يبدأ عندها تنفيذ البرنامج. ينفّذ الحاسوب الأوامر داخل الأقواس { ... } من الأعلى إلى الأسفل.

4

الأقواس المعقوفة { }

تُستخدم لتجميع مجموعة من التعليمات في كتلة واحدة. ستراها لاحقاً في الدوال، والحلقات التكرارية، وعبارات الشرط.

5

الفاصلة المنقوطة ;

كل أمر (instruction) ينتهي بفاصلة منقوطة. نسيانها يؤدي إلى ظهور خطأ عند الترجمة، وهو من أكثر الأخطاء شيوعاً عند المبتدئين.

6

أمر الإرجاع return

السطر return 0; ينهي تنفيذ البرنامج، ويُشير إلى أنه انتهى بنجاح دون أي أخطاء.

التعليقات (Comments)

التعليقات هي ملاحظات يكتبها المبرمج، ويتجاهلها الحاسوب تماماً عند التنفيذ. الغرض منها توضيح وظيفة أجزاء من البرنامج، وستستخدمها كثيراً لشرح ما يفعله الكود وتذكير نفسك أو غيرك بوظيفته لاحقاً.

comments.cpp
// هذا تعليق من سطر واحد

/*
هذا تعليق
من عدة أسطر متتالية
*/

مثال إضافي: طباعة أكثر من سطر

لنطبّق ما تعلمناه في مثال جديد يستخدم cout عدة مرات، بالإضافة إلى الكلمة endl التي تعني الانتقال إلى سطر جديد بعد الطباعة:

welcome.cpp 
#include <iostream>
using namespace std;

int main() {
    // طباعة رسالة ترحيبية على سطرين
    cout << "Welcome to C++!" << endl;
    cout << "This is my second line." << endl;
    return 0;
}

الناتج على الشاشة سيكون:

Welcome to C++!
This is my second line.

لاحظ الفرق: بدون endl، كانت كل جملة cout ستُطبع مباشرة بجانب سابقتها في نفس السطر.

المسافات البادئة وتحسين القراءة (Indentation)

يُفضَّل دائماً الإزاحة (Indent) داخل الأقواس { } باستخدام Tab أو 4 مسافات، لأن ذلك يجعل الكود أوضح وأسهل قراءة. تنظيم البرنامج لا يغيّر من طريقة تنفيذه، لكنه مهم جداً لقراءته وصيانته لاحقاً.

أسلوب جيد
int main() {
    cout << "Good style matters!";
}
أسلوب غير جيد
int main(){
cout<<"Hard to read";
}

تثبيت بيئة التطوير Code::Blocks

لتشغيل أول برنامج لك، تحتاج إلى بيئة تطوير متكاملة (IDE) — برنامج يُستخدم لكتابة الشيفرة المصدرية وتشغيلها وإدارتها. سنشرح هنا Code::Blocks، ويمكنك لاحقاً تجربة أي بيئة أخرى تناسبك.

1

توجّه إلى صفحة تحميل Code::Blocks وحمّل ملف التثبيت codeblocks-25.03mingw-setup.exe (اختر الإصدار الذي يحتوي على MinGW؛ قد يكون رقم الإصدار لديك مختلفاً).

2

هذا الإصدار يتضمّن مترجم MinGW، لذلك لا حاجة لتثبيت مترجم منفصل.

3

شغّل ملف التثبيت واترك الخيارات الافتراضية كما هي.

1

ثبّت أدوات سطر الأوامر من Apple لتحصل على مترجم clang: xcode-select --install

2

حمّل ملف CodeBlocks-25.03_macOS-11.7_x64-wx3.2.6.dmg من صفحة التحميل وثبّته (قد يختلف رقم الإصدار).

3

إذا لم يجد Code::Blocks المترجم عند أول تشغيل: اذهب إلى Settings → Compiler واختر Clang إن كان متاحاً.

إذا بدا لك Code::Blocks غير مريح (خصوصاً على macOS)، يمكنك استخدام CLion أو VS Code بدلاً منه. على Windows وmacOS ستحتاج لتثبيت مترجم (MinGW أو Clang)، بينما في Linux يكون مترجم GCC متوفراً مسبقاً غالباً. إذا استخدمت VS Code، تأكد من تثبيت إضافة C/C++.

إنشاء المشروع وتشغيل أول برنامج

1

مشروع جديد

من القائمة الرئيسية: File → New → Project → Console application، ثم اختر C++ واضغط Next.

2

تسمية المشروع

أدخل اسماً مثل HelloWorld، اختر مجلد الحفظ، ثم اضغط Finish. سينشئ Code::Blocks ملفاً باسم main.cpp.

3

كتابة البرنامج

افتح main.cpp واستبدل محتواه بالكامل ببرنامج Hello World الموضح أعلاه.

4

البناء والتشغيل

اضغط زر Build and run (المثلث الأخضر) أو F9. يجب أن تظهر النتيجة Hello, World!.

ماذا يحدث فعلياً؟ عند الضغط على Build، يستدعي Code::Blocks المترجم (MinGW على Windows أو Clang على macOS)، الذي يحوّل الشيفرة المصدرية إلى ملف تنفيذي (Binary) يمكن لنظام التشغيل تشغيله مباشرة — بامتداد .exe غالباً على Windows. لاحقاً ستتعرّف بتفصيل أكبر على المترجم (Compiler) والرابط (Linker) وإعدادات البناء (Build Settings)؛ يكفي الآن فهم الفكرة العامة.

قاموس المصطلحات

هذه أهم المصطلحات الإنجليزية التي ظهرت في هذا الدرس مع مرادفها العربي، لتعتاد على استخدامها بثقة:

Preprocessorالمعالج القبلي / المترجم القبلي

مرحلة تسبق الترجمة، تُنفَّذ فيها أوامر تبدأ بـ #.

Namespaceمساحة الاسم

مجموعة أسماء (دوال، متغيرات) مُجمَّعة تحت نطاق واحد لتفادي التعارض بينها.

Functionدالة

مجموعة أوامر مجمّعة تحت اسم واحد لتنفيذ مهمة محددة.

main()الدالة الرئيسية

نقطة البداية التي ينفذ عندها الحاسوب أول أمر في البرنامج.

Compilerالمترجم (المصرّف)

برنامج يحوّل الشيفرة المصدرية إلى ملف تنفيذي يفهمه الحاسوب.

Commentتعليق

ملاحظة نصية يكتبها المبرمج ويتجاهلها الحاسوب عند التنفيذ.

Indentationالإزاحة / المسافة البادئة

تنسيق الكود بمسافات ثابتة لتحسين وضوحه وقراءته.

IDEبيئة تطوير متكاملة

برنامج يجمع محرر الكود والمترجم وأدوات التشغيل في مكان واحد.

Compileترجمة / تصريف

عملية تحويل الشيفرة المصدرية إلى ملف تنفيذي.

Linkerالرابط

أداة تربط أجزاء البرنامج المترجمة معاً لإنتاج الملف التنفيذي النهائي.

Buildبناء

العملية الكاملة من الترجمة إلى الربط لإنتاج برنامج قابل للتشغيل.

Executable / Binaryملف تنفيذي / ثنائي

الملف الجاهز الذي يستطيع نظام التشغيل تشغيله مباشرة.

endlنهاية السطر

اختصار لكلمة end line، يُستخدم مع cout للانتقال إلى سطر جديد.

Console applicationتطبيق طرفي

برنامج يعمل عبر نافذة نصية بسيطة (Terminal) بدون واجهة رسومية.
