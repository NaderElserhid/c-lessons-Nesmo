::سؤال 1: مفهوم الثابت::ما هو الثابت (Constant) في C++؟ {
=قيمة تُحدَّد مرة واحدة ولا يمكن تغييرها أثناء تشغيل البرنامج
~متغير يتغيّر تلقائياً في كل دورة تكرار
~نوع خاص من أنواع الدوال في C++
}

::سؤال 2: محاولة تغيير ثابت::ماذا يحدث إذا حاولت تغيير قيمة ثابت مُعرَّف بـ const بعد تعريفه؟ {
=يظهر خطأ عند الترجمة (Compile Error)
~تتغيّر القيمة بنجاح دون أي مشاكل
~يتم تجاهل السطر تلقائياً فقط دون أي رسالة
}

::سؤال 3: الكلمة المفتاحية الحديثة::ما الكلمة المفتاحية المفضّلة لتعريف ثابت في C++ الحديثة؟ {
=const
~define
~fixed
}

::سؤال 4: تهيئة الثابت::هل يمكن ترك الثابت بدون قيمة عند تعريفه، لملئها لاحقاً كما نفعل مع المتغيرات العادية؟ {
=لا، يجب إعطاء الثابت قيمة لحظة تعريفه
~نعم، يمكن ملؤها في أي سطر لاحق
~نعم، لكن فقط داخل الحلقات
}

::سؤال 5: القيمة الحرفية::ما المقصود بالقيمة الحرفية (Literal)؟ {
=قيمة خام تُكتب مباشرة في الكود، مثل الرقم 5 أو النص "Hi"
~اسم متغير يُعرَّف باستخدام const
~دالة جاهزة في مكتبة iostream
}

::سؤال 6: لاحقة float::أي لاحقة تُستخدم لتعريف قيمة عددية من نوع float؟ {
=f
~LL
~U
}

::سؤال 7: لاحقة long long::أي لاحقة تُستخدم لتعريف قيمة عددية من نوع long long؟ {
=LL
~f
~U
}

::سؤال 8: لاحقة unsigned::أي لاحقة تُستخدم لتعريف عدد صحيح غير سالب (unsigned int)؟ {
=U
~L
~f
}

::سؤال 9: النوع الافتراضي للأعداد الصحيحة::إذا لم تُضِف أي لاحقة لعدد صحيح، ما النوع الذي تفترضه C++ افتراضياً؟ {
=int
~double
~char
}

::سؤال 10: النوع الافتراضي للأعداد العشرية::إذا لم تُضِف أي لاحقة لعدد عشري، ما النوع الذي تفترضه C++ افتراضياً؟ {
=double
~float
~long
}

::سؤال 11: الطريقة القديمة للثوابت::كيف كانت تُعرَّف الثوابت في C++ قبل ظهور الكلمة المفتاحية const؟ {
=باستخدام #define
~باستخدام كلمة final
~لم تكن هناك طريقة لتعريف ثوابت أصلاً
}

::سؤال 12: الفرق بين const و#define::ما الفرق الأساسي بين const و#define؟ {
=const يحترم نوع البيانات ويخضع لفحص المترجم، بينما #define مجرد استبدال نصي قبل الترجمة
~لا يوجد أي فرق بينهما إطلاقاً
~#define أكثر أماناً من const في C++ الحديثة
}

::سؤال 13: توجيه المعالج القبلي::ما اسم الأمر الذي يبدأ بـ # ويُنفَّذ قبل ترجمة الكود نفسه، مثل #define أو #include؟ {
=توجيه للمعالج القبلي (Preprocessor directive)
~دالة رئيسية (Main function)
~متغير عام (Global variable)
}

::سؤال 14: فوائد استخدام الثوابت::من فوائد استخدام الثوابت: حماية القيم المهمة، وضوح الكود، وأيضاً؟ {
=سهولة التحديث لاحقاً من مكان واحد فقط في الكود
~تسريع عملية الترجمة بشكل كبير جداً
~تقليل حجم ملف البرنامج التنفيذي
}

::سؤال 15: مصطلح Read-only::ما المقصود بمصطلح Read-only؟ {
=قيمة يمكن قراءتها واستخدامها، لكن لا يمكن تعديلها
~قيمة لا يمكن قراءتها إطلاقاً
~نوع بيانات خاص بالنصوص فقط
}
