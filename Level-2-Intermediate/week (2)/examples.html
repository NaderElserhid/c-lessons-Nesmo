اختبر معلوماتك: الخرائط (Maps)

المثال التدريبي الشامل (Comprehensive Example)

هذا المثال يحتوي على تطبيق عملي لنظام إدارة درجات الطلاب، يجمع كل المفاهيم: الإضافة، البحث، التكرار، الحذف، والفرق بين map و unordered_map.

#include <iostream>
#include <map>
#include <unordered_map>
#include <string>

using namespace std;

int main() {
    // 1. Creating an ordered map (Key: string, Value: int)
    map<string, int> grades;

    // 2. Inserting elements using the [] operator
    grades["Alice"] = 95;
    grades["Bob"] = 82;
    grades["Charlie"] = 88;

    // 3. Checking if map is empty and getting its size
    if (!grades.empty()) {
        cout << "Map size is: " << grades.size() << endl;
    }

    // 4. Checking if a key exists using count()
    if (grades.count("Alice")) {
        cout << "Alice is in the system." << endl;
    }

    // 5. Accessing an existing element
    cout << "Bob's grade: " << grades["Bob"] << endl;

    // 6. WARNING: Accessing a non-existent element creates it with a default value (0)
    cout << "David's default grade: " << grades["David"] << endl;

    // 7. Searching safely using find()
    auto it = grades.find("Charlie");
    if (it != grades.end()) {
        cout << "Found " << it->first << " with grade " << it->second << endl;
    }

    // 8. Iterating using a range-based for loop (Output is alphabetically sorted)
    cout << "\n--- All Grades (Ordered) ---" << endl;
    for (auto p : grades) {
        cout << p.first << ": " << p.second << endl;
    }

    // 9. Erasing an element by its key
    grades.erase("David");

    // 10. Iterating using iterators
    cout << "\n--- Grades after erasing David ---" << endl;
    for (auto iter = grades.begin(); iter != grades.end(); iter++) {
        cout << iter->first << ": " << iter->second << endl;
    }

    // 11. Using unordered_map for faster access (Order is not guaranteed)
    unordered_map<int, string> id_to_name;
    id_to_name[101] = "Alice";
    id_to_name[102] = "Bob";

    cout << "\n--- Unordered Map (ID -> Name) ---" << endl;
    for (auto p : id_to_name) {
        cout << "ID " << p.first << " -> " << p.second << endl;
    }

    // 12. Clearing all elements from the map
    grades.clear();
    cout << "\nMap cleared. Is empty now? " << (grades.empty() ? "Yes" : "No") << endl;

    return 0;
}

شرح المثال الشامل:

  • الخطوات 1 و 2: أنشأنا map عادية للدرجات، وأضفنا البيانات باستخدام الأقواس [].
  • الخطوة 3: استخدمنا empty() لنتأكد أنها غير فارغة، ثم size() لمعرفة عدد الطلاب.
  • الخطوة 4 و 5: استخدمنا count() للبحث السريع عن (Alice)، وطبعنا درجة (Bob) مباشرة.
  • الخطوة 6 (مهمة جداً): حاولنا طباعة درجة شخص غير موجود (David). في C++ هذا لا يسبب خطأ، بل يضيفه تلقائياً بصفر!
  • الخطوة 7: استخدمنا الدالة الاحترافية والآمنة find() للبحث عن (Charlie).
  • الخطوة 8 و 9 و 10: قمنا بالمرور على العناصر وطباعتها (لاحظ الترتيب الأبجدي)، ثم حذفنا (David) الذي تمت إضافته بالخطأ باستخدام erase()، ثم طبعنا العناصر مجدداً باستخدام المؤشرات (Iterators).
  • الخطوة 11: استخدمنا unordered_map لربط (رقم الطالب -> اسمه). هذه الخريطة أسرع لكنها لا ترتب العناصر.
  • الخطوة 12: استخدمنا clear() لتدمير جميع البيانات داخل الخريطة في نهاية البرنامج.
