دليل شامل لفهم الخرائط (Maps) في C++

ما هي الخرائط (Maps)؟

الخريطة (map) في لغة C++ هي نوع من أنواع الحاويات (Containers) المتاحة في مكتبة القوالب القياسية (STL). تقوم هذه الحاوية بتخزين البيانات على شكل أزواج (Pairs) تتكون من:
مفتاح (Key) -> قيمة (Value).

  • المفاتيح فريدة: لا يمكن أن يتكرر نفس المفتاح داخل الخريطة مرتين.
  • الترتيب التلقائي: تقوم الـ map بترتيب العناصر بداخلها تلقائياً تصاعدياً بناءً على "المفتاح" (Key) باستخدام بنية بيانات الشجرة (غالبًا Red-Black Tree).
  • الوصول السريع: تتيح لك الوصول إلى أي قيمة بسرعة عالية جداً تعادل تعقيد وقتي $O(\log n)$ بمجرد معرفة المفتاح الخاص بها.

مثال أساسي على استخدام Map

#include <iostream>
#include <map>
using namespace std;

int main() {
    map<string, int> ages;
    
    ages["Alice"] = 25;
    ages["Bob"] = 30;
    ages["Charlie"] = 22;
    
    for (auto p : ages) {
        cout << p.first << ": " << p.second << endl;
    }
    
    return 0;
}
شرح الكود:
في هذا المثال، قمنا بإنشاء خريطة اسمها ages مفتاحها من نوع نص (string) يمثل اسم الشخص، وقيمتها من نوع رقم صحيح (int) تمثل عمره. أضفنا ثلاثة أشخاص بأعمارهم. عند طباعة العناصر باستخدام حلقة for، ستلاحظ أن الناتج سيُطبع بالترتيب الأبجدي للأسماء (Alice ثم Bob ثم Charlie) لأن الخريطة ترتب البيانات تلقائيًا حسب المفتاح. المخرجات ستكون:
Alice: 25
Bob: 30
Charlie: 22

إنشاء خريطة (Creating a map)

لاستخدام الخرائط في برنامجك، يجب عليك أولاً تضمين المكتبة الخاصة بها:

#include <map>

بعد ذلك، يمكنك الإعلان عن الخريطة وتحديد أنواع البيانات للمفتاح والقيمة كما يلي:

map<int, string> students;     // المفتاح: رقم صحيح (int)، القيمة: نص (string)
map<string, double> prices;    // المفتاح: نص (string)، القيمة: رقم عشري (double)
map<char, int> frequency;      // المفتاح: حرف (char)، القيمة: رقم صحيح (int)
شرح الكود:
طريقة التعريف مرنة جداً؛ يمكنك دمج أي نوعين من البيانات. الجزء الأول بين الأقواس الزاوية < > يمثل نوع المفتاح، والجزء الثاني يمثل نوع القيمة المرتبطة بهذا المفتاح.

إضافة العناصر والوصول إليها

map<string, int> scores;
scores["Mark"] = 90;          // إضافة عنصر جديد باستخدام الأقواس المربعة []
cout << scores["Mark"];       // يطبع: 90

cout << scores["Unknown"];  // تحذير: هذا سينشئ المفتاح "Unknown" بقيمة افتراضية (0)
شرح الكود:
نستخدم الأقواس المربعة [] لإضافة قيم جديدة أو تعديل قيم موجودة أو حتى طباعتها. ملاحظة هامة: إذا حاولت طباعة مفتاح غير موجود (مثل "Unknown")، فإن C++ لن تعطي خطأ، بل ستقوم بإنشاء هذا المفتاح وتعيين قيمة افتراضية له (وهي 0 للأرقام الصحيحة).

إذا كنت تريد التحقق من وجود مفتاح بدون إنشاءه عن طريق الخطأ، يُفضل استخدام دالة count():

if (scores.count("Tom")) {
    cout << "Tom is in the map!";
} else {
    cout << "Tom is not found.";
}
شرح الكود:
دالة count(key) ترجع الرقم 1 إذا كان المفتاح موجوداً في الخريطة، وترجع 0 إذا لم يكن موجوداً. هذه هي الطريقة الآمنة للتحقق من وجود العناصر.

العمليات الشائعة (Common Operations)

العملية المثال الوصف
m[key] m["Bob"] الوصول إلى القيمة المرتبطة بالمفتاح، أو إنشاؤها بقيمة افتراضية إن لم تكن موجودة.
erase(key) m.erase("Bob") حذف المفتاح والقيمة المرتبطة به من الخريطة.
count(key) if (m.count("Bob")) ترجع 1 إذا كان المفتاح موجوداً، و 0 إذا لم يكن كذلك.
size() m.size(); إرجاع عدد العناصر (الأزواج) المخزنة حالياً في الخريطة.
clear() m.clear(); حذف جميع العناصر وتفريغ الخريطة بالكامل.
empty() m.empty(); ترجع القيمة true إذا كانت الخريطة فارغة، و false إن كان بها عناصر.

مثال عملي: حساب تكرار الكلمات

#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    string text = "apple banana apple orange banana apple";
    map<string, int> freq;
    string word = "";
    
    for (char c : text) {
        if (c == ' ') {
            if (!word.empty()) {
                freq[word]++; // زيادة تكرار الكلمة
            }
            word.clear(); // تصفير المتغير لاستقبال الكلمة التالية
        } else {
            word += c; // بناء الكلمة حرفاً بحرف
        }
    }
    if (!word.empty()) freq[word]++; // إضافة الكلمة الأخيرة
    
    // طباعة النتائج
    for (auto p : freq) {
        cout << p.first << ": " << p.second << endl;
    }
    
    return 0;
}
شرح الكود:
هذا المثال يقوم بقراءة نص طويل ويحسب عدد مرات تكرار كل كلمة فيه. نقوم بالمرور على النص حرفاً بحرف، وعندما نجد "مسافة فارغة" نعرف أن الكلمة قد انتهت فنزيد عدادها في الخريطة باستخدام freq[word]++. الخريطة هنا مثالية لهذا الغرض؛ لأن المفتاح هو "الكلمة"، والقيمة هي "عدد مرات ظهورها". المخرجات ستكون مرتبة أبجدياً:
apple: 3
banana: 2
orange: 1

التكرار عبر الخريطة (Iterating over a map)

يمكنك المرور على عناصر الخريطة بطريقتين أساسيتين:

1. باستخدام حلقة for الحديثة (Range-based for loop):

for (auto p : myMap) {
    cout << p.first << " -> " << p.second << endl;
}
شرح الكود:
الرمز p يمثل الزوج (Pair) في كل دورة. للوصول إلى المفتاح نكتب p.first، وللوصول إلى القيمة نكتب p.second.

2. باستخدام المؤشرات (Iterators):

for (auto it = myMap.begin(); it != myMap.end(); it++) {
    cout << it->first << ": " << it->second << endl;
}
شرح الكود:
هنا نستخدم مؤشر it يبدأ من العنصر الأول begin() ويستمر حتى نهاية الخريطة end(). لاحظ أننا نستخدم المعامل -> للوصول إلى first و second لأن it هو مؤشر وليس كائناً عادياً.

أنواع الخرائط (map مقابل unordered_map)

النوع يحافظ على الترتيب؟ يسمح بالمفاتيح المكررة؟ السرعة (متوسط) ملاحظات
map نعم لا $O(\log n)$ يخزن المفاتيح مرتبة باستخدام شجرة متوازنة (Balanced Tree).
unordered_map لا لا $O(1)$ سريع جداً في البحث والوصول، يعتمد على الجداول المبعثرة (Hash Tables)، لكن الترتيب يكون عشوائياً.

مثال على unordered_map:

#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    unordered_map<string, int> age;
    age["Bob"] = 30;
    age["Alice"] = 25;
    age["Tom"] = 28;
    
    for (auto p : age) {
        cout << p.first << ": " << p.second << endl;
    }
    
    return 0;
}
شرح الكود:
هنا استخدمنا unordered_map بدلاً من map. الكود هو نفسه تماماً، ولكن المخرجات لن تكون مرتبة أبجدياً بل ستكون بترتيب عشوائي يعتمد على دالة التجزئة (Hash Function) الداخلية. يتميز هذا النوع بسرعة أكبر في إضافة والبحث عن البيانات.
المخرجات (مثال):
Bob: 30
Tom: 28
Alice: 25

أمثلة إضافية (متقدمة قليلاً)

استخدام دالة find() للبحث الاحترافي:

#include <iostream>
#include <map>
using namespace std;

int main() {
    map<string, string> dictionary;
    dictionary["Car"] = "سيارة";
    dictionary["House"] = "منزل";

    auto it = dictionary.find("Car");
    
    if (it != dictionary.end()) {
        cout << "معنى الكلمة هو: " << it->second << endl;
    } else {
        cout << "الكلمة غير موجودة في القاموس" << endl;
    }
    return 0;
}
شرح الكود:
دالة find(key) تقوم بالبحث عن المفتاح. إذا وجدته، تُرجع مؤشراً (Iterator) يشير إليه، وإذا لم تجده تُرجع مؤشراً يشير إلى end(). هذه الطريقة أسرع وأكثر احترافية من استخدام دالة count() عندما تحتاج إلى قيمة العنصر بمجرد التأكد من وجوده.
