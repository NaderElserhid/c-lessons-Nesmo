📝 وصف المسألة: Sum of Two Values (CSES)

يُعطى لك مصفوفة تحتوي على n من الأعداد الصحيحة، ومهمتك هي إيجاد موقعين مختلفين بحيث يكون مجموع القيمتين يساوي القيمة x.

الإدخال:
- السطر الأول: عددان صحيحان n و x.
- السطر الثاني: n من الأعداد الصحيحة.

المخرجات:
- إمّا موقعان (يبدأ الترقيم من 1) بحيث مجموعهما يساوي x.
- أو IMPOSSIBLE إذا لم يوجد حل.

مثال:
الإدخال: 4 8
المصفوفة: 2 7 5 1
المخرجات: 2 4 (لأن العنصر الثاني هو 7، والرابع 1، ومجموعهما 8)

كيف نفكر كالمحترفين؟ 🤔

الطريقة البسيطة: استخدام حلقتين متداخلتين، لكن ستكون العمليات N × N وهذا بطيء جداً.

الطريقة الذكية: استخدام الخريطة (Map) 🗺️
تخيل أنك تبحث عن المجموع 8، ووجدت الرقم 2. إذن أنت فوراً تعرف أنك بحاجة للرقم 6 (لأن 8 - 2 = 6).
في البرمجة نقول: A + B = X وهذا يعني أننا نبحث عن المتمم: B = X - A.
نسأل الخريطة: هل رأينا الرقم 6 سابقاً؟
- نعم: اطبع الموقعين.
- لا: سجل الرقم 2 في الخريطة وأكمل طريقك.

#include <iostream>
#include <map>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; long long x;
    cin >> n >> x;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    map<long long, int> pos;
    for (int i = 0; i < n; i++) {
        long long need = x - a[i];
        if (pos.find(need) != pos.end()) {
            cout << pos[need] << " " << (i + 1) << "\n";
            return 0;
        }
        pos[a[i]] = i + 1;
    }
    cout << "IMPOSSIBLE\n";
    return 0;
}

📝 وصف المسألة: Difference of Two Values

يُعطى لك مصفوفة تحتوي على n أعداد، ومهمتك هي إيجاد موقعين مختلفين بحيث يكون الفرق (الطرح) بينهما يساوي x.

مثال:
الإدخال: 4 5
المصفوفة: 8 2 1 7
المخرجات: 4 2 (لأن العنصر الرابع هو 7، والعنصر الثاني هو 2، والفرق 7 - 2 = 5)

كيف نعدّل فكرتنا لتناسب هذه المسألة؟ 🧐

نحن نبحث عن رقمين الفرق بينهما يساوي X. أي: |A - B| = X.

بافتراض أن A هو الرقم الحالي الذي نقف عنده، فإن الرقم B الذي نبحث عنه في الخريطة إما أن يكون:
1. أصغر من A: فتكون المعادلة B = A - X.
2. أكبر من A: فتكون المعادلة B = A + X.

إذن في كل خطوة، سنسأل الخريطة: هل رأيتِ A - X أو A + X من قبل؟

#include <iostream>
#include <map>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; long long x;
    cin >> n >> x;
    vector<long long> a(n);
    map<long long, int> pos;

    for (int i = 0; i < n; i++) {
        cin >> a[i];
        long long current = a[i];

        long long target1 = current - x;
        if (pos.find(target1) != pos.end()) {
            cout << pos[target1] << " " << (i + 1) << "\n";
            return 0;
        }

        long long target2 = current + x;
        if (pos.find(target2) != pos.end()) {
            cout << pos[target2] << " " << (i + 1) << "\n";
            return 0;
        }

        pos[current] = i + 1;
    }
    cout << "IMPOSSIBLE\n";
    return 0;
}
