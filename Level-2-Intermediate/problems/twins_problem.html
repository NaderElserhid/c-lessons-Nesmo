مسألة التوأم (Twins) 👯‍♂️

تطبيق كلاسيكي من Codeforces على خوارزميات الجشع (Greedy)

📝 نص المسألة

تخيل أنك وأخوك التوأم وجدتما مصفوفة $A$ تحتوي على $n$ من العملات المعدنية بقيم مختلفة. تريدان تقاسم هذه العملات، ولكنك لست عادلاً تماماً!

المطلوب: حدد أقل عدد من العملات التي يجب عليك اختيارها لنفسك، بحيث يكون مجموع قيم العملات التي تمتلكها أكبر تماماً من مجموع قيم العملات المتبقية لأخيك.

💡 الفكرة الجشعة (Greedy Logic):
بما أننا نريد أخذ "أقل عدد" من العملات لنصل إلى مجموع كبير، فمن المنطقي جداً أن نكون جشعين ونستهدف العملات ذات القيمة الأكبر دائماً!
لذلك: سنقوم أولاً بحساب المجموع الكلي، ثم نرتب العملات، ونبدأ بأخذ العملة الأكبر فالأكبر حتى يتفوق مجموعنا على المتبقي.

🎮 محاكي الخوارزمية التفاعلي

أدخل قيم العملات مفصولة بمسافة (مثال: 3 3 1 2)، وشاهد كيف تفكر الخوارزمية الجشعة!

المجموع الكلي: -
مجموعي: 0
المتبقي: 0
العملات المختارة: 0
انتظر بدء المحاكاة...
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int a[n];
    
    int total_sum = 0;
    
    // 1. قراءة العملات وحساب المجموع الكلي
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        total_sum += a[i];
    }
    
    // 2. ترتيب المصفوفة تصاعدياً (من الأصغر للأكبر)
    sort(a, a + n);
    
    int selected_sum = 0;
    int cnt = 0;
    
    // 3. المرور العكسي (Greedy: نأخذ من الأكبر إلى الأصغر)
    for (int i = n - 1; i >= 0; i--) {
        selected_sum += a[i]; // نأخذ العملة الأكبر
        cnt++;                // نزيد عداد العملات المختارة
        
        // إذا أصبح مجموعنا أكبر من المجموع المتبقي، نتوقف!
        if (selected_sum > total_sum - selected_sum) {
            cout << cnt << endl;
            break;
        }
    }
    return 0;
}
