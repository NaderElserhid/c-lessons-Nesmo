📖 الشرح المبسط للمسألة

تخيل أننا قمنا بلصق جميع الأرقام الصحيحة الموجبة (1، 2، 3، ...) بجانب بعضها البعض لتكوين سلسلة نصية لانهائية الطول هكذا:

123456789101112131415...

لدينا $q$ استعلامات. في كل استعلام، يُعطى لك موقع $k$ (مرقم بداية من 1). المطلوب: ما هو الرقم (الخانة) الموجود في هذا الموقع تحديداً؟
ملاحظة: الموقع $k$ يمكن أن يصل إلى $10^{18}$، لذا مستحيل بناء السلسلة فعلياً في الذاكرة!

💡 الفكرة السحرية (استبعاد الكتل):
سنقوم بتقسيم الأعداد إلى كتل: كتلة ذات خانة واحدة (1-9)، كتلة ذات خانتين (10-99)، وهكذا. سنطرح حجم كل كتلة من $k$ حتى نكتشف في أي كتلة يقع هدفنا!

📝 خطوات الحل رياضياً

  1. تخطي الكتل غير المناسبة:
    • الأعداد ذات خانة واحدة ($d=1$) عددها 9، وإجمالي خاناتها $= 9 \times 1 = 9$.
    • الأعداد ذات خانتين ($d=2$) عددها 90، وإجمالي خاناتها $= 90 \times 2 = 180$.
    • في كل خطوة نحسب block_len = 9 * base * d. إذا كان $k > block_len$، نطرح هذا الطول من $k$ وننتقل للكتلة التالية ($d+1$).
  2. تحديد العدد بالضبط:
    • بمجرد معرفة الكتلة $d$، نجعل $k_0 = k - 1$ لنتعامل بنظام (0-based).
    • لمعرفة "أي عدد" داخل الكتلة يقع فيه هدفنا: index_of_number = k0 / d.
    • العدد الفعلي $= 10^{d-1} + index\_of\_number$.
  3. استخراج الخانة:
    • لمعرفة "أي خانة" داخل هذا العدد: index_in_number = k0 % d.
    • نحول العدد لنص ونستخرج الحرف الموجود في index_in_number.

💻 كود الحل (C++)

#include <iostream>
#include <string>
using namespace std;

int main() {
    // تسريع عمليات الإدخال والإخراج
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int q;
    cin >> q;
    
    while (q--) {
        long long k;
        cin >> k;
        
        long long d = 1;       // طول الخانات للكتلة الحالية
        long long base = 1;    // 10^(d-1) (بداية الكتلة)
        
        // الخطوة 1: البحث عن الكتلة الصحيحة
        while (true) {
            long long count_numbers = 9 * base;      
            long long block_len = count_numbers * d; 
            
            if (k > block_len) {
                k -= block_len;
                d++;
                base *= 10;
            } else {
                break; // وجدنا الكتلة!
            }
        }
        
        // الخطوة 2: تحديد العدد والخانة داخله
        long long k0 = k - 1;                 // تحويل لـ 0-based
        long long index_of_number = k0 / d;   // ترتيب العدد داخل الكتلة
        long long index_in_number = k0 % d;   // ترتيب الخانة داخل العدد
        
        long long num = base + index_of_number;
        
        // تحويل العدد لنص لاستخراج الخانة المطلوبة
        string s = to_string(num);
        cout << s[index_in_number] << "\n";
    }
    
    return 0;
}
