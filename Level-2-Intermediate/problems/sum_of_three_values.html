مستوى متقدم: تحدي الثلاثيات! 🎯

في الدرس السابق بحثنا عن رقمين، اليوم سنرفع التحدي لنبحث عن ثلاثة أرقام. هل أنت مستعد للغوص في "البحث الثنائي"؟

📝 وصف المسألة: Sum of Three Values (CSES)

يُعطى لك مصفوفة من n أعداد صحيحة، ومهمتك هي إيجاد ثلاث قيم في مواقع مختلفة يكون مجموعها يساوي x.

الإدخال:
- السطر الأول: عددان صحيحان n (حجم المصفوفة) و x (المجموع المطلوب).
- السطر الثاني: n من الأعداد الصحيحة.

المخرجات:
- اطبع ثلاثة أعداد صحيحة: مواقع القيم المختارة (مرقّمة من 1).
- إذا لم توجد أي ثلاثية تحقق الشرط، فاطبع IMPOSSIBLE.

مثال:
الإدخال: 4 8
المصفوفة: 2 7 5 1
المخرجات: 1 3 4 (لأن العنصر الأول هو 2، والثالث 5، والرابع 1. ومجموعهم: 2 + 5 + 1 = 8)

كيف نبتعد عن الحل البطيء؟ 🐢 ⬅️ 🐇

الحل العنيف (البطيء جداً): استخدام 3 حلقات تكرار متداخلة (Nested Loops) لتجربة كل الاحتمالات الممكنة. هذا الحل يحتاج إلى وقت O(N³) وسيفشل إذا كانت المصفوفة كبيرة!

الحل الذكي: الفرز + البحث الثنائي (Binary Search) 🔍
تخيل أنك تختار فريقاً من 3 لاعبين لتحقيق نقاط معينة. بدلاً من تجربة الجميع معاً عشوائياً، سنقوم بالتالي:
1. نرتب اللاعبين (الأرقام) من الأصغر للأكبر. لكن تذكر أن نحتفظ بأرقام قمصانهم الأصلية (مواقعهم الأولى)!
2. نختار أول لاعبين (نُثبت i و j).
3. الآن نحن نعرف بالضبط كم نقطة نحتاج من اللاعب الثالث: need = x - (القيمة الأولى + القيمة الثانية).
4. بما أن القائمة مرتبة، لا داعي للبحث عن اللاعب الثالث بالمرور عليهم واحداً تلو الآخر، بل نستخدم البحث الثنائي لنجده في ثوانٍ معدودة!
هذه الطريقة تقلل الوقت من O(N³) إلى O(N² log N)، وهو أداء ممتاز!

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long x;
    cin >> n >> x;

    // مصفوفة من الأزواج (Pair) لتخزين القيمة وموقعها الأصلي
    vector<pair<long long, int>> a(n);
    for (int i = 0; i < n; ++i) {
        long long v;
        cin >> v;
        a[i] = {v, i + 1}; // تخزين القيمة والموقع (1-based)
    }

    // 1. فرز المصفوفة حسب القيمة
    sort(a.begin(), a.end());

    // 2. تثبيت عنصرين والبحث الثنائي عن الثالث
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            long long need = x - a[i].first - a[j].first;
            
            // نبدأ البحث الثنائي بعد العنصر j مباشرة لضمان عدم التكرار
            int lo = j + 1, hi = n - 1;
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                
                if (a[mid].first == need) {
                    // وجدنا الثلاثية المطلوبة! نطبع مواقعهم الأصلية
                    cout << a[i].second << " " 
                         << a[j].second << " " 
                         << a[mid].second << "\n";
                    return 0;
                } else if (a[mid].first < need) {
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
        }
    }

    cout << "IMPOSSIBLE\n";
    return 0;
}
⚠️ انتبه لنوع المتغيرات: استخدمنا long long للقيمة x ولعناصر المصفوفة، لأن مجموع 3 أرقام قد يتخطى سعة المتغير العادي int!

📝 وصف المسألة: Product of Three Values (حاصل ضرب 3 قيم)

لنختبر فهمك للخوارزمية السابقة! يُعطى لك مصفوفة من n أعداد صحيحة موجبة، ومهمتك هي إيجاد ثلاث قيم في مواقع مختلفة يكون حاصل ضربها يساوي x.

الإدخال:
- السطر الأول: عددان صحيحان n و x (حاصل الضرب المطلوب).
- السطر الثاني: n من الأعداد الصحيحة الموجبة.

المخرجات:
- إمّا ثلاثة مواقع (مرقمة من 1) بحيث يكون حاصل ضرب قيمها يساوي x.
- أو IMPOSSIBLE إذا لم يوجد.

مثال:
الإدخال: 4 30
المصفوفة: 10 2 5 3
المخرجات: 1 4 2 (لأن 10 × 3 × 2 = 60.. عذراً، نحتاج 30. إذن 2 × 5 × 3 = 30. الحل هو العناصر: 2، 3، 4)

نفس الخطة.. مع تعديل رياضي بسيط 🧠

سنستخدم نفس استراتيجية المسألة الأولى تماماً: (ترتيب + تثبيت عنصرين + بحث ثنائي).

لكن ما هو الرقم الذي سنبحث عنه (need)؟
في الجمع كنا نقول: $need = x - (a + b)$.
في الضرب سنقول: $need = x / (a \times b)$.

شرط مهم جداً قبل البحث:
لا يمكننا البحث عن (need) إلا إذا كان الهدف $x$ يقبل القسمة تماماً على $(a \times b)$ بدون باقٍ!
لذلك قبل أن نُشغل البحث الثنائي، نتحقق: if (x % (a * b) == 0)، وإذا تحقق الشرط نبحث عن x / (a * b).

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    long long x;
    cin >> n >> x;

    vector<pair<long long, int>> a(n);
    for (int i = 0; i < n; ++i) {
        long long v;
        cin >> v;
        a[i] = {v, i + 1};
    }

    sort(a.begin(), a.end());

    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            long long prod = a[i].first * a[j].first;
            
            // التأكد من أن حاصل الضرب لا يساوي صفر لتجنب القسمة على صفر
            // والتأكد من أن X يقبل القسمة على حاصل ضرب الرقمين الأولين
            if (prod != 0 && x % prod == 0) {
                long long need = x / prod;
                
                int lo = j + 1, hi = n - 1;
                while (lo <= hi) {
                    int mid = (lo + hi) / 2;
                    
                    if (a[mid].first == need) {
                        cout << a[i].second << " " 
                             << a[j].second << " " 
                             << a[mid].second << "\n";
                        return 0;
                    } else if (a[mid].first < need) {
                        lo = mid + 1;
                    } else {
                        hi = mid - 1;
                    }
                }
            }
        }
    }

    cout << "IMPOSSIBLE\n";
    return 0;
}
