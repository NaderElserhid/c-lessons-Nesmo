مسألة: Domino Piling (Codeforces - Easy)

وصف المسألة

توجد مصفوفة (شبكة) ثنائية الأبعاد مكوّنة من M صف و N عمود. لديك عدد غير محدود من قطع الدومينو ذات الحجم 2 × 1، وتريد وضع أكبر عدد ممكن من هذه القطع في المصفوفة بحيث:

  • كل قطعة تغطي خانتين كاملتين.
  • لا تتقاطع أي من القطع مع بعضها البعض.
  • يجب أن تكون جميع القطع داخل المصفوفة تماماً.

الرسم التفاعلي للحل

أدخل عدد الصفوف والأعمدة لتشاهد كيف يتم ترتيب قطع الدومينو خوارزمياً!

تحليل الحل (كما شرحته)

في هذه المسألة لدينا 3 حالات رئيسية. لنحللها:

  1. إذا كان عدد الصفوف N زوجياً (N % 2 == 0):
    يمكننا تغطية المصفوفة كاملة بوضع القطع بشكل عمودي. عدد القطع المستخدمة سيكون (N * M) / 2 لأن المصفوفة تحتوي على N×M خانة وكل قطعة تغطي خانتين.
  2. إذا كان عدد الأعمدة M زوجياً (M % 2 == 0):
    يمكننا تغطية المصفوفة كاملة بوضع القطع بشكل أفقي. عدد القطع سيكون (N * M) / 2.
  3. إذا كان كلاً من N و M أعداداً فردية:
    أولًا، نضع القطع بشكل عمودي ابتداءً من الصف الأول، مما يترك صفًا كاملًا غير مغطى (لأن عدد الصفوف فردي). في ذلك الصف نضع القطع بشكل أفقي، فتتبقى خانة واحدة فقط (الزاوية) غير مغطاة. بالتالي عدد القطع المستخدمة سيكون (N * M - 1) / 2.

كود C++

#include <iostream>
using namespace std;

int main() {
    int N, M;
    cin >> N >> M;

    if (N % 2 == 0) {
        cout << (N * M) / 2 << endl;
    }
    else if (M % 2 == 0) {
        cout << (N * M) / 2 << endl;
    }
    else {
        cout << (N * M - 1) / 2 << endl;
    }
    
    return 0;
}

ملاحظة جانبية لطلابك: بما أن القسمة في لغة C++ للأعداد الصحيحة (Integer Division) تتجاهل الباقي تلقائياً، فإن كتابة cout << (M * N) / 2; مباشرة دون شروط ستعطي نفس النتيجة الصحيحة في جميع الحالات!
