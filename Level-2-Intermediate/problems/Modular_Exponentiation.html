مسألة: Modular Exponentiation (Codeforces - Easy)

وصف المسألة

لديك رقمان n و m. المطلوب هو طباعة ناتج العملية الحسابية: m % 2n

ملحوظة هامة: بالنسبة لأي رقمين x و y، إذا كان y > x فإن x % y == x.

الرسم التفاعلي للحل (المحاكاة خطوة بخطوة)

أدخل قيمتي n و m لترى كيف يتضاعف الرقم power وكيف تعمل خوارزمية الإيقاف المبكر (Early Exit) لحماية البرنامج من تجاوز سعة المتغير (Overflow).

تحليل الحل

يمكن أن تؤدي عملية حساب 2n مباشرة إلى تجاوز حدود النوع int. لتجنب ذلك:

  • نستخدم متغيراً power بقيمة مبدئية تساوي 1 ونضربه في 2 بشكل متكرر في حلقة تتكرر n مرة.
  • أثناء كل تكرار، إذا أصبح power أكبر من m، نستنتج فوراً أن الناتج يجب أن يكون m (استناداً للملحوظة)، ونخرج من الحلقة بـ break.
  • إذا اكتملت الحلقة دون أن يتجاوز power قيمة m، فهذا يعني أنه لم يحصل تجاوز لحدود النوع int، ويمكننا حساب الناتج ببساطة كـ m % power.

كود C++

#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    
    int power = 1;
    for (int i = 0; i < n; i++) {
        power *= 2;
        if (power > m) {
            cout << m << endl;
            break;
        }
    }
    
    if (power <= m) {
        cout << m % power << endl;
    }
    
    return 0;
}
