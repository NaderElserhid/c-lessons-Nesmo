العمل على الحالات (Case Work)

فن تفكيك المشاكل المعقدة إلى أجزاء بسيطة للسيطرة عليها
📖 مقدمة من الواقع:
تخيل أنك تعمل مبرمجاً في شركة شحن بضائع، وطُلب منك كتابة برنامج يحسب تكلفة الشحن بناءً على وزن الطرد. لا توجد "معادلة سحرية واحدة" تناسب كل الأوزان! بل ستلجأ إلى تقسيم المشكلة لحالات:

1️⃣ الحالة الأولى: إذا كان الوزن أقل من 1 كغ ⬅️ التكلفة 5 دولارات.
2️⃣ الحالة الثانية: إذا كان الوزن بين 1 و 5 كغ ⬅️ التكلفة 10 دولارات.
3️⃣ الحالة الثالثة: إذا كان الوزن أكبر من 5 كغ ⬅️ التكلفة 20 دولاراً.

أنت هنا لم تخترع خوارزمية معقدة، بل قمت بتطبيق مبدأ (العمل على الحالات - Case Work)، وهذا بالضبط ما سنفعله في البرمجة التنافسية!

ما هو "العمل على الحالات"؟

في العديد من المسائل، قد ترهق نفسك في محاولة إيجاد "معادلة رياضية واحدة" أو "حلقة تكرارية واحدة" تحل المشكلة بالكامل. في مسائل (Case Work)، تلاحظ أن المواقف المختلفة تتصرف بقواعد مختلفة.

لذا، بدلاً من قاعدة عامة معقدة، نقوم بالآتي:

  • إذا حدثت الحالة A، نفذ الكود الخاص بها.
  • إذا حدثت الحالة B، نفذ الكود الخاص بها.
  • وهكذا مع الحالة C، و D، إلخ.

ثم في النهاية، إما نجمع إجابات كل الحالات معاً، أو نختار الأفضل بينها (مثلاً القيمة الأكبر أو الأصغر).

لماذا نستخدم هذا الأسلوب؟

  • يسمح بالتعامل مع الحالات الخاصة (Edge Cases) بوضوح تام دون تشويش الكود الأساسي.
  • يُقسم المشكلة الصعبة والضخمة إلى أجزاء صغيرة سهلة الفهم والبرمجة.
  • شائع جداً في مسائل "العد" (Combinatorics) أو المسائل ذات النتائج الهندسية المتعددة.

مثال 1: المجموع الزوجي (Even or Odd Sum)

لديك عددان $a$ و $b$. يُطلب منك حساب عدد الأزواج الممكنة $(x, y)$ بحيث يكون $x \le a$ و $y \le b$، ويكون المجموع $(x + y)$ عدداً زوجياً. (بافتراض أن الأرقام تبدأ من 1).

💡 تحليل رياضي: متى يكون مجموع رقمين عدداً زوجياً؟
الحالة 1: (زوجي + زوجي = زوجي) ⬅️ مثل $2 + 4 = 6$
الحالة 2: (فردي + فردي = زوجي) ⬅️ مثل $3 + 5 = 8$
إذن، لإيجاد عدد الأزواج، سنقوم بحساب الأزواج من (الحالة 1) والأزواج من (الحالة 2) ونجمعهما معاً! 
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    
    // حساب عدد الأرقام الزوجية والفردية حتى الرقم a
    int evenA = a / 2;
    int oddA = a - evenA;
    
    // حساب عدد الأرقام الزوجية والفردية حتى الرقم b
    int evenB = b / 2;
    int oddB = b - evenB;
    
    // الحالة 1 (زوجي مع زوجي) + الحالة 2 (فردي مع فردي)
    int pairs = (evenA * evenB) + (oddA * oddB);
    
    cout << pairs << endl;
    return 0;
}

كيف يعمل الكود؟

لمعرفة كم عدداً زوجياً يوجد من 1 إلى $a$، ببساطة نقسم $a$ على 2. (مثال: إذا كان $a = 5$، إذن $5/2 = 2$، وهما الرقمان 2 و 4).
ولمعرفة الأعداد الفردية، نطرح الأعداد الزوجية من العدد الكلي $a$.
في النهاية، نضرب احتمالات الزوجي ببعضها، واحتمالات الفردي ببعضها، ونجمعهما ليعطينا إجمالي الأزواج الصحيحة. هذا هو العمل على الحالات بأبهى صوره!

مثال 2: صلاحية المثلث (Triangle Validity)

مُعطى لك ثلاثة أطوال أضلاع $a, b, c$. حدد إن كانت هذه الأضلاع قادرة على تشكيل مثلث حقيقي أم لا.

[Image of triangle inequality theorem geometry]
💡 تحليل رياضي (متباينة المثلث): لكي تتشكل أضلاع مثلث، يجب أن يكون مجموع أي ضلعين أكبر تماماً من الضلع الثالث. أي يجب أن تتحقق الحالات الثلاث معاً:
$a + b > c$
$a + c > b$
$b + c > a$ 
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    
    // نعتبر مبدئياً أن المثلث صالح (نظام العلم / Flag)
    bool ok = true;
    
    // نتحقق من الحالات المعاكسة (إذا فشل أي شرط، نُسقط العلم)
    if (b + c <= a) ok = false;
    if (a + c <= b) ok = false;
    if (a + b <= c) ok = false;
    
    // طباعة النتيجة بناءً على حالة العلم النهائية
    cout << (ok ? "YES" : "NO") << endl;
    
    return 0;
}

كيف يعمل الكود؟ (نمط العلم - Flag Pattern)

بدلاً من كتابة شرط if طويل ومعقد يحتوي على (AND &&) كثيرة، قمنا بإنشاء متغير منطقي ok وافترضنا أن الإجابة صحيحة. ثم فحصنا الحالات بشكل مستقل.
استخدمنا <= لأنه إذا كان مجموع ضلعين أصغر من أو يساوي الضلع الثالث، فالمثلث سيفشل وينهار. إذا سقطت أي حالة، نجعل العلم false.

مثال 3: تحديد أرباع الإحداثيات (Coordinate Quadrant)

مُعطى لك نقطة بإحداثيات $(x, y)$ على المستوى الديكارتي. اطبع في أي "ربع" (Quadrant) تقع هذه النقطة.

💡 تحليل رياضي: المستوى الديكارتي مقسم إلى 4 حالات (أرباع)، وحالة خامسة خاصة:
الربع الأول: $x$ موجب، $y$ موجب.
الربع الثاني: $x$ سالب، $y$ موجب.
الربع الثالث: $x$ سالب، $y$ سالب.
الربع الرابع: $x$ موجب، $y$ سالب.
الحالة الخاصة: إذا كان أحدهما 0، فالنقطة تقع على المحور نفسه. 
#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;
    
    // تفصيل الحالات بدقة باستخدام if و else if
    if (x > 0 && y > 0) {
        cout << "Quadrant I" << endl;
    } 
    else if (x < 0 && y > 0) {
        cout << "Quadrant II" << endl;
    } 
    else if (x < 0 && y < 0) {
        cout << "Quadrant III" << endl;
    } 
    else if (x > 0 && y < 0) {
        cout << "Quadrant IV" << endl;
    } 
    else {
        cout << "On an axis" << endl; // إذا كان x أو y يساوي صفراً
    }
    
    return 0;
}

كيف يعمل الكود؟

هذا هو التجسيد الحرفي لـ (العمل على الحالات). قمنا بوضع كل ربع في شرط مستقل وواضح لتجنب التداخل. استخدام else if يضمن أنه بمجرد العثور على الربع الصحيح، سيتجاهل البرنامج باقي الشروط ليوفر وقت المعالجة.

نصائح ذهبية للعمل على الحالات 🚀

  • امنع التداخل: تأكد أن حالاتك لا تتداخل (Mutually Exclusive). لا ينبغي أن ينطبق شرطان على نفس المدخل في نفس الوقت لتجنب النتائج الخاطئة.
  • لا تترك ثغرات: تأكد أن حالاتك تغطي جميع الاحتمالات الممكنة (Collectively Exhaustive).
  • احذر من الحالات الحدية (Edge Cases): في كثير من الأحيان ينسى الطلاب حالة الصفر (0) أو المساواة. دائماً اسأل نفسك: ماذا لو كان الإدخال صفراً؟
  • استخدم الورقة والقلم: قبل كتابة سطر كود واحد، ارسم خريطة ذهنية أو جدولاً لكل الحالات المحتملة لتتأكد من أن منطقك سليم.
🎯 خلاصة سريعة:
العمل على الحالات ليس "خوارزمية" أو كوداً يجب حفظه، بل هو أسلوب تفكير. وهو ممتاز جداً في بداية رحلتك في حل المشاكل. نصيحتنا لك: عندما تقرأ مسألة وتبدو لك معقدة أو ليس لها قاعدة واحدة ثابتة، اسأل نفسك فوراً: "ما هي الحالات الممكنة لهذه المسألة؟" وبذلك تكون قد خطوت خطوتك الأولى نحو الحل!
