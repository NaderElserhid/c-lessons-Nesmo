دليل الحسابيات المعيارية (Modular Arithmetic)

مقدمة: ما هي الحسابيات المعيارية؟

الحسابيات المعيارية (Modular Arithmetic) هي نظام حسابي للأعداد الصحيحة، حيث "تدور" الأعداد عند الوصول إلى قيمة معينة تسمى المعامل (Modulus). يُشار إلى هذه العملية غالباً باسم "حساب الساعات".

🕰️ تشبيه من الواقع:
فكر في ساعة الحائط. إذا كانت الساعة الآن 8 مساءً، وأضفنا 6 ساعات، فلن تكون الساعة 14، بل ستكون 2 صباحاً. هذا لأن الساعة "تدور" كل 12 ساعة. في لغة الرياضيات، نقول إن $8 + 6 \equiv 2 \pmod{12}$.

1. معنى "mod"

عندما نقول $a \mod m$، فإننا نعني باقي قسمة العدد $a$ على العدد $m$. النتيجة دائماً تكون عدداً صحيحاً في النطاق $[0, m-1]$.

أمثلة نظرية:

- $7 \pmod 3$: $7$ تقسيم $3$ يساوي $2$ والباقي $1$. النتيجة هي 1.
- $10 \pmod 4$: $10$ تقسيم $4$ يساوي $2$ والباقي $2$. النتيجة هي 2.
- $15 \pmod 6$: $15$ تقسيم $6$ يساوي $2$ والباقي $3$. النتيجة هي 3.
- $12 \pmod{12}$: $12$ تقسيم $12$ يساوي $1$ والباقي $0$. النتيجة هي 0.

في لغة C++:

نستخدم العامل % للحصول على باقي القسمة للأعداد الموجبة.

#include <iostream>
using namespace std;

int main() {
    cout << 7 % 3 << endl;   // سيطبع: 1
    cout << 10 % 4 << endl;  // سيطبع: 2
    cout << 10 % 5 << endl;  // سيطبع: 0
    return 0;
}
شرح الكود:
يقوم هذا الكود البسيط بطباعة باقي قسمة أعداد مختلفة. عامل % في C++ يعمل كعامل "mod" للأعداد الموجبة، معطياً القيمة المتبقية بعد عملية القسمة الصحيحة.

2. استخدام الحسابيات المعيارية في البرمجة التنافسية

عند التعامل مع مسائل تتطلب حساب التوافيق، التباديل، أو الأسس الكبيرة، غالباً ما تكون النتائج ضخمة جداً وتتجاوز سعة تخزين أنواع البيانات القياسية مثل long long، مما يؤدي إلى مشكلة تجاوز السعة (Overflow).

✅ الحل:
نقوم بإجراء جميع العمليات الحسابية تحت "مودولو" معين لإبقاء النتائج ضمن نطاق آمن وقابل للتخزين.

المعامل الشائع في البرمجة:

const int MOD = 1'000'000'007; // 10^9 + 7
لماذا هذا العدد بالذات؟
  • إنه عدد أولي كبير، مما يمنحه خصائص رياضية مفيدة جداً (خاصة عند حساب المعكوس المعياري).
  • إنه صغير بما يكفي ليسمح بضرب عددين تحت المودولو دون أن تتجاوز النتيجة سعة long long (التي تتحمل حتى $\approx 9 \times 10^{18}$).

3. القواعد الأساسية للحسابيات المعيارية

هذه القواعد هي حجر الزاوية في حل المسائل الحسابية الكبيرة:

أ) الجمع

$(a + b) \pmod m = ((a \pmod m) + (b \pmod m)) \pmod m$

ب) الطرح

$(a - b) \pmod m = ((a \pmod m - b \pmod m) + m) \pmod m$

نضيف $m$ قبل المودولو الأخير لضمان أن النتيجة لن تكون سالبة، لأن عامل % في C++ قد يعطي نتيجة سالبة إذا كان القاسم سالباً.

ج) الضرب

$(a \times b) \pmod m = ((a \pmod m) \times (b \pmod m)) \pmod m$

مثال برمجي شامل:

#include <iostream>
using namespace std;

int main() {
    long long a = 1e12; // عدد كبير
    long long b = 1e12; // عدد كبير آخر
    const int MOD = 1'000'000'007;

    long long sum_mod = (a % MOD + b % MOD) % MOD;
    long long prod_mod = ((a % MOD) * (b % MOD)) % MOD;

    cout << "الجمع تحت المودولو: " << sum_mod << endl;
    cout << "الضرب تحت المودولو: " << prod_mod << endl;

    return 0;
}
شرح الكود:
لدينا عددان كبيران جداً a و b. بدلاً من جمعهما مباشرة (الأمر الذي قد يسبب Overflow)، نقوم بأخذ مودولو لكل منهما أولاً، ثم جمعهما، ثم أخذ المودولو للناتج النهائي لضمان بقائه ضمن النطاق المطلوب. نفس الفكرة تُطبق على عملية الضرب.

4. التعامل مع الأعداد السالبة في C++

هذه مشكلة شائعة جداً! في C++، نتيجة (-5) % 3 هي -2، بينما في الرياضيات يجب أن تكون 1 (لأن $-5 = 3 \times (-2) + 1$).

✅ الحل البرمجي الصحيح:
للحصول على باقي قسمة موجب دائماً، نستخدم المعادلة التالية:
((a % m) + m) % m

مثال برمجي:

#include <iostream>
using namespace std;

int main() {
    int a = -5, m = 3;
    
    int wrong_mod = a % m; // سيطبع -2
    int correct_mod = ((a % m) + m) % m; // سيطبع 1
    
    cout << "النتيجة الخاطئة: " << wrong_mod << endl;
    cout << "النتيجة الصحيحة رياضياً: " << correct_mod << endl;

    return 0;
}
شرح الكود:
نقوم بحساب باقي القسمة بالطريقتين. المعادلة الصحيحة تضمن أنه حتى لو كان a % m سالباً، فإن إضافة m ستجعله موجباً، ثم المودولو الأخير يضمن بقاء النتيجة ضمن النطاق $[0, m-1]$.

5. الأسس المعيارية السريعة (Modular Exponentiation)

لحساب $(a^b) \pmod m$ حيث $b$ عدد ضخم جداً، لا يمكننا استخدام الضرب المتكرر البسيط لأنه سيكون بطيئاً جداً. نستخدم خوارزمية الأس السريع (Binary Exponentiation).

الفكرة الرياضية (T = $O(\log b)$):

نعتمد على التقسيم التكراري للأس $b$:

  • إذا كان $b$ زوجياً: $a^b = (a^{b/2})^2$
  • إذا كان $b$ فردياً: $a^b = (a^{b/2})^2 \times a$
  • حالة التوقف: إذا كان $b = 0$، فإن $a^0 = 1$.

الكود البرمجي (Recursive):

#include <iostream>
using namespace std;

long long modpow(long long a, long long b, long long m) {
    if (b == 0) return 1;
    
    long long half = modpow(a, b / 2, m); // احسب نصف الأس مرة واحدة فقط
    long long res = (half * half) % m;   // ضاعف النتيجة وخذ المودولو
    
    if (b % 2 == 1) // إذا كان الأس فردياً، اضرب في الأساس
        res = (res * (a % m)) % m;
        
    return res;
}

int main() {
    cout << modpow(2, 10, 1000); // سيطبع 24، لأن 1024 mod 1000 = 24
    return 0;
}
شرح الكود:
دالة modpow هي دالة تكرارية (Recursive). في كل خطوة، يتم تقسيم الأس b إلى النصف، مما يجعل عدد الاستدعاءات التكرارية هو $\log b$. هذا يضمن سرعة فائقة جداً. التعقيد الزمني لهذه الدالة هو $O(\log b)$.

6. المعكوس المعياري (Modular Inverse) والتحكم في القسمة

القسمة ليست مباشرة في الحسابيات المعيارية! لا يمكننا القول إن $(a/b) \pmod m = (a \pmod m / b \pmod m) \pmod m$. بدلاً من ذلك، نضرب في المعكوس المعياري للعدد $b$.

$(a / b) \pmod m = (a \times b^{-1}) \pmod m$

حيث $b^{-1}$ هو المعكوس المعياري للعدد $b$ تحت المودولو $m$.

كيف نحسب المعكوس المعياري؟

إذا كان $m$ عدداً أولياً (مثل $10^9+7$)، فإن نظرية فيرما الصغرى تنص على أن المعكوس المعياري لـ $b$ هو ببساطة $modpow(b, m-2, m)$.

مثال برمجي للقسمة:

#include <iostream>
using namespace std;

// دالة modpow السابقة يجب أن تكون موجودة هنا
long long modpow(long long a, long long b, long long m) {
    if (b == 0) return 1;
    long long half = modpow(a, b / 2, m);
    long long res = (half * half) % m;
    if (b % 2 == 1) res = (res * (a % m)) % m;
    return res;
}

int main() {
    const int MOD = 1'000'000'007;
    long long a = 100, b = 10;
    
    // نريد حساب (a / b) mod MOD
    long long b_inverse = modpow(b, MOD - 2, MOD);
    long long result = (a * b_inverse) % MOD;
    
    cout << "(100 / 10) mod MOD = " << result << endl; // سيطبع 10
    
    return 0;
}
شرح الكود:
لحساب $100/10$ تحت المودولو، لا نقسم مباشرة. بل نحسب أولاً المعكوس المعياري للـ 10 عن طريق رفعه للأس $MOD-2$ باستخدام دالة modpow السريعة. ثم نضرب الأساس 100 في هذا المعكوس ونأخذ المودولو للناتج النهائي.
