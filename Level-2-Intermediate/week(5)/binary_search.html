دليل خوارزميات البحث (Searching) في C++

مقدمة: ما هو البحث البرمجي؟

البحث هو عملية العثور على عنصر معين (Target) داخل مجموعة من البيانات (مثل مصفوفة أو قائمة). تختلف كفاءة البحث بناءً على الخوارزمية المستخدمة وحالة البيانات (هل هي مرتبة أم عشوائية؟). سنتعرف هنا على أشهر طريقتين للبحث.

1. البحث الخطي (Linear Search)

👕 تشبيه من الواقع:
تخيل أنك تبحث عن قميص معين في خزانة ملابس غير مرتبة تماماً. الطريقة الوحيدة للعثور عليه هي إخراج القمصان واحداً تلو الآخر وفحصها حتى تجد القميص المطلوب، أو تنهي الخزانة بأكملها وتتأكد أنه غير موجود.

الكود البرمجي (C++)

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {4, 8, 15, 16, 23, 42};
    int target = 15; // الرقم الذي نبحث عنه

    // حلقة للمرور على جميع العناصر من البداية للنهاية
    for (int i = 0; i < arr.size(); i++) {
        if (arr[i] == target) {
            cout << "Found at index " << i;
            return 0; // إنهاء البرنامج فور العثور على الرقم
        }
    }
    
    // إذا انتهت الحلقة ولم يجد الرقم
    cout << "Not found";
    return 0;
}
شرح تفصيلي للكود:
  • تهيئة البيانات: أنشأنا قائمة arr تحتوي على الأرقام، وحددنا الهدف target وهو 15.
  • حلقة البحث (Loop): استخدمنا for لتبدأ من أول عنصر (المؤشر 0) وتستمر حتى نهاية القائمة.
  • المقارنة: في كل خطوة نسأل: هل العنصر الحالي arr[i] يساوي الهدف؟
  • النجاح: إذا كان متساوياً، نطبع مكانه i ونستخدم return 0 لإيقاف البرنامج وتوفير الوقت (فلا داعي لإكمال البحث).
  • الفشل: إذا انتهت حلقة for بالكامل ولم يتوقف البرنامج، فهذا يعني أن الرقم غير موجود، لذلك نطبع "Not found".
⏱️ التعقيد الزمني (Time Complexity):
في أسوأ الحالات (الرقم غير موجود أو موجود في آخر خانة)، سنضطر للتحقق من كل عنصر. لذا التعقيد هو $O(n)$. يعمل دائماً، ولكنه بطيء جداً مع البيانات الضخمة (مليون عنصر = مليون خطوة).

2. البحث الثنائي (Binary Search)

⚠️ شرط ذهبي: خوارزمية البحث الثنائي لا تعمل أبداً إلا إذا كانت البيانات مرتبة مسبقاً (Sorted)!
📖 تشبيه من الواقع:
تخيل أنك تبحث عن كلمة "كمبيوتر" في قاموس ورقي ضخم (مرتب أبجدياً). أنت لن تقرأ القاموس صفحة بصفحة! بل ستفتحه من المنتصف تقريباً. إذا وجدت نفسك في حرف "م"، ستعرف فوراً أن حرف "ك" يقع في النصف الأول. ستقوم بتجاهل النصف الثاني بالكامل، ثم تفتح منتصف النصف الأول، وتستمر في استبعاد نصف الخيارات في كل خطوة حتى تجد الكلمة.

🎮 محاكي البحث الثنائي التفاعلي

اضغط على الزر بالأسفل لبدء البحث عن الرقم ( 7 ) في المصفوفة المرتبة.

الكود البرمجي (C++)

#include <iostream>
#include <vector>
using namespace std;

int main() {
    // يجب أن تكون المصفوفة مرتبة!
    vector<int> arr = {1, 3, 5, 6, 7, 9, 11};
    int target = 7;
    
    int left = 0;                  // بداية النطاق
    int right = arr.size() - 1;    // نهاية النطاق

    // طالما أن نطاق البحث لا يزال منطقياً
    while (left <= right) {
        // حساب المنتصف بطريقة آمنة
        int mid = left + (right - left) / 2; 

        if (arr[mid] == target) {
            cout << "Found at index " << mid;
            return 0; // وجدناه، ننهي البرنامج
        } 
        else if (arr[mid] < target) {
            // الرقم في المنتصف أصغر من الهدف، إذن الهدف في النصف الأيمن
            left = mid + 1;
        } 
        else {
            // الرقم في المنتصف أكبر من الهدف، إذن الهدف في النصف الأيسر
            right = mid - 1;
        }
    }
    
    cout << "Not found";
    return 0;
}
شرح تفصيلي للكود:
  • تحديد النطاق (Pointers): استخدمنا left ليؤشر على بداية المصفوفة، و right ليؤشر على نهايتها.
  • حلقة البحث: while (left <= right) تعني استمر في القطع للنصف طالما أن المؤشرين لم يتقاطعا (أي لا يزال هناك عناصر للبحث فيها).
  • المنتصف: mid هو المؤشر الذي يقع في منتصف النطاق الحالي.
  • المقارنات الثلاث الذكية:
    • إذا كان الرقم في المنتصف هو الهدف: رائع، اطبع مكانه وأنهِ البرنامج.
    • إذا كان الرقم في المنتصف أصغر من الهدف: نتجاهل النصف الأيسر بالكامل، وننقل نقطة البداية left إلى ما بعد المنتصف mid + 1.
    • إذا كان الرقم في المنتصف أكبر من الهدف: نتجاهل النصف الأيمن بالكامل، وننقل نقطة النهاية right إلى ما قبل المنتصف mid - 1.
⏱️ التعقيد الزمني (Time Complexity):
بما أننا نحذف نصف البيانات المتبقية في كل خطوة، فالتعقيد هو $O(\log n)$. هذا سريع بشكل لا يصدق! لو كان لديك مليون عنصر، ستحتاج إلى 20 محاولة كحد أقصى لإيجاد الرقم.

3. نصائح ومعلومات احترافية (Pro Tips) 🔥

أ) تجنب مشكلة تجاوز السعة (Integer Overflow)

في العديد من الشروحات القديمة، ستجد حساب المنتصف يُكتب هكذا: mid = (left + right) / 2;. هذا يعمل جيداً للمصفوفات الصغيرة. لكن في المسابقات البرمجية، إذا كانت المصفوفة ضخمة جداً، فإن جمع left + right قد يتجاوز الحد الأقصى المسموح به للمتغير int، مما يسبب خطأ رياضياً وانهياراً للبرنامج!

✅ الحل الاحترافي: احسب المنتصف دائماً باستخدام هذه المعادلة الآمنة:
int mid = left + (right - left) / 2;

ب) استخدام الدالة الجاهزة المدمجة

في لغة C++، لست مضطراً دائماً لكتابة خوارزمية البحث الثنائي من الصفر. توفر مكتبة <algorithm> دالة سريعة جداً:

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    vector<int> arr = {1, 3, 5, 7, 9};
    
    // ترجع true إذا كان الرقم موجوداً، و false إذا لم يكن
    bool isFound = binary_search(arr.begin(), arr.end(), 7);
    
    if(isFound) cout << "موجود!";
    else cout << "غير موجود!";
    
    return 0;
}

4. البحث الثنائي المتقدم: إيجاد أول عنصر $\ge X$ (Lower Bound)

البحث الثنائي يمكنه فعل أكثر من مجرد إيجاد رقم متطابق! يمكن استخدامه لإيجاد مواضع أو حدود (Bounds).

👟 تشبيه من الواقع:
تخيل أنك ذهبت لشراء حذاء رياضي ومقاسك هو 7. إذا أخبرك البائع أن مقاس 7 غير متوفر، فإنك ستبحث عن أول مقاس أكبر من أو يساوي 7 (مثلاً 8) لكي يناسبك، ولن تشتري مقاس 10 لأنه سيكون كبيراً جداً! هذا بالضبط ما تفعله هذه الخوارزمية.

تحدي المواقع (Position Hunt)

لديك مصفوفة مرتبة [2, 4, 6, 8, 10]. اعثر على أول عنصر أكبر من أو يساوي 7 باستخدام البحث الثنائي.

الكود البرمجي (C++)

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {2, 4, 6, 8, 10};
    int x = 7;
    
    int left = 0, right = arr.size() - 1;
    int ans = -1; // متغير لحفظ الإجابة المؤقتة

    while (left <= right) {
        // حساب آمن للمنتصف
        int mid = left + (right - left) / 2; 

        if (arr[mid] >= x) {
            ans = mid;         // ربما تكون هذه هي الإجابة، نحفظها
            right = mid - 1;   // لكن نستمر بالبحث في اليسار لعلنا نجد رقماً أصغر يحقق الشرط
        } else {
            left = mid + 1;    // الرقم أصغر من المطلوب، نبحث في اليمين
        }
    }

    if (ans == -1) 
        cout << "No element found";
    else 
        cout << "First element >= " << x << " is at index " << ans;
        
    return 0;
}
كيف تعمل الخوارزمية (الخطوات):
  • نبدأ بمؤشرين left و right كالمعتاد، ونستخدم متغيراً إضافياً ans لحفظ أفضل إجابة نجدها (نبدأه بـ -1 كدلالة على عدم وجود إجابة بعد).
  • نحسب منتصف النطاق mid.
  • السر هنا: إذا كانت القيمة arr[mid] >= x (مثلاً وجدنا 8 وهي أكبر من 7)، نقوم بحفظ موقعها ans = mid. ولكننا لا نتوقف! بل ننقل right = mid - 1 لنبحث في النصف الأيسر لعلنا نجد رقماً أقرب للـ 7 (مثل 7 نفسها إن وُجدت).
  • إذا كانت القيمة صغيرة جداً arr[mid] < x، نحرك left = mid + 1.
  • نكرر العملية حتى يتقاطع المؤشران ويصبح left > right. النتيجة النهائية ستكون محفوظة في ans (وهي الخانة 3، التي تحتوي على الرقم 8).
💡 ملاحظة احترافية: هذه الخوارزمية مشهورة جداً في لغة C++ ولها دالة مدمجة جاهزة وقوية جداً تسمى lower_bound تؤدي نفس الغرض تماماً.
