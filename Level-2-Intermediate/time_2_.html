أمثلة تفاعلية: التعقيد الزمني (Time Complexity)

1. جدول تذكيري بالرموز (Notations)

الرمز (Big O) الاسم (بالعربية) الاسم (بالإنجليزية) الوصف المبسط
$O(1)$ وقت ثابت Constant سريع جداً، لا يتأثر بحجم المدخلات (مثال: عملية حسابية بسيطة).
$O(\log n)$ لوغاريتمي Logarithmic كل خطوة تقلل حجم المشكلة للنصف (مثال: القسمة على 2).
$O(\sqrt{n})$ جذر خطي Square Root ينمو بشكل بطيء نسبياً (مثال: حلقة تتوقف عند $i \times i \le n$).
$O(n)$ وقت خطي Linear الوقت ينمو بشكل مباشر ومتساوٍ مع حجم $n$ (مثال: حلقة واحدة).
$O(n \log n)$ شبه خطي Linearithmic شائع في خوارزميات الترتيب السريعة (Merge Sort).
$O(n^2)$ تربيعي Quadratic حلقات متداخلة، ينمو الوقت بسرعة كبيرة ويصبح بطيئاً.

2. ترتيب السرعة (من الأسرع إلى الأبطأ)

تذكر دائماً هذا الترتيب، فكلما اتجهنا لليسار كانت الخوارزمية أبطأ والتعقيد أسوأ:

$O(1) < O(\log n) < O(\sqrt{n}) < O(n) < O(n \log n) < O(n^2) < O(2^n) < O(n!)$

التطبيقات التفاعلية

اقرأ الكود الأسود، فكر في الحل، ثم اضغط على "عرض الحل" لتظهر لك خطوات التحليل باللون الأحمر (كما في الصورة التوضيحية التالية).

مثال 1: الحلقة الأساسية سهل 
for(int i = 0; i < n; i++) {  // -> n
    cout << "Hello";          // -> 1
}

التحليل: حلقة واحدة تمر $n$ مرة، وداخلها عملية ثابتة.
التعقيد النهائي: $O(n)$
مثال 2: حلقتان منفصلتان سهل 
for(int i = 0; i < n; i++) {  // -> n
    cout << i;
}
for(int j = 0; j < n; j++) {  // -> n
    cout << j;
}

التحليل: العمليات هنا متتالية (جمع) وليست متداخلة (ضرب). إذن: $n + n = 2n$
التعقيد النهائي (بعد تجاهل الثوابت): $O(n)$
مثال 3: القفز الثابت سهل 
for(int i = 0; i < n; i += 5) {  // -> n/5
    cout << i;                   // -> 1
}

التحليل: الحلقة تزيد بمقدار 5 كل مرة، لذا ستعمل $\frac{n}{5}$ مرة.
التعقيد النهائي (تجاهل القسمة على 5): $O(n)$
مثال 4: الحلقات المتداخلة متوسط 
for(int i = 0; i < n; i++) {        // -> n
    for(int j = 0; j < n; j++) {    // -> n
        cout << "*";
    }
}

التحليل: حلقة داخلية تنفذ $n$ مرة، مكررة $n$ مرة بسبب الحلقة الخارجية. إذن: $n \times n$
التعقيد النهائي: $O(n^2)$
مثال 5: التضاعف (الضرب في 2) متوسط 
for(int i = 1; i < n; i *= 2) {   // -> log(n)
    cout << i;
}

التحليل: قيمة $i$ تتضاعف (1, 2, 4, 8, 16...). نصل إلى $n$ بعد $\log_2 n$ خطوة.
التعقيد النهائي: $O(\log n)$
مثال 6: تقليص النصف (القسمة على 2) متوسط 
for(int i = n; i > 0; i /= 2) {   // -> log(n)
    cout << i;
}

التحليل: تماماً مثل الضرب، كل خطوة نقلل المشكلة للنصف (n, n/2, n/4...).
التعقيد النهائي: $O(\log n)$
مثال 7: المتداخل الخطي واللوغاريتمي متوسط 
for(int i = 0; i < n; i++) {            // -> n
    for(int j = 1; j < n; j *= 2) {     // -> log(n)
        cout << i + j;
    }
}

التحليل: الخارجي $n$ والداخلي $\log n$. نضربهم لأنهم متداخلان.
التعقيد النهائي: $O(n \log n)$
مثال 8: متغيران مختلفان متوسط 
for(int i = 0; i < n; i++) {        // -> n
    for(int j = 0; j < m; j++) {    // -> m
        cout << "*";
    }
}

التحليل: الحلقة الداخلية تعتمد على متغير $m$ مختلف عن $n$.
التعقيد النهائي: $O(n \times m)$
مثال 9: الثلاثي المتداخل متوسط 
for(int i = 0; i < n; i++) {            // -> n
    for(int j = 0; j < n; j++) {        // -> n
        for(int k = 0; k < n; k++) {    // -> n
            cout << "*";
        }
    }
}

التحليل: $n \times n \times n$
التعقيد النهائي: $O(n^3)$
مثال 10: حلقة داخلية بثابت متوسط 
for(int i = 0; i < n; i++) {          // -> n
    for(int j = 0; j < 100; j++) {    // -> 100 (ثابت)
        cout << "*";
    }
}

التحليل: الحلقة الداخلية تدور 100 مرة دائماً، هذا مجرد ثابت! إذن $100 \times n$
التعقيد النهائي (تجاهل الثابت 100): $O(n)$

تحديات متقدمة (صعبة) 🔥

مثال 11: التطبيق من الصورة صعب 
for(int i = n/2; i < n; i++)          // -> n/2
    for(int k = 1; k < n; k *= 2)     // -> log(n)
        for(int j = 1; j < n; j *= 2) // -> log(n)
            print i + k + j;


التحليل (كما في الصورة تماماً):
نضرب التعقيدات: $n/2 \times \log n \times \log n$
نتجاهل الثابت (النصف) فتصبح: $n \times \log n \times \log n$
التعقيد النهائي: $O(n \log^2 n)$
مثال 12: الحلقات المعتمدة على بعضها صعب 
for(int i = 0; i < n; i++) {          // -> n
    for(int j = i; j < n; j++) {      // -> (n-i) مرة في كل دورة
        cout << "*";
    }
}

التحليل: الحلقة الداخلية لا تدور $n$ مرة كاملة، بل تبدأ من $i$. 
المرات هي: $n + (n-1) + (n-2) + ... + 1$
هذا تسلسل حسابي ومجموعه هو $\frac{n(n+1)}{2} = \frac{n^2 + n}{2}$
التعقيد النهائي (بأخذ أعلى أس): $O(n^2)$
مثال 13: الجذر التربيعي صعب 
for(int i = 1; i * i <= n; i++) {   // -> sqrt(n)
    cout << i;
}

التحليل: الحلقة تستمر طالما أن $i^2 \le n$. 
هذا يعني أنها تتوقف عندما تصل $i$ إلى $\sqrt{n}$.
التعقيد النهائي: $O(\sqrt{n})$
مثال 14: الخداع اللوغاريتمي صعب جداً 
for(int i = 1; i <= n; i *= 2) {      // -> log(n) (خارجياً)
    for(int j = 1; j <= i; j++) {     // -> i مرة
        cout << "*";
    }
}

التحليل: قد تظن أنه $O(n \log n)$ لكن انتبه! الداخلي يعمل $i$ مرة.
قيم $i$ تتضاعف: $1 + 2 + 4 + 8 + ... + n$
مجموع هذه المتسلسلة الهندسية يقارب $2n$.
التعقيد النهائي (مفاجأة!): $O(n)$
مثال 15: المتسلسلة الأُسية صعب جداً 
for(int i = 2; i <= n; i = i * i) {   // -> log(log(n))
    cout << i;
}

التحليل: قيمة $i$ تتربع في كل خطوة (2, 4, 16, 256, 65536...).
هذا نمو أسّي جبار، وعدد الخطوات للوصول إلى $n$ صغير جداً بشكل لا يصدق.
التعقيد النهائي: $O(\log \log n)$
