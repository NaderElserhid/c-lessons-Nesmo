🏆 تحديات الخوارزميات الجشعة (مستوى متوسط)

في هذه المسائل، سنستخدم قاعدة "الفرز ثم الاختيار" (Sort & Select). تذكر دائماً: ابحث عن أفضل خيار ممكن في اللحظة الحالية دون القلق بشأن المستقبل!

🍪 المسألة الأولى: توزيع البسكويت (Assign Cookies)

لديك مصفوفة تمثل "مستوى الجوع" لمجموعة من الأطفال، ومصفوفة أخرى تمثل "أحجام قطع البسكويت" المتاحة.
الطفل سيشبع فقط إذا أعطيته قطعة بسكويت حجمها أكبر من أو يساوي مستوى جوعه. (يُسمح بإعطاء قطعة بسكويت واحدة كحد أقصى لكل طفل).
المطلوب: ما هو أكبر عدد من الأطفال الذين يمكنك إشباعهم؟
💡 الفكرة الجشعة: رتّب مصفوفة الأطفال ومصفوفة البسكويت تصاعدياً. ابدأ بأقل طفل جوعاً، وابحث عن أصغر قطعة بسكويت تكفيه. لماذا نعطيه أصغر قطعة؟ لكي نحتفظ بالقطع الكبيرة للأطفال الأكثر جوعاً لاحقاً!
الأطفال (الجوع) [1, 2, 3]
➕
البسكويت (الحجم) [1, 1]
➡️
طفل واحد فقط سيشبع الطفل (1) يأخذ البسكويتة (1)
Input:
Children = [1, 2, 3]
Cookies = [1, 1]
Output:
1 
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> children = {1, 2, 3};
    vector<int> cookies = {1, 1};
    
    // 1. ترتيب المصفوفات تصاعدياً
    sort(children.begin(), children.end());
    sort(cookies.begin(), cookies.end());
    
    int child_i = 0; // مؤشر للأطفال
    int cookie_j = 0; // مؤشر للبسكويت
    
    // 2. المرور الجشع (Two Pointers)
    while (child_i < children.size() && cookie_j < cookies.size()) {
        // إذا كانت البسكويتة تكفي الطفل الحالي
        if (cookies[cookie_j] >= children[child_i]) {
            child_i++; // الطفل شبع، ننتقل للطفل التالي
        }
        // في كل الأحوال ننتقل للبسكويتة التالية (سواء استخدمناها أو كانت صغيرة جداً)
        cookie_j++; 
    }
    
    // عدد الأطفال الذين شبعوا هو المؤشر الذي وصلوا إليه
    cout << "Max Happy Children: " << child_i << endl;
    return 0;
}

🛶 المسألة الثانية: قوارب النجاة (Boats to Save People)

هناك سفينة تغرق، ولديك مصفوفة تمثل "أوزان الأشخاص". هناك عدد غير محدود من قوارب النجاة، ولكن كل قارب يتحمل وزناً أقصى W، ويتسع لـ شخصين كحد أقصى في نفس الوقت.
المطلوب: ما هو أقل عدد من القوارب تحتاجه لإنقاذ جميع الأشخاص؟ (بافتراض أن وزن أي شخص لا يتجاوز W).
💡 الفكرة الجشعة: رتب الأوزان تصاعدياً. لتقليل عدد القوارب، يجب أن نملأ القارب بأكبر قدر ممكن. القاعدة الجشعة هي: حاول دائماً أن تضع الشخص الأخف مع الشخص الأثقل في نفس القارب. إذا كان وزنهما أكبر من الحد، فالشخص الأثقل سيركب في قارب بمفرده حتماً!
الأوزان [3, 2, 2, 1] الحد الأقصى للقارب = 3
➡️ ترتيب: [1, 2, 2, 3] ➡️
القوارب المطلوبة: 3 قارب1: [3] | قارب2: [2, 1] | قارب3: [2]
Input:
Weights = [3, 2, 2, 1]
Limit = 3
Output:
3 
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> people = {3, 2, 2, 1};
    int limit = 3;
    
    // 1. ترتيب الأوزان تصاعدياً
    sort(people.begin(), people.end());
    
    // 2. استخدام مؤشرين (Two Pointers): واحد للأخف وواحد للأثقل
    int left = 0;
    int right = people.size() - 1;
    int boats = 0;
    
    while (left <= right) {
        // هل يمكن أن يركب الأخف مع الأثقل في قارب واحد؟
        if (people[left] + people[right] <= limit) {
            left++;  // نعم، الأخف ركب بأمان، ننتقل للأخف الذي يليه
        }
        
        // في جميع الأحوال، الأثقل سيركب القارب (إما مع الأخف أو بمفرده)
        right--; 
        boats++; // استهلكنا قارباً واحداً
    }
    
    cout << "Minimum Boats: " << boats << endl;
    return 0;
}
