دليل خوارزميات الترتيب (Sorting) في C++

مقدمة نظرية: ما هو الترتيب ولماذا هو مهم؟

الترتيب (Sorting) هو عملية تنظيم مجموعة من العناصر في تسلسل محدد مسبقًا. غالباً ما يكون هذا التسلسل تصاعدياً (من الأصغر للأكبر) أو تنازلياً، وإذا كانت العناصر نصوصاً فيتم ترتيبها أبجدياً.

💡 لماذا نرتب البيانات؟
الترتيب يجعل البيانات أسهل للبحث والمقارنة والمعالجة بكفاءة. على سبيل المثال، خوارزمية البحث السريعة جداً مثل البحث الثنائي (Binary Search) لا يمكن أن تعمل إطلاقاً إلا إذا كانت البيانات مرتبة مسبقاً.

1. ترتيب الاختيار (Selection Sort)

هذه الخوارزمية هي واحدة من أبسط طرق الترتيب فهماً. تعتمد فكرتها على تقسيم المصفوفة ذهنياً إلى جزأين: جزء مرتب (في البداية يكون فارغاً) وجزء غير مرتب.

كيف تعمل خطوة بخطوة؟

  1. البحث عن أصغر عنصر في الجزء غير المرتب من المصفوفة.
  2. تبديل هذا العنصر الصغير مع أول عنصر في الجزء غير المرتب.
  3. الآن أصبح العنصر الأول في مكانه الصحيح (مرتب). ننتقل للعنصر الثاني ونكرر العملية.
  4. تستمر العملية حتى يتم ترتيب جميع العناصر.

مثال توضيحي

لنفترض أن لدينا المصفوفة التالية: [5, 8, 3, 4, 2]

  • نجد أصغر عنصر وهو 2. نقوم بتبديله مع أول عنصر 5. تصبح: [2, 8, 3, 4, 5]
  • الآن نتجاهل العنصر الأول. نبحث عن الأصغر في الباقي ونجده 3. نبدله مع العنصر الثاني 8. تصبح: [2, 3, 8, 4, 5]
  • نبحث عن الأصغر في الباقي ونجده 4. نبدله مع العنصر الثالث 8. تصبح: [2, 3, 4, 8, 5]
  • أخيراً، نجد الأصغر بين المتبقي وهو 5. نبدله مع 8. تصبح المصفوفة مرتبة: [2, 3, 4, 5, 8]

تنفيذ الترتيب بالاختيار (C++ Code)

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {5, 8, 3, 4, 2};
    int n = arr.size();
    
    // الحلقة الخارجية تمر على كل المواقع
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i; // نفترض أن العنصر الحالي هو الأصغر
        
        // الحلقة الداخلية تبحث عن العنصر الأصغر الفعلي
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j; // تحديث موقع أصغر عنصر
            }
        }
        // تبديل العنصر الحالي بأصغر عنصر تم العثور عليه
        swap(arr[i], arr[minIndex]);
    }
    
    // طباعة النتيجة
    for (int x : arr) 
        cout << x << ' ';
    cout << '\n';
    
    return 0;
}
شرح الكود:
استخدمنا حلقتين متداخلتين. الحلقة i تحدد الموقع الذي نريد وضع العنصر الصحيح فيه. الحلقة j تبحث في باقي المصفوفة عن أصغر عنصر. عندما تجده، تقوم الدالة الجاهزة swap بتبديل مكانهما.
التعقيد الزمني: بما أن هناك حلقتين متداخلتين تمران على العناصر، فإن عدد الخطوات يقارب $n \times n$. لذا فإن التعقيد الزمني هو $O(n^2)$. هذا يعتبر بطيئاً جداً للمصفوفات الكبيرة.

2. استخدام الدالة الجاهزة المدمجة (std::sort)

في البرمجة الحقيقية والمسابقات التنافسية، لا نكتب خوارزميات الترتيب البطيئة يدوياً. لغة C++ توفر دالة جاهزة ومحسنة جداً اسمها sort موجودة داخل مكتبة <algorithm>.

أ) ترتيب القوائم (Vectors)

#include <iostream>
#include <vector>
#include <algorithm> // ضرورية لاستخدام دالة sort

using namespace std;

int main() {
    vector<int> arr = {5, 8, 3, 4, 2};
    
    // ترتيب الـ vector بأكمله تصاعدياً
    sort(arr.begin(), arr.end());
    
    for (int x : arr) 
        cout << x << ' ';
    cout << '\n';
    return 0;
}
شرح الكود:
دالة sort تحتاج إلى معرفة نقطة البداية ونقطة النهاية. نمرر لها arr.begin() لتبدأ من أول عنصر، و arr.end() لتتوقف عند النهاية. النتيجة ترتبت فوراً (2 3 4 5 8).

ب) ترتيب المصفوفات العادية (Arrays)

#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n = 5;
    int arr[] = {5, 8, 3, 4, 2}; 
    
    // ترتيب المصفوفة العادية
    sort(arr, arr + n);
    
    for (int i = 0; i < n; i++)
        cout << arr[i] << ' ';
    cout << '\n';
    return 0;
}
شرح الكود:
مع المصفوفات العادية لا نملك begin() و end(). لذا نمرر اسم المصفوفة arr (والذي يمثل المؤشر للعنصر الأول)، ونقطة النهاية تكون arr + n (بداية المصفوفة زائد عدد عناصرها).

3. الترتيب التنازلي (Descending Order)

الترتيب الافتراضي هو تصاعدي. لجعله تنازلياً (من الأكبر للأصغر)، نمرر معامل مقارنة يسمى greater<int>() كعامل ثالث.

// للـ Vector
sort(arr.begin(), arr.end(), greater<int>());

// للمصفوفة العادية
sort(arr, arr + n, greater<int>());

// طريقة أخرى سريعة للـ vector باستخدام المؤشرات العكسية (Reverse Iterators)
sort(arr.rbegin(), arr.rend());
شرح الكود:
greater<int>() يخبر دالة الترتيب أن العنصر الأكبر يجب أن يأتي أولاً. طريقة rbegin() و rend() تجعل الترتيب يبدأ بقراءة المصفوفة من الخلف للأمام مما ينتج ترتيباً عكسياً (8 5 4 3 2).

4. الترتيب بمقارنة مخصصة (Custom Comparator)

ماذا لو أردنا ترتيب نصوص ليس أبجدياً، بل حسب طول الكلمة؟ هنا نكتب دالة شروط خاصة بنا (Comparator).

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// دالة المقارنة: ترجع true إذا كان a يجب أن يسبق b
bool comparator_by_length(string a, string string b) {
    if (a.length() < b.length())
        return true;  // ضع الكلمة الأقصر أولاً
    else
        return false;
}

int main() {
    vector<string> names = {"Charlie", "Bob", "Alice"};
    
    // تمرير دالة المقارنة كمعامل ثالث
    sort(names.begin(), names.end(), comparator_by_length);
    
    for (string s : names) cout << s << " ";
    return 0;
}
شرح الكود:
كتبنا دالة comparator_by_length تخبر الخوارزمية: "إذا كان طول الكلمة a أصغر من طول الكلمة b، فالترتيب صحيح (true)، وإلا فقم بتبديلهما". الناتج سيكون: Bob Alice Charlie (مرتبة حسب عدد الحروف: 3، 5، ثم 7 حروف).

⚠️ تحذير برمجي خطير:
دالة المقارنة يجب أن تتصرف حصرياً كقاعدة "أصغر من تماماً" (Strict Weak Ordering). لا تُرجع أبداً true إذا كان العنصران متساويين، وإلا ستدخل دالة sort في سلوك غير متوقع (Undefined Behavior) وقد تتسبب بانهيار البرنامج!

5. التعقيد الزمني لدالة (std::sort)

تستخدم الدالة المدمجة sort خوارزمية هجينة وذكية جداً تسمى Introsort (مزيج بين Quick Sort و Heap Sort و Insertion Sort).

التعقيد الزمني لهذه الدالة هو $O(n \log n)$، وهذا أسرع بكثير جداً من $O(n^2)$ الخاصة بترتيب الاختيار، خاصة عندما تكون المدخلات ضخمة.
  • إذا كان لديك $100,000$ عنصر ($10^5$):
  • ترتيب الاختيار $O(n^2)$: سيقوم بحوالي $10,000,000,000$ (عشرة مليار) عملية، وسيأخذ عدة ثوانٍ للانتهاء!
  • دالة sort $O(n \log n)$: ستقوم بحوالي $1,600,000$ (مليون وستمائة ألف) عملية فقط، وستنتهي في أجزاء من الألف من الثانية!
