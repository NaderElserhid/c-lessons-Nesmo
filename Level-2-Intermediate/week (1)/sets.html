المجموعات (Sets) في C++

الـ set في C++ هو حاوية لعناصر من نفس النوع ويحقق الخصائص التالية:

  • يحتوي على عناصر فريدة فقط (لا يسمح بالتكرار).
  • يكون دائمًا مرتبًا (تصاعدياً بشكل افتراضي).
  • يسمح بالإدراج والحذف والاستعلام بكفاءة عالية.
السر خلف الـ set (كيف تعمل؟):
حاوية set لا تضع العناصر بجوار بعضها في الذاكرة مثل المصفوفات العادية. بل تستخدم هيكل بيانات متقدم يسمى شجرة البحث الثنائية (Binary Search Tree). هذا التصميم الذكي هو ما يجعلها ترتب العناصر تلقائياً وتمنع التكرار بسرعة فائقة.
تنبيه (Caution): يمكن أن يحتوي set فقط على أنواع يمكن مقارنتها باستخدام معامل <.

الإعلان عن المجموعة (Declaration)

#include <iostream>
#include <set>
using namespace std;

int main () {
    set<int> my_int_set;
    set<double> my_double_set;
    set<string> my_string_set = {"abc", "def", "ghi"};
}

الحجم (Size)

تعيد الدالة size() عدداً يمثل عدد العناصر الفعلية الموجودة داخل المجموعة.

set<double> s = {1, 2, 3.2, 32.0 / 10.0};
cout << s.size(); // Output: 3

شرح المثال: العملية الحسابية 32.0 / 10.0 نتيجتها 3.2. وبما أن القيمة 3.2 تم إدخالها مسبقاً في نفس السطر، سترفض المجموعة هذه القيمة المكررة للحفاظ على قاعدتها. لذلك، حجم المجموعة سيكون 3 عناصر فقط، وليس 4.

الإدراج (Insert)

تضيف الدالة insert() عنصرًا إلى الحاوية فقط إذا لم يكن موجودًا مسبقًا وتحافظ على ترتيب العناصر.

set<int> s = {1, 3};
s.insert(2); // Now s = {1, 2, 3} not {1, 3, 2}
s.insert(3); // s remains unchanged

الحذف (Erase)

تزيل الدالة erase() عنصرًا من الحاوية فقط إذا كان موجودًا مسبقًا.

set<string> s = {"abc", "def"};
s.erase("xyz"); // s unchanged, "xyz" is not in the set
s.erase("abc"); // Now s = {"def"}

العد والبحث (Count)

تعيد الدالة count() عدد مرات ظهور القيمة. وبما أن التكرار ممنوع، فهي تعمل كإجابة لسؤال (هل العنصر موجود؟): تعيد 1 إذا كان موجوداً و 0 إذا لم يكن.

set<int> s = {1, 2, 3};
cout << s.count(2) << '\n'; // Output: 1
s.insert(2);
cout << s.count(2) << '\n'; // Output: 1 (No duplicates allowed)
s.erase(2);
cout << s.count(2) << '\n'; // Output: 0
تحذير (Warning): على الرغم من أن set لها ترتيب محدد، لا يمكننا الوصول إلى عنصر محدد باستخدام الفهارس [] (مثل s[0]). لمعرفة السبب وكيفية الوصول للعناصر، نستخدم حلقات التكرار.

التكرار والوصول للعناصر (Looping)

للمرور على جميع العناصر، نستخدم حلقة for المعتمدة على النطاق (Range-based for loop):

set<string> my_string_set = {"abc", "def", "ghi"};
for (string s : my_string_set) {
    cout << s << '\n';
}

مثال تطبيقي متكامل (Comprehensive Example)

#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> afak_students;

    afak_students.insert(105);
    afak_students.insert(101);
    afak_students.insert(108);
    afak_students.insert(103);
    afak_students.insert(101); // Attempt to duplicate

    cout << "Number of attending students: " << afak_students.size() << "\n";

    if (afak_students.count(103) == 1) {
        cout << "Student 103 is (Present).\n";
    }

    afak_students.erase(108);

    cout << "\nFinal Attendance List:\n";
    for (int id : afak_students) {
        cout << "- Student ID: " << id << "\n";
    }

    return 0;
}

اختبار معلوماتك (Interactive Quiz)

اختر الإجابة الصحيحة لكل من الأسئلة التالية لتختبر فهمك لدرس المجموعات:

1. أي من التالي يعتبر من الخصائص الأساسية لحاوية set في C++؟

  • أ) تسمح بتكرار العناصر وغير مرتبة.
  • ب) تمنع تكرار العناصر وترتبها تلقائياً.
  • ج) تعتمد على الفهارس (Indexes) للوصول للعناصر.
  • د) تخزن العناصر في مصفوفة متجاورة في الذاكرة.

2. ما هو هيكل البيانات (Data Structure) الذي تُبنى عليه حاوية set خلف الكواليس؟

  • أ) Linked List (القائمة المترابطة)
  • ب) Array (المصفوفة العادية)
  • ج) Binary Search Tree (شجرة البحث الثنائية)
  • د) Stack (المكدس)

3. ماذا يحدث إذا حاولت استخدام دالة insert() لإضافة عنصر موجود بالفعل في المجموعة؟

  • أ) يتوقف البرنامج عن العمل ويظهر خطأ (Error).
  • ب) يتم استبدال العنصر القديم بالعنصر الجديد.
  • ج) يتم إضافة العنصر وتكراره في المجموعة.
  • د) يتم تجاهل أمر الإضافة وتبقى المجموعة كما هي.

4. ما هو ناتج طباعة s.size() بعد تنفيذ الكود التالي؟
set<int> s; s.insert(5); s.insert(5); s.insert(5);

  • أ) 3
  • ب) 1
  • ج) 0
  • د) غير معروف

5. هل يمكنك الوصول إلى العنصر الأول في المجموعة باستخدام الكود s[0]؟

  • أ) نعم، يمكن ذلك دائماً.
  • ب) لا، المجموعات لا تدعم الوصول عبر الفهارس (Indexes).
  • ج) نعم، ولكن فقط إذا كانت المجموعة تحتوي على أرقام.
  • د) لا، يجب استخدام الدالة s.at(0) بدلاً من ذلك.

6. ما هي القيم الممكنة التي تعيدها دالة count(x) عند استخدامها مع set؟

  • أ) أي رقم صحيح يمثل عدد مرات التكرار.
  • ب) موقع العنصر في الذاكرة.
  • ج) 0 أو 1 فقط.
  • د) حجم المجموعة الكلي.

7. ماذا يحدث عند استدعاء s.erase(10) إذا كان الرقم 10 غير موجود في المجموعة s؟

  • أ) ينهار البرنامج (Crash).
  • ب) يتم إضافة الرقم 10 تلقائياً.
  • ج) يتم حذف أول عنصر في المجموعة.
  • د) لا يحدث شيء ويستمر البرنامج في العمل بشكل طبيعي.

8. إذا قمنا بإدراج العناصر {10, 5, 20} في مجموعة، بأي ترتيب سيتم طباعتها عند استخدام حلقة for؟

  • أ) 10 ثم 5 ثم 20 (حسب ترتيب الإدخال)
  • ب) 5 ثم 10 ثم 20 (تصاعدياً)
  • ج) 20 ثم 10 ثم 5 (تنازلياً)
  • د) ترتيب عشوائي في كل مرة.

9. ما هو المعامل (Operator) الذي يجب أن يدعمه نوع البيانات لكي يمكن تخزينه داخل set؟

  • أ) معامل الجمع +
  • ب) معامل المساواة ==
  • ج) معامل الأصغر من <
  • د) معامل الأكبر من >

10. ما هو ناتج s.size() للكود التالي؟
set<double> s = {2.5, 2.50, 5.0/2.0};

  • أ) 3
  • ب) 2
  • ج) 1
  • د) البرنامج سيظهر خطأ بسبب القسمة.
