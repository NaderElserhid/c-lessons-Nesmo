لماذا نحتاج المتغيرات؟

لحل المشكلات البرمجية، نحتاج إلى تخزين البيانات والعمل عليها، مثل الأرقام أو الحروف أو الكلمات. نقوم بتخزين هذه البيانات داخل المتغيرات (Variables) — وهي مساحات في الذاكرة نُطلق عليها اسماً لنستطيع استخدامها لاحقاً في برنامجنا.

variables.cpp 
#include <iostream>
using namespace std;

int main() {
    int age = 15;
    double height = 1.70;
    char grade = 'A';
    string name = "Ali";
    cout << name << " is " << age << " years old.";
    return 0;
}

اضغط على سطر من الكود لعرض شرحه هنا...

الناتج:

Ali is 15 years old.

أنواع أعداد إضافية: long long

عندما تصبح الأعداد كبيرة جداً بحيث لا يمكن تخزينها في متغير من نوع int (مثل التعامل مع المليارات أو التريليونات)، نستخدم النوع long long:

population.cpp
long long population = 8000000000; // 8 billion

السبب أن النوع int يمكنه عادة تخزين قيم تصل حتى حوالي 2 مليار (2,147,483,647). أما إذا احتجنا أعداداً أكبر، فنستخدم long long.

float و double

كلا النوعين يخزنان الأعداد العشرية، لكنهما يختلفان في الدقة (عدد الخانات العشرية التي يمكن تمثيلها بدقة):

النوعالدقة التقريبيةالمثال
floatحوالي 6–7 خانات عشرية3.141593
doubleحوالي 15–16 خانة عشرية3.141592653589793
precision.cpp
float f = 1.61;
double d = 1.61;
cout << setprecision(20); // عرض 20 خانة عشرية
cout << f << endl; // يطبع 1.6100000143051147461
cout << d << endl; // يطبع 1.6100000000000000977

تنبيه: كما تلاحظ في المثال، أغلب الأعداد الحقيقية لا يمكن تمثيلها بدقة تامة باستخدام float أو double. يجب أن تضع ذلك في اعتبارك دائماً عند التعامل مع هذه الأنواع. في الغالب يستخدم المبرمجون double لأنه أكثر دقة، لكنه يستهلك 8 بايت من الذاكرة مقابل 4 بايت فقط لـ float. لذا استخدم float فقط إذا كنت بحاجة فعلية لتقليل استهلاك الذاكرة.

bool

المتغير من نوع bool يمكن أن يأخذ قيمتين فقط: true أو false. غالباً ما نستخدمه في الشروط والمنطق داخل تعبيرات if:

bool.cpp
bool isEven = true;
bool isPrime = false;

int x = 7;
bool big = x > 10;
cout << big; // يطبع 0 (false)

القيمة true تمثَّل داخلياً بالرقم 1، بينما false تمثَّل بالرقم 0.

تحويل الأنواع

أحياناً نستخدم أنواعاً مختلفة في العملية نفسها:

conversion.cpp
int a = 3;
double b = 2.5;
cout << a + b; // 5.5

يقوم C++ بتحويل المتغير a مؤقتاً إلى double، لذلك يكون الناتج من نفس النوع.

اختياري: auto

الكلمة المفتاحية auto تسمح للمترجم بتحديد نوع المتغير تلقائياً من القيمة المُسندة إليه:

auto.cpp
auto x = 5;        // int
auto y = 3.14;     // double
auto word = "Hi";  // const char*

ستستخدمها غالباً في مسائل متقدمة لاحقاً.

تسمية المتغيرات

عند إنشاء متغيرات في C++، يجب اختيار اسم لكل متغير يوضح للبرنامج (وللقارئ البشري) وظيفته وما يمثله. الأسماء الجيدة تجعل الكود أكثر وضوحاً وسهولة في الفهم.

يمكنك
  • استخدام الحروف، الأرقام، والشرطة السفلية (_)
  • البدء بحرف أو بشرطة سفلية
  • استخدام الحروف الكبيرة والصغيرة (C++ تفرّق بينهما)
لا يمكنك
  • البدء برقم
  • استخدام المسافات
  • استخدام رموز خاصة مثل @, $, %, !, #, ?
  • استخدام الكلمات المحجوزة (مثل int, for, return, while)
أسماء صحيحة
int age;
double total_price;
bool isValid;
string firstName;
أسماء غير صحيحة
int 2cats;       // يبدأ برقم
int my variable; // يحتوي مسافة
int total$;      // رمز خاص
int int;         // كلمة محجوزة

حساسية حالة الأحرف (Case Sensitivity)

لغة C++ تفرّق بين الأحرف الكبيرة والصغيرة:

case.cpp
int score = 10;
int Score = 20;
cout << score; // يطبع 10

في هذا المثال، score وScore هما متغيران مختلفان تماماً.

أنماط التسمية

توجد عدة أنماط لتسمية المتغيرات، ومعظم مبرمجي C++ يستخدمون أحد الأنماط التالية:

النمطالمثالالاستخدام الشائع
snake_caseplayer_healthللمتغيرات والدوال في البرامج البسيطة
camelCaseplayerHealthيُستخدم عادة في المشاريع الكبيرة أو المكتبات
PascalCasePlayerHealthيُستخدم عادة في تعريف classes أو structs

اختر نمطاً واحداً والتزم به في جميع أجزاء الكود — الاتساق أهم من اختيار نمط معين بعينه.

naming.cpp 
#include <iostream>
using namespace std;

int main() {
    int playerHealth = 100;
    int playerScore = 2500;
    bool isAlive = true;
    cout << "Health: " << playerHealth << endl;
    cout << "Score: " << playerScore << endl;
    cout << "Alive: " << isAlive << endl;
    return 0;
}

الناتج:

Health: 100
Score: 2500
Alive: 1

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

Variableمتغيّر

مساحة في الذاكرة لها اسم، تُستخدم لتخزين قيمة يمكن تغييرها لاحقاً.

Integerعدد صحيح

رقم بدون كسور عشرية، موجباً كان أو سالباً.

Floating-pointعدد عشري (فاصلة عائمة)

رقم يحتوي على جزء كسري بعد الفاصلة العشرية.

Precisionالدقة

عدد الخانات العشرية التي يمكن تمثيلها بدقة لعدد ما.

Booleanمنطقي (ثنائي القيمة)

قيمة تأخذ إما صحيح (true) أو خطأ (false) فقط.

Stringنص / سلسلة نصية

تسلسل من الحروف يُستخدم لتخزين الكلمات والجمل.

Characterحرف

رمز واحد فقط، مثل حرف أو رقم أو علامة.

Memoryالذاكرة

المساحة داخل الحاسوب التي تُخزَّن فيها المتغيرات أثناء تشغيل البرنامج.

Byteبايت

وحدة قياس لحجم البيانات المخزَّنة في الذاكرة.

Type conversionتحويل الأنواع

تحويل قيمة من نوع بيانات إلى آخر، تلقائياً أو يدوياً.

Keywordكلمة مفتاحية

كلمة لها معنى خاص في اللغة، مثل int أو return.

Reserved wordكلمة محجوزة

كلمة لا يمكن استخدامها كاسم متغير لأنها جزء من لغة البرمجة نفسها.

Case sensitiveحسّاس لحالة الأحرف

يُفرّق بين الحروف الكبيرة والصغيرة، فيصبح score وScore مختلفين.

Naming conventionنمط التسمية

أسلوب موحّد لكتابة أسماء المتغيرات، مثل snake_case أو camelCase.

Input / Outputإدخال / إخراج

استقبال بيانات من المستخدم (input) أو عرضها على الشاشة (output).

autoاستنتاج النوع تلقائياً

كلمة مفتاحية تجعل المترجم يحدد نوع المتغير تلقائياً من قيمته.
