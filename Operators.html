العوامل (Operators)

هذا الشرح مقدم من منصة تويت كود

عامل الإسناد: =

تُستخدم العوامل (Operators) في إجراء العمليات الحسابية أو تعديل القيم المخزّنة في المتغيرات. أول وأهم عامل هو عامل الإسناد =، ويُستخدم لتعيين قيمة محدّدة إلى متغير.

assignment.cpp
int x;
x = 5; // here we set the value of the variable 'x' to 5

في المثال السابق، تم إسناد القيمة 5 (العامل الأيمن) إلى المتغير x (العامل الأيسر). يتم التقييم من اليمين إلى اليسار.

العوامل الحسابية

العاملالمعنى
*الضرب
/القسمة
%باقي القسمة (modulo)
+الجمع
-الطرح

جميع هذه العوامل ثنائية (binary)، أي تتطلّب عاملين (operands)، مثل: 5 * 3، 1 + 1، 6 / 2. يعيد عامل باقي القسمة % الباقي الناتج من قسمة العامل الأيسر على العامل الأيمن، بينما تُنفَّذ باقي العمليات تماماً كما في الرياضيات العادية.

إسناد التعابير (Assigning Expressions)

القيمة المسندة إلى متغير ليست بالضرورة ثابتة أو متغيراً آخر؛ إذ يمكن أن تكون تعبيراً حسابياً يحتوي على عدة عوامل رياضية معاً.

expressions.cpp
int x, y;
x = 5;
y = 3 + 2 * x;
// since '*' comes before '+' in operator precedence, y will be 13 not 25

الإسناد المركّب: *= /= %= += -=

إذا كنا نرغب في تعديل قيمة متغير ثم إسناد النتيجة إلى نفسه، يمكننا استخدام الصيغ المركّبة بدلاً من الكتابة الطويلة — أكثر اختصاراً ووضوحاً:

التعبير العاديباستخدام الإسناد المركّب
x = x + yx += y
x = x - 5x -= 5
x = x / yx /= y
price = price * (units + 1)price *= units + 1

الزيادة والنقصان: ++ و --

عند إضافة 1 إلى متغير، يمكننا استخدام x += 1، لكن توجد طريقة أقصر: x++ للزيادة وx-- للنقصان بمقدار واحد فقط.

increment.cpp
int x;
x = 0;
x++; // after this line is executed x is 1
x--; // after this line is executed x is 0

يوجد فرق دقيق بين ++x (سابقة / prefix) وx++ (لاحقة / suffix): في الحالة الأولى تحدث الزيادة قبل استخدام القيمة، وفي الثانية بعد استخدامها.

العوامل العَلاقية والمقارنة

تشبه هذه العوامل العوامل الحسابية من حيث أنها ثنائية، لكنها بدلاً من إجراء عمليات رياضية، تقوم بالمقارنة بين العاملين وتُرجع نتيجة من نوع منطقي (bool):

العاملالوصف

!=لا يساوي
<أصغر من

<=أصغر من أو يساوي

relational.cpp
int x = 1, y = 2;
bool same = (x == y);        // false, لأن x وy غير متساويين
bool x_less_than_y = (x < y); // true, لأن x أصغر من y

العوامل المنطقية: ! && ||

العامل ! (NOT) أحادي (unary)، يعمل على عامل منطقي واحد: إذا كانت قيمته true يُنتج false، والعكس صحيح.

not.cpp
bool a = (5 > 7);  // false
bool b = !a;       // true
bool c = !(7 > 5); // false

أما && (AND) و|| (OR) فهما ثنائيان، يُستخدمان لدمج قيمتين منطقيتين: && يُرجع true فقط إذا كانت كلتا القيمتين true، بينما || يُرجع true إذا كانت إحداهما (أو كلتاهما) true.

خاصية التقييم القصير (Short-Circuit Evaluation)

تتميّز العاملان && و|| بخاصية التقييم القصير. في التعبير A && B، إذا كانت A تساوي false، فلن يتم تقييم B إطلاقاً لأن النتيجة معروفة مسبقاً.

short_circuit.cpp
int x = 0;
bool b = (5 % 2 == 0) && (x++ == 0);
// (5 % 2 == 0) تُعيد false
// إذن لن يُنفَّذ الجزء الثاني (x++ == 0)
// ولذلك لن تتغيّر قيمة x إطلاقاً

وبالمثل، في حالة العامل ||: إذا كان العامل الأيسر true، فلن يتم تقييم العامل الأيمن على الإطلاق.

العامل الثلاثي الشرطي: ?:

يُعد هذا العامل ثلاثياً (ternary) لأنه يقبل ثلاثة عوامل: شرطاً، وتعبيراً عند تحقق الشرط، وآخر عند عدم تحققه. صيغته العامة:

ternary_syntax.cpp
condition ? expression_t : expression_f

إذا كان الشرط صحيحاً تُعاد expression_t، وإلا تُعاد expression_f:

ternary_example.cpp
int x = 5;
int y = (x % 2 == 0 ? x : x + 1);
// إذا كان x زوجياً فـ y = x، وإلا y = x + 1
// بما أن 5 فردي، فإن y = x + 1 = 6

ومثال شائع آخر: إيجاد الأكبر بين عددين a وb:

max_ternary.cpp
int max = (a > b ? a : b);

أولوية تنفيذ العوامل (Precedence of Operators)

عند وجود عدّة عوامل في تعبير واحد، تتّبع C++ ترتيباً محدداً لتنفيذها. مثلاً: 5 + 7 % 2 يُقيَّم إلى 6 لأن % يُنفَّذ قبل +. أما (5 + 7) % 2 فتكون نتيجته 0 بسبب الأقواس.

1لاحقة (أحادية)++ --زيادة/نقصان بعديةيسار → يمين
2سابقة (أحادية)++ -- !زيادة/نقصان سابقة، نفي منطقييمين → يسار
3حسابية (ضرب/قسمة)* / %الضرب، القسمة، باقي القسمةيسار → يمين
4حسابية (جمع/طرح)+ -الجمع والطرحيسار → يمين
5علاقية< > <= >=المقارنة بين القيميسار → يمين
6المساواة== !=التساوي وعدم التساوييسار → يمين
7اقتران منطقي&&منطق ANDيسار → يمين
8اقتران منطقي||منطق ORيسار → يمين
9إسناد وتعبيرات شرطية= *= /= %= += -= ?:إسناد، إسناد مركّب، عامل شرطييمين → يسار

باختصار: العوامل في المستويات العليا من الجدول (كـ ++ و* و/) تُنفَّذ قبل العوامل في المستويات الأدنى (كـ = و&&). عند الشك، استخدم الأقواس () لتوضيح الترتيب الذي تريده بدل الاعتماد على الحفظ.

قاموس المصطلحات

أهم المصطلحات الإنجليزية في هذا الدرس مع مرادفها العربي:

Operatorعامل

رمز يُجري عملية على قيمة أو أكثر، مثل + أو ==.

Operandمُعامَل

القيمة أو المتغير الذي يعمل عليه العامل.

Binary operatorعامل ثنائي

عامل يحتاج إلى عاملين (operands) لتنفيذ عمليته، مثل +.

Unary operatorعامل أحادي

عامل يعمل على مُعامَل واحد فقط، مثل ! أو ++.

Ternary operatorعامل ثلاثي

عامل يأخذ ثلاثة عناصر، وهو ?: الوحيد من هذا النوع في C++.

Precedenceأولوية التنفيذ

الترتيب الذي تُنفَّذ به العوامل عند وجود أكثر من عامل في تعبير واحد.

Associativityاتجاه التنفيذ

الاتجاه (يمين لليسار أو العكس) الذي تُنفَّذ به العوامل ذات الأولوية نفسها.

Compound assignmentإسناد مركّب

صيغة مختصرة تجمع بين عملية حسابية والإسناد معاً، مثل +=.

Increment / Decrementزيادة / نقصان

زيادة أو إنقاص قيمة متغير بمقدار واحد باستخدام ++ أو --.

Prefix / Postfixسابقة / لاحقة

موضع عامل ++ أو -- قبل المتغير (سابقة) أو بعده (لاحقة)، ولكل منهما سلوك مختلف.

Relational operatorعامل علاقي (مقارنة)

عامل يقارن بين قيمتين ويُرجع نتيجة منطقية، مثل < أو ==.

Short-circuit evaluationالتقييم القصير

تجاهل تقييم الجزء الثاني من تعبير منطقي إذا كانت النتيجة معروفة مسبقاً من الجزء الأول.

Moduloباقي القسمة

الباقي الناتج عن قسمة عدد على آخر، ويُرمز له بـ %.
